## Scope of GEO

The implementation emphasizes clear visible answers, factual consistency, internal discovery, and structured data matching the page. It does not promise rankings, citations, or rich results. No new AI-specific file format was introduced.

Reference: [Google Search Central: AI features and your website](https://developers.google.com/search/docs/appearance/ai-features). Google states that existing SEO fundamentals apply, important facts should be available as text, and structured data should match visible content; special AI markup is not required.
