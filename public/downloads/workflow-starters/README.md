# Safe starter files for Zush

All files are synthetic. The PDFs and spoken WAV reuse the public September 5, 2026 pilot fixtures. scan_001.pdf is a text invoice despite its generic name, not an image-only scan. document.pdf contains fictional meeting notes. voice_memo_042.wav is 11.49 seconds of synthetic speech about an autumn product launch. track_01.flac is a generated 3-second 440 Hz tone with artist Zush Demo and title Calibration Tone. It tests embedded tags, not music recognition. No real clients, financial records, voices, API keys, or local paths are included.

Use Zush 3.13+ on Mac or 3.10+ on Windows. Download Zush separately from https://zushapp.com/ . In Templates choose More (...) > Import Templates, select the .zushtemplates file, then select the imported Template in AI Rename. Test on copies. These archives contain two Templates each, explicit English output, sorting off and metadata writing off; no providers, keys, destination paths or monitoring settings. Free includes 50 renames total shared across all modes; importing does not remove that limit.

PDF: choose the invoice Template for scan_001.pdf and document Template for document.pdf. Compare date, vendor and invoice number against the page. The invoice issue date is 2026-08-18, vendor Northstar Studio, number NS-1042.

Audio: choose Spoken audio topic for voice_memo_042.wav and Tagged music artist and title for track_01.flac. Speech context depends on the AI mode and transcription path; templates do not install transcription or models. If a field is missing, review the file and adjust the name rather than guessing.

Before/after names on the website are illustrative targets for these patterns, not observed results from this new Template configuration. The separate 2026-09-05 pilot used Smart Title Name and produced Russian names; its results are not attributed to these new Templates. Apply reviewed names and use Rename History to restore them.
