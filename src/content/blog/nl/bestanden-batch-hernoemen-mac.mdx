## Wordt een gewijzigde bestandsnaam metadata op Mac?

Meestal niet. Een naam hoort bij het bestandspad en is niet hetzelfde als EXIF, Finder-tags, Spotlight-opmerkingen, pdf-titels of Office-eigenschappen. Na `IMG_4382.jpg` → `client-office-whiteboard.jpg` vinden Finder en Spotlight de nieuwe naam, maar camera, datum, gps en ingebedde metadata blijven gelijk.

- Gebruik **Finder Name and Index** voor zichtbare namen als `invoice-001.pdf`.
- Gebruik **Automator of Terminal** om bestaande metadata in namen te verwerken.
- Gebruik **AI-batchhernoemen** als de nuttige naam uit screenshot- of pdf-inhoud moet komen.

Wil je schone namen én zoekcontext, kies dan een tool die ook tags of metadata kan schrijven. Alleen Finder hernoemen volstaat dan niet.

Eenvoudige regels zijn eenvoudig; unieke beschrijvende namen zijn dat niet. Name and Index volstaat voor `photo-001.jpg`. Voor gemengde screenshots, pdf's en downloads is inhoudsbegrip nodig. Bij vooral foto's behandelt [foto's organiseren op Mac](/blog/best-ways-to-organize-photos-on-mac) ook mappen, datums, tags en back-ups.

## Methode 1: Finder Wijzig naam

Finder bevat een batchtool voor tekst vervangen, tekst vóór/achter een naam toevoegen en namen opmaken met een nummer of teller.

### Wanneer Finder-batchhernoemen gebruiken

Gebruik Finder als alle bestanden dezelfde voorspelbare regel krijgen: prefix, suffix, vervanging of nummerreeks. Voor complexere regex kun je [Bulk Rename Utility-alternatieven op Mac](/blog/bulk-rename-utility-alternatives) of [Advanced Renamer](/blog/advanced-renamer-alternatives) bekijken.

### Stap voor stap: bestanden batchgewijs hernoemen in Finder

1. Open Finder en zet de gewenste sorteervolgorde.
2. Selecteer de bestanden.
3. Klik met rechts en kies **Wijzig naam van X onderdelen**.
4. Kies **Vervang tekst**, **Voeg tekst toe** of **Opmaak**.
5. Controleer het voorbeeld linksonder.
6. Klik op **Wijzig naam**.
7. Gebruik direct `Cmd+Z` bij een fout.

### Voorbeelden van Finder-hernoemen

#### Modus Vervang tekst

Vervang `IMG_` door `vakantie-2026-`. Geschikt wanneer alleen een vast fragment verandert.

#### Modus Voeg tekst toe

Voeg `client-acme-` vóór bestaande namen toe of `-approved` erachter.

#### Modus Opmaak

Kies **Naam en index** voor `project-1`, `project-2`; gebruik **Naam en teller** voor vaste nulvulling. Finder volgt de selectievolgorde.

### Beperkingen van Finder-batchhernoemen

Finder leest geen screenshot, pdf of foto. Het maakt geen unieke beschrijving per bestand en schrijft zonder extra tool geen [Finder-tags en Spotlight-metadata](/mac).

### Verandert Finder-batchhernoemen metadata?

Nee. Finder wijzigt de naam en het pad, niet EXIF, opmerkingen of documenteigenschappen. De Finder-zoekindex ziet de nieuwe naam wel.

## Methode 2: Automator-workflows

Automator bewaart een vaste reeks acties, bijvoorbeeld bestanden ophalen, type filteren, kopiëren en hernoemen.

### Wanneer Automator gebruiken

Gebruik Automator voor een identieke terugkerende regel: datum prefixen, extensies filteren of een klantcode toevoegen. Lees ook [bestanden hernoemen met Automator op Mac](/blog/macos-automator-rename-files-guide).

### Stap voor stap: een Automator-workflow bouwen

1. Open Automator en kies **Snelle taak** of **Programma**.
2. Voeg **Vraag om Finder-onderdelen** toe.
3. Voeg voor veiligheid eerst **Kopieer Finder-onderdelen** toe.
4. Voeg **Wijzig naam Finder-onderdelen** toe.
5. Kies datum, tekstvervanging of volgnummer.
6. Bewaar en test met kopieën.

### Automator-voorbeeld: klantbestanden met datumprefix

Laat Automator een aanmaakdatum vóór `deliverable-01.pdf` zetten. Bestaande metadata kan zo een consistente naam voeden.

### Beperkingen van Automator

Automator begrijpt geen inhoud en complexe acties vragen onderhoud. Gebruik de [gids voor veilig batchhernoemen](/blog/how-to-safely-batch-rename-files) vóór echte archieven.

### Shortcuts: hier investeert Apple nu in

Shortcuts biedt een moderne, deelbare workflow. Maak een shortcut die bestanden vraagt, details zoals Aanmaakdatum ophaalt, namen opbouwt, previewt en daarna hernoemt. Voor achtergrondbewaking is een Folder Action of app geschikter.

## Methode 3: Terminal-scripts voor bulkhernoemen op Mac

Scripts zijn krachtig voor regex, metadata en precies vastgelegde regels. Werk eerst in een kopie en print de geplande uitvoer.

### Wanneer scripts gebruiken

Kies Terminal wanneer je de logica exact kunt beschrijven en onderhouden. Gebruik geen geïmproviseerd script op je enige archief.

### Eenvoudig hernoemen met een lus

```bash
for f in *.jpeg; do
  mv "$f" "${f%.jpeg}.jpg"
done
```

### Tekst in namen vervangen

```bash
for f in *\ *; do
  mv "$f" "${f// /-}"
done
```

### Datumprefix uit bestandsmetadata toevoegen

Gebruik `exiftool` om de EXIF-datum als `YYYY-MM-DD` vóór de naam te zetten:

```bash
for f in *.jpg; do
  date=$(exiftool -d "%Y-%m-%d" -DateTimeOriginal -s3 "$f")
  mv "$f" "${date}_${f}"
done
```

### Volgnummers met voorloopnullen

`printf` maakt nummers met voorloopnullen en houdt alfabetische sortering bruikbaar:

```bash
counter=1
for f in *.png; do
  mv "$f" "$(printf 'slide-%03d.png' $counter)"
  counter=$((counter + 1))
done
```

### De opdracht `rename` gebruiken (Perl)

Na installatie via Homebrew kan `rename` regex-vervangingen op een hele set uitvoeren:

```bash
rename 's/IMG_/vacation-/' *.jpg
```

### Beperkingen van scripts

Fouten, botsingen, extensies en spaties vragen expliciete afhandeling. Scripts bieden standaard geen preview-UI of volledige undo. Gebruik eerst `echo` voor een dry-run:

```bash
for f in *.jpg; do
  echo "mv $f -> vacation-${f#IMG_}"
done
```

## Veelgemaakte fouten bij batchhernoemen

### De extensie vergeten

Behoud `.pdf`, `.jpg` of `.docx`; een verkeerd verwijderde extensie kan apps verwarren.

### Niet eerst op een kopie testen

Test tien representatieve bestanden. Controleer ook herstel vóór honderden items.

### Problematische tekens gebruiken

Vermijd `/`, `:` en onnodige spaties in gedeelde workflows. Gebruik de [beste regels voor bestandsnamen](/blog/file-naming-conventions-best-practices).

### De verkeerde methode kiezen

Gebruik geen AI voor één vaste prefix en geen Finder wanneer elk bestand een unieke inhoudsnaam vraagt.

### Sorteervolgorde negeren

Finder nummert op selectievolgorde. Sorteer zichtbaar en controleer het eerste en laatste item.

## Veelgestelde vragen

### Wat is de snelste manier om bestanden batchgewijs te hernoemen op Mac?

Voor dezelfde regel is Finder het snelst. Voor unieke inhoudsnamen is een previewgerichte AI-app sneller.

### Hoe hernoem ik bestanden op Mac zonder iets te installeren?

Gebruik Finder, Automator, Shortcuts of Terminal; ze worden met macOS geleverd.

### Kan Finder bestanden op inhoud hernoemen?

Nee. Finder vervangt tekst, voegt tekst toe of nummert, maar analyseert geen inhoud.

### Voegt Finder Name and Index metadata toe op Mac?

Nee. Finder verandert alleen naam en pad. Tags, EXIF en documentmetadata blijven ongewijzigd.

### Kan ik een batchhernoeming op Mac ongedaan maken?

Direct na Finder-hernoemen werkt `Cmd+Z`. Voor blijvende geschiedenis kies je een tool die batches registreert.

### Wat is de beste manier om foto's met datums te hernoemen op Mac?

Gebruik EXIF-datum via metadataworkflow en behoud originelen. Voor inhoudsdetails combineer je datum met AI.

### Hoe hernoem ik honderden screenshots op Mac?

Gebruik mapbewaking en preview. Zie [screenshots automatisch hernoemen op Mac](/blog/rename-screenshots-automatically-mac).

### Kan ik pdf's batchgewijs hernoemen op inhoud?

Ja, met tekst-/OCR-analyse. Zie [pdf's automatisch hernoemen](/blog/rename-pdf-files-automatically).

### Verandert batchhernoemen metadata of aanmaakdatum?

Normaal verandert alleen naam/pad. Controleer gespecialiseerde tools als ze tags of metadata schrijven.

### Welke conventie gebruik ik voor batchnamen?

Gebruik voorspelbare onderdelen zoals `YYYY-MM-DD_onderwerp_type_volgnummer`. Lees [Best practices voor bestandsnamen](/blog/file-naming-conventions-best-practices).
