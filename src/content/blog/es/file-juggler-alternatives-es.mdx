## Lo que File Juggler hace bien

File Juggler es una herramienta de automatización para Windows creada por un desarrollador independiente en Dinamarca. Las reglas se construyen con tres partes:

1. **Carpetas vigiladas**, como Descargas, el Escritorio o la carpeta del escáner.
2. **Condiciones**: nombre y ruta del archivo, texto dentro del archivo, tamaño y fecha de creación o modificación.
3. **Acciones**: mover, copiar, renombrar, cambiar la extensión, eliminar o enviar a la Papelera de reciclaje, extraer archivos comprimidos, añadir a un zip, ejecutar un comando o subir a Evernote.

Reacciona casi al instante porque se suscribe a las notificaciones de cambios de carpeta en lugar de escanear cada cierto tiempo. Puede leer el texto de archivos PDF, Word y Excel y reutilizar en el nuevo nombre las palabras y fechas que encuentra. La versión 3.1.9 salió el 30 de octubre de 2026, así que no está abandonado. Los editores de Softpedia le dan un 4,5/5, la misma nota que a Zush.

El precio es sencillo: $50 de pago único antes de impuestos al pagar, válido para todas las actualizaciones futuras. Una licencia cubre a una persona en varios PC, o un PC compartido por varias personas. La prueba de 30 días incluye todas las funciones y, cuando termina, la aplicación te recuerda que la compres pero sigue funcionando.

## Por qué la gente busca una alternativa

- **Sin IA.** Cada regla hay que escribirla a mano. Una regla no puede atrapar `Screenshot 2026-10-02 141203.png` ni `IMG_4382.jpg`, porque nada en el nombre ni en el texto dice qué es el archivo.
- **Sin OCR.** Las preguntas frecuentes de File Juggler dicen que los escaneos que solo contienen imagen no tienen texto buscable, así que necesitas un programa de OCR aparte antes de que sus reglas de contenido puedan reconocerlos.
- **Solo Windows.** No hay versión para Mac. En Mac, el equivalente es [Hazel](/hazel-alternative).
- **No es un servicio.** Funciona mientras hay un usuario con la sesión iniciada, así que no encaja bien en servidores.
- **El precio**, si solo necesitas ordenar por tipo de archivo. Varias herramientas gratuitas ya lo hacen.

## 1. Zush: para los archivos que las reglas no pueden describir

[Zush para Windows](/windows) funciona en Windows 10 y 11 desde [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X). En lugar de comprobar condiciones, lee el archivo: el texto de un PDF o un escaneo, el contenido de una foto o una captura, los fotogramas, la voz y los subtítulos de un vídeo (MKV incluido). Después propone un nombre como `2026-09-12_acme_invoice_1042.pdf` o `stripe-revenue-dashboard-september.png`.

![Zush para Windows renombrando un lote variado según su contenido, con cada nombre propuesto visible antes de aplicar el lote](/videos/windows/zush-batch-rename.mp4)

Donde File Juggler necesita una regla por destino, Zush acepta una sola frase en **Folder rules**, por ejemplo «Agrupa las facturas por empresa y los recibos por mes», o agrupa los archivos por contenido en Auto. Revisas los nombres y las carpetas propuestos a la vez antes de que se mueva nada. Comprueba los archivos ambiguos antes de aplicar.

![Zush para Windows mostrando una vista previa de los grupos de carpetas por contenido y de los nombres de archivo propuestos antes de Rename & sort](/images/showcase/windows/folder-sorting-light.webp)

Para la parte «siempre activa» de File Juggler, guarda la configuración en un Template y asígnala a **Monitor**. Los archivos nuevos que lleguen a Descargas o a la carpeta del escáner se renombran y clasifican a medida que aparecen. Rename History conserva los nombres antiguos y nuevos aunque reinicies, y Undo All revierte un lote completo y muestra los conflictos que haya. AI Rename también puede detectar descargas duplicadas y moverlas a la Papelera de reciclaje; las copias no consumen créditos y Undo las restaura.

Funciona desde el primer momento: los primeros 50 renombrados con IA usan la IA gestionada Zush Cloud AI sin cuenta, tarjeta, clave de API ni descarga de modelos. Para archivos que no deben salir del PC, cambia a Ollama o LM Studio, o usa tu propia clave de API.

![Pestaña Monitor de Zush para Windows vigilando las carpetas de capturas y Descargas y renombrando los archivos nuevos a medida que llegan](/images/showcase/windows/monitor-light.webp)

Elige Zush cuando tu lista de reglas no deja de crecer y aun así se le escapan archivos. Paso a paso: [clasificar archivos en carpetas con IA en Windows](/blog/sort-files-into-folders-with-ai-windows) y [30 reglas de carpeta listas para usar](/blog/ai-folder-sorting-prompts).

## 2. DropIt: el motor de reglas gratuito

DropIt es gratuito y de código abierto. Las reglas reconocen archivos por nombre, tamaño, fecha, propiedades o expresiones regulares, y 21 acciones cubren mover, copiar, renombrar, comprimir, extraer y más. Puedes arrastrar archivos a un objetivo flotante o dejar que escanee carpetas vigiladas cada cierto tiempo.

Punto débil: la última versión, la 8.5.1, es de febrero de 2018. Sigue funcionando, pero no esperes funciones nuevas ni IA.

Elige DropIt cuando solo necesitas «los PDF van aquí, las imágenes allá» y pagar no es una opción.

## 3. Sortio: planes con IA y reglas por debajo

Sortio combina los dos enfoques. Puedes escribir reglas clásicas o describir la organización en lenguaje natural, revisar un plan y dejar que renombre, cree carpetas y mueva archivos. Smart Folders sigue aplicando el plan a lo que va llegando. Funciona en Windows, macOS y Linux.

El plan gratuito incluye clasificación por reglas con hasta cinco reglas y tres Spaces, vista previa, historial de clasificación, deshacer y una prueba de IA única. Las carpetas vigiladas y las automatizaciones requieren Pro, por $14.99 al mes o $99 al año con un cupo mensual de IA. Ollama mantiene el procesamiento en local, y se inicia sesión con una cuenta de correo.

Elige Sortio si quieres reglas al estilo de File Juggler e IA en una sola aplicación, o si necesitas Linux. Punto débil: la parte siempre activa es exclusiva de Pro. Compáralo en detalle: [Zush vs Sortio](/blog/zush-vs-sortio).

## 4. Wisfile: limpieza gratuita con IA para documentos

Wisfile es gratuito, funciona en local en Mac y Windows, y renombra documentos según su contenido con plantillas como `Author-Year-Title`. También puede agrupar un lote en carpetas por tema. Sus preguntas frecuentes indican Word y PDF como formatos compatibles.

No vigila carpetas ni programa tareas: arrastras los archivos y lo ejecutas cada vez. Sus preguntas frecuentes también dicen que no tiene función de deshacer integrada, así que prueba antes con copias.

Elige Wisfile para una limpieza puntual de un archivo de papeles o documentos. Consulta [Zush vs Wisfile](/blog/zush-vs-wisfile) para verlo más de cerca.

## 5. PowerShell y el Programador de tareas: la vía hazlo tú mismo

Windows puede hacer los trabajos básicos de File Juggler sin software adicional. PowerShell mueve y renombra archivos; el Programador de tareas ejecuta el script al iniciar sesión o cada pocos minutos:

```powershell
Get-ChildItem "$env:USERPROFILE\Downloads" -Filter *.pdf |
  Move-Item -Destination "$env:USERPROFILE\Documents\PDFs"
```

Es gratis y tan flexible como tus scripts. A cambio, te encargas tú de los nombres duplicados, los archivos bloqueados, los registros y el deshacer. Más opciones: [cómo organizar la carpeta Descargas en Windows](/blog/organize-downloads-folder-windows).

## ¿Quedarte con File Juggler o cambiar?

- Tus archivos siguen patrones fijos (mismo banco, mismo formato, mismo prefijo en el nombre): **quédate con File Juggler**.
- Capturas, escaneos, fotos del móvil y descargas al azar con nombres sin sentido: **Zush**.
- Clasificación gratuita por extensión o nombre: **DropIt** o **PowerShell**.
- Reglas e IA en una sola herramienta, o Linux: **Sortio**.
- Una pasada gratuita y puntual sobre archivos PDF y Word: **Wisfile**.

También puedes usar los dos. Zush vigila Descargas y escribe nombres predecibles como `2026-10-02_acme_invoice.pdf`, y File Juggler mueve `*_invoice.pdf` a una carpeta fija de Finanzas. Cada herramienta hace la parte que mejor se le da. Prueba cualquier configuración con copias primero; nuestra lista sobre [cómo renombrar archivos por lotes de forma segura](/blog/how-to-safely-batch-rename-files) explica qué revisar.

Para una comparativa más amplia de herramientas con IA, consulta los [mejores organizadores de archivos con IA para Windows 11](/blog/best-ai-file-organizers-windows). ¿Vienes de Mac? Lee [alternativas a Hazel para Windows](/blog/hazel-for-windows-alternatives).

## Preguntas frecuentes

### ¿Hay una alternativa gratuita a File Juggler?

Sí. DropIt es gratuito y de código abierto, aunque su última versión es de febrero de 2018. El plan gratuito de Sortio incluye hasta cinco reglas, pero las carpetas vigiladas requieren Pro. PowerShell con el Programador de tareas es gratis si sabes programar scripts. Wisfile es gratuito para archivos PDF y Word. Zush incluye 50 renombrados con IA gratis, sin cuenta ni tarjeta, si tu problema son los nombres de archivo poco claros.

### ¿File Juggler sigue teniendo mantenimiento?

Sí. La versión 3.1.9 se publicó el 30 de octubre de 2026, según la propia página de novedades de File Juggler, y la licencia incluye todas las actualizaciones futuras. Eso lo convierte en uno de los pocos organizadores de Windows basados en reglas que siguen recibiendo actualizaciones con regularidad. DropIt, la principal alternativa gratuita, no ha sacado ninguna versión desde febrero de 2018.

### ¿File Juggler usa IA?

No. Compara condiciones que escribes tú, incluidas palabras que encuentra dentro de archivos PDF, Word y Excel, y puede reutilizar fechas que encuentra en el texto. No puede leer escaneos que solo contienen imagen sin un programa de OCR aparte, y no sabe qué muestra una foto o una captura. Para esos archivos necesitas una herramienta con IA como Zush, Sortio o Wisfile.

### ¿Vale la pena File Juggler por $50 frente a Zush por $48?

Compran cosas distintas. Los $50 más impuestos de File Juggler te dan un motor de reglas con todas las actualizaciones futuras, pero sin IA. La licencia de pago único de $48 de Zush incluye nombres con IA y clasificación en carpetas con la IA gestionada Zush Cloud AI, modos local y BYOK, renombrados ilimitados, todas las actualizaciones futuras y hasta 3 dispositivos entre Windows y Mac. Mucha gente usa los dos.

### ¿Zush o File Juggler envían mis archivos a algún sitio?

File Juggler ejecuta sus reglas en local. Con Zush depende del modo que elijas: con Ollama o LM Studio, el análisis se queda en tu PC; con Zush Cloud AI o tu propia clave de API, el contenido del archivo se envía a ese modelo en la nube para generar un nombre. Elige un modo local para carpetas confidenciales, y revisa también la configuración de Sortio, que ofrece IA alojada, BYOK u Ollama.

### ¿Existe File Juggler para Mac?

No, File Juggler es solo para Windows. Hazel es el equivalente más cercano en Mac para reglas, y los editores de Softpedia le dan un 5,0/5. Zush para Mac cubre los nombres con IA y la clasificación en carpetas, incluidas carpetas vigiladas en discos externos. Consulta nuestra página de [alternativa a Hazel](/hazel-alternative) para ver cómo se comparan los dos enfoques en un Mac.

### ¿Puede Zush sustituir del todo a File Juggler?

Para nombrar archivos según su contenido y clasificarlos en carpetas, sí, incluidas las carpetas vigiladas. File Juggler sigue teniendo acciones que Zush no ofrece, como ejecutar un comando, extraer archivos comprimidos o subir a Evernote. Si dependes de ellas, mantén File Juggler para esa parte y deja que Zush escriba los nombres descriptivos que sus reglas pueden reconocer.
