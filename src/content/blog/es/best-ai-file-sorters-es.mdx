## Cómo se decide la carpeta

Las instrucciones en lenguaje natural definen agrupaciones por proveedor, cliente, mes o tema: Zush, Sortio y Sparkle. Las listas de categorías fijan opciones como Facturas o Contratos: RenameClick y AI File Sorter. Las condiciones usan nombre, fecha o texto: Hazel, NameQuick Rules, File Juggler y DropIt. Una instrucción es flexible; las listas necesitan mantenimiento; las condiciones dependen de que cada archivo cumpla el patrón esperado.

## 1. Zush

Elige el **Destination folder** como raíz de las carpetas propuestas.

**Folder rules** admite hasta 2.000 caracteres; vacío, Auto crea pocos grupos amplios reutilizables. El **Template** define fecha, proveedor, importe, cliente o asunto en el nombre; Folder rules determina el destino. Se revisan juntos.

Lee PDF y escaneos de imagen, RAW y HEIC, capturas, Office, iWork, diseño, 16 formatos de vídeo y audio. Analiza fotogramas para comprender vídeos. **Reuse existing folders** aprovecha carpetas adecuadas y crea otras cuando ninguna encaja. **Monitor** aplica un Template a nuevos archivos y recuerda carpetas creadas. LM Studio y Ollama mantienen análisis y planificación locales. PRO incluye Zush Cloud AI sin límite mensual de archivos.

La clasificación está en beta y cada lote crea un nivel de carpetas dentro del destino. Revisa los casos ambiguos. Guías para [Mac](/blog/sort-files-into-folders-with-ai-mac) y [Windows](/blog/sort-files-into-folders-with-ai-windows).

## 2. Sortio

[Sortio](https://www.getsortio.com/) planifica nombres, carpetas y movimientos mediante instrucciones. Puede restringirse a carpetas existentes y enviar los casos sin coincidencia a una carpeta alternativa. El plan gratuito incluye clasificación ilimitada por reglas con hasta cinco reglas, vigilancia, deshacer y una prueba IA única. BYOK y Ollama están en todos los planes; Pro incluye un cupo IA. Menciona documentos, imágenes, PDF y hojas de cálculo sin publicar lista completa. Sortio para Linux o equipos; Zush para audio, vídeo, más control del nombre y pago único. [Zush frente a Sortio](/blog/zush-vs-sortio).

## 3. RenameClick

[RenameClick](https://rename.click/) ofrece AI Categories, Metadata Folders basadas en fechas o EXIF y Match Folders entre hasta 50 carpetas de primer nivel. Auto Flow vigila y mueve o copia mientras la app está abierta. Análisis ilimitado y 100 cambios de nombre o movimientos exitosos al mes gratis; modelo local incluido. Vídeo, RAW y diseño no están en su lista publicada. Para categorías fijas; Zush para agrupaciones deducidas del contenido. [Comparación](/blog/zush-vs-renameclick).

## 4. Sparkle

[Sparkle](https://makeitsparkle.co/) organiza Escritorio, Descargas y Documentos con una programación, crea una AI Library, acepta instrucciones y limpia duplicados y capturas antiguas enviándolos primero a la Papelera. Solo Mac; incluido también en Every. No renombra. Adecuado para limpieza personal automática; Zush si importan los nombres, Windows o reglas explícitas. [Alternativas](/blog/sparkle-alternatives).

## 5. NameQuick

[NameQuick](https://www.namequick.app/) renombra documentos por contenido y luego ejecuta Rules para mover, etiquetar, colorear o archivar. Managed empieza en $12/mes por 500 renombrados. Self-Managed de $69 requiere clave API o modelo local. Cada destino necesita una condición. [Comparación](/blog/zush-vs-namequick).

## 6. AI File Sorter

[AI File Sorter](https://github.com/hyperfield/ai-file-sorter) es gratuito y tiene licencia AGPL. Sugiere categorías, subcategorías opcionales y nombres, permite listas de categorías, lee imágenes con visión local y extrae texto. Usa modelos locales o clave propia; deshace la última ejecución. No tiene instrucciones libres para agrupar ni vigilancia. Audio y vídeo se clasifican por metadatos integrados. Para una limpieza puntual con configuración de modelo.

## 7. Hazel, File Juggler y DropIt

[Hazel](https://www.noodlesoft.com/) ($42, Mac), [File Juggler](https://www.filejuggler.com/) (unos $40, Windows) y [DropIt](https://www.dropitproject.com/) (gratis, Windows) vigilan condiciones de nombre, extensión, fecha o texto. Son fiables con archivos predecibles, pero no comprenden fotos, escaneos ni vídeo. Los nombres IA pueden facilitar sus reglas. [Alternativa a Hazel](/hazel-alternative), [opciones Windows](/blog/hazel-for-windows-alternatives).

## Elegir y probar

Zush para instrucciones libres y formatos variados; Sortio para Linux o equipos; RenameClick para categorías fijas; Sparkle para limpiar Mac sin renombrar; AI File Sorter para una opción gratuita; Hazel, File Juggler o DropIt para patrones exactos.

Copia primero 20 archivos variados: facturas, recibos, fotos, captura, escaneo y vídeo. Escribe una instrucción real, comprueba carpetas y destinos, aplica y prueba deshacer. ## Preguntas frecuentes

### ¿Cuál es la mejor opción general?
Zush para Mac y Windows, con revisión, audio, vídeo e IA local y sin cupo mensual PRO.

### ¿Puede funcionar automáticamente?
Zush, Sortio, RenameClick y Sparkle mueven archivos a carpetas. En Zush, guarda Folder rules en un Template y asígnalo a Monitor para nuevos archivos directamente dentro de la carpeta vigilada.

### ¿Hay opciones gratuitas?
AI File Sorter es gratuito; Zush ofrece 50 cambios, Sortio una prueba IA única y RenameClick 100 renombrados o movimientos mensuales.

### ¿Qué funciona sin conexión?
Zush con LM Studio u Ollama, RenameClick con su modelo incluido, Sortio con Ollama y AI File Sorter con modelos locales.

### ¿IA o reglas?
Las reglas comprueban nombres y extensiones. La IA interpreta el contenido y puede agrupar facturas por empresa aunque los nombres originales no den pistas.
