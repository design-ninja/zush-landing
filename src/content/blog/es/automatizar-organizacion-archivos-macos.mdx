## Qué debe resolver primero un organizador automático

Empieza por los archivos frecuentes y molestos. No se trata de construir un sistema universal el primer día, sino de eliminar uno o dos problemas recurrentes, ver el resultado y ampliar después.

Buenos candidatos:

- **Capturas**: macOS las llama `Screenshot 2026-03-12 at 10.44.11.png`, sin explicar el contenido.
- **Descargas**: navegador, correo y AirDrop acumulan nombres genéricos.
- **Exportaciones recurrentes**: facturas, extractos e informes semanales de las mismas apps.
- **Fotos de cámara**: `IMG_4382.HEIC` no ayuda seis meses después.
- **Volcados repetitivos de documentos**: entregables, PDF de investigación y activos de proyecto.

La automatización funciona mejor cuando elimina una molestia semanal, no cuando crea un sistema elaborado que nadie mantiene.

### Cómo detectar los peores casos

Abre Finder y ordena Descargas o Escritorio por Fecha de modificación. Examina los últimos 50 archivos y cuenta cuántos nombres explican su contenido. Si son menos de la mitad, esa carpeta es una buena candidata.

También puedes medir el volumen. Abre Terminal y ejecuta:

```bash
ls -1 ~/Downloads | wc -l
```

Si supera 200, hay un atraso que merece automatización.

## Carpetas inteligentes: configuración paso a paso

Las Carpetas inteligentes no mueven nada. Muestran dinámicamente archivos según criterios de búsqueda: son búsquedas de Spotlight guardadas en la barra lateral de Finder.

Sirven para reunir archivos dispersos sin reestructurar carpetas.

### Cómo crear una Carpeta inteligente

1. Abre Finder.
2. Pulsa **Cmd + F** o ve a **Archivo > Nueva carpeta inteligente**.
3. Pulsa **+** arriba a la derecha para añadir criterios.
4. Configura las condiciones de los ejemplos siguientes.
5. Pulsa **Guardar** y asigna un nombre.
6. Marca **Añadir a la barra lateral**.
7. Elige dónde guardar `.savedSearch`; la ubicación predeterminada sirve.

### Criterios más útiles

| Objetivo | Criterios |
|---|---|
| Capturas recientes | Tipo = Imagen, Nombre contiene «Screenshot», Modificado = últimos 7 días |
| Archivos grandes | Tamaño > 500 MB |
| PDF recientes | Tipo = PDF, Modificado = últimos 30 días |
| Documentos por revisar | Etiqueta = «Review», Tipo = Documento |
| Presentaciones | Tipo = Presentación |
| Descargas recientes | Carpeta = Descargas, Modificado = últimos 3 días |

### Consejos avanzados

- Mantén **Option** al pulsar **+** para grupos compuestos AND/OR.
- Filtra por extensión, creación, última apertura y muchos otros metadatos.
- Se actualizan en tiempo real y reflejan siempre el estado del disco.
- Funcionan en todos los volúmenes montados, incluidos discos externos.

No son automatización real porque no mueven ni renombran, pero permiten ver qué hace falta organizar antes de comprometerse con reglas.

Consulta la guía de [búsqueda y etiquetas en Finder](/blog/finder-tags-guide-organize-files-mac).

## Automator y Shortcuts: crear flujos reales

Automator y su alternativa moderna Shortcuts pueden renombrar, mover, copiar, redimensionar y convertir archivos mediante una interfaz visual.

### Acción de carpeta de Automator: ordenar Descargas por tipo

Este flujo supervisa Descargas y mueve archivos a subcarpetas según la extensión.

**Configuración paso a paso:**

1. Abre **Automator** desde Spotlight.
2. Elige **Acción de carpeta**.
3. Configura «recibe archivos y carpetas añadidos a» con **Descargas**.
4. Añade **Ejecutar script de shell**.
5. En «Pasar entrada», selecciona **como argumentos**.
6. Pega este script:

```bash
for f in "$@"; do
    ext="${f##*.}"
    ext=$(echo "$ext" | tr '[:upper:]' '[:lower:]')
    case "$ext" in
        pdf)
            dest="$HOME/Documents/PDFs" ;;
        jpg|jpeg|png|heic|webp|gif)
            dest="$HOME/Pictures/Downloads" ;;
        zip|gz|tar|dmg)
            dest="$HOME/Downloads/Archives" ;;
        doc|docx|xlsx|pptx|csv)
            dest="$HOME/Documents/Office" ;;
        *)
            dest="" ;;
    esac
    if [ -n "$dest" ]; then
        mkdir -p "$dest"
        mv "$f" "$dest/"
    fi
done
```

7. Guarda como «Ordenar Descargas por tipo».
8. La Acción queda activa y clasificará automáticamente los archivos nuevos.

### Shortcuts: una alternativa más sencilla desde macOS Ventura

En macOS Ventura o posterior, Shortcuts sustituye Automator en muchas tareas. Ofrece una interfaz más limpia y mejor integración con activadores del sistema.

**Ejemplo: renombrar y mover capturas**

1. Abre **Shortcuts**.
2. Crea un atajo.
3. Añade **Obtener contenido de carpeta** y elige Capturas.
4. Añade **Filtrar archivos** cuyo nombre contenga «Screenshot».
5. Añade **Renombrar archivo** con un patrón como `Screenshot-[Date Created]`.
6. Añade **Mover archivo** al destino deseado.
7. Para automatizar, abre **Automatización** y crea un activador al añadir archivos a Capturas.

Shortcuts funciona mejor para automatizaciones puntuales; Automator, para flujos complejos con scripts shell. La [guía para renombrar con Automator](/blog/macos-automator-rename-files-guide) ofrece un recorrido completo.

## Hazel para rutas complejas basadas en reglas

Hazel es útil cuando una carpeta requiere reglas continuas con varias condiciones, movimientos en segundo plano, etiquetas, archivos o scripts. Una regla típica puede mover PDF cuyo nombre incluya `invoice` a una carpeta de año y mes y dejar intactas las demás descargas.

Hazel y los nombres según contenido resuelven capas distintas. Hazel destaca cuando extensión, fecha, etiqueta, patrón o texto extraído ofrecen una condición fiable. La IA es más útil si hay que entender una captura, foto, vídeo o escaneo genérico antes de nombrarlo.

Mantén el orden explícito: primero renombra y después enruta. No dejes que dos herramientas observen y modifiquen la misma carpeta de entrada a la vez. Para comparar funciones, consulta [Zush como alternativa a Hazel](/hazel-alternative).

## Dónde falla la automatización basada en reglas

Las reglas funcionan si el archivo ya revela qué es mediante nombre, extensión o metadatos.

Fallan cuando llega como:

- `IMG_4382.HEIC`
- `Screenshot 2026-03-12 at 10.44.11.png`
- `download (7).jpg`
- `Document.pdf`
- `Untitled.png`
- `image (3).webp`

Una regla puede moverlos, pero no explicar qué contienen. Sin un nombre descriptivo, seguirán siendo difíciles de encontrar aunque estén en carpetas perfectas.

Aquí resulta útil la IA. Una herramienta que analiza píxeles, fotogramas, texto PDF o diseño de documentos puede generar un nombre que describa realmente el archivo.

Para entenderlo en la práctica, consulta el [renombrador para Mac y Windows](/).

## Configuración recomendada: paso a paso

Este sistema combina las herramientas anteriores y puede montarse en menos de una hora.

### Paso 1: evalúa el desorden actual

Abre Descargas, Escritorio y Documentos. Anota dónde hay más nombres inútiles y elige las dos carpetas problemáticas principales.

### Paso 2: crea Carpetas inteligentes para visibilidad

Crea tres búsquedas guardadas:

1. **Archivos grandes recientes**: Tamaño > 100 MB, Modificado = últimos 30 días.
2. **Capturas sin ordenar**: Tipo = Imagen, Nombre contiene «Screenshot», Modificado = últimos 14 días.
3. **Documentos recientes**: Tipo = Documento O Tipo = PDF, Modificado = últimos 7 días.

Así ves inmediatamente qué necesita atención.

### Paso 3: configura rutas básicas

Elige una opción:

**Opción A: Acción de carpeta de Automator** (gratis e integrada en Automator)
- Crea el flujo de Descargas descrito arriba.
- Tarda diez minutos y cubre los tipos comunes.

**Opción B: reglas de Hazel** (de pago y con el motor avanzado de Hazel)
- Instala Hazel y crea entre tres y cinco reglas para Descargas.
- Envía PDF a Documentos, imágenes a Imágenes y comprimidos a una carpeta propia.
- Añade limpieza para archivos con más de 30 días.

**Opción C: automatización de Shortcuts** (gratis, macOS Ventura+)
- Crea un atajo que clasifique por tipo.
- Ejecútalo con horario o manualmente.

### Paso 4: añade nombres con IA para archivos visuales

![Pestaña Monitor de Zush con supervisión configurada para Escritorio](/images/showcase/macos/monitor-light.webp)

Instala [Zush para Mac](/mac) y configura la supervisión de Capturas y Descargas. Así resuelve lo que las reglas no pueden nombrar bien:

- Las capturas reciben nombres según la app y el contenido visible.
- Los PDF se nombran según su texto.
- Las fotos se nombran según la imagen.
- Las descargas dejan de llamarse `download (7).jpg`.

### Paso 5: revisa cada semana

Aunque automatices, dedica cinco minutos semanales a las Carpetas inteligentes. Detectarás casos límite y podrás mejorar las reglas.

### Paso 6: amplía gradualmente

Tras una semana, comprueba qué sigue escapándose y añade reglas o Carpetas inteligentes. No intentes cubrir todos los casos desde el principio.

## Errores comunes que debes evitar

**Automatizar demasiado pronto.** No crees 20 reglas de Hazel sin saber qué necesita enrutarse. Empieza con dos o tres.

**Ignorar el problema de los nombres.** Mover archivos no ayuda si todos siguen llamándose `IMG_4382.HEIC`; tendrás que abrirlos uno por uno. Nombrar es tan importante como clasificar.

**No probar las reglas.** Antes de activar una Acción de carpeta o Hazel en Descargas, usa una carpeta ficticia. Una regla incorrecta puede dispersar archivos por el disco.

**Olvidar las subcarpetas.** Muchas herramientas solo supervisan un nivel. Si llegan archivos dentro de subcarpetas, activa explícitamente la recursividad.

**No tener reversión.** Toda automatización que mueva o renombre necesita salida. Hazel conserva logs, Zush permite revertir y Automator no; trata con cuidado las acciones destructivas.

## FAQ

### ¿Cómo automatizo la organización en Mac sin instalar nada?

Usa Carpetas inteligentes para mostrar archivos y Automator o Shortcuts para enrutarlos. Las primeras están en Finder > Archivo > Nueva carpeta inteligente. Automator crea Acciones de carpeta al llegar nuevos elementos. Cubren clasificaciones básicas por tipo, fecha y patrón sin software adicional.

### ¿Cuál es la diferencia entre Automator y Shortcuts?

Automator es más antiguo y ofrece más tipos de acción, scripts shell y Acciones de carpeta. Shortcuts apareció después, tiene una interfaz más limpia e integra activadores y Siri. Para archivos, Automator sigue siendo más capaz por sus scripts y manipulación amplia. Apple traslada funciones poco a poco a Shortcuts, así que conviene conocer ambos.

### ¿Puede Hazel renombrar según el contenido?

Hazel puede leer texto de PDF y documentos y usarlo en reglas; por ejemplo, extraer fecha o palabra clave. No analiza imágenes ni vídeos porque carece de visión. Para capturas, fotos y grabaciones necesitas una herramienta con IA que vea el contenido.

### ¿Cómo evito que Descargas se llene?

Usa dos capas. Primero, reglas de Automator o Hazel mueven los archivos por tipo al llegar. Después, otra regla de Automator o Hazel envía los de más de 30 días a Archivo o Papelera. Consulta la [guía para organizar Descargas](/blog/how-to-organize-downloads-folder-mac).

### ¿Es seguro renombrar con IA?

La IA solo cambia el nombre, no el contenido. Herramientas como Zush guardan historial para revertir al instante. El riesgo es bajo, pero prueba con un lote pequeño y confirma la calidad antes de supervisar carpetas de gran volumen.

### ¿Cómo automatizo fotos específicamente?

Los nombres originales (`IMG_`, `DSC_`, `DCIM`) no describen el contenido. Combina nombres con IA y clasificación por fecha o evento. Consulta la [guía para organizar fotos en Mac](/blog/best-ways-to-organize-photos-on-mac).

### ¿Puedo combinar varias herramientas?

Sí, y es recomendable. Usa Carpetas inteligentes para visibilidad, Hazel o Automator para rutas e IA para nombres según contenido. Cada una cubre una capa; mantén reglas simples para que el sistema sea sostenible.

### ¿Qué ocurre si dos reglas entran en conflicto?

Si Hazel y una Acción de carpeta de Automator observan el mismo lugar, pueden competir: uno mueve el archivo antes de que el otro termine. Usa una sola herramienta de automatización por carpeta. Si quieres nombrar y enrutar, deja que Zush renombre primero y que Hazel mueva después según el nombre nuevo.

## Conclusión

Para automatizar macOS de forma eficaz, deja las decisiones simples a las reglas y la ambigüedad visual a la IA. Así obtendrás un sistema mantenible.

Empieza con Carpetas inteligentes para visibilidad. Añade Automator o Hazel para rutas e IA para archivos con nombres inútiles. Revisa semanalmente y amplía poco a poco.

El objetivo no es la perfección, sino dedicar cinco minutos semanales a organizar en lugar de treinta.
