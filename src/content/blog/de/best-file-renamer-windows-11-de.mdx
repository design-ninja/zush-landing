Kurze Antwort: Wenn jede Datei die gleiche Art von Änderung bekommt, etwa ein Präfix, ein Datum oder eine Nummernfolge, nutzen Sie **PowerRename**. Das Tool ist kostenlos von Microsoft und erledigt die meisten Musteraufgaben. Wenn jede Datei einen eigenen Namen braucht, der sich aus ihrem Inhalt ergibt, nehmen Sie einen KI-Umbenenner wie [Zush](/windows).

Diese Unterscheidung entscheidet alles Weitere. Mustertools sind schnell und präzise, verändern aber nur den Namen, den eine Datei schon hat. Aus `IMG_4382.jpg` kann `Vacation_001.jpg` werden, aber nie `lisbon-tram-at-night.jpg`.

**Zush-Funktionen geprüft am 18. Oktober 2026.** Für Angaben zu anderen Produkten gelten weiterhin die im Artikel genannten Prüfzeitpunkte.

## 1. File Explorer: ausreichend für fünf Dateien

Markieren Sie mehrere Dateien, drücken Sie **F2**, geben Sie einen Namen ein und drücken Sie Enter. Windows benennt sie dann `Trip (1).jpg`, `Trip (2).jpg` und so weiter. Mit **Ctrl+Z** machen Sie das sofort rückgängig.

Mehr kann er nicht. Keine Vorschau, keine Datumsangaben, kein Suchen und Ersetzen. Nutzen Sie ihn, wenn das Ergebnis nur ordentlich, aber nicht aussagekräftig sein muss.

## 2. PowerRename: die beste kostenlose Wahl für die meisten

[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename) gehört zu Microsoft PowerToys. Dateien markieren, Rechtsklick, **Rename with PowerRename** wählen, und schon haben Sie Suchen und Ersetzen mit Live-Vorschau.

Es kann mehr, als man ihm ansieht:

- Reguläre Ausdrücke, einschließlich Capture-Gruppen (`29-03-2020` → `2020-03-29`)
- Zähler mit Auffüllung und Startwerten (`Image_${padding=4}`)
- Variablen für das Erstellungsdatum der Datei wie `$YYYY-$MM-$DD`
- EXIF-Felder von Fotos wie `$DATE_TAKEN_YYYY`, `$CAMERA_MODEL` und GPS-Koordinaten

Wählen Sie PowerRename für jede Aufgabe, die sich als Muster beschreiben lässt. Zur KI-Seite lesen Sie unsere Seite zur [PowerRename-Alternative](/windows).

## 3. Bulk Rename Utility: maximale Kontrolle

[Bulk Rename Utility](https://www.bulkrenameutility.co.uk/) packt alle Musteroptionen in ein dichtes Fenster: Regex, JavaScript, automatische Nummerierung, EXIF-Datumsangaben, MP3-Tags, CSV-gesteuerte Umbenennungen und Änderungen von Zeitstempeln. Es verarbeitet über 100.000 Dateien, ohne langsamer zu werden. Rückgängigmachen funktioniert über eine erzeugte Batch-Datei, die die Änderung umkehrt.

Für private Nutzung ist es kostenlos; für geschäftliche Nutzung braucht es eine kommerzielle Lizenz. An die Oberfläche muss man sich etwas gewöhnen. Mehr dazu in unserem Leitfaden zu den [Alternativen zu Bulk Rename Utility](/blog/bulk-rename-utility-alternatives).

## 4. Advanced Renamer: am besten für Foto- und Musik-Metadaten

[Advanced Renamer](https://www.advancedrenamer.com/) baut einen Namen aus gestapelten Methoden auf: Tags aus EXIF, ID3, Videoeigenschaften und GPS (Koordinaten lassen sich in einen Städtenamen umwandeln). Es zeigt eine Live-Vorschau und kann einen ganzen Batch rückgängig machen. Es läuft auch unter macOS.

Für leichte private Nutzung ist es kostenlos. Regelmäßige Nutzer sollen eine private Lizenz für $25 kaufen, für den beruflichen Einsatz ist eine gewerbliche Lizenz für $45 nötig. Beide sind einmalige Zahlungen. Lesen Sie unseren [Test zu Advanced Renamer](/blog/advanced-renamer-alternatives).

## 5. ReNamer: Regeln und Skripte

[ReNamer](https://www.den4b.com/products/renamer) wendet eine geordnete Liste von Regeln an: Einfügen, Löschen, Ersetzen, Groß-/Kleinschreibung, Regex, Meta-Tags und Pascal Script für alles Individuelle. Es ist portabel und unterstützt über 25 Oberflächensprachen.

ReNamer Lite ist für nicht-kommerzielle Nutzung kostenlos und auf 5 Regeln und 5 Voreinstellungen begrenzt. Pro hebt diese Grenzen auf und erlaubt die kommerzielle Nutzung.

## 6. Zush: wenn jede Datei einen eigenen Namen braucht

[Zush](/windows) arbeitet anders. Statt den alten Namen zu bearbeiten, schaut es sich die Datei an: den Text in einem PDF, was ein Screenshot zeigt, die Szene auf einem Foto, den Inhalt einer Word- oder Excel-Datei. Dann schreibt es einen Namen, der sie beschreibt.

| Vorher | Nachher |
|---|---|
| `Screenshot 2026-09-18 141203.png` | `github-pull-request-review-comments.png` |
| `scan_0042.pdf` | `2026-09-12_acme_invoice_1042.pdf` |
| `Document1.docx` | `q3-marketing-plan-draft.docx` |
| `IMG_4382.jpg` | `2026-08-30_lisbon_tram_street.jpg` |

Die Form behalten Sie selbst in der Hand. Templates und über 145 Naming Blocks legen die Reihenfolge (Datum, Anbieter, Kunde, Titel), die Groß-/Kleinschreibung und die Trennzeichen fest. Sie prüfen jeden Vorschlag, bevor Sie ihn anwenden, und Rename History kann einen ganzen Batch später wiederherstellen. Die Ordnerüberwachung benennt neue Dateien in Downloads oder in einem Scanner-Ordner automatisch um.

Die KI kann über Zush Cloud AI, Ihren eigenen API-Schlüssel oder lokal mit Ollama oder LM Studio laufen. Die ersten 50 Umbenennungen sind kostenlos.

### Die umbenannten Dateien in Ordner sortieren

Unter Windows kann Zush Dateien außerdem **mit KI in Ordner sortieren**. Wählen Sie die Gruppierung **Auto** oder schreiben Sie **Folder rules** wie „Rechnungen nach Firma und Belege nach Monat gruppieren.“ Prüfen Sie die vorgeschlagenen Ordnergruppen zusammen mit den Dateinamen; ein Muster-Umbenenner genügt weiterhin, wenn Sie nur dieselbe Textänderung für einen ganzen Batch brauchen.

Wählen Sie einen **Destination folder** oder behalten Sie den Quellordner als Wurzel. Aktivieren Sie **Reuse existing folders**, damit bereits vorhandene passende Ordner bevorzugt werden; Zush kann einen neuen anlegen, wenn nichts passt. Prüfen Sie in einem manuellen Batch sowohl die vorgeschlagenen Namen als auch die Ordner, bevor Sie sie anwenden. Um an Ort und Stelle umzubenennen, lassen Sie die Sortierung aus und behalten Sie das ursprüngliche Ziel bei.

Speichern Sie die Sortiereinstellungen in einem **Template** und weisen Sie es **Monitor** für neue Dateien direkt im überwachten Ordner zu. Bereits verarbeitete Dateien werden dadurch nicht neu organisiert. Testen Sie das Template zuerst in einem manuellen Batch. Einrichtung und Überwachungsumfang finden Sie in der [Anleitung zur Ordnersortierung](/docs/folder-sorting).

Zush unterstützt auch verschachtelte Ordnerregeln, etwa nach Jahr und darunter nach Monat. Bereits umbenannte Dateien lassen sich sortieren, ohne ihre Namen erneut zu ändern oder ein weiteres Umbenennungsguthaben zu verbrauchen. Prüfen Sie die Zielpfade vor dem Anwenden. Diese separate Aktion bearbeitet vorhandene Dateien; eine Änderung am Monitor-Template sortiert sie nicht rückwirkend. Die [KI-Ordnersortierung](/docs/folder-sorting) funktioniert auf Mac und Windows.

## Welchen Umbenenner sollten Sie verwenden?

- Dieselbe Änderung für jede Datei (Präfix, Datum, Nummer): **PowerRename**.
- Komplexe Muster in riesigen Ordnern: **Bulk Rename Utility**.
- Namen aus Foto-, Musik- oder GPS-Metadaten: **Advanced Renamer**.
- Screenshots, Scans, Downloads und Fotos, die echte Namen brauchen: **Zush**.

Viele behalten beide Arten. PowerRename für schnelle mechanische Korrekturen, Zush für die Ordner, in denen Sie derzeit jede Datei öffnen, um zu sehen, was sie ist.

## FAQ

### Kann Zush Dateien nicht nur umbenennen, sondern auch in Ordner sortieren?

Ja. Die optionale KI-Ordnersortierung funktioniert auf Mac und Windows. Wählen Sie Auto oder schreiben Sie Folder rules, wählen Sie das Ziel und prüfen Sie in einem manuellen Batch sowohl Namen als auch Gruppen. Ein Template mit aktivierter Sortierung kann auch neue Dateien direkt in einem überwachten Ordner verarbeiten; bereits verarbeitete Dateien werden dadurch nicht neu organisiert. Lassen Sie die Sortierung aus und behalten Sie das ursprüngliche Ziel bei, wenn Sie nur Namen vergeben wollen.

### Was ist der beste kostenlose Datei-Umbenenner für Windows 11?

PowerRename, Teil von Microsoft PowerToys. Es ist kostenlos, zeigt jede Änderung vorab an, unterstützt Regex und Datumsvariablen und lässt sich mit Ctrl+Z rückgängig machen. Bulk Rename Utility ist die kostenlose Alternative für aufwendigere private Aufgaben.

### Hat Windows 11 eine integrierte Mehrfachumbenennung?

Ja, aber eine einfache. Markieren Sie Dateien im File Explorer und drücken Sie F2, um ihnen einen gemeinsamen Namen mit Nummern in Klammern zu geben. Für Suchen und Ersetzen oder Datumsangaben installieren Sie PowerToys und nutzen PowerRename.

### Kann ein Datei-Umbenenner lesen, was in meinen Dateien steht?

Mustertools können das nicht; sie lesen nur den vorhandenen Namen und Metadatenfelder wie EXIF oder ID3. KI-Umbenenner wie Zush lesen den Inhalt selbst (Text, Bilder, Videobilder) und schreiben einen neuen, beschreibenden Namen.

### Welcher Datei-Umbenenner ist am sichersten?

Jedes Tool mit Vorschau und Rückgängigmachen für ganze Batches. PowerRename, Advanced Renamer und Zush zeigen die Ergebnisse vor dem Anwenden an. Zush führt außerdem einen dauerhaften Rename History, sodass Sie einen Batch noch Tage später zurücksetzen können, nicht nur unmittelbar danach.
