## Was File Juggler gut kann

File Juggler ist ein Windows-Automatisierungstool, das ein unabhängiger Entwickler in Dänemark gebaut hat. Sie erstellen Regeln aus drei Teilen:

1. **Überwachte Ordner**, etwa Downloads, Desktop oder ein Scanner-Ordner.
2. **Bedingungen**: Dateiname und Pfad, Text in der Datei, Größe sowie Erstellungs- oder Änderungsdatum.
3. **Aktionen**: verschieben, kopieren, umbenennen, Dateiendung ändern, löschen oder in den Papierkorb verschieben, Archive entpacken, zu einer Zip-Datei hinzufügen, einen Befehl ausführen oder zu Evernote hochladen.

Es reagiert fast sofort, weil es Benachrichtigungen über Ordneränderungen abonniert, statt in festen Zeitabständen zu scannen. Es kann Text in PDF-, Word- und Excel-Dateien lesen und gefundene Wörter und Datumsangaben in einem neuen Dateinamen wiederverwenden. Version 3.1.7 erschien im September 2026, im Oktober folgte eine Beta von 3.1.8; das Tool ist also nicht aufgegeben.

Die Preisgestaltung ist einfach: 50 $ einmalig vor Steuern an der Kasse, gültig für alle künftigen Upgrades. Eine Lizenz deckt eine Person auf mehreren PCs oder einen PC ab, den mehrere Personen gemeinsam nutzen. Die 30-Tage-Testversion enthält alle Funktionen, und nach Ablauf erinnert die App an den Kauf, funktioniert aber weiter.

## Warum Leute nach einer Alternative suchen

- **Keine KI.** Jede Regel muss von Hand geschrieben werden. Eine Regel kann `Screenshot 2026-10-02 141203.png` oder `IMG_4382.jpg` nicht erfassen, weil nichts im Namen oder Text verrät, was die Datei ist.
- **Keine OCR.** Laut der FAQ von File Juggler haben reine Bild-Scans keinen durchsuchbaren Text, daher brauchen Sie ein separates OCR-Programm, bevor die Inhaltsregeln greifen können.
- **Nur Windows.** Es gibt keine Mac-Version. Auf dem Mac ist [Hazel](/hazel-alternative) das Gegenstück.
- **Kein Dienst.** Es läuft nur, solange ein Benutzer angemeldet ist, und eignet sich daher nicht gut für Server.
- **Der Preis**, wenn Sie nur eine einfache Sortierung nach Dateityp brauchen. Mehrere kostenlose Tools erledigen das.

## 1. Zush: für die Dateien, die Regeln nicht beschreiben können

[Zush für Windows](/windows) läuft unter Windows 10 und 11 und ist im [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X) erhältlich. Statt Bedingungen abzugleichen, liest es die Datei: den Text in einem PDF oder Scan, den Inhalt eines Fotos oder Screenshots, die Einzelbilder eines Videos. Dann schlägt es einen Namen vor, etwa `2026-09-12_acme_invoice_1042.pdf` oder `stripe-revenue-dashboard-september.png`.

![Zush für Windows benennt einen gemischten Stapel nach Inhalt um, wobei jeder vorgeschlagene Dateiname angezeigt wird, bevor der Stapel angewendet wird](/videos/windows/zush-batch-rename.mp4)

Wo File Juggler eine Regel pro Ziel braucht, genügt Zush ein Satz unter **Folder rules**, etwa „Gruppiere Rechnungen nach Firma und Belege nach Monat“, oder es gruppiert Dateien auf Auto nach Inhalt. Sie prüfen vorgeschlagene Namen und Ordner gemeinsam, bevor irgendetwas verschoben wird. Prüfen Sie mehrdeutige Dateien, bevor Sie Änderungen anwenden.

![Zush für Windows zeigt eine Vorschau inhaltsbasierter Ordnergruppen und vorgeschlagener Dateinamen vor Rename & sort](/images/showcase/windows/folder-sorting-light.webp)

Für den Dauerbetrieb, den File Juggler bietet, speichern Sie die Einrichtung in einem Template und weisen es **Monitor** zu. Neue Dateien in Downloads oder einem Scanner-Ordner werden dann beim Eintreffen umbenannt und sortiert. Rename History speichert die alten und neuen Namen, sodass sich ein missglückter Stapel zurücksetzen lässt. Die KI läuft über Zush Cloud AI, Ihren eigenen API-Schlüssel oder lokal mit Ollama oder LM Studio, wenn die Dateien auf dem PC bleiben sollen.

![Der Monitor-Tab von Zush für Windows überwacht die Ordner Screenshots und Downloads und benennt neue Dateien beim Eintreffen um](/images/showcase/windows/monitor-light.webp)

Wählen Sie Zush, wenn Ihre Regelliste immer weiter wächst und trotzdem Dateien übersieht. Schritt für Schritt: [Dateien mit KI unter Windows in Ordner sortieren](/blog/sort-files-into-folders-with-ai-windows) und [30 fertige Ordnerregeln](/blog/ai-folder-sorting-prompts).

Eine Zush-Lizenz deckt bis zu 3 Geräte unter Mac und Windows ab.

Sie können [Templates exportieren](/docs/template-import-export), einschließlich Naming Blocks, Custom AI Blocks und Ordnerregeln, und sie auf einem anderen Computer importieren. Wählen Sie dort lokale Ziele, Ordnerberechtigungen und KI-Verbindungen erneut aus; übertragen werden die Workflow-Einstellungen, nicht Ihre Dateien.

Zush unterstützt außerdem verschachtelte Ordnerregeln, etwa die Gruppierung nach Jahr und dann nach Monat. Sie können bereits umbenannte Dateien sortieren, ohne ihre Namen erneut zu ändern oder einen weiteren Umbenennungs-Credit zu verbrauchen. Prüfen Sie die Ziele, bevor Sie sie anwenden. Diese separate Aktion verarbeitet einen bestehenden Stapel; eine Änderung am Monitor-Template ordnet ihn nicht rückwirkend neu. Die [KI-Ordnersortierung](/docs/folder-sorting) funktioniert unter Mac und Windows.

## 2. DropIt: die kostenlose Regel-Engine

DropIt ist kostenlos und Open Source. Regeln erfassen Dateien nach Name, Größe, Datum, Eigenschaften oder regulären Ausdrücken, und 21 Aktionen decken Verschieben, Kopieren, Umbenennen, Komprimieren, Entpacken und mehr ab. Sie ziehen Dateien auf ein schwebendes Ziel oder lassen überwachte Ordner in festen Zeitabständen scannen.

Die neueste Version, 8.5.1, stammt vom Oktober 2018. Sie läuft weiterhin, aber erwarten Sie keine neuen Funktionen und keine KI.

Wählen Sie DropIt, wenn Sie nur „PDFs hierhin, Bilder dorthin“ brauchen und Bezahlen keine Option ist.

## 3. Sortio: KI-Pläne mit Regeln darunter

Sortio kombiniert beide Ansätze. Sie können klassische Regeln schreiben oder die Organisation in einfachem Englisch beschreiben, einen Plan prüfen und dann umbenennen, Ordner anlegen und Dateien verschieben lassen. Smart Folders wenden den Plan weiter auf neu eintreffende Dateien an. Es läuft unter Windows, macOS und Linux.

Der kostenlose Tarif umfasst regelbasierte Sortierung mit bis zu fünf Regeln, überwachte Ordner, Rückgängig-Funktion und eine einmalige KI-Testversion. Pro kostet $14,99 pro Monat oder $99 pro Jahr mit einem monatlichen KI-Kontingent; Ollama hält die Verarbeitung lokal.

Wählen Sie Sortio, wenn Sie Regeln im Stil von File Juggler und KI in einer App möchten oder Linux brauchen. Ausführlicher Vergleich: [Zush vs. Sortio](/blog/zush-vs-sortio).

## 4. Wisfile: kostenlose KI-Bereinigung für Dokumente

Wisfile ist kostenlos, läuft lokal unter Mac und Windows und benennt Dokumente anhand ihres Inhalts mit Vorlagen wie `Author-Year-Title` um. Es kann einen Stapel auch in Themenordner gruppieren. Laut der FAQ werden Word und PDF als Formate unterstützt.

Es gibt keine Ordnerüberwachung und keine Zeitplanung: Sie ziehen die Dateien hinein und starten es jedes Mal neu. Laut der FAQ gibt es außerdem keine eingebaute Rückgängig-Funktion, testen Sie also zuerst an Kopien.

Wählen Sie Wisfile für eine einmalige Bereinigung eines Papier- oder Dokumentenarchivs. Einen genaueren Blick bietet [Zush vs. Wisfile](/blog/zush-vs-wisfile).

## 5. PowerShell und Aufgabenplanung: der Do-it-yourself-Weg

Windows kann einfache File-Juggler-Aufgaben ohne zusätzliche Software erledigen. PowerShell verschiebt und benennt Dateien um; die Aufgabenplanung führt das Skript bei der Anmeldung oder alle paar Minuten aus:

```powershell
Get-ChildItem "$env:USERPROFILE\Downloads" -Filter *.pdf |
  Move-Item -Destination "$env:USERPROFILE\Documents\PDFs"
```

Das ist kostenlos und so flexibel wie Ihre Skriptkenntnisse. Sie kümmern sich aber auch selbst um doppelte Namen, gesperrte Dateien, Protokollierung und Rückgängigmachen. Weitere Optionen: [So organisieren Sie Ihren Downloads-Ordner unter Windows](/blog/organize-downloads-folder-windows).

## File Juggler behalten oder wechseln?

- Ihre Dateien folgen festen Mustern (dieselbe Bank, dasselbe Layout, dasselbe Namenspräfix): **File Juggler behalten**.
- Screenshots, Scans, Handyfotos und zufällige Downloads mit bedeutungslosen Namen: **Zush**.
- Kostenlose Sortierung nach Dateiendung oder Name: **DropIt** oder **PowerShell**.
- Regeln und KI in einem Tool oder Linux: **Sortio**.
- Ein kostenloser einmaliger Durchlauf über PDFs und Word-Dateien: **Wisfile**.

Sie können auch beide nutzen. Zush überwacht Downloads und schreibt vorhersehbare Namen wie `2026-10-02_acme_invoice.pdf`, und File Juggler verschiebt `*_invoice.pdf` in einen festen Ordner „Finanzen“. Jedes Tool übernimmt den Teil, den es gut kann. Testen Sie jede Einrichtung zuerst an Kopien; unsere Checkliste [So benennen Sie Dateien sicher im Stapel um](/blog/how-to-safely-batch-rename-files) zeigt, was Sie prüfen sollten.

## FAQ

### Gibt es eine kostenlose Alternative zu File Juggler?

Ja. DropIt ist kostenlos und Open Source, wurde aber seit 2018 nicht mehr aktualisiert. Der kostenlose Tarif von Sortio umfasst bis zu fünf Regeln. PowerShell mit Aufgabenplanung ist kostenlos, wenn Sie skripten können. Zush enthält 50 kostenlose KI-Umbenennungen, falls Ihr Problem unklare Dateinamen sind.

### Wird File Juggler noch gepflegt?

Ja. Laut den Versionshinweisen erschien Version 3.1.7 im September 2026 und eine Beta von 3.1.8 im Oktober 2026.

### Nutzt File Juggler KI?

Nein. Es gleicht Bedingungen ab, die Sie schreiben, einschließlich Wörtern in PDFs und Office-Dateien. Reine Bild-Scans kann es ohne separate OCR nicht lesen.

### Gibt es File Juggler für den Mac?

Nein, File Juggler gibt es nur für Windows. Hazel ist das nächstliegende Mac-Gegenstück für Regeln, und Zush für Mac deckt KI-Benennung und Ordnersortierung ab. Siehe unsere Seite zur [Hazel-Alternative](/hazel-alternative).

### Kann Zush File Juggler vollständig ersetzen?

Für das Benennen von Dateien nach Inhalt und das Sortieren in Ordner ja, einschließlich überwachter Ordner. File Juggler hat noch Aktionen, die Zush nicht bietet, etwa einen Befehl ausführen, Archive entpacken oder zu Evernote hochladen. Wenn Sie darauf angewiesen sind, behalten Sie es neben Zush.
