Zush renames files on Windows 10 and 11 by reading what is inside them: the text of a scanned PDF, what a screenshot shows, the rows of a spreadsheet, the frames of a video. Install it from the Microsoft Store, then right-click files in File Explorer and choose **Rename with Zush**, or add a folder to **AI Rename** to review the names first; the first 50 AI renames are free, and PRO costs $10 a month or $48 once.

This guide follows the Windows app screen by screen, starting with the File Explorer right-click menu added in Windows version 3.19.5.0 on November 19, 2026. If you want to compare F2, PowerRename and PowerShell first, read [how to batch rename files in Windows 11](/blog/batch-rename-files-windows-11). For how AI renaming works in general, see the [AI file renaming guide](/blog/rename-files-with-ai-guide).

## 1. Right-click rename in File Explorer

**Rename with Zush** renames the selected files without opening the Zush window. You pick a naming setup from a submenu, and the new names appear in File Explorer when processing finishes.

### Steps

1. Select one or more supported files in File Explorer. Select files, not a folder.
2. Right-click the selection and choose **Rename with Zush**.
3. Pick **Smart**, **Screenshots** or one of your own Templates from the submenu.
4. Wait for processing. The new names appear in File Explorer and in **Activity**.

### What each choice does

- **Smart** uses the default setup saved in **Templates → Smart Rename**: its Naming Blocks, language and metadata settings.
- **Screenshots** is a built-in Template for screen captures.
- **Your Templates** apply their own pattern. A `{Created Date}_{Vendor}_{Amount}` Template for receipts and a Screenshots Template for captures can sit side by side, and you choose per selection.

The rename uses whichever [AI mode](/docs/ai-modes) is active in Settings: Zush Cloud AI, your own key (BYOK), Ollama or LM Studio.

### No preview, so check Activity

The right-click rename applies names straight away. There is no review step. To check or reverse the result:

1. Open Zush and go to **Activity**.
2. Find the file. Activity lists the original name next to the new one.
3. Choose **Undo** for that file, or **Undo All** to reverse the saved history.

If another file now holds the original name, use **Restore with New Name** so nothing gets overwritten. Details are in [undo history](/docs/undo-history).

![Zush Activity on Windows listing renamed files with their original and new names and an Undo control](/images/showcase/windows/activity-light.webp)

### Which version has it

The File Explorer menu ships in the Microsoft Store version of Zush, from version 3.19.5.0. Zush has to be running for the menu to work. If you prefer the keyboard, turn on **Quick Rename Shortcut** in **Preferences**: it renames up to 10 selected files at a time with the Smart setup. The full steps are in the [Quick Rename docs](/docs/quick-rename).

## 2. Batch rename in AI Rename, with a review step

Use AI Rename when you want to read every proposed name before anything changes, or when the folder is new to you and you have not tested a Template on it yet.

1. Open Zush and go to **AI Rename**. Drag in files or a whole folder from File Explorer, the Desktop, Downloads or OneDrive.
2. Choose the naming setup. Pick a Template from the Template row, or build a pattern with [Naming Blocks](/docs/naming-blocks) such as Created Date, Title, Client, Vendor or Document Type.
3. Wait for the suggestions. Each file shows its current name and the proposed one.
4. Double-click any suggested name to edit it. Regenerate a single file if its suggestion misses.
5. Click **Rename**. Only checked files are renamed.
6. If you change your mind, open **Activity** and undo one file or the whole batch.

A manual batch holds up to 1,000 files. On Free, files beyond your remaining free renames stay in the list as **Awaiting PRO** and are analyzed after you upgrade.

![Zush AI Rename on Windows with a mixed batch of files and a proposed new name for each one](/images/showcase/windows/batch-rename-light.webp)

### Save the setup as a Template

Once a pattern works, save it in **Templates**. The same Template then appears in the right-click submenu, in AI Rename and in Monitor, so a naming rule you tested with a preview is the one that runs without one.

![The Zush Templates screen on Windows with Smart Rename and built-in Templates such as Screenshots](/images/showcase/windows/templates-light.webp)

### Exact copies found while renaming

Turn on **Detect duplicate files** in a Template's **Processing** settings, or use the button at the right of the Template row in AI Rename. Zush compares file contents in the batch. When two files are identical byte for byte, one is the original and the rest are copies, whatever they are called. You choose what happens to the copies:

- **Keep as is**: copies are unchecked, so Rename skips them.
- **Mark in name**: each copy takes the original's new name plus a DUPLICATE mark.
- **Move to Trash**: on Windows, copies go to the Recycle Bin when you click Rename. Undo in Activity brings them back as long as the Recycle Bin has not been emptied.

Copies are never sent to the AI, so they do not use renames. Only exact copies count: two separate scans of the same page are different files. More in [duplicate detection](/docs/duplicates).

![Zush AI Rename with Move to Trash selected, showing exact copies marked to go to the Recycle Bin](/images/showcase/windows/duplicates-trash-light.webp)

## 3. Which tool to use when

| Tool | Use it when | Reads file content | Preview | Undo |
|---|---|---|---|---|
| File Explorer F2 | You want `Name (1)`, `Name (2)` for a few files | No | No | Ctrl+Z right after |
| PowerRename | Every file needs the same find-and-replace or regex change | No | Yes | Ctrl+Z in File Explorer |
| Zush AI Rename | Each file needs its own name and you want to review the batch | Yes | Yes | Activity |
| Zush right-click | You trust a Template and want a few files renamed now | Yes | No | Activity |
| Zush Monitor | New files keep landing in the same folder | Yes | No | Activity |

Monitor watches a folder you choose and applies the Template assigned to it as files arrive. Zush must stay running. Test the Template in AI Rename first, since Monitor has no review step. Setup is in [folder monitoring](/docs/folder-monitoring), and the folders worth starting with are covered in [auto rename files on Windows](/blog/auto-rename-files-windows-guide).

## FAQ

### Can I rename files from the right-click menu?

Yes. In the Microsoft Store version of Zush (3.19.5.0 or newer), select files in File Explorer, right-click, choose **Rename with Zush**, then **Smart**, **Screenshots** or one of your Templates. Zush renames them in the background without opening its window. The result appears in Activity, where you can undo it.

### Why doesn't Rename with Zush do anything?

Check that Zush is running and an AI mode is turned on. Select files rather than a folder, and make sure the format is [supported](/docs/supported-file-types). If you are on Free, check that you have free renames left.

### Does the right-click rename use my 50 free renames?

Yes. Free renames are shared across every way of renaming in Zush and every AI mode, including Ollama and LM Studio. PRO removes the limit: $10 a month or $48 as a one-time purchase. See [pricing](/pricing).

### Can I pick a different Template for each folder?

Yes. The right-click submenu lists every Template, so you pick one per selection. In AI Rename you choose from the Template row, and in Monitor each watched folder has its own Template.

### Can I just use PowerRename instead?

For pattern work, yes. [PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename) ships with PowerToys and handles search-and-replace, regex, and date or attribute variables across a File Explorer selection. If every file needs the same change, it is the faster tool, and it is free. It reads filenames and attributes, not file contents, so it cannot give two identically named scans different descriptive names. That split is covered in the [PowerRename alternative comparison](/blog/best-file-renamer-windows-11).

### Will Zush delete my duplicate files?

Only if you choose **Move to Trash**, and only for files that are byte-for-byte identical. On Windows the copies go to the Recycle Bin, and Undo in Activity restores them to their original folders until the Recycle Bin is emptied.
