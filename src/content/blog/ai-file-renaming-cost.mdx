## The three pricing models

**1. Metered subscription.** You pay for a recurring allowance. Check whether a credit buys a generated suggestion or an applied rename, and whether retries consume credits. Examples: Renamer.ai, NameQuick Managed, FilesDesk Monthly, and NameThisPic. [FilesDesk's pricing FAQ](https://filesdesk.app/pricing) confirms that its Monthly credits refresh each month and each new suggestion, including a retry, uses a credit.

**2. Prepaid credits.** You buy a pack and spend credits as you process files. Check the expiry date and any free allowance separately. Examples: Renamed.to and AI Renamer cloud. This is different from a subscription whose credits refresh every billing period.

**3. Unmetered.** One price, no file count. Some unmetered plans include cloud AI; others only unlock the app and expect you to bring an API key or run a local model. Examples: Zush PRO, RenameClick Pro, FilesDesk lifetime, NameQuick Self-Managed.

An unmetered app license removes the app's per-file charge. It does not remove a third-party API bill: BYOK costs can still rise with usage, while local AI needs compatible hardware and a model. Zush PRO includes managed cloud AI; BYOK is optional and billed by your provider.

## Which pricing model should you choose?

- **Under 50 files, once:** use a free tier. Zush gives 50 renames, RenameClick currently allows 100 successful renames or moves a month, and Renamed.to gives 50 documents.
- **Recurring mixed-file batches:** Zush PRO gives a fixed app cost with managed cloud AI included. Compare the total over your expected months of use, not just one month's file count.
- **You already have an API key:** Zush supports BYOK on every plan. A ChatGPT, Claude, or Gemini chat subscription is not the same as funded API access; check your provider's separate API billing.
- **Sensitive files:** pick a tool with a local mode. Zush with Ollama or LM Studio, RenameClick's built-in model, FilesDesk or NameQuick with a local model.

## FAQ

### How much does an AI file renamer cost?

From free to about $100 a month. Metered tools like Renamer.ai run $9.95 to $99.95 a month depending on volume. Unmetered tools like Zush cost $10 a month or $48 once for unlimited renames.

### Is there a free AI file renamer?

Several have free tiers: Zush (50 renames), RenameClick (currently 100 successful renames or moves a month), Renamer.ai (25 files a month), and Renamed.to (50 documents). For unlimited free use, run a local model with an open-source script, which takes technical setup. See [how to rename files with AI for free](/blog/rename-files-with-ai-free).

### What is the cheapest AI file renamer for large volumes?

There is no universal cheapest option across cloud, BYOK, and local processing. Zush PRO costs $48 one-time with managed cloud AI and unlimited renames included. A self-managed license may add API charges or model setup, and metered plans may offer free quotas or annual discounts. Compare supported formats and total cost for the same processing mode and time period.

### Do FilesDesk credits renew each month?

Yes. FilesDesk Monthly credits refresh monthly, and each generated name suggestion uses one credit, including retries. Its $40 Self-Managed license has no suggestion credits but requires your own API key or local model. It covers one device with one year of updates, according to the [official pricing page](https://filesdesk.app/pricing).

### Is BYOK cheaper than a subscription?

Sometimes. BYOK means you pay your AI provider per request, which is cheap at low volume and grows with use. Zush lets you use BYOK on any plan, or switch to its included cloud AI, so you can choose per workflow.
