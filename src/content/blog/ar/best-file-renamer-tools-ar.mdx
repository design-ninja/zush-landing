## 1. الأدوات المدمجة والقواعد المجانية

### Finder
حدد الملفات وانقر بالزر الأيمن ثم اختر Rename لاستبدال النص أو إضافته أو الجمع بين اسم ورقم. لا يحتاج تثبيتًا، لكنه لا يقدم تعبيرات نمطية أو تحليل محتوى أو قواعد بيانات وصفية أو مراقبة أو سجلًا دائمًا. يتناول [دليل إعادة التسمية على Mac](/blog/batch-rename-files-on-mac-complete-guide) أيضًا Automator وTerminal.

### PowerRename
جزء من Microsoft PowerToys، ويتيح البحث والاستبدال والتعبيرات النمطية والمعاينة من File Explorer. يناسب قاعدة مشتركة، لكنه لا يقرأ المحتوى ولا يراقب المجلدات المختلطة. انظر [بديل هذه الأداة](/powerrename-alternative).

### Bulk Rename Utility
يجمع BRU البادئات والأرقام وحالة الأحرف والتعبيرات النمطية. واجهته الكثيفة مناسبة لعمليات Windows الآلية المحددة. لا توجد نسخة Mac ولا تحليل محتوى. يوضح [تحليل هذه الأداة](/blog/bulk-rename-utility-alternatives) الحدود.

## 2. إعادة التسمية بالبيانات الوصفية

يستخدم Advanced Renamer وA Better Finder Rename تواريخ EXIF وGPS ووسوم ID3 وتواريخ الملفات. اخترهما إذا كانت هذه الحقول تحتوي بالفعل على الاسم الكامل المطلوب. تخبرك EXIF بوقت التقاط الصورة، لا بأنها تعرض كلبًا في حديقة. ولا تتضمن بيانات PDF الوصفية بالضرورة المورد ومبلغ الفاتورة. اقرأ [مقارنة أدوات البيانات الوصفية](/blog/advanced-renamer-alternatives).

## 3. الذكاء الاصطناعي حين يحتاج كل ملف إلى اسم خاص

لا توضح `Screenshot 2026-03-23.png` و`Scan0001.pdf` و`IMG_4382.HEIC` و`download (7).pdf` الموضوع. يقرأ Zush لقطات الشاشة وصور RAW وHEIC وPDF و[المستندات الممسوحة بالرؤية الاصطناعية](/rename-scanned-documents) وOffice وiWork وملفات التصميم والصوت والفيديو. تحدد [كتل التسمية](/docs/naming-blocks) بنية موحدة؛ تراجع كل اقتراح قبل التطبيق ويمكن التراجع من السجل. تعالج [مراقبة المجلدات](/docs/folder-monitoring) التنزيلات والمسح الجديد.

تُشارك أول 50 إعادة تسمية بين الأوضاع الأربعة. تكلف PRO مبلغ $10 شهريًا أو $48 مرة واحدة دون حد لعدد عمليات إعادة التسمية. يتوفر Zush Cloud AI وBYOK عبر الإنترنت، وLM Studio وOllama على Mac وWindows. تشمل [مقارنة أدوات الذكاء الاصطناعي](/blog/best-ai-file-renamer-tools-2026) أيضًا FilesDesk وRenameClick وRenamer.ai وNameQuick.

### الفرز الاختياري إلى المجلدات

الفرز بالذكاء الاصطناعي تجريبي. اختر Auto أو اكتب في **Folder rules** مثلًا «لقطات الشاشة حسب المشروع والفواتير حسب الشركة». قواعد المجلد مستقلة عن Naming Blocks. اختر **Destination folder** أو احتفظ بالمجلد الأصلي جذرًا. تستخدم **Reuse existing folders** المجلدات المناسبة الموجودة، وتنشئ غيرها عند الحاجة. راجع الأسماء والمواقع قبل التطبيق.

احفظ الإعداد في **Template** واختبره يدويًا ثم اربطه بـ **Monitor**. يعالج الملفات الجديدة الموجودة مباشرة داخل المجلد المراقب، ولا يعيد تنظيم الملفات المعالجة سابقًا. لتغيير الأسماء في مكانها، أوقف الفرز واحتفظ بالوجهة الأصلية. [وثائق الفرز](/docs/folder-sorting).
