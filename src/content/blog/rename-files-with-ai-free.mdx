## Rename your first batch for free

1. **Install Zush for [Mac](/mac) or [Windows](/windows).** Open the app and select Zush Cloud AI in AI Modes. This route includes managed AI without your own API key.
2. **Add a small test folder.** Copy five to ten screenshots, photos, or documents into it, then add those copies to AI Rename. Use files whose contents you can check easily.
3. **Choose a Template.** Start with Smart Rename for descriptive titles. Set the language and formatting you want; add [Naming Blocks](/docs/naming-blocks) if the name needs specific fields.
4. **Review the suggestions.** Compare each proposed title with the file. Correct invented or missing details, check extensions, and deselect anything you do not want to rename.
5. **Apply the selected names.** Open a few renamed files to check the result. Use [Rename History](/docs/undo-history) to restore the original names if needed.

## Can I use local AI for free?

Yes, within the same 50-renames Zush allowance. Install LM Studio or Ollama, download a compatible vision model, and test the local connection in Zush before adding files. Model downloads need disk space, and memory requirements depend on the model you choose.

After setup, local models can analyze supported files without a cloud AI provider. A local mode does not remove the FREE app limit. Follow the [offline AI file renamer setup](/offline-ai-file-renamer) for connection checks and a small offline test.

An open-source script is a different workflow: you would need to configure file extraction, a model, previews, collision handling, and recovery yourself. This guide uses Zush so the first test includes those desktop review controls.

## Make the first 50 renames useful

Start with filenames that hide useful content: timestamp-only screenshots, downloaded PDFs, scans, and generic exports. Use one Template on a few files before processing a full folder. Keep dates, invoice numbers, and other identifiers only when you can verify them in the source.

If a folder only needs a common prefix or a numbered sequence, content analysis may be unnecessary. Save the AI allowance for files that need different descriptions drawn from their contents.

## What happens after 50 renames?

Zush PRO removes the app's rename limit at **$10/month or $48 one-time**. Managed Zush Cloud AI is included. If you choose BYOK, your provider bills API usage separately; LM Studio and Ollama use your own hardware. See [current pricing](/pricing) and [plan limits](/docs/pricing-limits).

Before upgrading, check whether the names help you find your files and whether your Template works on recurring examples. Review and undo a small batch before automating a folder.

## FAQ

### Is Zush free on both Mac and Windows?

Yes. Zush FREE includes 50 renames shared across Zush Cloud AI, BYOK, LM Studio, and Ollama on Mac and Windows.

### Do I need an API key?

No. Zush Cloud AI includes managed processing without your own provider key. BYOK is optional.

### Does switching to Ollama or LM Studio reset the allowance?

No. All four modes use the same 50-renames FREE allowance. PRO removes the app limit; local models do not bypass it.

### Can I review names before files change?

Yes. Zush displays suggested names before you apply the selected batch. Check the content, edit uncertain suggestions, and leave unwanted changes unselected.

### Can I undo a batch?

Yes. Rename History records original and new names and lets you revert an applied batch. Test this on copied files before renaming files linked from another application.
