## AI 파일 이름 짓기 vs 폴더 분류

AI 파일 정리 도구는 서로 다른 두 문제를 풀 수 있습니다. 어떤 앱은 파일을 폴더로 옮기고, 어떤 앱은 Finder와 Spotlight가 검색하는 파일 이름을 개선합니다. 문제가 **파일이 어디에 있는지**인지, **파일 이름이 무엇인지**인지, 아니면 둘 다인지 정하세요.

`scan_0042.pdf`라는 청구서는 위치를 바꾸지 않고 `2026-07-18_Acme_INV-1042.pdf`가 될 수 있습니다. 분류 앱이라면 대신 `Finance/Invoices/2026/Acme/`로 옮길 수도 있습니다. 둘 다 유용하지만, 둘 다 바로 가기, 동기화 도구, 프로젝트 파일이 기대하는 파일 경로를 바꾸므로 미리 보기와 실행 취소가 중요합니다.

앱들을 같은 실제 작업으로 비교했습니다. 섞인 파일 이름 짓기, 예측 가능한 다운로드 파일 보내기, 새로 들어오는 파일 처리, 변경 미리 보기, 잘못된 묶음 되돌리기입니다. 제조사가 문서화하지 않은 기능은 추측하지 않고 그렇다고 적었습니다.

평가 기준: 내용 기반 이름 짓기와 폴더 분류, 계정 없는 무료 시작, 1회 결제 가격에 포함된 것, 영구 실행 취소가 있는 미리 보기, 새 파일 자동 처리.

## 1. Zush: Mac용 종합 1위 AI 파일 정리 도구

[Mac용 Zush](/mac)는 섞인 파일에 검색 가능한 이름, 내용 기반 폴더, 또는 둘 다 필요할 때 도움이 됩니다. 스크린샷, 사진(RAW와 HEIC 포함), PDF와 이미지로만 된 스캔본, Office와 iWork 문서, EPUB, 디자인 파일, 오디오, 동영상을 분석한 뒤 파일마다 다른 이름을 제안합니다. 동영상은 MKV를 포함해 음성, 내장 자막, 메타데이터로 이름을 짓습니다. Rename을 누르기 전에는 아무것도 바뀌지 않습니다.

![Mac용 Zush가 여러 종류의 파일이 섞인 폴더에서 제안한 파일 이름을 적용 전에 모두 보여 주는 화면](/images/showcase/macos/batch-rename-light.webp)

바로 쓸 수 있습니다. 무료 AI 이름 변경 50회는 계정, 카드, API 키, 모델 다운로드 없이 관리형 Zush Cloud AI로 실행됩니다. 클라우드 모드는 컴퓨터에 부담이 적습니다(RAM 최소 4 GB, 앱 약 200 MB, macOS 15 이상의 Apple Silicon과 Intel Mac). 파일을 Mac 안에 두고 싶다면 Ollama나 LM Studio로 전환하세요. BYOK도 있습니다.

이 목록에서 이름 설정이 가장 세밀합니다. Screenshots, Bookkeeper Expenses, Photographer Shoots, Movies & TV, Remove Duplicates 같은 준비된 Templates를 145개 이상의 Naming Blocks, Custom AI Blocks와 조합합니다. 항목 순서, 대소문자, 구분자, 날짜 형식, 일련번호(시작 값, 앞자리 0, 폴더별 번호), 출력 언어, Finder 태그, Spotlight 메타데이터를 직접 정합니다. 제안된 이름을 더블클릭하면 적용 전에 수정할 수 있습니다.

![Rename & sort를 적용하기 전에 내용 기반 폴더 그룹과 제안된 파일 이름을 미리 보여 주는 Mac용 Zush 화면](/images/showcase/macos/folder-sorting-light.webp)

폴더 분류는 사용자의 지시를 따릅니다. "청구서는 회사별로, 영수증은 월별로 묶기" 같은 규칙을 쓰거나 Auto로 두고, 대상을 고른 뒤, Zush가 이미 있는 폴더를 다시 쓰게 하세요. 규칙은 중첩할 수 있고(연도 아래 월) 크기, 날짜, 카메라, 재생 시간, 페이지 수를 쓸 수 있습니다. 이름을 바꾸지 않고 폴더로 분류만 할 수도 있습니다. Movies & TV Template은 에피소드를 프로그램과 시즌별로, 음악을 아티스트와 앨범별로 분류합니다.

![청구서는 회사별, 영수증은 월별로 묶으라는 지시와 예시 규칙이 들어 있는 Zush의 Folder rules 대화 상자](/images/showcase/macos/folder-rules-light.webp)

Monitor는 외장 드라이브의 폴더를 포함해 새로 들어오는 파일을 처리하며, 드라이브를 다시 연결하면 감시가 재개됩니다. AI Rename은 중복도 찾아냅니다. 그대로 두거나, 이름에 표시하거나, 휴지통으로 옮길 수 있습니다. 사본에는 크레딧을 쓰지 않으며 Undo로 복원됩니다.

Rename History는 원래 이름, 새 이름, 폴더, 시각을 기록하고 재시작 후에도 남습니다. Undo All은 묶음 전체를 복원하면서 충돌을 나열하고 새 이름으로 복원하는 옵션을 줍니다.

![원래 파일 이름과 새 파일 이름을 하나씩 나열하고 이름 변경을 되돌리는 버튼이 있는 Zush의 Activity 탭](/images/showcase/macos/activity-light.webp)

가격: 월 $10 또는 1회 $48. 1회 결제 라이선스에는 모든 모드(Zush Cloud AI, BYOK, Ollama, LM Studio)의 무제한 이름 변경, 이후 모든 업데이트, Mac과 Windows를 합쳐 최대 3대, 14일 환불이 포함됩니다. [Templates를 내보내](/docs/template-import-export) 다른 컴퓨터에서 가져올 수 있습니다. 평점(2026년 11월 17일 기준): 미국 Microsoft Store 평가 8개 기준 5.0, Softpedia 편집자 리뷰 4.5/5.

적합한 경우: 섞인 폴더, Finder와 Spotlight에서 의미로 찾기, 모든 변경을 일어나기 전에 보고 싶은 사람. Hazel 관점의 비교는 [Zush Hazel 대안](/hazel-alternative) 페이지를 보세요.

[AI 파일 정리 도구](/ai-file-organizer) 페이지에서 Zush가 파일 분류와 이름 짓기를 함께 처리하는 방식을 가격, 비교표와 함께 볼 수 있습니다.

## 2. Hazel: AI 없는 결정적 규칙

Hazel 6(현재 버전 6.1.2)은 폴더를 감시하며 이름, 날짜, 종류, 출처, 내용 패턴, 태그, 스크립트를 기준으로 규칙을 적용합니다. 이동, 하위 폴더로 분류, 패턴 이름 변경, 보관, 업로드, 태그, 단축어·AppleScript·Automator 실행을 할 수 있습니다. 라이선스는 $42입니다. Softpedia 편집자 평가는 5.0/5로 Zush의 4.5보다 높습니다.

Hazel에는 AI가 없습니다. 조건을 정확히 말할 수 있을 때 빛납니다. 스캐너 폴더의 모든 PDF를 `Documents/Scans`로 옮기기, 90일이 지난 파일 보관하기 같은 작업입니다. 아무 스크린샷이나 사진을 보고 무엇이 담겼는지 알아내지는 못합니다.

Hazel을 고를 때: 규칙에 스크립트, AppleScript, 보관이 필요할 때. 약점: 경우마다 규칙이 필요해서 설정과 시험에 시간이 듭니다. Hazel의 간단한 작업은 Zush도 합니다. 날짜, 확장자, 원래 이름 블록이 있고, Monitor에서 파일 형식이나 이름 앞부분으로 거를 수 있으며, 폴더 규칙으로 연도와 월별로 나눌 수 있습니다. 이 역할 분담은 [Hazel 대안으로서의 Zush](/hazel-alternative)에서 더 볼 수 있습니다.

## 3. Sparkle: 알아서 하는 폴더 재구성

Sparkle은 선택한 폴더를 관리하며 AI Library를 만들고, 일정 시간이 지난 새 파일을 옮기고, 중복을 표시하고, 이동 기록을 남기며, 정리 결과를 되돌릴 수 있습니다. 파일 내용, 이름, 종류를 읽고 폴더 구조를 계획합니다. 파일 이름은 바꾸지 않습니다.

무료 요금제는 없습니다. 15일 체험에는 이메일과 카드가 필요합니다. 요금제는 Mac 1대 연 $119 또는 최대 5대 평생 $179입니다.

Sparkle을 고를 때: 데스크탑, 다운로드, 문서 폴더를 앱이 알아서 재구성해 주길 원하고 파일 이름은 상관없을 때. 약점: 설계상 파일을 옮기므로, 진행 중인 프로젝트 폴더를 맡기기 전에 Manual Library, 대기 시간, 제외 설정을 확인하세요.

## 4. NameQuick: 문서 이름 변경과 if/then Rules

NameQuick(3.0.57 버전, Mac App Store에도 있음)은 내용 기반 이름 짓기에 Presets, Watch Folders, Finder 태그, 그리고 이름을 바꾼 뒤 파일을 옮기거나 태그를 달거나 보관하는 조건부 Rules를 합쳤습니다. Mac과 Windows에서 동작합니다.

시작은 Zush만큼 쉽습니다. 이메일이나 카드 없이 Managed 이름 변경 30회가 무료입니다. 그 뒤 Managed 요금제는 500회에 월 $12부터 10,000회에 월 $99까지이고, 이름 변경 팩은 500회 $19 또는 1,500회 $39입니다(12개월 유효). 70회가 포함된 14일 Managed 체험에는 카드가 필요합니다. $69 Self-Managed 라이선스는 컴퓨터 1대용이며 본인의 API 키나 로컬 모델이 필요하고, NameQuick은 AI 비용이 별도라고 밝힙니다.

NameQuick을 고를 때: 반복되는 PDF, 영수증, 계약서를 처리하고 이름을 붙인 뒤 Rules를 적용하고 싶을 때. 약점: 관리형 AI가 포함된 1회 결제 선택지가 없고, 파일을 나중에 옮기면 실행 취소가 실패할 수 있습니다. 자세한 비교는 [Zush vs NameQuick](/blog/zush-vs-namequick)에 있습니다.

## 5. Sortio: 프롬프트 기반 분류, Linux도 지원

Sortio(v9.0.0)는 자연어 지시를 받아 계획을 미리 보여 준 뒤, 이름을 바꾸고 폴더를 만들어 파일을 보냅니다. macOS, Windows, Linux에서 동작하며, 호스팅 AI와 함께 Free를 포함한 모든 요금제에서 BYOK나 Ollama, LM Studio를 통한 로컬 모델을 쓸 수 있습니다. 최신 버전은 사진과 동영상의 위치 메타데이터를 읽습니다.

무료 요금제에는 규칙 5개, Spaces 3개까지의 규칙 기반 분류, 1회성 AI 체험, 미리 보기, 분류 기록, 실행 취소가 있습니다. 폴더 감시와 자동화는 이제 Pro가 필요하며, 웹사이트 기준 월 $14.99 또는 연 $99입니다(App Store에는 월 $19.99로 표시). 로그인하려면 이메일 계정이 필요합니다. 로컬 모드는 RAM 최소 8 GB와 디스크 10 GB를 요구합니다.

Sortio를 고를 때: Linux나 팀 작업 공간이 필요할 때. 약점: 무료 요금제는 더 이상 폴더를 감시하지 않고, 호스팅 AI는 1회 구매가 아니라 월간 사용량 방식입니다. [Zush vs Sortio](/blog/zush-vs-sortio)를 참고하세요.

## 6. Floxtop: Apple Silicon용 기기 내 분류

Floxtop은 기기 내 AI로 파일을 분류해 대상 폴더를 제안하고, 이동은 하나하나 승인합니다. Smart Rename은 내용 기반 이름을 묶음 단위로 제안하며, v1.24.0부터 날짜, 회사 이름, 문서 유형, 주제에 대한 사용자 이름 규칙을 지정할 수 있습니다. 스캔본을 포함한 PDF도 시각적으로 읽습니다.

실행 취소도 이제 문서화돼 있습니다. v1.16에서 Activity History가, v1.18에서 이동 실행 취소가, 2026년 10월 26일 v1.24.0에서 이름 변경의 완전한 실행 취소(Cmd+Z, 하나 또는 묶음)가 추가됐습니다.

무료 요금제는 이메일이나 카드 없이 월 100개 파일을 처리합니다. Pro는 Mac 1대용 1회 $19.99로 v1 업데이트가 포함되며, Floxtop은 Zush의 14일보다 긴 30일 환불을 제공합니다. Apple Silicon의 macOS 15 이상이 필요하고, 이름 변경에는 macOS 26의 Apple Intelligence가 필요합니다.

Floxtop을 고를 때: 최신 Apple Silicon Mac이 있고 저렴한 1회 결제로 모든 것을 기기에서 처리하고 싶을 때. 약점: Intel이나 Windows를 지원하지 않고, 이름 변경이 Apple Intelligence에 의존하며, 폴더 감시는 제조사가 밝히지 않았습니다.

## 7. Files Magic AI: 정리 도구와 시스템 클리너

Files Magic AI는 폴더 정리, Magic Rename, 중복과 사용하지 않는 앱 정리, 개발자 캐시 정리를 합쳤습니다. 폴더 정리 기능은 파일 이름으로 구조를 제안합니다. Magic Rename은 Apple Intelligence, 앱에 포함된 영어 기기 내 모델, 선택 사항인 Rename LLM, 또는 Cloud AI로 실행할 수 있고, 선택한 폴더를 감시할 수 있습니다. 미리 보고, 항목을 제외하고, 적용합니다.

가격: 이름 변경 크레딧 25개와 폴더 1개 정리가 되는 Free 요금제, 이후 월 $6.99(첫 달 $3.49), 연 $34.99, 평생 $49.99(할인가로 표시). 3일 체험과 14일 환불이 있습니다. 사이트에 Windows 다운로드 버튼이 있지만 공개 릴리스 페이지에는 Mac DMG만 있으므로 Mac 앱으로 봅니다.

Files Magic AI를 고를 때: 폴더 정리와 시스템 정리를 하나의 유틸리티로 하고 싶을 때. 약점: 실행 취소는 최근 작업만 다루고, 정리와 이동은 이름 변경보다 영향 범위가 크므로 삭제 항목을 꼼꼼히 검토하세요. 자세한 비교: [Zush vs Files Magic AI](/blog/zush-vs-files-magic-ai).

## Mac용 최고의 AI 파일 정리 도구: 결론

- 내용 기반 파일 이름, 직접 정한 규칙의 폴더 분류, 모든 변경 전 미리 보기, 영구 Rename History가 필요하면 **Zush**. 1회 $48로 클라우드 AI까지 해결됩니다.

- 정리와 시스템 클리닝을 한 앱에서 하고 싶다면 **Files Magic AI**.

## 자주 묻는 질문

### Mac에서 가장 좋은 AI 파일 정리 도구는?

대부분의 사람에게는 Zush를 추천합니다. 파일에 내용 기반의 검색 가능한 이름을 붙이고, Auto나 평범한 문장 규칙으로 폴더에 분류하며, 미리 보기와 영구 실행 취소를 제공합니다. 스크립트와 보관에는 Hazel, Linux에는 Sortio, Apple Silicon에서 완전한 기기 내 분류에는 Floxtop, 시스템 클리너까지 원하면 Files Magic AI가 더 낫습니다. Zush는 저희 제품이니 어떤 도구든 먼저 사본으로 시험하세요.

### Mac에서 AI가 파일을 자동으로 정리해 줄 수 있나요?

네. Zush는 외장 드라이브의 폴더를 포함해 폴더를 감시하며, 저장한 Template으로 새 파일의 이름을 바꾸고 분류할 수 있습니다. NameQuick, Files Magic AI, Sortio Pro도 폴더를 감시하고, Hazel은 고정 규칙으로 합니다. 다운로드 폴더나 고객 보관함을 자동화하기 전에 테스트 폴더 하나로 시작해 첫 결과를 확인하고 실행 취소를 쓸 수 있게 두세요.

### Mac용 로컬 AI 파일 정리 도구가 있나요?

네. Zush는 기기 내 분석을 위해 Ollama와 LM Studio를 지원합니다. Floxtop은 완전히 기기 내에서 동작하지만 Apple Silicon이 필요하고, 이름 변경에는 macOS 26의 Apple Intelligence가 필요합니다. Files Magic AI는 영어 기기 내 모델을 포함합니다. NameQuick Self-Managed와 Sortio는 로컬 모델을 쓸 수 있습니다. Zush Cloud AI나 BYOK 제공업체를 쓰면 분석을 위해 파일 내용이 해당 클라우드 모델로 전송됩니다.

### 1회 결제 가격으로 가장 많이 주는 Mac AI 파일 정리 도구는?

Floxtop Pro($19.99)와 NameQuick Self-Managed($69)는 1회 결제지만 기기 내 또는 본인 API 키로 동작합니다. Zush의 $48 라이선스에는 관리형 Zush Cloud AI, 모든 모드의 무제한 이름 변경, 이후 모든 업데이트, Mac과 Windows를 합쳐 최대 3대가 포함됩니다. Floxtop의 30일 환불은 Zush의 14일보다 깁니다.

### Zush는 파일을 폴더로 옮기나요?

원한다면 옮깁니다. Folder rules를 비워 두면 Auto로 묶고, "영수증은 월별로 분류하고 폴더 이름은 YYYY-MM으로" 같은 평범한 문장으로 묶는 방식을 설명할 수도 있습니다. Zush는 기존 폴더를 다시 쓰고 연도와 월로 중첩할 수 있습니다. Undo는 파일을 원래 폴더와 이름으로 되돌립니다. 분류를 끄면 파일은 현재 위치에 그대로 있습니다.
