**확인 방법:** 이 글은 [Zush](/) 제작사가 썼습니다. 경쟁 제품의 가격, 기능, 평점은 2026년 11월 17일에 각 제조사 사이트와 공식 스토어에서 확인했습니다([아래 출처](#sources-and-how-we-checked)). 실험실 테스트가 아니라 문서로 확인된 기능을 비교한 글입니다.

## File Juggler가 잘하는 것

File Juggler는 덴마크의 독립 개발자가 만든 Windows 자동화 도구입니다. 규칙은 세 부분으로 만듭니다.

1. **감시 폴더**: 다운로드, 바탕 화면, 스캐너 폴더 등.
2. **조건**: 파일 이름과 경로, 파일 안의 텍스트, 크기, 생성 또는 수정 날짜.
3. **동작**: 이동, 복사, 이름 변경, 확장자 변경, 삭제 또는 휴지통으로 보내기, 압축 풀기, zip에 추가, 명령 실행, Evernote 업로드.

타이머로 검사하는 대신 폴더 변경 알림을 구독하므로 거의 즉시 반응합니다. PDF, Word, Excel 파일의 텍스트를 읽고, 찾은 단어와 날짜를 새 파일 이름에 다시 쓸 수 있습니다. 3.1.9 버전이 2026년 10월 30일에 나왔으니 방치된 프로그램이 아닙니다. Softpedia 편집자 평가는 4.5/5로 Zush와 같습니다.

가격은 단순합니다. 결제 시 세전 $50 1회이며 이후 모든 업그레이드에 유효합니다. 라이선스 하나로 한 사람이 여러 PC에서 쓰거나, 여러 사람이 PC 한 대를 함께 쓸 수 있습니다. 30일 체험판은 모든 기능을 제공하고, 체험이 끝나면 구매하라는 알림이 뜨지만 앱은 계속 동작합니다.

## 대안을 찾는 이유

- **AI가 없습니다.** 모든 규칙을 손으로 써야 합니다. 이름에도 텍스트에도 파일이 무엇인지 드러나지 않으니 규칙으로는 `Screenshot 2026-10-02 141203.png`나 `IMG_4382.jpg`를 잡을 수 없습니다.
- **OCR이 없습니다.** File Juggler의 FAQ에 따르면 이미지로만 된 스캔본에는 검색 가능한 텍스트가 없으므로, 내용 규칙이 작동하려면 별도의 OCR 프로그램이 필요합니다.
- **Windows 전용입니다.** Mac 버전은 없습니다. Mac에서 비슷한 도구는 [Hazel](/hazel-alternative)입니다.
- **서비스가 아닙니다.** 사용자가 로그인해 있을 때만 동작하므로 서버에는 잘 맞지 않습니다.
- **가격.** 파일 형식별로 단순히 나누기만 하면 된다면 무료 도구도 여럿 있습니다.

## 1. Zush: 규칙으로 설명할 수 없는 파일을 위해

[Windows용 Zush](/windows)는 [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X)에서 설치하며 Windows 10과 11에서 동작합니다. 조건을 맞추는 대신 파일을 읽습니다. PDF나 스캔본의 텍스트, 사진이나 스크린샷의 내용, 동영상(MKV 포함)의 프레임, 음성, 자막을 보고 `2026-09-12_acme_invoice_1042.pdf`나 `stripe-revenue-dashboard-september.png` 같은 이름을 제안합니다.

![내용에 따라 섞인 파일 묶음의 이름을 바꾸며, 적용 전에 제안된 파일 이름을 모두 보여 주는 Windows용 Zush](/videos/windows/zush-batch-rename.mp4)

File Juggler는 목적지마다 규칙이 하나씩 필요하지만, Zush는 **Folder rules**에 "청구서는 회사별로, 영수증은 월별로 묶기" 같은 문장 하나를 받거나 Auto로 내용에 따라 묶습니다. 무엇이든 옮겨지기 전에 제안된 이름과 폴더를 함께 검토합니다. 애매한 파일은 적용 전에 확인하세요.

![Rename & sort 전에 내용 기반 폴더 그룹과 제안 파일 이름을 미리 보여 주는 Windows용 Zush](/images/showcase/windows/folder-sorting-light.webp)

File Juggler처럼 항상 켜져 있게 하려면 설정을 Template에 저장하고 **Monitor**에 연결하세요. 그러면 다운로드 폴더나 스캐너 폴더에 들어오는 새 파일의 이름이 바뀌고 분류됩니다. Rename History는 재시작 후에도 이전 이름과 새 이름을 보관하고, Undo All은 묶음 전체를 되돌리면서 충돌을 보여 줍니다. AI Rename은 중복 다운로드를 잡아 휴지통으로 옮길 수도 있습니다. 사본에는 크레딧을 쓰지 않으며 Undo로 복원됩니다.

바로 쓸 수 있습니다. 처음 50회 AI 이름 변경은 계정, 카드, API 키, 모델 다운로드 없이 관리형 Zush Cloud AI로 실행됩니다. PC 밖으로 나가면 안 되는 파일에는 Ollama나 LM Studio로 전환하거나 본인의 API 키를 쓰세요.

![Screenshots와 Downloads 폴더를 감시하며 들어오는 새 파일의 이름을 바꾸는 Windows용 Zush의 Monitor 탭](/images/showcase/windows/monitor-light.webp)

규칙 목록이 계속 늘어나는데도 파일을 놓친다면 Zush를 고르세요. 단계별 안내: [Windows에서 AI로 파일을 폴더에 분류하기](/blog/sort-files-into-folders-with-ai-windows), [바로 쓰는 폴더 규칙 30개](/blog/ai-folder-sorting-prompts).

가격: 월 $10 또는 1회 $48. File Juggler처럼 1회 결제 라이선스에 이후 모든 업데이트가 포함되고, 여기에 관리형 Zush Cloud AI와 BYOK, Ollama, LM Studio, 무제한 이름 변경, Windows와 Mac을 합쳐 최대 3대, 14일 환불이 더해집니다. 미국 Microsoft Store에서 Zush는 평가 8개 기준 5.0이고, Softpedia 편집자 평가는 4.5/5입니다(2026년 11월 17일 기준).

File Juggler와 비교한 약점: Zush에는 "명령 실행", 압축 풀기, Evernote 동작이 없으므로 이런 동작에 의존하는 규칙 체인은 대신하지 못합니다.

## 2. DropIt: 무료 규칙 엔진

DropIt은 무료 오픈 소스입니다. 규칙은 이름, 크기, 날짜, 속성, 정규식으로 파일을 찾고, 21가지 동작으로 이동, 복사, 이름 변경, 압축, 압축 풀기 등을 합니다. 떠 있는 대상 위로 파일을 끌어다 놓거나, 감시 폴더를 주기적으로 검사하게 할 수 있습니다.

약점: 최신 릴리스인 8.5.1은 2018년 2월에 나왔습니다. 여전히 동작하지만 새 기능이나 AI는 기대하기 어렵습니다.

"PDF는 여기, 이미지는 저기" 정도만 필요하고 돈을 쓸 수 없다면 DropIt을 고르세요.

## 3. Sortio: 규칙 위에 AI 계획

Sortio는 두 방식을 섞었습니다. 기존 방식의 규칙을 쓰거나 정리 방식을 영어 문장으로 설명하고 계획을 검토한 뒤, 이름 변경, 폴더 생성, 파일 이동을 맡길 수 있습니다. Smart Folders는 새로 들어오는 파일에 계속 계획을 적용합니다. Windows, macOS, Linux에서 동작합니다.

무료 요금제에는 규칙 5개, Spaces 3개까지의 규칙 기반 분류, 미리 보기, 분류 기록, 실행 취소, 1회성 AI 체험이 있습니다. 폴더 감시와 자동화는 Pro가 필요하며, 월간 AI 사용량을 포함해 월 $14.99 또는 연 $99입니다. Ollama를 쓰면 처리가 로컬에 머물고, 이메일 계정으로 로그인해야 합니다.

File Juggler식 규칙과 AI를 한 앱에서 쓰고 싶거나 Linux가 필요하면 Sortio를 고르세요. 약점: 항상 켜 두는 기능은 Pro 전용입니다. 자세한 비교: [Zush vs Sortio](/blog/zush-vs-sortio).

## 4. Wisfile: 문서용 무료 AI 정리

Wisfile은 무료이고 Mac과 Windows에서 로컬로 동작하며, `Author-Year-Title` 같은 템플릿으로 문서 내용에 따라 이름을 바꿉니다. 묶음을 주제별 폴더로 나눌 수도 있습니다. FAQ에는 지원 형식이 Word와 PDF로 나와 있습니다.

폴더 감시나 예약 실행은 없습니다. 매번 파일을 끌어다 놓고 실행해야 합니다. FAQ에 따르면 내장 실행 취소도 없으니 먼저 사본으로 시험하세요.

논문이나 문서 보관함을 한 번 정리하려면 Wisfile을 고르세요. 자세한 내용은 [Zush vs Wisfile](/blog/zush-vs-wisfile)에 있습니다.

## 5. PowerShell과 작업 스케줄러: 직접 만드는 방법

Windows는 추가 소프트웨어 없이도 기본적인 File Juggler 작업을 할 수 있습니다. PowerShell이 파일을 옮기고 이름을 바꾸며, 작업 스케줄러가 로그인 시 또는 몇 분마다 스크립트를 실행합니다.

```powershell
Get-ChildItem "$env:USERPROFILE\Downloads" -Filter *.pdf |
  Move-Item -Destination "$env:USERPROFILE\Documents\PDFs"
```

무료이고 스크립트 실력만큼 유연합니다. 대신 중복 이름, 잠긴 파일, 로그, 실행 취소도 직접 책임져야 합니다. 다른 방법: [Windows에서 다운로드 폴더 정리하는 법](/blog/organize-downloads-folder-windows).

## File Juggler를 계속 쓸까, 바꿀까?

- 파일이 고정된 패턴을 따른다(같은 은행, 같은 양식, 같은 이름 접두사): **File Juggler 유지**.
- 의미 없는 이름의 스크린샷, 스캔본, 휴대폰 사진, 잡다한 다운로드 파일: **Zush**.
- 확장자나 이름 기준의 무료 분류: **DropIt** 또는 **PowerShell**.
- 규칙과 AI를 한 도구에서, 또는 Linux: **Sortio**.
- PDF와 Word 파일을 무료로 한 번 정리: **Wisfile**.

둘 다 쓸 수도 있습니다. Zush가 다운로드 폴더를 감시하며 `2026-10-02_acme_invoice.pdf`처럼 예측 가능한 이름을 쓰고, File Juggler가 `*_invoice.pdf`를 고정된 Finance 폴더로 옮기는 식입니다. 각 도구가 잘하는 부분만 맡습니다. 어떤 설정이든 먼저 사본으로 시험하세요. 무엇을 확인해야 하는지는 [안전하게 파일 일괄 이름 변경하는 법](/blog/how-to-safely-batch-rename-files) 체크리스트에 정리했습니다.

AI 도구를 더 넓게 비교하려면 [Windows 11용 AI 파일 정리 도구 추천](/blog/best-ai-file-organizers-windows)을 보세요. Mac에서 넘어오셨다면 [Windows용 Hazel 대안](/blog/hazel-for-windows-alternatives)을 읽어 보세요.

## 자주 묻는 질문

### File Juggler의 무료 대안이 있나요?

네. DropIt은 무료 오픈 소스지만 최신 릴리스가 2018년 2월입니다. Sortio의 무료 요금제는 규칙 5개까지 제공하지만 폴더 감시는 Pro가 필요합니다. 스크립트를 쓸 수 있다면 PowerShell과 작업 스케줄러는 무료입니다. Wisfile은 PDF와 Word 파일용으로 무료입니다. 문제가 알아보기 힘든 파일 이름이라면 Zush가 계정이나 카드 없이 AI 이름 변경 50회를 무료로 제공합니다.

### File Juggler는 아직 관리되고 있나요?

네. File Juggler 공식 뉴스 페이지에 따르면 3.1.9 버전이 2026년 10월 30일에 나왔고, 라이선스에는 이후 모든 업그레이드가 포함됩니다. 지금도 정기적으로 업데이트되는 몇 안 되는 규칙 기반 Windows 정리 도구입니다. 대표적인 무료 대안인 DropIt은 2018년 2월 이후 릴리스가 없습니다.

### File Juggler는 AI를 쓰나요?

아니요. PDF, Word, Excel 파일 안의 단어를 포함해 직접 쓴 조건을 맞추고, 텍스트에서 찾은 날짜를 다시 쓸 수 있습니다. 별도의 OCR 프로그램 없이는 이미지로만 된 스캔본을 읽지 못하고, 사진이나 스크린샷에 무엇이 있는지도 알 수 없습니다. 이런 파일에는 Zush, Sortio, Wisfile 같은 AI 도구가 필요합니다.

### $48인 Zush와 비교해 File Juggler는 $50 가치가 있나요?

사는 것이 다릅니다. File Juggler의 $50 + 세금으로는 이후 모든 업그레이드가 포함된 규칙 엔진을 얻지만 AI는 없습니다. Zush의 $48 1회 결제 라이선스에는 관리형 Zush Cloud AI를 쓰는 AI 이름 짓기와 폴더 분류, 로컬 및 BYOK 모드, 무제한 이름 변경, 이후 모든 업데이트, Windows와 Mac을 합쳐 최대 3대가 포함됩니다. 둘 다 쓰는 사람도 많습니다.

### Zush나 File Juggler가 내 파일을 어디로 보내나요?

File Juggler는 규칙을 로컬에서 실행합니다. Zush는 선택한 모드에 따라 다릅니다. Ollama나 LM Studio를 쓰면 분석이 PC 안에 머물고, Zush Cloud AI나 본인의 API 키를 쓰면 이름을 만들기 위해 파일 내용이 해당 클라우드 모델로 전송됩니다. 기밀 폴더에는 로컬 모드를 고르세요. Sortio도 호스팅 AI, BYOK, Ollama를 제공하니 설정을 확인하세요.

### Mac용 File Juggler가 있나요?

아니요, File Juggler는 Windows 전용입니다. 규칙 기반으로는 Hazel이 Mac에서 가장 비슷하며, Softpedia 편집자 평가는 5.0/5입니다. Mac용 Zush는 외장 드라이브의 감시 폴더를 포함해 AI 이름 짓기와 폴더 분류를 지원합니다. Mac에서 두 방식이 어떻게 다른지는 [Hazel 대안](/hazel-alternative) 페이지를 참고하세요.

### Zush가 File Juggler를 완전히 대신할 수 있나요?

내용으로 파일 이름을 짓고 폴더로 분류하는 일이라면 감시 폴더를 포함해 가능합니다. 다만 File Juggler에는 명령 실행, 압축 풀기, Evernote 업로드처럼 Zush에 없는 동작이 있습니다. 이런 기능에 의존한다면 그 부분은 File Juggler에 맡기고, Zush가 File Juggler 규칙이 찾을 수 있는 설명형 이름을 쓰게 하세요.
