## 목적지를 정하는 세 가지 방식

공급업체, 고객, 월, 주제별 그룹을 지시하는 방식은 Zush, Sortio, Sparkle. 고정 카테고리 목록은 RenameClick, AI File Sorter. 이름, 날짜, 텍스트 조건은 Hazel, NameQuick Rules, File Juggler, DropIt입니다. 지시는 유연하고 목록은 관리가 필요하며 조건은 예상과 다른 파일에서 실패할 수 있습니다.

## 1. Zush

제안 폴더의 루트로 **Destination folder**를 선택하세요.

**Folder rules**는 최대 2,000자입니다. 비워 두면 Auto가 몇 개의 넓고 재사용 가능한 폴더로 묶습니다. **Template**은 날짜, 공급업체, 금액, 고객, 주제 등 이름을 정하고 Folder rules는 위치를 정합니다. 함께 미리 볼 수 있습니다.

PDF와 이미지 스캔, RAW, HEIC, Office, iWork, 디자인, 16가지 동영상 형식, 오디오를 지원합니다. 동영상은 프레임을 분석합니다. **Reuse existing folders**는 적합한 기존 폴더를 사용하고 필요하면 만듭니다. **Monitor**는 새 파일에 Template을 적용하며 만든 폴더를 기억합니다. LM Studio와 Ollama는 분석과 폴더 계획을 기기 안에 유지합니다. PRO는 Zush Cloud AI를 포함해 월간 파일 한도가 없습니다.

분류는 베타이며 목적지 아래 한 단계의 폴더를 만듭니다. 모호한 파일은 확인하세요. [Mac 안내](/blog/sort-files-into-folders-with-ai-mac), [Windows 안내](/blog/sort-files-into-folders-with-ai-windows).

## 2. Sortio

[Sortio](https://www.getsortio.com/)는 지시문으로 이름, 폴더, 이동을 계획합니다. 기존 폴더만 허용하거나 맞지 않는 파일의 대체 폴더를 지정할 수 있습니다. 무료는 최대 다섯 규칙의 무제한 규칙 분류, 감시, 취소, 일회성 AI 시험입니다. BYOK와 Ollama는 모든 요금제, Pro는 월간 AI 할당량이 있습니다. 문서, 이미지, PDF, 스프레드시트를 언급하지만 전체 형식 목록은 없습니다. Linux·팀에는 Sortio, 오디오·동영상과 세밀한 이름, 일회성 구매에는 Zush. [비교](/blog/zush-vs-sortio).

## 3. RenameClick

[RenameClick](https://rename.click/)은 AI Categories, 날짜·EXIF 기반 Metadata Folders, 최대 50개 최상위 폴더 중 고르는 Match Folders를 제공합니다. Auto Flow는 앱 실행 중 감시, 이동, 복사합니다. 분석 무제한, 성공한 이름 변경 또는 이동 월 100회 무료. 로컬 모델 포함. 동영상, RAW, 디자인은 공개 형식 목록에 없습니다. 고정 카테고리에는 적합하고 내용에서 회사별 그룹을 만들려면 Zush입니다. [비교](/blog/zush-vs-renameclick).

## 4. Sparkle

[Sparkle](https://makeitsparkle.co/)은 바탕화면, 다운로드, 문서를 일정에 따라 정리하고 AI Library를 만들며 지시를 받습니다. 중복과 오래된 스크린샷은 먼저 휴지통으로 보냅니다. Mac 전용, Every에도 포함됩니다. 이름은 바꾸지 않습니다. 개인 Mac 자동 청소용이며 이름, Windows, 명시적인 폴더 규칙이 중요하면 Zush입니다. [대안](/blog/sparkle-alternatives).

## 5. NameQuick

[NameQuick](https://www.namequick.app/)은 문서 내용으로 이름을 만든 후 Rules로 이동, 태그, 색, 보관을 실행합니다. Managed는 월 500회에 $12부터. $69 Self-Managed는 개인 API 키나 로컬 모델이 필요합니다. 목적지마다 조건을 만듭니다. [비교](/blog/zush-vs-namequick).

## 6. AI File Sorter

[AI File Sorter](https://github.com/hyperfield/ai-file-sorter)는 무료 AGPL 앱입니다. 카테고리, 선택적 하위 카테고리와 이름을 제안하고 허용 목록, 로컬 이미지 모델, 문서 텍스트 추출을 지원합니다. 로컬 모델 또는 개인 키, 마지막 실행 취소. 자유로운 그룹 지시와 감시는 없습니다. 오디오·동영상은 내장 메타데이터로 분류합니다. 모델을 설정할 수 있는 사용자의 일회성 정리에 적합합니다.

## 7. Hazel, File Juggler, DropIt

[Hazel](https://www.noodlesoft.com/) (Mac, $42), [File Juggler](https://www.filejuggler.com/) (Windows, 약 $40), [DropIt](https://www.dropitproject.com/) (Windows, 무료)는 이름, 확장자, 날짜, 텍스트 조건을 감시합니다. 예측 가능한 파일에는 좋지만 사진, 스캔, 동영상 의미를 이해하지 않습니다. AI 이름은 규칙을 쉽게 만들 수 있습니다. [Hazel 대안](/hazel-alternative), [Windows 옵션](/blog/hazel-for-windows-alternatives).

## 선택과 소량 시험

자유로운 지시와 다양한 형식은 Zush, Linux·팀은 Sortio, 고정 카테고리는 RenameClick, Mac 청소는 Sparkle, 무료는 AI File Sorter, 정확한 규칙은 Hazel 등입니다. 청구서, 영수증, 사진, 스크린샷, 스캔, 동영상 20개를 복사해 시험하세요. 필요한 지시를 쓰고 폴더와 배치를 확인한 뒤 적용하고 취소도 시험합니다. 이후 실제 폴더로 진행하세요. ## 자주 묻는 질문

### 일반적인 추천은?
Mac·Windows에서 검토, 오디오, 동영상, 로컬 AI, 월간 한도 없는 PRO를 원하면 Zush.

### 자동화할 수 있나요?
Zush, Sortio, RenameClick, Sparkle은 이동을 지원합니다. Zush에서 Folder rules를 Template에 저장하고 Monitor에 연결하면 감시 폴더 바로 안의 새 파일을 처리합니다.

### 무료 옵션은?
AI File Sorter, Zush 50회, Sortio 일회성 AI 시험, RenameClick 월 100회입니다.

### 오프라인 지원은?
Zush는 LM Studio·Ollama, RenameClick은 포함 모델, Sortio는 Ollama, AI File Sorter는 로컬 모델을 사용합니다.

### 규칙과 차이는?
규칙은 이름·확장자를 검사합니다. AI는 내용을 읽어 기존 이름에 단서가 없어도 청구서를 회사별로 분류합니다.
