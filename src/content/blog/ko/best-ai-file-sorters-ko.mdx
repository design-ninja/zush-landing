## AI 파일 분류 도구가 파일 위치를 정하는 방법

모든 분류 도구에는 폴더를 고르는 방법이 필요합니다. 방식은 세 가지입니다.

| 방식 | 사용자가 주는 것 | 예시 | 쓰는 앱 |
|---|---|---|---|
| **프롬프트** | 폴더 구성을 설명하는 문장 | "청구서는 회사별로, 영수증은 월별로 묶기" | Zush, Sortio |
| **카테고리 목록** | AI가 고를 폴더 이름 | 청구서, 영수증, 계약서, 기타 | RenameClick, AI File Sorter |
| **조건** | 이름, 날짜, 텍스트에 대한 if/then 규칙 | 이름에 "invoice"가 있으면 Finance로 이동 | Hazel, NameQuick Rules, File Juggler, DropIt |

프롬프트가 가장 유연합니다. 거래처, 고객, 월, 주제별로 파일 내용에 따라 폴더를 만들 수 있기 때문입니다. 카테고리 목록은 예측하기 쉽지만 직접 관리해야 합니다. 조건은 정확하지만 패턴에 맞지 않는 파일은 놓칩니다. Sparkle은 사용자 입력을 거의 받지 않고 스스로 라이브러리를 만듭니다.

Windows에서 이름 짓기, 폴더 감시, 실행 취소를 한곳에서 비교하고 싶다면 [Windows 11용 AI 파일 정리 도구 비교](/blog/best-ai-file-organizers-windows)를 보세요. Mac이라면 [Mac용 AI 파일 정리 도구 추천](/blog/best-ai-file-organizers-mac)이 있습니다.

평가 기준: 앱이 폴더를 얼마나 유연하게 정하는지, 같은 검토 단계에서 이름도 바꾸는지, 미리 보기와 실행 취소, 로컬 AI 선택지, 가격에 포함된 것.

## 1. Zush: 종합 1위 AI 파일 분류 도구

Zush는 한 번 검토하는 묶음 안에서 두 가지 일을 합니다. 파일 내용으로 이름을 짓고, 폴더로 분류합니다. 폴더 구성은 최대 2,000자를 받는 자연어 입력란인 **Folder rules**에서 정합니다. 비워 두면 Auto가 내용에 따라 다시 쓰기 쉬운 몇 개의 넓은 폴더로 묶습니다.

![청구서는 회사별, 영수증은 월별로 묶으라는 지시와 예시 규칙이 들어 있는 Zush의 Folder rules 대화 상자](/images/showcase/macos/folder-rules-light.webp)

다른 점:

- **더 많은 종류의 파일을 읽습니다.** PDF와 이미지로만 된 스캔본, RAW와 HEIC를 포함한 사진, 스크린샷, Office와 iWork 문서, 디자인 파일, 오디오, 그리고 MP4, MOV, MKV, AVI, WMV를 포함한 동영상. 동영상은 프레임, 음성, 내장 자막, 메타데이터로 이해하므로 "동영상을 주제별로 묶기"도 됩니다.
- **이름과 폴더를 함께 계획합니다.** Template이 파일 이름을, Folder rules가 위치를 정하고, 무엇이든 옮겨지기 전에 둘 다 확인할 수 있습니다.
- **이미 있는 폴더에 넣습니다.** Reuse existing folders를 켜면 Zush가 파일을 알맞은 기존 폴더에 맞추고, 맞는 폴더가 없을 때만 새로 만듭니다. 연도 아래 월처럼 중첩 규칙도 됩니다. 기준 위치는 **Destination folder**에서 정합니다.
- **중복 파일을 잡아냅니다.** AI Rename이 사본을 유지, 표시하거나 휴지통으로 보낼 수 있습니다. 사본에는 크레딧을 쓰지 않으며 Undo로 복원됩니다.
- **새 파일도 계속 분류합니다.** Template을 Monitor에 연결하면 새로 내려받거나 스캔한 파일이 들어오는 대로 이름이 바뀌고 분류됩니다.
- **무료로 시작해 1회 결제로 끝납니다.** 계정, 카드, 키 없이 Zush Cloud AI로 AI 이름 변경 50회 무료. PRO는 월 $10 또는 1회 $48이며, 1회 결제 라이선스는 클라우드를 포함한 모든 모드에서 무제한 이름 변경을 Mac과 Windows를 합쳐 최대 3대에서 제공합니다.

LM Studio나 Ollama를 쓰면 분석과 폴더 계획 모두 내 컴퓨터 안에서 처리됩니다. Rename History는 재시작 후에도 남고, Undo All은 묶음 전체를 되돌리면서 충돌을 표시합니다. Mac과 Windows 모두에서 이름을 바꾸지 않고 분류만 할 수도 있고, 날짜나 페이지 수 같은 파일 정보로 규칙을 만들 수 있습니다(Mac 앱은 크기, 카메라, 재생 시간도 씁니다). 설정 안내: [Mac](/blog/sort-files-into-folders-with-ai-mac), [Windows](/blog/sort-files-into-folders-with-ai-windows). 설정 항목 설명은 [폴더 분류 문서](/docs/folder-sorting)에 있습니다.

## 2. Sortio: 가장 가까운 대안, Linux도 지원

Sortio도 프롬프트 방식입니다. 정리 방식을 영어 문장으로 설명하고 계획을 검토하면 파일 이름을 바꾸고 폴더를 만들어 옮깁니다. 기존 폴더로만 분류하도록 제한하고, 맞지 않는 파일은 대체 폴더로 보낼 수 있습니다. macOS, Windows, Linux에서 동작하며 최신 버전은 사진과 동영상의 위치 메타데이터도 읽습니다.

무료 요금제에는 규칙 5개, Spaces 3개까지의 무제한 규칙 기반 분류, 1회성 AI 체험, 미리 보기, 분류 기록, 실행 취소가 있습니다. 폴더 감시와 자동화는 Pro가 필요합니다. 월간 AI 사용량을 포함해 월 $14.99 또는 연 $99입니다(App Store에는 월 $19.99로 표시). Ollama나 LM Studio를 통한 로컬 모델과 BYOK는 Free를 포함한 모든 요금제에서 쓸 수 있습니다. 이메일 계정으로 로그인해야 합니다.

Linux나 팀 좌석이 필요하면 Sortio를 고르세요. 약점: 무료 요금제에서는 더 이상 폴더를 감시하지 않고, 키를 직접 넣거나 로컬 모델을 쓰지 않으면 호스팅 AI 사용량이 제한됩니다. 자세한 비교: [Zush vs Sortio](/blog/zush-vs-sortio).

## 3. RenameClick: 직접 정한 카테고리로 분류

RenameClick의 분류 방식은 세 가지입니다. AI가 기본 또는 사용자 지정 세트에서 고르는 **폴더 세트**, 날짜나 EXIF 필드로 만드는 **Metadata Folders**, 출력 폴더의 기존 하위 폴더를 3단계 깊이까지 읽는 **Match Folders**입니다. Auto Flow는 앱이 실행 중일 때 폴더를 감시해 파일을 옮기거나 복사합니다.

![RenameClick(Mac 버전)이 Rename & Move 전에 이름을 바꾼 파일을 Legal Documents, Medical Documents, Uncategorized로 분류하는 화면](/images/blog/competitors/renameclick.webp)

무료 AI는 내장 로컬 모델(약 4 GB, RAM 16 GB 권장)로 동작하므로 Ollama를 설정할 필요가 없습니다. 4.1.2 버전부터 MP4, MOV, M4V, 3GP 동영상을 처리하지만 MKV, WebM, AVI, RAW, 디자인 파일은 지원하지 않습니다. 무료 요금제는 월 100회 이름 변경 또는 이동을 제공하고, 평생 라이선스는 $36 + VAT입니다.

카테고리가 고정돼 있고 미리 알고 있다면 RenameClick을 고르세요. 약점: 이름 변경 실행 취소는 메모리에 10개 항목만 남고 재시작하면 지워집니다. [Zush vs RenameClick](/blog/zush-vs-renameclick)을 참고하세요.

## 4. Sparkle: Mac을 알아서 정리

Sparkle은 데스크탑, 다운로드, 문서 등 폴더를 일정에 따라 정리합니다. 파일을 바탕으로 AI Library 폴더를 만들고, 중복을 표시하며, 정리 결과를 되돌릴 수 있습니다.

Mac 전용이고 무료 요금제가 없으며(15일 체험에 카드 필요), Mac 1대 기준 연 $119 또는 최대 5대 평생 $179입니다. 파일 이름은 바꾸지 않습니다.

개인 Mac을 한 번 설정해 두고 잊어버리는 정리용이라면 Sparkle을 고르세요. 약점: 폴더 구성을 직접 지정하지 않으며 파일 이름은 그대로입니다. [Sparkle 대안](/blog/sparkle-alternatives)을 참고하세요.

## 5. NameQuick: 이름 변경 후 규칙 적용

NameQuick은 문서를 내용으로 이름 지은 뒤 조건부 Rules를 실행해 파일을 폴더로 옮기거나, 태그를 붙이거나, 색상 라벨을 지정하거나, 보관합니다. Mac과 Windows에서 동작합니다.

![스캔한 청구서, 영수증, 계약서가 날짜와 거래처가 담긴 이름으로 바뀌는 모습을 보여 주는 NameQuick 홍보 이미지](/images/blog/competitors/namequick.webp)

카드 없이 Managed 이름 변경 30회가 무료입니다. Managed 요금제는 500회에 월 $12부터 시작하고, 이름 변경 팩은 500회 $19 또는 1,500회 $39이며, $69 Self-Managed 라이선스는 본인의 API 키나 로컬 모델이 필요합니다.

AI로 이름을 지은 뒤 if/then으로 보내고 싶다면 NameQuick을 고르세요. 약점: 목적지마다 규칙을 따로 만들어야 합니다. [Zush vs NameQuick](/blog/zush-vs-namequick)을 참고하세요.

## 6. AI File Sorter: 무료 오픈 소스

AI File Sorter는 Windows, macOS, Linux용 무료 AGPL-3.0 데스크톱 앱입니다(1.9.2 버전). 파일마다 카테고리와 선택적 하위 카테고리를 제안하고, 허용 카테고리 목록을 지원하며, 로컬 비전 모델로 이미지를 읽고, 문서에서 텍스트를 추출하고, 새 파일 이름도 제안할 수 있습니다. 로컬 모델이나 원격 API로 동작하며, Edit > Undo last run으로 마지막 묶음을 되돌립니다.

로컬 모델을 고르는 데 익숙하고 무료로 한 번 크게 정리하고 싶다면 AI File Sorter를 고르세요. 약점: 오디오와 동영상은 내장 메타데이터로만 이름을 짓고, 감시 폴더 기능은 문서에 없습니다.

## 7. Hazel, File Juggler, DropIt: AI 없는 규칙 도구

Hazel 6($42, Mac), File Juggler($50 + 세금, Windows, 3.1.9 버전), DropIt(무료, Windows, 마지막 릴리스 2018년 2월)은 폴더를 감시하다가 이름 패턴, 확장자, 날짜, 일치하는 텍스트 같은 조건에 따라 동작합니다. Softpedia 편집자 평가는 Hazel 5.0/5, File Juggler 4.5/5입니다.

약점: 셋 다 사진, 스캔본, 동영상에 무엇이 담겼는지 이해하지 못하므로 경우마다 규칙이 필요합니다. 설명형 이름이 있으면 규칙을 쓰기 쉬워서 AI 이름 변경 도구와 함께 쓰는 사람이 많습니다. [Hazel 대안](/hazel-alternative) 페이지와 [Windows용 Hazel 대안](/blog/hazel-for-windows-alternatives)을 참고하세요.

## 어떤 AI 파일 분류 도구를 골라야 할까요?

- Mac이나 Windows에서 폴더 구성을 평범한 문장으로 설명하고 싶다: **Zush**.
- 동영상(MKV 포함), 오디오, RAW 사진, 디자인 파일을 내용으로 분류해야 한다: **Zush**.
- Linux나 팀 좌석이 필요하다: **Sortio**.
- 카테고리가 고정돼 있고 내장 로컬 모델을 원한다: **RenameClick**.
- Mac을 알아서 정리해 주면 되고 파일 이름은 상관없다: **Sparkle**.
- 무료 오픈 소스를 원한다: **AI File Sorter**.

## 자주 묻는 질문

### 가장 좋은 AI 파일 분류 도구는?

Mac과 Windows 사용자 대부분에게는 Zush를 추천합니다. 폴더 구성을 평범한 문장으로 쓰거나 Auto를 쓰면, 묶음을 검토한 뒤 Zush가 파일을 읽고 이름을 바꿔 맞는 폴더로 옮깁니다. PDF, 스캔본, 사진, 동영상, 오디오를 처리하고 로컬 AI로도 동작합니다. Linux가 필요하면 Sortio가 가장 가까운 대안입니다. Zush는 저희 제품이니 두 앱 모두 사본으로 시험해 보세요.

### AI가 파일을 폴더로 자동 분류할 수 있나요?

네. Zush, Sortio Pro, RenameClick의 Auto Flow, NameQuick, Sparkle 모두 묶음을 매번 시작하지 않아도 새 파일을 폴더로 옮길 수 있습니다. Zush에서는 Folder rules를 Template에 저장하고 Monitor에 연결하면, 그 폴더에 들어오는 새 파일마다 이름이 바뀌고 분류됩니다. 어떤 폴더를 고르는지 확인할 수 있도록 먼저 수동 묶음으로 Template을 시험하세요.

### 무료 AI 파일 분류 도구가 있나요?

AI File Sorter는 무료 오픈 소스입니다. Zush는 계정, 카드, API 키 없이 AI 이름 변경 50회를 무료로 제공하므로 폴더 분류를 제대로 시험하기에 충분합니다. Sortio는 1회성 AI 체험과 무료 규칙 기반 분류를, NameQuick은 30회 무료 이름 변경을, RenameClick은 로컬 모델을 내려받은 뒤 월 100회 이름 변경 또는 이동을 무료로 제공합니다.

### 가격 대비 가장 많이 주는 AI 파일 분류 도구는?

무엇이 포함되는지에 따라 다릅니다. RenameClick의 평생 $36 + VAT는 로컬 모델이나 본인 키 사용을 포함하고, Sortio Pro는 AI 사용량을 포함해 연 $99입니다. Zush의 $48 1회 결제 라이선스에는 관리형 Zush Cloud AI와 BYOK, Ollama, LM Studio, 무제한 이름 변경, 이후 업데이트, Mac과 Windows를 합쳐 최대 3대가 포함됩니다.

### 오프라인으로 동작하는 AI 파일 분류 도구는?

Zush는 Mac과 Windows에서 LM Studio나 Ollama로 오프라인 분류가 가능하며, 파일 분석과 폴더 계획이 모두 내 컴퓨터에서 실행됩니다. RenameClick은 로컬 모델을 내장하고(RAM 16 GB 권장), Sortio는 Free를 포함한 모든 요금제에서 Ollama와 LM Studio를 지원하며, AI File Sorter는 로컬 모델로 동작합니다. 클라우드 모드에서는 Zush가 분석을 위해 파일 내용을 Zush Cloud AI나 본인의 제공업체로 보냅니다.

### AI 파일 분류 도구와 규칙 기반 정리 도구의 차이는?

Hazel이나 DropIt 같은 규칙 기반 도구는 파일 이름 패턴이나 확장자처럼 직접 쓴 조건에 맞는 파일을 옮깁니다. Zush 같은 AI 파일 분류 도구는 파일 내용을 읽고 "청구서는 회사별로 묶기" 같은 지시를 따르므로, 이름만으로는 알 수 없는 파일도 분류할 수 있습니다. 둘을 함께 쓸 수도 있습니다. AI가 먼저 이름을 짓고, 규칙이 그다음에 옮기는 식입니다.
