![이전 이름과 설명이 담긴 새 이름, 녹색 확인 표시가 보이는 Zush AI 이름 변경 결과](/images/showcase/macos/batch-rename-light.webp)

Zush는 섞인 폴더를 위한 데스크톱 AI 파일 이름 변경 도구입니다. 파일을 하나씩 읽고 이름을 제안하며, Rename을 누르기 전에는 아무것도 바꾸지 않습니다. 제안을 더블클릭해 먼저 수정할 수도 있습니다. 이름은 준비된 Templates(Movies & TV, Remove Duplicates 등), 145개 이상의 Naming Blocks, Custom AI Blocks, 그리고 대소문자, 구분자, 날짜, 언어 설정으로 만듭니다. Rename History는 묶음마다 원래 이름, 새 이름, 폴더, 시각을 보관하므로 다음 주에도 묶음을 되돌릴 수 있습니다.

`IMG_4821.HEIC`, `_DSC0019.NEF`, `checkout-flow.fig`, `voice-memo.m4a`, `client-brief.pages`, `episode-03.mkv`, `invoice.pdf`가 든 폴더도 하나의 작업 흐름에서 처리됩니다.

무료 요금제는 계정, 카드, API 키, 모델 다운로드 없이 Zush Cloud AI로 AI 이름 변경 50회를 제공합니다. PRO는 월 $10 또는 1회 $48입니다. 둘 다 Zush Cloud AI, BYOK(Gemini, OpenRouter, OpenAI, Claude), LM Studio, Ollama 전체에서 한도를 없앱니다. 라이선스 하나로 Mac과 Windows를 합쳐 최대 3대에서 쓸 수 있고, [Templates를 내보내](/docs/template-import-export) 기기 간에 설정을 옮길 수 있습니다.

## RenameClick

</BlogToolMeta>

![RenameClick 데스크톱 앱 화면(이미지: rename.click)](/images/blog/competitors/renameclick.webp)

RenameClick은 macOS와 Windows용 로컬 우선 데스크톱 앱으로, 현재 주소는 rename.click입니다. 내장 제공자는 API 키 없이 기기에서 약 4 GB 로컬 모델을 실행하며, 제조사는 RAM 16 GB를 권장합니다. Mac과 Windows 직접 배포 빌드(Mac App Store 빌드 제외)에서는 LM Studio, Ollama, OpenRouter 같은 OpenAI 호환 API에도 연결할 수 있고, 제공업체 사용료는 따로 청구됩니다.

최근 두 번의 릴리스로 상황이 달라졌습니다. 4.0.1 버전은 MCP 서버를 추가해 AI 에이전트가 RenameClick을 조작할 수 있게 했습니다. 4.1.2 버전(2026년 11월 10일)은 동영상을 추가했습니다. MP4, MOV, M4V, 3GP 파일을 샘플링한 프레임과 로컬 음성 받아쓰기로 이름 짓습니다. MKV, WebM, AVI는 여전히 미지원으로 나와 있습니다.

RenameClick은 순수한 이름 변경 도구라기보다 파일 정리 도구에 가깝습니다. 이름을 바꾸고, 파일을 폴더 세트로 옮기고, Auto Flow 감시 규칙을 실행하며, 의미로 파일을 찾는 AI Search 작업 공간이 있어서 청구서를 검색하면 `scan_001.pdf`라는 스캔본도 찾을 수 있습니다.

## 가격: 라이선스마다 포함된 것

Zush는 1회 $48 또는 월 $10이며, 월 요금으로는 세전 1년 $120, 3년 $360, 5년 $600이 됩니다. RenameClick은 1회 $36 + VAT 또는 월 $8 + VAT입니다. 의미 있는 비교는 1회 결제로 무엇을 사느냐입니다.

- **Zush $48:** 관리형 Zush Cloud AI와 BYOK, 로컬 모델에서 무제한 이름 변경, 이후 모든 업데이트, Mac과 Windows를 합쳐 최대 3대, 14일 환불 기간.
- **RenameClick $36 + VAT:** 내장 로컬 모델, Ollama, LM Studio, 본인 API 키로 무제한 이름 변경. 클라우드 제공업체 요금은 본인 부담. 평생 업데이트, 직접 배포 빌드 기준 최대 3대, 환불은 법이 요구하는 경우에만.

모델을 돌리거나 제공업체에 돈을 내지 않고 클라우드 수준의 이름을 원한다면 Zush 라이선스는 이를 포함하고 RenameClick 라이선스는 포함하지 않습니다. 추가 설정 없이 모든 것을 기기에서 처리하고 싶다면 RenameClick의 내장 모델이 더 간단합니다. Zush는 그러려면 Ollama나 LM Studio가 필요합니다.

무료 한도도 다릅니다. Zush는 월별 초기화 없이 총 50회를 제공합니다. RenameClick은 모델을 내려받은 뒤 매달 100회 이름 변경 또는 이동을 제공합니다.

## 동영상과 미디어

이제 두 앱 모두 동영상 내용으로 이름을 짓습니다. 차이는 지원 범위와 근거에 있습니다.

- **컨테이너.** Zush는 MP4, MOV, MKV, AVI, WMV 등 일반적인 형식을 읽습니다. RenameClick은 MP4, MOV, M4V, 3GP를 읽고 MKV, WebM, AVI는 미지원으로 표시합니다. 보관함이 MKV로 저장하는 다운로드나 화면 녹화 프로그램에서 온다면 중요한 차이입니다.
- **근거.** Zush는 샘플링한 프레임, 음성, 내장 자막 트랙(MKV 파일 안의 자막 포함), 파일 메타데이터를 합칩니다. RenameClick은 프레임과 로컬 음성 받아쓰기를 합칩니다.
- **로컬 음성.** Zush는 Ollama나 LM Studio로 로컬 받아쓰기를 할 수 있습니다(Mac 3.20.1). RenameClick은 자체 로컬 구성으로 합니다.
- **TV와 영화.** Zush의 Movies & TV 템플릿은 프로그램, 시즌, 에피소드 번호로 에피소드 이름을 짓고 프로그램과 시즌 폴더로 분류할 수 있습니다.

Windows에서는 Zush가 태그 없는 음악도 식별할 수 있습니다. 이 기능은 아직 Mac에는 없습니다. [오디오와 동영상 분석](/docs/audio-video)과 [AI로 동영상 이름 변경](/rename-videos-with-ai)을 참고하세요.

## 사진, 디자인 파일, 문서

RenameClick은 일반 이미지와 긴 문서 목록을 잘 다루며, PDF와 Office 파일에서 텍스트를 추출하고 스캔본에는 비전 모델을 대신 씁니다. 문서에는 카메라 RAW, Sketch, Figma, PSD 파일이 나와 있지 않습니다.

Zush는 RAW 변형 11가지(CR2, CR3, NEF, ARW, DNG, ORF, RAF, RW2, PEF, SRW, SR2), 디자인 파일(Sketch, Figma, Illustrator, Photoshop), iWork 문서, EPUB, 자막을 지원 목록에 올려 두었습니다. 이런 형식 때문에 이 글을 읽고 있다면 먼저 시험해 보세요.

## 실행 취소와 복구

RenameClick의 기본 Rename 작업 공간은 실행 취소 항목을 메모리에 최대 10개까지 보관하고 앱을 재시작하면 지웁니다. 테스트에서는 Undo 한 번으로 파일 27개 묶음 전체가 되돌아갔습니다. Auto Flow는 해당 기록을 재시작 후에도 유지합니다.

Zush는 모든 묶음에 대해 영구 [Rename History](/docs/undo-history)를 남깁니다. Undo All은 묶음을 복원하면서 충돌(예: 새 파일이 이제 이전 이름을 쓰고 있는 경우)을 나열하고 새 이름으로 복원하도록 제안합니다. AI Rename 중에 Zush가 휴지통으로 옮긴 중복 사본도 Undo로 복원됩니다.

## 자동화와 분류

두 앱 모두 폴더를 감시하고 파일을 옮깁니다.

Zush의 Monitor는 Template으로 새 파일 이름을 바꾸고, 자연어 Folder rules나 Auto로 중첩 폴더까지 분류할 수 있습니다. 규칙에는 날짜나 페이지 수 같은 파일 정보도 쓸 수 있습니다(Mac 앱은 크기, 카메라, 재생 시간도 씁니다). 이미 이름을 바꾼 파일은 다시 이름을 바꾸지 않고 분류할 수 있습니다. Mac에서는 외장 드라이브도 감시하며 다시 연결하면 재개합니다. [폴더 분류 가이드](/docs/folder-sorting)를 참고하세요.

RenameClick의 Auto Flow는 규칙 행의 모음으로, 행마다 원본 폴더, 대상, 이름 형식, 지시, 언어, 분류 프리셋이 있습니다. 파일 쓰기가 끝날 때까지 기다리고, 대상 폴더 안에서 반복되지 않게 하며, 무료 요금제 크레딧이 떨어지면 멈춥니다. 앱이 열려 있을 때만 동작합니다.

## 무엇을 골라야 할까요?

**Zush를 고를 때:**

- 폴더에 MKV 동영상, RAW 사진, 디자인 파일, iWork 문서가 있다
- 재시작 후에도 어떤 묶음이든 되돌릴 수 있어야 한다
- 모델 다운로드나 제공업체 청구서 없이 관리형 클라우드 AI가 포함된 1회 결제 가격을 원한다
- Mac과 Windows 컴퓨터를 아우르는 라이선스 하나로 최대 3대를 쓰고 싶다
- 이름 변경과 같은 단계에서 중복까지 처리하고 싶다

**RenameClick을 고를 때:**

- Ollama 설정 없이 내장 모델로 오프라인 이름 변경을 원하고, Mac이나 PC의 메모리가 충분하다
- 전용 작업 공간에서 내용으로 파일을 검색해야 한다
- AI 에이전트가 MCP 서버로 이름 변경을 실행하게 하고 싶다
- 폴더 규칙을 쓰기보다 폴더 세트에서 고르는 편이 좋다

어느 쪽이든 사기 전에 대표적인 파일 10개를 테스트 폴더에 복사해 두 무료 요금제를 모두 써 보세요. 이름, 미리 보기, 미지원 형식, 묶음 전체를 되돌릴 수 있는지 비교하세요.

## 자주 묻는 질문

### 언제 RenameClick 대신 Zush를 골라야 하나요?

폴더에 RAW 사진, 디자인 파일, iWork 문서, 오디오, MKV 동영상이 섞여 있고 이름이 재사용 가능한 Template을 따르길 원할 때 Zush를 고르세요. Zush는 모든 이름을 미리 보여 주고, 묶음 단위 실행 취소가 되는 영구 Rename History를 남기며, $48 라이선스에 최대 3대용 관리형 클라우드 AI가 포함됩니다. 내장 로컬 모델, AI Search, MCP 서버가 필요하다면 RenameClick이 더 맞습니다.

### RenameClick은 동영상 파일을 지원하나요?

네, 4.1.2 버전(2026년 11월 10일)부터 지원합니다. MP4, MOV, M4V, 3GP 동영상을 샘플링한 프레임과 로컬 음성 받아쓰기로, MP3, WAV, FLAC, M4A, AAC 같은 오디오 파일도 이름 짓습니다. MKV, WebM, AVI는 여전히 미지원으로 나와 있습니다. Zush는 MP4, MOV, MKV, AVI, WMV 등을 처리하고 내장 자막 트랙도 읽습니다. [지원 형식 목록](/docs/supported-file-types)을 참고하세요.

### RenameClick이 Zush보다 싼가요?

표시 가격은 더 낮습니다. 1회 $36 + VAT 대 $48입니다. 하지만 라이선스가 포함하는 것이 다릅니다. Zush의 $48에는 관리형 Zush Cloud AI, BYOK와 로컬 모델, 이후 모든 업데이트, Mac과 Windows를 합쳐 3대, 14일 환불이 포함됩니다. RenameClick의 평생 라이선스는 로컬 모델이나 본인 키 사용을 포함하며, 제공업체 요금은 본인 부담이고 환불은 법이 요구하는 경우에만 됩니다.

### 각 앱에서 내 파일은 어디서 처리되나요?

RenameClick의 내장 모델은 약 4 GB를 내려받은 뒤 기기에서 실행되고, 연결한 클라우드 제공업체는 필요한 내용을 받습니다. Zush에서는 Ollama와 LM Studio가 분석을 컴퓨터 안에 두고, Zush Cloud AI와 BYOK는 이름을 짓는 데 필요한 내용을 클라우드 모델로 보냅니다. 모드는 Template마다 고를 수 있으므로 개인 폴더는 로컬에 둘 수 있습니다.

### 재시작한 뒤에도 일괄 이름 변경을 되돌릴 수 있나요?

Zush에서는 됩니다. Rename History가 디스크에 저장되고, Undo All이 묶음 전체를 복원하면서 이름 충돌을 나열합니다. RenameClick의 Rename 작업 공간에서는 실행 취소가 메모리에 최대 10개 항목을 보관하고 재시작하면 지웁니다. Auto Flow는 해당 기록을 재시작 후에도 유지합니다. 큰 폴더에 어느 앱이든 쓰기 전에 사본으로 복구를 시험하세요.

### RenameClick은 OpenRouter를 지원하나요?

네, Mac과 Windows 직접 배포 빌드에서 다른 OpenAI 호환 API와 함께 지원합니다. Mac App Store 빌드에는 없고, 연결한 제공업체가 사용료를 따로 청구합니다. Zush는 모든 요금제에서 BYOK로 OpenRouter를 지원하므로, OpenRouter만으로는 어느 쪽으로든 바꿀 이유가 되지 않습니다.

### RenameClick은 RAW 사진을 지원하나요?

공개된 지원 파일 목록에는 CR2, CR3, NEF, ARW, DNG 같은 카메라 RAW 형식도, PSD, Sketch, Figma 같은 디자인 파일도 없습니다. Zush는 RAW 변형 11가지와 이 디자인 형식들을 지원 목록에 올려 두었습니다. RAW 파일이 작업에 포함된다면 사기 전에 두 무료 요금제로 몇 개를 처리해 보세요.
