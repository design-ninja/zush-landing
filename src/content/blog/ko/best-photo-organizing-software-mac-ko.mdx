Mac의 개인 사진 보관함에는 무료 Apple Photos로 시작할 수 있습니다. 여러 기기의 개인 아카이브에는 Mylio, 편집과 정리에는 Lightroom과 Capture One이 적합합니다. 일반 Finder 폴더의 사진은 Zush로 내용을 설명하는 이름을 붙이고 실제 폴더로 분류할 수 있습니다. 선택 기능인 폴더 분류는 베타입니다. 수동 일괄 처리를 적용하기 전에 이름과 위치를 확인하세요.

## 사진 보관함과 일반 파일의 차이

보관함은 앨범, 얼굴, 평가, 검색을 자체 데이터베이스로 관리합니다. 파일 이름과 실제 폴더는 파일 시스템, 외장 드라이브, 공유 위치에서도 보입니다. Zush는 파일을 정리하며 앨범, 얼굴 인식, 중복 검토, 백업을 대체하지 않습니다.

## 1. Apple Photos

Apple Photos는 iPhone과 Mac의 개인 사진 보관함에 적합합니다. 앨범, 인물, 장소, 중복 사진을 앱 안에서 관리하며 Finder에서 보관함 패키지를 직접 수정하면 안 됩니다. iCloud는 삭제도 동기화하므로 별도의 백업이 필요합니다.

[Apple Photos](https://support.apple.com/guide/photos/welcome/mac).

## 2. Adobe Lightroom

Lightroom은 편집, 평점, 앨범, 검색을 클라우드 동기화 보관함에 결합합니다. Lightroom Classic은 파일 제어가 더 자유로운 데스크톱 카탈로그를 사용합니다. 대량으로 가져오기 전에 방식을 선택하고 구독 비용을 고려하세요.

[Adobe Lightroom](https://helpx.adobe.com/lightroom/desktop/organize-photos/organize-photos.html).

## 3. Mylio Photos

Mylio는 컴퓨터, 휴대기기, 드라이브의 사진과 동영상을 하나로 모읍니다. 로컬 분석과 기기 간 동기화는 개인 아카이브에 유용합니다. 최적화된 미리보기는 원본을 대체하지 않으므로 저장 공간과 백업 계획을 마련하세요.

[Mylio Photos](https://mylio.com/).

## 5. Excire Foto 2027

Excire는 내용, 얼굴, 비슷한 사진, 중복을 검색하는 로컬 카탈로그를 만듭니다. 사진을 찾기 쉽게 하지만 파일 이름을 자동으로 개선하지는 않습니다. 구입 전 체험판에서 시스템 요구 사항과 카탈로그 용량을 확인하세요.

[Excire Foto 2027](https://excire.com/en/excire-foto/).

## 6. Photo Mechanic Plus

[Photo Mechanic Plus는 더 이상 판매되지 않습니다. 새 카탈로그에는 다른 도구를 선택하세요.](https://home.camerabits.com/photo-mechanic-plus-is-no-longer-available-for-purchase/)

Photo Mechanic Plus는 빠른 가져오기와 선별에 여러 폴더와 드라이브를 아우르는 카탈로그를 더합니다. IPTC 메타데이터, 필터, 저장된 검색이 강점입니다. 완전한 RAW 편집기는 아니며 메타데이터가 부족한 아카이브에는 사전 정리가 필요합니다.

[Photo Mechanic Plus](https://home.camerabits.com/photo-mechanic-plus-is-no-longer-available-for-purchase/).

## 7. Zush

내용 기반 이름과 선택적 AI 폴더 그룹 (베타).

Zush 폴더 분류는 Mac과 Windows에서 베타로 제공됩니다. 지원 파일의 내용을 분석해 이름과 그룹을 제안합니다. Auto를 쓰려면 Folder rules를 비우고, 직접 정하려면 자연어로 지시하세요. 파일 이름 형식은 Naming Blocks에서 별도로 설정합니다.

내보낸 이미지나 복사 폴더로 시험하세요. Photos 보관함 패키지 내부를 재배치하지 마세요. 카탈로그에 등록된 원본은 해당 프로그램의 이름 변경 또는 다시 연결 절차를 따르세요. 이름 변경과 이동 모두 파일 경로를 바꿉니다.

## AI로 파일을 폴더에 분류하기

> 이미지를 사람, 음식, 풍경 등 주제별로 묶어 주세요.

1. 복사한 작은 묶음을 AI Rename에 추가하고 Template을 선택합니다.
2. + Sort를 켜고 하위 폴더의 루트로 Destination folder를 선택합니다. 별도 대상이 없으면 원본 폴더가 루트입니다.
3. Folder rules에 분류 방법을 적습니다. 대상 안의 적절한 기존 폴더를 쓰려면 Reuse existing folders를 켭니다. 맞는 폴더가 없으면 새로 만들 수 있습니다.
4. 처리를 적용하기 전에 제안된 이름과 그룹을 확인하고 수정합니다.

![Mac용 Zush에서 Rename & sort 적용 전 제안된 파일 이름과 내용별 폴더 그룹을 표시](/images/showcase/macos/folder-sorting-light.webp)

검증한 대상과 규칙을 Template에 저장하세요. Monitor는 감시 폴더 바로 안에 새로 들어오는 파일의 이름과 분류를 처리합니다. 이미 처리한 파일을 소급해 정리하지 않습니다. 분류를 끄고 원래 대상을 선택하면 파일은 현재 폴더에 남습니다.

## 어떤 프로그램을 선택할까요?

보관함, 편집, 메타데이터, 고정 규칙, 내용 기반 이름과 폴더 중 필요한 작업으로 선택하세요. Zush는 일반 폴더의 지원 파일에 미리보기와 선택적 그룹 분류를 제공합니다. 카탈로그나 백업을 대체하지 않습니다.

## 전환 전에 복사본으로 시험하기

사진, 스크린샷, RAW, 문서, 모호한 이름이 포함된 작은 복사본부터 시작하세요. 미리보기, 그룹, 메타데이터, 보조 파일, 외장 드라이브, 복구를 확인합니다. 보관함에서는 가져오기, 내보내기, 백업, 카탈로그 복원도 시험하세요. 새 절차가 검증될 때까지 기존 아카이브를 유지하세요.

## 자주 묻는 질문

### Zush는 파일을 실제 폴더로 이동하나요?

예. 선택적인 베타 분류를 켜고 대상, 이름, 그룹을 확인하세요. 현재 위치에서 이름만 바꾸려면 분류를 끄고 원래 대상을 유지합니다.

### 새 파일을 자동으로 분류할 수 있나요?

예. 시험한 Template을 Monitor에 지정합니다. 감시 폴더 바로 안의 새 파일이 대상이며 이미 처리한 파일은 재배치하지 않습니다.

### 기존 폴더와 외장 드라이브를 사용할 수 있나요?

Reuse existing folders는 대상 루트 안의 적합한 폴더를 사용하고 필요하면 새 폴더를 만듭니다. 드라이브와 파일에 접근할 수 있어야 하며 클라우드 파일은 먼저 내려받습니다.

### 파일이 클라우드 AI로 전송되나요?

Zush Cloud AI와 BYOK는 선택한 클라우드 제공자에게 내용을 보냅니다. Ollama와 LM Studio는 지원되는 로컬 분석을 제공합니다. 로컬 분석이 앱의 모든 기능이 오프라인이라는 뜻은 아닙니다.
