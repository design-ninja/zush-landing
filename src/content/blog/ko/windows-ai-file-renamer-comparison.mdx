**확인 방법:** 이 글은 [Zush](/) 제작사가 썼습니다. 2026년 11월 25일에 6개 앱을 모두 Windows 11에 설치하고 각 앱에 같은 파일 30개를 넣었습니다([아래 테스트 결과](#같은-파일-30개로-6개-앱을-모두-테스트했습니다)). 가격, 기능, 평점은 2026년 11월 17일에 각 제조사 사이트와 공식 스토어에서 확인했습니다([아래 출처](#sources-and-how-we-checked)).

## 같은 파일 30개로 6개 앱을 모두 테스트했습니다

2026년 11월 25일에 Windows 11 Pro(ARM64, 가상 머신)에서 모든 앱을 기본 설정으로 실행했습니다. 테스트 세트는 파일 30개로, 일상 문서 20개(그중 4개는 텍스트 레이어가 없는 스캔 PDF)와 RAW 사진 3개, JPG 4개, HEIC 3개입니다. 결과는 [공개한 채점 기준](/methodology)으로 점수를 매겼고, 별도 채점자가 어느 앱이 만든 이름인지 모르는 상태에서 파일 이름을 하나하나 채점했습니다. [전체 데이터, 입력 파일, 모든 이름](/benchmarks/windows-ai-renamers-2026-11-25/README.md)을 공개해 두었습니다.

| 앱 | 이름을 바꾼 파일(30개 중) | 첫 결과 전에 필요한 계정이나 키 | 텍스트 없는 스캔본 | 묶음 전체 실행 취소 | 점수 / 100 |
|---|---|---|---|---|---|
| <BlogHighlight>**Zush**</BlogHighlight> | **30** | **없음** | **4개 중 4개** | **클릭 한 번, 30개 모두 복원** | **94.8** |
| NameQuick | 30 | 없음 | 4개 중 4개 | 파일별(작업 30번) | 73.0 |
| RenameClick | 27, RAW 건너뜀 | 본인 API 키 | 4개 중 4개 | 작업 한 번 | 70.2 |
| Renamer.ai(웹) | 25, RAW 거부 | 계정 | 4개 중 4개 | 이름 바뀐 사본을 내려받음 | 56.8 |
| FilesDesk | 15, 무료 크레딧, RAW와 HEIC 제외 | 계정 | 4개 중 4개 | 파일별 | 52.5 |
| AI Renamer | 10, 텍스트 문서 모두 실패 | Google 계정 | 4개 중 1개 | 없음 | 37.2 |

눈에 띈 점:

- **Zush**는 파일 30개의 이름을 약 22초 만에 짓고 2초도 안 걸려 적용했습니다. Undo All은 원래 이름 30개를 0.6초 만에 모두 되돌렸고, 파일마다 직접 확인했습니다. 평범한 영어 문장으로 쓴 Custom AI Block 하나로 문서 20개 중 16개의 이름에 문서에 인쇄된 날짜를 넣었습니다. 사본 3개가 섞인 파일 33개에서는 Sort into folders가 모든 파일을 폴더에 넣고 사본 3개를 모두 표시했습니다.
- **NameQuick**은 모든 파일에 좋은 이름을 붙였지만 온보딩에서는 처음 10개만 받았습니다. 나머지 20개는 감시 폴더로 처리했고, 30개 이름이 모두 나오기까지 3분 가까이 걸렸습니다. 되돌리려면 파일마다 한 번씩 클릭해야 했습니다.
- **RenameClick**은 자체 AI가 없어서 본인 API 키나 4 GB 로컬 모델이 필요합니다. 분류를 켜자 파일 33개 중 21개를 옮겼고, 중복 배지는 원본에 붙였습니다.
- **Renamer.ai**는 RAW 사진 3개 때문에 선택 전체를 거부했습니다. 테스트 PC에서 데스크톱 앱이 실행되지 않아 웹 앱을 썼습니다.
- **FilesDesk**와 **AI Renamer**는 세트를 끝내기 전에 무료 크레딧이 떨어졌고, AI Renamer에는 실행 취소가 아예 없습니다.

### Windows에서 Zush가 1위인 이유

1. **Microsoft Store에서 설치합니다.** Windows 10과 11용 x64 및 ARM64 패키지가 있고, 업데이트는 스토어가 관리합니다. 포터블 ZIP도 있습니다.
2. **File Explorer와 잘 맞습니다.** Explorer, OneDrive, 바탕 화면에서 파일을 드롭존으로 끌어오거나, Explorer에서 파일을 최대 10개 선택하고 Quick Rename 단축키를 누르세요. 묶음은 미리 보기를 거치고, Rename History로 재시작 후에도 묶음 전체를 되돌릴 수 있습니다.
3. **PowerRename이 못 읽는 것을 읽습니다.** PowerRename은 선택 전체에 규칙 하나를 적용합니다. Zush는 PDF 텍스트, 사진에 보이는 것, 동영상(MKV 포함)의 음성과 자막, 그리고 Windows 전용 기능인 태그 없는 음악 식별까지, 파일마다 내용으로 고유한 이름을 붙입니다.
4. **오프라인 AI에 음성도 포함됩니다.** Ollama나 LM Studio에 AI 설정에서 내려받는 선택 사항인 기기 내 음성 인식을 더하면 클라우드 없이 오디오와 동영상 이름을 지을 수 있습니다. 같은 $48 라이선스에 최대 3대용 관리형 Zush Cloud AI도 포함됩니다.

미국 Microsoft Store 평점(2026년 11월 17일 기준): Zush 평가 8개 기준 5.0, RenameClick 평가 6개 기준 3.0, FilesDesk는 아직 평가 없음. Softpedia 편집자 점수: Zush 4.5/5, Renamer.ai 4.5/5, RenameClick 3.5/5.

## Windows에서 Zush가 제공하는 클라우드와 로컬 AI 선택지는?

Zush에는 클라우드 선택지 두 가지와 로컬 선택지 두 가지가 있습니다. 이름을 만들고, 미리 보고, 적용하는 방식은 그대로 두고 전환할 수 있습니다.

| Zush AI 선택지 | 분석이 실행되는 곳 | 적합한 경우 |
|---|---|---|
| **Zush Cloud AI** | Zush가 관리하는 클라우드 서비스 | 제공업체나 모델 설정 없이 바로 시작 |
| **BYOK** | 본인의 Gemini, OpenRouter, OpenAI, Claude 계정 | 본인의 제공업체 계정과 API 키 사용 |
| **Ollama** | 내 PC | 기존 Ollama 설정의 모델 실행 |
| **LM Studio** | 내 PC | LM Studio가 제공하는 모델 사용 |

민감한 폴더라면 로컬 선택지가 분석을 PC 안에 둡니다. 선택 사항인 기기 내 음성 인식이 동영상도 처리합니다. BYOK는 직접 관리하는 계정을 거치더라도 여전히 클라우드 경로입니다. 경로마다 무엇을 다루는지는 [개인정보 및 보안 가이드](/docs/privacy-security)에 설명돼 있습니다.

## AI 이름 변경이 PowerRename과 다른 점

PowerRename 같은 패턴 도구는 선택한 모든 파일에 규칙 하나를 적용합니다. AI 이름 변경 도구는 파일을 하나씩 엽니다. 문서 텍스트, 이미지나 스크린샷에 보이는 것, 동영상의 음성을 보고 파일마다 다른 이름을 제안하므로 `scan_004.pdf`가 `invoice-7842-webdesign-services.pdf`가 됩니다. 공통 접두사나 번호만 필요하다면 PowerRename은 무료이고 충분합니다. 이런 도구는 [Windows 11 파일 이름 변경 도구 가이드](/blog/best-file-renamer-windows-11)에서 다룹니다.

## Windows에서 검토하는 묶음 시험해 보기

1. Microsoft Store에서 [Windows용 Zush](/windows)를 설치하고 Zush Cloud AI를 선택한 채로 둡니다.
2. 스크린샷, PDF, Office 파일 몇 개를 테스트 폴더에 복사합니다. AI Rename에 넣고 Template을 고릅니다.
3. 제안된 이름을 파일과 하나씩 비교합니다. 이름을 더블클릭해 수정한 뒤 Rename을 누릅니다.
4. [Rename History](/docs/undo-history)를 열고 묶음을 되돌려 복구가 되는지 확인합니다. Template이 마음에 들면 폴더 감시를 켭니다.

[Windows용 Zush](/windows)는 스크린샷, PDF, Office 파일, RAW를 포함한 사진, 디자인 파일, 오디오, 동영상을 내용으로 이름 짓습니다. 준비된 Templates(Smart Rename, Movies & TV, Remove Duplicates 등)와 145개 이상의 Naming Blocks가 구조를 고정하고, Custom AI Blocks가 기본 블록이 다루지 않는 항목을 뽑아냅니다.

**장점:**

- 자동 업데이트되는 Microsoft Store 설치
- 하나의 작업 흐름에 AI 경로 네 가지: Zush Cloud AI, BYOK, Ollama, LM Studio
- MKV를 포함한 동영상을 음성, 내장 자막, 메타데이터로 이름 지정
- 태그 없는 음악 식별
- 중복 감지: 유지, 이름에 표시, 또는 휴지통으로 이동, 사본은 크레딧 미사용, Undo로 복원
- 시작 값과 앞자리 0을 지정하는 폴더별 일련번호
- 폴더마다 Template을 지정하는 폴더 감시와 선택 사항인 AI 폴더 분류
- 묶음 단위 실행 취소가 되는 영구 Rename History, Undo All이 충돌 표시

**한계:**

- Linux 빌드와 브라우저 전용 버전 없음
- Zush Cloud AI와 BYOK는 인터넷 필요, Ollama와 LM Studio는 로컬에서 실행

## 2. FilesDesk

## 3. RenameClick

Auto Flow는 앱이 실행 중일 때 파일 이름을 바꾸고 옮깁니다. 무료 요금제는 월 100회 이름 변경 또는 이동을 허용하고, Lifetime은 직접 배포 빌드 기준 최대 3대에 $36 + VAT입니다.

## 4. AI Renamer

Local Mode는 본인 키, Ollama, LM Studio로 쓰는 1회 $19이고, 클라우드 크레딧은 200개당 $10이며 Google 로그인 후 10개가 무료입니다. 환불 규정은 없고 크레딧 구매는 환불되지 않습니다.

같은 개발자가 GitHub에 무료 GPL-3.0 명령줄 도구인 [`ozgrozer/ai-renamer`](https://github.com/ozgrozer/ai-renamer)도 공개하고 있습니다. 데스크톱 앱은 자체 설치 프로그램이 있는 별개 제품입니다.

## 자주 묻는 질문

### AI 이름 변경 소프트웨어란?

AI 이름 변경 소프트웨어는 파일마다 내용(문서 텍스트, 이미지에 보이는 것, 동영상의 음성)을 읽고 설명형 파일 이름을 제안합니다. 일괄 이름 변경 도구는 묶음 전체의 텍스트를 바꾸거나 번호를 붙일 수 있지만, 둘 다 `scan_004.pdf`라는 이름이라면 청구서와 보증서를 구분하지 못합니다. Zush, FilesDesk, RenameClick, AI Renamer, Renamer.ai, NameQuick이 Windows용 AI 이름 변경 도구입니다.

### Windows에서 가장 좋은 AI 파일 이름 변경 도구는?

저희 추천은 Zush입니다. Microsoft Store에서 설치하고, 계정, 카드, API 키 없이 AI 이름 변경 50회를 무료로 제공하며, $48 1회 결제 라이선스에 관리형 클라우드 AI, BYOK, Ollama, LM Studio가 최대 3대용으로 포함됩니다. 모든 묶음은 미리 보고, 묶음 단위 실행 취소가 되는 Rename History에 남습니다. 같은 파일 30개로 6개 앱을 비교한 테스트에서 30개 모두 이름을 바꿨고 100점 만점에 94.8점을 받았습니다. FilesDesk, RenameClick, AI Renamer, Renamer.ai, NameQuick은 각각 더 좁은 필요에 맞습니다.

### Renamer.ai와 AI Renamer는 같은 제품인가요?

아니요. Renamer.ai(renamer.ai)는 Windows, Mac, 웹용 구독형 이름 변경 도구로, 요금제는 월 $9.95~$99.95이고 모든 요금제에 로컬 모드가 있습니다. AI Renamer(airenamer.app)는 1회 $19 Local Mode와 $10 클라우드 크레딧 팩이 있는 데스크톱 앱입니다. GitHub의 무료 `ozgrozer/ai-renamer` 명령줄 도구는 AI Renamer와 같은 개발자가 만들었지만 별개 프로젝트입니다.

### $48 1회 결제 라이선스가 더 저렴한 라이선스보다 가치가 있나요?

AI가 포함되길 원하느냐에 달려 있습니다. AI Renamer Local($19)과 RenameClick Lifetime($36 + VAT)은 앱을 포함하지만 AI는 본인 키나 PC가 직접 돌려야 하는 모델로 실행됩니다. Zush의 $48에는 무제한 이름 변경이 가능한 관리형 Zush Cloud AI와 BYOK, 로컬 모델, 이후 모든 업데이트, Windows와 Mac을 합쳐 3대, 14일 환불이 포함됩니다.

### Windows에서 Zush를 쓰면 내 파일은 어디서 처리되나요?

Zush Cloud AI나 BYOK를 쓰면 이름을 만들기 위해 파일 내용이 AI 서비스로 갑니다. BYOK는 본인의 제공업체 계정을 씁니다. Ollama나 LM Studio를 쓰면 분석이 PC에서 실행되고, 선택 사항인 기기 내 음성 인식이 동영상을 처리합니다. 미리 보기, 수동 확인, Rename History는 모든 모드에서 똑같이 동작합니다. [개인정보 및 보안 가이드](/docs/privacy-security)를 참고하세요.

### Windows에서 Zush는 PowerRename과 어떻게 다른가요?

PowerToys 유틸리티인 [PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)은 File Explorer에서 선택한 파일에 찾아 바꾸기, 정규식, 카운터, 날짜나 EXIF/XMP 토큰 같은 공통 규칙 하나를 적용합니다. AI가 없고 파일 내용을 읽지 않습니다. Zush는 파일을 하나씩 읽고 고유한 이름을 제안한 뒤, 묶음을 미리 보고, 적용하고, 되돌릴 수 있게 합니다. 일정한 패턴 변경이라면 PowerRename은 무료이고 충분합니다.

### 브라우저 도구가 아닌 Windows 네이티브 앱이 있나요?

네. [Windows용 Zush](/windows)는 x64와 ARM64 패키지로 Microsoft Store에서 설치하며 Windows 10과 11에서 동작합니다. FilesDesk와 RenameClick도 Microsoft Store에 있습니다. AI Renamer, Renamer.ai, NameQuick은 자체 사이트에서 Windows 설치 프로그램을 제공합니다. 브라우저 도구는 대신 파일을 업로드하므로, 소프트웨어를 설치할 수 없을 때 가끔 쓰기에 맞습니다.
