간단한 답: Windows 11에서 여러 파일의 이름을 한 번에 바꾸려면 File Explorer에서 파일을 선택하고 **F2**를 누른 다음 이름을 입력하고 **Enter**를 누르세요. Windows가 `Name (1)`, `Name (2)` 같은 식으로 이름을 붙입니다. 텍스트 바꾸기, 날짜 추가, 파일마다 실제 이름 지정처럼 더 똑똑한 작업이 필요하면 아래 네 가지 방법 중 하나를 사용하세요.

| 방법 | 적합한 작업 | 미리보기 | 실행 취소 |
|---|---|---|---|
| File Explorer (F2) | 번호가 붙은 이름을 빠르게 만들기 | 아니요 | 직후 Ctrl+Z |
| PowerRename | 찾아 바꾸기, 날짜, 정규식 | 예 | Explorer에서 Ctrl+Z |
| 명령 프롬프트 | 확장명 변경 | 아니요 | 아니요 |
| PowerShell | 스크립트로 처리할 수 있는 모든 작업 | `-WhatIf` 사용 시 | 아니요 |
| Zush (AI) | 파일마다 설명적인 이름 지정 | 예 | 전체 Rename History |

일괄 이름 변경을 하기 전에 몇 개의 파일을 테스트 폴더에 복사해 두고, 먼저 그곳에서 방법을 시험해 보세요.

## 1. File Explorer: F2로 번호가 붙은 이름 만들기

1. 폴더를 열고 파일을 선택합니다. 전체 선택은 **Ctrl+A**, 개별 선택은 **Ctrl+클릭**을 사용하세요.
2. **F2**를 누릅니다. 또는 마우스 오른쪽 버튼을 클릭하고 **이름 바꾸기**를 선택합니다. Windows 11에서는 텍스트 커서 아이콘입니다.
3. 새 이름을 입력하고(예: `Lisbon trip`) **Enter**를 누릅니다.

그러면 `Lisbon trip (1).jpg`, `Lisbon trip (2).jpg` 같은 이름이 만들어집니다. 번호는 현재 정렬 순서를 따르므로 순서가 중요하다면 먼저 **날짜**순으로 정렬하세요. 바로 **Ctrl+Z**를 누르면 실행 취소됩니다.

**팁:** 파일 이름을 차례로 바꾸려면 첫 번째 파일에서 F2를 누르고 이름을 입력한 다음 **Tab**을 눌러 다음 파일로 이동하세요.

## 2. PowerRename: 미리보기가 있는 찾아 바꾸기

PowerRename은 [PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)에 포함된 Microsoft의 무료 도구입니다. Microsoft Store에서 PowerToys를 설치한 다음 이렇게 하세요.

1. File Explorer에서 파일을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 **PowerRename으로 이름 바꾸기**를 선택합니다. Windows 11에서는 **추가 옵션 표시** 아래에 있을 수 있습니다.
2. **검색 대상**에 찾을 내용을, **바꿀 항목**에 대신 넣을 내용을 입력합니다.
3. 오른쪽의 미리보기를 확인한 다음 **적용**을 클릭합니다.

유용한 활용 예:

| 목표 | 검색 대상 | 바꿀 항목 | 옵션 |
|---|---|---|---|
| 공백을 하이픈으로 | ` ` (공백) | `-` | 모든 항목 일치 |
| 접두사 추가 | `^` | `2026_` | 정규식 사용 |
| 날짜 순서 바꾸기 `29-03-2026` → `2026-03-29` | `(\d{2})-(\d{2})-(\d{4})` | `$3-$2-$1` | 정규식, 모든 항목 일치 |
| 파일에 번호 매기기 | `.*` | `Photo_${padding=3;start=1}` | 정규식, 항목 열거, 파일 이름에만 적용 |
| 사진 촬영 날짜 | `^` | `$DATE_TAKEN_YYYY-$DATE_TAKEN_MM-$DATE_TAKEN_DD-` | 정규식, EXIF/XMP 메타데이터 원본 |

PowerRename은 대소문자(소문자, 대문자, 제목 형식 대문자) 전환과 확장명만 바꾸는 작업도 할 수 있습니다.

## 3. 명령 프롬프트: 확장명을 빠르게 변경하기

오래된 `ren` 명령은 확장명을 일괄 변경하는 한 가지 작업에 유용합니다.

```bat
cd "C:\Users\You\Pictures\Export"
ren *.jpeg *.jpg
```

이 명령은 폴더 안의 모든 `.jpeg` 파일을 `.jpg`(으)로 바꿉니다. 먼저 확인을 묻지 않고 실행 취소도 없으므로 복사본으로 먼저 시험해 보세요.

## 4. PowerShell: 스크립트로 이름 변경하기

PowerShell은 설명할 수 있는 모든 패턴을 처리할 수 있습니다. **터미널**을 열고(시작 버튼을 마우스 오른쪽 버튼으로 클릭) `cd`(으)로 폴더로 이동하세요. 어떤 명령이든 끝에 `-WhatIf`을(를) 추가하면 실제로 이름을 바꾸지 않고 미리 볼 수 있습니다.

모든 JPG에 접두사 추가:

```powershell
(Get-ChildItem *.jpg) | Rename-Item -NewName { "Lisbon_" + $_.Name }
```

공백을 하이픈으로 바꾸기:

```powershell
(Get-ChildItem) | Rename-Item -NewName { $_.Name -replace ' ', '-' }
```

모든 PDF 앞에 수정한 날짜 추가:

```powershell
(Get-ChildItem *.pdf) | Rename-Item -NewName { $_.LastWriteTime.ToString('yyyy-MM-dd') + '_' + $_.Name }
```

날짜순으로 파일에 번호 매기기(`Trip_001.jpg`, `Trip_002.jpg` 형식):

```powershell
$i = 1
Get-ChildItem *.jpg | Sort-Object LastWriteTime | ForEach-Object {
  Rename-Item $_ -NewName ('Trip_{0:D3}{1}' -f $i++, $_.Extension)
}
```

`Get-ChildItem` 주위의 괄호는 중요합니다. 이름 변경을 시작하기 전에 파일 목록을 먼저 수집하므로, 이미 이름이 바뀐 파일이 다시 선택되지 않습니다.

## 5. AI: 파일마다 고유한 이름 지정하기

위의 네 가지 방법은 모두 파일에 이미 있는 이름을 변환합니다. 정보가 이름이 아니라 파일 안에 있기 때문에 `scan_0042.pdf`을(를) `2026-09-12_acme_invoice_1042.pdf`(으)로 바꿀 수는 없습니다.

AI 이름 변경 도구가 바로 그 일을 합니다. [Zush for Windows](/windows)는 각 파일(PDF의 텍스트, 스크린샷에 보이는 내용, 사진 속 장면, Word 또는 Excel 파일의 내용)을 읽고 설명적인 이름을 제안합니다.

1. [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X)에서 Zush를 설치합니다.
2. 폴더 또는 선택한 파일을 끌어다 놓습니다.
3. Screenshots나 Bookkeeper Expenses 같은 Template을 고르거나, `{Created Date}_{Vendor}_{Document Type}` 같은 Naming Blocks로 패턴을 만듭니다.
4. 제안된 이름을 검토합니다. 이름을 두 번 클릭하면 수정할 수 있습니다.
5. **Rename**을 클릭합니다. 나중에 마음이 바뀌면 Rename History에서 해당 배치를 복원하세요.

| 변경 전 | 변경 후 |
|---|---|
| `Screenshot 2026-09-18 141203.png` | `github-pull-request-review-comments.png` |
| `scan_0042.pdf` | `2026-09-12_acme_invoice_1042.pdf` |
| `Document1.docx` | `q3-marketing-plan-draft.docx` |

폴더 모니터링을 켜면 Downloads나 스캐너 폴더에 새 파일이 도착할 때마다 이름이 바뀝니다. 처음 50번의 AI 이름 변경은 무료입니다.

## 자주 발생하는 문제

**"파일 이름이 너무 깁니다."** Windows 경로는 기본적으로 260자로 제한됩니다. 새 이름을 줄이거나 폴더를 드라이브 루트에 더 가깝게 옮기세요.

**PowerShell에서 파일을 건너뛰거나 두 번 이름을 바꾸는 경우.** 위 예시처럼 `Get-ChildItem`을(를) 괄호로 감싸세요.

**PowerRename이 마우스 오른쪽 버튼 메뉴에 없는 경우.** PowerToys 설정을 열어 PowerRename이 켜져 있는지 확인하고, Windows 11에서는 **추가 옵션 표시**를 확인하세요.

**번호 순서가 잘못된 경우.** File Explorer와 PowerRename은 현재 정렬 순서대로 파일에 번호를 매깁니다. 이름을 바꾸기 전에 날짜나 이름순으로 정렬하세요.

**파일이 "사용 중"인 경우.** 파일을 열어 둔 앱(주로 사진 뷰어나 Word)을 닫고 다시 시도하세요.

## 자주 묻는 질문

### Windows 11에서 여러 파일의 이름을 한 번에 바꾸려면 어떻게 하나요?

File Explorer에서 파일을 선택하고 F2를 누른 다음 이름을 입력하고 Enter를 누르세요. Windows가 각 파일에 (1), (2), (3)을 붙입니다. 찾아 바꾸기나 날짜 작업에는 Microsoft PowerToys의 PowerRename을 사용하세요.

### Windows에서 일괄 이름 변경을 취소하려면 어떻게 하나요?

이름을 바꾼 직후 File Explorer에서 Ctrl+Z를 누르세요. F2와 PowerRename에서 모두 작동합니다. 명령 프롬프트와 PowerShell로 바꾼 이름은 실행 취소할 수 없습니다. Zush는 언제든 복원할 수 있는 Rename History를 유지합니다.

### 아무것도 설치하지 않고 파일 이름을 일괄 변경할 수 있나요?

네. File Explorer(F2), 명령 프롬프트(`ren`), PowerShell(`Rename-Item`)은 모두 Windows 11과 10에 기본 내장되어 있습니다.

### Windows에서 파일 내용을 기준으로 이름을 바꾸려면 어떻게 하나요?

기본 제공 도구는 파일 내용을 읽을 수 없습니다. 각 파일을 분석해 담긴 내용에 따라 이름을 제안하는 Zush 같은 AI 이름 변경 도구를 사용하세요.
