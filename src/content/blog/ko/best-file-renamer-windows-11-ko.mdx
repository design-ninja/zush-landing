짧은 답: 모든 파일에 접두사, 날짜, 순번처럼 같은 종류의 변경을 적용한다면 **PowerRename**을 쓰세요. Microsoft가 무료로 제공하며 대부분의 패턴 작업을 처리합니다. 파일 안의 내용에 따라 파일마다 고유한 이름이 필요하다면 [Zush](/windows) 같은 AI 이름 변경 도구를 쓰세요. 파일을 하나씩 읽고, 계정 없이 AI 이름 변경 50회를 무료로 제공합니다.

**확인 방법:** 이 글은 [Zush](/) 제작사가 썼습니다. 경쟁 제품의 가격, 기능, 평점은 2026년 11월 17일에 각 제조사 사이트와 공식 스토어에서 확인했습니다([아래 출처](#sources-and-how-we-checked)). 실험실 테스트가 아니라 문서로 확인된 기능을 비교한 글입니다.

이 구분이 나머지를 모두 결정합니다. 패턴 도구는 빠르고 정확하지만 파일이 이미 가진 이름을 변형할 뿐입니다. `IMG_4382.jpg`는 `Vacation_001.jpg`가 될 수는 있어도 `lisbon-tram-at-night.jpg`가 될 수는 없습니다.

## 1. File Explorer: 파일 다섯 개 정도라면 충분

파일 여러 개를 선택하고 **F2**를 누른 뒤 이름을 입력하고 Enter를 누르세요. Windows가 `Trip (1).jpg`, `Trip (2).jpg` 식으로 이름을 붙입니다. **Ctrl+Z**를 누르면 바로 되돌릴 수 있습니다.

할 수 있는 건 그게 전부입니다. 미리 보기도, 날짜도, 찾아 바꾸기도 없습니다. 결과가 의미 있을 필요 없이 깔끔하기만 하면 될 때 쓰세요.

## 2. PowerRename: 대부분에게 가장 좋은 무료 선택

[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)은 Microsoft PowerToys에 포함돼 있습니다. 파일을 선택하고 오른쪽 클릭한 뒤 **Rename with PowerRename**을 고르면 실시간 미리 보기가 있는 찾아 바꾸기를 쓸 수 있습니다.

보기보다 많은 일을 합니다.

- 캡처 그룹을 포함한 정규식(`29-03-2020` → `2020-03-29`)
- 자릿수 채우기와 시작 값을 지정하는 카운터(`Image_${padding=4}`)
- `$YYYY-$MM-$DD` 같은 파일 생성 날짜 변수
- `$DATE_TAKEN_YYYY`, `$CAMERA_MODEL` 같은 사진 EXIF와 XMP 토큰

Ctrl+Z로 마지막 이름 변경을 되돌립니다. AI가 없고 파일을 열지 않으므로 스캔본이나 스크린샷에 무엇이 있는지 알 수 없습니다. 패턴으로 설명할 수 있는 작업이라면 PowerRename을 고르세요. AI 쪽 이야기는 [PowerRename 대안](/windows) 페이지를 참고하세요.

## 3. Bulk Rename Utility: 최대한의 제어

Bulk Rename Utility는 정규식, JavaScript, 자동 번호, EXIF 날짜, MP3 태그, CSV 기반 이름 변경, 타임스탬프 변경 등 모든 패턴 옵션을 빽빽한 창 하나에 담았습니다. 파일 10만 개 이상도 느려지지 않고 처리합니다. 실행 취소는 변경을 되돌리는 배치 파일을 만드는 방식입니다.

개인 사용은 무료지만 JavaScript 이름 변경에는 유료 라이선스($24.95)가 필요하고, 상업용은 컴퓨터당 $92.95입니다. 4.1.0.1 버전에서 JavaScript와 정규식 규칙을 대신 써 주는 AI 도우미가 추가됐습니다. 패턴을 만드는 데는 도움이 되지만 파일 내용은 읽지 않습니다. 인터페이스에 익숙해지는 데 시간이 걸립니다. 자세한 내용은 [Bulk Rename Utility 대안](/blog/bulk-rename-utility-alternatives) 가이드에 있습니다.

## 4. Advanced Renamer: 사진과 음악 메타데이터에 최적

Advanced Renamer는 여러 방법을 쌓아 이름을 만듭니다. EXIF, ID3, 동영상 속성, GPS 태그를 쓰고, 좌표를 도시 이름으로 바꿀 수도 있습니다. 실시간 미리 보기가 있고 묶음 전체를 되돌릴 수 있으며 macOS에서도 동작합니다. 현재 버전은 4.28이고 스크립트 방식으로 PDF와 TXT 파일에서 텍스트를 뽑을 수 있지만, AI나 OCR이 없습니다. 스캔한 PDF와 사진은 읽지 못하고, 텍스트를 이름으로 바꾸는 스크립트는 직접 써야 합니다.

가벼운 개인 사용은 무료입니다. 자주 쓰는 사용자에게는 $30 개인용 라이선스 구매를 요청하고, 업무용은 $50 상업용 라이선스가 필요합니다. 둘 다 1회 결제입니다. [Advanced Renamer 리뷰](/blog/advanced-renamer-alternatives)를 참고하세요.

## 5. ReNamer: 규칙과 스크립트

ReNamer는 삽입, 삭제, 치환, 대소문자, 정규식, 메타 태그, 그리고 사용자 지정용 Pascal Script까지 순서가 있는 규칙 목록을 적용합니다. 포터블로 쓸 수 있고 25개 이상의 인터페이스 언어를 지원합니다.

ReNamer Lite는 비상업적 사용에 한해 무료이며 규칙 5개, 프리셋 5개로 제한됩니다. Pro는 이 제한을 없애고 상업적 사용을 허용합니다.

## 6. Zush: 파일마다 고유한 이름이 필요할 때

[Zush](/windows)는 방식이 다릅니다. 기존 이름을 고치는 대신 파일 자체를 봅니다. PDF의 텍스트, 스크린샷에 보이는 화면, 사진 속 장면, Word나 Excel 파일의 내용을 보고 그것을 설명하는 이름을 씁니다.

| 변경 전 | 변경 후 |
|---|---|
| `Screenshot 2026-09-18 141203.png` | `github-pull-request-review-comments.png` |
| `scan_0042.pdf` | `2026-09-12_acme_invoice_1042.pdf` |
| `Document1.docx` | `q3-marketing-plan-draft.docx` |
| `IMG_4382.jpg` | `2026-08-30_lisbon_tram_street.jpg` |

이름의 형태는 직접 정합니다. Templates와 145개 이상의 Naming Blocks로 순서(날짜, 거래처, 고객, 제목), 대소문자, 구분자를 고정합니다. 적용 전에 모든 제안을 검토하고, 나중에 Rename History로 묶음 전체를 복원할 수 있습니다. 폴더 감시를 켜면 다운로드 폴더나 스캐너 폴더에 들어오는 새 파일 이름을 자동으로 바꿉니다.

AI는 Zush Cloud AI, 본인의 API 키, 또는 Ollama나 LM Studio로 로컬에서 실행할 수 있습니다. 처음 50회 AI 이름 변경은 계정, 카드, API 키 없이 무료입니다. 이후 Zush는 월 $10 또는 1회 $48입니다. 1회 결제 라이선스에는 무제한 이름 변경이 가능한 관리형 클라우드 AI, 이후 모든 업데이트, Windows와 Mac을 합쳐 최대 3대, 14일 환불이 포함됩니다. AI Rename 중에 중복 파일을 찾아내고(사본에는 크레딧을 쓰지 않음), 동영상은 음성과 자막으로 이름을 지으며, Windows에서는 태그 없는 음악도 식별합니다.

Zush 라이선스 하나로 Mac과 Windows를 합쳐 최대 3대에서 쓸 수 있습니다.

Naming Blocks, Custom AI Blocks, 폴더 규칙을 담은 [Templates를 내보낸](/docs/template-import-export) 뒤 다른 컴퓨터에서 가져올 수 있습니다. 그 컴퓨터에서는 로컬 대상 폴더, 폴더 권한, AI 연결을 다시 선택하세요. 옮겨지는 것은 작업 설정이지 파일이 아닙니다.

### 이름을 바꾼 파일을 폴더로 분류하기

Windows에서 Zush는 **AI로 파일을 폴더에 분류**할 수도 있습니다. **Auto** 그룹화를 고르거나 "청구서는 회사별로, 영수증은 월별로 묶기" 같은 **Folder rules**를 쓰세요. 제안된 폴더 그룹을 파일 이름과 함께 검토합니다. 묶음 전체에 같은 텍스트 변경만 필요하다면 패턴 이름 변경 도구로도 충분합니다.

**Destination folder**를 고르거나 원본 폴더를 루트로 유지하세요. **Reuse existing folders**를 켜면 이미 있는 알맞은 폴더를 우선 쓰고, 맞는 폴더가 없으면 Zush가 새로 만들 수 있습니다. 수동 묶음에서는 적용 전에 제안된 이름과 폴더를 모두 검토하세요. 제자리에서 이름만 바꾸려면 분류를 끄고 원래 위치를 유지하면 됩니다.

분류 설정을 **Template**에 저장하고 **Monitor**에 연결하면 감시 폴더 바로 안에 들어오는 새 파일에 적용됩니다. Monitor의 Template을 바꿔도 이미 처리된 파일이 자동으로 다시 정리되지는 않습니다. 먼저 수동 묶음으로 Template을 시험하세요. 설정과 감시 범위는 [폴더 분류 가이드](/docs/folder-sorting)에 있습니다.

Zush는 연도 아래 월로 묶는 식의 중첩 폴더 규칙도 지원합니다. 이미 이름을 바꾼 파일은 이름을 다시 바꾸거나 이름 변경 크레딧을 더 쓰지 않고 분류할 수 있습니다. 적용 전에 대상 위치를 검토하세요. 이 별도 작업은 기존 묶음을 처리하며, Monitor의 Template을 바꿔도 소급해 다시 정리하지는 않습니다. [AI 폴더 분류](/docs/folder-sorting)는 Mac과 Windows에서 쓸 수 있습니다.

## 어떤 이름 변경 도구를 써야 할까요?

- 모든 파일에 같은 변경(접두사, 날짜, 번호): **PowerRename**.
- 아주 큰 폴더에 복잡한 패턴: **Bulk Rename Utility**.
- 사진, 음악, GPS 메타데이터로 이름 만들기: **Advanced Renamer**.
- 제대로 된 이름이 필요한 스크린샷, 스캔본, 다운로드 파일, 사진: **Zush**.

두 종류를 함께 쓰는 사람도 많습니다. 간단한 기계적 수정에는 PowerRename을, 지금은 무엇인지 보려고 파일을 하나하나 열어 보는 폴더에는 Zush를 씁니다.

## 자주 묻는 질문

### Windows 11에서 Zush로 동영상과 음악 파일 이름을 바꿀 수 있나요?

네. Windows용 Zush는 MKV를 포함한 동영상을 음성, 내장 자막, 메타데이터로 이름 짓고, 태그가 없는 음악도 식별할 수 있습니다. 음악 식별은 현재 Windows 전용 기능입니다. 오프라인으로 작업하려면 AI 설정에서 선택 사항인 기기 내 음성 인식을 내려받아 Ollama나 LM Studio와 함께 쓰면 됩니다. PowerRename 같은 패턴 도구는 규칙에 따라 이름만 바꾸므로 녹음에 무엇이 담겼는지 알 수 없습니다.

### Windows 11에서 가장 좋은 무료 파일 이름 변경 도구는?

Microsoft PowerToys에 포함된 PowerRename입니다. 무료이고, 모든 변경을 미리 보여 주며, 정규식, 카운터, 날짜 변수, EXIF/XMP 토큰을 지원하고, Ctrl+Z로 되돌립니다. 더 무거운 개인 작업에는 Bulk Rename Utility도 무료지만 JavaScript 이름 변경에는 유료 라이선스가 필요합니다. Advanced Renamer는 가벼운 개인 사용 무료입니다. 이 도구들은 모두 파일 내용을 읽지 않습니다. 내용이 필요하다면 Zush가 계정 없이 AI 이름 변경 50회를 무료로 제공합니다.

### Windows 11에 일괄 이름 변경 기능이 내장돼 있나요?

네, 기본적인 기능만 있습니다. File Explorer에서 파일을 선택하고 F2를 누르면 하나의 이름에 괄호 번호를 붙여 줍니다. 찾아 바꾸기나 날짜가 필요하면 PowerToys를 설치하고 PowerRename을 쓰세요.

### 파일 이름 변경 도구가 파일 안의 내용을 읽을 수 있나요?

패턴 도구는 대부분 못 합니다. 기존 이름과 EXIF, ID3 같은 메타데이터 필드를 읽을 뿐입니다. Advanced Renamer는 스크립트로 PDF와 TXT 파일에서 텍스트를 뽑을 수 있지만 AI나 OCR이 없어 스캔본과 사진은 읽지 못합니다. Zush 같은 AI 이름 변경 도구는 텍스트, 이미지, 음성, 동영상 프레임 등 내용 자체를 읽고, 적용 전에 검토할 수 있는 새 설명형 이름을 제안합니다.

### 가장 안전한 파일 이름 변경 도구는?

미리 보기와 묶음 단위 실행 취소가 있는 도구라면 어느 것이든 안전합니다. PowerRename, Advanced Renamer, Zush 모두 적용 전에 결과를 보여 줍니다. Zush는 영구 Rename History도 남기므로 직후뿐 아니라 며칠 뒤에도 묶음을 되돌릴 수 있습니다.

### PowerRename이 무료인데 Zush에 돈을 낼 가치가 있나요?

파일 내용에 따른 이름이 필요할 때만 그렇습니다. 일정한 패턴 변경에는 PowerRename이 맞는 도구이고 비용도 들지 않습니다. 이름을 붙이기 전에 무엇인지 보려고 스크린샷, 스캔본, 다운로드 파일을 열어 본다면 Zush가 그 확인을 대신합니다. $48 1회 결제 라이선스에는 무제한 이름 변경이 가능한 관리형 클라우드 AI, BYOK와 로컬 모델, 이후 모든 업데이트, 3대, 14일 환불이 포함됩니다.

### Windows에서 Zush는 내 파일을 어디서 처리하나요?

모드에 따라 다릅니다. Zush Cloud AI와 BYOK는 이름을 만들기 위해 파일 내용을 AI 서비스로 보냅니다. BYOK는 본인의 제공업체 계정을 씁니다. Ollama나 LM Studio를 쓰면 분석이 내 PC에서 실행되며, 동영상용 기기 내 음성 인식도 쓸 수 있습니다. PowerRename, Bulk Rename Utility, Advanced Renamer는 내용을 분석하지 않으므로 파일을 어디로도 보내지 않습니다. [오프라인 AI 파일 이름 변경](/offline-ai-file-renamer)을 참고하세요.
