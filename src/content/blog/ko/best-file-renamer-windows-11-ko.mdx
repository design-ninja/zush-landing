간단히 답하면, 모든 파일에 접두사, 날짜, 순번처럼 같은 종류의 변경을 적용한다면 **PowerRename**을 쓰세요. Microsoft에서 무료로 제공하며 대부분의 패턴 작업을 처리합니다. 파일 안의 내용에 따라 파일마다 고유한 이름이 필요하다면 [Zush](/windows) 같은 AI 이름 변경 도구를 쓰세요.

이 구분이 나머지 모든 선택을 좌우합니다. 패턴 도구는 빠르고 정확하지만, 파일이 이미 가진 이름을 변형할 뿐입니다. `IMG_4382.jpg`를 `Vacation_001.jpg`로 바꿀 수는 있어도 `lisbon-tram-at-night.jpg`로 바꿀 수는 없습니다.

**최종 확인: 2026년 9월 22일.** Mac·Windows용 AI 파일 이름 변경 도구 [Zush](/ko) 제작자가 작성했습니다. 다른 도구의 세부 정보는 각 도구의 공식 페이지를 참고했습니다.

**Zush 기능 확인일: 2026년 10월 26일.** 경쟁 제품 정보에는 본문에 명시된 기존 확인 날짜가 적용됩니다.

## 1. File Explorer: 파일 다섯 개 정도라면 충분합니다

파일 여러 개를 선택하고 **F2**를 누른 뒤 이름을 입력하고 Enter를 누르세요. Windows가 `Trip (1).jpg`, `Trip (2).jpg` 같은 식으로 이름을 붙입니다. **Ctrl+Z**를 누르면 바로 되돌릴 수 있습니다.

할 수 있는 건 이게 전부입니다. 미리보기도, 날짜도, 찾아 바꾸기도 없습니다. 결과가 의미 있을 필요 없이 단정하기만 하면 될 때 쓰세요.

## 2. PowerRename: 대부분의 사용자에게 가장 좋은 무료 선택

[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)은 Microsoft PowerToys에 포함되어 있습니다. 파일을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 **Rename with PowerRename**을 선택하면 실시간 미리보기와 함께 검색 및 바꾸기를 사용할 수 있습니다.

보기보다 훨씬 많은 일을 처리합니다.

- 캡처 그룹을 포함한 정규식 (`29-03-2020` → `2020-03-29`)
- 자릿수 채우기와 시작값을 지원하는 카운터 (`Image_${padding=4}`)
- `$YYYY-$MM-$DD` 같은 파일 생성 날짜 변수
- `$DATE_TAKEN_YYYY`, `$CAMERA_MODEL`, GPS 좌표 같은 사진 EXIF 필드

패턴으로 설명할 수 있는 작업이라면 PowerRename을 고르세요. AI 쪽이 궁금하다면 [PowerRename 대안](/windows) 페이지를 참고하세요.

## 3. Bulk Rename Utility: 최대한의 제어

Bulk Rename Utility는 정규식, JavaScript, 자동 번호 매기기, EXIF 날짜, MP3 태그, CSV 기반 이름 변경, 타임스탬프 변경까지 모든 패턴 옵션을 빽빽한 하나의 창에 담았습니다. 10만 개가 넘는 파일도 느려지지 않고 처리합니다. 실행 취소는 변경을 되돌리는 배치 파일을 생성하는 방식으로 작동합니다.

개인 사용은 무료이며, 업무용으로 쓰려면 상업용 라이선스가 필요합니다. 인터페이스에 익숙해지는 데 시간이 좀 걸립니다. 자세한 내용은 [Bulk Rename Utility 대안](/blog/bulk-rename-utility-alternatives) 가이드를 참고하세요.

## 4. Advanced Renamer: 사진과 음악 메타데이터에 가장 적합

Advanced Renamer는 EXIF, ID3, 동영상 속성, GPS의 태그(좌표를 도시 이름으로 바꿀 수도 있습니다)를 겹겹이 쌓은 방식으로 이름을 만듭니다. 실시간 미리보기를 보여 주고 배치 전체를 실행 취소할 수 있습니다. macOS에서도 실행됩니다.

가벼운 개인 사용은 무료입니다. 자주 쓰는 사용자에게는 $25 개인 라이선스 구매를 요청하며, 업무용은 $45 상업용 라이선스가 필요합니다. 둘 다 일시불입니다. [Advanced Renamer 리뷰](/blog/advanced-renamer-alternatives)를 참고하세요.

## 5. ReNamer: 규칙과 스크립트

ReNamer는 삽입, 삭제, 바꾸기, 대소문자, 정규식, 메타 태그로 이루어진 순서 있는 규칙 목록을 적용하며, 맞춤 작업에는 Pascal Script를 사용할 수 있습니다. 포터블 버전이 있고 25개 이상의 인터페이스 언어를 지원합니다.

ReNamer Lite는 비상업적 용도에 한해 무료이며 규칙 5개, 프리셋 5개로 제한됩니다. Pro는 이 제한을 없애고 상업적 사용을 허용합니다.

## 6. Zush: 파일마다 고유한 이름이 필요할 때

[Zush](/windows)는 방식이 다릅니다. 예전 이름을 고치는 대신 파일 자체를 봅니다. PDF 속 텍스트, 스크린샷에 보이는 것, 사진의 장면, Word나 Excel 파일의 내용을 읽은 다음 그것을 설명하는 이름을 만듭니다.

| 변경 전 | 변경 후 |
|---|---|
| `Screenshot 2026-09-18 141203.png` | `github-pull-request-review-comments.png` |
| `scan_0042.pdf` | `2026-09-12_acme_invoice_1042.pdf` |
| `Document1.docx` | `q3-marketing-plan-draft.docx` |
| `IMG_4382.jpg` | `2026-08-30_lisbon_tram_street.jpg` |

이름의 형식은 사용자가 정합니다. Template과 145개 이상의 Naming Blocks로 순서(날짜, 업체, 고객, 제목), 대소문자, 구분 기호를 고정합니다. 적용하기 전에 모든 제안을 검토하고, 나중에 Rename History로 배치 전체를 복원할 수 있습니다. 폴더 모니터링은 Downloads나 스캐너 폴더에 새로 생기는 파일의 이름을 자동으로 바꿉니다.

AI는 Zush Cloud AI, 직접 입력한 API 키, 또는 Ollama나 LM Studio를 통한 로컬 환경에서 실행할 수 있습니다. 처음 50회 이름 변경은 무료입니다.

Zush 라이선스 하나로 Mac과 Windows를 합해 최대 3대에서 사용할 수 있습니다.

Naming Blocks, Custom AI Blocks, 폴더 규칙을 포함한 [Templates를 내보내고](/docs/template-import-export) 다른 컴퓨터에서 가져올 수 있습니다. 대상 폴더, 접근 권한, AI 연결은 새 컴퓨터에서 다시 설정해야 합니다. 파일 자체가 아닌 설정을 옮기는 기능입니다.

### 이름을 바꾼 파일을 폴더로 정리하기

Windows에서 Zush는 **AI로 파일을 폴더로 정리**할 수도 있습니다. **Auto** 그룹화를 선택하거나 “송장은 회사별로, 영수증은 월별로 묶어 줘.” 같은 **Folder rules**를 작성하세요. 제안된 폴더 그룹을 파일 이름과 함께 검토하세요. 한 배치 전체에 같은 텍스트 변경만 하면 된다면 패턴 이름 변경 도구로도 충분합니다.

**Destination folder**를 선택하거나 원본 폴더를 루트로 유지하세요. **Reuse existing folders**를 켜면 이미 있는 적합한 폴더를 우선 사용하며, 맞는 폴더가 없으면 Zush가 새 폴더를 만들 수 있습니다. 수동 배치에서는 적용하기 전에 제안된 이름과 폴더를 모두 검토하세요. 제자리에서 이름만 바꾸려면 정리 기능을 끄고 기존 대상 위치를 그대로 두세요.

정리 설정을 **Template**에 저장하고 **Monitor**에 지정하면 감시 중인 폴더 안에 직접 생기는 새 파일에 적용됩니다. 이미 처리된 파일은 다시 정리되지 않습니다. 먼저 수동 배치에서 Template을 테스트해 보세요. 설정 방법과 모니터링 범위는 [폴더 정리 가이드](/docs/folder-sorting)를 참고하세요.

Zush는 연도 아래 월을 두는 식의 중첩 폴더 규칙도 지원합니다. 이미 이름을 바꾼 파일은 이름을 다시 변경하거나 추가 이름 변경 크레딧을 쓰지 않고 분류할 수 있습니다. 적용 전에 대상 경로를 확인하세요. 이 작업은 Monitor와 별개이며, Template을 바꿔도 이전 파일을 자동으로 다시 정리하지는 않습니다. [AI 폴더 정리](/docs/folder-sorting)는 Mac과 Windows에서 사용할 수 있습니다.

## 어떤 이름 변경 도구를 써야 할까요?

- 모든 파일에 같은 변경(접두사, 날짜, 번호): **PowerRename**.
- 방대한 폴더에 복잡한 패턴: **Bulk Rename Utility**.
- 사진, 음악, GPS 메타데이터에서 가져온 이름: **Advanced Renamer**.
- 제대로 된 이름이 필요한 스크린샷, 스캔 파일, 다운로드 파일, 사진: **Zush**.

두 종류를 함께 쓰는 사람도 많습니다. 빠른 기계적 수정은 PowerRename으로, 지금은 파일을 하나하나 열어 봐야 무엇인지 알 수 있는 폴더는 Zush로 처리합니다.

## 자주 묻는 질문

### Zush는 파일 이름을 바꾸는 것뿐 아니라 폴더로 정리도 할 수 있나요?

네. 선택 사항인 AI 폴더 정리는 Mac과 Windows에서 사용할 수 있습니다. Auto를 선택하거나 Folder rules를 작성하고 대상 위치를 고른 뒤, 수동 배치에서 이름과 그룹을 모두 검토하세요. 정리가 켜진 Template은 모니터링 중인 폴더 안에 직접 생기는 새 파일도 처리할 수 있으며, 이미 처리된 파일은 다시 정리하지 않습니다. 이름만 바꾸려면 정리 기능을 끄고 기존 대상 위치를 유지하세요.

### Windows 11에서 가장 좋은 무료 파일 이름 변경 도구는 무엇인가요?

Microsoft PowerToys에 포함된 PowerRename입니다. 무료이고 모든 변경 사항을 미리 보여 주며, 정규식과 날짜 변수를 지원하고 Ctrl+Z로 되돌릴 수 있습니다. 더 무거운 개인 작업에는 무료 대안으로 Bulk Rename Utility가 있습니다.

### Windows 11에는 일괄 이름 변경 기능이 기본 내장되어 있나요?

네, 하지만 기본적인 수준입니다. File Explorer에서 파일을 선택하고 F2를 누르면 하나의 이름에 괄호 안 번호를 붙여 줍니다. 찾아 바꾸기나 날짜가 필요하면 PowerToys를 설치하고 PowerRename을 사용하세요.

### 파일 이름 변경 도구가 내 파일 안의 내용을 읽을 수 있나요?

패턴 도구는 읽지 못합니다. 기존 이름과 EXIF나 ID3 같은 메타데이터 필드만 읽습니다. Zush 같은 AI 이름 변경 도구는 내용 자체(텍스트, 이미지, 동영상 프레임)를 읽고 새로운 설명형 이름을 만듭니다.

### 가장 안전한 파일 이름 변경 도구는 무엇인가요?

미리보기와 배치 실행 취소를 갖춘 도구라면 모두 안전합니다. PowerRename, Advanced Renamer, Zush는 모두 적용하기 전에 결과를 보여 줍니다. Zush는 영구적인 Rename History도 유지하므로 작업 직후뿐 아니라 며칠 뒤에도 배치를 되돌릴 수 있습니다.
