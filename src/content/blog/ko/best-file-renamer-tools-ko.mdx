## 1. 기본 기능과 무료 규칙 도구

### Finder
파일을 선택하고 우클릭한 뒤 Rename에서 텍스트를 바꾸거나 추가하고, 이름과 번호를 조합합니다. 설치는 필요 없지만 정규식, 내용 분석, 메타데이터 규칙, 감시, 지속적인 기록은 없습니다. [Mac 일괄 변경 안내](/blog/batch-rename-files-on-mac-complete-guide)는 Automator와 Terminal도 다룹니다.

### PowerRename
Microsoft PowerToys에 포함됩니다. File Explorer에서 검색과 치환, 정규식, 미리 보기를 사용합니다. 공통 규칙에는 적합하지만 내용을 읽거나 혼합 폴더를 감시하지 않습니다. [PowerRename 대안](/powerrename-alternative)을 참고하세요.

### Bulk Rename Utility
BRU는 접두사, 번호, 대소문자, 정규식을 조합합니다. 복잡한 화면은 Windows의 기계적인 작업을 위한 것입니다. Mac 버전과 내용 분석은 없습니다. [BRU 비교](/blog/bulk-rename-utility-alternatives)에서 범위를 설명합니다.

## 2. 메타데이터로 이름 만들기

Advanced Renamer와 A Better Finder Rename은 EXIF 날짜, GPS, ID3 태그, 파일 날짜를 사용합니다. 원하는 전체 이름이 이미 이 필드에 있을 때 선택하세요. EXIF는 사진을 찍은 시간을 알려줄 뿐 공원에 있는 개라는 내용은 알려주지 않습니다. PDF 메타데이터도 공급업체와 청구 금액을 반드시 담지는 않습니다. [Advanced Renamer 비교](/blog/advanced-renamer-alternatives)에서 한계를 확인할 수 있습니다.

## 3. 파일마다 다른 이름이 필요하면 AI

`Screenshot 2026-03-23.png`, `Scan0001.pdf`, `IMG_4382.HEIC`, `download (7).pdf`는 주제를 설명하지 않습니다. Zush는 스크린샷, RAW·HEIC 사진, PDF, [AI 시각 분석 스캔](/rename-scanned-documents), Office, iWork, 디자인, 오디오, 동영상을 읽습니다. [Naming Blocks](/docs/naming-blocks)로 공통 형식을 정하고, 적용 전에 모든 제안을 확인하며 기록에서 취소할 수 있습니다. [폴더 감시](/docs/folder-monitoring)는 새 다운로드와 스캔을 처리합니다.

무료 50회는 네 가지 모드가 공유합니다. PRO는 월 $10 또는 일회성 $48이며 이름 변경 횟수 제한이 없습니다. 온라인 Zush Cloud AI와 BYOK 외에 Mac·Windows에서 LM Studio와 Ollama를 쓸 수 있습니다. [AI 종합 비교](/blog/best-ai-file-renamer-tools-2026)는 FilesDesk, RenameClick, Renamer.ai, NameQuick도 다룹니다.

### 필요하면 폴더에도 분류

선택적 AI 분류는 베타입니다. Auto를 쓰거나 **Folder rules**에 “스크린샷은 프로젝트별, 청구서는 회사별”이라고 적습니다. 폴더 규칙은 Naming Blocks와 별개입니다. **Destination folder**를 선택하거나 원본 폴더를 루트로 유지합니다. **Reuse existing folders**는 적절한 기존 폴더를 사용하고 없으면 만듭니다. 적용 전에 이름과 위치를 확인하세요.

설정을 **Template**에 저장해 먼저 수동으로 시험하고 **Monitor**에 연결합니다. 감시 폴더 바로 안에 들어오는 새 파일만 처리하며 처리된 파일을 다시 정리하지 않습니다. 제자리에서 이름만 바꾸려면 분류를 끄고 원래 목적지를 유지합니다. [분류 문서](/docs/folder-sorting).

## 자주 묻는 질문

### 폴더로 이동할 수 있나요?
네. 선택적 베타 기능으로 이름과 폴더를 확인한 후 이동합니다. 시험한 Template은 Monitor로 새 파일을 처리할 수 있습니다.

### 무료라면 무엇을 쓰나요?
공통 규칙에는 Mac의 Finder, Windows의 PowerRename. Zush는 AI 이름 변경 50회를 제공합니다. [무료 AI 안내](/blog/rename-files-with-ai-free)는 Cloud AI, BYOK, LM Studio, Ollama, 로컬 명령줄 도구를 다룹니다.

### Mac과 Windows 추천은?
혼합 파일에는 [Mac용 Zush](/mac)와 [Windows용 Zush](/windows). Finder, A Better Finder Rename, PowerRename, BRU는 좁은 규칙 작업용입니다.

### 내용으로 이름을 만들 수 있나요?
AI는 실제 텍스트나 이미지를 읽으며 텍스트 층이 없는 스캔도 처리합니다. 규칙 도구는 기존 이름과 태그를 재배치합니다.

### 유료 AI가 필요한가요?
기계적인 작업은 무료 규칙으로 충분합니다. 내용을 알아보려고 매번 파일을 연다면 AI가 그 작업을 줄일 수 있습니다. Zush PRO에는 일회성 $48 라이선스가 있습니다.
