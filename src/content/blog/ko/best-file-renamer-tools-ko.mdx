## 1유형: 기본 내장 및 무료 규칙 도구

### Finder 이름 변경(Mac)

파일을 선택하고 오른쪽 클릭한 뒤 **이름 변경**을 고르면 텍스트 대치, 텍스트 추가, 이름과 번호 지정을 할 수 있습니다. 따로 설치할 것이 없습니다. 정규식, 메타데이터, 내용 읽기는 지원하지 않습니다. Finder와 함께 Automator, 터미널을 다루는 [Mac 일괄 이름 변경 가이드](/blog/batch-rename-files-on-mac-complete-guide)도 참고하세요.

**이럴 때 고르세요:** 규칙 하나로 모든 파일을 고칠 수 있을 때. **약점:** 정규식도 메타데이터도 전혀 없습니다.

### PowerRename(Windows)

Microsoft PowerToys에 포함된 도구입니다. 선택한 파일을 오른쪽 클릭하면 정규식 기반 찾아 바꾸기, 카운터, 생성 날짜 변수, 사진 EXIF/XMP 토큰을 실시간 미리 보기와 함께 쓸 수 있습니다. Ctrl+Z로 이름 변경을 되돌립니다. AI는 없고 파일 내용도 읽지 않습니다. 두 도구를 비교한 [Windows용 Zush](/windows) 페이지에서 더 자세히 볼 수 있습니다.

**이럴 때 고르세요:** 변경 내용을 패턴으로 설명할 수 있을 때. **약점:** `scan_004.pdf`를 스캔 내용에 따라 이름 지을 수는 없습니다.

### Bulk Rename Utility(Windows)

BRU는 접두사, 번호, 대소문자, 정규식, EXIF와 ID3 태그 규칙을 빽빽한 창 하나에 겹겹이 쌓아 씁니다. 개인 사용은 무료입니다. JavaScript 이름 변경에는 유료 라이선스($24.95)가 필요하고, 상업용은 컴퓨터당 $92.95입니다. 4.1.0.1 버전에서 JavaScript와 정규식을 대신 써 주는 AI 도우미가 추가됐지만, 여전히 파일 내용은 읽지 않습니다. Mac 버전은 없습니다. [Bulk Rename Utility 대안](/blog/bulk-rename-utility-alternatives)도 참고하세요.

**이럴 때 고르세요:** 아주 큰 폴더에 복잡한 기계적 규칙을 적용할 때. **약점:** 화면이 복잡하고, 업무용은 컴퓨터 대수만큼 비용이 듭니다.

## 2유형: 메타데이터 기반 도구

**Advanced Renamer**와 **A Better Finder Rename**은 EXIF 날짜, GPS 좌표, ID3 태그, 파일 날짜로 이름을 만듭니다. Advanced Renamer(4.28 버전)는 스크립트 방식으로 PDF와 TXT 파일에서 텍스트를 뽑아낼 수도 있지만, AI나 OCR이 없어서 스캔한 PDF와 이미지는 읽지 못하고, 추출한 텍스트를 이름으로 바꾸는 로직은 직접 작성해야 합니다. 가벼운 개인 사용은 무료이고, 자주 쓰는 사용자에게는 $30 개인용 라이선스 구매를 요청하며, 업무용은 $50 상업용 라이선스가 필요합니다. A Better Finder Rename은 Mac용이며 $29.95입니다.

한계는 메타데이터가 *언제*, *무엇으로* 찍었는지는 알려 주지만 *무엇이* 담겼는지는 알려 주지 않는다는 점입니다. 사진의 EXIF는 촬영 시각을 알려 줄 뿐, 공원에 있는 골든 리트리버가 찍혔다는 사실은 모릅니다. 이런 규칙이 어디서 막히는지는 [Advanced Renamer 대안](/blog/advanced-renamer-alternatives) 리뷰에서 정리했습니다.

**이럴 때 고르세요:** 원하는 이름 전체가 이미 EXIF, GPS, 태그 안에 있을 때. **약점:** 이미지나 스캔 문서의 내용은 이해하지 못합니다.

## 3유형: 파일마다 고유한 이름이 필요할 때 쓰는 AI 도구

`Screenshot 2026-03-23.png`, `Scan0001.pdf`, `IMG_4382.HEIC`, `download (7).pdf`처럼 위의 두 유형으로는 해결되지 않는 폴더가 있습니다. 파일마다 맞는 이름이 다르고, 그 정보는 픽셀, 텍스트, 음성 안에 들어 있습니다.

[Zush](/)는 스크린샷, 사진(RAW, HEIC 포함), PDF, [스캔 문서](/rename-scanned-documents), Office와 iWork 파일, 디자인 파일, 오디오, 동영상의 내용을 읽습니다. 동영상은 음성, 내장 자막, 메타데이터로 이름을 짓고 MKV도 지원합니다. 준비된 Template을 고르거나 145개 이상의 [Naming Blocks](/docs/naming-blocks)로 규칙을 만들고, 제안된 이름을 모두 확인할 수 있으며, Rename을 누르기 전에는 아무것도 바뀌지 않습니다. Rename History는 재시작 후에도 남고 묶음 전체를 되돌립니다. [폴더 감시](/docs/folder-monitoring)를 켜면 다운로드 폴더나 스캐너 폴더에 들어오는 파일에 바로 이름을 붙입니다.

비용을 내면 얻는 것:

- **바로 쓸 수 있음:** 계정, 카드, API 키, 모델 다운로드 없이 Zush Cloud AI로 AI 이름 변경 50회 무료.
- **1회 결제에 클라우드 포함:** $48 평생 라이선스에 Zush Cloud AI 무제한 이름 변경, BYOK, Ollama, LM Studio, 이후 모든 업데이트, Mac과 Windows를 합쳐 최대 3대, 14일 환불이 포함됩니다. 월 $10 요금제도 있습니다.
- **중복 파일 처리:** AI Rename이 중복 파일을 찾아내고, 사본에는 크레딧을 쓰지 않으며, Undo로 복원됩니다. [중복 파일 제거](/remove-duplicate-files)를 참고하세요.
- **클라우드 모드에서 가벼움:** 약 200 MB, RAM 4 GB.

### 필요하면 폴더 분류까지

Zush는 **Auto** 그룹화나 **Folder rules**로 파일을 폴더에 분류할 수도 있습니다. 중첩 폴더도 지원하고, 이름을 바꾸지 않고 분류만 할 수도 있습니다. **Destination folder**로 분류할 위치를 정하고, **Reuse existing folders**를 켜면 비슷한 폴더를 새로 만들지 않고 기존 폴더를 씁니다. 이름 규칙은 **Naming Blocks**로 만들고, 같은 설정을 **Monitor**에 연결하면 새로 들어오는 파일도 자동으로 처리됩니다. 자세한 내용은 [폴더 분류 가이드](/docs/folder-sorting), [Mac에서 AI로 파일을 폴더에 분류하는 방법](/blog/sort-files-into-folders-with-ai-mac), [AI 폴더 분류 지시 예시](/blog/ai-folder-sorting-prompts)를 참고하세요.

장단점이 다른 AI 이름 변경 도구도 있습니다. [크로스플랫폼 AI 이름 변경 도구 비교](/blog/best-ai-file-renamer-tools-2026)에서 10개를 다뤘고, [Mac](/blog/best-ai-file-renamer-tools-mac-compared)과 [Windows](/blog/best-ai-file-renamer-tools-windows-compared) 순위도 따로 있습니다.

## 자주 묻는 질문

### 무료 파일 이름 변경 도구 중 가장 좋은 것은?

패턴 작업이라면 Mac의 Finder와 Windows의 PowerRename이 무료이고 모든 변경을 미리 보여 줍니다. Bulk Rename Utility는 개인 사용 무료, Advanced Renamer는 가벼운 개인 사용 무료입니다. 파일 내용에 따른 이름이 필요하면 Zush가 계정, 카드, API 키 없이 AI 이름 변경 50회를 무료로 제공하며, 유료 버전과 같은 미리 보기와 Rename History를 씁니다. [무료 AI 이름 변경 가이드](/blog/rename-files-with-ai-free)를 참고하세요.

### 파일 안의 내용으로 이름을 지을 수 있나요?

제대로 할 수 있는 것은 AI 이름 변경 도구뿐입니다. 규칙 도구는 기존 이름을 재배열하고, 메타데이터 도구는 EXIF나 ID3 태그를 읽습니다. Advanced Renamer는 스크립트로 PDF와 TXT 파일에서 텍스트를 뽑을 수 있지만 AI나 OCR이 없어 스캔본과 이미지는 읽지 못합니다. Zush 같은 AI 도구는 텍스트 레이어가 없는 스캔본을 포함해 텍스트, 이미지, 오디오, 동영상을 읽고, 먼저 검토할 수 있는 이름을 제안합니다.

### AI 파일 이름 변경 도구에 돈을 낼 가치가 있나요?

이름 변경이 기계적인 작업이라면 아닙니다. 무료 규칙 도구로 충분합니다. 무엇인지 확인하려고 파일을 자주 열어 본다면 가치가 있습니다. Zush의 $48 1회 결제 라이선스에는 무제한 이름 변경이 가능한 관리형 클라우드 AI, BYOK와 로컬 모델, 이후 모든 업데이트, Mac과 Windows를 합쳐 최대 3대, 14일 환불이 포함됩니다. 먼저 사본으로 무료 50회를 써 보세요.

### Zush는 내 파일을 어디서 처리하나요?

선택한 모드에 따라 다릅니다. Zush Cloud AI와 BYOK는 이름을 만들기 위해 파일 내용을 AI 서비스로 보냅니다. BYOK는 본인의 제공업체 계정을 씁니다. Ollama나 LM Studio를 쓰면 분석이 내 컴퓨터에서 실행되고 파일도 그 안에 머뭅니다. Finder, PowerRename, Bulk Rename Utility 같은 규칙 도구는 내용을 아예 읽지 않으므로 아무것도 컴퓨터 밖으로 나가지 않습니다. [오프라인 AI 파일 이름 변경](/offline-ai-file-renamer) 설정을 참고하세요.

### Mac에서 가장 좋은 파일 이름 변경 도구는?

파일마다 설명형 이름이 필요한 혼합 폴더라면 [Mac용 Zush](/mac)입니다. 스크린샷, PDF, RAW 사진, 디자인 파일, 오디오, 동영상을 읽고 영구 Rename History를 남깁니다. 공통 규칙 하나라면 기본 내장된 Finder가 있고, EXIF와 메타데이터 패턴에는 $29.95인 A Better Finder Rename이 있습니다. 전체 후보는 [Mac AI 이름 변경 도구 비교](/blog/best-ai-file-renamer-tools-mac-compared)에 있습니다.

### Windows 11에서 가장 좋은 파일 이름 변경 도구는?

패턴 작업이라면 PowerRename이 무료이고, 변경을 미리 보여 주며, Ctrl+Z로 되돌립니다. Bulk Rename Utility와 Advanced Renamer는 더 복잡한 규칙과 메타데이터를 다룹니다. 파일마다 내용에 맞는 이름이 필요하다면 [Windows용 Zush](/windows)를 Microsoft Store에서 설치하면 미리 보기, 폴더 감시, 영구 Rename History를 쓸 수 있습니다. [Windows AI 이름 변경 도구 비교](/blog/best-ai-file-renamer-tools-windows-compared)를 참고하세요.
