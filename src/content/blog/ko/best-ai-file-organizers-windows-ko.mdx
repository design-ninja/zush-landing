Zush는 Windows 10과 11에서 내용 기반 이름 변경과 선택적인 AI 폴더 분류를 제공합니다. Auto가 그룹을 제안하거나 Folder rules로 원하는 구조를 설명할 수 있습니다. Sortio와 Wisfile도 AI 작업 흐름을 제공하며 File Juggler와 DropIt은 고정 규칙을 사용합니다. 미리보기, 복구, 형식 지원, 데이터 처리 방식을 비교하세요.

## 1. Zush

내용 기반 이름과 선택적 AI 폴더 그룹 (베타).

Zush 폴더 분류는 Mac과 Windows에서 베타로 제공됩니다. 지원 파일의 내용을 분석해 이름과 그룹을 제안합니다. Auto를 쓰려면 Folder rules를 비우고, 직접 정하려면 자연어로 지시하세요. 파일 이름 형식은 Naming Blocks에서 별도로 설정합니다.

내보낸 이미지나 복사 폴더로 시험하세요. Photos 보관함 패키지 내부를 재배치하지 마세요. 카탈로그에 등록된 원본은 해당 프로그램의 이름 변경 또는 다시 연결 절차를 따르세요. 이름 변경과 이동 모두 파일 경로를 바꿉니다.

## 2. Sortio

Sortio는 지시에 따라 이름 변경, 폴더 생성, 이동 계획을 보여 줍니다. Smart Folders는 새 파일을 처리하며 Linux도 지원합니다. AI 사용량과 계획을 확인하세요. 이동하면 파일 경로가 바뀝니다.

[Sortio](https://www.getsortio.com/).

## 3. Wisfile

Wisfile은 PDF, 논문, 교육 자료 같은 로컬 문서에 집중합니다. 내용에서 이름을 추출하고 묶음을 주제별로 정리할 수 있습니다. 제품 페이지에는 이미지·영상 작업 흐름, 폴더 모니터링, 실행 취소 기록이 설명되어 있지 않습니다.

[Wisfile](https://www.wisfile.ai/).

## 4. RenameClick

RenameClick은 큰 모델을 다운로드한 뒤 로컬에서 실행합니다. Auto Flow는 새 파일의 이름을 변경하고 이동할 수 있습니다. 지원 형식을 확인하세요. 제한된 실행 취소 기록은 재시작하면 사라지며 백업을 대체하지 않습니다.

[RenameClick](https://rename.click/).

## 5. File Juggler

File Juggler는 PDF 내용과 속성을 포함한 명시적인 조건으로 파일 이름을 바꾸거나 이동합니다. AI 없는 예측 가능한 작업에 적합합니다. 각 규칙을 구체적으로 정의하고 대표 파일로 시험해야 합니다.

[File Juggler](https://www.filejuggler.com/).

## 6. DropIt

DropIt은 이름, 확장자, 날짜, 크기, 정규식으로 정리합니다. 파일을 끌어 놓거나 모니터링 폴더를 주기적으로 검사할 수 있습니다. 무료지만 내용 분석 AI는 없으며 마지막 버전은 2018년에 나왔습니다.

[DropIt](https://www.dropitproject.com/).

## AI로 파일을 폴더에 분류하기

Zush 폴더 분류는 Mac과 Windows에서 베타로 제공됩니다. 지원 파일의 내용을 분석해 이름과 그룹을 제안합니다. Auto를 쓰려면 Folder rules를 비우고, 직접 정하려면 자연어로 지시하세요. 파일 이름 형식은 Naming Blocks에서 별도로 설정합니다.

> 청구서는 회사별, 영수증은 월별로 묶어 주세요. 월 폴더 이름은 YYYY-MM으로 지정해 주세요.

1. 복사한 작은 묶음을 AI Rename에 추가하고 Template을 선택합니다.
2. + Sort를 켜고 하위 폴더의 루트로 Destination folder를 선택합니다. 별도 대상이 없으면 원본 폴더가 루트입니다.
3. Folder rules에 분류 방법을 적습니다. 대상 안의 적절한 기존 폴더를 쓰려면 Reuse existing folders를 켭니다. 맞는 폴더가 없으면 새로 만들 수 있습니다.
4. 처리를 적용하기 전에 제안된 이름과 그룹을 확인하고 수정합니다.

검증한 대상과 규칙을 Template에 저장하세요. Monitor는 감시 폴더 바로 안에 새로 들어오는 파일의 이름과 분류를 처리합니다. 이미 처리한 파일을 소급해 정리하지 않습니다. 분류를 끄고 원래 대상을 선택하면 파일은 현재 폴더에 남습니다.

[AI 폴더 분류 단계별 가이드](/blog/sort-files-into-folders-with-ai-windows) · [폴더 분류 문서](/docs/folder-sorting) · [폴더 규칙 예시 30가지](/blog/ai-folder-sorting-prompts).

RenameClick 무료 플랜은 월 100회의 성공한 이름 변경 또는 이동을 제공합니다. 로컬 모델은 큰 다운로드가 필요하며 RAW, 디자인 형식, 동영상은 공개 지원 목록에 없습니다. 실행 취소는 최대 10단계이며 재시작하면 삭제됩니다. File Juggler는 30일 체험을 제공합니다. DropIt은 21가지 작업을 지원하며 최신 8.5.1은 2018년 10월 공개되었습니다. Sortio 무료 플랜은 최대 5개 규칙과 일회성 AI 체험을 포함하고 Pro에는 월간 AI 한도가 있습니다.

## 어떤 프로그램을 선택할까요?

보관함, 편집, 메타데이터, 고정 규칙, 내용 기반 이름과 폴더 중 필요한 작업으로 선택하세요. Zush는 일반 폴더의 지원 파일에 미리보기와 선택적 그룹 분류를 제공합니다. 카탈로그나 백업을 대체하지 않습니다.

## 전환 전에 복사본으로 시험하기

사진, 스크린샷, RAW, 문서, 모호한 이름이 포함된 작은 복사본부터 시작하세요. 미리보기, 그룹, 메타데이터, 보조 파일, 외장 드라이브, 복구를 확인합니다. 보관함에서는 가져오기, 내보내기, 백업, 카탈로그 복원도 시험하세요. 새 절차가 검증될 때까지 기존 아카이브를 유지하세요.

## 자주 묻는 질문

### Zush는 파일을 실제 폴더로 이동하나요?

예. 선택적인 베타 분류를 켜고 대상, 이름, 그룹을 확인하세요. 현재 위치에서 이름만 바꾸려면 분류를 끄고 원래 대상을 유지합니다.

### 새 파일을 자동으로 분류할 수 있나요?

예. 시험한 Template을 Monitor에 지정합니다. 감시 폴더 바로 안의 새 파일이 대상이며 이미 처리한 파일은 재배치하지 않습니다.

### 기존 폴더와 외장 드라이브를 사용할 수 있나요?

Reuse existing folders는 대상 루트 안의 적합한 폴더를 사용하고 필요하면 새 폴더를 만듭니다. 드라이브와 파일에 접근할 수 있어야 하며 클라우드 파일은 먼저 내려받습니다.

### 파일이 클라우드 AI로 전송되나요?

Zush Cloud AI와 BYOK는 선택한 클라우드 제공자에게 내용을 보냅니다. Ollama와 LM Studio는 지원되는 로컬 분석을 제공합니다. 로컬 분석이 앱의 모든 기능이 오프라인이라는 뜻은 아닙니다.
