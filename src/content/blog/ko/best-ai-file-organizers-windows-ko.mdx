## 제자리에서 이름만 바꿀까, 폴더로 옮길까?

모든 AI 파일 정리 도구는 다음 중 하나 또는 둘 다를 합니다.

1. File Explorer와 Windows 검색이 내용으로 파일을 찾을 수 있도록 이름을 바꿉니다.
2. 파일을 폴더 구조로 옮깁니다. 때로는 도구가 직접 만든 구조로 옮깁니다.

둘 다 파일 경로를 바꾸므로 바로 가기와 프로젝트 링크가 깨질 수 있습니다. 옮기는 쪽이 더 큰 변화이므로, 미리 보기와 재시작 후에도 남는 실행 취소가 필요합니다. 무엇인지 알려고 파일을 열어 본다면 먼저 이름 문제부터 해결해야 합니다.

## 1. Zush: 내용 기반 이름과 AI 폴더 분류

[Windows용 Zush](/windows)는 Windows 10과 11에서 동작하며 [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X)에서 설치합니다. 스크린샷, PDF, 스캔본, 사진, Office 문서, 디자인 파일, 오디오, 동영상이 든 폴더를 넣으면, Zush가 파일을 하나씩 읽고 `2026-09-18_acme_invoice_1042.pdf`나 `stripe-revenue-dashboard-september.png` 같은 이름을 제안합니다. 동영상은 MKV를 포함해 음성, 내장 자막, 메타데이터로 이름을 짓고, 음악은 태그가 없어도 식별할 수 있습니다.

바로 쓸 수 있습니다. 처음 50회 AI 이름 변경은 계정, 카드, API 키, 모델 다운로드 없이 관리형 Zush Cloud AI로 실행되며, 클라우드 모드는 RAM 4 GB면 충분합니다. 폴더가 PC 밖으로 나가면 안 될 때는 Ollama나 LM Studio로 전환하세요. 선택 사항인 기기 내 음성 인식을 쓰면 동영상 받아쓰기도 로컬에서 처리됩니다.

무엇이든 바뀌기 전에 모든 제안을 볼 수 있습니다. 이름을 더블클릭해 수정하거나, 하나만 다시 생성하거나, 묶음을 적용하세요. 준비된 Templates(Movies & TV, Remove Duplicates 포함)와 145개 이상의 Naming Blocks가 날짜, 거래처, 금액, 고객, 앞자리 0을 채운 일련번호로 이름을 일관되게 유지합니다.

![Windows용 Zush가 여러 종류의 파일을 내용에 따라 일괄 이름 변경하고, 적용 전에 제안된 파일 이름을 모두 보여 주는 모습](/videos/windows/zush-batch-rename.mp4)

폴더 정리까지 하려면 Auto를 쓰거나 "청구서는 회사별로, 영수증은 월별로 묶기" 같은 규칙을 **Folder rules**에 쓰세요. 그룹을 미리 보고, **Destination folder**를 고르고, **Reuse existing folders**로 기존 폴더를 다시 씁니다. 규칙은 중첩할 수 있고 날짜나 페이지 수 같은 파일 정보를 쓸 수 있으며, 현재 이름을 유지한 채 분류만 할 수도 있습니다. AI Rename은 중복도 찾아냅니다. 그대로 두거나, 이름에 표시하거나, 휴지통으로 옮길 수 있습니다. 사본에는 크레딧을 쓰지 않으며 Undo로 복원됩니다. 단계별 안내: [Windows에서 AI로 파일을 폴더에 분류하기](/blog/sort-files-into-folders-with-ai-windows), [바로 쓰는 폴더 규칙 30개](/blog/ai-folder-sorting-prompts). 각 설정은 [폴더 분류 문서](/docs/folder-sorting)에 설명돼 있습니다.

![Rename & sort를 적용하기 전에 내용 기반 폴더 그룹과 제안된 파일 이름을 미리 보여 주는 Windows용 Zush 화면](/images/showcase/windows/folder-sorting-light.webp)

**Monitor**는 저장한 Template을 다운로드 폴더나 스캐너 폴더에 들어오는 새 파일에 적용합니다. Rename History는 재시작 후에도 이전 이름과 새 이름을 보관하고, Undo All은 묶음 전체를 복원하면서 충돌을 나열하고 새 이름으로 복원하는 옵션을 줍니다.

![Windows용 Zush의 Monitor 탭에서 Screenshots와 Downloads 폴더를 감시하며 새 파일이 들어오면 이름을 바꾸는 설정](/images/showcase/windows/monitor-light.webp)

가격: 월 $10 또는 1회 $48. 1회 결제 라이선스에는 모든 모드(Zush Cloud AI, BYOK, Ollama, LM Studio)의 무제한 이름 변경, 이후 모든 업데이트, Mac과 Windows를 합쳐 최대 3대, 14일 환불이 포함됩니다. 미국 Microsoft Store에서 Zush는 평가 8개 기준 5.0이고, Softpedia 편집자 리뷰는 4.5/5입니다(둘 다 2026년 11월 17일 기준).

## 2. Sortio: 프롬프트 기반 분류, Linux도 지원

Sortio는 "청구서는 연도별로, 스크린샷은 프로젝트별로" 같은 평범한 문장 지시를 받아 계획을 보여 준 뒤, 이름을 바꾸고 폴더를 만들어 파일을 옮깁니다. Windows 10/11, macOS, Linux에서 동작하며 이메일 계정으로 로그인해야 합니다.

무료 요금제에는 규칙 5개, Spaces 3개까지의 규칙 기반 분류, 1회성 AI 체험, 미리 보기, 분류 기록, 실행 취소가 있습니다. 폴더 감시와 자동화는 이제 Pro가 필요하며, 월간 AI 사용량을 포함해 월 $14.99 또는 연 $99입니다. 본인의 키를 쓰면 이 사용량 제한을 피할 수 있고, Ollama를 쓰면 처리가 로컬에 머뭅니다(RAM 최소 8 GB).

Linux나 팀 좌석이 필요하면 Sortio를 고르세요. 약점: 호스팅 AI는 월간 사용량 제한이 있고, 무료 요금제에서는 더 이상 폴더를 감시하지 않습니다. [Zush vs Sortio](/blog/zush-vs-sortio)를 참고하세요.

## 3. Wisfile: 문서용 무료 선택지

Wisfile은 무료이고 Windows와 Mac에서 완전히 기기 안에서만 동작합니다. 문서 내용(제목, 저자, 연도)으로 이름을 바꾸고 묶음을 주제별 폴더로 나눌 수 있습니다. `Author-Year-Title` 같은 템플릿을 지원합니다.

![무작위 PDF 이름이 날짜가 포함된 알기 쉬운 문서 이름으로 바뀌는 모습을 담은 Wisfile 공식 일러스트](/images/blog/competitors/wisfile.webp)

예산이 가장 중요하고 PDF와 Word 보관함을 한 번 정리하려면 Wisfile을 고르세요. 약점: 실행 취소와 폴더 감시가 없고, 이미지나 동영상보다는 PDF와 Word에 집중합니다. 사본으로 작업하세요.

## 4. RenameClick: 내장 로컬 모델

RenameClick의 무료 AI는 내장 로컬 모델로 동작하며, 다운로드 크기는 약 4 GB이고 RAM 16 GB를 권장합니다. Ollama를 설정할 필요가 없다는 점은 확실히 편합니다. 이미지, 문서, 오디오, 그리고 4.1.2 버전부터는 동영상(MP4, MOV, M4V, 3GP, 프레임과 로컬 음성 받아쓰기 사용)의 이름을 바꿉니다. MKV, WebM, AVI, RAW 사진, 디자인 파일은 지원 형식 목록에 없습니다. Auto Flow는 앱이 실행 중일 때 새 파일의 이름을 바꾸고 옮깁니다.

무료 요금제는 무제한 분석과 월 100회 이름 변경 또는 이동을 제공하며, 처음 적용하기 전에 한 번은 온라인에 연결해야 합니다. 평생 라이선스는 $36 + VAT로 직접 배포 빌드 기준 최대 3대이고, 환불은 법이 요구하는 경우에만 제공됩니다. Standard Rename은 실행 취소 항목 10개를 메모리에 보관하며 재시작하면 지워집니다. 평점: 미국 Microsoft Store 평가 6개 기준 3.0, Softpedia 편집자 3.5.

![RenameClick(Mac 버전)이 Rename & Move 전에 이름을 바꾼 파일을 Legal Documents, Medical Documents, Uncategorized로 분류하는 화면](/images/blog/competitors/renameclick.webp)

설정 없이 오프라인 AI를 쓰고 싶고 RAM이 충분하다면 RenameClick을 고르세요. 자세한 비교: [Zush vs RenameClick](/blog/zush-vs-renameclick).

## 5. NudgeFile: 무료 로컬 AI 폴더 감시 도구

NudgeFile은 Windows 10과 11용 신생 앱으로 Microsoft Store에서 무료로 내려받을 수 있습니다. 사이트에 따르면 다운로드와 바탕 화면 같은 폴더를 감시하고, 새 파일에 표준화된 이름을 붙이며, 대상 폴더로 보내고, 체크섬과 로컬 시각 AI로 중복을 찾습니다. AI는 Ollama로 로컬에서 실행되며 클라우드 옵션도 있습니다. "Human Approval Pipeline"으로 제안을 검토하거나 자동으로 실행되게 할 수 있고, 사이트에는 모든 동작을 클릭 한 번으로 되돌릴 수 있다고 나와 있습니다.

Windows에서 무료로 항상 켜 두는 로컬 정리 도구를 원한다면 NudgeFile을 고르세요. 약점: FAQ에는 모델이 "파일 메타데이터와 구조"를 분석한다고 되어 있고, 사이트에 지원 파일 형식도 유료 요금제도 나와 있지 않으니 먼저 본인 파일로 시험해 보세요.

## 6. Foldora: $14.99짜리 일회성 로컬 정리

Foldora는 Windows 10, 11과 macOS에서 동작합니다. 선택한 파일을 로컬에서 분석해 폴더와 더 명확한 파일 이름을 제안하고, 미리 보기를 승인하면 적용합니다. 가격은 평생 $14.99입니다. 구매, 활성화, 주기적인 라이선스 확인에는 인터넷 연결이 필요합니다.

섞인 묶음을 싸게, 로컬에서, 한 번 정리하려면 Foldora를 고르세요. 약점: 폴더 감시가 없고, 제조사 스스로 클릭 한 번 실행 취소를 보장한다고 광고하지 않는다고 밝히므로 큰 변경 전에는 백업하세요.

## 7. File Juggler: AI 없는 예측 가능한 규칙

File Juggler는 오래된 Windows 자동화 도구이며 지금도 관리되고 있습니다(3.1.9 버전, 2026년 10월 30일). "다운로드 폴더의 PDF에 'Invoice'가 있으면 날짜로 이름을 바꾸고 Finance로 옮기기" 같은 규칙을 쓰면 파일이 들어오는 대로 적용합니다. 규칙에 쓰려고 PDF, Word, Excel 텍스트를 읽을 수 있습니다. Softpedia 편집자 평가는 4.5/5입니다.

가격은 $50 + 세금의 1회 결제 라이선스이며, 모든 기능을 쓸 수 있는 30일 체험판이 있습니다. 약점: AI와 OCR이 없어서 경우마다 규칙이 필요하고, 이미지로만 된 스캔본에는 별도의 OCR 단계가 필요합니다. 다른 선택지: [File Juggler 대안](/blog/file-juggler-alternatives).

## 8. DropIt: 무료 규칙 엔진

DropIt은 무료 오픈 소스입니다. 규칙은 이름, 크기, 날짜, 정규식으로 파일을 찾고, 파일을 끌어다 놓거나 감시 폴더를 주기적으로 검사하게 할 수 있습니다. 이동, 복사, 이름 변경, 압축, 압축 풀기 등 21가지 동작이 있습니다.

약점: 최신 릴리스인 8.5.1이 2018년 2월에 나왔으므로 업데이트나 AI는 기대하기 어렵습니다. 확장자나 이름 패턴으로 무료로 간단히 분류하려면 DropIt을 고르세요. Mac에서 넘어오셨다면 [Windows용 Hazel 대안](/blog/hazel-for-windows-alternatives)을 보세요.

## 무엇을 골라야 할까요?

- 파일 이름이 문제이거나, 한 번 검토하는 묶음에서 이름과 폴더를 함께 처리하고 싶다: **Zush**.
- Linux나 팀 좌석이 필요하다: **Sortio**.
- 무료, 로컬, 문서 전용 정리: **Wisfile**.

- 직접 시험해 볼 의향이 있는 무료 로컬 감시 도구: **NudgeFile**.
- 저렴한 일회성 로컬 정리: **Foldora**.
- AI 없는 정확한 규칙: **File Juggler**, 무료여야 한다면 **DropIt**.

## 자주 묻는 질문

### Windows 11에서 가장 좋은 AI 파일 정리 도구는?

저희 추천은 Zush입니다. 내용으로 파일 이름을 바꾸고 Auto나 직접 쓴 지시로 폴더에 분류하며, 미리 보기, Templates, 폴더 감시, 영구 실행 취소를 제공합니다. Linux가 필요하면 Sortio, 내장 로컬 모델을 원하면 RenameClick, AI 없는 정확한 규칙이 파일에 맞다면 File Juggler가 대안입니다. Zush는 저희 제품이니 어떤 도구든 먼저 사본으로 시험하세요.

### Windows용 무료 AI 파일 정리 도구가 있나요?

네. Wisfile은 PDF와 Word 파일용으로 무료이며 로컬에서 동작하고, NudgeFile은 Microsoft Store에서 무료로 내려받을 수 있습니다. Zush는 계정, 카드, API 키 없이 AI 이름 변경 50회를 무료로 제공합니다. RenameClick은 4 GB 모델을 내려받은 뒤 월 100회 이름 변경 또는 이동을 허용합니다. DropIt도 무료지만 AI가 아닌 고정 규칙을 씁니다.

### 1회 결제 가격으로 가장 많이 주는 Windows 정리 도구는?

Foldora는 $14.99, RenameClick은 $36 + VAT이지만 둘 다 로컬 AI나 본인 AI로만 동작합니다. Zush의 $48 라이선스에는 관리형 Zush Cloud AI와 BYOK, Ollama, LM Studio, 무제한 이름 변경, 이후 모든 업데이트, Windows와 Mac을 합쳐 최대 3대, 14일 환불이 포함됩니다. File Juggler의 $50 라이선스로는 AI가 아니라 규칙을 삽니다.

### AI 파일 정리 도구가 내 파일을 업로드하나요?

모드에 따라 다릅니다. Ollama나 LM Studio를 쓰는 Zush는 분석을 PC 안에서 처리하고, Zush Cloud AI와 BYOK는 이름을 짓기 위해 파일 내용을 클라우드 모델로 보냅니다. Wisfile, Foldora, RenameClick 내장 모델은 로컬에서 동작하고, NudgeFile은 기본값이 로컬 AI입니다. Sortio는 호스팅 AI와 함께 모든 요금제에서 BYOK, Ollama, LM Studio를 제공합니다. 민감한 폴더에 쓰기 전에 앱마다 AI 설정을 확인하세요.

### Windows에서 AI가 다운로드 폴더를 자동으로 정리할 수 있나요?

네. Zush는 다운로드 폴더를 감시하며 새 파일 이름을 바꾸고 Template에 저장한 폴더 규칙을 적용할 수 있습니다. RenameClick의 Auto Flow, Sortio Pro, NudgeFile도 폴더를 감시합니다. 중요한 폴더를 자동화하기 전에 테스트 폴더 하나로 시작하세요. Zush 설정 방법은 [다운로드 폴더 자동화 가이드](/ai-file-sorter)에서 단계별로 안내합니다.
