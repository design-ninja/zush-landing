**Mac이나 Windows를 쓰는 대부분의 사람에게 가장 좋은 AI 파일 이름 변경 도구는 [Zush](/)입니다.** 계정, 카드, API 키 없이 이름 변경 50회가 무료이고, $48 1회 결제 라이선스에 최대 3대용 관리형 클라우드 AI가 포함됩니다. Linux에는 AI Renamer, Mac과 Windows에서 무료 로컬 도구로는 Wisfile이 있습니다. RenameClick과 RenamerX는 로컬 모델을 내장하고, Renamed.to는 클라우드 저장소에 맞습니다.

**확인 방법:** 이 글은 [Zush](/) 제작사가 썼습니다. 경쟁 제품의 가격, 기능, 평점은 2026년 11월 17일에 각 제조사 사이트와 공식 스토어에서 확인했습니다([아래 출처](#sources-and-how-we-checked)). 실험실 테스트가 아니라 문서로 확인된 기능을 비교한 글이며, 실제 파일에 대한 Zush의 결과는 [8개 파일 파일럿 테스트](/benchmarks/ai-file-renamer-pilot-2026-09-05/README.md)에 공개했습니다.

이 페이지는 크로스플랫폼 개요입니다. 플랫폼별 추천은 [Mac용 AI 파일 이름 변경 도구 추천](/blog/best-ai-file-renamer-tools-mac-compared)과 [Windows용 AI 파일 이름 변경 도구 추천](/blog/best-ai-file-renamer-tools-windows-compared)을 보세요.

### Zush가 1위인 이유

인상이 아니라 확인할 수 있는 사실입니다.

1. **Mac이나 Windows에서 바로 동작합니다.** 계정, 카드, API 키, 모델 다운로드 없이 관리형 Zush Cloud AI로 AI 이름 변경 50회가 무료입니다. AI Renamer는 Google 로그인이, FilesDesk는 로그인이 필요하고, RenameClick의 무료 AI는 RAM 16 GB를 권장하는 약 4 GB 로컬 모델을 내려받아야 합니다. NameQuick Managed도 30회 무료로 똑같이 쉽게 시작할 수 있습니다.
2. **라이선스 하나로 두 플랫폼, 클라우드까지.** 1회 $48로 Mac과 Windows를 합쳐 최대 3대, 모든 모드(Zush Cloud AI, BYOK, Ollama, LM Studio)의 무제한 이름 변경, 이후 모든 업데이트, 14일 환불이 해결됩니다. AI Renamer($19), RenameClick($36 + VAT), RenamerX($36), FilesDesk($40), NameQuick($69)의 1회 결제 라이선스는 모두 본인 키나 로컬 모델이 필요합니다.
3. **Rename을 누르기 전에는 아무것도 바뀌지 않고, 나중에 되돌릴 수 있습니다.** Rename History는 재시작 후에도 남고 묶음 전체를 되돌릴 수 있습니다. RenameClick의 실행 취소는 메모리의 10개 항목이고, AI Renamer는 실행 취소를 문서화하지 않았으며, Wisfile에는 없습니다.
4. **폭넓은 지원.** MKV를 포함한 동영상을 음성, 내장 자막, 메타데이터로 이름 짓고, RAW 사진, 디자인 파일, 오디오, Office, iWork, EPUB을 처리합니다. AI Rename 안의 중복 감지에는 크레딧이 들지 않습니다.

Zush가 답이 아닌 경우: Linux 빌드가 없고(AI Renamer에는 있음), 브라우저 전용이나 클라우드 저장소 API 작업 흐름이 없으며(Renamed.to에는 있음), 환불 기간은 14일입니다. 평점(2026년 11월 17일 기준): 미국 Microsoft Store 평가 8개 기준 5.0, Softpedia 편집자 리뷰 4.5/5.

### 1. Zush

![변경을 적용하기 전에 섞인 묶음의 원래 파일 이름 옆에 AI 제목 제안을 보여 주는 Mac용 Zush](/images/showcase/macos/batch-rename-light.webp)

[Zush](/)는 내용으로 파일 이름을 짓는 Mac과 Windows용 데스크톱 앱입니다. 100개 이상의 형식을 지원합니다. HEIC, AVIF, 카메라 RAW를 포함한 이미지 형식 41개, 디자인 형식 4개(Sketch, Figma .fig, Illustrator .ai, PSD), PDF, Office, iWork, OpenDocument, EPUB을 포함한 문서 형식 40개, MP4, MOV, MKV를 포함한 동영상, 오디오 형식 7개입니다. 동영상은 음성, 내장 자막, 메타데이터로 이름을 짓습니다. 무엇을 읽는지는 [AI로 동영상 파일 이름 바꾸는 법](/blog/rename-video-files-with-ai)에서 설명합니다.

작동 방식: 준비된 Template(Smart Rename, Screenshots, Movies & TV, Remove Duplicates 등)을 고르거나 145개 이상의 Naming Blocks와 Custom AI Blocks로 직접 만드세요. Zush가 파일마다 이름을 제안합니다. 이름을 더블클릭해 수정할 수 있고, Rename을 누르기 전에는 아무것도 바뀌지 않습니다.

**장점:**

- 계정이나 키 없이 관리형 클라우드 AI로 처음 실행할 때부터 동작
- 하나의 작업 흐름에 AI 경로 네 가지: Zush Cloud AI, BYOK(Gemini, OpenRouter, OpenAI, Claude), Ollama, LM Studio, 그리고 Ollama나 LM Studio를 통한 동영상용 로컬 음성 인식
- 적용 전 미리 보기, 묶음 단위 실행 취소가 되는 영구 Rename History, 충돌을 표시하는 Undo All
- 중복 감지: 사본을 유지, 이름에 표시, 또는 휴지통으로 이동, 크레딧 미사용
- 폴더 감시, Mac에서는 다시 연결하면 재개되는 외장 드라이브 포함
- 시작 값과 앞자리 0을 지정하는 폴더별 일련번호
- 중첩 폴더를 지원하는 선택 사항인 AI 폴더 분류
- 클라우드 모드에서 가벼움: 약 200 MB, RAM 최소 4 GB
- 11개 이상 언어 인터페이스, 60개 이상 언어로 이름 생성

**한계:**

- Linux 빌드와 브라우저 전용 버전 없음
- Zush Cloud AI와 BYOK는 인터넷 필요, Ollama와 LM Studio는 내 컴퓨터에서 실행
- 태그 없는 음악 식별은 현재 Windows 전용

**적합한 사람:** AI 이름 변경이 바로 동작하고 한 번만 결제하고 싶은, 섞인 폴더를 가진 Mac과 Windows 사용자.

Zush 라이선스 하나로 Mac과 Windows를 합쳐 최대 3대에서 쓸 수 있습니다. [Templates를 내보내](/docs/template-import-export) 다른 컴퓨터에서 가져올 수 있습니다.

#### 선택 사항: AI 폴더 분류

Zush는 파일을 폴더로 분류할 수도 있습니다. **Auto**를 고르거나 "청구서는 회사별로, 영수증은 월별로 묶기" 같은 **Folder rules**를 쓰세요. 규칙으로 중첩 폴더를 만들고 날짜나 페이지 수 같은 파일 정보를 쓸 수 있습니다(Mac 앱은 크기, 카메라, 재생 시간도 씁니다). 이름을 바꾸지 않고 분류만 하거나, 대상 폴더를 고르거나, 기존 폴더를 다시 쓸 수 있습니다. 설정을 Template에 저장해 감시 폴더에 연결하면 새로 들어오는 파일에도 적용됩니다. [폴더 분류 가이드](/docs/folder-sorting)와 [AI 파일 정리](/ai-file-organizer) 페이지를 참고하세요.

### 2. FilesDesk

FilesDesk는 Mac과 Windows에서 동작하며 Watch Folders, Gmail·iCloud·IMAP 이메일 첨부 파일 이름을 바꾸는 Watch Inbox, 템플릿, 실행 취소가 되는 기록이 있습니다. 로그인하면 무료 크레딧 15개로 시작합니다. 관리형 AI는 구독 전용입니다. 500 크레딧 월 $8 또는 2,000 크레딧 월 $20(연 $80 또는 $200)이며, AI 이름 제안 1개당 1 크레딧이고 같은 파일을 다시 실행하면 크레딧을 또 씁니다. $40 Self-Managed 라이선스는 본인 키나 로컬 모델(Ollama, LM Studio, vLLM)을 쓰고, 기기 1대에 묶이며, 1년 업데이트가 포함되고, 환불 기간은 3일입니다.

**FilesDesk를 고를 때:** 이메일 첨부 파일이 도착하는 대로 이름을 바꾸고 싶을 때. **약점:** 1회 결제 라이선스에 관리형 AI가 포함되지 않습니다. [Zush vs FilesDesk](/blog/zush-vs-filesdesk)를 참고하세요.

### 3. RenameClick

RenameClick(현재 rename.click)은 Mac과 Windows에서 동작합니다. 4.1.2 버전에서 프레임과 로컬 음성 받아쓰기를 이용한 MP4, MOV, M4V, 3GP 동영상 지원이 추가됐지만 MKV, WebM, AVI는 지원하지 않고 카메라 RAW나 디자인 파일도 지원하지 않습니다. 무료 요금제는 무제한 분석과 월 100회 이름 변경 또는 이동을 허용합니다. Lifetime 라이선스는 직접 배포 빌드 기준 최대 3대에 $36 + VAT이며, 제공업체 요금은 포함되지 않습니다.

**RenameClick을 고를 때:** Ollama 설정이 필요 없는 내장 로컬 모델을 원할 때. **약점:** 모델 다운로드가 약 4 GB이고 RAM 16 GB를 권장하며, Undo는 메모리에 10개 항목만 보관하고 재시작하면 지워집니다. [Zush vs RenameClick](/blog/zush-vs-renameclick)을 참고하세요.

### 4. AI Renamer

AI Renamer(airenamer.app)는 Mac, Windows, 그리고 이제 Linux용 데스크톱 앱입니다. 1.9 버전에서 앱이 열려 있을 때만 동작하고 하위 폴더를 건너뛰는 Watch Folder(베타)가 추가됐고, 1.10 버전에서 동영상, 오디오, RAW, HEIC, Office, EPUB이 추가됐습니다. Local Mode는 본인 키나 Ollama/LM Studio로 쓰는 1회 $19이고, 클라우드 크레딧은 200개당 $10이며 Google 로그인 후 10개가 무료입니다. 환불 규정은 없고 크레딧 구매는 환불되지 않습니다. GitHub의 무료 GPL-3.0 `ozgrozer/ai-renamer` CLI는 무관한 프로젝트입니다.

**AI Renamer를 고를 때:** Linux가 필요하거나 로컬 AI용으로 가장 낮은 1회 결제 가격을 원할 때. **약점:** 실행 취소가 문서화돼 있지 않습니다. [Zush vs AI Renamer](/blog/zush-vs-airenamer)를 참고하세요.

### 5. Renamer.ai

Renamer.ai는 Windows와 Mac 앱, 웹 인터페이스를 제공하며 Magic Folders, 템플릿, 미리 보기, 실행 취소가 있습니다. 무료 Starter 요금제(월 25개 파일)를 포함한 모든 요금제에서 로컬 모드를 쓸 수 있습니다. 유료 클라우드 요금제는 Pro 월 $9.95(200개), Power $29.95(1,000개), Ultimate $99.95(5,000개)이며 연간 결제 시 15% 저렴합니다. BYOK는 Ultimate에만 있습니다. Softpedia 편집자 점수는 4.5/5입니다.

**Renamer.ai를 고를 때:** 문서 템플릿과 무료 로컬 처리를 원할 때. **약점:** 1회 결제 라이선스가 없어서 관리형 AI는 월간 사용량제입니다. [Zush vs Renamer.ai](/blog/zush-vs-renamer-ai)를 참고하세요.

### 6. NameQuick

NameQuick(3.0.57 버전, 이제 Mac App Store에도 있음)은 Mac과 Windows에서 동작하며 Watch Folders, Rules, Quick Organize, 실행 취소를 제공합니다. 이메일이나 카드 없이 Managed 이름 변경 30회를 무료로 주고, 14일 Managed 체험(70회)에는 카드가 필요합니다. Managed 요금제는 월 $12부터이고, 이름 변경 팩은 500회 $19 또는 1,500회 $39이며 12개월 유효합니다. Self-Managed는 컴퓨터 1대용 1회 $69로 평생 업데이트와 14일 환불이 있고, AI 비용은 별도입니다.

**NameQuick을 고를 때:** AI 이름 짓기 위에 규칙 엔진을 원할 때. **약점:** 1회 결제 라이선스는 컴퓨터 1대용이고 관리형 AI가 없습니다. [Zush vs NameQuick](/blog/zush-vs-namequick)을 참고하세요.

### 7. RenamerX

RenamerX는 Mac과 Windows용 로컬 우선 이름 변경 도구입니다. 내장 모델(Qwen3.5 4B)은 약 3.4 GB를 내려받으며, Apple Silicon이나 호환 GPU가 있는 Windows x64 PC에서 실행됩니다. Ollama, LM Studio, OpenAI 호환 엔드포인트, 또는 본인 키로 OpenAI와 Gemini에도 연결합니다. 사이트에는 문서, 카메라 RAW를 포함한 이미지, MKV를 포함한 동영상, Watch Folders, 실행 취소가 나와 있습니다. Free는 월 50 크레딧, Pro는 무제한 크레딧의 평생 $36입니다. 기기 수, 환불 조건, 업데이트 정책은 홈페이지에 나와 있지 않습니다.

**RenamerX를 고를 때:** 내장 로컬 모델로 RAW와 MKV를 지원받고 싶을 때. **약점:** 관리형 클라우드가 없고, 오디오 파일은 지원 목록에 없습니다.

### 8. Wisfile

Wisfile은 무료이고 Mac과 Windows에서 100% 로컬로 동작하며 PDF와 Word 파일에 집중합니다. 실행 취소는 없습니다.

**Wisfile을 고를 때:** 가끔 문서 이름을 바꾸고 비용도 클라우드도 원하지 않을 때. **약점:** 실행 취소가 없어서 잘못된 묶음은 손으로 고쳐야 합니다.

### 9. Renamed.to

Renamed.to는 API와 CLI가 있는 클라우드 서비스입니다. 무료 이름 변경 50회로 시작하고, 이후 크레딧을 1,000개 $9 또는 10,000개 $49에 판매하며 12개월간 유효합니다.

**Renamed.to를 고를 때:** 문서가 클라우드 저장소에 있거나 API가 필요할 때. **약점:** 클라우드 전용이라 로컬 처리 경로가 없습니다.

### 10. File Renamer AI

File Renamer AI는 브라우저 도구입니다. 파일을 업로드하고, 이름을 검토하고, ZIP으로 내려받습니다. 크레딧은 1,000개 $10 또는 10,000개 $100이며 만료되지 않습니다. 홈페이지에는 이제 PDF, Office, 동영상, 오디오가 언급되지만 가격 페이지는 여전히 이미지를 설명합니다.

**File Renamer AI를 고를 때:** 소프트웨어를 설치할 수 없을 때. **약점:** 데스크톱 앱, 폴더 감시가 없고 ZIP을 내려받은 뒤에는 실행 취소도 없습니다.

### 참고: Riffo

이 페이지의 이전 버전에는 Mac 앱과 웹 데모가 있는 Riffo가 있었습니다. 2026년 11월 17일에 확인했을 때 riffo.ai가 연결을 거부했으므로 더 이상 순위에 넣지 않습니다.

## 클라우드 AI와 로컬 AI 중 무엇을?

여기 나온 여러 도구가 로컬로 실행되므로 로컬 AI만으로는 결정이 나지 않습니다. 차이는 하드웨어와 설정입니다. 클라우드 모드의 Zush는 RAM 4 GB와 디스크 약 200 MB면 됩니다. RenameClick은 내장 모델에 RAM 16 GB를 권장하고, RenamerX의 로컬 모델은 Apple Silicon이나 호환 Windows GPU가 필요합니다. 파일이 컴퓨터 밖으로 나가면 안 된다면 Zush는 Ollama나 LM Studio로 동작합니다. ## 자주 묻는 질문

### AI 파일 이름 변경 도구란?

AI 파일 이름 변경 도구는 파일마다 내용을 읽고 설명형 이름을 제안하는 앱입니다. 패턴 도구는 묶음 전체에 날짜를 붙이거나 텍스트를 바꿀 수 있지만, 둘 다 `scan_004.pdf`라는 이름이라면 청구서와 계약서를 구분하지 못합니다. AI 이름 변경 도구는 텍스트, 이미지, 오디오, 동영상을 읽고 파일마다 고유한 이름을 붙이며, 무엇이든 바뀌기 전에 검토할 수 있어야 합니다.

### 2026년 가장 좋은 AI 파일 이름 변경 도구는?

Mac과 Windows에서는 Zush를 추천합니다. 계정, 카드, API 키 없이 AI 이름 변경 50회로 처음 실행할 때부터 동작합니다. $48 1회 결제 라이선스에 관리형 클라우드 AI, BYOK, Ollama, LM Studio가 최대 3대용으로 포함되며, 모든 묶음은 미리 보고 묶음 단위 실행 취소가 되는 Rename History에 남습니다. Linux에는 AI Renamer, Mac과 Windows의 무료 로컬 도구로는 Wisfile이 있고, Renamed.to는 클라우드 저장소와 API 작업에 맞습니다.

### $48 1회 결제 라이선스가 $19나 $36 라이선스보다 가치가 있나요?

AI를 어디서 실행하고 싶은지에 달려 있습니다. $19 AI Renamer, $36 RenameClick, $36 RenamerX 라이선스는 앱을 포함하지만 AI는 본인의 API 키나 컴퓨터가 직접 돌려야 하는 로컬 모델입니다. Zush의 $48에는 무제한 이름 변경이 가능한 관리형 Zush Cloud AI와 BYOK, 로컬 모델, 이후 모든 업데이트, Mac과 Windows를 합쳐 3대, 14일 환불이 포함됩니다.

### 내 파일은 어디서 처리되나요?

모드에 따라 다릅니다. Zush Cloud AI나 BYOK를 쓰면 이름을 만들기 위해 파일 내용이 AI 서비스로 전송됩니다. Ollama나 LM Studio를 쓰면 분석이 내 컴퓨터에서 실행됩니다. RenameClick과 RenamerX는 기본값이 내장 로컬 모델이고, Renamer.ai는 모든 요금제에 로컬 모드가 있으며, Wisfile은 로컬 전용이고, Renamed.to와 File Renamer AI는 클라우드 서비스입니다. 보관 조건은 각 제조사의 개인정보 페이지를 확인하세요.

### Linux에서 동작하는 AI 파일 이름 변경 도구는?

여기서 비교한 도구 중에서는 AI Renamer가 이제 Linux 빌드를 공개합니다. 2026년 11월 17일 확인 기준 Zush, FilesDesk, RenameClick, NameQuick, RenamerX, Wisfile은 Mac과 Windows 앱만 있고 Linux 버전은 없습니다. Wisfile은 Linux를 출시 예정으로 표시합니다. Renamed.to와 File Renamer AI 같은 브라우저 및 API 도구는 어떤 운영체제에서든 쓸 수 있지만 파일이 해당 클라우드 서비스로 갑니다.

### AI 이름 변경을 되돌릴 수 있나요?

Zush에서는 됩니다. Rename History가 영구적이라 며칠 뒤에도 묶음 전체를 되돌릴 수 있고, Undo All은 복원 전에 충돌을 나열합니다. FilesDesk와 NameQuick도 실행 취소가 되는 기록을 남깁니다. RenameClick은 실행 취소 항목 10개를 메모리에 보관하고 재시작하면 지웁니다. AI Renamer는 실행 취소를 문서화하지 않았고 Wisfile에는 없으니 먼저 사본으로 시험하세요.
