빠른 답: 무료로 하는 방법은 Microsoft PowerToys의 **PowerRename**입니다. 사진을 선택하고 PowerRename을 연 다음, 메타데이터 소스를 EXIF로 바꾸고 이름 앞에 `$DATE_TAKEN_YYYY-$DATE_TAKEN_MM-$DATE_TAKEN_DD`를 넣으세요. 날짜와 함께 사진에 무엇이 담겼는지까지 이름에 넣고 싶다면 [Zush](/windows)를 사용하세요.

어떤 도구를 쓰든 **만든 날짜**가 아니라 **촬영 날짜**를 기준으로 이름을 바꾸세요. Windows는 파일을 새 드라이브로 복사할 때 "Date created"를 다시 설정하므로, 이 값은 사진을 찍은 날이 아니라 백업한 날인 경우가 많습니다. 촬영 날짜는 사진 내부(EXIF)에 저장되어 있어 변하지 않습니다.

## 어떤 날짜 형식을 사용할까

날짜를 맨 앞에 두고 연-월-일 순서로 쓰세요.

- `2026-08-30_lisbon_trip_001.jpg`는 File Explorer에서 올바르게 정렬됩니다.
- `30-08-2026_lisbon.jpg`는 일을 먼저 기준으로 정렬되므로 올바르게 정렬되지 않습니다.

연사로 촬영한다면 시간(`2026-08-30_143512`)도 추가해서 같은 날 찍은 두 사진의 이름이 겹치지 않게 하세요.

## 네 가지 방법

| 방법 | 비용 | 설명 추가 | 되돌리기 |
|---|---|---|---|
| PowerRename | 무료 | 아니요 | 직후 Ctrl+Z |
| Bulk Rename Utility | 개인 사용 무료 | 아니요 | 되돌리기 배치 파일 |
| ExifTool | 무료 | 아니요 | 불가 |
| Zush | 무료 이름 변경 50회, 이후 월 $10 또는 $48 | 예, 사진 내용을 기반으로 | 전체 Rename History |

## 1. PowerRename (무료, Microsoft 제작)

1. Microsoft Store에서 [Microsoft PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)를 설치하고 PowerRename이 켜져 있는지 확인합니다.
2. File Explorer에서 사진을 선택하고 마우스 오른쪽 버튼을 클릭한 뒤 **Rename with PowerRename**을 선택합니다(Windows 11에서는 **Show more options** 아래에 있습니다).
3. **Use regular expressions**를 켜고 메타데이터 소스를 **EXIF/XMP**로 설정합니다.
4. **Search for**에 `^`를 입력합니다. 이는 이름의 시작 부분과 일치합니다.
5. **Replace with**에 `$DATE_TAKEN_YYYY-$DATE_TAKEN_MM-$DATE_TAKEN_DD_`를 입력합니다.
6. 미리보기를 확인하고 **Apply**를 클릭합니다.

`IMG_4382.jpg`는 `2026-08-30_IMG_4382.jpg`가 됩니다. 원래 이름을 끝에 남겨 두는 것은 의도적인 선택으로, 두 사진의 이름이 같아지는 일을 막아 줍니다.

시간까지 추가하려면 `$DATE_TAKEN_YYYY-$DATE_TAKEN_MM-$DATE_TAKEN_DD_$DATE_TAKEN_HH$DATE_TAKEN_mm$DATE_TAKEN_SS_`를 사용하세요.

## 2. Bulk Rename Utility

Bulk Rename Utility도 EXIF 데이터를 읽으며 형식을 더 세밀하게 제어할 수 있습니다. 개인 사용은 무료입니다.

1. Bulk Rename Utility에서 폴더를 열고 사진을 선택합니다.
2. **Auto Date** 패널에서 **Prefix**를 선택하고 유형을 **EXIF Date Picture Taken**(또는 사용 중인 버전의 동등한 EXIF 옵션)으로 설정합니다.
3. `Y-M-D` 같은 형식과 구분 기호를 고릅니다.
4. **New Name** 열을 확인한 다음 **Rename**을 클릭합니다.

이름 변경을 되돌리는 배치 파일도 생성할 수 있습니다.

## 3. ExifTool (정밀함, 명령줄)

ExifTool은 사진가들이 메타데이터 작업에 신뢰하는 도구입니다. 설치한 후 사진 폴더에서 터미널을 열고 다음을 실행하세요.

```bat
exiftool "-FileName<DateTimeOriginal" -d "%Y-%m-%d_%H%M%S%%-c.%%e" .
```

이 명령은 모든 사진의 이름을 `2026-08-30_143512.jpg`처럼 촬영 날짜와 시간으로 바꿉니다. `%%-c` 부분은 두 사진이 같은 초에 찍혔을 때 `-1`, `-2`를 붙여 줍니다. 촬영 날짜가 없는 사진은 그대로 둡니다.

먼저 폴더 사본으로 테스트하세요. 되돌리기 기능은 없습니다.

## 4. Zush: 날짜와 사진 내용을 함께

날짜는 언제인지만 알려 줍니다. 그날 찍은 400장의 사진 중 어느 것이 트램이고, 해변이며, 저녁 식사인지는 알려 주지 않습니다. [Windows용 Zush](/windows)는 촬영 날짜를 읽고 각 이미지를 살펴본 다음, 둘을 합쳐 줍니다.

| 변경 전 | 변경 후 |
|---|---|
| `IMG_4382.jpg` | `2026-08-30_lisbon_tram_street.jpg` |
| `PXL_20260712_183455.jpg` | `2026-07-12_dog_running_on_beach.jpg` |
| `DSC01877.ARW` | `2026-06-14_wedding_first_dance.ARW` |

설정 방법:

1. [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X)에서 Zush를 설치하고 사진 폴더를 끌어다 놓습니다.
2. **Photographer Shoots** Template을 고르거나, Naming Blocks로 `{Capture Date}_{Event}_{Scene}` 같은 패턴을 만듭니다.
3. 날짜 형식과 구분 기호를 선택합니다.
4. 이름을 검토하고, 고치고 싶은 이름은 더블 클릭해서 수정한 다음 **Rename**을 클릭합니다.

Zush는 JPG, iPhone의 HEIC, PNG, 그리고 CR3, NEF, ARW, DNG 같은 RAW 파일을 읽습니다. 사진에 촬영 날짜가 없으면 추측하지 않고 Capture Date 블록을 비워 둡니다. Rename History로 언제든 원래 이름을 복원할 수 있습니다.

## 대규모 라이브러리의 이름을 바꾸기 전에

- **먼저 사본으로 작업하세요.** 사진 20,000장에 실행하기 전에 20장으로 어떤 방법이든 먼저 시험해 보세요.
- **누락된 날짜를 확인하세요.** 스크린샷, 다운로드한 이미지, 편집 후 내보낸 파일에는 EXIF 날짜가 없는 경우가 많습니다. File Explorer의 자세히 보기에서 **Date taken** 열로 정렬하면 빈 항목을 찾을 수 있습니다.
- **RAW와 JPEG 쌍은 함께 유지하세요.** 카메라가 둘 다 저장한다면 같은 일괄 작업에서 이름을 바꿔 `DSC01877.ARW`와 `DSC01877.JPG`가 서로 대응하는 이름을 갖게 하세요.
- **휴대폰 백업은 건드리지 마세요.** OneDrive나 Google Photos 같은 앱은 파일을 이름으로 추적합니다. 확실하지 않다면 동기화 폴더 자체가 아니라 사본의 이름을 바꾸세요.

## FAQ

### Windows 11에서 촬영 날짜로 사진 이름을 바꾸려면 어떻게 하나요?

Microsoft PowerToys를 설치하고 사진을 선택한 다음 PowerRename을 엽니다. 메타데이터 소스를 EXIF/XMP로 설정하고, 정규식을 켠 상태에서 `^`를 검색해 `$DATE_TAKEN_YYYY-$DATE_TAKEN_MM-$DATE_TAKEN_DD_`로 바꾸세요. 그러면 모든 이름 앞에 촬영 날짜가 붙습니다.

### 사진의 만든 날짜가 왜 틀리게 표시되나요?

Windows는 해당 드라이브에서 파일이 만들어질 때, 복사할 때도 포함해서 "Date created"를 설정합니다. 대신 사진의 EXIF 데이터에 있는 "Date taken"을 사용하세요. 이 값은 카메라가 설정하며 파일을 복사해도 바뀌지 않습니다.

### File Explorer가 사진 이름을 날짜에 따라 자동으로 바꿔 줄 수 있나요?

아니요. File Explorer는 Date taken으로 정렬하고 그룹화할 수는 있지만, 그 날짜를 파일 이름에 넣을 수는 없습니다. PowerRename, Bulk Rename Utility, ExifTool 또는 Zush를 사용하세요.

### 촬영 날짜가 없는 사진이 있으면 어떻게 하나요?

스크린샷과 다운로드한 이미지에는 없는 경우가 많습니다. ExifTool과 Zush는 추측하지 않고 날짜를 비워 둡니다. PowerRename에서는 미리보기를 확인해 해당 파일을 제외하거나, 수정한 날짜를 기준으로 따로 이름을 바꾸세요.
