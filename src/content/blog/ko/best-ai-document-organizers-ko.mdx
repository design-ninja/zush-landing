## AI로 문서를 정리하는 두 가지 방식

AI 문서 정리 도구는 두 그룹으로 나뉘며, 어떤 그룹을 고르느냐가 기능 목록보다 더 중요합니다.

1. **폴더 기반 도구**는 파일이 원래 있는 자리에서 이름을 바꾸고 이동합니다. 문서는 Finder, File Explorer, iCloud, OneDrive, Dropbox에서 평범한 파일로 그대로 남습니다. Zush, NameQuick, Wisfile, File Juggler가 이 방식입니다.
2. **아카이브 도구**는 문서를 자체 라이브러리나 서버로 가져온 뒤 태그, 전문 검색, 메타데이터를 추가합니다. Paperless-ngx와 DEVONthink가 이 방식입니다.

회계사, 팀, 다른 앱과 폴더를 공유한다면 폴더 기반 도구를 고르세요. 모든 것을 한곳에서 검색하고 싶고 그 앱 안에서 작업해도 괜찮다면 아카이브를 고르세요.

## 1. Zush: 이미 쓰는 폴더에 가장 알맞은 AI 문서 정리 도구

[Zush](/ai-file-organizer)는 Mac과 Windows에서 실행됩니다. PDF, 스캔본, 영수증, 계약서, Word, Excel, Pages 파일이 든 폴더를 끌어다 놓으면 텍스트 레이어가 없는 이미지 전용 스캔을 포함해 모든 파일을 읽습니다. 그런 다음 날짜, 거래처, 금액, 고객, 문서 유형, 청구서 번호처럼 중요한 항목으로 구성한 이름을 제안합니다.

![일괄 적용 전에 혼합 폴더의 각 제안 파일명을 보여주는 Mac용 Zush](/images/showcase/macos/batch-rename-light.webp)

이름은 템플릿을 따르므로, AI가 즉흥적으로 짓는 대신 모든 청구서가 같은 형태가 됩니다. Bookkeeper Expenses는 기본 제공 템플릿 중 하나이며, 145개 이상의 Naming Blocks로 나만의 패턴을 만들 수 있습니다.

문서까지 정리하려면 **Folder rules**에 "청구서는 회사별로, 영수증은 월별로 묶어줘"와 같은 문장을 쓰거나 Auto로 두세요. 무엇이든 이동하기 전에 하나의 미리보기에서 이름과 폴더를 검토합니다.

![청구서는 회사별로, 영수증은 월별로 묶으라는 지시문과 예시 규칙이 들어 있는 Zush Folder rules 대화상자](/images/showcase/macos/folder-rules-light.webp)

새로 들어오는 서류는 스캐너 폴더나 Downloads 폴더의 **Monitor**에 템플릿을 지정하면, 새 문서가 도착하는 대로 이름이 붙고 정리됩니다. Rename History로 적용한 일괄 작업을 되돌릴 수 있습니다. 민감한 파일은 Ollama나 LM Studio를 사용해 컴퓨터 안에 둘 수 있으며, Zush Cloud AI와 직접 발급받은 API 키가 다른 선택지입니다.

문서를 누구나 공유 폴더에서 열 수 있는 일반 파일로 유지하고 싶다면 Zush를 고르세요. 유용한 가이드: [스캔 문서 자동으로 이름 바꾸기](/blog/rename-scanned-documents-automatically), [AI로 청구서 이름 바꾸기](/rename-invoices-with-ai), [AI로 영수증 이름 바꾸기](/rename-receipts-with-ai).

Zush 라이선스 하나로 Mac과 Windows에서 최대 3대의 기기를 사용할 수 있습니다.

Naming Blocks, Custom AI Blocks, 폴더 규칙이 포함된 [템플릿을 내보낸](/docs/template-import-export) 뒤 다른 컴퓨터에서 가져올 수 있습니다. 로컬 대상 폴더, 폴더 권한, AI 연결은 그 컴퓨터에서 다시 선택해야 합니다. 옮겨지는 것은 워크플로 설정이며 파일 자체는 아닙니다.

Zush는 연도별로 묶은 다음 월별로 묶는 것 같은 중첩 폴더 규칙도 지원합니다. 이미 이름을 바꾼 파일은 이름을 다시 바꾸거나 이름 변경 크레딧을 추가로 쓰지 않고도 정리할 수 있습니다. 적용하기 전에 대상 폴더를 검토하세요. 이 별도 작업은 기존 일괄 작업을 처리하며, Monitor 템플릿을 바꿔도 이미 정리된 파일이 소급해서 재정리되지는 않습니다. [AI 폴더 정리](/docs/folder-sorting)는 Mac과 Windows에서 작동합니다.

## 2. Paperless-ngx: 가장 좋은 무료 셀프 호스팅 아카이브

[Paperless-ngx](https://github.com/paperless-ngx/paperless-ngx)는 자체 서버나 NAS에서, 보통 Docker로 운영하는 오픈 소스 문서 관리 시스템(GPL-3.0)입니다. Tesseract로 100개 넘는 언어의 OCR을 수행하고, 원본을 PDF/A 아카이브 사본과 함께 보관하며, 머신러닝으로 태그, 거래 상대방, 문서 유형을 제안합니다. 이메일에서 문서를 가져오는 것도 가능합니다.

최신 버전에는 기본값이 꺼짐인 선택형 AI 기능이 추가되었습니다. 문서 제안, 문서와의 대화, 유사 문서 검색입니다. 이 기능은 Ollama를 통해 로컬로 실행하거나 OpenAI 호환 API를 통해 실행할 수 있습니다. Paperless는 설정 가능한 형식으로 파일명과 폴더를 직접 관리합니다.

셀프 호스팅이 익숙하고 가정이나 소규모 사무실을 위한 검색 가능한 종이 문서 아카이브를 원한다면 Paperless-ngx를 고르세요. 파일을 기존 폴더 구조에 그대로 두고 싶다면 건너뛰세요.

## 3. DEVONthink: Mac에서 가장 좋은 문서 데이터베이스

[DEVONthink](https://www.devontechnologies.com/apps/devonthink)는 문서를 저장, 검색, 분류하는 오래된 Mac 앱입니다. 버전 4.4.2는 macOS Ventura 이상이 필요합니다. 모든 에디션이 이전에 정리해 둔 방식을 바탕으로 문서를 그룹으로 분류할 수 있습니다. Pro와 Server는 OCR이 포함된 스캐너 연동과 채팅, 요약, 태그 지정, 스마트 규칙 일괄 처리 같은 생성형 AI 기능을 추가합니다. 지원 모델에는 ChatGPT, Claude, Mistral이 있고, Ollama나 LM Studio를 통한 로컬 모델도 쓸 수 있습니다.

Standard는 $99, Pro는 $199, Server는 $499이며 세금 별도입니다. 모두 2개 좌석과 1년간의 업데이트가 포함됩니다.

Mac에서 연구용 수준의 문서 라이브러리를 원하고 문서를 그 안에 보관해도 괜찮다면 DEVONthink를 고르세요. 서류의 이름을 짓고 정리하는 용도로만 쓰기에는 대부분의 사람에게 과합니다.

## 4. NameQuick: 조건부 규칙을 갖춘 Mac 이름 변경 도구

[NameQuick](https://www.namequick.app/)은 Mac에서 반복적으로 생기는 PDF, 스캔본, 영수증, 청구서, 계약서, Word 문서, 스프레드시트에 초점을 맞춥니다. Presets로 내용에 따라 이름을 바꾸고, 폴더를 감시하며, 이름을 지은 뒤 파일을 이동하거나 태그를 달거나 보관하는 조건부 Rules를 실행할 수 있습니다.

![날짜와 거래처 이름이 붙어 이름이 바뀐 스캔 청구서, 영수증, 계약서를 보여주는 NameQuick 홍보 이미지](/images/blog/competitors/namequick.webp)

관리형 플랜은 이름 변경 500회에 월 $12부터 시작해 10,000회에 월 $99까지 있습니다. $69짜리 Self-Managed 라이선스는 직접 준비한 API 키나 로컬 모델이 필요합니다.

if/then 규칙을 기반으로 한 Mac 전용 문서 워크플로가 필요하다면 NameQuick을 고르세요. 전체 비교: [Zush vs NameQuick](/blog/zush-vs-namequick).

## 5. Wisfile: PDF와 Word를 위한 무료 로컬 이름 변경 도구

[Wisfile](https://www.wisfile.ai/)은 무료이며 Mac과 Windows에서 로컬로 실행됩니다. PDF와 Word 문서의 내용을 읽어 이름을 바꾸며, 예를 들어 연구 논문에는 `Author-Year-Title` 같은 이름을 붙이고, 파일을 주제별 폴더로 묶을 수 있습니다.

![무작위 PDF 이름이 날짜와 설명이 담긴 문서 파일명으로 바뀌는 Wisfile 자체 일러스트](/images/blog/competitors/wisfile.webp)

FAQ에 따르면 폴더 감시, 예약 실행, 내장 되돌리기 기능이 없습니다. 예산 없이 문서 아카이브를 한 번 정리하려면 Wisfile을 고르세요. 자세한 내용: [Zush vs Wisfile](/blog/zush-vs-wisfile).

## 6. File Juggler: Windows에서 예측 가능한 문서를 위한 규칙

[File Juggler](https://www.filejuggler.com/)는 AI는 아니지만, 항상 같은 모양을 한 문서를 분류하는 믿을 만한 방법입니다. 규칙으로 PDF, Word, Excel 파일 안의 단어를 찾고, 텍스트에서 찾은 날짜를 재사용한 뒤 파일 이름을 바꾸고 이동할 수 있습니다. 별도의 OCR 없이는 이미지 전용 스캔을 읽지 못합니다.

가격은 세금 별도 1회 결제 $50이며, 30일 전체 체험판이 있습니다. 같은 유형의 모든 문서가 동일한 레이아웃을 따를 때 고르세요. 그렇지 않다면 [File Juggler 대안](/blog/file-juggler-alternatives)을 보세요.

## 어떤 도구가 내 문서에 맞을까요?

- 공유 폴더의 청구서, 영수증, 계약서: **Zush**.
- 가정이나 사무실용 검색 가능한 아카이브이며 셀프 호스팅이 가능한 경우: **Paperless-ngx**.
- Mac의 연구용 라이브러리: **DEVONthink**.
- Mac 전용이며 이름을 바꾼 뒤 규칙을 적용하려는 경우: **NameQuick**.
- 연구 논문을 한 번만 무료로 정리하려는 경우: **Wisfile**.
- Windows에서 동일한 형태의 문서를 AI 없이 처리하려는 경우: **File Juggler**.

명명 패턴이 담긴 업종별 가이드: [세무 서류 정리하기](/blog/how-to-organize-tax-documents), [법률 파일 명명 규칙](/blog/legal-file-naming-conventions), [소규모 병원에서 스캔한 의료 기록 정리하기](/blog/how-to-organize-scanned-medical-records-small-practice).

## 실제 문서 15개로 테스트하기

테스트 폴더에 문서 15개를 복사하세요. 청구서나 영수증 5개, 텍스트 레이어가 없는 스캔본 3개, 계약서 2개, 스프레드시트 2개, Word 파일 1개, 은행 명세서 1개, 손글씨 메모 사진 1장입니다. 그런 다음 확인하세요.

1. 도구가 스캔본을 읽었나요, 건너뛰었나요?
2. 이름에 날짜, 회사, 금액처럼 내가 검색할 때 쓰는 항목이 들어 있나요?
3. 모든 변경을 먼저 검토하고 나중에 되돌릴 수 있었나요?
4. 다른 모든 사람이 같은 공유 폴더에서 파일을 여전히 열 수 있나요?

## 자주 묻는 질문

### 가장 좋은 AI 문서 정리 도구는 무엇인가요?

Mac이나 Windows의 일반 폴더에 그대로 두어야 하는 문서라면 Zush입니다. 미리보기와 되돌리기를 제공하면서 PDF, 스캔본, Office 파일을 내용 기준으로 이름 짓고 정리하기 때문입니다. 셀프 호스팅 아카이브를 원한다면 Paperless-ngx가 가장 좋은 무료 선택지입니다.

### 무료 AI 문서 정리 도구가 있나요?

네. Paperless-ngx는 무료 오픈 소스이지만 서버가 필요합니다. Wisfile은 Mac과 Windows에서 PDF와 Word 문서에 무료로 쓸 수 있습니다. Zush에는 무료 AI 이름 변경 50회가 포함되어 있습니다.

### AI 문서 정리 도구가 스캔한 PDF를 읽을 수 있나요?

Zush는 이미지 전용 스캔을 바로 읽습니다. Paperless-ngx와 DEVONthink Pro는 OCR을 실행합니다. File Juggler는 먼저 별도의 OCR 단계가 필요합니다.

### 문서를 업로드하지 않고 AI로 정리할 수 있나요?

네. Ollama나 LM Studio를 쓰는 Zush, Wisfile, 로컬 Ollama 백엔드를 쓰는 Paperless-ngx, 로컬 모델을 쓰는 DEVONthink는 모두 문서를 내 하드웨어에 그대로 둡니다.
