Windows 11에서는 보기와 검색에 Microsoft Photos, 얼굴과 태그를 사용하는 무료 보관함에 digiKam, 편집과 카탈로그에 Lightroom Classic이 적합합니다. 일반 폴더에서는 Zush가 지원 사진의 이름과 내용별 폴더 분류를 제안합니다. 적용 전에 AI 분류 결과를 확인하세요.

## 사진 보관함과 일반 파일의 차이

보관함은 앨범, 얼굴, 평가, 검색을 자체 데이터베이스로 관리합니다. 파일 이름과 실제 폴더는 파일 시스템, 외장 드라이브, 공유 위치에서도 보입니다. Zush는 파일을 정리하며 앨범, 얼굴 인식, 중복 검토, 백업을 대체하지 않습니다.

## 1. Microsoft Photos

Microsoft Photos는 Windows에서 간단히 사진을 보고 관리하기에 적합합니다. 설명문 기반 AI 검색은 Copilot+ PC가 필요합니다. 고급 태그, 얼굴 인식, 전문 RAW 카탈로그가 필요하면 전용 도구를 비교하세요.

**Folders** 창에서 두 번째 드라이브나 카메라 가져오기 폴더처럼 Photos에 표시할 폴더를 추가할 수 있습니다. 여기서 폴더를 제거해도 Photos에서 숨겨질 뿐 아무것도 삭제되지 않습니다. 하트 아이콘으로 마음에 드는 사진을 즐겨찾기에 모을 수 있습니다. 검색은 모든 PC에서 파일 이름, 촬영 날짜, 파일 형식으로 할 수 있고, 위치 기반 기능을 허용하면 장소로도 찾을 수 있습니다. Copilot+ PC에서는 설명으로 찾는 검색이 추가됩니다.

할 수 없는 일: 파일 이름 변경, 내용에 따라 사진을 폴더로 옮기기, 메타데이터 일괄 편집. 디스크의 파일 이름은 `IMG_4382.jpg` 그대로라서, Photos에서 찾은 사진도 파일 탐색기나 백업 드라이브, 공유 폴더에서는 여전히 찾기 어렵습니다.

[Microsoft Photos](https://support.microsoft.com/en-us/windows/apps/photos/search-photos).

## 2. digiKam

digiKam은 대규모 컬렉션에 앨범, 태그, 평점, 얼굴 인식을 무료로 제공합니다. 단순한 뷰어보다 본격적인 보관함 관리 기능을 갖춥니다. 이전하기 전에 가져오기, 메타데이터, 데이터베이스 백업을 시험하세요.

digiKam.

## 3. Lightroom Classic

Lightroom은 편집, 평점, 앨범, 검색을 클라우드 동기화 보관함에 결합합니다. Lightroom Classic은 파일 제어가 더 자유로운 데스크톱 카탈로그를 사용합니다. 대량으로 가져오기 전에 방식을 선택하고 구독 비용을 고려하세요.

Lightroom Classic.

## 4. XnView MP

XnView MP는 빠른 보기, 메타데이터 확인, 일괄 변환에 적합합니다. 개인 및 교육용은 무료지만 상업용에는 라이선스가 필요합니다. 여러 기기 간 보관함이나 고급 RAW 편집에는 다른 도구가 더 적합합니다.

XnView MP.

## 5. Mylio Photos

Mylio는 컴퓨터, 휴대기기, 드라이브의 사진과 동영상을 하나로 모읍니다. 로컬 분석과 기기 간 동기화는 개인 아카이브에 유용합니다. 최적화된 미리보기는 원본을 대체하지 않으므로 저장 공간과 백업 계획을 마련하세요.

Mylio Photos.

## 6. Zush

내용 기반 이름과 선택적 AI 폴더 그룹.

Zush 폴더 분류는 Mac과 Windows에서 사용할 수 있습니다. 지원 파일의 내용을 분석해 이름과 그룹을 제안합니다. Auto를 쓰려면 Folder rules를 비우고, 직접 정하려면 자연어로 지시하세요. 파일 이름 형식은 Naming Blocks에서 별도로 설정합니다.

내보낸 이미지나 복사 폴더로 시험하세요. Photos 보관함 패키지 내부를 재배치하지 마세요. 카탈로그에 등록된 원본은 해당 프로그램의 이름 변경 또는 다시 연결 절차를 따르세요. 이름 변경과 이동 모두 파일 경로를 바꿉니다.

Zush 라이선스 하나로 Mac과 Windows를 합해 최대 3대에서 사용할 수 있습니다.

Naming Blocks, Custom AI Blocks, 폴더 규칙을 포함한 [Templates를 내보내고](/docs/template-import-export) 다른 컴퓨터에서 가져올 수 있습니다. 대상 폴더, 접근 권한, AI 연결은 새 컴퓨터에서 다시 설정해야 합니다. 파일 자체가 아닌 설정을 옮기는 기능입니다.

## AI로 파일을 폴더에 분류하기

Zush 폴더 분류는 Mac과 Windows에서 사용할 수 있습니다. 지원 파일의 내용을 분석해 이름과 그룹을 제안합니다. Auto를 쓰려면 Folder rules를 비우고, 직접 정하려면 자연어로 지시하세요. 파일 이름 형식은 Naming Blocks에서 별도로 설정합니다.

> 이미지를 사람, 음식, 풍경 등 주제별로 묶어 주세요.

1. 복사한 작은 묶음을 AI Rename에 추가하고 Template을 선택합니다.
2. + Sort를 켜고 하위 폴더의 루트로 Destination folder를 선택합니다. 별도 대상이 없으면 원본 폴더가 루트입니다.
3. Folder rules에 분류 방법을 적습니다. 대상 안의 적절한 기존 폴더를 쓰려면 Reuse existing folders를 켭니다. 맞는 폴더가 없으면 새로 만들 수 있습니다.
4. 처리를 적용하기 전에 제안된 이름과 그룹을 확인하고 수정합니다.

![Windows용 Zush에서 Rename & sort 적용 전 파일 이름과 폴더 그룹을 미리보기](/images/showcase/windows/folder-sorting-light.webp)

검증한 대상과 규칙을 Template에 저장하세요. Monitor는 감시 폴더 바로 안에 새로 들어오는 파일의 이름과 분류를 처리합니다. 이미 처리한 파일을 소급해 정리하지 않습니다. 분류를 끄고 원래 대상을 선택하면 파일은 현재 폴더에 남습니다.

[AI 폴더 분류 단계별 가이드](/blog/sort-files-into-folders-with-ai-windows) · [폴더 분류 문서](/docs/folder-sorting) · [폴더 규칙 예시 30가지](/blog/ai-folder-sorting-prompts).

Zush는 연도 아래 월을 두는 식의 중첩 폴더 규칙도 지원합니다. 이미 이름을 바꾼 파일은 이름을 다시 변경하거나 추가 이름 변경 크레딧을 쓰지 않고 분류할 수 있습니다. 적용 전에 대상 경로를 확인하세요. 이 작업은 Monitor와 별개이며, Template을 바꿔도 이전 파일을 자동으로 다시 정리하지는 않습니다. [AI 폴더 정리](/docs/folder-sorting)는 Mac과 Windows에서 사용할 수 있습니다.

Microsoft Photos의 설명 기반 검색은 Copilot+ PCs에서 사용할 수 있으며 다른 PC의 검색은 더 기본적입니다. XnView MP는 개인·교육 용도로 무료이며 상업 라이선스는 €29부터입니다. 뷰어가 전체 편집 또는 보관함 작업을 대체하지는 않습니다.

## 어떤 프로그램을 선택할까요?

보관함, 편집, 메타데이터, 고정 규칙, 내용 기반 이름과 폴더 중 필요한 작업으로 선택하세요. Zush는 일반 폴더의 지원 파일에 미리보기와 선택적 그룹 분류를 제공합니다. 카탈로그나 백업을 대체하지 않습니다.

## 전환 전에 복사본으로 시험하기

사진, 스크린샷, RAW, 문서, 모호한 이름이 포함된 작은 복사본부터 시작하세요. 미리보기, 그룹, 메타데이터, 보조 파일, 외장 드라이브, 복구를 확인합니다. 보관함에서는 가져오기, 내보내기, 백업, 카탈로그 복원도 시험하세요. 새 절차가 검증될 때까지 기존 아카이브를 유지하세요.

## 자주 묻는 질문

### Windows 11에 가장 좋은 사진 관리 소프트웨어는 무엇인가요?

용도에 따라 다릅니다. 보기와 공유만 한다면 Microsoft Photos로 충분하고, 얼굴·태그·별점을 갖춘 무료 라이브러리로는 digiKam이 가장 강력하며, RAW 파일도 편집한다면 Lightroom Classic이 맞습니다. 파일 자체에 알기 쉬운 이름과 내용별 폴더가 필요하다면 Zush를 함께 쓰세요.

### Zush는 파일을 실제 폴더로 이동하나요?

예. 선택적인 분류를 켜고 대상, 이름, 그룹을 확인하세요. 현재 위치에서 이름만 바꾸려면 분류를 끄고 원래 대상을 유지합니다.

### 새 파일을 자동으로 분류할 수 있나요?

예. 시험한 Template을 Monitor에 지정합니다. 감시 폴더 바로 안의 새 파일이 대상이며 이미 처리한 파일은 재배치하지 않습니다.

### 기존 폴더와 외장 드라이브를 사용할 수 있나요?

Reuse existing folders는 대상 루트 안의 적합한 폴더를 사용하고 필요하면 새 폴더를 만듭니다. 드라이브와 파일에 접근할 수 있어야 하며 클라우드 파일은 먼저 내려받습니다.

### 파일이 클라우드 AI로 전송되나요?

Zush Cloud AI와 BYOK는 선택한 클라우드 제공자에게 내용을 보냅니다. Ollama와 LM Studio는 지원되는 로컬 분석을 제공합니다. 로컬 분석이 앱의 모든 기능이 오프라인이라는 뜻은 아닙니다.
