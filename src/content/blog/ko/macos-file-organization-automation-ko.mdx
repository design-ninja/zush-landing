## 자동 파일 정리 도구가 먼저 처리해야 할 사항

자주 발생하고 성가신 파일부터 시작하세요. 목표는 첫날부터 대통일 체제를 구축하는 것이 아닙니다. 목표는 한두 가지 반복되는 문제점을 제거하고 결과를 확인한 후 거기에서 확장하는 것입니다.

자동화에 가장 적합한 후보:

- **스크린샷** - macOS에서는 콘텐츠에 대해 아무 것도 알려주지 않는 `Screenshot 2026-03-12 at 10.44.11.png`라는 이름을 지정합니다.
- **다운로드 폴더** - 브라우저 다운로드, 이메일 첨부 파일 및 AirDrop 파일이 일반 이름으로 빠르게 쌓입니다.
- **반복 내보내기** - 매주 동일한 앱의 송장, 은행 명세서, 보고서
- **카메라 사진 수신** - `IMG_4382.HEIC`는 6개월 후에는 유용하지 않습니다.
- **반복적인 문서 덤프** - 고객 결과물, 연구 PDF, 프로젝트 자산

자동화는 유지 관리하지 않는 정교한 시스템을 만드는 것이 아니라 주간 짜증을 제거할 때 가장 효과적입니다.

### 최악의 범죄자를 식별하는 방법

Finder를 열고 다운로드 또는 데스크톱 폴더를 수정 날짜별로 정렬하세요. 최근 50개 파일을 살펴보세요. 안에 무엇이 있는지 알려주는 이름이 몇 개나 있는지 세어 보세요. 대답이 절반 미만인 경우 해당 폴더는 강력한 자동화 후보입니다.

폴더에 있는 파일의 양을 확인할 수도 있습니다. 터미널을 열고 다음을 실행하세요.

```bash
ls -1 ~/Downloads | wc -l
```

숫자가 200보다 높으면 자동화할 가치가 있는 백로그가 있는 것입니다.

## 스마트 폴더: 단계별 설정

스마트 폴더는 파일을 이동하지 않습니다. 검색 기준에 따라 동적으로 파일을 표시합니다. Finder 사이드바에 표시되는 저장된 Spotlight 검색이라고 생각하세요.

폴더 계층 구조를 재구성하지 않고도 흩어져 있는 위치에서 파일을 찾는 데 유용합니다.

### 스마트 폴더를 만드는 방법

1. Finder 열기
2. **Cmd + F**를 누르거나 **파일 > 새 스마트 폴더**로 이동합니다.
3. 오른쪽 상단의 ****버튼을 클릭해 기준을 추가하세요.
4. 조건을 설정하세요(아래 예시 참조)
5. **저장**을 클릭하고 스마트 폴더 이름을 지정하세요.
6. **사이드바에 추가**를 선택하여 계속 액세스할 수 있도록 하세요.
7. `.savedSearch` 파일을 저장할 위치를 선택하세요. (기본값은 괜찮습니다.)

### 가장 유용한 스마트 폴더 기준

| 스마트 폴더 목적 | 설정 기준 |
|---|---|
| 최근 스크린샷 | 종류 = 이미지, 이름에 "스크린샷" 포함, 수정 날짜 = 지난 7일 |
| 디스크를 잡아먹는 대용량 파일 | 파일 크기 > 500MB |
| 최근 PDF | 종류 = PDF, 수정일 = 최근 30일 |
| 검토가 필요한 서류 | 태그 = "검토", 종류 = 문서 |
| 모든 프레젠테이션 | 종류 = 프레젠테이션 |
| 최근 다운로드 | 폴더 = 다운로드, 수정 날짜 = 지난 3일 |

### 고급 스마트 폴더 팁

- 복합 기준(AND/OR 그룹화)을 추가하려면 **옵션**을 누른 상태에서 **+** 버튼을 클릭하세요.
- 파일 확장자, 생성 날짜, 마지막으로 연 날짜 및 기타 수십 개의 메타데이터 필드를 기준으로 필터링할 수 있습니다.
- 스마트 폴더는 실시간으로 업데이트되므로 항상 드라이브의 현재 상태를 반영합니다.
- 외부 드라이브를 포함하여 마운트된 모든 볼륨에서 작동합니다.

스마트 폴더는 아무것도 이동하거나 이름을 바꾸지 않으므로 진정한 자동화가 아닙니다. 그러나 규칙을 적용하기 전에 정리해야 할 사항을 확인할 수 있기 때문에 훌륭한 첫 번째 단계입니다.

## 자동화 및 단축키: 실제 작업 흐름 구축

Automator(및 최신 형제인 Shortcuts)를 사용하면 실제 파일 처리 작업 흐름을 만들 수 있습니다. 끌어서 놓기 인터페이스를 사용하여 파일 이름 바꾸기, 이동, 복사, 크기 조정 및 변환을 수행할 수 있습니다.

### Automator 폴더 작업: 다운로드를 파일 유형별로 자동 정렬

이것은 가장 실용적인 Automator 작업 흐름 중 하나입니다. 다운로드 폴더를 감시하고 확장자에 따라 파일을 하위 폴더로 이동합니다.

**단계별 설정:**

1. **Automator**를 엽니다(Spotlight에서 검색).
2. 문서 유형으로 **폴더 작업**을 선택합니다.
3. 상단에서 **다운로드** 폴더에 "폴더 작업은 추가된 파일 및 폴더 수신"을 설정합니다.
4. **쉘 스크립트 실행** 작업 추가
5. "입력 전달"을 **인수**로 설정합니다.
6. 다음 스크립트를 붙여넣습니다.

```bash
for f in "$@"; do
    ext="${f##*.}"
    ext=$(echo "$ext" | tr '[:upper:]' '[:lower:]')
    case "$ext" in
        pdf)
            dest="$HOME/Documents/PDFs" ;;
        jpg|jpeg|png|heic|webp|gif)
            dest="$HOME/Pictures/Downloads" ;;
        zip|gz|tar|dmg)
            dest="$HOME/Downloads/Archives" ;;
        doc|docx|xlsx|pptx|csv)
            dest="$HOME/Documents/Office" ;;
        *)
            dest="" ;;
    esac
    if [ -n "$dest" ]; then
        mkdir -p "$dest"
        mv "$f" "$dest/"
    fi
done
```

7. "유형별 다운로드 정렬"과 같은 설명이 포함된 이름으로 워크플로를 저장합니다.
8. 이제 폴더 작업이 활성화되었습니다. 다운로드의 새 파일은 자동으로 정렬됩니다.

### 단축키: macOS Ventura+를 위한 더 간단한 대안

macOS Ventura 이상을 사용하는 경우 단축어는 많은 작업에서 Automator를 대체할 수 있습니다. 장점은 더욱 깔끔한 인터페이스와 시스템 트리거와의 긴밀한 통합입니다.

**예: 스크린샷 이름 바꾸기 및 이동**

1. **바로가기**를 엽니다.
2. 새로운 바로가기 만들기
3. 작업 추가: **폴더 내용 가져오기**(스크린샷 폴더로 설정)
4. 작업 추가: 이름에 "스크린샷"이 포함된 **파일 필터링**
5. 작업 추가: `Screenshot-[Date Created]`와 같은 패턴을 사용하여 **파일 이름 바꾸기**
6. 작업 추가: 원하는 대상 폴더로 **파일 이동**
7. 자동으로 실행하려면 **자동화** 탭으로 이동하여 스크린샷 폴더에 파일이 추가될 때 트리거를 생성하세요.

일회성 자동화에는 바로가기가 더 좋습니다. Automator는 셸 스크립트 액세스가 필요한 복잡한 다단계 작업 흐름에 더 좋습니다. Automator 기반 파일 이름 바꾸기에 대한 자세한 내용은 [Automator 파일 이름 바꾸기 가이드](/blog/macos-automator-rename-files-guide)를 참조하세요.

## 복잡한 규칙 기반 라우팅을 위한 Hazel

Hazel은 폴더에 연속적인 다중 조건 규칙, 백그라운드 이동, 태그, 아카이브 또는 스크립트가 필요할 때 유용합니다. 대표적인 규칙은 이름에 `invoice`가 포함된 PDF를 연도 및 월 폴더로 이동하고 비교할 수 없는 다운로드는 그대로 유지할 수 있습니다.

Hazel 및 콘텐츠 인식 이름 지정은 다양한 레이어를 해결합니다. Hazel은 확장자, 날짜, 태그, 파일 이름 패턴 또는 추출된 텍스트가 신뢰할 수 있는 조건을 제공할 때 탁월합니다. AI 이름 지정 도구는 검색 가능한 이름을 받기 전에 스크린샷, 사진, 비디오 또는 일반 스캔을 이해해야 할 때 더 유용합니다.

순서를 명시적으로 유지하세요. 먼저 이름을 바꾼 다음 결과 파일 이름을 라우팅하세요. 두 도구가 동시에 동일한 섭취 폴더를 관찰하고 변경하지 않도록 하십시오. 기능별 제품 비교는 [Hazel 대안으로 사용되는 Zush](/hazel-alternative)를 참조하세요.

## 규칙 기반 자동화가 실패하는 경우

파일이 이름, 확장자 또는 메타데이터를 통해 파일 내용을 이미 알려줄 때 규칙이 작동합니다.

파일이 다음과 같이 도착하면 실패합니다.

- `IMG_4382.HEIC`
- `Screenshot 2026-03-12 at 10.44.11.png`
- `download (7).jpg`
- `Document.pdf`
- `Untitled.png`
- `image (3).webp`

규칙은 해당 파일을 특정 폴더로 이동할 수 있습니다. 그 안에 무엇이 들어 있는지 설명할 수 없습니다. 그리고 설명적인 이름이 없으면 폴더에 완벽하게 정리되어 있어도 나중에 찾을 수 없습니다.

이것이 바로 AI 기반 명명이 유용해지는 곳입니다. 이미지의 실제 픽셀, 비디오의 샘플링된 프레임, PDF의 텍스트, 문서의 레이아웃 등 파일 콘텐츠를 분석하는 도구는 파일이 실제로 무엇인지 설명하는 이름을 생성할 수 있습니다.

AI 파일 이름 바꾸기가 실제로 어떻게 작동하는지에 대한 자세한 내용은 [Mac 및 Windows에 대한 파일 이름 바꾸기](/)를 참조하세요.

## 권장되는 자동 파일 구성 도우미 설정: 단계별

위의 도구를 하나의 일관된 시스템으로 결합하여 한 시간 안에 구축할 수 있는 실용적인 설정은 다음과 같습니다. 이는 노력과 결과의 균형을 맞추는 접근 방식입니다.

### 1단계: 현재 혼란스러운 상황을 감사하세요.

다운로드, 데스크탑, 문서 폴더를 엽니다. 쓸모없는 이름을 가진 파일이 가장 많은 폴더를 확인하십시오. 상위 2개의 문제 폴더를 선택하세요.

### 2단계: 가시성을 위해 스마트 폴더 만들기

Finder에서 세 개의 스마트 폴더 설정:

1. **최근 대용량 파일** -- 파일 크기 > 100MB, 수정 날짜 = 지난 30일
2. **정렬되지 않은 스크린샷** -- 종류 = 이미지, 이름에 "스크린샷" 포함, 수정 날짜 = 지난 14일
3. **최근 문서** -- 종류 = 문서 OR 종류 = PDF, 수정 날짜 = 지난 7일

이를 통해 주의가 필요한 사항을 즉시 확인할 수 있습니다.

### 3단계: 기본 파일 라우팅 설정

선호도에 따라 다음 옵션 중 하나를 선택하세요.

**옵션 A: 자동화 폴더 작업**(무료, 내장)
- 위에서 설명한 다운로드 정렬 작업 흐름을 만듭니다.
- 10분 정도 소요, 가장 일반적인 파일 형식 처리

**옵션 B: 헤이즐 규칙**(유료, 더 강력함)
- Hazel을 설치하고 다운로드 폴더에 대한 3~5개의 규칙을 설정하세요.
- 초점: PDF를 문서로, 이미지를 사진으로, 아카이브를 전용 폴더로
- 30일이 지난 파일에 대한 정리 규칙 추가

**옵션 C: 바로가기 자동화**(무료, macOS Ventura+)
- 유형별로 파일을 정렬하는 바로가기 만들기
- 일정에 따라 또는 수동으로 실행되도록 설정

### 4단계: 시각적 파일에 대한 AI 이름 변경 추가

![데스크탑 폴더가 선택된 폴더 모니터링 구성을 보여주는 Zush 모니터 탭](/images/showcase/macos/monitor-light.webp)

[Mac의 경우 Zush](/mac)를 설치하고 스크린샷 폴더와 다운로드 폴더를 모니터링하도록 설정하세요. 이는 규칙 기반 도구가 제대로 이름을 지정할 수 없는 파일을 처리합니다.

- 표시되는 앱과 콘텐츠에 따라 스크린샷 이름이 변경됩니다.
- PDF는 텍스트 내용에 따라 이름이 변경됩니다.
- 이미지 내용에 따라 사진 이름이 변경됩니다.
- 다운로드한 이미지는 `download (7).jpg` 대신 설명이 포함된 이름을 갖습니다.

### 5단계: 주간 검토 설정

자동화하더라도 일주일에 한 번 5분씩 스마트 폴더를 살펴보세요. 이는 극단적인 경우를 파악하고 시간이 지남에 따라 규칙을 구체화하는 데 도움이 됩니다.

### 6단계: 점진적으로 확장

이 설정을 일주일 동안 실행한 후에도 여전히 균열이 발생하는 것을 살펴보세요. 필요에 따라 새로운 Hazel 규칙이나 스마트 폴더를 추가합니다. 모든 엣지 케이스를 전면적으로 덮으려고 하지 마십시오.

## 비교: 어떤 작업에 어떤 도구가 사용되는지

| 작업 | 최고의 도구 | 왜 |
|---|---|---|
| 파일을 이동하지 않고 찾기 | 스마트 폴더 | 가상, 구조 조정 필요 없음 |
| 유형별로 파일을 폴더로 정렬 | 자동화 또는 헤이즐 | 확장 기반 규칙은 간단합니다 |
| 오래된 파일을 자동으로 보관 | 헤이젤 | 백그라운드 모니터링을 통한 날짜 기반 조건 |
| 설명적으로 스크린샷 이름 바꾸기 | Zush(AI) | 이미지 분석을 통한 내용 인식 명명 |

일괄 이름 변경 방법에 대한 자세한 비교는 [Mac 일괄 이름 바꾸기 방법 가이드](/blog/batch-rename-files-on-mac-complete-guide)를 참조하세요. AI 기반 고유 이름(공유 접두사 아님)이 필요하다는 것을 이미 알고 있다면 [Mac의 일괄 이름 바꾸기 도구](/mac)가 가장 짧은 경로입니다. 50번의 무료 이름 변경, 가입 불필요.

## 피해야 할 일반적인 실수

**너무 일찍 과도하게 자동화되었습니다.** 실제로 라우팅이 필요한 파일을 알기 전에는 20개 규칙 Hazel 설정을 구축하지 마세요. 2~3개의 규칙으로 시작하여 확장하세요.

**이름 지정 문제는 무시합니다.** 모든 파일 이름이 `IMG_4382.HEIC`인 경우 파일을 깔끔한 폴더로 이동하는 것은 도움이 되지 않습니다. 필요한 파일을 찾으려면 각 파일을 열어야 합니다. 이름 바꾸기는 적어도 정렬만큼 중요합니다.

**규칙을 테스트하지 않습니다.** 실제 다운로드 폴더에서 폴더 작업 또는 Hazel 규칙을 활성화하기 전에 샘플 파일이 있는 더미 폴더에서 테스트하세요. 하나의 잘못된 이동 규칙으로 인해 파일이 드라이브 전체에 분산될 수 있습니다.

**중첩 폴더는 잊어버리세요.** 대부분의 자동화 도구는 기본적으로 단일 폴더 수준을 감시합니다. 파일이 하위 폴더 내에 있는 경우 재귀 모니터링을 명시적으로 구성해야 합니다.

**롤백 계획 없음.** 파일 이름을 바꾸거나 파일을 이동하는 자동화에는 실행 취소 경로가 있어야 합니다. Hazel은 로그를 유지합니다. Zush는 롤백을 지원합니다. Automator는 그렇지 않습니다. 따라서 파괴적인 행동에 주의하십시오.

## FAQ

### 아무것도 설치하지 않고 Mac에서 파일 정리를 자동화하려면 어떻게 해야 하나요?

파일 표시를 위한 스마트 폴더, 파일 라우팅을 위한 Automator 또는 바로가기 등 내장된 도구를 사용하세요. 스마트 폴더는 Finder의 파일 > 새 스마트 폴더에 있습니다. Automator는 파일이 특정 디렉토리에 있을 때 트리거되는 폴더 작업을 생성할 수 있습니다. 여기에는 타사 소프트웨어 없이 파일 유형, 날짜 및 이름 패턴을 기준으로 하는 기본 정렬이 포함됩니다.

### macOS에서 Automator와 바로가기의 차이점은 무엇인가요?

Automator는 더 많은 작업 유형, 셸 스크립트 지원 및 폴더 작업 통합을 갖춘 오래된 도구입니다. 바로가기는 최신 버전(macOS Monterey+)으로 더욱 깔끔한 인터페이스를 갖추고 있으며 시스템 트리거 및 Siri 통합을 지원합니다. 특히 파일 자동화의 경우 Automator는 쉘 스크립트 작업과 더 광범위한 파일 조작 옵션으로 인해 더 많은 기능을 제공합니다. Apple은 천천히 기능을 바로가기로 마이그레이션하고 있으므로 둘 다 알아 둘 가치가 있습니다.

### Hazel은 내용에 따라 파일 이름을 바꿀 수 있나요?

Hazel은 PDF 및 문서 내의 텍스트 내용을 읽고 이를 규칙 이름 변경에 사용할 수 있습니다. 예를 들어 PDF에서 날짜나 키워드를 추출하여 파일 이름에 포함할 수 있습니다. 그러나 Hazel은 이미지나 비디오 콘텐츠를 분석할 수 없습니다. 즉, 비전 기능이 없습니다. 스크린샷, 사진, 화면 녹화 및 기타 시각적 파일의 경우 파일 내용을 실제로 볼 수 있는 AI 기반 도구가 필요합니다.

### 다운로드 폴더가 복잡해지는 것을 방지하려면 어떻게 해야 하나요?

2계층 시스템을 구축합니다. 먼저, 파일이 도착하면 유형별 폴더로 파일을 이동하는 라우팅 규칙(Automator 또는 Hazel을 통해)을 만듭니다. 둘째, 30일이 지난 파일을 보관 폴더나 휴지통으로 이동하는 정리 규칙을 추가합니다. 이 조합을 사용하면 중요한 내용을 잃지 않고 다운로드 폴더를 간결하게 유지할 수 있습니다. 자세한 연습은 [다운로드 폴더 정리 가이드](/blog/how-to-organize-downloads-folder-mac)를 참조하세요.

### AI 파일 이름 바꾸기는 안전한가요? 내 파일을 망칠 수 있나요?

AI 이름 바꾸기는 파일 내용이 아닌 파일 이름만 변경합니다. Zush와 같은 훌륭한 도구는 이름 변경 기록도 유지하므로 이름 변경을 즉시 롤백할 수 있습니다. 위험은 낮지만 항상 작은 배치에서 먼저 테스트하고 대용량 디렉터리에서 폴더 모니터링을 활성화하기 전에 이름 지정 품질을 확인해야 합니다.

### 사진 파일 정리를 구체적으로 자동화하려면 어떻게 해야 하나요?

사진의 원래 이름(`IMG_`, `DSC_`, `DCIM`)에는 콘텐츠에 대한 정보가 전혀 없기 때문에 사진에는 고유한 문제가 있습니다. 가장 좋은 접근 방식은 AI 이름을 변경하여 설명적인 이름을 추가하고 날짜 또는 이벤트별로 폴더를 정렬하는 것입니다. 사진별 작업 흐름은 [Mac의 사진 정리 가이드](/blog/best-ways-to-organize-photos-on-mac)를 참조하세요.

### 여러 자동화 도구를 결합할 수 있나요?

예, 그래야 합니다. 도구는 상호 배타적이지 않습니다. 강력한 설정에서는 가시성을 위해 스마트 폴더를 사용하고 라우팅을 위해 Hazel 또는 Automator를 사용하며 콘텐츠 인식 이름 지정을 위해 AI 이름 변경을 사용합니다. 각 도구는 서로 다른 레이어를 처리합니다. 핵심은 각 계층에서 규칙을 단순하게 유지하여 전체 시스템을 유지 관리할 수 있도록 하는 것입니다.

### 두 자동화 규칙이 충돌하면 어떻게 되나요?

Hazel과 Automator Folder Action이 모두 동일한 폴더를 감시하는 경우 서로 경쟁할 수 있습니다. 결과는 예측할 수 없습니다. 다른 도구가 파일을 처리하기 전에 파일이 이동될 수 있습니다. 해결 방법은 간단합니다. 폴더당 하나의 자동화 도구만 사용하면 됩니다. 라우팅과 이름 바꾸기를 모두 원하는 경우 먼저 이름 바꾸기를 수행한 다음(예: Zush가 파일 이름 바꾸기) 라우팅 도구(Hazel)를 사용하여 새 이름에 따라 이름이 바뀐 파일을 이동하도록 합니다.

## 결론

macOS에서 파일 구성을 효과적으로 자동화하려면 간단한 규칙으로 간단한 결정을 처리하고 AI가 시각적 모호성을 처리하도록 하세요. 이러한 균형은 실제로 유지 관리가 가능한 시스템을 제공합니다.

가시성을 위해 스마트 폴더로 시작하세요. 라우팅을 위해 Automator 또는 Hazel을 추가합니다. 쓸모없는 이름으로 도착하는 파일에 대해 AI 기반 이름 변경을 계층화합니다. 매주 검토하고 점진적으로 확장하세요.

목표는 완벽한 시스템이 아닙니다. 목표는 일주일에 30분이 아닌 5분을 파일 정리에 투자하는 시스템입니다.
