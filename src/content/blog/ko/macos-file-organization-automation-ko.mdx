## 자동 파일 정리 도구로 먼저 해결할 것

자주 생기면서 귀찮은 파일부터 시작하세요. 첫날부터 모든 것을 아우르는 시스템을 만들 필요는 없습니다. 반복되는 불편 한두 가지를 없애고, 결과를 확인한 다음 넓혀 가면 됩니다.

자동화하기 좋은 대상:

- **스크린샷** - macOS는 `Screenshot 2026-03-12 at 10.44.11.png` 같은 이름을 붙이는데, 내용은 전혀 알 수 없습니다
- **다운로드 폴더** - 브라우저 다운로드, 이메일 첨부 파일, AirDrop 파일이 의미 없는 이름으로 금세 쌓입니다
- **반복되는 내보내기 파일** - 매주 같은 앱에서 나오는 청구서, 은행 거래 내역서, 보고서
- **카메라에서 가져온 사진** - `IMG_4382.HEIC`는 6개월 뒤에 아무 도움이 되지 않습니다
- **한꺼번에 쏟아지는 문서** - 고객 납품물, 리서치 PDF, 프로젝트 자료

자동화는 정작 관리하지 않게 되는 복잡한 시스템을 만들 때보다, 매주 겪는 짜증 하나를 없앨 때 가장 효과가 큽니다.

### 가장 문제가 큰 폴더 찾기

Finder에서 다운로드나 데스크탑 폴더를 수정일 순으로 정렬하세요. 최근 파일 50개를 보면서 이름만으로 내용을 알 수 있는 파일이 몇 개인지 세어 봅니다. 절반이 안 된다면 그 폴더는 자동화할 가치가 충분합니다.

폴더에 쌓이는 파일 수를 확인하는 방법도 있습니다. 터미널을 열고 다음을 실행하세요.

```bash
ls -1 ~/Downloads | wc -l
```

200개가 넘는다면 자동화로 정리할 만큼 밀려 있는 상태입니다.

## 뒤섞인 파일을 AI로 폴더에 분류하기

[Zush AI 파일 분류](/ai-file-sorter)는 지원하는 파일에 알아보기 쉬운 이름을 붙이고, 같은 묶음 안에서 내용에 따라 실제 폴더로 나눌 수 있습니다. **AI 폴더 분류는 Mac과 Windows에서 모두 동작합니다.** Auto로 묶으려면 **Folder rules**를 비워 두고, 직접 정하려면 평범한 문장으로 적으세요. 뒤섞인 파일이라면 이렇게 써 볼 수 있습니다.

> 청구서는 회사별로, 영수증은 월별로 묶어 줘.

1. 복사해 둔 작은 묶음을 **AI Rename**에 추가하고 Template을 고릅니다.
2. **+ Sort**를 켜고 **Destination folder**를 고릅니다. 여기가 분류된 하위 폴더들의 기준 위치입니다. 따로 지정하지 않으면 원본 폴더가 기준이 됩니다.
3. **Folder rules**에 묶는 방법을 적습니다. 파일 이름 형식은 **Naming Blocks**에서 따로 정합니다.
4. 기준 위치 안에 알맞은 폴더가 이미 있다면 **Reuse existing folders**를 켭니다. 맞는 폴더가 없으면 Zush가 새로 만들 수 있습니다.
5. 제안된 이름과 폴더 그룹을 모두 확인합니다. 적용하기 전에 폴더 이름이나 파일 위치를 고치세요.

![Rename & sort 전에 내용 기반 폴더 그룹과 제안된 파일 이름을 미리 보여 주는 Mac용 Zush](/images/showcase/macos/folder-sorting-light.webp)

시험을 마친 대상 폴더와 규칙은 Template에 저장하세요. 그 Template을 **Monitor**에 지정하면 감시 폴더 바로 아래로 새로 들어오는 파일의 이름을 바꾸고 분류합니다. 이미 처리한 파일을 거슬러 올라가 다시 정리하지는 않습니다. 분류를 끄고 원래 대상을 선택해 두면 파일은 지금 있는 폴더에 그대로 남습니다.

자세한 방법은 [Mac 분류 단계별 가이드](/blog/sort-files-into-folders-with-ai-mac)를 따라 하거나 [폴더 분류 문서](/docs/folder-sorting)와 [Folder rules 예시 30개](/blog/ai-folder-sorting-prompts)를 참고하세요.

## Smart Folders 단계별 설정

Smart Folders는 파일을 옮기지 않습니다. 검색 조건에 맞는 파일을 그때그때 모아 보여 줄 뿐입니다. Finder 사이드바에 걸어 두는 저장된 Spotlight 검색이라고 생각하면 됩니다.

폴더 구조를 바꾸지 않고 여기저기 흩어진 파일을 찾을 때 유용합니다.

### Smart Folder 만들기

1. Finder를 엽니다
2. **Cmd + F**를 누르거나 **파일 > 새로운 스마트 폴더**를 선택합니다
3. 오른쪽 위의 **+** 버튼을 눌러 조건을 추가합니다
4. 조건을 설정합니다(아래 예시 참고)
5. **저장**을 누르고 Smart Folder 이름을 정합니다
6. 언제든 열 수 있도록 **사이드바에 추가**를 체크합니다
7. `.savedSearch` 파일을 저장할 위치를 고릅니다(기본 위치도 괜찮습니다)

### 쓸모 있는 Smart Folder 조건

| 용도 | 설정할 조건 |
|---|---|
| 최근 스크린샷 | 종류 = 이미지, 이름에 "Screenshot" 포함, 수정일 = 최근 7일 |
| 디스크를 차지하는 대용량 파일 | 파일 크기 > 500 MB |
| 최근 PDF | 종류 = PDF, 수정일 = 최근 30일 |
| 검토할 문서 | 태그 = "검토", 종류 = 문서 |
| 모든 프레젠테이션 | 종류 = 프레젠테이션 |
| 최근 다운로드 | 폴더 = 다운로드, 수정일 = 최근 3일 |

### Smart Folders 활용 팁

- **Option** 키를 누른 채 **+** 버튼을 누르면 AND/OR로 묶인 복합 조건을 추가할 수 있습니다
- 파일 확장자, 생성일, 마지막으로 연 날짜를 비롯해 수십 가지 메타데이터로 걸러낼 수 있습니다
- Smart Folders는 실시간으로 갱신되므로 항상 드라이브의 현재 상태를 보여 줍니다
- 외장 드라이브를 포함해 연결된 모든 볼륨에서 동작합니다

Smart Folders는 아무것도 옮기거나 이름을 바꾸지 않으니 엄밀히 말해 자동화는 아닙니다. 그래도 규칙을 정하기 전에 무엇을 정리해야 하는지 볼 수 있어서 첫 단계로 아주 좋습니다.

더 자세한 내용은 [macOS 파일 검색 활용 가이드](/blog/finder-tags-guide-organize-files-mac)를 보세요.

## Automator와 Shortcuts로 실제 작업 흐름 만들기

Automator와 그 후속작인 Shortcuts로는 실제로 파일을 처리하는 작업 흐름을 만들 수 있습니다. 끌어다 놓는 방식으로 파일 이름 변경, 이동, 복사, 크기 조절, 변환을 처리합니다.

### Automator 폴더 동작: 다운로드를 파일 형식별로 자동 분류

가장 실용적인 Automator 작업 흐름 중 하나입니다. 다운로드 폴더를 감시하다가 확장자에 따라 파일을 하위 폴더로 옮깁니다.

**단계별 설정:**

1. **Automator**를 엽니다(Spotlight에서 검색)
2. 문서 유형으로 **폴더 동작**을 선택합니다
3. 상단의 "폴더 동작이 다음에 추가된 파일 및 폴더를 수신" 항목을 **다운로드** 폴더로 지정합니다
4. **셸 스크립트 실행** 동작을 추가합니다
5. "입력 전달"을 **인수로**로 설정합니다
6. 다음 스크립트를 붙여 넣습니다

```bash
for f in "$@"; do
    ext="${f##*.}"
    ext=$(echo "$ext" | tr '[:upper:]' '[:lower:]')
    case "$ext" in
        pdf)
            dest="$HOME/Documents/PDFs" ;;
        jpg|jpeg|png|heic|webp|gif)
            dest="$HOME/Pictures/Downloads" ;;
        zip|gz|tar|dmg)
            dest="$HOME/Downloads/Archives" ;;
        doc|docx|xlsx|pptx|csv)
            dest="$HOME/Documents/Office" ;;
        *)
            dest="" ;;
    esac
    if [ -n "$dest" ]; then
        mkdir -p "$dest"
        mv "$f" "$dest/"
    fi
done
```

7. "다운로드 형식별 분류"처럼 알아보기 쉬운 이름으로 작업 흐름을 저장합니다
8. 이제 폴더 동작이 켜졌습니다. 다운로드 폴더에 들어오는 새 파일은 자동으로 분류됩니다.

### Shortcuts: macOS Ventura 이상에서 더 간단한 대안

macOS Ventura 이상이라면 많은 작업에서 Shortcuts가 Automator를 대신할 수 있습니다. 인터페이스가 더 깔끔하고 시스템 트리거와 더 잘 연동된다는 장점이 있습니다.

**예시: 스크린샷 이름을 바꾸고 옮기기**

1. **Shortcuts**를 엽니다
2. 새 단축어를 만듭니다
3. **폴더 내용 가져오기** 동작을 추가하고 스크린샷 폴더를 지정합니다
4. **파일 필터** 동작을 추가해 이름에 "Screenshot"이 포함된 파일만 남깁니다
5. **파일 이름 변경** 동작을 추가하고 `Screenshot-[Date Created]` 같은 패턴을 씁니다
6. **파일 이동** 동작을 추가해 원하는 대상 폴더로 옮깁니다
7. 자동으로 실행하려면 **자동화** 탭에서 스크린샷 폴더에 파일이 추가될 때 실행되는 트리거를 만듭니다

가끔 한 번씩 돌리는 자동화에는 Shortcuts가, 셸 스크립트가 필요한 여러 단계짜리 작업 흐름에는 Automator가 낫습니다. Automator로 파일 이름을 바꾸는 방법은 [Automator 파일 이름 변경 가이드](/blog/macos-automator-rename-files-guide)에 자세히 정리했습니다.


## 스크립트와 보관에는 Hazel

Hazel은 보관, 스크립트 실행, 업로드처럼 Zush에 없는 동작이 들어간 다중 조건 규칙을 폴더에 계속 걸어 두어야 할 때 유용합니다. 청구서 PDF를 연도와 월 폴더로 옮기기만 하는 규칙이라면 이제 Hazel이 필요 없습니다. Zush에서 "청구서를 연도와 월 폴더에 넣기" 같은 Folder rules 한 줄로 같은 일을 할 수 있고, 파일 이름이 `scan0043.pdf`여도 청구서임을 알아봅니다.

Hazel은 확장자, 날짜, 태그, 파일 이름 패턴, 추출한 텍스트가 확실한 조건이 될 때 잘 동작합니다. Zush도 같은 정보를 씁니다. 날짜와 확장자 Naming Blocks가 있고, Monitor에서 파일 형식이나 이름 앞부분으로 걸러낼 수 있습니다. 여기에 더해 스크린샷, 사진, 동영상, 특징 없는 스캔본의 내용을 이해한 뒤 이름을 붙이거나 폴더에 넣습니다.

두 도구를 함께 쓴다면 각각 다른 폴더를 맡기세요. 같은 수신 폴더를 두 도구가 동시에 감시하며 바꾸게 두면 안 됩니다. 기능별로 비교한 내용은 [Hazel 대안으로서의 Zush](/hazel-alternative)를 보세요.

## 규칙 기반 자동화가 통하지 않는 경우

규칙은 파일이 이름, 확장자, 메타데이터로 이미 정체를 드러낼 때 통합니다.

다음처럼 들어오는 파일에는 통하지 않습니다.

- `IMG_4382.HEIC`
- `Screenshot 2026-03-12 at 10.44.11.png`
- `download (7).jpg`
- `Document.pdf`
- `Untitled.png`
- `image (3).webp`

규칙으로 이런 파일을 특정 폴더로 옮길 수는 있습니다. 하지만 무엇이 들어 있는지는 알려 줄 수 없습니다. 그리고 내용을 설명하는 이름이 없으면 폴더에 완벽하게 정리돼 있어도 나중에 찾지 못합니다.

AI 이름 짓기가 쓸모 있는 지점이 바로 여기입니다. 이미지의 실제 픽셀, 동영상에서 뽑은 프레임, PDF의 텍스트, 문서의 레이아웃 같은 파일 내용을 분석하는 도구는 파일이 실제로 무엇인지 설명하는 이름을 만들어 냅니다.

AI 파일 이름 변경이 실제로 어떻게 동작하는지는 [Mac과 Windows용 파일 이름 변경 도구](/)에서 확인하세요.

## 추천 자동 파일 정리 설정 단계별 안내

위 도구들을 하나의 일관된 시스템으로 묶어, 한 시간 안에 만들 수 있는 실용적인 설정입니다. 들이는 노력과 얻는 결과 사이의 균형이 가장 좋은 방법입니다.

### 1단계: 지금 얼마나 어질러져 있는지 점검하기

다운로드, 데스크탑, 문서 폴더를 엽니다. 쓸모없는 이름이 붙은 파일이 가장 많은 폴더를 적어 두고, 그중 문제가 큰 폴더 두 개를 고릅니다.

### 2단계: Zush 이름과 선택형 폴더 그룹 미리 보기

[Mac용 AI 파일 이름 변경 도구](/mac)를 설치하고, 복사해 둔 수신 폴더를 지정한 다음 Template을 골라 처음 제안된 이름을 검토합니다. 지속 감시를 켜기 전에 Rename History로 되돌릴 수 있는 상태인지 확인하세요.

### 3단계: 필요하면 한눈에 보기 위한 Smart Folders 만들기

Finder에서 Smart Folders 세 개를 만듭니다.

1. **최근 대용량 파일** -- 파일 크기 > 100 MB, 수정일 = 최근 30일
2. **정리 안 된 스크린샷** -- 종류 = 이미지, 이름에 "Screenshot" 포함, 수정일 = 최근 14일
3. **최근 문서** -- 종류 = 문서 OR 종류 = PDF, 수정일 = 최근 7일

이렇게 하면 손봐야 할 파일이 바로 눈에 들어옵니다.

### 4단계: 필요하면 기본 파일 분류 설정하기

원하는 방식에 맞춰 하나를 고르세요.

**옵션 A: Automator 폴더 동작**(무료, 기본 내장)
- 위에서 설명한 다운로드 분류 작업 흐름을 만듭니다
- 10분이면 끝나고, 가장 흔한 파일 형식을 처리합니다

**옵션 B: Hazel 규칙**(유료, 더 강력함)
- Hazel을 설치하고 다운로드 폴더에 규칙 3~5개를 만듭니다
- PDF는 문서로, 이미지는 사진으로, 압축 파일은 전용 폴더로 보내는 데 집중합니다
- 30일이 지난 파일을 치우는 정리 규칙을 추가합니다

**옵션 C: Shortcuts 자동화**(무료, macOS Ventura 이상)
- 파일을 형식별로 분류하는 단축어를 만듭니다
- 일정에 따라 실행하거나 직접 실행하도록 설정합니다

**옵션 D: Zush Folder rules**(Zush에 포함)
- Template에서 Sort를 켜고 "PDF는 문서로, 이미지는 사진으로, 영수증은 월별로"처럼 폴더를 설명합니다
- 그 Template을 Monitor에 지정하면 새로 내려받은 파일이 들어오는 대로 이름이 바뀌고 분류됩니다

### 5단계: 시험이 끝나면 Zush 감시 켜기

![데스크탑 폴더를 선택한 폴더 감시 설정을 보여 주는 Zush Monitor 탭](/images/showcase/macos/monitor-light.webp)

시험 묶음을 확인했다면 Zush가 스크린샷 폴더와 다운로드 폴더를 감시하도록 설정하세요. 규칙 기반 도구로는 제대로 이름을 붙일 수 없는 파일을 처리해 줍니다.

- 스크린샷은 화면에 보이는 앱과 내용에 따라 이름이 바뀝니다
- PDF는 본문 텍스트에 따라 이름이 바뀝니다
- 사진은 찍힌 내용에 따라 이름이 바뀝니다
- 내려받은 이미지는 `download (7).jpg` 대신 내용을 설명하는 이름을 얻습니다

### 6단계: 매주 점검 시간 정하기

자동화를 해 두었더라도 일주일에 한 번 5분 정도 Smart Folders를 훑어보세요. 예외적인 경우를 잡아내고 시간이 지나면서 규칙을 다듬는 데 도움이 됩니다.

### 7단계: 조금씩 넓히기

일주일 동안 써 본 뒤, 여전히 빠져나가는 파일이 무엇인지 살펴보세요. 필요하면 Hazel 규칙이나 Smart Folders를 더합니다. 처음부터 모든 예외를 다 막으려 하지 마세요.


## 비교: 어떤 작업에 어떤 도구를 쓸까

| 작업 | 추천 | 이유 |

| 파일을 옮기지 않고 찾기 | Smart Folders(선택) | 가상 폴더라 구조를 바꿀 필요 없음 |
| 형식이나 날짜에 따라 파일을 폴더로 분류하기 | Zush, Automator, Hazel | Zush는 평범한 문장으로 쓴 폴더 규칙을, Automator와 Hazel은 확장자 규칙을 씀 |
| 오래된 파일 자동 보관 | Hazel | 백그라운드 감시와 날짜 조건 |
| 스크린샷에 내용을 설명하는 이름 붙이기 | Zush(AI) | 이미지 분석으로 내용에 맞는 이름 생성 |
| PDF 이름을 내용에 따라 바꾸기 | Zush(AI) | 문서 텍스트를 읽어 이름 생성 |
| 패턴으로 일괄 이름 변경 | Finder 또는 Automator | 기본 내장된 패턴 치환 |
| 클릭 한 번으로 파일 처리 | Shortcuts | 깔끔한 UI, 공유하기 쉬움 |
| 스크립트나 사용자 지정 동작이 들어간 규칙 | Hazel | macOS에서 가장 강력한 규칙 엔진 |

일괄 이름 변경 방법만 따로 비교한 내용은 [Mac 일괄 이름 변경 방법 가이드](/blog/batch-rename-files-on-mac-complete-guide)를 보세요. 같은 접두어가 아니라 AI로 만든 서로 다른 이름이 필요하다는 것을 이미 알고 있다면 [Mac용 일괄 이름 변경 도구](/mac)가 가장 빠릅니다. 가입 없이 50회 무료로 이름을 바꿀 수 있습니다.

## 흔히 하는 실수

**너무 일찍 너무 많이 자동화하기.** 어떤 파일을 실제로 분류해야 하는지 알기 전에 Hazel 규칙을 20개씩 만들지 마세요. 규칙 2~3개로 시작해 늘려 가세요.

**이름 문제를 무시하기.** 모든 파일 이름이 `IMG_4382.HEIC`라면 깔끔한 폴더로 옮겨 봐야 소용이 없습니다. 원하는 파일을 찾으려면 결국 하나씩 열어 봐야 합니다. 이름 변경은 분류만큼, 혹은 그 이상으로 중요합니다.

**규칙을 시험하지 않기.** 실제 다운로드 폴더에 폴더 동작이나 Hazel 규칙을 켜기 전에, 샘플 파일을 넣은 테스트 폴더에서 먼저 시험하세요. 잘못된 이동 규칙 하나가 파일을 드라이브 곳곳에 흩어 놓을 수 있습니다.

**하위 폴더를 잊기.** 대부분의 자동화 도구는 기본적으로 한 단계 폴더만 감시합니다. 파일이 하위 폴더 안으로 들어온다면 하위 폴더까지 감시하도록 따로 설정해야 합니다.

**되돌릴 방법이 없는 경우.** 파일 이름을 바꾸거나 옮기는 자동화에는 되돌릴 길이 있어야 합니다. Hazel은 로그를 남기고 Zush는 되돌리기를 지원합니다. Automator에는 없으니 되돌릴 수 없는 동작은 조심하세요.

## 자주 묻는 질문

### 아무것도 설치하지 않고 Mac에서 파일 정리를 자동화할 수 있나요?

기본 도구를 쓰면 됩니다. 파일을 모아 보는 데는 Smart Folders를, 파일 분류에는 Automator나 Shortcuts를 쓰세요. Smart Folders는 Finder의 파일 > 새로운 스마트 폴더에 있습니다. Automator로는 특정 폴더에 파일이 들어올 때 실행되는 폴더 동작을 만들 수 있습니다. 서드파티 소프트웨어 없이도 파일 형식, 날짜, 이름 패턴에 따른 기본 분류는 충분히 됩니다.

### macOS에서 Automator와 Shortcuts는 무엇이 다른가요?

Automator는 더 오래된 도구로, 동작 종류가 더 많고 셸 스크립트와 폴더 동작을 지원합니다. Shortcuts는 더 새로운 도구(macOS Monterey 이상)로, 인터페이스가 깔끔하고 시스템 트리거와 Siri 연동을 지원합니다. 파일 자동화만 놓고 보면 셸 스크립트 동작과 폭넓은 파일 처리 옵션 덕분에 여전히 Automator가 더 강력합니다. Apple이 기능을 조금씩 Shortcuts로 옮기고 있으니 둘 다 알아 두면 좋습니다.

### Hazel로 파일 내용에 따라 이름을 바꿀 수 있나요?

Hazel은 PDF와 문서 안의 텍스트를 읽어 이름 변경 규칙에 쓸 수 있습니다. 예를 들어 PDF에서 날짜나 키워드를 뽑아 파일 이름에 넣을 수 있습니다. 하지만 이미지나 동영상의 내용은 분석하지 못합니다. 시각 인식 기능이 없기 때문입니다. 스크린샷, 사진, 화면 녹화 같은 시각 파일에는 파일에 무엇이 담겼는지 실제로 볼 수 있는 AI 도구가 필요합니다.

### 다운로드 폴더가 어질러지지 않게 하려면 어떻게 하나요?

두 단계로 나눠 설정하세요. 먼저 파일이 들어오는 대로 형식별 폴더로 옮기는 분류 규칙(Zush Folder rules, Automator, Hazel)을 만듭니다. 다음으로 30일이 지난 파일을 보관 폴더나 휴지통으로 옮기는 정리 규칙을 추가합니다. 이렇게 하면 중요한 파일을 잃지 않으면서 다운로드 폴더를 가볍게 유지할 수 있습니다. 자세한 방법은 [다운로드 폴더 정리 가이드](/blog/how-to-organize-downloads-folder-mac)를 보세요.

### AI 파일 이름 변경은 안전한가요? 파일이 망가지지는 않나요?

AI 이름 변경은 파일 내용이 아니라 파일 이름만 바꿉니다. Zush 같은 좋은 도구는 이름 변경 기록도 남기므로 어떤 이름 변경이든 바로 되돌릴 수 있습니다. 위험은 낮지만, 파일이 많이 들어오는 폴더에 감시를 켜기 전에 항상 작은 묶음으로 먼저 시험하고 이름 품질을 확인하세요.

### 사진 정리만 따로 자동화하려면 어떻게 하나요?

사진은 원래 이름(`IMG_`, `DSC_`, `DCIM`)에 내용에 관한 정보가 전혀 없어서 까다롭습니다. AI 이름 변경으로 내용을 설명하는 이름을 붙이고, 날짜나 이벤트별 폴더 분류와 함께 쓰는 방법이 가장 좋습니다. 사진 전용 작업 흐름은 [Mac 사진 정리 가이드](/blog/best-ways-to-organize-photos-on-mac)를 보세요.

### 자동화 도구를 여러 개 함께 써도 되나요?

두 번째 도구가 정말 필요하다면 괜찮습니다. 이름 짓기와 폴더 분류는 Zush로 시작하고, 필요할 때만 한눈에 보기 위한 Smart Folders나 스크립트와 보관을 위한 Hazel 또는 Automator를 더하세요. 시스템을 관리하기 쉽도록 추가 규칙은 적게 두세요.

### 두 자동화 규칙이 충돌하면 어떻게 되나요?

Hazel과 Automator 폴더 동작이 같은 폴더를 감시하면 서로 먼저 처리하려고 다툴 수 있습니다. 결과는 예측할 수 없습니다. 한 도구가 처리하기도 전에 다른 도구가 파일을 옮겨 버릴 수 있습니다. 해결책은 간단합니다. 폴더 하나에는 자동화 도구를 하나만 쓰세요. Zush는 이름 변경과 분류를 한 번에 처리하므로 도구 하나로 충분한 경우가 많습니다. 보관처럼 Hazel에 맡길 일이 남아 있다면 Zush가 먼저 끝내게 하고, Hazel은 대상 폴더를 감시하게 하세요.

## 마무리

macOS에서 파일 정리를 제대로 자동화하려면 단순한 결정은 단순한 규칙에 맡기고, 눈으로 봐야 알 수 있는 파일은 AI에 맡기세요. 이렇게 나눠야 실제로 유지할 수 있는 시스템이 됩니다.

내용에 맞는 이름, 선택형 AI 폴더 분류, 되돌리기를 위해 Zush로 시작하세요. 시험을 마친 분류 설정은 Template에 저장해 Monitor에 씁니다. 저장된 보기에는 Smart Folders를, 스크립트와 보관에는 Automator나 Hazel을 쓰세요. 매주 점검하고 조금씩 넓혀 가세요.

완벽한 시스템을 만드는 것이 목표가 아닙니다. 파일 정리에 쓰는 시간을 일주일에 30분에서 5분으로 줄이는 것이 목표입니다.
