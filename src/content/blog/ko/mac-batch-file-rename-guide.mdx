Finder는 번호가 매겨진 배치 및 공유 접두사에 대한 가장 빠른 방법입니다. 반복 가능한 작업 흐름에는 Automator와 Shortcuts가 더 좋습니다. 정규식이나 메타데이터 논리가 필요할 때 터미널이 가장 좋습니다. AI 파일 이름 바꾸기는 스크린샷, PDF, 다운로드, 사진 또는 혼합 폴더에 각각 다른 검색 가능한 이름이 필요한 경우에 적합합니다.

검색이 구체적으로 Finder의 **이름 및 색인** 옵션에 관한 것인 경우 중요한 세부 사항은 다음과 같습니다. 새 파일 이름은 Finder에 즉시 표시되지만 파일 이름을 변경했다는 이유만으로 macOS에서는 추가 설명 메타데이터를 추가하지 않습니다. Spotlight는 새 파일 이름을 검색할 수 있습니다. Finder 태그, 주석, EXIF ​​필드 및 PDF 메타데이터는 도구가 별도로 작성하지 않는 한 변경되지 않습니다.

Finder는 또한 현재 선택한 순서대로 파일 번호를 매깁니다. 이름 및 색인을 사용하기 전에 최종 시퀀스를 읽으려는 방식으로 폴더를 정렬하십시오. `photo-001.jpg`가 가장 빠른 이미지여야 하는 경우 배치를 선택하기 전에 생성 날짜를 기준으로 정렬하세요. 순서가 현재 Finder 보기와 일치해야 하는 경우 먼저 표시되는 순서를 확인한 다음 이름을 바꾸십시오.

스크린샷, PDF, 사진, 비디오, 디자인 파일, 오디오 및 문서에 대해 다른 이름을 생성하는 Mac 앱을 원한다면 [Zush Mac용 AI 파일 이름 바꾸기 프로그램](/mac)를 사용하세요. 이 문서는 Finder, Automator, Terminal 및 AI 방법을 비교하기 위한 단계별 튜토리얼 레이어입니다.

## 파일 이름 변경이 Mac의 메타데이터에 표시됩니까?

보통은 그렇지 않습니다. Mac 파일 이름은 파일 경로의 일부이며 EXIF ​​데이터, Finder 태그, Spotlight 주석, PDF 제목 필드 또는 Office 문서 속성과 동일하지 않습니다. `IMG_4382.jpg`의 이름을 `client-office-whiteboard.jpg`로 바꾸는 경우 Finder와 Spotlight는 새 파일 이름을 찾을 수 있지만 카메라 모델, 촬영 날짜, GPS 데이터 및 기타 내장된 사진 메타데이터는 변경되지 않습니다.

이러한 구별은 일괄 이름 바꾸기 방법을 선택할 때 유용합니다.

- `invoice-001.pdf`와 같이 눈에 보이는 파일 이름만 필요한 경우 **Finder 이름 및 색인**을 사용하세요.
- 메타데이터가 이미 존재하고 이를 파일 이름으로 복사하려는 경우 **Automator 또는 Terminal**을 사용합니다.
- 스크린샷에 표시되는 내용, PDF 송장 내용 등 파일 콘텐츠에서 유용한 이름을 가져와야 하는 경우 **AI 일괄 이름 바꾸기**를 사용하세요.

깔끔한 파일 이름과 검색하기 쉬운 컨텍스트가 모두 필요한 경우 파일 이름을 의도적으로 작성하고 태그나 메타데이터도 추가할 수 있는 도구를 선택하세요. 해당 작업에는 일반 Finder 이름 바꾸기만으로는 충분하지 않습니다.

이름 바꾸기 규칙이 간단하면 Mac에서 파일 이름을 일괄적으로 바꾸는 것은 쉽지만, 모든 파일에 다른 설명 이름이 필요한 경우에는 훨씬 어렵습니다. Finder의 **이름 및 색인** 옵션은 `photo-001.jpg`, `photo-002.jpg` 및 유사한 배치에 충분합니다. 스크린샷, PDF, 다운로드가 혼합된 폴더의 이름을 검색 가능한 폴더로 바꾸는 학생에게는 다른 문제가 있습니다. 배치가 대부분 사진인 경우 [Mac에서 사진을 정리하는 방법](/blog/best-ways-to-organize-photos-on-mac)의 가이드는 이름 바꾸기 단계와 관련된 폴더, 날짜, 태그 및 백업을 다룹니다.

## 방법 1: Finder에서 항목 이름 바꾸기

Finder에는 대부분의 Mac 사용자가 결코 발견하지 못하는 일괄 이름 바꾸기 도구가 내장되어 있습니다. 세 가지 유형의 이름 바꾸기, 즉 파일 이름의 텍스트 바꾸기, 기존 이름 앞이나 뒤에 텍스트 추가, 일련 번호 또는 카운터로 이름 서식 지정을 처리합니다.

### Finder 일괄 이름 바꾸기를 사용해야 하는 경우

- 여러 파일에서 공통 문자열 바꾸기(예: `IMG_`를 `vacation-`로 변경)
- 파일 그룹에 날짜 접두사 또는 프로젝트 접미사 추가
- 파일 세트에 순차적으로 번호 매기기(예: `photo-001.jpg`, `photo-002.jpg`)
- 모든 파일에 동일한 규칙이 적용되는 이름 변경

### 단계별: Finder에서 파일 이름을 일괄적으로 바꾸는 방법

**1단계: 파일을 선택합니다.**
이름을 바꾸려는 파일이 포함된 폴더를 엽니다. Cmd+A를 사용하여 모든 파일을 선택하거나 첫 번째 파일을 클릭하여 특정 범위를 선택한 다음 Shift+마지막 파일을 클릭합니다. 개별 파일을 선택하려면 Cmd를 누른 상태에서 각 파일을 클릭하세요.

**2단계: 이름 바꾸기 대화상자를 엽니다.**
선택한 파일을 마우스 오른쪽 버튼으로 클릭(또는 Control+클릭)하고 상황에 맞는 메뉴에서 "이름 바꾸기..."를 선택합니다. Finder 메뉴 표시줄을 사용할 수도 있습니다. 파일 > 이름 바꾸기로 이동하세요.

**3단계: 이름 바꾸기 모드를 선택합니다.**
이름 바꾸기 대화 상자 상단에는 다음 세 가지 옵션이 있는 드롭다운이 있습니다.

- **텍스트 바꾸기** -- 현재 파일 이름에서 문자열을 찾아 다른 것으로 바꿉니다.
- **텍스트 추가** -- 모든 파일 이름에 텍스트를 추가하거나 추가합니다.
- **형식** -- 전체 이름을 기본 이름과 일련 번호, 카운터 또는 날짜로 바꿉니다.

**4단계: 구성 및 미리보기.**
필드를 채우십시오. Finder는 커밋하기 전에 확인할 수 있도록 새 이름의 미리보기를 표시합니다. 결과가 올바른지 확인하세요.

**5단계: 이름 바꾸기를 클릭합니다.**
선택한 모든 파일의 이름이 즉시 변경됩니다. 실수한 경우 즉시 Cmd+Z를 눌러 전체 배치를 취소하세요.

### Finder 이름 바꾸기 예

#### 텍스트 바꾸기 모드

공급업체로부터 일련의 제품 이미지를 다운로드했는데 모두 필요하지 않은 공급업체 코드로 시작됩니다.

| 이전 | 이후 |
|---|---|
| `VNDX-001_blue-widget.png` | `blue-widget.png` |
| `VNDX-001_red-widget.png` | `red-widget.png` |
| `VNDX-001_green-widget.png` | `green-widget.png` |

설정: `VNDX-001_`를 찾아 (비어 있음)으로 교체합니다.

#### 텍스트 모드 추가

결과물 세트에 프로젝트 이름을 접두어로 추가하려고 합니다.

| 이전 | 이후 |
|---|---|
| `homepage-hero.psd` | `acme-redesign_homepage-hero.psd` |
| `about-section.psd` | `acme-redesign_about-section.psd` |
| `footer-layout.psd` | `acme-redesign_footer-layout.psd` |

설정: 이름 앞에 텍스트 `acme-redesign_`를 추가합니다.

#### 포맷 모드

한 이벤트에서 50장의 사진을 촬영했는데 정확한 번호가 매겨진 이름을 원합니다.

| 이전 | 이후 |
|---|---|
| `IMG_7823.jpg` | `company-retreat-001.jpg` |
| `IMG_7824.jpg` | `company-retreat-002.jpg` |
| `IMG_7825.jpg` | `company-retreat-003.jpg` |

설정: 이름 형식: 이름 및 색인, 사용자 정의 형식: `company-retreat-`, 시작 번호: 1.

### Finder 일괄 이름 바꾸기의 제한 사항

Finder는 선택한 모든 파일에 동일한 규칙을 적용합니다. 각 파일에 해당 내용을 기반으로 고유한 설명 이름을 부여할 수는 없습니다. 또한 정규식 패턴, 조건부 논리 또는 메타데이터 기반 이름 지정을 처리할 수 없습니다. 해당 작업에는 다른 도구가 필요합니다. Windows 전환자는 종종 [Mac의 대량 이름 바꾸기 유틸리티](/blog/bulk-rename-utility-alternatives)를 요청합니다. 이는 macOS에는 존재하지 않으며 [고급 이름 바꾸기](/blog/advanced-renamer-alternatives)는 두 플랫폼 모두에서 패턴 및 메타데이터 틈새 시장을 다룹니다. 내용별로 파일 이름을 지정하지도 않습니다.

### Finder에서 일괄 이름 변경을 하면 파일 메타데이터가 변경되나요?

아니요. Finder 일괄 이름 바꾸기는 파일 이름만 변경합니다. 새 이름은 Finder, Spotlight, 열기 대화 상자 및 파일 경로에 표시되지만 이름 변경으로 인해 EXIF ​​메타데이터, Finder 태그, Finder 주석, PDF 제목 필드 또는 문서 속성이 자동으로 기록되지는 않습니다.

나중에 파일을 계속 검색 가능하게 하려는 경우 이러한 구별이 중요합니다.

| 필드 | Finder 일괄 이름 변경으로 변경되었나요? | 검색 영향 |
|---|---|---|
| 파일 이름 | 예 | Spotlight 및 Finder 검색은 새 이름과 일치할 수 있습니다 |
| 파일 경로 | 예 | 경로에 새 이름이 즉시 반영됩니다. |
| Finder 태그 | 아니요 | 태그는 별도로 추가해야 합니다 |
| Finder 댓글 | 아니요 | 댓글은 별도로 추가해야 합니다 |
| EXIF/카메라 메타데이터 | 아니요 | 사진 메타데이터는 변경되지 않습니다. |
| PDF 또는 Office 문서 속성 | 아니요 | 문서 제목/저자 필드는 변경되지 않습니다. |

더 깔끔한 파일 이름만 필요한 경우 Finder로 충분합니다. 혼합된 스크린샷, PDF, 사진 및 문서에 대한 의미 체계 이름, 태그 및 메타데이터도 원하는 경우 검색하기 쉬운 이름과 메타데이터를 의도적으로 작성하는 AI 파일 이름 변경기를 사용하세요. Zush는 AI 생성 파일 이름과 함께 [Finder 태그 및 스포트라이트 친화적인 메타데이터](/mac)를 지원합니다.

일괄 이름 변경을 효과적으로 수행하는 명명 규칙 설정에 대한 자세한 내용은 [파일 명명 규칙: 모든 워크플로에 대한 모범 사례](/blog/file-naming-conventions-best-practices)를 참조하세요.

## 방법 2: 자동화 작업 흐름

Automator는 코드를 작성하지 않고도 다단계 작업 흐름을 구축할 수 있는 macOS 자동화 도구입니다. 파일 이름 바꾸기의 경우 여러 이름 바꾸기 작업을 연결하고, 생성 날짜와 같은 메타데이터를 사용하고, 워크플로를 폴더에 연결하여 자동으로 실행될 수 있으므로 Finder보다 더 강력한 기능을 제공합니다.

### Automator를 사용해야 하는 경우

- 정기적으로 적용되는 동일한 이름 바꾸기 규칙이 필요합니다(주간 내보내기, 반복 보고서).
- 이름 바꾸기를 다른 작업(파일 이동, 확장명 변경)과 결합하려는 경우
- 메타데이터 기반의 네이밍(생성일, 파일 크기, 이미지 크기)이 필요합니다.
- 비기술적인 팀원을 위한 드래그 앤 드롭 애플리케이션을 원합니다.

### 단계별: Automator에서 이름 바꾸기 작업 흐름 구축

**1단계: Automator를 엽니다.**
응용 프로그램이나 Spotlight(Cmd+Space, "Automator" 입력)에서 Automator를 실행합니다. 메시지가 나타나면 "새 문서"를 선택하십시오.

**2단계: 워크플로 유형을 선택합니다.**
사용 사례에 따라 다음 중 하나를 선택하세요.

- **워크플로** -- Automator 내에서 수동으로 실행합니다. 테스트하기에 좋습니다.
- **애플리케이션** -- 파일을 드래그할 수 있는 독립형 앱을 만듭니다. 가끔 사용하기에 좋습니다.
- **폴더 작업** -- 특정 폴더에 첨부됩니다. 새 파일이 추가되면 자동으로 실행됩니다. 지속적인 자동화에 적합합니다.
- **빠른 작업** - Finder에서 마우스 오른쪽 버튼을 클릭하면 나타나는 상황에 맞는 메뉴에 표시됩니다. 주문형 사용에 적합합니다.

일괄 이름 바꾸기의 경우 **응용 프로그램** 또는 **폴더 작업**이 가장 실용적인 선택입니다.

**3단계: 이름 바꾸기 작업을 추가합니다.**
왼쪽 사이드바에서 "Finder 항목 이름 바꾸기"를 검색하세요. 오른쪽의 워크플로 영역으로 끌어다 놓습니다. Automator는 원본을 보존하기 위해 먼저 "Finder 항목 복사" 단계를 추가할지 묻습니다. 이름을 그대로 바꾸려면 "추가 안 함"을 클릭하고, 백업을 유지하려면 "추가"를 클릭하세요.

**4단계: 이름 바꾸기 규칙을 구성합니다.**
"Finder 항목 이름 바꾸기" 작업에는 여러 가지 모드가 있습니다.

- **날짜 또는 시간 추가** -- 파일 생성 또는 수정 날짜를 앞에 추가하거나 추가합니다. 내보내기를 시간순으로 정리하는 데 유용합니다.
- **대소문자 변경** -- 파일 이름을 소문자, 대문자 또는 제목 케이스로 변환합니다.
- **찾기 및 바꾸기** -- Finder의 텍스트 바꾸기와 동일하지만 다른 작업과 연결할 수 있습니다.
- **순차화** -- 각 파일에 색인 번호를 추가합니다.
- **텍스트 바꾸기** -- 한 문자열을 다른 문자열로 바꿉니다.

여러 이름 바꾸기 작업을 순서대로 쌓을 수 있습니다. 예를 들어 먼저 `IMG_`를 빈 문자열로 바꾼 다음 생성 날짜를 접두어로 추가한 다음 대소문자를 소문자로 변경합니다.

**5단계: 입력을 추가합니다.**
작업 흐름을 선택한 경우 상단에 "지정된 Finder 항목 가져오기" 작업을 추가하고 파일을 끌어다 놓습니다. 애플리케이션 또는 폴더 작업을 선택한 경우 파일이 자동으로 전달됩니다.

**6단계: 워크플로 테스트.**
오른쪽 상단의 실행 버튼을 클릭하세요. Finder에서 결과를 확인하세요. 문제가 발생한 경우 Finder에서 Cmd+Z를 눌러 실행을 취소하세요.

**7단계: 저장합니다.**
"클라이언트 내보내기 이름 바꾸기"와 같은 설명이 포함된 이름으로 저장합니다. 애플리케이션을 구축한 경우 이를 애플리케이션 폴더나 데스크탑에 저장하세요. 폴더 작업을 구축한 경우 지정한 폴더에 연결됩니다.

### Automator 이름 변경 예: 날짜 접두사가 붙은 클라이언트 결과물

디자이너는 매주 클라이언트를 위해 파일을 내보내고 파일 앞에 내보내기 날짜가 붙기를 원합니다.

| 이전 | 이후 |
|---|---|
| `homepage-mockup-v3.pdf` | `2026-02-08_homepage-mockup-v3.pdf` |
| `mobile-nav-prototype.pdf` | `2026-02-08_mobile-nav-prototype.pdf` |
| `brand-guidelines-update.pdf` | `2026-02-08_brand-guidelines-update.pdf` |

작업 흐름: 지정된 Finder 항목 가져오기 > Finder 항목 이름 바꾸기(날짜 또는 시간 추가, 추가된 날짜, 이름 앞, 형식 YYYY-MM-DD, 구분 기호 밑줄).

### 자동화 제한 사항

Automator는 패턴 기반입니다. 모든 파일이 동일한 규칙을 따라야 할 때 잘 작동합니다. PDF를 보고 파일 이름을 `scan_003.pdf` 대신 `tax-return-2025.pdf`로 결정할 수 없습니다. 또한 AI 통합이 없으며 macOS 업데이트 전반에 걸쳐 안정성이 일관되지 않습니다. Apple은 일부 동일한 작업을 처리하지만 다른 인터페이스를 사용하는 바로가기로 투자를 전환해 왔습니다.

[Automator Mac에서 파일 이름 바꾸기](/blog/macos-automator-rename-files-guide)를 자동으로 수행하는 방법에 대한 전체 단계별 내용을 보려면 전용 Automator 가이드를 읽어보세요.

### 바로가기: Apple이 현재 노력하고 있는 곳

단축키는 macOS Monterey 이상과 함께 제공되며 Apple이 적극적으로 개발하고 있는 도구이므로 기존 Automator 작업 흐름이 계속 실행되더라도 알아두는 것이 좋습니다. 일괄 이름 바꾸기의 경우 다른 어셈블리 모델을 사용하여 "Finder 항목 이름 바꾸기"가 수행하는 작업의 대부분을 다룹니다. 하나의 작업을 구성하는 대신 작은 루프를 만듭니다.

최소 일괄 이름 바꾸기 바로 가기는 다음과 같습니다.

1. 새 바로가기를 시작하고 **빠른 작업**에서 **수신** 입력을 **파일**로 설정합니다.
2. **바로가기 입력**을 전달하여 **각각 반복**을 추가합니다.
3. 루프 내부에 **Rename File**을 추가하고 파일을 **Repeat Item**으로 설정한 다음 **Text**를 사용하여 새 이름을 만듭니다(예: **Format Date** 결과, 밑줄 및 반복 색인).
4. 바로가기 세부정보 창에서 **빠른 작업으로 사용**을 활성화하고 **Finder**를 선택합니다.

그러면 바로 가기가 Finder의 마우스 오른쪽 버튼 클릭 **빠른 작업** 하위 메뉴에 나타나므로 파일을 선택하고 실행하면 전체 배치의 이름이 변경됩니다.

실제로는 두 가지 한계가 중요합니다. 바로가기는 여전히 패턴 기반입니다. 날짜, 카운터 또는 기존 텍스트에서 이름을 구성할 수 있지만 PDF가 임대 계약인지 결정할 수는 없습니다. 그리고 단축키로 수행한 이름 변경은 Finder의 실행 취소 스택에 없으므로 Cmd+Z는 이름을 되돌리지 않습니다. 먼저 복사된 폴더에서 테스트해 보세요.

이미 작업 중인 `.workflow` 파일이 있거나 폴더 작업이 필요한 경우 Automator를 선택하십시오. Apple이 계속 업데이트하는 경로이기 때문에 새로운 항목에 대해서는 바로가기를 선택하세요.

## 방법 3: Mac에서 파일 이름을 일괄적으로 바꾸는 터미널 스크립트

명령줄 사용에 익숙하다면 쉘 스크립트를 사용하여 Mac에서 일괄 이름 바꾸기를 가장 효과적으로 제어할 수 있습니다. 명령줄 도구를 통해 사용 가능한 정규식, 조건문, 루프 및 모든 메타데이터를 사용할 수 있습니다.

### 스크립트를 사용해야 하는 경우

- 정규식 기반 패턴 일치가 필요합니다(예: 파일 이름에서 날짜 추출).
- 파일 메타데이터(EXIF 데이터, PDF 속성)를 기반으로 이름을 바꾸고 싶습니다.
- 조건부 논리가 필요합니다(특정 기준에 맞는 파일만 이름 바꾸기).
- 당신은 이미 터미널에 편안하게 있습니다

### 루프를 사용한 기본 이름 바꾸기

모든 `.jpeg` 파일의 이름을 `.jpg`로 바꿉니다.

```bash
for f in *.jpeg; do
  mv "$f" "${f%.jpeg}.jpg"
done
```

### 파일 이름의 텍스트 바꾸기

현재 디렉터리의 모든 파일 이름에서 공백을 하이픈으로 바꿉니다.

```bash
for f in *\ *; do
  mv "$f" "${f// /-}"
done
```

### 파일 메타데이터에서 날짜 접두사 추가

`exiftool`를 사용하여 각 JPEG 앞에 EXIF 생성 날짜를 붙입니다.

```bash
for f in *.jpg; do
  date=$(exiftool -d "%Y-%m-%d" -DateTimeOriginal -s3 "$f")
  mv "$f" "${date}_${f}"
done
```

전후:

| 이전 | 이후 |
|---|---|
| `IMG_4201.jpg` | `2026-01-15_IMG_4201.jpg` |
| `IMG_4202.jpg` | `2026-01-15_IMG_4202.jpg` |
| `IMG_4203.jpg` | `2026-01-16_IMG_4203.jpg` |

### 제로 패딩을 사용한 일련 번호 매기기

접두사와 0으로 채워진 숫자를 사용하여 파일 세트의 이름을 바꿉니다.

```bash
counter=1
for f in *.png; do
  mv "$f" "$(printf 'slide-%03d.png' $counter)"
  counter=$((counter + 1))
done
```

| 이전 | 이후 |
|---|---|
| `Screen Shot 2026-02-01.png` | `slide-001.png` |
| `Screen Shot 2026-02-02.png` | `slide-002.png` |
| `Screen Shot 2026-02-03.png` | `slide-003.png` |

### `rename` 명령 사용(Perl 기반)

Homebrew(`brew install rename`)를 통해 Perl `rename` 유틸리티를 설치하면 단일 명령으로 정규식 지원을 받을 수 있습니다.

```bash
rename 's/IMG_/vacation-/' *.jpg
```

이는 현재 디렉터리의 모든 `.jpg` 파일 이름에서 `IMG_`를 `vacation-`로 대체합니다.

### 스크립트 제한사항

스크립트는 강력하지만 기술적인 지식이 필요합니다. 이름 바꾸기 스크립트의 오타로 인해 실행 취소 없이 전체 디렉터리의 파일 이름이 손상될 수 있습니다. 항상 파일 복사본을 먼저 테스트하거나 `mv`보다 먼저 `echo`를 사용하여 어떤 일이 일어날지 미리 확인하세요. 전체 [안전한 배치 파일 이름 바꾸기 가이드](/blog/how-to-safely-batch-rename-files)에서는 GUI 도구 및 스크립트 전반에 걸쳐 테스트 실행, 확장 및 충돌 검사, 연결된 파일 위험 및 복구 옵션을 설명합니다.

```bash
for f in *.jpg; do
  echo "mv $f -> vacation-${f#IMG_}"
done
```

스크립트는 또한 Finder 및 Automator와 동일한 기본 제한 사항을 공유합니다. 즉, 이해가 아닌 규칙을 적용합니다. 스크립트는 이미지를 보고 표시되는 내용을 결정할 수 없습니다. 콘텐츠 인식 이름 바꾸기에는 AI가 필요합니다.

## 방법 4: AI 지원 콘텐츠 인식 이름 바꾸기

AI 이름 바꾸기는 위의 모든 방법과 다릅니다. 파일 이름에 패턴이나 규칙을 적용하는 대신 각 파일의 실제 내용을 분석하고 찾은 내용을 기반으로 설명적인 이름을 생성합니다. Stripe 대시보드의 스크린샷은 `stripe-monthly-revenue-chart.png`가 됩니다. 스캔한 PDF는 `apartment-lease-agreement-2026.pdf`가 됩니다. 다운로드한 사진은 `golden-gate-bridge-foggy-morning.jpg`가 됩니다.

### AI 이름 바꾸기를 사용해야 하는 경우

- 콘텐츠에 대해 아무 것도 알려주지 않는 타임스탬프 이름이 포함된 스크린샷
- `scan_001.pdf`와 같은 이름을 가진 스캔된 문서 및 PDF
- `download.jpg` 또는 `IMG_4392.heic`와 같은 의미 없는 이름을 가진 다운로드된 이미지
- 파일 이름이 파일에 실제로 포함된 내용을 설명해야 하는 모든 폴더

### 작동 방식

1. 파일을 선택하거나 도구로 폴더를 가리킵니다.
2. AI는 문서의 텍스트 읽기, 이미지의 개체 및 장면 인식, 비디오 프레임 샘플링, 스크린샷의 UI 요소 이해 등 각 파일을 분석합니다.
3. 콘텐츠를 기반으로 각 파일에 대한 설명 파일 이름을 생성합니다.
4. 파일 이름은 각각 파일에 포함된 내용을 반영하는 고유한 이름으로 변경됩니다.

이것이 다른 모든 방법과의 주요 차이점입니다. 각 파일은 그룹에 적용되는 공유 패턴이 아니라 자체 콘텐츠를 기반으로 고유한 이름을 갖습니다.

## 일괄 이름 변경 시 흔히 발생하는 실수

### 파일 확장자를 포함하는 것을 잊어버렸습니다.

스크립트를 사용할 때 실수로 파일 확장자를 제거하거나 덮어쓰는 것은 일반적인 오류입니다. `report.pdf`에서 `quarterly-report`(`.pdf` 제외)로 이름이 변경된 파일은 두 번 클릭해도 제대로 열리지 않습니다. 항상 이름 바꾸기 논리에서 확장자를 유지하십시오.

### 복사본을 먼저 테스트하지 않음

이름을 바꾸는 것은 파괴적입니다. 500개의 파일에 잘못된 패턴을 적용하면 실행 취소가 힘들거나 불가능할 수 있습니다(특히 스크립트의 경우). 작은 파일 샘플을 테스트 폴더에 복사하고 거기에서 이름 바꾸기를 실행한 다음 원본을 터치하기 전에 결과를 확인하십시오.

### 문제를 일으키는 문자 사용

macOS에서는 파일 이름에 `/`, `:` 및 null 바이트 문자를 사용하지 마세요. macOS는 Windows보다 더 허용적이지만 특수 문자가 포함된 파일 이름은 클라우드 저장소에 동기화하거나, 외부 드라이브로 전송하거나, Windows 또는 Linux 사용자와 공유할 때 문제를 일으킬 수 있습니다. 문자, 숫자, 하이픈, 밑줄을 사용하세요.

### 문제에 잘못된 방법을 적용한 경우

Finder의 텍스트 바꾸기를 사용하여 혼합 스크린샷 폴더의 이름을 바꾸는 것은 모든 스크린샷이 서로 다르기 때문에 시간 낭비입니다. 반대로 AI를 사용하여 `IMG_`가 필요한 파일 배치의 이름을 `vacation-`로 바꾸는 것은 과잉입니다. 도구를 실제 작업에 연결하십시오.

### 정렬 순서 무시

특정 순서의 파일이 필요한 경우 0으로 채워진 숫자(`001`, `002`, `1`, `2` 아님)를 사용하세요. 패딩 없이 파일 `10`는 숫자순이 아닌 알파벳순으로 정렬되기 때문에 Finder에서 `1`와 `2` 사이에 정렬됩니다. 1000개 미만의 파일 컬렉션에는 최소 3자리 숫자를 사용하세요.

## 더 나은 일괄 이름 변경 결과를 위한 팁

### 먼저 명명 규칙을 설정하세요.

이름을 바꾸기 전에 규칙을 결정하세요. 하이픈이나 밑줄을 사용하시겠습니까? 소문자인가요, 아니면 대소문자 혼합인가요? 날짜 접두어 또는 아니오? 규칙이 있다는 것은 한 번 이름을 바꾸면 그 이름이 계속 유용하다는 것을 의미합니다. 지침은 [파일 명명 규칙: 모든 워크플로에 대한 모범 사례](/blog/file-naming-conventions-best-practices)를 참조하세요.

### 이름을 바꾸기 전에 파일을 그룹화하세요

단일 패스로 혼합 파일 형식의 전체 폴더 이름을 바꾸려고 하지 마십시오. 사진과 문서, 스크린샷을 분리한 다음 적절한 도구와 패턴을 사용하여 각 그룹의 이름을 일괄적으로 바꿉니다. 이렇게 하면 사진 명명 체계를 PDF에 적용하거나 그 반대의 경우를 피할 수 있습니다.

### Finder의 실행 취소를 즉시 사용

Finder의 일괄 이름 변경은 Cmd+Z 실행 취소를 지원하지만 이름 변경 직후에만 가능합니다. 다른 Finder 작업을 먼저 수행하면 실행 취소 기록이 계속 진행됩니다. 이름을 바꾼 후 바로 결과를 확인하고 문제가 있으면 즉시 실행 취소하세요.

### 복잡한 작업을 위한 방법 결합

실제 폴더에는 두 가지 이상의 접근 방식이 필요한 경우가 많습니다. Finder를 사용하여 공통 접두사를 제거한 다음 [Zush는 Mac에서 파일 이름을 일괄적으로 바꿉니다.](/mac)를 사용하고 내용 인식 이름 변경이 필요한 파일에 대한 설명 이름을 생성할 수 있습니다. 이벤트 사진의 순차적 이름 변경, 스크린샷의 AI 이름 변경, 반복 내보내기를 위한 Automator가 모두 동일한 워크플로에 공존할 수 있습니다.

### 다운로드 폴더를 깨끗하게 유지하세요

다운로드 폴더는 이름이 잘못된 파일의 가장 일반적인 소스입니다. 다운로드에 대한 자동 이름 바꾸기를 설정하면 혼란이 누적되는 것을 방지할 수 있습니다. 전체 전략은 [Mac에서 다운로드 폴더를 구성하는 방법](/blog/how-to-organize-downloads-folder-mac)를 참조하세요.

## FAQ

### Mac에서 파일 이름을 일괄적으로 바꾸는 가장 빠른 방법은 무엇입니까?

Finder는 모든 파일에 동일한 변경 사항이 적용되는 가장 빠른 방법입니다. 파일을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 이름 바꾸기를 선택하고 텍스트 바꾸기, 텍스트 추가 또는 서식을 선택하고 적용합니다. 파일 수에 관계없이 약 10초 정도 소요되며 설정이나 다운로드가 필요하지 않습니다. 하나의 규칙이 전체 배치에 맞는 경우에만 가장 빠릅니다. 각 파일에 다른 설명 이름이 필요한 경우 Finder는 작업을 전혀 수행할 수 없으며 파일 내용을 읽는 AI 이름 바꾸기 프로그램은 추가 설치에도 불구하고 더 빠른 경로입니다.

### Mac에서 아무것도 설치하지 않고 파일 이름을 일괄 변경하려면 어떻게 해야 하나요?

Finder에 내장된 이름 바꾸기 도구를 사용하세요. 이름을 바꾸려는 파일을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 상황에 맞는 메뉴에서 "이름 바꾸기..."를 선택합니다. 텍스트를 바꾸거나, 텍스트를 추가하거나, 이름 형식을 일련 번호로 지정할 수 있습니다. 이는 다운로드가 필요 없이 macOS Yosemite(10.10) 이상을 실행하는 모든 Mac에서 작동합니다.

### Finder는 콘텐츠에 따라 파일 이름을 바꿀 수 있나요?

아니요. Finder의 일괄 이름 바꾸기는 엄격하게 패턴 기반입니다. 텍스트 문자열을 바꾸고 접두사 또는 접미사를 추가하고 순차 번호를 적용할 수 있지만 파일에 포함된 내용을 분석할 수는 없습니다. 각 파일이 고유한 설명 이름을 갖는 콘텐츠 인식 이름 변경을 위해서는 이미지, 비디오 및 문서를 읽을 수 있는 AI 기반 도구가 필요합니다.

### Finder 이름과 색인이 Mac에 메타데이터를 추가하나요?

아니요. Finder 이름 및 색인은 파일 이름과 표시되는 파일 경로만 변경합니다. Finder 태그, Finder 주석, EXIF ​​메타데이터, PDF 메타데이터 또는 Office 문서 속성은 추가되지 않습니다. Spotlight는 새 파일 이름을 검색할 수 있지만 더 깊은 메타데이터에는 별도의 도구가 필요합니다.

### Mac에서 일괄 이름 변경을 실행 취소하는 방법이 있나요?

예, Finder를 사용한다면 가능합니다. 일괄 이름 변경 직후 Cmd+Z를 눌러 전체 작업을 실행 취소합니다. 모든 파일은 원래 이름으로 돌아갑니다. 이 실행 취소는 바로 다음 작업으로만 가능합니다. 터미널 스크립트를 사용하는 경우 기본 실행 취소 기능이 없으므로 스크립트를 실행하기 전에 항상 복사본을 먼저 테스트하거나 원본 파일 이름 목록을 저장하세요.

### Mac에서 날짜가 포함된 사진 이름을 바꾸는 가장 좋은 방법은 무엇입니까?

파일 생성 날짜를 접두사로 추가하려면 Automator의 "날짜 또는 시간 추가" 이름 바꾸기 작업이 가장 쉬운 옵션입니다. 카메라 메타데이터에서 EXIF ​​캡처 날짜를 추가하려면 `exiftool`와 함께 터미널 스크립트를 사용하세요. 날짜와 설명적인 콘텐츠 이름을 추가하기 위해 Zush와 같은 AI 도구는 날짜 패턴을 콘텐츠 분석과 결합할 수 있습니다.

### Mac에서 수백 개의 스크린샷 이름을 어떻게 바꾸나요?

"스크린샷"을 프로젝트 이름으로 바꾸는 것과 같은 기본적인 이름 바꾸기의 경우 Finder는 이를 몇 초 안에 처리합니다. 각 스크린샷에 표시되는 내용을 기반으로 설명적인 이름을 지정하려면 AI 이름 바꾸기를 사용하세요. 모든 스크린샷을 선택하고 AI가 각 이미지를 분석하도록 하여 `Screenshot 2026-02-08 at 10.45.33.png` 대신 `slack-design-review-thread.png`와 같은 이름을 얻습니다. 향후 스크린샷의 이름을 자동으로 바꾸려면 폴더 모니터링을 설정하세요. ### 내용에 따라 PDF 이름을 일괄 변경할 수 있나요?

예, AI 이름 변경 도구를 사용하면 됩니다. AI는 각 PDF의 텍스트 내용을 읽고 문서의 주제를 반영하는 파일 이름을 생성합니다. `scan_042.pdf`라는 이름의 스캔된 송장은 `invoice-7842-webdesign-services-march-2026.pdf`가 됩니다. 전체 연습을 보려면 [PDF 파일 이름을 자동으로 바꾸는 방법: 반복 폴더를 위한 AI 워크플로](/blog/rename-pdf-files-automatically)를 참조하세요.

### 일괄 이름 바꾸기가 파일 메타데이터나 생성 날짜에 영향을 미치나요?

Finder나 Automator를 통해 파일 이름을 바꿔도 생성 날짜, 수정 날짜 또는 내부 메타데이터는 변경되지 않습니다. 파일 내용은 동일하게 유지됩니다. 파일 시스템의 파일 이름만 변경됩니다. 그러나 일부 클라우드 동기화 서비스에서는 이름 변경을 새 업로드로 처리할 수 있으므로 동기화 폴더에서 대규모 배치의 이름을 변경한 후 동기화 상태를 확인하세요.

### 일괄 이름이 변경된 파일에는 어떤 명명 규칙을 사용해야 합니까?

시간 순서가 중요한 경우 소문자, 단어 사이에 하이픈, 날짜를 ISO 형식(YYYY-MM-DD)으로 사용하세요. 공백, 특수 문자 및 `final-v2`와 같은 모호한 레이블을 사용하지 마세요. 일관된 규칙을 통해 운영 체제 간에 파일을 정렬, 검색 및 전송할 수 있습니다. 자세한 지침은 [파일 명명 규칙: 모범 사례](/blog/file-naming-conventions-best-practices)를 참조하세요.

## 결론

Mac에서의 일괄 이름 변경은 하나의 작업 흐름이 아닙니다. 이는 일련의 작업 흐름이며 올바른 접근 방식은 실제로 필요한 이름 변경 종류에 따라 다릅니다.

빠른 텍스트 교체 및 일련 번호 매기기를 위해 Finder는 설정 없이 몇 초 만에 처리합니다. 자동으로 실행되는 반복 가능한 규칙의 경우 Automator는 폴더 작업 및 메타데이터 액세스를 통해 더 많은 기능을 제공합니다. 정규식 패턴 및 전체 제어의 경우 터미널 스크립트를 사용하면 파일 시스템에서 허용하는 모든 작업을 수행할 수 있습니다. 그리고 가장 어려운 이름 바꾸기 문제의 경우 모든 파일에 실제 콘텐츠를 기반으로 고유한 설명 이름을 부여하는 경우 AI 기반 도구가 패턴 기반 방법이 도달할 수 없는 격차를 메워줍니다.

실제 문제에 맞는 가장 간단한 도구를 선택하세요. 가능하면 Finder를 사용하고, 필요할 때는 스크립트를 사용하고, 파일 이름에 의미가 필요할 때는 AI를 사용하세요.
