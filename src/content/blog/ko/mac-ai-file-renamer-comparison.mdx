### Mac에서 Zush가 1위인 이유

1. **Apple Silicon과 Intel 모두에서 동작합니다.** macOS 15 이상의 모든 Mac에서 Mac App Store나 직접 다운로드로 쓸 수 있습니다. 클라우드 모드에서는 약 200 MB이고 RAM 4 GB면 됩니다. RenameClick은 내장 모델에 16 GB를 권장합니다.
2. **Finder에서 바로 씁니다.** 파일을 선택하고 **Rename with Zush**를 고르거나 Quick Rename 단축키를 누르세요. Mac App Store 빌드에서는 대신 파일 선택 창이 열립니다. 큰 묶음은 미리 보기를 거치고, Rename History로 재시작 후에도 묶음 전체를 되돌릴 수 있습니다.
3. **연결을 끊어도 살아남는 감시.** 감시 폴더를 외장 드라이브에 둘 수 있고, 드라이브를 다시 연결하면 감시가 재개됩니다.
4. **필요할 땐 로컬, 아니면 클라우드.** Ollama나 LM Studio를 쓰면 파일 분석과 오디오·동영상 음성 인식이 Mac에서 실행됩니다(3.20.1 이상). 같은 $48 라이선스에 관리형 Zush Cloud AI, 무제한 이름 변경, 이후 모든 업데이트, 최대 3대도 포함됩니다.

2026년 11월 17일 기준 Zush는 미국 Microsoft Store에서 평가 8개 기준 5.0, Softpedia 편집자 점수 4.5/5입니다. Mac App Store 평점은 웹에서 읽을 수 없으므로 인용하지 않습니다.

## 개별 리뷰

### 1. Zush: Mac용 종합 1위 AI 파일 이름 변경 도구

<BlogToolMeta platform="macOS 15 이상(Apple Silicon과 Intel), Windows 10/11" website="https://zushapp.com/mac" label="zushapp.com/mac">
  <Fragment slot="pricing">무료: 계정·카드 없이 AI 이름 변경 50회. Pro: 월 $10 또는 1회 $48, Zush Cloud AI, BYOK, Ollama, LM Studio에서 무제한 이름 변경, 최대 3대</Fragment>
</BlogToolMeta>

[Mac용 Zush](/mac)는 100개 이상의 형식에서 내용으로 파일 이름을 짓는 네이티브 앱입니다. HEIC, AVIF, SVG와 카메라 RAW(CR2, CR3, NEF, ARW, DNG 등), Sketch, Figma .fig, Illustrator .ai와 PSD, PDF, Office, iWork, OpenDocument, EPUB과 자막, MP3, M4A, WAV, FLAC, 그리고 MP4, MOV, MKV를 포함한 동영상을 지원합니다.

**작동 방식:** 준비된 Template(Smart Rename, Screenshots, Movies & TV, Remove Duplicates 등)을 고르거나 145개 이상의 Naming Blocks와 Custom AI Blocks로 직접 만드세요. Zush가 파일마다 이름을 제안하고, 이름을 더블클릭해 수정할 수 있습니다. Rename을 누르기 전에는 아무것도 바뀌지 않습니다.

**장점:**

- 관리형 클라우드 AI로 처음 실행할 때부터 동작, BYOK(Gemini, OpenRouter, OpenAI, Claude), Ollama, LM Studio도 같은 작업 흐름 사용
- 동영상은 음성, 내장 자막, 메타데이터로 이름 지정, Ollama나 LM Studio로 로컬 음성 인식
- 묶음 단위 실행 취소가 되는 영구 Rename History, Undo All이 충돌 표시
- 중복 감지: 사본을 유지, 이름에 표시, 또는 휴지통으로 이동, 사본은 크레딧 미사용, Undo로 복원
- Movies & TV Template이 프로그램과 시즌별로 분류, 음악은 아티스트와 앨범별로 분류
- 폴더 감시, 다시 연결하면 재개되는 외장 드라이브 포함
- 이름 변경 없이 폴더 분류, 중첩 폴더, 크기·날짜·카메라·재생 시간·페이지 수 기반 규칙
- 시작 값과 앞자리 0을 지정하는 폴더별 일련번호
- Finder 태그와 Spotlight 메타데이터, 11개 이상 언어 인터페이스, 60개 이상 언어로 이름 생성

**한계:**

- Linux 빌드와 브라우저 전용 버전 없음
- Zush Cloud AI와 BYOK는 인터넷 필요, Ollama와 LM Studio는 Mac에서 실행
- 태그 없는 음악 식별은 현재 Windows 전용

Zush 라이선스 하나로 Mac과 Windows를 합쳐 최대 3대에서 쓸 수 있습니다. [Templates를 내보내](/docs/template-import-export) 다른 컴퓨터에서 가져올 수 있고, 이름을 바꾼 파일을 저장할 위치도 고를 수 있습니다. 폴더 묶기는 [폴더 분류 가이드](/docs/folder-sorting)와 [AI 파일 정리](/ai-file-organizer)를 참고하세요.

Renamer.ai는 템플릿, Magic Folders, OCR, 미리 보기, 실행 취소를 갖춘 문서 중심 이름 변경 도구입니다. 무료를 포함한 모든 요금제에 로컬 모드가 있습니다. BYOK는 월 $99.95 Ultimate 요금제에만 있습니다. 공개된 형식 목록에는 HEIC, EPS, SVG, AI를 포함한 30개 이상의 문서, 이미지, 벡터 형식이 있지만 카메라 RAW, PSD, Sketch, Figma는 없습니다. Softpedia 편집자 리뷰는 4.5/5입니다.

**Renamer.ai를 고를 때:** 주로 문서 이름을 바꾸고 무료 요금제에서 로컬 처리를 원할 때. **약점:** 1회 결제 라이선스가 없어서 관리형 클라우드 이름 변경은 항상 월간 사용량제입니다. [Zush vs Renamer.ai](/blog/zush-vs-renamer-ai)를 참고하세요.

### 3. AI Renamer

<BlogToolMeta platform="Mac, Windows, Linux용 데스크톱 앱">
  <Fragment slot="pricing">Local Mode 1회 $19, Cloud Mode 200 크레딧당 $10, Google 로그인 후 무료 크레딧 10개</Fragment>
</BlogToolMeta>

AI Renamer(airenamer.app)는 이번 달 빠르게 바뀌었습니다. 1.9.0 버전에서 History 목록이 있는 Watch Folder(베타)가 추가됐는데, 앱이 열려 있을 때만 동작하고 하위 폴더는 다루지 않습니다. 1.10.0 버전에서 동영상, 오디오, RAW, HEIC, Office, EPUB이 추가됐습니다. 이제 Linux 빌드도 있고, 제공자는 Ollama와 LM Studio 외에 Google AI Studio와 OpenRouter도 있습니다. 환불 규정은 없고 크레딧 구매는 환불되지 않습니다.

GitHub의 무료 GPL-3.0 `ozgrozer/ai-renamer` CLI는 별개의 무관한 프로젝트입니다.

**AI Renamer를 고를 때:** 로컬 AI용으로 가장 낮은 1회 결제 가격을 원하거나 Linux가 필요할 때. **약점:** 실행 취소나 되돌리기가 문서화돼 있지 않으니 사본으로 시험하세요. [Zush vs AI Renamer](/blog/zush-vs-airenamer)를 참고하세요.

MLX와 Finder 태그/코멘트는 Mac 전용입니다. 이메일이나 카드 없이 Managed 이름 변경 30회를 주고, 70회가 포함된 14일 Managed 체험에는 카드가 필요하지만 Self-Managed 체험에는 필요 없습니다. Self-Managed는 컴퓨터 1대에 $69이며 평생 업데이트와 14일 환불이 있습니다. AI 비용은 별도이고, 파일을 옮긴 경우 실행 취소가 실패할 수 있습니다.

**NameQuick을 고를 때:** AI 이름 짓기 위에 규칙 엔진을 원할 때. **약점:** 1회 결제 라이선스는 컴퓨터 1대용이고 관리형 AI가 포함되지 않습니다. [Zush vs NameQuick](/blog/zush-vs-namequick)을 참고하세요.

**FilesDesk를 고를 때:** 이메일 첨부 파일 이름을 자동으로 바꾸고 싶을 때. **약점:** 1회 결제 라이선스에 관리형 AI가 포함되지 않습니다. [Zush vs FilesDesk](/blog/zush-vs-filesdesk)를 참고하세요.

RenameClick(현재 rename.click, 4.1.2 버전)은 로컬 모델을 내장하고 Ollama, LM Studio, 본인의 클라우드 키로도 동작합니다. 4.1.2 버전에서 프레임과 로컬 음성 받아쓰기를 이용한 MP4, MOV, M4V, 3GP 동영상 지원이 추가됐습니다. MKV, WebM, AVI는 지원하지 않고 카메라 RAW나 디자인 파일도 지원하지 않습니다. Auto Flow는 앱이 실행 중일 때 폴더를 감시하고, 4.0.1 버전에서 AI 에이전트용 MCP 서버가 추가됐습니다. 처음 적용하기 전에 한 번 온라인에 연결해야 합니다.

**RenameClick을 고를 때:** Ollama 설정이 필요 없는 내장 로컬 모델을 원할 때. **약점:** 모델 다운로드가 약 4 GB이고 RAM 16 GB를 권장하며, Undo는 메모리에 10개 항목만 보관하고 재시작하면 지워집니다. Softpedia 편집자 점수는 3.5/5입니다. [Zush vs RenameClick](/blog/zush-vs-renameclick)을 참고하세요.

### 7. File Renamer AI

  <Fragment slot="pricing">만료되지 않는 1회성 크레딧 1,000개 $10 또는 10,000개 $100</Fragment>
</BlogToolMeta>

File Renamer AI는 브라우저에서 동작합니다. 파일을 업로드하고, 제안을 수정하고, ZIP으로 내려받습니다. 홈페이지에는 이제 PDF, Office, 동영상, 오디오가 언급되지만 가격 페이지는 여전히 이미지 이름 변경을 설명합니다. 파일당 크기 제한은 제조사가 밝히지 않았습니다.

**File Renamer AI를 고를 때:** Mac에 앱을 설치할 수 없을 때. **약점:** 네이티브 앱, 폴더 감시가 없고 ZIP을 내려받은 뒤에는 실행 취소도 없습니다.

### 참고: Riffo

이 순위의 이전 버전에는 Mac 앱과 웹 데모가 있는 Riffo가 있었습니다. 2026년 11월 17일에 확인했을 때 riffo.ai가 연결을 거부했으므로 더 이상 순위에 넣지 않습니다.

## 자주 묻는 질문

### Mac에서 가장 좋은 AI 파일 이름 변경 도구는?

저희 추천은 Zush입니다. 계정, 카드, API 키 없이 관리형 클라우드 AI로 AI 이름 변경 50회를 무료로 시작합니다. $48 1회 결제 라이선스에는 관리형 클라우드 AI, BYOK, Ollama, LM Studio가 Mac이나 PC 최대 3대용으로 포함되며, 모든 묶음은 미리 보고 묶음 단위 실행 취소가 되는 영구 Rename History에 남습니다. RAW, 디자인 파일, iWork, MKV 동영상도 지원합니다.

### Zush의 $48 라이선스가 $19나 $36 라이선스보다 가치가 있나요?

더 저렴한 라이선스는 앱을 포함하지만 AI는 본인의 API 키나 로컬 모델로 실행됩니다. AI Renamer Local은 $19, RenameClick Lifetime은 $36 + VAT이며 둘 다 관리형 클라우드 AI를 포함하지 않습니다. Zush의 $48에는 무제한 이름 변경이 가능한 Zush Cloud AI와 BYOK, 로컬 모델, 이후 모든 업데이트, Mac과 Windows를 합쳐 3대, 14일 환불이 포함됩니다.

### AI 파일 이름 변경 도구가 내 파일을 업로드하나요?

모드에 따라 다릅니다. Zush Cloud AI와 BYOK는 이름을 만들기 위해 파일 내용을 AI 서비스로 보냅니다. Ollama나 LM Studio를 쓰면 Zush가 Mac에서 파일을 분석합니다. RenameClick은 기본값이 내장 로컬 모델이고, Renamer.ai는 모든 요금제에 로컬 모드가 있으며, File Renamer AI는 브라우저 업로드 서비스입니다. [Zush 개인정보 및 보안 가이드](/docs/privacy-security)와 각 제조사의 개인정보 페이지를 확인하세요.

### Mac에서 가장 좋은 무료 AI 파일 이름 변경 도구는?

Zush는 계정이나 카드 없이 AI 이름 변경 50회를 제공하며, 유료 버전과 같은 미리 보기와 Rename History를 씁니다. RenameClick은 4 GB 모델을 내려받은 뒤 월 100회 이름 변경 또는 이동을 허용합니다. NameQuick은 카드 없이 Managed 이름 변경 30회, Renamer.ai는 월 25개 파일, AI Renamer는 Google 로그인 후 크레딧 10개를 줍니다. [무료 AI 파일 이름 변경 도구 비교](/blog/free-ai-file-renamers)에서 어떤 한도가 매달 초기화되는지 정리했고, [무료 AI 이름 변경 가이드](/blog/rename-files-with-ai-free)에서 첫 묶음을 안내합니다.

### AI 파일 이름 변경 도구가 RAW 사진과 MKV 동영상을 처리할 수 있나요?

모두 그런 것은 아닙니다. Zush는 CR2, CR3, NEF, ARW, DNG 등 RAW 형식을 지원 목록에 올려 두었고, MKV를 포함한 동영상을 음성, 자막, 메타데이터로 이름 짓습니다. AI Renamer는 1.10 버전에서 RAW와 동영상을 추가했습니다. RenameClick은 MP4, MOV, M4V, 3GP를 처리하지만 MKV, WebM, AVI, RAW는 처리하지 않습니다. Renamer.ai는 카메라 RAW 형식을 지원 목록에 올리지 않았습니다.

### Mac에서 AI 이름 변경을 되돌릴 수 있나요?

Zush에서는 됩니다. Rename History가 재시작 후에도 남으므로 나중에 묶음 전체를 되돌릴 수 있고, Undo All은 복원 전에 충돌을 표시합니다. NameQuick과 FilesDesk는 실행 취소가 되는 기록을 남기며, NameQuick은 파일을 옮긴 경우 실행 취소가 실패할 수 있다고 밝힙니다. RenameClick은 실행 취소 항목 10개를 메모리에 보관하고 재시작하면 지웁니다. AI Renamer는 실행 취소를 문서화하지 않았으니 사본으로 시험하세요.
