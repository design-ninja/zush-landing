Zush Monitor watches a folder on Mac or Windows and renames each new PDF from what the document says, so `scan_0042.pdf` becomes something like `2026-11-03_acme-supply_invoice_INV-10234.pdf`. Monitor applies the name as soon as the file arrives, without a review step, and lists every change in Activity, where you can undo it.

This guide covers that one job: PDFs that keep landing in the same place, from a scanner, an email client, or an external drive. For other PDF tasks, start elsewhere:

## Set up automatic PDF renaming in Monitor

The setup is the same in Zush for Mac and Zush for Windows.

### 1. Add the intake folder in Monitor

Create a folder that only receives the documents you want renamed, such as `PDF Inbox` or your scanner's output folder. Open **Monitor** in Zush and add it. A narrow folder is easier to check than all of Downloads, which also collects installers, images, and archives.

### 2. Limit it to PDF

In the monitored folder's options, include PDF and leave other file types out. The same options control subfolders and filename filters, so you can also restrict Monitor to names that start with your scanner's prefix, such as `Scan`.

### 3. Choose a Template

Click the Template button next to the folder and pick the Template Monitor should use. A Template holds the [Naming Blocks](/docs/naming-blocks) that build each name, plus any custom prompt and folder sorting settings. Each monitored folder can have its own Template.

A pattern that works for mixed business PDFs:

```text
{Detected Date}_{Vendor}_{Document Type}_{Title}
```

**Detected Date** is the date printed in the document, which is usually the one you want. **Created Date** is when the file was made or downloaded. For invoices, the [Invoices template guide](/docs/templates/invoices) adds **Invoice Number** and **Amount**. Zush for Mac 3.25.0 also includes a built-in **Financial Statements** template that names bank, card, mortgage, loan, and investment statements by date, bank, account holder, and account number. Since Mac 3.23.2, Zush Cloud AI names invoices more specifically, with the vendor and the billing period.

### 4. Check the AI mode

The AI mode is a global setting in Settings, so it applies to every monitored folder. Zush has four: Zush Cloud AI (no key needed), BYOK with your own Gemini, OpenRouter, OpenAI, or Claude key, Ollama, and LM Studio. Ollama and LM Studio keep the analysis on your computer, which matters if you would rather not send bank statements or contracts to a cloud service. See [AI modes](/docs/ai-modes) for the differences.

### 5. Dry-run the Template on copies in AI Rename

Monitor does not show suggestions before it renames, so test first. Copy 10 to 20 representative PDFs into a scratch folder, open **AI Rename**, select the same Template, and add the copies. AI Rename shows every proposed name before anything changes. Include the awkward cases: a scanned page, a statement with two dates, two invoices from the same vendor. Adjust the Template until the names are right.

### 6. Turn Monitor on

Turn monitoring on for the folder and keep Zush running. From then on, each new PDF directly in that folder is analyzed and renamed. Open **Activity** to see what changed and [undo a rename](/docs/undo-history) if a name is wrong.

## Sort incoming PDFs into folders automatically

A Monitor Template can also move each renamed PDF into a subfolder. Turn on **Folder sorting** in the Template, choose a destination folder, and write a folder rule in plain language. See [AI folder sorting](/docs/folder-sorting) for every option.

Example: you want each supplier's documents in `Finance/<Vendor>`.

| Template setting | Value |
|---|---|
| Destination folder | `Finance` |
| Folder sorting | Custom |
| Folder rule | Group invoices and statements by company and use the company name for each folder. |

| Arrives in PDF Inbox | Ends up as |
|---|---|
| `scan_0042.pdf` | `Finance/Acme Supply/2026-11-03_acme-supply_invoice_INV-10234.pdf` |
| `Statement.pdf` | `Finance/First National Bank/2026-10-31_first-national-bank_statement_october.pdf` |
| `download (7).pdf` | `Finance/Cloudflare/2026-11-01_cloudflare_invoice_CF-88112.pdf` |

If you already keep one folder per vendor, turn on **Existing folders only** (Mac 3.24.0, Windows 3.19.5.0). Files then go only into folders that already exist, and a PDF that fits none of them stays where it is. In a monitored inbox, that leftover file is your signal that a new vendor arrived. You can also ask for nested folders, such as "by year, then by month inside each year", or turn on **Keep current names** if you only want PDFs moved.

Sorting applies to new arrivals. Changing the Template later does not reorganize PDFs that were already processed.

## Where the PDFs come from

**Scanner share.** Point the scanner's "scan to folder" or network share at the monitored folder. Zush also reads image-only scans that have no text layer. The [scanned document guide](/blog/rename-scanned-documents-automatically) covers scanner settings.

**Email downloads.** Set your mail app or browser to save PDF attachments into `PDF Inbox` instead of Downloads. If you would rather monitor Downloads itself, keep the PDF-only filter on. The Downloads guides for [Mac](/blog/how-to-organize-downloads-folder-mac) and [Windows](/blog/organize-downloads-folder-windows) help with a first cleanup.

**External drive.** Zush for Mac can monitor a folder on an external drive and resumes when the drive reconnects. Since Mac 3.23.1, Monitor also waits when its destination folder is offline, for example on a disconnected drive, and renames the waiting files once the drive is back. Files that changed while it waited are analyzed again. The same release made Monitor keep retrying files on a network share that drops for a moment and skip files it cannot read instead of stopping.

## Check exceptions before you leave it running

- **Wrong date:** compare the name with the date printed on the PDF. Use **Detected Date** rather than **Created Date** when the download day is meaningless.
- **Two similar documents:** add a block that tells them apart, such as **Invoice Number** or the account number. Two statements from one bank in the same month need it.
- **Unreadable scan:** rescan it or name it by hand. A plausible title on a blurry page is worse than no title.
- **Mixed packet:** a single PDF holding a letter, a form, and an invoice gets one name. Split it first if you need to find each part.
- **New sender or layout:** test again in AI Rename when a new supplier or a redesigned statement starts arriving.

## Fix exceptions with right-click Rename with Zush

For a single PDF that needs a different Template, you don't have to open Zush. Select the file, right-click, choose **Rename with Zush**, then **Smart** or one of your Templates. See [Quick Rename](/docs/quick-rename) for setup.

- **Mac (3.24.0):** in Finder. Turn it on in Zush Settings under **Quick Rename**, then enable the Zush extension in System Settings. The Finder menu does not work for files in iCloud Drive, Dropbox, Google Drive, or OneDrive.
- **Windows (3.19.5.0):** in the File Explorer context menu, in the Microsoft Store version.

Quick Rename applies the name right away, like Monitor. If you want to review a suggestion first, use AI Rename. Either way, the change shows up in Activity.

## FAQ

### Does Zush ask before renaming a new PDF in a monitored folder?

No. Monitor has no review-before-rename switch. It applies the name when the PDF arrives and records the change in Activity, where you can undo it. That is why the Template should be tested on copies in AI Rename first, where you do see every name before applying.

### Does Monitor rename the PDFs that are already in the folder?

Monitor is built for new arrivals. For PDFs that were already sitting in the folder, run them once through AI Rename with the same Template, so you can review the names of the backlog.

### Can different intake folders use different naming rules?

Yes. Each monitored folder has its own Template. A scanner folder can use the Invoices setup while a contracts folder uses a Template built around client and document type. The AI mode is the one setting they share.

### What happens if the drive with my monitored folder is unplugged?

On Mac, the folder stays configured, and Monitor resumes when the drive reconnects. If the sorting destination is offline, Monitor waits and renames the waiting PDFs once it is back. Files on a disconnected drive cannot be processed until then.

### Can I sort PDFs only into vendor folders I already have?

Yes. Turn on **Existing folders only** in the Template's folder sorting settings. PDFs go only into existing folders, and anything that matches none of them stays in place for you to handle.

### Does Zush need to be open for Monitor to work?

Yes. Zush has to be running for Monitor to process new PDFs.
