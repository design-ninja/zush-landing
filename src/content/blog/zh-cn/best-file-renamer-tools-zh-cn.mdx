## 第一类：系统自带和免费的规则重命名工具

### Finder 重命名（Mac）

选中文件，右键单击，选择**重新命名**：替换文本、添加文本，或者用“名称和编号”格式。无需安装。没有正则表达式，没有元数据，也不读取内容。[Mac 批量重命名指南](/blog/batch-rename-files-on-mac-complete-guide) 介绍了 Finder 以及 Automator 和终端的用法。

**适合**一条规则就能修正所有文件的情况。**不足**：完全不支持正则表达式和元数据。

### PowerRename（Windows）

它是 Microsoft PowerToys 的一部分。右键单击选中的文件，即可进行带实时预览的搜索替换，支持正则表达式、计数器、创建日期变量和照片 EXIF/XMP 标记。Ctrl+Z 可以撤销重命名。它没有 AI，也不读取文件内容。更多内容见 [Windows 版 Zush](/windows) 页面，其中对比了两者。

**适合**能把改动描述成规则的情况。**不足**：它无法根据扫描件的内容为 `scan_004.pdf` 命名。

### Bulk Rename Utility（Windows）

BRU 在一个密集的窗口里叠加前缀、编号、大小写、正则表达式、EXIF 和 ID3 标签等规则。个人使用免费。JavaScript 重命名需要付费许可证（$24.95），商业用途每台电脑 $92.95。4.1.0.1 版新增了一个能替你编写 JavaScript 和正则表达式的 AI 助手，但它仍然不读取文件内容。没有 Mac 版。请看我们的 [Bulk Rename Utility 替代品](/blog/bulk-rename-utility-alternatives)。

**适合**对超大文件夹执行复杂机械规则的情况。**不足**：界面信息密度高，商业使用按电脑数量计费。

## 第二类：元数据重命名工具

**Advanced Renamer** 和 **A Better Finder Rename** 根据 EXIF 日期、GPS 坐标、ID3 标签和文件日期生成名称。Advanced Renamer（4.28 版）还能通过脚本方法从 PDF 和 TXT 文件中提取文本，但它没有 AI 或 OCR，所以扫描的 PDF 和图片仍然无法读取，把提取的文本转换成名称的逻辑也要你自己写。它对轻度个人使用免费；经常使用的用户需要购买 $30 的个人许可证，工作用途需要 $50 的商业许可证。A Better Finder Rename 为 Mac 版，售价 $29.95。

局限在于，元数据描述的是*何时*和*用什么拍的*，而不是*拍了什么*。照片的 EXIF 只说明拍摄时间，不会告诉你画面里是一只在公园里的金毛寻回犬。我们的 [Advanced Renamer 替代品](/blog/advanced-renamer-alternatives) 评测说明了这些规则在哪里会失效。

**适合**你想要的完整名称已经存在于 EXIF、GPS 或标签中的情况。**不足**：无法理解图片或扫描文档。

## 常见问题

### 最好的免费文件重命名工具是哪款？

对于规则类任务，Mac 上的 Finder 和 Windows 上的 PowerRename 都免费，而且会预览每处改动。Bulk Rename Utility 个人使用免费，Advanced Renamer 对轻度个人使用免费。如果要根据文件内容命名，Zush 提供 50 次免费 AI 重命名，无需账号、银行卡或 API 密钥，使用的预览和 Rename History 与付费版相同。请看 [免费 AI 重命名指南](/blog/rename-files-with-ai-free)。

### 文件重命名工具能根据文件内容命名吗？

只有 AI 重命名工具能真正做到。规则工具只是重新排列现有名称；元数据工具读取 EXIF 或 ID3 标签。Advanced Renamer 可以通过脚本从 PDF 和 TXT 文件中提取文本，但没有 AI 或 OCR，扫描件和图片仍然无法读取。Zush 这样的 AI 重命名工具会读取文字、图片、音频和视频，包括没有文字层的扫描件，并给出一个由你先审阅的名称。

### AI 文件重命名工具值得付费吗？

如果你的重命名是机械性的，不值得：免费的规则工具就能完成。如果你经常需要打开文件看看是什么，那就值得。Zush 的 $48 一次性许可证包含托管云端 AI 和无限次重命名，以及 BYOK 和本地模型、今后所有更新、最多 3 台 Mac 和 Windows 设备，以及 14 天退款。请先在副本上试用 50 次免费重命名。

### Zush 在哪里处理我的文件？

取决于你选择的模式。Zush Cloud AI 和 BYOK 会把文件内容发送到 AI 服务来生成名称；BYOK 使用的是你自己的服务商账号。使用 Ollama 或 LM Studio 时，分析在你自己的电脑上进行，文件也留在那里。Finder、PowerRename 和 Bulk Rename Utility 等规则工具从不读取内容，所以没有任何东西离开你的电脑。请看 [离线 AI 文件重命名工具](/offline-ai-file-renamer) 的设置方法。

### Mac 上最好的文件重命名工具是哪款？

对于每个文件都需要描述性名称的混合文件夹，推荐 [Mac 版 Zush](/mac)：它能读取截图、PDF、RAW 照片、设计文件、音频和视频，并持久保存 Rename History。如果只需一条通用规则，Finder 是系统自带的；如果要按 EXIF 和元数据规则命名，A Better Finder Rename 售价 $29.95。完整的对比见 [Mac AI 重命名工具对比](/blog/best-ai-file-renamer-tools-mac-compared)。
