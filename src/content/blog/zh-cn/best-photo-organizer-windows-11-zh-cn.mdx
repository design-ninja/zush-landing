在 Windows 11 上，Microsoft Photos 适合浏览，digiKam 提供带人脸和标签的免费图库，Lightroom Classic 适合编辑与编目。普通文件夹中的兼容照片可用 Zush 命名并按内容分组。AI 分类处于 beta 阶段，请先检查建议。

## 照片图库与普通文件夹有何区别？

图库使用自己的数据库管理相册、人脸、评分和搜索。文件名和真实文件夹则在文件系统、外接硬盘及共享位置保持可见。Zush 整理文件本身，不代替相册、人脸识别、重复文件检查或备份。两种工作方式可以配合使用。

## 1. Microsoft Photos

Microsoft Photos适合在Windows中简单查看和管理照片。通过描述进行AI搜索需要Copilot+ PC。如果需要高级标签、人脸识别或专业RAW目录，请比较专门的工具。

[Microsoft Photos](https://support.microsoft.com/en-us/windows/apps/photos/search-photos).

## 2. digiKam

digiKam为大型照片收藏免费提供相簿、标签、评分和人脸识别。其图库管理比普通看图软件更完整。迁移档案前先测试导入、元数据和数据库备份。

[digiKam](https://www.digikam.org/).

## 3. Lightroom Classic

Lightroom将编辑、评分、相簿和搜索结合到云端同步图库中。Lightroom Classic则使用桌面目录，对实际文件的控制更灵活。大量导入之前先选定模式，并考虑持续的订阅费用。

[Lightroom Classic](https://www.adobe.com/creativecloud/photography/compare-plans.html).

## 4. XnView MP

XnView MP适合快速浏览、查看元数据和批量转换。个人及教育用途免费，商业用途需要许可证。多设备图库或高级RAW编辑更适合使用其他工具。

[XnView MP](https://www.xnview.com/en/xnviewmp/).

## 5. Mylio Photos

Mylio可汇集电脑、移动设备和硬盘上的照片与视频。本地分析和设备间同步适合私人档案。优化预览不能代替原始文件，需要自行规划存储和备份。

[Mylio Photos](https://mylio.com/).

## 用 AI 将文件分类到文件夹

Zush 文件夹分类在 Mac 和 Windows 上均为 beta 功能。它分析兼容文件的内容，提出名称和分组。使用 Auto 时将 Folder rules 留空，或用自然语言描述分类。Naming Blocks 单独控制文件名格式。

> 按主题分组图片，例如人物、食物和风景。

1. 将一小批文件副本加入 AI Rename，并选择 Template。
2. 启用 + Sort，将 Destination folder 设为子文件夹的根目录。未选择单独目标时，源文件夹仍为根目录。
3. 在 Folder rules 中填写分组方法。启用 Reuse existing folders 可使用目标中的合适文件夹；没有合适的现有文件夹时，Zush 可以新建。
4. 应用批次前检查并修正建议的文件名和分组。

先复制少量照片、截图、RAW、文档和名称不清晰的文件。检查预览、分组、元数据、附属文件、外接硬盘和恢复功能。图库还应测试导入、导出、备份和目录恢复。在新流程验证通过前保留旧档案。

## 常见问题

### Zush 能把文件实际移动到文件夹吗？

可以。启用可选的 beta 分类，选择目标并检查名称与分组。只在原位置改名时，关闭分类并保留原始目标。

### 能自动分类新文件吗？

可以，使用已测试并分配给 Monitor 的 Template。处理监控文件夹直属的新文件，不自动重新分配已处理的旧文件。

### 支持现有文件夹和外接硬盘吗？

Reuse existing folders 能使用目标根目录下的合适文件夹，并按需新建。硬盘与文件必须可访问；云端文件需先下载。

### 文件会发送给云端 AI 吗？

Zush Cloud AI 和 BYOK 会将内容发送到选择的云端提供商。Ollama 和 LM Studio 提供支持的本地分析。本地分析不等于整个应用的所有功能都离线运行。
