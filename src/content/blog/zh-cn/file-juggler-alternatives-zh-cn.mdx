## File Juggler 的优点

File Juggler 是一款 Windows 自动化工具，由丹麦的一位独立开发者打造。每条规则由三部分组成：

1. **监控文件夹**，例如 Downloads、桌面或扫描仪输出文件夹。
2. **条件**：文件名和路径、文件内的文字、大小、创建或修改日期。
3. **操作**：移动、复制、重命名、更改扩展名、删除或移到回收站、解压压缩包、添加到 zip、运行命令，或上传到 Evernote。

它订阅的是文件夹变更通知，而不是定时扫描，所以几乎能即时响应。它可以读取 PDF、Word 和 Excel 文件里的文字，并把找到的词语和日期用到新文件名里。3.1.9 版于 2026 年 10 月 30 日发布，可见并没有停止开发。Softpedia 编辑给它的评分是 4.5/5，和给 Zush 的分数相同。

定价很简单：结账时一次性 50 美元（未含税），包含今后所有升级。一份许可证可供一个人在多台 PC 上使用，也可供多人共用一台 PC。30 天试用期内所有功能都可用，试用结束后应用会提醒你购买，但仍可继续使用。

## 为什么人们会寻找替代品

- **没有 AI。** 每条规则都要手写。规则抓不住 `Screenshot 2026-10-02 141203.png` 或 `IMG_4382.jpg`，因为文件名和文字里都没有说明文件是什么。
- **没有 OCR。** File Juggler 的 FAQ 说明，纯图像的扫描件没有可搜索的文字，因此在内容规则能匹配之前，你需要先用另一个 OCR 程序处理。
- **仅限 Windows。** 没有 Mac 版。在 Mac 上，对应的工具是 [Hazel](/hazel-alternative)。
- **不是系统服务。** 它只在用户登录时运行，不太适合服务器。
- **价格**，如果你只需要按文件类型简单分类。好几款免费工具就能做到。

## 1. Zush：处理规则无法描述的文件

[Windows 版 Zush](/windows) 支持 Windows 10 和 11，可从 [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X) 获取。它不去匹配条件，而是读取文件本身：PDF 或扫描件中的文字、照片或截图里的内容、视频的画面、语音和字幕（包括 MKV）。然后给出类似 `2026-09-12_acme_invoice_1042.pdf` 或 `stripe-revenue-dashboard-september.png` 的名称。

![Windows 版 Zush 按内容重命名一批混合文件，在应用之前列出每个拟定的文件名](/videos/windows/zush-batch-rename.mp4)

File Juggler 每个目标文件夹都需要一条规则，而 Zush 只需在 **Folder rules** 里写一句话，例如“发票按公司分组，收据按月份分组”，或者用 Auto 按内容自动分组。在任何文件移动之前，你会同时看到拟定的名称和文件夹。应用之前请检查含义不明确的文件。

![Windows 版 Zush 在执行 Rename & sort 之前预览按内容划分的文件夹分组和拟定文件名](/images/showcase/windows/folder-sorting-light.webp)

对于 File Juggler 那种始终在线的部分，可以把设置保存为 Template 并分配给 **Monitor**。这样 Downloads 或扫描仪文件夹里的新文件一到就会被重命名和分类。Rename History 在重启后仍保留新旧名称，Undo All 可以还原整批操作并列出所有冲突。AI Rename 还能识别重复下载的文件并移到回收站；副本不消耗额度，Undo 可以把它们恢复。

开箱即用：前 50 次 AI 重命名在托管的 Zush Cloud AI 上运行，无需账号、银行卡、API 密钥，也不用下载模型。如果文件应当留在本机，可以切换到 Ollama 或 LM Studio，或者使用你自己的 API 密钥。

![Windows 版 Zush 的 Monitor 标签页正在监控 Screenshots 和 Downloads 文件夹，并在新文件到达时重命名](/images/showcase/windows/monitor-light.webp)

如果你的规则列表越写越长却仍然漏掉文件，就选 Zush。分步教程：[在 Windows 上用 AI 把文件分类到文件夹](/blog/sort-files-into-folders-with-ai-windows)，以及 [30 条现成的文件夹规则](/blog/ai-folder-sorting-prompts)。

价格：$10/月或 $48 一次性买断。和 File Juggler 一样，一次性许可证包含今后所有更新；此外还包括托管的 Zush Cloud AI 以及 BYOK、Ollama 和 LM Studio、无限次重命名、最多 3 台 Windows 和 Mac 设备，以及 14 天退款。在 Microsoft Store（美国区）上，Zush 获得 5.0 分（8 个评分），Softpedia 编辑评分为 4.5/5（截至 2026 年 11 月 17 日）。

## 2. DropIt：免费的规则引擎

DropIt 免费且开源。规则可以按名称、大小、日期、属性或正则表达式匹配文件，21 种操作涵盖移动、复制、重命名、压缩、解压等。你可以把文件拖到一个悬浮目标上，也可以让它定时扫描监控文件夹。

不足：最新版本 8.5.1 发布于 2018 年 2 月。它仍然能运行，但别指望有新功能，也没有 AI。

如果你只需要“PDF 放这里，图片放那里”，又不打算付费，就选 DropIt。

## 3. Sortio：规则打底的 AI 方案

Sortio 把两种方式结合在一起。你可以写传统规则，也可以用日常英语描述想要的整理方式，审阅方案后再让它重命名、创建文件夹并移动文件。Smart Folders 会持续把方案应用到新到达的文件上。它支持 Windows、macOS 和 Linux。

免费版包括最多 5 条规则和 3 个 Spaces 的规则分类、预览、分类历史、撤销，以及一次性 AI 试用。监控文件夹和自动化需要 Pro，价格为每月 $14.99 或每年 $99，含每月 AI 用量。Ollama 可让处理留在本地，使用时需用电子邮件账号登录。

如果你想在一个应用里同时拥有 File Juggler 式的规则和 AI，或者需要 Linux，就选 Sortio。不足：始终在线的功能仅限 Pro。详细对比见 [Zush 与 Sortio 对比](/blog/zush-vs-sortio)。

## 4. Wisfile：面向文档的免费 AI 清理

Wisfile 免费，在 Mac 和 Windows 上本地运行，会根据内容用 `Author-Year-Title` 这类模板重命名文档。它也能把一批文件按主题分到不同文件夹。其 FAQ 列出的支持格式为 Word 和 PDF。

它没有文件夹监控，也没有定时任务：每次都要把文件拖进去再运行。其 FAQ 还说明没有内置撤销功能，所以请先在副本上测试。

如果要一次性清理纸质资料或文档归档，就选 Wisfile。更详细的分析见 [Zush 与 Wisfile 对比](/blog/zush-vs-wisfile)。

## 5. PowerShell 和 Task Scheduler：自己动手的路线

Windows 无需额外软件就能完成 File Juggler 的基础工作。PowerShell 负责移动和重命名文件，Task Scheduler 在登录时或每隔几分钟运行脚本：

```powershell
Get-ChildItem "$env:USERPROFILE\Downloads" -Filter *.pdf |
  Move-Item -Destination "$env:USERPROFILE\Documents\PDFs"
```

它免费，灵活程度取决于你的脚本能力。但重名、文件被占用、日志和撤销也都得你自己处理。更多方法：[如何整理 Windows 上的 Downloads 文件夹](/blog/organize-downloads-folder-windows)。

## 保留 File Juggler，还是换工具？

- 文件遵循固定规律（同一家银行、同样的版式、同样的名称前缀）：**继续用 File Juggler**。
- 截图、扫描件、手机照片和名称毫无意义的随手下载：**Zush**。
- 按扩展名或名称免费分类：**DropIt** 或 **PowerShell**。
- 在一个工具里同时用规则和 AI，或者需要 Linux：**Sortio**。
- 免费一次性处理 PDF 和 Word 文件：**Wisfile**。

你也可以两者一起用。Zush 监控 Downloads 并写出 `2026-10-02_acme_invoice.pdf` 这样可预期的名称，File Juggler 再把 `*_invoice.pdf` 移到固定的财务文件夹。两个工具各做自己擅长的部分。任何设置都请先在副本上测试；我们关于 [如何安全地批量重命名文件](/blog/how-to-safely-batch-rename-files) 的检查清单列出了需要确认的事项。

想看更全面的 AI 工具对比，请阅读 [Windows 11 最佳 AI 文件整理工具](/blog/best-ai-file-organizers-windows)。从 Mac 转过来？请阅读 [Windows 上的 Hazel 替代品](/blog/hazel-for-windows-alternatives)。

## 常见问题

### File Juggler 有免费的替代品吗？

有。DropIt 免费且开源，但最新版本发布于 2018 年 2 月。Sortio 的免费版最多支持 5 条规则，不过监控文件夹需要 Pro。会写脚本的话，PowerShell 加 Task Scheduler 也是免费的。Wisfile 可免费处理 PDF 和 Word 文件。如果你的问题是文件名含糊不清，Zush 提供 50 次免费 AI 重命名，无需账号或银行卡。

### File Juggler 还在维护吗？

是的。根据 File Juggler 自己的新闻页面，3.1.9 版于 2026 年 10 月 30 日发布，许可证包含今后所有升级。这让它成为少数仍在定期更新的 Windows 规则整理工具之一。主要的免费替代品 DropIt 自 2018 年 2 月以来就没有发布过新版本。

### File Juggler 使用 AI 吗？

不使用。它匹配你写好的条件，包括 PDF、Word 和 Excel 文件中的词语，也能复用文本中找到的日期。没有单独的 OCR 程序，它就读不了纯图像的扫描件，也无法判断照片或截图里是什么。处理这类文件需要 AI 工具，例如 Zush、Sortio 或 Wisfile。

### File Juggler 卖 $50，Zush 卖 $48，哪个更值？

两者买到的东西不同。File Juggler 的 $50 加税换来的是一个包含今后所有升级的规则引擎，但没有 AI。Zush 的 $48 一次性许可证包含 AI 命名和文件夹分类，可用托管的 Zush Cloud AI、本地模式和 BYOK 模式，无限次重命名，今后所有更新，以及最多 3 台 Windows 和 Mac 设备。很多人两个都用。

### Zush 或 File Juggler 会把我的文件发到别处吗？

File Juggler 的规则在本地运行。Zush 取决于你选择的模式：使用 Ollama 或 LM Studio 时，分析留在你的 PC 上；使用 Zush Cloud AI 或你自己的 API 密钥时，文件内容会发送到相应的云端模型来生成名称。机密文件夹请选择本地模式；也请检查 Sortio 的设置，因为它提供托管 AI、BYOK 或 Ollama。

### File Juggler 有 Mac 版吗？

没有，File Juggler 仅支持 Windows。在规则方面，Mac 上最接近的是 Hazel，Softpedia 编辑给它的评分是 5.0/5。Mac 版 Zush 负责 AI 命名和文件夹分类，也支持监控外置硬盘上的文件夹。两种思路在 Mac 上的对比见我们的 [Hazel 替代品](/hazel-alternative) 页面。

### Zush 能完全取代 File Juggler 吗？

在按内容命名文件并分类到文件夹这件事上可以，包括监控文件夹。File Juggler 仍有一些 Zush 不提供的操作，例如运行命令、解压压缩包或上传到 Evernote。如果你依赖这些操作，就让 File Juggler 继续负责这部分，由 Zush 写出它的规则能够匹配的描述性名称。
