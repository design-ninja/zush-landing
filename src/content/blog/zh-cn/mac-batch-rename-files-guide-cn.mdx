## 方法 1：Finder 重命名项目

Finder 有一个大多数 Mac 用户从未发现的内置批量重命名工具。它处理三种类型的重命名：替换文件名中的文本、在现有名称之前或之后添加文本以及使用连续数字或计数器格式化名称。

### 何时使用 Finder 批量重命名

- 替换多个文件中的公共字符串（例如，将 `IMG_` 更改为 `vacation-`）
- 向一组文件添加日期前缀或项目后缀
- 按顺序对一组文件进行编号（例如，`photo-001.jpg`、`photo-002.jpg`）
- 每个文件都应用相同规则的任何重命名

### 分步：如何在 Finder 中批量重命名文件

**第 1 步：选择文件。**
打开包含要重命名的文件的文件夹。使用 Cmd+A 选择所有文件，或者通过单击第一个文件，然后按住 Shift 键单击最后一个文件来选择特定范围。要选择单个文件，请按住 Cmd 并单击每个文件。

**第 2 步：打开重命名对话框。**
右键单击（或按住 Control 键单击）任何选定的文件，然后从上下文菜单中选择“重命名...”。您还可以使用 Finder 菜单栏：转至文件 > 重命名。

**第 3 步：选择您的重命名模式。**
重命名对话框顶部有一个下拉菜单，其中包含三个选项：

- **替换文本** -- 在当前文件名中查找字符串并将其替换为其他内容。
- **添加文本** -- 将文本附加或添加到每个文件名。
- **格式** -- 将整个名称替换为基本名称加上序号、计数器或日期。

**第 4 步：配置和预览。**
填写字段。 Finder 显示新名称的预览，以便您可以在提交之前进行验证。检查结果是否正确。

**第 5 步：单击“重命名”。**
所有选定的文件都会立即重命名。如果您犯了错误，请立即按 Cmd+Z 以撤消整个批次。

### Finder 批量重命名的限制

Finder 对每个选定的文件应用相同的规则。它无法根据每个文件的内容为其指定唯一的描述性名称。它还无法处理正则表达式模式、条件逻辑或元数据驱动的命名。对于这些工作，您需要不同的工具。 Windows 切换者经常要求 [Mac 上的批量重命名实用程序](/blog/bulk-rename-utility-alternatives) - 它在 macOS 上不存在，并且 [高级重命名器](/blog/advanced-renamer-alternatives) 涵盖了两个平台上的模式和元数据利基；都不按内容命名文件。

### Finder 是否批量重命名更改文件元数据？

不会。Finder 批量重命名仅更改文件名。新名称在 Finder、Spotlight、打开对话框和文件路径中可见，但重命名不会自动写入 EXIF 元数据、Finder 标签、Finder 注释、PDF 标题字段或文档属性。

当您希望文件以后保持可搜索时，这种区别很重要：

|领域| Finder批量重命名改变了？ |搜索影响 |
|---|---|---|
|文件名 |是的 | Spotlight 和 Finder 搜索可匹配新名称 |
|文件路径 |是的 |路径立即反映新名称 |
|Finder标签 |没有 |标签必须单独添加 |
|Finder评论 |没有 |评论必须单独添加 |
| EXIF / 相机元数据 |没有 |照片元数据保持不变 |
| PDF 或 Office 文档属性 |没有 |文档标题/作者字段保持不变 |

如果您只需要更清晰的文件名，Finder 就足够了。如果您还需要混合屏幕截图、PDF、照片和文档的语义名称、标签和元数据，请使用 AI 文件重命名器，该文件重命名器会有意写入便于搜索的名称和元数据。 Zush 支持 [Finder 标签和 Spotlight 友好的元数据](/mac) 以及 AI 生成的文件名。

## 方法 2：Automator 工作流程

Automator 是一款 macOS 自动化工具，可让您无需编写代码即可构建多步骤工作流程。对于文件重命名，它提供了比 Finder 更强大的功能，因为您可以链接多个重命名操作、使用创建日期等元数据，并将工作流程附加到文件夹以便其自动运行。

### 何时使用 Automator

- 您需要定期应用相同的重命名规则（每周导出、定期报告）
- 您想要将重命名与其他操作结合起来（移动文件、更改扩展名）
- 您需要基于元数据的命名（创建日期、文件大小、图像尺寸）
- 您想要一个供非技术团队成员使用的拖放应用程序

### 分步：在 Automator 中构建重命名工作流程

**第 1 步：打开 Automator。**
从应用程序或 Spotlight 启动 Automator（Cmd+Space，键入“Automator”）。出现提示时选择“新建文档”。

**第 2 步：选择工作流程类型。**
根据您的用例选择其中之一：

- **工作流程** -- 从 Automator 中手动运行。适合测试。
- **应用程序** -- 创建一个可以将文件拖到其中的独立应用程序。适合偶尔使用。
- **文件夹操作** -- 附加到特定文件夹。添加新文件时自动运行。有利于持续自动化。
- **快速操作** -- 显示在 Finder 的右键单击上下文菜单中。适合按需使用。

对于批量重命名，**应用程序**或**文件夹操作**是最实用的选择。

**第 3 步：添加重命名操作。**
在左侧边栏中，搜索“重命名Finder项目”。将其拖动到右侧的工作流程区域中。 Automator 会询问您是否要首先添加“复制Finder项目”步骤以保留原件。如果您想就地重命名，请单击“不添加”；如果您想保留备份，请单击“添加”。

**步骤4：配置重命名规则。**
“重命名Finder项目”操作有多种模式：

- **添加日期或时间** -- 前置或附加文件的创建或修改日期。对于按时间顺序组织导出很有用。
- **更改大小写** -- 将文件名转换为小写、大写或标题大小写。
- **查找和替换** -- 与 Finder 的替换文本相同，但可与其他操作链接。
- **Make Sequential** -- 为每个文件添加索引号。
- **替换文本** -- 将一个字符串替换为另一个字符串。

您可以按顺序堆叠多个重命名操作。例如：首先将 `IMG_` 替换为空字符串，然后添加创建日期作为前缀，然后将大小写更改为小写。

**第 5 步：添加输入。**
如果您选择工作流程，请在顶部添加“获取指定的Finder项目”操作并将文件拖入其中。如果您选择应用程序或文件夹操作，文件将自动传入。

**第 6 步：测试工作流程。**
单击右上角的运行按钮。在 Finder 中检查结果。如果出现问题，请在 Finder 中按 Cmd+Z 进行撤消。

**第 7 步：保存。**
使用描述性名称保存，例如“重命名客户端导出”。如果您构建了应用程序，请将其保存到您的应用程序文件夹或桌面。如果您构建了文件夹操作，它将附加到您指定的文件夹。

### 自动机限制

Automator 是基于模式的。当每个文件都遵循相同的规则时，它会很好地发挥作用。它无法查看 PDF 并决定文件名应为 `tax-return-2025.pdf` 而不是 `scan_003.pdf`。它还没有人工智能集成，并且其在 macOS 更新中的可靠性变得不一致。苹果一直在将投资转向快捷方式，它可以处理一些相同的任务，但界面不同。

有关如何自动执行 [Automator 在 Mac 上重命名文件](/blog/macos-automator-rename-files-guide) 的完整步骤，请阅读专用的 Automator 指南。

### 快捷方式：苹果现在正在努力的地方

Shortcuts 随 macOS Monterey 及更高版本一起提供，并且是 Apple 正在积极开发的工具，因此即使您现有的 Automator 工作流程仍在运行，也值得了解。对于批量重命名，它涵盖了“重命名Finder项”的大部分功能，使用不同的装配模型：构建一个小循环而不是配置一个操作。

最小的批量重命名快捷方式如下所示：

1. 启动一个新快捷方式，并将 **接收** 输入设置为 **快速操作** 中的 **文件**。
2.添加**Repeat with Each**，传入**Shortcut Input**。
3. 在循环内，添加 **重命名文件**，将文件设置为 **重复项目**，并使用 **文本** 构建新名称 - 例如 **格式日期** 结果、下划线和重复索引。
4. 在快捷方式详细信息窗格中，启用**用作快速操作**并勾选**Finder**。

然后，该快捷方式会出现在 Finder 右键单击​​“快速操作”子菜单中，因此您可以选择文件并运行它，然后整个批次就会被重命名。

在实践中有两个限制很重要。 Shortcuts 仍然是基于模式的——它可以根据日期、计数器或现有文本组成名称，但它无法确定 PDF 是租赁协议。并且通过快捷方式执行的重命名不在 Finder 的撤消堆栈中，因此 Cmd+Z 不会反转它；首先在复制的文件夹上进行测试。

如果您已经有可用的 `.workflow` 文件或需要文件夹操作，请选择 Automator；对于任何新事物，请选择“快捷方式”，因为这是 Apple 不断更新的路径。

## 方法 3：在 Mac 上批量重命名文件的终端脚本

如果您熟悉命令行，shell 脚本可以让您在 Mac 上最大程度地控制批量重命名。您可以使用正则表达式、条件、循环以及通过命令行工具可用的任何元数据。

### 何时使用脚本

- 您需要基于正则表达式的模式匹配（例如，从文件名中提取日期）
- 您想要根据文件元数据（EXIF 数据、PDF 属性）重命名
- 您需要条件逻辑（仅重命名符合特定条件的文件）
- 您已经对航站楼感到满意了

### 带循环的基本重命名

将所有 `.jpeg` 文件Renamed.to `.jpg`：

```bash
for f in *.jpeg; do
  mv "$f" "${f%.jpeg}.jpg"
done
```

### 替换文件名中的文本

将当前目录中所有文件名中的空格替换为连字符：

```bash
for f in *\ *; do
  mv "$f" "${f// /-}"
done
```

### 从文件元数据添加日期前缀

使用 `exiftool` 在每个 JPEG 上添加 EXIF 创建日期作为前缀：

```bash
for f in *.jpg; do
  date=$(exiftool -d "%Y-%m-%d" -DateTimeOriginal -s3 "$f")
  mv "$f" "${date}_${f}"
done
```

### 带零填充的顺序编号

使用前缀和零填充数字重命名一组文件：

```bash
counter=1
for f in *.png; do
  mv "$f" "$(printf 'slide-%03d.png' $counter)"
  counter=$((counter + 1))
done
```

### 使用 `rename` 命令（基于 Perl）

如果您通过 Homebrew (`brew install rename`) 安装 Perl `rename` 实用程序，则可以通过单个命令获得正则表达式支持：

```bash
rename 's/IMG_/vacation-/' *.jpg
```

这会将当前目录中每个 `.jpg` 文件名中的 `IMG_` 替换为 `vacation-`。

### 脚本限制

脚本功能强大，但需要技术知识。重命名脚本中的拼写错误可能会损坏整个目录中的文件名，并且无法撤消。始终首先在文件副本上进行测试，或者在 `mv` 之前使用 `echo` 来预览将会发生的情况。完整的 [安全批处理文件重命名指南](/blog/how-to-safely-batch-rename-files) 解释了跨 GUI 工具和脚本的试运行、扩展和冲突检查、链接文件风险以及恢复选项：

```bash
for f in *.jpg; do
  echo "mv $f -> vacation-${f#IMG_}"
done
```

脚本还与 Finder 和 Automator 具有相同的基本限制：它们应用规则，而不是理解。脚本无法查看图像并决定它显示的内容。对于内容感知重命名，您需要人工智能。

## 方法 4：AI 辅助内容感知重命名

AI重命名与上述每种方法都不同。它不是对文件名应用模式或规则，而是分析每个文件的实际内容并根据找到的内容生成描述性名称。 Stripe 仪表板的屏幕截图变为 `stripe-monthly-revenue-chart.png`。扫描的 PDF 变为 `apartment-lease-agreement-2026.pdf`。下载的照片变为 `golden-gate-bridge-foggy-morning.jpg`。

### 何时使用 AI 重命名

- 带有时间戳名称的屏幕截图无法告诉您有关内容的任何信息
- 名称为 `scan_001.pdf` 的扫描文档和 PDF
- 下载的图像名称无意义，例如 `download.jpg` 或 `IMG_4392.heic`
- 文件名应描述文件实际包含内容的任何文件夹

### 它是如何工作的

1. 选择文件或将工具指向文件夹
2. AI分析每个文件：阅读文档中的文本、识别图像中的对象和场景、采样视频帧以及理解屏幕截图中的UI元素
3.它根据内容为每个文件生成一个描述性文件名
4. 文件被单独重命名，每个文件都有一个反映其包含内容的唯一名称

这是与其他方法的主要区别：每个文件根据自己的内容获取自己的名称，而不是应用于组的共享模式。

## 批量重命名时的常见错误

### 忘记包含文件扩展名

使用脚本时，意外删除或覆盖文件扩展名是一个常见错误。从 `report.pdf` Renamed.to `quarterly-report`（不含 `.pdf`）的文件在双击时将无法正确打开。始终在重命名逻辑中保留扩展名。

### 不先在副本上进行测试

重命名具有破坏性。如果您将错误的模式应用于 500 个文件，则撤消它可能会很痛苦或不可能（尤其是对于脚本）。将一小部分文件样本复制到测试文件夹，在那里运行重命名，并在接触原始文件之前验证结果。

### 使用会导致问题的字符

在 macOS 上的文件名中避免使用以下字符：`/`、`:` 和空字节。虽然 macOS 比 Windows 更宽松，但在同步到云存储、传输到外部驱动器或与 Windows 或 Linux 用户共享时，带有特殊字符的文件名可能会导致问题。坚持使用字母、数字、连字符和下划线。

### 对问题应用错误的方法

使用 Finder 的替换文本重命名混合屏幕截图的文件夹是浪费时间，因为每个屏幕截图显示的内容都不同。相反，用AI重命名一批只需要把`IMG_`改成`vacation-`的文件就有点大材小用了。将工具与实际任务相匹配。

### 忽略排序顺序

如果您需要按特定顺序排列文件，请使用零填充数字（`001`、`002`，而不是 `1`、`2`）。如果没有填充，文件 `10` 在 Finder 中会在 `1` 和 `2` 之间排序，因为它按字母顺序排序，而不是按数字排序。对于 1000 个文件以下的集合，至少使用三位数字。

## 获得更好的批量重命名结果的提示

### 首先建立命名约定

在重命名任何内容之前，请确定您的约定。您会使用连字符或下划线吗？小写还是混合大小写？是否有日期前缀？制定约定意味着您重命名一次并且名称仍然有用。如需指导，请阅读 [文件命名约定：任何工作流程的最佳实践](/blog/file-naming-conventions-best-practices)。

### 重命名之前对文件进行分组

不要尝试一次性重命名混合文件类型的整个文件夹。将照片、文档和屏幕截图分开，然后使用适当的工具和模式批量重命名每个组。这可以避免将照片命名方案应用于 PDF，反之亦然。

### 立即使用 Finder 的撤消功能

Finder 的批量重命名支持 Cmd+Z 撤消，但仅限于重命名后立即执行。如果您先执行其他 Finder 操作，撤消历史记录将继续。重命名后立即检查结果，如果出现问题，请立即撤消。

### 组合复杂作业的方法

现实世界的文件夹通常需要不止一种方法。您可以使用 Finder 去除公共前缀，然后使用 [Zush在Mac上批量重命名文件](/mac) 并为需要内容感知重命名的文件生成描述性名称。事件照片的顺序重命名、屏幕截图的 AI 重命名以及用于定期导出的 Automator 都可以在同一工作流程中共存。

### 保持下载文件夹干净

Downloads 文件夹是命名不当的文件的最常见来源。设置下载的自动重命名可以防止混乱堆积。有关完整策略，请参阅 [如何在Mac上组织你的下载文件夹](/blog/how-to-organize-downloads-folder-mac)。

## ＃＃ 常问问题

### 在 Mac 上批量重命名文件最快的方法是什么？

当每个文件进行相同的更改时，Finder 是最快的方法：选择文件，右键单击，选择重命名，选择替换文本、添加文本或格式，然后应用。对于任何数量的文件来说，这大约需要十秒，并且不需要设置或下载。只有当一条规则适合整个批次时，它才是最快的 - 如果每个文件需要不同的描述性名称，则 Finder 根本无法完成这项工作，而读取文件内容的 AI 重命名器是更快的路线，尽管需要额外安装。

### 如何在 Mac 上批量重命名文件而不安装任何东西？

使用 Finder 的内置重命名工具。选择要重命名的文件，右键单击，然后从上下文菜单中选择“重命名...”。您可以替换文本、添加文本或使用连续数字设置名称格式。这适用于任何运行 macOS Yosemite (10.10) 或更高版本的 Mac，无需下载。

### Finder 可以根据文件内容重命名文件吗？

不会。Finder 的批量重命名是严格基于模式的。它可以替换文本字符串、添加前缀或后缀以及应用顺序编号，但它无法分析文件包含的内容。对于内容感知重命名（其中每个文件都获得唯一的描述性名称），您需要一个可以读取图像、视频和文档的人工智能工具。

### Finder 名称和索引是否在 Mac 上添加元数据？

不会。Finder 名称和索引仅更改文件名和可见文件路径。它不添加 Finder 标签、Finder 注释、EXIF 元数据、PDF 元数据或 Office 文档属性。 Spotlight 可以搜索新文件名，但更深层次的元数据需要单独的工具。

### 有没有办法在 Mac 上撤消批量重命名？

是的，如果您使用 Finder。批量重命名后，立即按 Cmd+Z 撤消整个操作。所有文件都恢复为其原始名称。此撤消仅可在下一个操作中使用。如果您使用终端脚本，则没有内置撤消功能，因此请始终先测试副本或在运行脚本之前保存原始文件名列表。

### 在 Mac 上重命名带有日期的照片的最佳方式是什么？

要添加文件的创建日期作为前缀，Automator 的“添加日期或时间”重命名操作是最简单的选项。要从相机元数据添加 EXIF 拍摄日期，请使用带有 `exiftool` 的终端脚本。为了添加日期和描述性内容名称，Zush 这样的人工智能工具可以将日期模式与内容分析结合起来。

### 如何在 Mac 上重命名数百张屏幕截图？

对于基本重命名（例如用项目名称替换“屏幕截图”），Finder 可以在几秒钟内处理完毕。要根据每个屏幕截图显示的内容为每个屏幕截图指定一个描述性名称，请使用 AI 重命名。选择所有屏幕截图，让 AI 分析每张图像，并获得 `slack-design-review-thread.png` 等名称，而不是 `Screenshot 2026-02-08 at 10.45.33.png`。为了自动重命名未来的屏幕截图，请设置文件夹监控。参见 [如何在Mac上自动重命名屏幕截图](/blog/rename-screenshots-automatically-mac)。

### 我可以根据 PDF 的内容批量重命名吗？

是的，使用人工智能重命名工具。 AI 读取每个 PDF 的文本内容并生成反映文档主题的文件名。名为 `scan_042.pdf` 的扫描发票将变为 `invoice-7842-webdesign-services-march-2026.pdf`。有关完整演练，请参阅 [如何自动重命名PDF文件：重复文件夹的AI工作流程](/blog/rename-pdf-files-automatically)。

### 批量重命名是否会影响文件元数据或创建日期？

在 Finder 中或通过 Automator 重命名文件不会更改其创建日期、修改日期或内部元数据。文件内容保持相同。仅文件系统中的文件名发生变化。但是，某些云同步服务可能会将重命名视为新上传，因此在重命名同步文件夹上的大批量文件后请检查同步状态。

### 批量重命名文件应使用什么命名约定？

当时间顺序很重要时，请使用小写字母、单词之间的连字符以及 ISO 格式 (YYYY-MM-DD) 的日期。避免空格、特殊字符和模糊标签，例如 `final-v2`。一致的约定使得文件可在操作系统之间排序、搜索和传输。有关详细指南，请参阅 [文件命名约定：最佳实践](/blog/file-naming-conventions-best-practices)。

## ＃＃ 结论

Mac 上的批量重命名不是一个工作流程。它是一组工作流程，正确的方法取决于您实际需要哪种重命名。

对于快速文本替换和顺序编号，Finder 无需任何设置即可在几秒钟内完成处理。对于自动运行的可重复规则，Automator 为您提供了文件夹操作和元数据访问的更多功能。对于正则表达式模式和完全控制，终端脚本允许您执行文件系统允许的任何操作。对于最难的重命名问题，基于每个文件的实际内容为每个文件指定一个唯一的描述性名称，人工智能驱动的工具填补了基于模式的方法无法达到的空白。

选择与实际问题相匹配的最简单的工具。可以时使用 Finder，必须时使用脚本，当文件名需要有意义时使用 AI。
