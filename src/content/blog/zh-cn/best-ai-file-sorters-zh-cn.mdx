## AI 文件分类工具如何决定文件放在哪里

每款分类工具都需要一种选择文件夹的方式。共有三种：

| 方式 | 你需要提供 | 示例 | 采用的工具 |
|---|---|---|---|
| **指令** | 一句描述文件夹的话 | “发票按公司分组，收据按月份分组” | Zush、Sortio |
| **类别列表** | 供 AI 挑选的文件夹名称 | 发票、收据、合同、其他 | RenameClick、AI File Sorter |
| **条件** | 基于名称、日期或文本的“如果/那么”规则 | 如果名称包含“invoice”，就移到财务文件夹 | Hazel、NameQuick Rules、File Juggler、DropIt |

指令最灵活，因为文件夹可以根据文件内容来创建：每个供应商、客户、月份或主题一个。类别列表可预期，但需要你自己维护。条件很精确，但会漏掉任何不符合规律的文件。Sparkle 则几乎不需要你输入，就会自己构建文件库。

想在同一处对比命名、监控和撤销功能的 Windows 用户，可以阅读 [Windows 11 AI 文件整理工具对比](/blog/best-ai-file-organizers-windows)。Mac 用户请看 [Mac 最佳 AI 文件整理工具](/blog/best-ai-file-organizers-mac)。

排名依据：应用决定文件夹的灵活程度、是否在同一次审阅中完成重命名、预览和撤销、本地 AI 选项，以及价格包含的内容。

## 1. Zush：综合最佳 AI 文件分类工具

Zush 在同一次审阅的批处理中完成两件事：按内容为每个文件命名，并把它分类到文件夹。你在 **Folder rules** 中决定文件夹的组织方式，这是一个最多可输入 2,000 个字符的日常语言字段。留空时，Auto 会按内容把文件分到少数几个宽泛、可复用的文件夹中。

![Zush 的 Folder rules 对话框，指令为发票按公司分组、收据按月份分组，并附有示例规则](/images/showcase/macos/folder-rules-light.webp)

它的独特之处：

- **它能读取更多类型的文件。** PDF 和纯图像扫描件、照片（包括 RAW 和 HEIC）、截图、Office 和 iWork 文档、设计文件、音频，以及包括 MP4、MOV、MKV、AVI 和 WMV 在内的视频。视频通过画面、语音、内嵌字幕和元数据来理解，所以“按主题给视频分组”也能实现。
- **名称和文件夹一起规划。** Template 决定文件名，Folder rules 决定位置，在任何文件移动之前你都能同时看到两者。
- **它能归档到你已有的文件夹。** 选择 **Destination folder** 并打开 **Reuse existing folders** 后，Zush 会把文件匹配到合适的现有文件夹，只有在都不合适时才新建。嵌套规则（先按年份，再按月份）也可以。
- **它能找出重复文件。** AI Rename 可以保留、标记副本或把副本移到废纸篓；副本不消耗额度，Undo 可以恢复它们。
- **它会持续分类新文件。** 把 Template 分配给 Monitor，新下载的文件或扫描件一到就会被重命名和分类。
- **免费开始，一次性买断。** 在 Zush Cloud AI 上有 50 次免费 AI 重命名，无需账号、银行卡或密钥。PRO 价格为每月 $10 或 $48 一次性买断，一次性许可证涵盖所有模式（包括云端）下的无限次重命名，最多可用于 3 台 Mac 和 Windows 设备。

使用 LM Studio 或 Ollama 时，分析和文件夹规划都留在你的电脑上。Rename History 在重启后仍会保留，Undo All 可以还原整批操作并标出冲突。在 Mac 和 Windows 上，你还可以只分类不重命名，并使用基于日期、页数等文件信息的规则（Mac 应用还能使用大小、相机和时长）。设置指南：[Mac](/blog/sort-files-into-folders-with-ai-mac) 和 [Windows](/blog/sort-files-into-folders-with-ai-windows)，完整说明见 [文件夹分类文档](/docs/folder-sorting)。

## 2. Sortio：最接近的替代品，还支持 Linux

Sortio 同样由指令驱动：用日常英语描述整理方式，审阅方案，它就会重命名文件、创建文件夹并把文件分流过去。它可以只把文件分到现有文件夹，并把无法匹配的文件放到备用文件夹。它支持 macOS、Windows 和 Linux，近期版本还能读取照片和视频的位置元数据。

免费版提供无限次规则分类（最多 5 条规则和 3 个 Spaces）、一次性 AI 试用、预览、分类历史和撤销。监控文件夹和自动化需要 Pro：每月 $14.99 或每年 $99，含每月 AI 用量（App Store 上标价 $19.99/月）。所有方案（包括免费版）都可以通过 Ollama 或 LM Studio 使用本地模型，也支持 BYOK。使用时需用电子邮件账号登录。

如果你需要 Linux 或团队席位，就选 Sortio。不足：免费版不再监控文件夹，而且除非自带密钥或运行本地模型，托管 AI 都按量计费。完整分析：[Zush 与 Sortio 对比](/blog/zush-vs-sortio)。

## 3. RenameClick：分到你定义好的类别中

RenameClick 有三种分类方式：**文件夹集合**，由 AI 从内置或自定义集合中挑选；**Metadata Folders**，根据日期或 EXIF 字段生成；以及 **Match Folders**，读取输出文件夹中最多三层深的现有子文件夹。Auto Flow 会在应用运行时监控一个文件夹，并移动或复制文件。

![RenameClick（图为 Mac 版）在执行 Rename & Move 之前把重命名后的文件分到 Legal Documents、Medical Documents 和 Uncategorized](/images/blog/competitors/renameclick.webp)

它的免费 AI 方案是一个自带的本地模型（约 4 GB，建议 16 GB 内存），因此无需配置 Ollama。自 4.1.2 版起，它支持 MP4、MOV、M4V 和 3GP 视频；不支持 MKV、WebM、AVI、RAW 和设计文件。免费版每月包含 100 次重命名或移动，终身版 $36 加增值税。

如果你的类别固定且事先已知，就选 RenameClick。不足：重命名撤销只在内存中保存 10 条记录，重启后清空。请看 [Zush 与 RenameClick 对比](/blog/zush-vs-renameclick)。

## 4. Sparkle：Mac 上省心的自动清理

Sparkle 按计划整理桌面、Downloads、文稿和其他文件夹。它会根据你的文件建立一个由文件夹组成的 AI Library，标记重复文件，并可以撤回它的整理。

它仅支持 Mac，没有免费版（15 天试用需要绑定银行卡），一台 Mac 每年 $119，或终身版 $179（最多 5 台）。它不会重命名文件。

如果你想对个人 Mac 做一劳永逸的清理，就选 Sparkle。不足：你无法具体规定文件夹逻辑，文件名也保持原样。请看 [Sparkle 替代品](/blog/sparkle-alternatives)。

## 5. NameQuick：重命名之后执行规则

NameQuick 按内容重命名文档，然后运行条件 Rules，把文件移到某个文件夹、添加标签、设置颜色标记或归档。它支持 Mac 和 Windows。

![NameQuick 宣传图，展示扫描的发票、收据和合同被重命名为带日期和供应商名称的文件](/images/blog/competitors/namequick.webp)

你可以获得 30 次免费 Managed 重命名，无需银行卡。Managed 方案每月 $12 起（500 次重命名），重命名包为 $19 购 500 次或 $39 购 1,500 次，$69 的 Self-Managed 许可证需要使用你自己的 API 密钥或本地模型。

如果你想在 AI 命名之后按“如果/那么”分流，就选 NameQuick。不足：每个目标位置都需要单独一条规则。请看 [Zush 与 NameQuick 对比](/blog/zush-vs-namequick)。

## 6. AI File Sorter：免费开源

AI File Sorter 是一款免费的 AGPL-3.0 桌面应用，支持 Windows、macOS 和 Linux（1.9.2 版）。它为每个文件建议类别和可选的子类别，支持允许类别的白名单，用本地视觉模型读取图片，从文档中提取文本，还能建议新的文件名。它可以使用本地模型或远程 API，“编辑 > 撤销上次运行”可以撤回最近一批操作。

如果你想免费做一次性清理，并且能自己挑选本地模型，就选 AI File Sorter。不足：音频和视频只根据内嵌元数据命名，项目文档也没有提到监控文件夹功能。

## 7. Hazel、File Juggler 和 DropIt：不含 AI 的规则

Hazel 6（$42，Mac）、File Juggler（$50 加税，Windows，3.1.9 版）和 DropIt（免费，Windows，最后一次发布于 2018 年 2 月）会监控文件夹，并根据条件执行操作：名称格式、扩展名、日期或匹配的文本。Softpedia 编辑给 Hazel 的评分为 5.0/5，给 File Juggler 的评分为 4.5/5。

不足：它们都无法理解照片、扫描件或视频的内容，所以每种情况都需要单独的规则。简单的情况 Zush 也能处理：一句“收据先按年份、再按月份分组”或“PDF 放到文稿，图片放到图片”就能按日期或类型分类，不需要为每种情况单独写规则。规则引擎留给脚本、命令或解压归档这类任务。请看 [Hazel 替代品](/hazel-alternative) 页面和 [Windows 上的 Hazel 替代品](/blog/hazel-for-windows-alternatives)。

## 常见问题

### 最好的 AI 文件分类工具是哪款？

对大多数 Mac 和 Windows 用户，我们推荐 Zush。你用日常语言描述文件夹或使用 Auto，Zush 会读取每个文件、重命名，并在你审阅整批结果后把它移进正确的文件夹。它能处理 PDF、扫描件、照片、视频和音频，也支持本地 AI。如果你需要 Linux，Sortio 是最接近的替代品。Zush 是我们开发的，所以请在副本上测试这两款。

### AI 能自动把文件分类到文件夹吗？

能。Zush、Sortio Pro、RenameClick 的 Auto Flow、NameQuick 和 Sparkle 都能把新文件移进文件夹，而无需你每次手动启动。在 Zush 中，把 Folder rules 保存到 Template 并分配给 Monitor：该文件夹中的每个新文件一到就会被重命名和分类。请先在手动批处理中测试 Template，以便检查它选择的文件夹。

### 有免费的 AI 文件分类工具吗？

AI File Sorter 免费开源。Zush 提供 50 次免费 AI 重命名，无需账号、银行卡或 API 密钥，足以真正测试文件夹分类。Sortio 提供一次性 AI 试用和免费的规则分类，NameQuick 提供 30 次免费重命名，RenameClick 在下载本地模型后每月提供 100 次免费重命名或移动。

### 哪款 AI 文件分类工具最物有所值？

取决于包含哪些内容。RenameClick 的 $36 加增值税终身版涵盖其本地模型或你自己的密钥，Sortio Pro 每年 $99，含 AI 用量。Zush 的 $48 一次性许可证包含托管的 Zush Cloud AI 以及 BYOK、Ollama 和 LM Studio、无限次重命名、今后的更新，以及最多 3 台 Mac 和 Windows 设备。

### 哪款 AI 文件分类工具能离线使用？

Zush 在 Mac 和 Windows 上可以通过 LM Studio 或 Ollama 离线分类：文件分析和文件夹规划都在你的电脑上运行。RenameClick 自带本地模型（建议 16 GB 内存），Sortio 的所有方案（包括免费版）都支持 Ollama 和 LM Studio，AI File Sorter 可使用本地模型。在云端模式下，Zush 会把文件内容发送到 Zush Cloud AI 或你自己的服务商进行分析。

### AI 文件分类工具和基于规则的整理工具有什么区别？

Hazel 或 DropIt 这类基于规则的整理工具，会移动符合你所写条件（如文件名格式或扩展名）的文件。Zush 这类 AI 文件分类工具会读取文件内容，并遵循“发票按公司分组”这样的指令，所以连名称毫无线索的文件也能分类。Zush 也能执行简单的按日期或文件类型分类的指令，所以只有在需要脚本或解压归档等操作时，才需要规则引擎。
