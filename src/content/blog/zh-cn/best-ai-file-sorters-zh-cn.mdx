## 三种分类方式

自然语言指令按供应商、客户、月份或主题分组：Zush、Sortio、Sparkle。固定类别列表：RenameClick、AI File Sorter。按名称、日期或文本条件分流：Hazel、NameQuick Rules、File Juggler、DropIt。指令灵活，列表需要维护，条件遇到意外文件可能失效。

Windows 用户可以在 [Windows 11 AI 文件整理软件对比](/blog/best-ai-file-organizers-windows)中统一比较命名、监控、恢复和文件夹移动功能。

## 1. Zush

选择 **Destination folder** 作为建议文件夹的根目录。

**Folder rules** 最多 2,000 字符；留空时 Auto 建立少量通用、可复用的文件夹。**Template** 指定日期、供应商、金额、客户或主题等名称字段；Folder rules 指定位置，两者一起预览。支持 PDF、纯图像扫描件、RAW、HEIC、Office、iWork、设计文件、16 种视频格式和音频；视频通过帧分析理解。

**Reuse existing folders** 使用合适的现有文件夹，必要时新建。**Monitor** 给新文件应用 Template，并记住创建过的文件夹。LM Studio 和 Ollama 让分析与文件夹规划在本机运行。PRO 包括 Zush Cloud AI，没有每月文件上限。分类是测试版，每批在目的地内建立一层文件夹。模糊文件应先确认。[Mac 步骤](/blog/sort-files-into-folders-with-ai-mac)、[Windows 步骤](/blog/sort-files-into-folders-with-ai-windows)。

## 2. Sortio

[Sortio](https://www.getsortio.com/)从指令生成名称、文件夹和移动计划。可以限制为现有文件夹，并给不匹配文件指定备用目录。免费方案包括最多五条规则的无限规则分类、监控、撤销和一次 AI 试用。所有方案支持 BYOK 与 Ollama；Pro 有月度 AI 额度。列出文档、图像、PDF、表格，但未发布完整格式表。Linux 或团队选 Sortio，音视频、精细命名和买断选 Zush。[对比](/blog/zush-vs-sortio)。

## 3. RenameClick

[RenameClick](https://rename.click/)提供 AI Categories、基于日期或 EXIF 的 Metadata Folders，以及从最多 50 个顶层文件夹中选择的 Match Folders。Auto Flow 在应用运行时监控、移动或复制。分析无限，每月 100 次成功改名或移动免费，附带本地模型。视频、RAW、设计不在公开格式列表中。适合固定类别；从内容生成公司等分组可选 Zush。[对比](/blog/zush-vs-renameclick)。

## 4. Sparkle

[Sparkle](https://makeitsparkle.co/)定时整理桌面、下载、文稿等目录，构建 AI Library，接受自然语言请求，清理重复项和旧截图时先放入废纸篓。仅 Mac，也包含在 Every 套装中。不改名。适合个人 Mac 自动清理；需要名称、Windows 或明确分类逻辑时选 Zush。[替代工具](/blog/sparkle-alternatives)。

## 5. NameQuick

[NameQuick](https://www.namequick.app/)先按内容改名，再执行 Rules 移动、打标签、设颜色或归档。Managed 每月 $12 起，含 500 次改名。$69 的 Self-Managed 需要自己的 API 密钥或本地模型。每个目标都要设置条件。[对比](/blog/zush-vs-namequick)。

## 6. AI File Sorter

[AI File Sorter](https://github.com/hyperfield/ai-file-sorter)是免费的 AGPL 应用。建议类别、可选子类别和名称，支持允许列表、本地视觉模型和文档文字提取。使用本地模型或个人密钥，可撤销最后一次操作。没有自由分组指令或文件夹监控。音视频按内嵌元数据分类。适合愿意配置模型的用户做一次性整理。

## 7. Hazel、File Juggler、DropIt

[Hazel](https://www.noodlesoft.com/)（Mac，$42）、[File Juggler](https://www.filejuggler.com/)（Windows，约 $40）、[DropIt](https://www.dropitproject.com/)（Windows，免费）监控名称、扩展名、日期或文本条件。可预测文件处理可靠，但不能理解照片、扫描或视频内容。AI 名称可简化规则。[Hazel 替代](/hazel-alternative)、[Windows 选项](/blog/hazel-for-windows-alternatives)。

## 选择与小规模测试

自由指令、多格式选 Zush；Linux、团队选 Sortio；固定类别选 RenameClick；Mac 清理选 Sparkle；免费选 AI File Sorter；精确规则选 Hazel 等。先复制 20 个混合文件，包括发票、收据、照片、截图、扫描和视频。写实际规则，检查文件夹名称与位置，应用后测试撤销，再用于真实下载目录或档案。[30 条指令](/blog/ai-folder-sorting-prompts)、[文档](/docs/folder-sorting)、[价格](/pricing)。

## 常见问题

### 一般推荐哪款？
Mac 和 Windows 上需要预览、音视频、本地 AI、PRO 无月度上限时选 Zush。

### 可以自动处理吗？
Zush、Sortio、RenameClick、Sparkle 支持移动。在 Zush 中将 Folder rules 保存到 Template 并分配给 Monitor，处理监控文件夹直接包含的新文件。

### 免费选项有哪些？
AI File Sorter、Zush 免费 50 次、Sortio 一次 AI 试用、RenameClick 每月 100 次改名或移动。

### 哪些能离线运行？
Zush 使用 LM Studio 或 Ollama；RenameClick 使用附带模型；Sortio 使用 Ollama；AI File Sorter 使用本地模型。

### 与规则工具的区别？
规则检查名称或扩展名。AI 读取内容，即使旧名称没有线索，也可把发票按公司分类。
