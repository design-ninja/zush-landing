## 原地重命名，还是移到文件夹？

每款 AI 文件整理工具都会做以下一件或两件事：

1. 重命名文件，让 File Explorer 和 Windows 搜索能按内容找到它们。
2. 把文件移进一套文件夹结构，有时是它自己设计的结构。

两者都会改变文件路径，所以快捷方式和项目链接可能失效。移动的影响更大，因此需要预览，以及重启后依然有效的撤销。如果你得打开文件才知道它是什么，那你首先面临的是命名问题。

## 1. Zush：基于内容的名称和 AI 文件夹分类

[Windows 版 Zush](/windows) 支持 Windows 10 和 11，可从 [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X) 安装。把一个装满截图、PDF、扫描件、照片、Office 文档、设计文件、音频或视频的文件夹拖进去。Zush 会读取每个文件，并建议类似 `2026-09-18_acme_invoice_1042.pdf` 或 `stripe-revenue-dashboard-september.png` 的名称。视频根据语音、内嵌字幕和元数据命名（包括 MKV），音乐即使没有标签也能识别。

开箱即用。前 50 次 AI 重命名在托管的 Zush Cloud AI 上运行，无需账号、银行卡、API 密钥，也不用下载模型，云端模式只需 4 GB 内存。如果文件夹绝不能离开本机，可以切换到 Ollama 或 LM Studio；可选的本地语音识别也能让视频转写留在本地。

任何改动之前你都能看到每条建议。双击名称即可编辑，也可以重新生成某一条，或应用整批。现成的 Templates（包括 Movies & TV 和 Remove Duplicates）以及 145+ 个 Naming Blocks 让名称保持一致：日期、供应商、金额、客户、带前导零的序号。

![Windows 版 Zush 按内容重命名一批混合文件，在应用之前列出每个拟定的文件名](/videos/windows/zush-batch-rename.mp4)

如果还要归档，可以使用 Auto，或者在 **Folder rules** 中写一条规则，例如“发票按公司分组，收据按月份分组”。预览分组，选择 **Destination folder**，并可启用 **Reuse existing folders** 复用已有文件夹。规则可以嵌套，也可以使用日期、页数等文件信息，你还可以只分类文件而保留当前名称。AI Rename 还能识别重复文件：保留、在名称中标记，或移到回收站。副本不消耗额度，Undo 可以恢复它们。分步教程：[在 Windows 上用 AI 把文件分类到文件夹](/blog/sort-files-into-folders-with-ai-windows) 和 [30 条现成的文件夹规则](/blog/ai-folder-sorting-prompts)。完整的设置说明见 [文件夹分类文档](/docs/folder-sorting)。

![Windows 版 Zush 在执行 Rename & sort 之前预览按内容划分的文件夹分组和拟定的文件名](/images/showcase/windows/folder-sorting-light.webp)

Monitor 会把保存好的 Template 应用到 Downloads 或扫描仪文件夹中的新文件上。Rename History 在重启后仍保留新旧名称，Undo All 可以还原整批操作，列出所有冲突，并提供以新名称恢复的选项。

价格：$10/月或 $48 一次性买断。一次性许可证包含所有模式（Zush Cloud AI、BYOK、Ollama、LM Studio）下的无限次重命名、今后所有更新、最多 3 台 Mac 和 Windows 设备，以及 14 天退款。在 Microsoft Store（美国区）上，Zush 获得 5.0 分（8 个评分），Softpedia 编辑评测给出 4.5/5，均截至 2026 年 11 月 17 日。

## 2. Sortio：基于指令的分类，还支持 Linux

Sortio 接受一句日常语言的指令（“发票按年份放，截图按项目放”），展示方案，然后重命名、创建文件夹并移动文件。它支持 Windows 10/11、macOS 和 Linux，使用时需用电子邮件账号登录。

免费版包括最多 5 条规则和 3 个 Spaces 的规则分类、一次性 AI 试用、预览、分类历史和撤销。监控文件夹和自动化现在需要 Pro，价格为每月 $14.99 或每年 $99，含每月 AI 用量。使用你自己的密钥可以绕过该用量限制，Ollama 则让处理留在本地（至少 8 GB 内存）。

如果你需要 Linux 或团队席位，就选 Sortio。不足：托管 AI 按月限量，免费版也不再监控文件夹。请看 [Zush 与 Sortio 对比](/blog/zush-vs-sortio)。

## 3. Wisfile：面向文档的免费选择

Wisfile 免费，完全在你的设备上运行，支持 Windows 和 Mac。它根据内容（标题、作者、年份）重命名文档，还能把一批文件按主题分到不同文件夹。支持 `Author-Year-Title` 这样的模板。

![Wisfile 官方示意图：杂乱的 PDF 文件名被改成带日期、描述清楚的文档文件名](/images/blog/competitors/wisfile.webp)

如果预算最重要，想一次性清理 PDF 和 Word 归档，就选 Wisfile。不足：没有撤销，也没有文件夹监控，而且它专注于 PDF 和 Word，不处理图片或视频。请在副本上操作。

## 4. RenameClick：自带本地模型

RenameClick 的免费 AI 方案是一个内置本地模型，下载约 4 GB，建议 16 GB 内存。你不需要配置 Ollama，这确实方便。它可以重命名图片、文档、音频，自 4.1.2 版起还支持视频（MP4、MOV、M4V 和 3GP，使用画面加本地语音转写）。MKV、WebM、AVI、RAW 照片和设计文件不在其支持格式列表中。Auto Flow 会在应用运行时重命名并移动新文件。

免费版提供无限次分析和每月 100 次重命名或移动；首次应用之前，应用必须联网一次。终身版 $36 加增值税，直接下载版本最多可用于 3 台设备，仅在法律要求的情况下提供退款。Standard Rename 在内存中保存 10 条撤销记录，重启后清空。评分：Microsoft Store（美国区）3.0 分（6 个评分），Softpedia 编辑评分 3.5。

![RenameClick（图为 Mac 版）在执行 Rename & Move 之前把重命名后的文件分到 Legal Documents、Medical Documents 和 Uncategorized](/images/blog/competitors/renameclick.webp)

如果你想要无需配置的离线 AI，并且内存足够，就选 RenameClick。完整分析：[Zush 与 RenameClick 对比](/blog/zush-vs-renameclick)。

## 5. NudgeFile：免费的本地 AI 文件夹监控工具

NudgeFile 是一款较新的 Windows 10 和 11 应用，可从 Microsoft Store 免费下载。其官网称，它会监控 Downloads 和桌面等文件夹，为新文件统一命名，把它们分流到目标文件夹，并用校验和加本地视觉 AI 查找重复项。AI 通过 Ollama 在本地运行，也有云端选项。“Human Approval Pipeline”让你审阅建议，或让它们自动执行；官网还称任何操作都可以一键撤销。

如果你想在 Windows 上有一款免费、始终运行的本地整理工具，就选 NudgeFile。不足：其 FAQ 称模型分析的是“文件元数据和结构”，官网既没有列出支持的文件类型，也没有列出付费档位，所以请先用你自己的文件测试。

## 6. Foldora：$14.99 的一次性本地清理

Foldora 支持 Windows 10、11 和 macOS。它在本地分析选中的文件，建议文件夹和更清晰的文件名，并在你确认预览后应用。终身版 $14.99。购买、激活和定期许可证检查都需要联网。

如果你想便宜地在本地一次性整理一批混合文件，就选 Foldora。不足：没有文件夹监控，厂商自己也表示并未宣传有保证的一键撤销，所以大规模改动前请先备份。

## 7. File Juggler：不含 AI 的可预期规则

File Juggler 是一款历史悠久的 Windows 自动化工具，仍在维护（3.1.9 版于 2026 年 10 月 30 日发布）。你编写规则（“如果 Downloads 中的 PDF 包含‘Invoice’，就用日期重命名并移到 Finance”），它会在文件到达时执行这些规则。它可以读取 PDF、Word 和 Excel 文本用于规则判断。Softpedia 编辑评分为 4.5/5。

一次性许可证 $50 加税，提供 30 天全功能试用。不足：没有 AI 也没有 OCR，所以每种情况都需要一条规则，纯图像扫描件也需要单独的 OCR 步骤。更多选择：[File Juggler 替代品](/blog/file-juggler-alternatives)。

## 8. DropIt：免费的规则引擎

DropIt 免费且开源。规则可以按名称、大小、日期或正则表达式匹配文件；你可以把文件拖到它上面，也可以让它定时扫描监控文件夹。它有 21 种操作，包括移动、复制、重命名、压缩和解压。

不足：最新版本 8.5.1 发布于 2018 年 2 月，所以别指望有更新或 AI。如果只需按扩展名或名称格式免费分类，就选 DropIt。如果你是从 Mac 转过来的，请看 [Windows 上的 Hazel 替代品](/blog/hazel-for-windows-alternatives)。

## 常见问题

### Windows 11 上最好的 AI 文件整理工具是哪款？

我们推荐 Zush：它按内容重命名文件，并通过 Auto 或你自己的指令把文件分类到文件夹，提供预览、Templates、监控和持久撤销。如果你需要 Linux，可以选 Sortio；想要自带本地模型，选 RenameClick；如果不含 AI 的精确规则就适合你的文件，选 File Juggler。Zush 是我们开发的，所以请先在副本上测试任何一款。

### Windows 上有免费的 AI 文件整理工具吗？

有。Wisfile 免费且在本地处理 PDF 和 Word 文件，NudgeFile 可从 Microsoft Store 免费下载。Zush 提供 50 次免费 AI 重命名，无需账号、银行卡或 API 密钥。RenameClick 在下载 4 GB 模型后每月允许 100 次重命名或移动。DropIt 也免费，但它使用固定规则而不是 AI。

### 哪款 Windows 整理工具的一次性价格最划算？

Foldora $14.99，RenameClick $36 加增值税，但两者都只能使用本地 AI 或你自己的 AI。Zush 的 $48 许可证包含托管的 Zush Cloud AI 以及 BYOK、Ollama 和 LM Studio、无限次重命名、今后所有更新、最多 3 台 Windows 和 Mac 设备，以及 14 天退款。File Juggler 的 $50 许可证买到的是规则，而不是 AI。

### AI 文件整理工具会上传我的文件吗？

取决于模式。使用 Ollama 或 LM Studio 的 Zush 会把分析留在你的 PC 上；Zush Cloud AI 和 BYOK 会把文件内容发送到云端模型来命名。Wisfile、Foldora 和 RenameClick 的内置模型在本地运行，NudgeFile 默认使用本地 AI。Sortio 提供托管 AI，所有方案也都支持 BYOK 或 Ollama 和 LM Studio。在让任何应用处理敏感文件夹之前，请先检查它的 AI 设置。

### AI 能在 Windows 上自动整理我的 Downloads 文件夹吗？

能。Zush 可以监控 Downloads，重命名新文件，并应用 Template 中保存的文件夹规则。RenameClick 的 Auto Flow、Sortio Pro 和 NudgeFile 也能监控文件夹。在自动化重要目录之前，请先从一个测试文件夹开始。[Downloads 自动化指南](/ai-file-sorter) 介绍了 Zush 的设置方法。
