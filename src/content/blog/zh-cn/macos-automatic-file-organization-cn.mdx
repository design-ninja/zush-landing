## 自动文件管理器首先应该处理什么

从那些既频繁又烦人的文件开始。我们的目标不是在第一天就建立一个宏伟的统一系统。目标是消除一两个反复出现的痛点，看到结果，并从那里开始扩展。

自动化的最佳候选人：

- **Screenshots** - macOS 将其命名为 `Screenshot 2026-03-12 at 10.44.11.png`，这不会告诉您任何有关内容的信息
- **下载文件夹** - 浏览器下载、电子邮件附件和 AirDrop 文件在通用名称下快速堆积
- **定期导出** - 每周来自同一应用程序的发票、银行对账单、报告
- **传入的相机照片** - `IMG_4382.HEIC` 六个月后就没用了
- **重复的文档转储** - 客户可交付成果、研究 PDF、项目资产

当自动化消除每周的烦恼时，而不是当它创建一个您永远不会维护的复杂系统时，它才是最有效的。

### 如何识别最严重的罪犯

打开“Finder”并按修改日期对“下载”或“桌面”文件夹进行排序。查看最后 50 个文件。数一数有多少个的名字可以告诉你里面有什么。如果答案小于一半，则该文件夹是一个强大的自动化候选者。

您还可以检查文件夹中的文件量。打开“Terminal”并运行：

```bash
ls -1 ~/Downloads | wc -l
```

如果数字超过 200，则说明您有积压的工作值得自动化。

## Smart Folders：逐步设置

Smart Folders 不移动文件。它们根据搜索条件动态显示文件。将它们视为已保存的“Spotlight”搜索，显示在“Finder”侧栏中。

它们对于在分散的位置查找文件非常有用，而无需重组文件夹层次结构。

### 如何创建智能文件夹

1.打开Finder
2. 按 **Cmd + F** 或转到 **文件 > 新建智能文件夹**
3. 点击右上角的**+**按钮添加条件
4. 设置您的条件（参见下面的示例）
5. 单击“**保存**”并命名智能文件夹
6.选中**添加到侧边栏**，使其保持可访问性
7. 选择保存 `.savedSearch` 文件的位置（默认即可）

### 最有用的智能文件夹标准

|智能文件夹用途|设定标准|
|---|---|
|最近的截图|种类 = 图片，名称包含“屏幕截图”，修改日期 = 最近 7 天|
|大文件吃磁盘|文件大小 > 500 MB|
|最近的 PDF|种类 = PDF，修改日期 = 过去 30 天|
|需要审查的文件|标签=“评论”，种类=文档|
|所有演示|种类 = 演示|
|最近下载|文件夹 = 下载，修改日期 = 最近 3 天|

### 高级智能文件夹提示

- 按住 **Option**，同时单击 **+** 按钮添加复合条件（AND/OR 分组）
- 您可以按文件扩展名、创建日期、上次打开日期和数十个其他元数据字段进行过滤
- “Smart Folders”实时更新，因此它们始终反映您驱动器的当前状态
- 它们适用于所有已安装的卷，包括外部驱动器

“Smart Folders”不是真正的自动化，因为它们不会移动或重命名任何内容。但它们是一个很好的第一步，因为它们让你在遵守规则之前了解需要组织什么。

如需更深入的了解，请参阅我们的“[macOS 文件搜索电动工具指南](/blog/finder-tags-guide-organize-files-mac)”。

## Automator 和 Shortcuts：构建真实的工作流程

“Automator”（及其较新的兄弟产品“Shortcuts”）可让您创建实际的文件处理工作流程。他们可以使用拖放界面重命名、移动、复制、调整大小和转换文件。

### Automator 文件夹操作：按文件类型自动对下载进行排序

这是最实用的“Automator”工作流程之一。它会监视您的“下载”文件夹，并根据文件的扩展名将文件移动到子文件夹中。

**逐步设置：**

1.打开**Automator**（在Spotlight中搜索）
2. 选择 **文件夹操作** 作为文档类型
3. 在顶部，将“文件夹操作接收添加到的文件和文件夹”设置为 **下载** 文件夹
4. 添加 **运行 Shell 脚本** 操作
5. 将“传递输入”设置为**作为参数**
6. 粘贴以下脚本：

```bash
for f in "$@"; do
    ext="${f##*.}"
    ext=$(echo "$ext" | tr '[:upper:]' '[:lower:]')
    case "$ext" in
        pdf)
            dest="$HOME/Documents/PDFs" ;;
        jpg|jpeg|png|heic|webp|gif)
            dest="$HOME/Pictures/Downloads" ;;
        zip|gz|tar|dmg)
            dest="$HOME/Downloads/Archives" ;;
        doc|docx|xlsx|pptx|csv)
            dest="$HOME/Documents/Office" ;;
        *)
            dest="" ;;
    esac
    if [ -n "$dest" ]; then
        mkdir -p "$dest"
        mv "$f" "$dest/"
    fi
done
```

7. 使用描述性名称（例如“按类型对下载进行排序”）保存工作流程
8. 文件夹操作现已激活。下载中的新文件将自动排序。

### Shortcuts：macOS Ventura+ 的更简单替代方案

如果您使用的是“macOS”Ventura 或更高版本，“Shortcuts”可以替代“Automator”来完成许多任务。优点是界面更简洁，与系统触发器的集成更紧密。

**示例：重命名和移动屏幕截图**

1.打开**Shortcuts**
2.创建新的快捷方式
3. 添加操作：**获取文件夹内容**（设置为您的 Screenshots 文件夹）
4.添加操作：**过滤文件**，其中名称包含“屏幕截图”
5. 添加操作：**重命名文件** 使用“Screenshot-[创建日期]”等模式
6. 添加操作：**移动文件**到您想要的目标文件夹
7. 要自动运行，请转到 **Automation** 选项卡，并在文件添加到 Screenshots 文件夹时创建触发器

“Shortcuts”更适合一次性自动化。 “Automator”更适合需要 shell 脚本访问的复杂多步骤工作流程。有关基于“Automator”的文件重命名的完整演练，请参阅我们的“[Automator 重命名文件指南](/blog/macos-automator-rename-files-guide)”。


## “Hazel”用于复杂的基于规则的路由

当文件夹需要连续的多条件规则、背景移动、标签、档案或脚本时，“Hazel”非常有用。代表性规则可能会将名称包含“invoice”的 PDF 移动到年份和月份文件夹中，同时保持不匹配的下载不变。

“Hazel”和内容感知命名解决了不同的层问题。当扩展名、日期、标签、文件名模式或提取的文本提供可靠条件时，“Hazel”表现出色。当屏幕截图、照片、视频或通用扫描件在收到可搜索名称之前必须被理解时，人工智能命名工具会更有用。

保持顺序明确：首先重命名，然后路由生成的文件名。不要让两个工具同时监视和改变同一个摄入文件夹。有关逐项产品功能的比较，请参阅“[“Zush”作为“Hazel”的替代品](/hazel-alternative)”。

## 基于规则的自动化失败的地方

当文件已经通过其名称、扩展名或元数据告诉您它是什么时，规则就起作用。

当文件到达时它们会失败：

- `IMG_4382.HEIC`
- `屏幕截图 2026-03-12 10.44.11.png`
- `下载(7).jpg`
- `文档.pdf`
- `无标题.png`
- `图像 (3).webp`

规则可以将这些文件移动到特定文件夹。它无法解释它们所包含的内容。如果没有描述性名称，即使它们完美地组织到文件夹中，您以后也无法找到它们。

这正是基于人工智能的命名的用武之地。分析文件内容（图像中的实际像素、视频中的采样帧、PDF 中的文本、文档布局）的工具可以生成描述文件实际内容的名称。

有关 AI 文件重命名在实践中如何工作的更多信息，请参阅我们的“[适用于 Mac 和“Windows”的文件重命名器](/)”。

## 推荐的自动文件管理器设置：逐步

这是一个实用的设置，您可以在一小时内构建，将上述工具组合成一个统一的系统。这是平衡努力与结果的方法。

### 第 1 步：审核您当前的混乱情况

打开“下载”、“桌面”和“文档”文件夹。请注意哪些文件夹包含最多无用名称的文件。选择最上面的两个问题文件夹。

### 步骤 2：添加 Zush 内容感知命名

安装“[Mac 版“Zush”](/mac)”，将其指向复制的接收文件夹，选择一个模板，然后查看第一个建议的名称。在启用持续监控之前，请保持“Rename History”可用。

### 第 3 步：可以选择创建“Smart Folders”以实现可见性

在Finder中设置三个Smart Folders：

1. **最近的大文件** -- 文件大小 > 100 MB，修改日期 = 最近 30 天
2. **未排序的屏幕截图** -- 种类 = 图像，名称包含“屏幕截图”，修改日期 = 过去 14 天
3. **最近文档** -- 种类 = 文档或种类 = PDF，修改日期 = 最近 7 天

这些可以让您立即了解需要注意的事项。

### 第 4 步：（可选）设置基本文件路由

根据您的喜好选择以下选项之一：

**选项 A：Automator 文件夹操作**（免费，内置）
- 创建上述下载排序工作流程
- 需要 10 分钟，处理最常见的文件类型

**选项B：Hazel规则**（付费，更强大）
- 安装 Hazel 并为您的下载文件夹设置 3-5 条规则
- 专注于：PDF 到文档、图像到图片、存档到专用文件夹
- 添加30天以上文件的清理规则

**选项 C：Shortcuts 自动化**（免费，macOS Ventura+）
- 创建按类型对文件进行排序的快捷方式
- 将其设置为按计划触发或手动触发

### 步骤5：测试后启用Zush监控

![“Zush”监视器选项卡显示文件夹监视配置，并选择了桌面文件夹](/images/showcase/macos/monitor-light.webp)

验证测试批次后，设置“Zush”来监视您的“屏幕截图”文件夹和“下载”文件夹。这可以处理基于规则的工具无法正确命名的文件：

- 屏幕截图根据可见的应用程序和内容进行重命名
- PDF 根据文本内容重命名
- 照片根据图像中的内容重命名
- 下载的图像获得描述性名称，而不是“download (7).jpg”

### 第 6 步：设置每周回顾

即使采用自动化，每周也要花 5 分钟查看您的“Smart Folders”。这可以捕获边缘情况并帮助您随着时间的推移完善规则。

### 第7步：逐步扩展

运行此设置一周后，看看仍然存在哪些问题。根据需要添加新的“Hazel”规则或“Smart Folders”。不要试图预先覆盖每个边缘情况。

## 要避免的常见错误

**过早过度自动化。** 在知道哪些文件实际需要路由之前，不要构建 20 条规则“Hazel”设置。从 2-3 条规则开始并扩展。

**忽略命名问题。** 如果每个文件都命名为“IMG_4382.HEIC”，则将文件移动到整齐的文件夹中并没有帮助。您仍然需要打开每个文件来查找您需要的文件。重命名至少和排序一样重要。

**不测试您的规则。** 在对真实下载文件夹启用文件夹操作或“Hazel”规则之前，请在包含示例文件的虚拟文件夹上进行测试。一项错误的移动规则可能会将文件分散到整个驱动器中。

**忘记嵌套文件夹。** 大多数自动化工具默认情况下都会监视单个文件夹级别。如果文件位于子文件夹内，则需要显式配置递归监控。

**没有回滚计划。** 任何重命名或移动文件的自动化都应该有一个撤消路径。 Hazel 保存日志。 Zush 支持回滚。 Automator 不会——所以要小心破坏性行为。

## 常问问题

### 如何在不安装任何东西的情况下在 Mac 上自动进行文件组织？

使用内置工具：“Smart Folders”用于显示文件，“Automator”或“Shortcuts”用于文件路由。 “Smart Folders”位于“文件”>“新建智能文件夹”下的“Finder”中。 Automator 可以创建当文件到达特定目录时触发的文件夹操作。这些涵盖了按文件类型、日期和名称模式进行基本排序，无需任何第三方软件。

### “macOS”上的“Automator”和“Shortcuts”有什么区别？

“Automator”是较旧的工具，具有更多操作类型、shell 脚本支持和文件夹操作集成。 Shortcuts 较新（macOS Monterey+），具有更清晰的界面，并支持系统触发器和 Siri 集成。特别是对于文件自动化，“Automator”仍然更强大，因为它具有 shell 脚本操作和更​​广泛的文件操作选项。苹果正在慢慢地将功能迁移到“Shortcuts”，因此两者都值得了解。

### Hazel 可以根据文件内容重命名文件吗？

Hazel 可以读取 PDF 和文档中的文本内容，并将其用于重命名规则。例如，您可以从 PDF 中提取日期或关键字并将其包含在文件名中。然而，“Hazel”无法分析图像或视频内容——它没有视觉能力。对于屏幕截图、照片、屏幕录制和其他视觉文件，您需要一个基于 AI 的工具来实际查看文件中的内容。

### 如何防止我的下载文件夹变得混乱？

建立两层体系。首先，创建路由规则（通过“Automator”或“Hazel”），在文件到达时将其移动到特定类型的文件夹中。其次，添加一条清理规则，将超过 30 天的文件移动到“存档”文件夹或“废纸篓”中。这种组合可以使您的下载文件夹保持简洁，而不会丢失任何重要的内容。请参阅我们的“[组织下载文件夹的指南](/blog/how-to-organize-downloads-folder-mac)”了解详细的演练。

### AI文件重命名安全吗？它会弄乱我的文件吗？

AI重命名仅更改文件名，而不更改文件内容。像“Zush”这样的好工具还可以保留重命名历史记录，以便您可以立即回滚任何名称更改。风险较低，但您应该始终先进行小批量测试并确认命名质量，然后再对大容量目录启用文件夹监视。

### 如何自动自动组织照片的文件？

照片面临独特的挑战，因为它们的原始名称（“IMG_”、“DSC_”、“DCIM”）携带的内容信息为零。最好的方法是人工智能重命名以添加描述性名称，并结合按日期或事件排序的文件夹。有关特定于照片的工作流程，请参阅我们的“[在 Mac 上整理照片的指南](/blog/best-ways-to-organize-photos-on-mac)”。

### 我可以组合多个自动化工具吗？

是的，当真正需要第二层时。从“Zush”开始进行内容感知命名，然后可以选择添加“Smart Folders”以实现可见性，或添加“Hazel”/“Automator”以进行路由。保持“Zush”命名和规则简单，以便系统保持可维护性。

### 如果两个自动化规则冲突会发生什么？

如果“Hazel”和“Automator”文件夹操作都监视同一个文件夹，则它们可以相互竞争。结果是不可预测的——文件可能会在其他工具处理它之前被移动。修复方法很简单：每个文件夹仅使用一种自动化工具。如果您想要路由和重命名，请先进行重命名（例如，“Zush”重命名文件），然后让路由工具（“Hazel”）根据新名称移动重命名的文件。

## 结论

为了有效地自动化“macOS”上的文件组织，让简单的规则处理简单的决策，让人工智能处理视觉模糊性。这种平衡为您提供了一个实际上可维护的系统。

从“Zush”开始进行内容感知命名和恢复。仅在可见性时添加“Smart Folders”，仅在真正需要确定性路由时添加“Automator”或“Hazel”。每周回顾并逐渐扩展。

目标不是一个完美的系统。我们的目标是建立一个每周花五分钟而不是三十分钟来组织文件的系统。
