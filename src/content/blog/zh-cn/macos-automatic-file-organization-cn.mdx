## 自动整理工具应该先处理哪些文件

先从那些数量多又让人烦的文件下手。第一天不必搭一套大而全的系统，目标是解决一两个反复出现的麻烦，看到效果后再逐步扩展。

最适合自动化的文件：

- **截图**：macOS 会把它们命名为 `Screenshot 2026-03-12 at 10.44.11.png`，从名字完全看不出内容
- **下载文件夹**：浏览器下载、邮件附件和 AirDrop 文件顶着笼统的名字，很快就堆成一片
- **定期导出的文件**：每周从同几个应用导出的发票、银行对账单和报表
- **相机导入的照片**：半年后再看，`IMG_4382.HEIC` 这种名字毫无用处
- **成批涌入的重复文档**：交给客户的成果、研究用的 PDF、项目素材

自动化最有效的时候，是它帮你消除每周都会遇到的小烦恼，而不是让你搭起一套永远不会维护的复杂系统。

### 怎样找出最乱的文件夹

打开 Finder，把下载或桌面文件夹按修改日期排序，看最近的 50 个文件，数一数有多少个能从名字看出内容。如果不到一半，这个文件夹就很值得自动化。

你也可以看看一个文件夹里有多少文件。打开终端并运行：

```bash
ls -1 ~/Downloads | wc -l
```

如果数字超过 200，说明积压的文件已经多到值得自动化了。

## 用 AI 把混杂的文件分到文件夹

[Zush AI 文件分类工具](/ai-file-sorter) 可以在同一批处理中为支持的文件起描述性的名字，并按内容把它们分进真实的文件夹。**AI 文件夹分类在 Mac 和 Windows 上都能用。** 把 **Folder rules** 留空就是 Auto 分组，也可以用日常语言描述分组方式。对于混杂的文件，可以试试：

> 发票按公司分组，收据按月份分组。

1. 在 **AI Rename** 中加入一小批文件副本，并选择一个 Template。
2. 打开 **+ Sort**，选择 **Destination folder**，它是分类子文件夹的根目录。不单独指定目标时，源文件夹就是根目录。
3. 在 **Folder rules** 中填写分组说明。文件名格式由 **Naming Blocks** 另行设置。
4. 如果目标根目录里已经有合适的分组，打开 **Reuse existing folders**。没有合适的文件夹时，Zush 可以新建一个。
5. 同时检查建议的文件名和文件夹分组。应用整批结果之前，先改正文件夹名称或文件位置。

![Mac 版 Zush 在执行 Rename & sort 之前预览按内容划分的文件夹分组和建议的文件名](/images/showcase/macos/folder-sorting-light.webp)

把测试过的目标位置和规则保存到 Template，再把它分配给 **Monitor**，直接进入监控文件夹的新文件就会被重命名并分类。已经处理过的文件不会被追溯重新整理。关闭分类并保留原始目标位置时，文件会留在当前文件夹。

请参阅 [Mac 分类分步指南](/blog/sort-files-into-folders-with-ai-mac)，或查看 [文件夹分类文档](/docs/folder-sorting) 和 [30 个 Folder rules 示例](/blog/ai-folder-sorting-prompts)。

## Smart Folders：分步设置

Smart Folders 不会移动文件，而是根据搜索条件动态列出文件。可以把它们看作显示在 Finder 边栏里的已存储 Spotlight 搜索。

当文件散落在各处、你又不想调整文件夹结构时，用它们来找文件很方便。

### 如何创建 Smart Folder

1. 打开 Finder
2. 按 **Cmd + F**，或选择 **文件 > 新建智能文件夹**
3. 点击右上角的 **+** 按钮添加条件
4. 设置条件（见下方示例）
5. 点击 **存储** 并为 Smart Folder 命名
6. 勾选 **添加到边栏**，方便以后打开
7. 选择 `.savedSearch` 文件的保存位置（默认即可）

### 最实用的 Smart Folder 条件

| Smart Folder 用途 | 要设置的条件 |
|---|---|
| 最近的截图 | 种类 = 图像，名称包含“Screenshot”，修改日期 = 最近 7 天 |
| 占用磁盘的大文件 | 文件大小 > 500 MB |
| 最近的 PDF | 种类 = PDF，修改日期 = 最近 30 天 |
| 待审阅的文档 | 标签 =“Review”，种类 = 文稿 |
| 所有演示文稿 | 种类 = 演示文稿 |
| 最近的下载 | 文件夹 = 下载，修改日期 = 最近 3 天 |

### Smart Folders 进阶技巧

- 按住 **Option** 再点击 **+** 按钮，可以添加组合条件（AND/OR 分组）
- 可以按文件扩展名、创建日期、上次打开日期等几十种元数据字段筛选
- Smart Folders 实时更新，始终反映磁盘的当前状态
- 它们适用于所有已装载的宗卷，包括外置硬盘

Smart Folders 不算真正的自动化，因为它们不会移动或重命名任何东西。但作为第一步非常合适：在确定规则之前，你能先看清哪些文件需要整理。

## Automator 和 Shortcuts：搭建真正的工作流程

Automator（以及更新的 Shortcuts）可以用来创建真正处理文件的工作流程。通过拖放界面，它们能重命名、移动、复制、调整尺寸和转换文件。

### Automator 文件夹操作：按文件类型自动整理下载文件夹

这是最实用的 Automator 工作流程之一。它会监视你的下载文件夹，并按扩展名把文件移到子文件夹中。

**设置步骤：**

1. 打开 **Automator**（在 Spotlight 中搜索）
2. 选择 **文件夹操作** 作为文稿类型
3. 在顶部把“文件夹操作接收添加到以下位置的文件和文件夹”设为你的 **下载** 文件夹
4. 添加 **运行 Shell 脚本** 操作
5. 把“传递输入”设为 **作为自变量**
6. 粘贴下面的脚本：

```bash
for f in "$@"; do
    ext="${f##*.}"
    ext=$(echo "$ext" | tr '[:upper:]' '[:lower:]')
    case "$ext" in
        pdf)
            dest="$HOME/Documents/PDFs" ;;
        jpg|jpeg|png|heic|webp|gif)
            dest="$HOME/Pictures/Downloads" ;;
        zip|gz|tar|dmg)
            dest="$HOME/Downloads/Archives" ;;
        doc|docx|xlsx|pptx|csv)
            dest="$HOME/Documents/Office" ;;
        *)
            dest="" ;;
    esac
    if [ -n "$dest" ]; then
        mkdir -p "$dest"
        mv "$f" "$dest/"
    fi
done
```

7. 用一个能说明用途的名字保存工作流程，比如“按类型整理下载”
8. 文件夹操作现在已经生效，下载文件夹里的新文件会自动分类。

### Shortcuts：适用于 macOS Ventura 及更高版本的简单替代方案

如果你使用 macOS Ventura 或更高版本，很多任务都可以用 Shortcuts 代替 Automator。它的优点是界面更简洁，与系统触发器结合得更紧密。

**示例：重命名并移动截图**

1. 打开 **Shortcuts**
2. 新建一个快捷指令
3. 添加操作：**获取文件夹内容**（设为你的截图文件夹）
4. 添加操作：**过滤文件**，条件为名称包含“Screenshot”
5. 添加操作：**重命名文件**，使用 `Screenshot-[Date Created]` 这样的模式
6. 添加操作：**移动文件**，移到你想要的目标文件夹
7. 如果要自动运行，打开 **自动化** 标签页，创建一个在文件添加到截图文件夹时触发的自动化

Shortcuts 更适合单次的简单自动化，Automator 更适合需要调用 Shell 脚本的复杂多步骤工作流程。想完整了解如何用 Automator 重命名文件，请看我们的 [Automator 重命名文件指南](/blog/macos-automator-rename-files-guide)。


## Hazel：用于脚本和归档

如果一个文件夹需要持续运行的多条件规则，并且要用到 Zush 没有的操作，比如归档、运行脚本或上传，Hazel 就很有用。如果规则只是把发票 PDF 移进年份和月份文件夹，就不再需要它了：Zush 用一条“把发票放进年份和月份文件夹”这样的 Folder rules 就能做到，而且即使文件名是 `scan0043.pdf`，它也能认出这是一张发票。

当扩展名、日期、标签、文件名模式或提取出的文本能提供可靠的条件时，Hazel 很好用。Zush 也能利用同样的信息：有日期和扩展名的 Naming Blocks，Monitor 也能按文件类型或文件名前缀筛选。此外，它在命名或归档之前，还能看懂截图、照片、视频或名字笼统的扫描件。

如果两个工具都用，请给它们各自分配文件夹。不要让两个工具同时监视并改动同一个收件文件夹。逐项功能对比请看 [Zush 作为 Hazel 的替代方案](/hazel-alternative)。

## 基于规则的自动化在哪里失灵

当文件的名称、扩展名或元数据已经说明了它是什么时，规则很好用。

但如果文件是这样进来的，规则就失灵了：

- `IMG_4382.HEIC`
- `Screenshot 2026-03-12 at 10.44.11.png`
- `download (7).jpg`
- `Document.pdf`
- `Untitled.png`
- `image (3).webp`

规则可以把这些文件移到某个文件夹，却说不清它们里面是什么。没有描述性的名字，即使它们被整整齐齐地放进文件夹，你以后也找不到。

这正是 AI 命名派上用场的地方。分析文件内容的工具会看图像里的实际画面、视频中抽取的帧、PDF 里的文字和文档的版式，然后生成能说明文件真实内容的名字。

## 推荐的自动整理设置：分步说明

下面这套实用设置不到一小时就能搭好，它把上面的工具组合成一个完整的系统，在投入和效果之间取得平衡。

### 第 1 步：盘点现在的混乱情况

打开下载、桌面和文稿文件夹，记下哪些文件夹里名字没用的文件最多，挑出问题最严重的两个。

### 第 2 步：预览 Zush 生成的名字和可选的文件夹分组

安装 [Mac 版 AI 文件重命名工具](/mac)，把它指向复制出来的收件文件夹，选择一个 Template，然后检查最先生成的几个建议名字。开启持续监控之前，确保 Rename History 可用。

### 第 3 步：可选，创建 Smart Folders 来查看文件

在 Finder 中设置三个 Smart Folders：

1. **最近的大文件**：文件大小 > 100 MB，修改日期 = 最近 30 天
2. **未整理的截图**：种类 = 图像，名称包含“Screenshot”，修改日期 = 最近 14 天
3. **最近的文档**：种类 = 文稿 或 种类 = PDF，修改日期 = 最近 7 天

这样你马上就能看到哪些文件需要处理。

### 第 4 步：可选，设置基本的文件分流

按你的习惯从下面选一种：

**选项 A：Automator 文件夹操作**（免费，系统自带）
- 创建上文介绍的下载文件夹分类工作流程
- 10 分钟就能搞定，能处理最常见的文件类型

**选项 B：Hazel 规则**（付费，功能更强）
- 安装 Hazel，为下载文件夹设置 3–5 条规则
- 重点处理：PDF 移到文稿，图片移到图片，压缩包移到专门的文件夹
- 再加一条清理规则，处理超过 30 天的文件

**选项 C：Shortcuts 自动化**（免费，macOS Ventura 及更高版本）
- 创建一个按类型整理文件的快捷指令
- 设为定时触发或手动运行

**选项 D：Zush Folder rules**（Zush 自带）
- 在 Template 中打开 Sort，描述目标文件夹，例如“PDF 放到文稿，图片放到图片，收据按月份”
- 把 Template 分配给 Monitor，新下载的文件一进来就会被命名并分类

### 第 5 步：测试通过后开启 Zush 监控

![Zush 监控标签页，显示文件夹监控设置，已选中桌面文件夹](/images/showcase/macos/monitor-light.webp)

确认测试批次没有问题后，让 Zush 监控你的截图文件夹和下载文件夹。它能处理基于规则的工具没法好好命名的文件：

- 截图会根据画面中可见的应用和内容重命名
- PDF 会根据其中的文字重命名
- 照片会根据画面内容重命名
- 下载的图片会得到描述性的名字，而不是 `download (7).jpg`

### 第 6 步：安排每周检查

即使有了自动化，每周也花 5 分钟看一眼你的 Smart Folders。这样能发现特殊情况，并随着时间推移不断改进规则。

### 第 7 步：逐步扩展

这套设置运行一周后，看看还有哪些文件被漏掉了，再按需添加新的 Hazel 规则或 Smart Folders。不要一开始就试图覆盖所有特殊情况。

## 需要避免的常见错误

**太早过度自动化。** 在弄清哪些文件真正需要分流之前，不要搭一套 20 条规则的 Hazel 设置。先从 2–3 条规则开始，再慢慢扩展。

**忽视命名问题。** 如果每个文件都叫 `IMG_4382.HEIC`，把它们放进整齐的文件夹也没用，你还是得逐个打开才能找到想要的那个。重命名至少和分类一样重要。

**不测试规则。** 在真实的下载文件夹上启用文件夹操作或 Hazel 规则之前，先在放了样本文件的测试文件夹里试一遍。一条出错的移动规则就可能把文件散落到磁盘各处。

**忘了子文件夹。** 大多数自动化工具默认只监视一层文件夹。如果文件会落进子文件夹，你需要专门设置递归监控。

**没有回退方案。** 任何会重命名或移动文件的自动化，都应该能撤销。Hazel 会保留日志，Zush 支持回退，Automator 则没有这个功能，所以对破坏性操作要格外小心。

## 常见问题

### 不安装任何软件，怎样在 Mac 上自动整理文件？

用系统自带的工具：Smart Folders 负责把文件列出来，Automator 或 Shortcuts 负责分流文件。Smart Folders 在 Finder 的“文件 > 新建智能文件夹”中。Automator 可以创建文件夹操作，在文件进入指定目录时触发。这些工具不需要任何第三方软件，就能完成按文件类型、日期和名称模式的基本分类。

### macOS 上的 Automator 和 Shortcuts 有什么区别？

Automator 是较早的工具，操作类型更多，支持 Shell 脚本，并集成了文件夹操作。Shortcuts 较新（macOS Monterey 及更高版本），界面更简洁，支持系统触发器和 Siri。单就文件自动化来说，Automator 仍然更强，因为它有 Shell 脚本操作和更丰富的文件处理选项。Apple 正在把功能逐步迁移到 Shortcuts，所以两者都值得了解。

### Hazel 能根据文件内容重命名吗？

Hazel 可以读取 PDF 和文档里的文字，并在重命名规则中使用。例如，你可以从 PDF 中提取日期或关键词放进文件名。但 Hazel 无法分析图像或视频的内容，它没有视觉能力。截图、照片、录屏和其他视觉文件，需要一款真正能看懂文件内容的 AI 工具。

### 怎样防止下载文件夹变得杂乱？

搭一套两层的系统。第一层，设置分流规则（Zush Folder rules、Automator 或 Hazel），在文件进来时按类型移到对应的文件夹。第二层，加一条清理规则，把超过 30 天的文件移到归档文件夹或废纸篓。两者结合，下载文件夹能保持清爽，又不会丢掉重要文件。详细步骤请看我们的 [下载文件夹整理指南](/blog/how-to-organize-downloads-folder-mac)。

### AI 文件重命名安全吗？会不会弄乱我的文件？

AI 重命名只改文件名，不改文件内容。Zush 这样的好工具还会保留重命名历史，任何名字改动都能立即回退。风险很低，但你应该始终先用一小批文件测试，确认命名质量后，再对文件量大的目录开启文件夹监控。

### 照片怎样自动整理？

照片的难点在于原始名字（`IMG_`、`DSC_`、`DCIM`）完全不含内容信息。最好的办法是用 AI 重命名加上描述性的名字，再结合按日期或事件分文件夹。照片专用的工作流程请看我们的 [Mac 照片整理指南](/blog/best-ways-to-organize-photos-on-mac)。

### 可以组合使用多个自动化工具吗？

可以，前提是确实需要第二层。先用 Zush 完成命名和文件夹分类，再按需添加 Smart Folders 来查看文件，或用 Hazel、Automator 处理脚本和归档。额外的规则要少，系统才容易维护。

### 两条自动化规则冲突会怎样？

如果 Hazel 和一个 Automator 文件夹操作同时监视同一个文件夹，它们可能会互相抢着处理，结果无法预料：某个文件可能在另一个工具处理它之前就被移走了。解决办法很简单：每个文件夹只用一种自动化工具。Zush 可以一次完成重命名和分类，所以通常只需要一个工具。如果 Hazel 还有任务，比如归档，就让 Zush 先处理完，再让 Hazel 监视目标文件夹。

## 结论

要在 macOS 上有效地自动整理文件，就让简单的规则处理简单的判断，让 AI 处理看图才能分辨的情况。这样的分工才能让系统真正维护得下去。

先用 Zush 获得按内容生成的名字、可选的 AI 文件夹分类和撤销能力。把测试过的分类设置保存到 Template，交给 Monitor 使用。用 Smart Folders 保存视图，用 Automator 或 Hazel 处理脚本和归档。每周检查一次，再逐步扩展。

目标不是一套完美的系统，而是让你每周只花五分钟整理文件，而不是三十分钟。
