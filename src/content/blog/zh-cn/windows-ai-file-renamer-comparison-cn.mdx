## Zush 在 Windows 上提供哪些云端和本地 AI 选项？

Zush 有两种云端选项和两种本地选项。你可以在它们之间切换，而不用改变搭建、预览和应用名称的方式。

| Zush AI 选项 | 分析在哪里运行 | 最适合 |
|---|---|---|
| **Zush Cloud AI** | Zush 托管的云服务 | 立即开始，无需配置服务商或模型 |
| **BYOK** | 你的 Gemini、OpenRouter、OpenAI 或 Claude 账号 | 使用你自己的服务商账号和 API 密钥 |
| **Ollama** | 你的 PC | 使用现有 Ollama 环境中的模型 |
| **LM Studio** | 你的 PC | 使用 LM Studio 提供的模型 |

对于敏感文件夹，本地选项会把分析留在你的 PC 上；可选的本地语音识别还能覆盖视频。BYOK 仍然是云端路线，只是通过你掌控的账号。[隐私与安全指南](/docs/privacy-security) 说明了每条路线处理哪些内容。

## AI 重命名与 PowerRename 有何不同

PowerRename 这类规则工具对每个选中的文件应用同一条规则。AI 重命名工具则会打开每个文件：文档文字、图片或截图显示的内容，或视频中的语音。然后为每个文件给出不同的名称，于是 `scan_004.pdf` 变成了 `invoice-7842-webdesign-services.pdf`。如果你只需要统一的前缀或编号序列，免费的 PowerRename 就够用；[Windows 11 文件重命名工具指南](/blog/best-file-renamer-windows-11) 介绍了这类工具。

同一位开发者还在 GitHub 上发布了 [`ozgrozer/ai-renamer`](https://github.com/ozgrozer/ai-renamer)，这是一个免费的 GPL-3.0 命令行工具；桌面应用则是另一款独立产品，有自己的安装程序。

## 5. Renamer.ai

Renamer.ai 是一款专注于文档的重命名工具，提供 Windows 和 Mac 应用以及网页界面。它没有上架 Microsoft Store。包含 Magic Folders、模板、OCR、预览和撤销，所有档位都提供本地模式，包括免费的 Starter 方案（每月 25 个文件）。云端方案为 Pro 每月 $9.95（200 个文件）、Power $29.95（1,000 个）和 Ultimate $99.95（5,000 个），按年付费便宜 15%。BYOK 仅限 Ultimate。其格式列表没有列出相机 RAW、PSD、Sketch 或 Figma。

## 7. 自己用 PowerShell 或 Python

你可以自己搭建流程：读取文件，把文字或图片发给模型，把输出清理成安全的文件名，再重命名。一旦加上重试、模型输出异常、重名、Windows 路径长度限制、凭据和撤销，事情就变复杂了。

## 常见问题

### 什么是 AI 重命名软件？

AI 重命名软件会读取每个文件的内容（文档文字、图片显示的内容、视频中的语音），并为它建议一个描述性的文件名。批量重命名工具可以对一批文件替换文本或添加编号，但当发票和保修卡都叫 `scan_004.pdf` 时，它分辨不出哪个是哪个。Zush、FilesDesk、RenameClick、AI Renamer、Renamer.ai 和 NameQuick 都是 Windows 上的 AI 重命名工具。

### Windows 上最好的 AI 文件重命名工具是哪款？

我们推荐 Zush。它可从 Microsoft Store 安装，提供 50 次免费 AI 重命名，无需账号、银行卡或 API 密钥，$48 一次性许可证包含托管云端 AI、BYOK、Ollama 和 LM Studio，最多可用于 3 台设备。每一批都会先预览，并保存在支持批量撤销的 Rename History 中。在我们用同样 30 个文件对六款应用的测试中，它为全部 30 个文件重命名，得分 94.8（满分 100）。FilesDesk、RenameClick、AI Renamer、Renamer.ai 和 NameQuick 各自适合更具体的需求。

### Renamer.ai 和 AI Renamer 是同一个产品吗？

不是。Renamer.ai（renamer.ai）是一款订阅制重命名工具，支持 Windows、Mac 和网页，方案价格为每月 $9.95 到 $99.95，所有档位都有本地模式。AI Renamer（airenamer.app）是一款桌面应用，提供 $19 一次性买断的 Local Mode 和 $10 的云端额度包。GitHub 上免费的 `ozgrozer/ai-renamer` 命令行工具与 AI Renamer 出自同一位开发者，但它是一个独立项目。

### $48 的一次性许可证比更便宜的更值吗？

取决于你是否需要包含 AI。AI Renamer Local（$19）和 RenameClick 终身版（$36 + 增值税）涵盖的是应用本身，AI 则要用你自己的密钥或必须由你的 PC 运行的模型。Zush 的 $48 包含托管的 Zush Cloud AI 和无限次重命名，以及 BYOK 和本地模型、今后所有更新、3 台 Windows 和 Mac 设备，以及 14 天退款。

### 在 Windows 上用 Zush 时，我的文件在哪里处理？

使用 Zush Cloud AI 或 BYOK 时，文件内容会发送到 AI 服务来生成名称；BYOK 使用的是你自己的服务商账号。使用 Ollama 或 LM Studio 时，分析在你的 PC 上进行，可选的本地语音识别可处理视频。预览、手动确认和 Rename History 在所有模式下的工作方式都相同。请看 [隐私与安全指南](/docs/privacy-security)。

### Zush 和 Windows 上的 PowerRename 有什么不同？

[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename) 是 PowerToys 中的实用工具，它对 File Explorer 中选中的文件应用一条共同的规则：搜索替换、正则表达式、计数器，以及日期或 EXIF/XMP 标记。它没有 AI，也从不读取文件内容。Zush 读取每个文件并给出专属名称，然后让你预览、应用和撤销整批操作。对于统一的规则改动，免费的 PowerRename 就很好用。

### 有原生的 Windows 应用，而不只是浏览器工具吗？

有。[Windows 版 Zush](/windows) 可从 Microsoft Store 安装，提供 x64 和 ARM64 安装包，支持 Windows 10 和 11。FilesDesk 和 RenameClick 也在 Microsoft Store 上架。AI Renamer、Renamer.ai 和 NameQuick 在各自官网提供 Windows 安装程序。浏览器工具则需要上传你的文件，适合无法安装软件时偶尔使用。
