简短回答：如果每个文件要做的是同一类修改，比如加前缀、加日期或按序编号，就用 **PowerRename**。它是微软推出的免费工具，能应付大多数规则类任务。如果每个文件都需要根据其内部内容取一个独立的名称，就用 [Zush](/windows) 这样的 AI 重命名工具。

这一区分决定了其余的一切。规则类工具快速而精确，但只能转换文件已有的名称。`IMG_4382.jpg` 可以变成 `Vacation_001.jpg`，却永远变不成 `lisbon-tram-at-night.jpg`。

**最后核查日期：2026 年 9 月 22 日。** 本文作者为 Zush 的开发者。其他工具的详细信息均来自其官方页面。

## 1. File Explorer：处理五个文件足够了

选中多个文件，按 **F2**，输入名称，按 Enter。Windows 会把它们命名为 `Trip (1).jpg`、`Trip (2).jpg`，依此类推。按 **Ctrl+Z** 可以立即撤销。

它能做的仅此而已：没有预览、没有日期、没有查找替换。当结果只需要整齐、不需要有意义时，可以用它。

## 2. PowerRename：大多数人的最佳免费之选

[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename) 随 Microsoft PowerToys 一起提供。选中文件，右键单击，选择 **使用 PowerRename 重命名**，即可进行带实时预览的搜索和替换。

它的能力比看上去要强：

- 正则表达式，包括捕获组（`29-03-2020` → `2020-03-29`）
- 带补零和起始值的计数器（`Image_${padding=4}`）
- 文件创建日期变量，如 `$YYYY-$MM-$DD`
- 照片 EXIF 字段，如 `$DATE_TAKEN_YYYY`、`$CAMERA_MODEL` 以及 GPS 坐标

任何能用规则描述的任务，都可以选择 PowerRename。关于 AI 方案，请参阅我们的 [PowerRename 替代方案](/powerrename-alternative)页面。

## 3. Bulk Rename Utility：控制力最强

[Bulk Rename Utility](https://www.bulkrenameutility.co.uk/) 把所有规则选项都塞进了一个密集的窗口：正则表达式、JavaScript、自动编号、EXIF 日期、MP3 标签、由 CSV 驱动的重命名以及时间戳修改。它可以处理 10 万以上的文件而不会变慢。撤销的方式是生成一个批处理文件来还原改动。

个人使用免费；商业使用需要商业许可证。界面需要一段时间适应。更多内容请见我们的 [Bulk Rename Utility 替代方案](/blog/bulk-rename-utility-alternatives)指南。

## 4. Advanced Renamer：最适合照片和音乐元数据

[Advanced Renamer](https://www.advancedrenamer.com/) 通过叠加多种方法来构建名称：来自 EXIF、ID3、视频属性和 GPS 的标签（它可以把坐标转换成城市名称）。它提供实时预览，并且可以撤销整个批次。它同样支持 macOS。

轻度个人使用免费。经常使用的用户会被要求购买 $25 的个人许可证，工作用途则需要 $45 的商业许可证。两者均为一次性付费。请参阅我们的 [Advanced Renamer 评测](/blog/advanced-renamer-alternatives)。

## 5. ReNamer：规则与脚本

[ReNamer](https://www.den4b.com/products/renamer) 按顺序应用一组规则：插入、删除、替换、大小写、正则表达式、元标签，以及用于任何自定义需求的 Pascal Script。它是便携版，支持 25 种以上的界面语言。

ReNamer Lite 非商业使用免费，限制为 5 条规则和 5 个预设。Pro 版取消了这些限制，并允许商业使用。

## 6. Zush：当每个文件都需要自己的名称时

[Zush](/windows) 的工作方式不同。它不是修改旧名称，而是查看文件本身：PDF 中的文本、截图所显示的内容、照片中的场景、Word 或 Excel 文件的内容。然后它写出一个描述该文件的名称。

| 之前 | 之后 |
|---|---|
| `Screenshot 2026-09-18 141203.png` | `github-pull-request-review-comments.png` |
| `scan_0042.pdf` | `2026-09-12_acme_invoice_1042.pdf` |
| `Document1.docx` | `q3-marketing-plan-draft.docx` |
| `IMG_4382.jpg` | `2026-08-30_lisbon_tram_street.jpg` |

命名的格式始终由你掌控。Template 和 145 个以上的 Naming Blocks 可以固定顺序（日期、供应商、客户、标题）、大小写和分隔符。你可以在应用之前审阅每一条建议，之后还能通过 Rename History 恢复整个批次。文件夹监控会自动重命名“下载”文件夹或扫描仪文件夹中的新文件。

AI 可以通过 Zush Cloud AI、你自己的 API 密钥运行，也可以借助 Ollama 或 LM Studio 在本地运行。前 50 次重命名免费。

### 将重命名后的文件分类到文件夹

在 Windows 上，Zush 还可以**用 AI 将文件分类到文件夹（测试版）**。选择 **Auto** 分组，或编写 **Folder rules**，例如“按公司归类发票，按月份归类收据。”你可以在查看文件名的同时审阅建议的文件夹分组；如果你只需要对一批文件做相同的文本修改，规则类重命名工具仍然足够。

选择一个 **Destination folder**，或者保留源文件夹作为根目录。启用 **Reuse existing folders** 可优先使用已有的合适文件夹；当没有合适的文件夹时，Zush 可以新建一个。在手动批次中，应用之前请同时审阅建议的名称和文件夹。如果只想原地重命名，请关闭分类功能并保留原来的目标位置。

把分类设置保存到一个 **Template** 中，并将其分配给 **Monitor**，用于处理被监控文件夹内直接出现的新文件。这不会重新整理已经处理过的文件。请先在手动批次中测试该 Template。设置方法和监控范围请参阅[文件夹分类指南](/docs/folder-sorting)。

## 你应该使用哪款重命名工具？

- 对每个文件做相同的修改（前缀、日期、编号）：**PowerRename**。
- 在超大文件夹上处理复杂规则：**Bulk Rename Utility**。
- 根据照片、音乐或 GPS 元数据命名：**Advanced Renamer**。
- 需要真正有意义名称的截图、扫描件、下载文件和照片：**Zush**。

很多人两种都会保留。PowerRename 用于快速的机械式修正，Zush 则用于那些你目前需要逐个打开文件才能知道内容的文件夹。

## 常见问题

### Zush 除了重命名，还能把文件分类到文件夹吗？

可以。其可选的 AI 文件夹分类功能在 Mac 和 Windows 上均处于测试阶段。选择 Auto 或编写 Folder rules，选定目标位置，并在手动批次中同时审阅名称和分组。启用了分类的 Template 也可以处理被监控文件夹内直接出现的新文件；它不会重新整理已经处理过的文件。如果只需要命名，请关闭分类并保留原来的目标位置。

### Windows 11 上最好的免费文件重命名工具是什么？

PowerRename，它是 Microsoft PowerToys 的一部分。它免费、会预览每一处更改、支持正则表达式和日期变量，并且可以用 Ctrl+Z 撤销。对于较繁重的个人任务，Bulk Rename Utility 是免费的备选方案。

### Windows 11 有内置的批量重命名功能吗？

有，但比较基础。在 File Explorer 中选中文件并按 F2，即可为它们指定同一个名称，并在括号中加上编号。如果需要查找替换或日期，请安装 PowerToys 并使用 PowerRename。

### 文件重命名工具能读取我文件里的内容吗？

规则类工具不能；它们只读取现有的名称以及 EXIF 或 ID3 等元数据字段。像 Zush 这样的 AI 重命名工具会读取内容本身（文本、图像、视频帧），并写出新的描述性名称。

### 哪款文件重命名工具最安全？

任何带有预览和批量撤销功能的工具。PowerRename、Advanced Renamer 和 Zush 都会在应用之前显示结果。Zush 还会保留持久的 Rename History，因此你可以在几天之后还原某个批次，而不仅仅是在刚操作完之后。
