这个区别决定了其他一切。规则类工具快速而精确，但它们只能改造文件现有的名称。`IMG_4382.jpg` 可以变成 `Vacation_001.jpg`，却永远变不成 `lisbon-tram-at-night.jpg`。

## 1. File Explorer：五个文件以内够用

选中几个文件，按 **F2**，输入名称，按 Enter。Windows 会把它们命名为 `Trip (1).jpg`、`Trip (2).jpg`，依此类推。按 **Ctrl+Z** 可以立即撤销。

它能做的就这么多。没有预览，没有日期，没有查找替换。如果结果只需要整齐、不需要有意义，就用它。

## 2. PowerRename：大多数人的最佳免费之选

[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename) 随 Microsoft PowerToys 一起提供。选中文件，右键单击，选择 **Rename with PowerRename**，就能使用带实时预览的搜索替换。

它的能力比看上去更强：

- 正则表达式，包括捕获组（`29-03-2020` → `2020-03-29`）
- 可设置补零位数和起始值的计数器（`Image_${padding=4}`）
- 文件创建日期变量，例如 `$YYYY-$MM-$DD`
- 照片 EXIF 和 XMP 标记，例如 `$DATE_TAKEN_YYYY` 和 `$CAMERA_MODEL`

Ctrl+Z 可以撤销上一次重命名。它没有 AI，也从不打开文件，所以无法判断扫描件或截图里是什么。凡是能描述成规则的任务，都可以选 PowerRename。AI 方面的内容请看我们的 [PowerRename 替代品](/windows) 页面。

## 3. Bulk Rename Utility：最大程度的控制

Bulk Rename Utility 把所有规则选项都塞进一个密集的窗口：正则表达式、JavaScript、自动编号、EXIF 日期、MP3 标签、基于 CSV 的重命名，以及时间戳修改。处理 10 万个以上的文件也不会变慢。撤销的方式是生成一个可以逆转改动的批处理文件。

个人使用免费，但 JavaScript 重命名需要付费许可证（$24.95），商业用途每台电脑 $92.95。4.1.0.1 版新增了一个 AI 助手，可以替你编写 JavaScript 和正则规则；它帮你构建规则，但不读取文件内容。界面需要一段时间适应。更多内容见我们的 [Bulk Rename Utility 替代品](/blog/bulk-rename-utility-alternatives) 指南。

## 4. Advanced Renamer：最适合照片和音乐元数据

Advanced Renamer 通过叠加多种方法来生成名称：EXIF、ID3、视频属性和 GPS 中的标签（它能把坐标转换成城市名）。它提供实时预览，并能撤销整批操作。它也支持 macOS。当前版本为 4.28，其脚本方法可以从 PDF 和 TXT 文件中提取文本，但没有 AI 或 OCR：扫描的 PDF 和照片仍然无法读取，而且把文本转换成名称的脚本需要你自己写。

轻度个人使用免费。经常使用的用户需要购买 $30 的个人许可证，工作用途需要 $50 的商业许可证。两者都是一次性买断。请看我们的 [Advanced Renamer 评测](/blog/advanced-renamer-alternatives)。

## 5. ReNamer：规则和脚本

ReNamer 按顺序执行一系列规则：插入、删除、替换、大小写、正则表达式、元数据标签，以及用于自定义需求的 Pascal Script。它是便携版软件，界面支持 25 种以上语言。

ReNamer Lite 对非商业用途免费，限 5 条规则和 5 个预设。Pro 版取消这些限制，并允许商业使用。

## 6. Zush：每个文件都需要专属名称时

[Zush](/windows) 的工作方式不同。它不是编辑旧名称，而是查看文件本身：PDF 中的文字、截图显示的内容、照片中的场景、Word 或 Excel 文件的内容。然后写出一个描述该文件的名称。

| 重命名前 | 重命名后 |
|---|---|
| `Screenshot 2026-09-18 141203.png` | `github-pull-request-review-comments.png` |
| `scan_0042.pdf` | `2026-09-12_acme_invoice_1042.pdf` |
| `Document1.docx` | `q3-marketing-plan-draft.docx` |
| `IMG_4382.jpg` | `2026-08-30_lisbon_tram_street.jpg` |

名称的格式仍由你掌控。Templates 和 145+ 个 Naming Blocks 固定了顺序（日期、供应商、客户、标题）、大小写和分隔符。每条建议在应用之前都要经过你审阅，Rename History 之后还能还原整批操作。文件夹监控会自动重命名 Downloads 或扫描仪文件夹中的新文件。

AI 可以通过 Zush Cloud AI、你自己的 API 密钥运行，也可以用 Ollama 或 LM Studio 在本地运行。前 50 次 AI 重命名免费，无需账号、银行卡或 API 密钥。之后 Zush 的价格为 $10/月或 $48 一次性买断；一次性许可证包含托管云端 AI 和无限次重命名、今后所有更新、最多 3 台 Windows 和 Mac 设备，以及 14 天退款。它还能在 AI Rename 过程中发现重复文件（副本不消耗额度），根据语音和字幕为视频命名，并在 Windows 上识别没有标签的音乐。

### 把重命名后的文件分类到文件夹

在 Windows 上，Zush 还能**用 AI 把文件分类到文件夹**。选择 **Auto** 分组，或者写下 **Folder rules**，例如“发票按公司分组，收据按月份分组”。建议的文件夹分组会和文件名一起供你审阅；如果你只需要对一批文件做同样的文本改动，规则类重命名工具仍然够用。

选择一个 **Destination folder**，或者把源文件夹作为根目录。启用 **Reuse existing folders** 可以优先使用已有的合适文件夹；没有合适的文件夹时，Zush 会新建一个。手动处理一批文件时，请在应用之前同时审阅建议的名称和文件夹。如果要原地重命名，就关闭分类并保留原来的目标位置。

把分类设置保存到一个 **Template** 中，并分配给 **Monitor**，用于处理直接放入受监控文件夹的新文件。更改 Monitor 的 Template 不会自动重新整理已经处理过的文件。请先在手动批处理中测试 Template。设置方法和监控范围见 [文件夹分类指南](/docs/folder-sorting)。

Zush 还支持嵌套文件夹规则，例如先按年份再按月份分组。你可以对已经重命名的文件只做分类，而不再改名，也不再消耗重命名额度。应用之前请检查目标位置。这是一项单独的操作，用于处理现有的一批文件；更改 Monitor 的 Template 不会追溯重新整理它们。[AI 文件夹分类](/docs/folder-sorting) 支持 Mac 和 Windows。

## 该用哪款重命名工具？

- 每个文件做同样的改动（前缀、日期、编号）：**PowerRename**。
- 对超大文件夹应用复杂规则：**Bulk Rename Utility**。
- 根据照片、音乐或 GPS 元数据命名：**Advanced Renamer**。
- 需要真正有意义名称的截图、扫描件、下载文件和照片：**Zush**。

很多人两类工具都保留。PowerRename 用来做快速的机械修改，Zush 则用于那些你现在必须逐个打开才知道内容的文件夹。

## 常见问题

### Zush 能在 Windows 11 上重命名视频和音乐文件吗？

能。Windows 版 Zush 可以根据语音、内嵌字幕和元数据为视频命名（包括 MKV），即使音轨没有标签也能识别音乐，这项功能目前仅限 Windows。如果需要离线工作，可以在 AI 设置中下载可选的本地语音识别，并与 Ollama 或 LM Studio 搭配使用。PowerRename 等规则类工具只能按规则改名，无法判断录音的内容。

### Windows 11 上最好的免费文件重命名工具是哪款？

PowerRename，它是 Microsoft PowerToys 的一部分。它免费，可以预览每处改动，支持正则表达式、计数器、日期变量和 EXIF/XMP 标记，并可用 Ctrl+Z 撤销。对于更繁重的个人任务，Bulk Rename Utility 也免费，不过 JavaScript 重命名需要付费许可证。Advanced Renamer 对轻度个人使用免费。它们都不读取文件内容；如需读取内容，Zush 提供 50 次免费 AI 重命名，无需账号。

### Windows 11 有内置的批量重命名功能吗？

有，但很基础。在 File Explorer 中选中文件并按 F2，可以给它们统一命名，并在括号中加上编号。如果需要查找替换或日期，请安装 PowerToys 并使用 PowerRename。

### 文件重命名工具能读取文件里的内容吗？

规则类工具大多不能。它们读取的是现有名称和 EXIF、ID3 等元数据字段。Advanced Renamer 可以通过脚本从 PDF 和 TXT 文件中提取文本，但没有 AI 或 OCR，扫描件和照片仍然无法读取。Zush 这类 AI 重命名工具会读取内容本身（文字、图像、语音和视频画面），并给出一个新的描述性名称，由你审阅后再应用。

### 哪款文件重命名工具最安全？

任何带预览和批量撤销的工具。PowerRename、Advanced Renamer 和 Zush 都会在应用前显示结果。Zush 还会持久保存 Rename History，所以几天之后也能还原一批操作，而不只是在刚改完时。

### PowerRename 免费，Zush 还值得付费吗？

只有当你的文件需要根据内容命名时才值得。对于统一的规则改动，PowerRename 是合适的工具，而且分文不花。如果你在命名之前需要打开截图、扫描件或下载文件看看是什么，Zush 会替你完成这一步。它的 $48 一次性许可证包含托管云端 AI 和无限次重命名、BYOK 和本地模型、今后所有更新、3 台设备，以及 14 天退款。

### Zush 在 Windows 上在哪里处理我的文件？

取决于模式。Zush Cloud AI 和 BYOK 会把文件内容发送到 AI 服务来生成名称；BYOK 使用的是你自己的服务商账号。使用 Ollama 或 LM Studio 时，分析在你的 PC 上进行，视频还可以使用本地语音识别。PowerRename、Bulk Rename Utility 和 Advanced Renamer 不分析内容，因此从不把文件发到任何地方。请看 [离线 AI 文件重命名工具](/offline-ai-file-renamer)。
