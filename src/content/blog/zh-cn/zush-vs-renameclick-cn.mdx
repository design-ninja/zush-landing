Zush 是一款适用于混合文件夹的桌面 AI 文件重命名器。其最大的优势是命名系统：用于常见工作流程的内置 Templates、145+ Naming Blocks、Custom AI Blocks、提示、字段顺序、大小写、分隔符、日期格式、语言、Finder 标签、Spotlight 元数据和每个文件夹Template 作业。 Rename History 存储原始名称和新名称、文件夹和时间戳，并可以恢复已应用的批次。其 100+ formats 涵盖图像、RAW、设计、文档、iWork、字幕、视频和音频。

此比较中的重要部分是 Zush 不会强制使用文件类型筒仓。包含 `IMG_4821.HEIC`、`_DSC0019.NEF`、`checkout-flow.fig`、`voice-memo.m4a`、`client-brief.pages`、`recording.mov` 和 `invoice.pdf` 的文件夹可以保留在一个工作流程中。

定价很简单：$10/month 或 $48 一次性用于 PRO。这两种付费计划都消除了 Cloud AI、BYOK 和 Offline AI 的重命名限制。免费包含 Templates、Naming Blocks 和自定义提示。

RenameClick 是适用于 macOS 和 Windows 的本地优先桌面应用程序。其核心卖点是隐私：一次性本地模型下载后，其内置的 Qwen3-VL 提供程序可以在没有 API 密钥或互联网连接的情况下处理设备上的文件。它还支持用于本地服务器工作流程的 LM Studio 和 Ollama，当您显式连接云 API 密钥时，还支持 OpenAI、Google Gemini 和阿里云 Qwen。 RenameClick 指出，Mac App Store 版本中不提供云提供商；如果这些提供商很重要，请使用直接下载。

RenameClick 不仅仅是一个重命名器。它更接近文件管理器：它可以重命名文件、对文件进行分类、将文件移动到文件夹中、运行 Auto Flow 监视规则、使用 AI Search 按内容搜索，以及从 EXIF/日期占位符构建名称。其支持的文件文档现在涵盖三类：常见图像(JPEG、PNG、GIF、WebP、AVIF、BMP、SVG、HEIC、HEIF、TIFF)、长文档列表(PDF、 DOC/DOCX、TXT、MD、CSV、RTF、ODT、JSON、XML、YAML、HTML、日志、SQL、 SRT/VTT、ICS/VCF)、和音频 (MP3、WAV、FLAC、M4A、 AAC) 具有本地语音转录功能。视频文件、其他音频编解码器、存档和可执行文件被明确列为不受支持。

## 格式支持

### Zush 对于真正的混合文件夹来说更广泛

Zush 支持 RAW 照片格式、设计文件、音频、视频、iWork 文件、Office 文件、字幕和数据/文本格式。如果您的文件夹很乱，那么这就是实际优势，因为它们是真实的：手机照片旁边是屏幕截图，PDF 旁边是相机 RAW，Keynote/Pages 文档旁边是 Figma/Sketch/PSD 文件，会议记录旁边是视频文件。音频不再是这一差距的一部分——RenameClick 现在可以处理常见的音频格式——但 RAW、设计文件、iWork 和视频仍然是。

### RenameClick 涵盖常见图像、广泛的文档列表，现在还包括音频

RenameClick 很好地涵盖了常见的图像和文档工作流程 - JPEG、PNG、GIF、WebP、AVIF、BMP、SVG、HEIC、HEIF、TIFF，以及 PDF、DOC/DOCX、TXT、Markdown、CSV、RTF、ODT、 JSON、XML、YAML、HTML、日志、SQL、字幕和日历/联系人文件 - 并且添加了音频 (MP3、 WAV、FLAC、M4A、AAC) 具有本地语音转录功能。它还具有有用的文档处理详细信息：文本 PDF 和 Office 文档的文本提取、扫描 PDF 的视觉回退以及可配置的文档文本修剪限制。

差距在于媒体和设计格式。 RenameClick 的文档没有列出相机 RAW 格式或设计文件（如 Sketch/Figma/PSD），并且明确称视频文件、存档和可执行文件不受支持。如果这些格式很重要，Zush 更安全。

## 本地AI平价；命名控制不是

这两种产品都可以运行本地模型，因此离线处理并不是独特的优势。 RenameClick 在多 GB 下载后捆绑模型； Zush 连接到 Ollama。更重要的区别是工作流程的其余部分：Zush 记录现成的 Templates、145+ Naming Blocks、Custom AI Blocks、更丰富的本地化和元数据控件以及持久的 Rename History。

如果您更关心云提供商的选择和大容量 BYOK，则 Zush 会获胜。 Zush通过BYOK支持Gemini、Groq、OpenAI和Claude，密钥本地存储，并且当本地处理优先时，通过Ollama支持离线AI。 Groq 和 Claude 是值得注意的 Zush 侧选项；内置Qwen3-VL、阿里云Qwen、LM Studio为RenameClick侧选项。

实际的权衡很简单：选择 Zush 来命名深度、恢复细节和混合文件广度。仅当 AI Search 或文件夹移动超过其缺失的 RAW、设计、iWork 和视频覆盖范围时，才考虑 RenameClick。

## 自动化和组织

这两种工具都可以监视文件夹，但它们强调不同的结果。

Zush 文件夹监控是围绕自动 AI 重命名、可重用模板和 Naming Blocks 构建的。它非常适合下载清理、屏幕截图、重复客户端文件夹和可预测的命名约定，其中新文件到达时应获得可搜索的名称。

RenameClick Auto Flow更多的是一个规则行系统。每行可以有自己的源文件夹、目标文件夹、命名格式、自定义指令、语言、排序预设、递归设置和自动应用设置。它可以同时运行多行，在处理之前等待文件变得稳定，避免目标文件夹内的循环处理，并在免费计划积分用完时暂停。

如果您的自动化目标是“一致地重命名文件”，Zush 是更强大的文档化系统。仅当相同操作还必须移动文件时才考虑 RenameClick；其较窄的格式覆盖范围仍然是该选择的成本。

## 搜索、元数据和检索

Zush 通过生成有意义的文件名、添加 Finder 标签以及编写 Spotlight 友好的元数据来帮助检索。这适合已经搜索过 Finder/Spotlight 并希望文件名包含最重要上下文的 Mac 用户。

RenameClick 添加单独的 AI Search 工作区。它允许您按内容含义进行搜索，而不仅仅是文件名关键字。例如，即使原始文件名是 `scan_001.pdf`，发票搜索也可以匹配 PDF 扫描。 AI Search 是只读的，用于重命名/移动目的，但它可以显示文件、排除结果或将项目移至垃圾箱。

对于在混乱的文件夹中进行发现，RenameClick 的 AI Search 是一个有意义的差异化因素。为了将文件转变为跨操作系统的长期可搜索资产，Zush 的文件名 + 标签 + 元数据工作流程是更好的日常层。

**选择 Zush 如果：**

- 您需要最广泛的格式覆盖范围，尤其是RAW照片、设计文件、视频、iWork和字幕

** 仅当满足以下条件时才考虑 RenameClick：**

- 按文件内容需要AI Search
- 您想要在同一自动化中重命名文件并将其移动到文件夹中

## 迁移提示

如果您是从RenameClick转到Zush，请先测试RenameClick未公开覆盖的文件：RAW照片、设计文件、视频和iWork文档。如果这些是您转换的原因，那么差异很快就会显而易见。如果您已使用云提供商密钥，请将其添加到 Zush BYOK 中，并将提供商成本与桌面应用程序分开。

如果您从 Zush 转到 RenameClick，请从免费计划开始，并在代表性文件夹上测试本地模型。注意硬件：RenameClick推荐16 GB系统RAM并使用多GB本地型号。如果内置模型对于您的文件来说太通用，请在判断工作流程之前尝试 LM Studio、Ollama 或云提供商。

## 常见问题解答

### RenameClick 比 Zush 便宜吗？

这取决于计划和当地增值税。 Zush 是 $10/month 或 $48 一次性。 RenameClick 是 $8+ 增值税/月或 $48+ 增值税有效期。在许多市场中，每月总额接近于扣除增值税后，而 Zush 的终生结帐总额较低，因为两者都从 $48 开始，并且 RenameClick 都添加了增值税。

### RenameClick 是否可以离线工作？

是的。 RenameClick 是本地优先。下载本地模型后，内置本地提供程序可以在没有互联网的情况下运行，无需 API 密钥，也无需 API 成本。云提供商需要互联网和您自己的提供商密钥。

### Zush 是否可以离线工作？

是的，通过 Ollama 的离线 AI 模式。不同的是Zush没有捆绑自己的本地模型作为默认路径；您设置 Ollama 并选择兼容的本地型号。

### RenameClick是否支持RAW照片？

RenameClick 的公共支持文件列表不包括相机 RAW 格式，如 CR2、CR3、NEF、ARW、DNG、ORF、RAF、RW2、PEF、SRW 或 SR2。 Zush 明确支持这些 RAW 格式。

### RenameClick 支持视频或音频文件吗？

音频有，视频没有。其文档现在列出了带有本地语音转录的 MP3、WAV、FLAC、M4A 和 AAC，而视频文件 (`.mp4`、`.mov`、明确不支持 `.mkv`、`.webm`)、其他音频编解码器、存档和可执行文件。 Zush 支持 16 视频格式及其音频列表。

### 哪个文件夹自动化更好？

这取决于目标。 Zush 更适合使用模板和 Naming Blocks 进行自动命名。 RenameClick 更适合文件夹路由，因为 Auto Flow 可以重命名、分类文件并将其移动到目标文件夹中。
