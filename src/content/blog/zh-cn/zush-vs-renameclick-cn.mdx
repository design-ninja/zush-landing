Zush 是一款适用于混合文件夹的桌面 AI 文件重命名器。当前的产品面很广泛：100 多种格式，涵盖图像、RAW 照片、设计文件、文档、iWork 和 Office 文件、字幕、视频和音频。它还具有模板、145 多个命名块、自定义提示、文件夹监控、完整的重命名历史记录、Finder 标签、Spotlight 友好的元数据、BYOK 和通过 Ollama 的离线 AI。

此比较中的重要部分是 Zush 不强制使用文件类型孤岛。包含 `IMG_4821.HEIC`、`_DSC0019.NEF`、`checkout-flow.fig`、`voice-memo.m4a`、`client-brief.pages`、`recording.mov` 和 `invoice.pdf` 的文件夹可以保留在一个工作流程中。

定价很简单：PRO 版每月 10 美元或一次性 48 美元。这两种付费计划都消除了 Cloud AI、BYOK 和 Offline AI 的重命名限制。免费提供模板、命名块和自定义提示。

RenameClick 是适用于 macOS 和 Windows 的本地优先桌面应用程序。其核心卖点是隐私：一次性本地模型下载后，其内置的 Qwen3-VL 提供程序可以在没有 API 密钥或互联网连接的情况下处理设备上的文件。它还支持用于本地服务器工作流程的 LM Studio 和 Ollama，以及在显式连接云 API 密钥时支持 OpenAI、Google Gemini 和阿里云 Qwen。 RenameClick 指出，云提供商在 Mac App Store 版本中不可用；如果这些提供商很重要，请使用直接下载。

RenameClick 不仅仅是一个重命名器。它更接近文件管理器：它可以重命名文件、对文件进行分类、将文件移动到文件夹中、运行自动流监视规则、使用 AI 搜索按内容进行搜索，以及根据 EXIF/日期占位符构建名称。其支持的文件文档现在涵盖三个类别：常见图像（JPEG、PNG、GIF、WebP、AVIF、BMP、SVG、HEIC、HEIF、TIFF）、长文档列表（PDF、DOC/DOCX、TXT、MD、CSV、RTF、ODT、JSON、XML、YAML、HTML、日志、SQL、SRT/VTT、ICS/VCF）和音频（MP3、WAV、FLAC、M4A、 AAC）和本地语音转录。视频文件、其他音频编解码器、存档和可执行文件被明确列为不受支持。

## 格式支持

### Zush 对于真正的混合文件夹来说更广泛

Zush 支持 RAW 照片格式、设计文件、音频、视频、iWork 文件、Office 文件、字幕和数据/文本格式。如果您的文件夹很乱，那么这就是实际优势，因为它们是真实的：手机照片旁边是屏幕截图，PDF 旁边是相机 RAW，Keynote/Pages 文档旁边是 Figma/Sketch/PSD 文件，会议记录旁边是视频文件。音频不再是这一差距的一部分——RenameClick 现在可以处理常见的音频格式——但 RAW、设计文件、iWork 和视频仍然是。

### RenameClick 涵盖常见图像、广泛的文档列表，现在还包括音频

RenameClick 很好地涵盖了常见的图像和文档工作流程 - JPEG、PNG、GIF、WebP、AVIF、BMP、SVG、HEIC、HEIF、TIFF，以及 PDF、DOC/DOCX、TXT、Markdown、CSV、RTF、ODT、JSON、XML、YAML、HTML、日志、SQL、字幕和日历/联系人文件 - 并且它还添加了带有本地语音的音频（MP3、WAV、FLAC、M4A、AAC）转录。它还具有有用的文档处理详细信息：文本 PDF 和 Office 文档的文本提取、扫描 PDF 的视觉回退以及可配置的文档文本修剪限制。

差距在于媒体和设计格式。 RenameClick 的文档没有列出相机 RAW 格式或 Sketch/Figma/PSD 等设计文件，并且明确表示不支持视频文件、存档和可执行文件。如果这些格式很重要，Zush 会更安全。

## 线下人工智能和提供商

如果您希望立即实现本地优先行为，则 RenameClick 会获胜。其本地提供商是默认的，模型捆绑为产品流程的一部分，文档描述了模型下载后的离线使用，无需 API 密钥，也无需 API 成本。它还公开了高级本地 AI 设置，例如上下文大小、温度、提示长度、文本修剪和批处理文件限制。

如果您更关心云提供商的选择和大容量 BYOK，那么 Zush 会获胜。 Zush 通过 BYOK 支持 Gemini、Groq、OpenAI 和 Claude，密钥存储在本地，当本地处理优先时，它通过 Ollama 支持离线 AI。 Groq 和 Claude 是 Zush 方面著名的选择；内置的Qwen3-VL、阿里云Qwen和LM Studio是RenameClick端选项。

权衡很简单：

- RenameClick：本地AI是默认的产品标识。
- Zush：BYOK 和广泛的格式覆盖是默认的产品标识，Ollama 可用于离线工作流程。

## 自动化和组织

这两种工具都可以监视文件夹，但它们强调不同的结果。

Zush 文件夹监控是围绕自动 AI 重命名而构建的，具有可重用模板和命名块。它非常适合下载清理、屏幕截图、重复客户端文件夹和可预测的命名约定，其中新文件到达时应获得可搜索的名称。

RenameClick Auto Flow 更像是一个规则行系统。每行可以有自己的源文件夹、目标文件夹、命名格式、自定义指令、语言、排序预设、递归设置和自动应用设置。它可以同时运行多行，在处理之前等待文件变得稳定，避免目标文件夹内的循环处理，并在免费计划积分用完时暂停。

如果您的自动化目标是“一致地重命名文件”，Zush 会更干净。如果您的自动化目标是“重命名并将文件路由到文件夹结构”，则 RenameClick 更强大。

## 搜索、元数据和检索

Zush 通过生成有意义的文件名、添加 Finder 标签以及编写 Spotlight 友好的元数据来帮助检索。这适合已经通过 Finder/Spotlight 进行搜索并希望文件名包含最重要上下文的 Mac 用户。

RenameClick 添加了一个单独的 AI 搜索工作区。它允许您按内容含义进行搜索，而不仅仅是文件名关键字。例如，即使原始文件名是 `scan_001.pdf`，发票搜索也可以匹配 PDF 扫描。 AI 搜索对于重命名/移动目的是只读的，但它可以显示文件、排除结果或将项目移至垃圾箱。

对于在混乱的文件夹中进行发现，RenameClick 的 AI 搜索是一个有意义的差异化因素。为了将文件转变为跨操作系统的长期可搜索资产，Zush 的文件名 + 标签 + 元数据工作流程是更好的日常层。

## 按用例选择

**选择 Zush 如果：**

- 您需要最广泛的格式覆盖范围，尤其是 RAW 照片、设计文件、视频、iWork 和字幕
- 您想要更便宜的终身计划：一次性 48 美元，而不是 48 美元+增值税
- 您希望每个套餐都提供 Gemini、Groq、OpenAI 或 Claude 的 BYOK
- 您需要 60 多种输出语言
- 您需要模板和 145+ 命名块来实现可重复的文件名结构
- 您想要一个跨 Mac 和 Windows 的重命名工作流程，而不首先考虑本地模型硬件

**选择RenameClick如果：**

- 您想要捆绑的本地 AI 模型作为默认路径
- 您需要AI按文件内容搜索
- 您想要在同一自动化中重命名文件并将其移动到文件夹中
- 您依赖以 EXIF 为主的照片命名模式
- 您更喜欢基于 LM Studio、Ollama 或 Qwen 的工作流程
- 您处理敏感的法律、医疗或私人文档，其中默认离线比文件类型广度更重要

在购买之前，将相同的十个代表性文件复制到测试文件夹中，并通过两个免费工作流程运行它们。比较名称质量、预览清晰度、处理时间、不支持的格式以及反转整个批次的能力。

## 迁移提示

如果您从 RenameClick 转到 Zush，请首先测试 RenameClick 未公开覆盖的文件：RAW 照片、设计文件、视频和 iWork 文档。如果这些是您转换的原因，那么差异很快就会显而易见。如果您已使用云提供商密钥，请将其添加到 Zush BYOK 中，并将提供商成本与桌面应用程序分开。

如果您从 Zush 转到 RenameClick，请从免费计划开始，并在代表性文件夹上测试本地模型。注意硬件：RenameClick 建议使用 16 GB 系统 RAM，并使用多 GB 本地型号。如果内置模型对于您的文件来说太通用，请在判断工作流程之前尝试 LM Studio、Ollama 或云提供商。

## ＃＃ 常问问题

### RenameClick 比 Zush 便宜吗？

这取决于计划和当地增值税。 Zush 的价格为 10 美元/月或 48 美元/次。 RenameClick 每月需缴纳 8 美元以上增值税，或终身缴纳 48 美元以上增值税。在许多市场中，每月总结帐总额都接近扣除增值税后的金额，而 Zush 的终生结帐总额较低，因为两者起价均为 48 美元，而且 RenameClick 还添加了增值税。

### RenameClick 可以离线使用吗？

是的。 RenameClick 是本地优先的。下载本地模型后，内置的本地提供程序可以在没有互联网、没有 API 密钥、也没有 API 成本的情况下运行。云提供商需要互联网和您自己的提供商密钥。

### Zush 可以离线工作吗？

是的，通过 Ollama 的离线 AI 模式。不同的是，Zush 并没有捆绑自己的本地模型作为默认路径；您设置 Ollama 并选择兼容的本地型号。

### RenameClick 支持 RAW 照片吗？

RenameClick 的公共支持文件列表不包括相机 RAW 格式，如 CR2、CR3、NEF、ARW、DNG、ORF、RAF、RW2、PEF、SRW 或 SR2。 Zush 明确支持这些 RAW 格式。

### RenameClick 支持视频或音频文件吗？

音频有，视频没有。它的文档现在列出了带有本地语音转录的 MP3、WAV、FLAC、M4A 和 AAC，而视频文件（`.mp4`、`.mov`、`.mkv`、`.webm`）、其他音频编解码器、存档和可执行文件明确不受支持。 Zush 支持 16 种视频格式及其音频列表。

### 哪个文件夹自动化更好？

这取决于目标。 Zush 更适合使用模板和命名块进行自动命名。 RenameClick 更适合文件夹路由，因为自动流可以重命名、分类文件并将其移动到目标文件夹中。
