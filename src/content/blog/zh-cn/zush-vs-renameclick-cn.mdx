![Zush AI 重命名结果，显示文件改名前后的描述性名称和绿色对勾](/images/showcase/macos/batch-rename-light.webp)

Zush 是一款面向混合文件夹的桌面 AI 文件重命名工具。它会读取每个文件，给出一个名称，在你点击 Rename 之前什么都不会改变。你也可以先双击任意建议进行编辑。名称由现成的 Templates（Movies & TV、Remove Duplicates 等）、145+ 个 Naming Blocks、Custom AI Blocks，以及大小写、分隔符、日期和语言设置组合而成。Rename History 会记录每一批操作的原名、新名、文件夹和时间，所以下周也能撤销某一批。

一个包含 `IMG_4821.HEIC`、`_DSC0019.NEF`、`checkout-flow.fig`、`voice-memo.m4a`、`client-brief.pages`、`episode-03.mkv` 和 `invoice.pdf` 的文件夹，可以在同一个工作流中处理。

免费版在 Zush Cloud AI 上提供 50 次 AI 重命名，无需账号、银行卡、API 密钥，也不用下载模型。PRO 为每月 $10 或一次性 $48。两者都会解除 Zush Cloud AI、BYOK（Gemini、OpenRouter、OpenAI、Claude）、LM Studio 和 Ollama 的限制。一份许可证最多可用于 3 台 Mac 和 Windows 设备，你还可以 [导出 Templates](/docs/template-import-export)，在设备之间迁移设置。

![RenameClick 桌面应用界面（图片来源：rename.click）](/images/blog/competitors/renameclick.webp)

RenameClick 是一款本地优先的 macOS 和 Windows 桌面应用，官网现为 rename.click。它的内置服务商在你的设备上运行一个约 4 GB 的本地模型，无需 API 密钥；厂商建议 16 GB 内存。在直接下载的 Mac 和 Windows 版本中（不含 Mac App Store 版），它还能连接 LM Studio、Ollama 以及 OpenRouter 等兼容 OpenAI 的 API，服务商用量单独计费。

最近两个版本改变了局面。4.0.1 版新增了 MCP 服务器，让 AI 代理可以操作 RenameClick。4.1.2 版（2026 年 11 月 10 日）新增了视频支持：MP4、MOV、M4V 和 3GP 文件会根据抽样画面加本地语音转写来命名。MKV、WebM 和 AVI 仍被列为不支持。

RenameClick 更像文件整理工具，而不是单纯的重命名工具。它可以重命名、把文件移进文件夹集合、运行 Auto Flow 监控规则，还有一个按含义查找文件的 AI Search 工作区，所以搜索“发票”也能匹配到名为 `scan_001.pdf` 的扫描件。

## 价格：各自的许可证包含什么

Zush 一次性 $48 或每月 $10，税前一年合计 $120，三年 $360，五年 $600。RenameClick 一次性 $36 加增值税，或每月 $8 加增值税。真正有意义的比较是一次性价格能买到什么：

- **Zush $48**：托管 Zush Cloud AI 以及 BYOK 和本地模型下的无限次重命名、今后所有更新、最多 3 台 Mac 和 Windows 设备，以及 14 天退款期。
- **RenameClick $36 + 增值税**：使用内置本地模型、Ollama、LM Studio 或你自己 API 密钥的无限次重命名。云端服务商费用由你承担。终身更新，直接下载版本最多 3 台设备，仅在法律要求时退款。

如果你想要云端质量的名称，又不想运行模型或向服务商付费，Zush 的许可证涵盖了这一点，RenameClick 的则没有。如果你希望一切都在本机完成、无需额外设置，RenameClick 自带的模型更省事；Zush 则需要 Ollama 或 LM Studio 才能做到。

免费额度也不同。Zush 总共提供 50 次重命名，不按月重置。RenameClick 在下载模型后每月提供 100 次重命名或移动。

## 视频和媒体

两款应用现在都能根据视频内容命名。区别在于覆盖范围和依据：

- **容器格式。** Zush 读取 MP4、MOV、MKV、AVI、WMV 及其他常见格式。RenameClick 读取 MP4、MOV、M4V 和 3GP，并把 MKV、WebM 和 AVI 列为不支持。如果你的视频来自会输出 MKV 的下载或录屏工具，这一点很重要。
- **依据。** Zush 综合抽样画面、语音、内嵌字幕轨（包括 MKV 文件内的字幕）和文件元数据。RenameClick 综合画面和本地语音转写。
- **本地语音。** Zush 可以通过 Ollama 或 LM Studio 在本地转写（Mac 3.20.1）；RenameClick 用的是自己的本地技术栈。
- **剧集和电影。** Zush 的 Movies & TV 模板会按剧名、季数和集数为剧集命名，还能把它们分到剧集和季度文件夹中。

在 Windows 上，Zush 还能识别没有标签的音乐。该功能尚未在 Mac 上提供。请看 [音频和视频分析](/docs/audio-video) 和 [用 AI 重命名视频](/rename-videos-with-ai)。

## 照片、设计文件和文档

RenameClick 对常见图片和一长串文档格式的支持都不错，可从 PDF 和 Office 文件中提取文本，扫描件则退回视觉识别。它的文档没有列出相机 RAW、Sketch、Figma 或 PSD 文件。

Zush 列出了 11 种 RAW 变体（CR2、CR3、NEF、ARW、DNG、ORF、RAF、RW2、PEF、SRW、SR2）、设计文件（Sketch、Figma、Illustrator、Photoshop）、iWork 文档、EPUB 和字幕。如果你正是因为这些格式才读到这里，请先测试它们。

## 撤销和恢复

RenameClick 的标准 Rename 工作区在内存中最多保存 10 条撤销记录，应用重启后就会清空；在我们的测试中，它的撤销一次就恢复了整批 27 个文件。它的 Auto Flow 会在重启后保留符合条件的记录。

Zush 为每一批操作保存持久的 [Rename History](/docs/undo-history)。Undo All 会还原整批操作，列出所有冲突（例如某个新文件现在占用了旧名称），并提供以新名称恢复的选项。Zush 在 AI Rename 过程中移到废纸篓的重复副本，也能通过 Undo 恢复。

## 自动化和分类

两款应用都能监控文件夹并移动文件。

Zush 的 Monitor 会用 Template 重命名新文件，并可按日常语言的 Folder rules 或 Auto 进行分类，包括嵌套文件夹。规则还可以使用日期、页数等文件信息（Mac 应用还能使用大小、相机和时长）。你可以对已经重命名的文件只做分类，而不再改名。在 Mac 上，监控范围涵盖外置硬盘，重新连接后会自动恢复。请看 [文件夹分类指南](/docs/folder-sorting)。

RenameClick 的 Auto Flow 由一行行规则组成，每行包含源文件夹、目标位置、命名格式、指令、语言和分类预设。它会等待文件写入完成，避免在目标文件夹内形成循环，并在免费版额度用完时暂停。它只在应用打开时运行。

## 该选哪一款？

**以下情况选 Zush**：

- 你的文件夹里有 MKV 视频、RAW 照片、设计文件或 iWork 文档
- 你希望任何一批操作在重启后仍可撤销
- 你想要一个包含托管云端 AI 的一次性价格，不用下载模型，也没有服务商账单
- 你想要一份许可证覆盖多台 Mac 和 Windows 电脑，最多 3 台设备
- 你希望在重命名的同一轮中处理重复文件

**以下情况选 RenameClick**：

- 你想用自带模型离线重命名，不配置 Ollama，而且你的 Mac 或 PC 内存足够
- 你需要在专门的工作区中按内容搜索文件
- 你想让 AI 代理通过 MCP 服务器执行重命名
- 你更喜欢从文件夹集合中挑选，而不是编写文件夹规则

购买之前，把十个有代表性的文件复制到一个测试文件夹，分别用两款应用的免费版运行。对比名称、预览、不支持的格式，以及能否撤销整批操作。

## 常见问题

### 什么时候应该选 Zush 而不是 RenameClick？

当文件夹里混杂着 RAW 照片、设计文件、iWork 文档、音频和 MKV 视频，并且你希望名称遵循可复用的 Template 时，就选 Zush。Zush 会预览每个名称，持久保存带批量撤销的 Rename History，其 $48 许可证包含托管云端 AI，最多可用于 3 台设备。如果你需要自带的本地模型、AI Search 或 MCP 服务器，RenameClick 更合适。

### RenameClick 支持视频文件吗？

支持，自 4.1.2 版（2026 年 11 月 10 日）起。它会根据抽样画面加本地语音转写为 MP4、MOV、M4V 和 3GP 视频命名，也支持 MP3、WAV、FLAC、M4A 和 AAC 等音频文件。MKV、WebM 和 AVI 仍被列为不支持。Zush 支持 MP4、MOV、MKV、AVI、WMV 等格式，还能读取内嵌字幕轨。请看 [支持的格式列表](/docs/supported-file-types)。

### RenameClick 比 Zush 便宜吗？

标价更低：一次性 $36 加增值税，而 Zush 是 $48。但两份许可证涵盖的内容不同。Zush 的 $48 包含托管的 Zush Cloud AI、BYOK 和本地模型、今后所有更新、3 台 Mac 和 Windows 设备，以及 14 天退款。RenameClick 的终身许可证涵盖其本地模型或你自己的密钥，服务商费用由你承担，仅在法律要求时退款。

### 两款应用分别在哪里处理我的文件？

RenameClick 的内置模型在下载约 4 GB 后于你的设备上运行；你连接的云端服务商会收到所需的内容。在 Zush 中，Ollama 和 LM Studio 会把分析留在你的电脑上，而 Zush Cloud AI 和 BYOK 会把命名所需的内容发送到云端模型。你可以按 Template 选择模式，所以私密文件夹可以只在本地处理。

### 重启之后还能撤销批量重命名吗？

在 Zush 中可以。Rename History 保存在磁盘上，Undo All 可以还原整批操作，并列出所有名称冲突。在 RenameClick 的 Rename 工作区中，撤销记录最多在内存中保存 10 条，重启后清空；Auto Flow 会在重启后保留符合条件的记录。在用任何一款应用处理大型文件夹之前，请先在副本上测试恢复功能。

### RenameClick 支持 OpenRouter 吗？

支持，在其直接下载的 Mac 和 Windows 版本中，与其他兼容 OpenAI 的 API 一起提供。Mac App Store 版不包含此功能，所连接的服务商会单独计费。Zush 在所有方案中都通过 BYOK 支持 OpenRouter，所以单凭 OpenRouter 不构成换用任何一方的理由。

### RenameClick 支持 RAW 照片吗？

其公布的支持文件列表不包括 CR2、CR3、NEF、ARW 或 DNG 等相机 RAW 格式，也不包括 PSD、Sketch 和 Figma 等设计文件。Zush 列出了 11 种 RAW 变体以及这些设计格式。如果 RAW 文件是你工作流的一部分，请在购买前用两款应用的免费版各处理几个试试。

两者的重叠已经很大：都支持 Mac 和 Windows，都按内容重命名，都能处理常见的视频和音频，都能监控文件夹，都支持本地 AI，也都出售终身许可证。
