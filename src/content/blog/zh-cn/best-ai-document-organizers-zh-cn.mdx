## 用 AI 整理文档的两种方式

选哪一类，比任何功能清单都重要：

1. **基于文件夹的工具**直接在文件所在位置重命名和移动文件。文档仍然是 Finder、File Explorer、iCloud、OneDrive 或 Dropbox 里的普通文件。Zush、NameQuick、Wisfile 和 File Juggler 都是这种方式。
2. **档案类工具**把文档导入自己的资料库或服务器，再添加标签、全文搜索和元数据。Paperless-ngx 和 DEVONthink 属于这种方式。

如果你要和会计、团队或其他应用共享文件夹，请选择基于文件夹的工具。如果你想在一个地方搜索所有内容，并且乐意在该应用里工作，就选档案类工具。

## 1. Zush：最适合你现有文件夹的 AI 文档整理工具

[Zush](/ai-file-organizer) 支持 Mac 和 Windows。把一个装满 PDF、扫描件、收据、合同、Word、Excel、Pages 或 EPUB 文件的文件夹拖进去，它会逐个读取，包括没有文字层的纯图像扫描件。它根据你平时搜索用的字段生成名称：日期、供应商、金额、客户、文档类型、发票号。在你点击 Rename 之前什么都不会改动，你也可以双击任意建议进行编辑。

![Mac 版 Zush 在应用批处理之前列出混合文件夹中每个文件的拟定文件名](/images/showcase/macos/batch-rename-light.webp)

Zush 的名称遵循 Template，因此每张发票的格式都一致，而不是由 AI 随意发挥。Bookkeeper Expenses 是现成的 Templates 之一，145+ 个 Naming Blocks 让你搭建自己的命名格式，需要时还可以加序号。

如果还要归档文档，就在 **Folder rules** 里写一句话，例如“发票按公司分组，收据按月份分组”，或者交给 Auto。名称和文件夹会在同一个预览中供你审阅。规则也可以使用日期、页数等文件信息，而且在 Mac 和 Windows 上都可以只分类、不重命名。

![Zush 的 Folder rules 对话框，指令为发票按公司分组、收据按月份分组，并附有示例规则](/images/showcase/macos/folder-rules-light.webp)

对于持续进来的文件，把 Template 分配给扫描仪或 Downloads 文件夹的 **Monitor**。AI Rename 还能识别重复的扫描件：保留、在名称中标记，或移到废纸篓或回收站，副本不消耗额度。Rename History 在重启后仍会保留，Undo All 可以还原整批操作并标出冲突。

Zush 开箱即用：在 Zush Cloud AI 上有 50 次免费 AI 重命名，无需账号、银行卡、API 密钥，也不用下载模型。敏感文件可以通过 Ollama 或 LM Studio 留在你的电脑上。$48 一次性许可证包含托管云端 AI 以及所有本地和 BYOK 模式、今后所有更新、最多 3 台 Mac 和 Windows 设备，以及 14 天退款。

如果你的文档应当保持为任何人都能从共享文件夹打开的普通文件，就选 Zush。实用指南：[自动重命名扫描文档](/blog/rename-scanned-documents-automatically)、[用 AI 重命名发票](/rename-invoices-with-ai) 和 [用 AI 重命名收据](/rename-receipts-with-ai)。有重复扫描件？请看 [删除重复文件](/remove-duplicate-files)。

## 2. Paperless-ngx：最佳免费自托管档案库

Paperless-ngx（v3.4.2）是一款开源文档管理系统（GPL-3.0），运行在你自己的服务器或 NAS 上，通常借助 Docker 部署。它用 Tesseract 对 100 多种语言进行 OCR，在原件旁保留一份 PDF/A 归档副本，并用机器学习建议标签、往来方和文档类型。它还能从电子邮件导入文档。

它的 AI 功能是可选的，默认关闭：AI 建议、与文档对话、相似文档搜索。这些功能可通过 Ollama 在本地运行，也可以接入兼容 OpenAI 的 API。Paperless 自己管理文件名和存储路径，格式可配置。

如果你熟悉自托管，想为家庭或小型办公室建一个可搜索的纸质档案库，就选 Paperless-ngx。不足：需要服务器和 Docker 环境，文档存放在它的档案库里，而不是你现有的文件夹结构中。

## 3. DEVONthink：Mac 上最好的文档数据库

DEVONthink 4.4.2 是一款历史悠久的 Mac 应用，用于存储、搜索和分类文档。OCR 和生成式 AI 功能（对话、摘要、打标签、智能规则批处理）仅在 Pro 和 Server 版提供。支持的模型包括 ChatGPT、Claude 和 Mistral，也可通过 Ollama 或 LM Studio 使用本地模型。

Standard 版 $99，Pro 版 $199，Server 版 $499，每种都含两台 Mac 授权和一年更新。许可证永不过期，再续一年更新分别需要 $44、$89 或 $134。

如果你想在 Mac 上拥有研究级的文档库，就选 DEVONthink。不足：读取扫描件至少需要 $199 的 Pro 版，而且文档存放在它的数据库里，对于只想给文件命名和归档的大多数人来说有些过度。

## 4. NameQuick：带条件规则的文档重命名

NameQuick 专注于 Mac 和 Windows 上反复出现的 PDF、扫描件、收据、发票、合同、Word 文档和电子表格。它用 Presets 按内容重命名，可以监控文件夹，并在命名后运行条件 Rules 来移动、打标签或归档文件。

![NameQuick 宣传图，展示扫描的发票、收据和合同被重命名为带日期和供应商名称的文件](/images/blog/competitors/namequick.webp)

你可以获得 30 次免费 Managed 重命名，无需电子邮件或银行卡。Managed 方案从每月 $12（500 次重命名）到每月 $99（10,000 次）不等，重命名包为 $19 购 500 次或 $39 购 1,500 次（12 个月内有效）。NameQuick 的 $69 Self-Managed 许可证限一台电脑，需要使用你自己的 API 密钥或本地模型。

如果你需要基于“如果/那么”Rules 的文档工作流，就选 NameQuick。不足：一次性许可证不含托管 AI，而且文件之后若被移动，撤销可能失败。完整对比：[Zush 与 NameQuick 对比](/blog/zush-vs-namequick)。

## 5. Wisfile：免费在本地重命名 PDF 和 Word

Wisfile 免费，在 Mac 和 Windows 上本地运行。它根据内容重命名 PDF 和 Word 文档，例如把研究论文命名为 `Author-Year-Title`，还能把文件按主题分到不同文件夹。

![Wisfile 官方示意图：杂乱的 PDF 文件名被改成带日期、描述清楚的文档文件名](/images/blog/competitors/wisfile.webp)

如果你没有预算，只想一次性清理文档归档，就选 Wisfile。不足：据其 FAQ，它没有文件夹监控、定时任务和内置撤销，所以请在副本上操作。详情：[Zush 与 Wisfile 对比](/blog/zush-vs-wisfile)。

## 6. File Juggler：Windows 上处理格式固定文档的规则工具

File Juggler 不是 AI 工具，但能为格式总是一样的文档分流。规则可以匹配 PDF、Word 和 Excel 文件中的词语，复用文本中找到的日期，然后重命名并移动文件。3.1.9 版于 2026 年 10 月 30 日发布，Softpedia 编辑评分为 4.5/5。

价格为一次性 $50（未含税），提供 30 天全功能试用。不足：没有单独的 OCR 程序就读不了纯图像扫描件。如果你的文档格式多变，请看 [File Juggler 替代品](/blog/file-juggler-alternatives)。

## 用 15 份真实文档测试

把十五份文档复制到一个测试文件夹：五张发票或收据、三份没有文字层的扫描件、两份合同、两份电子表格、一个 Word 文件、一份银行对账单，以及一张手写便条的照片。然后检查：

3. 能否事先审阅每处改动，事后再撤销？
4. 其他人是否仍能从同一个共享文件夹打开这些文件？

## 常见问题

### 最好的 AI 文档整理工具是哪款？

如果文档应当留在 Mac 或 Windows 的普通文件夹里，答案是 Zush。它按内容为 PDF、扫描件和 Office 文件命名并分类，任何改动之前都有预览，撤销记录持久保存。如果你想要自托管的档案库，Paperless-ngx 是最好的免费选择；DEVONthink Pro 适合想要完整文档数据库的 Mac 用户。Zush 是我们开发的，所以请用你自己文件的副本来测试。

### 有免费的 AI 文档整理工具吗？

有。Paperless-ngx 免费开源，但需要服务器。Wisfile 在 Mac 和 Windows 上免费处理 PDF 和 Word 文档，但没有撤销。Zush 提供 50 次免费 AI 重命名，无需账号、银行卡或 API 密钥；NameQuick 提供 30 次免费 Managed 重命名。DEVONthink 和 File Juggler 提供试用，而不是免费版。

### AI 文档整理工具能读取扫描的 PDF 吗？

能，但并非全部都能。Zush 直接读取纯图像扫描件，不需要单独的 OCR 步骤。Paperless-ngx 在导入时运行 Tesseract OCR，DEVONthink 只有 Pro 和 Server 版才有 OCR。NameQuick 和 Wisfile 也能处理扫描件。File Juggler 需要先用单独的 OCR 程序处理，因为它的规则只能匹配文件中已有的文字。

### 能不上传文档就用 AI 整理吗？

能。使用 Ollama 或 LM Studio 的 Zush、Wisfile、接入本地 Ollama 后端的 Paperless-ngx、使用本地模型的 DEVONthink Pro，以及使用本地模型的 NameQuick Self-Managed，都能把文档留在你自己的设备上。在 Zush Cloud AI 或 BYOK 模式下，文档内容会发送到云端模型进行分析，所以机密文件请选择本地模式。

### 一次性买断的文档整理工具许可证包含什么？

差别很大。DEVONthink 的 $99 到 $499 许可证包含一年更新。NameQuick 的 $69 Self-Managed 许可证限一台电脑，需要自备 AI。File Juggler 的 $50 买到的是没有 AI 的规则。Zush 的 $48 许可证包含托管的 Zush Cloud AI、本地和 BYOK 模式、无限次重命名、今后所有更新，以及最多 3 台 Mac 和 Windows 设备。
