### 为什么 Zush 在 Mac 上排名第一

1. **它支持 Apple Silicon 和 Intel。** 任何运行 macOS 15 或更高版本的 Mac 都能用，可从 Mac App Store 获取，也可直接下载。在云端模式下约 200 MB，需要 4 GB 内存；RenameClick 的自带模型则建议 16 GB。
2. **它能从 Finder 直接使用。** 选中文件并选择 **Rename with Zush**（或按 Quick Rename 快捷键）；Mac App Store 版则会打开文件选择器。较大的批次会经过预览，Rename History 在重启后也能撤销整批操作。
3. **拔掉硬盘也不影响监控。** 受监控的文件夹可以位于外置硬盘上，硬盘重新连接后监控会自动恢复。
4. **需要时本地，不需要时云端。** 使用 Ollama 或 LM Studio 时，文件分析以及音频和视频的语音识别都在 Mac 上运行（3.20.1 及更高版本）。同一份 $48 许可证还包含托管的 Zush Cloud AI、无限次重命名、今后所有更新，以及最多 3 台设备。

## 好的 Mac AI 重命名工具应该产出什么

基于内容的重命名，会把毫无信息的名称变成能在 Spotlight 中搜索到的名称：

| 重命名前 | 重命名后 |
|---|---|
| `Screenshot 2026-02-14 at 10.32.15 AM.png` | `slack-conversation-project-timeline-update.png` |
| `IMG_4821.HEIC` | `golden-gate-bridge-fog-morning-view.heic` |
| `DSC_0093.NEF` | `portrait-woman-natural-light-studio.nef` |
| `scan0042.pdf` | `signed-lease-agreement-apartment-3b.pdf` |
| `Invoice-38291.pdf` | `invoice-cloudflare-december-2025.pdf` |
| `Untitled.xlsx` | `employee-onboarding-checklist-2026.xlsx` |

如果每个文件只需要加相同的前缀或编号，Finder 自带的重命名就够了；请看 [Mac 批量重命名](/blog/batch-rename-files-on-mac-complete-guide)。AI 重命名工具适用于每个文件都需要专属名称的文件夹。

**使用方式**：选择一个现成的 Template（Smart Rename、Screenshots、Movies & TV、Remove Duplicates 等），或者用 145+ 个 Naming Blocks 和 Custom AI Blocks 自己搭建。Zush 会为每个文件给出名称；双击任意名称即可编辑。在你点击 Rename 之前什么都不会改变。

**优点**：

- 首次启动即可使用托管云端 AI；BYOK（Gemini、OpenRouter、OpenAI、Claude）、Ollama 和 LM Studio 使用相同的工作流
- 根据语音、内嵌字幕和元数据为视频命名；搭配 Ollama 或 LM Studio 可进行本地语音识别
- 持久保存的 Rename History，支持批量撤销；Undo All 会标出冲突
- 重复文件检测：保留、在名称中标记，或把副本移到废纸篓；副本不消耗额度，Undo 可以恢复

- Finder 标签和 Spotlight 元数据；界面支持 11 种以上语言，名称支持 60 种以上语言

**局限**：

- 没有 Linux 版，也没有纯浏览器版
- Zush Cloud AI 和 BYOK 需要联网；Ollama 和 LM Studio 在你的 Mac 上运行
- 识别没有标签的音乐目前仅限 Windows

## 常见问题

### Mac 上最好的 AI 文件重命名工具是哪款？

我们推荐 Zush。它一开始就提供 50 次基于托管云端 AI 的免费重命名，无需账号、银行卡或 API 密钥。$48 一次性许可证包含托管云端 AI、BYOK、Ollama 和 LM Studio，最多可用于 3 台 Mac 或 PC，每一批都会先预览，并保存在支持批量撤销的持久 Rename History 中。它还支持 RAW、设计文件、iWork 和 MKV 视频。

### Zush 的 $48 许可证比 $19 或 $36 的更划算吗？

更便宜的许可证涵盖的是应用本身，AI 则要用你自己的 API 密钥或本地模型运行。AI Renamer Local 为 $19，RenameClick 终身版为 $36 + 增值税；两者都不含托管云端 AI。Zush 的 $48 包含 Zush Cloud AI 和无限次重命名，以及 BYOK 和本地模型、今后所有更新、3 台 Mac 和 Windows 设备，以及 14 天退款。

### AI 文件重命名工具会上传我的文件吗？

取决于模式。Zush Cloud AI 和 BYOK 会把文件内容发送到 AI 服务来生成名称。使用 Ollama 或 LM Studio 时，Zush 在你的 Mac 上分析文件。RenameClick 默认使用自带的本地模型，Renamer.ai 所有档位都提供本地模式，File Renamer AI 则是浏览器上传服务。请查看 [Zush 隐私与安全指南](/docs/privacy-security) 以及各厂商的隐私页面。

### Mac 上最好的免费 AI 文件重命名工具是哪款？

Zush 提供 50 次 AI 重命名，无需账号或银行卡，预览和 Rename History 与付费版相同。RenameClick 在下载 4 GB 模型后每月允许 100 次重命名或移动。NameQuick 提供 30 次无需银行卡的托管重命名，Renamer.ai 每月 25 个文件，AI Renamer 在 Google 登录后提供 10 个额度。[免费 AI 文件重命名工具对比](/blog/free-ai-file-renamers) 列出了哪些额度按月重置，[免费 AI 重命名指南](/blog/rename-files-with-ai-free) 则带你完成第一批重命名。

### AI 文件重命名工具能处理 RAW 照片和 MKV 视频吗？

并非全部都能。Zush 列出了 CR2、CR3、NEF、ARW、DNG 等 RAW 格式，并根据语音、字幕和元数据为包括 MKV 在内的视频命名。AI Renamer 在 1.10 版中新增了 RAW 和视频支持。RenameClick 支持 MP4、MOV、M4V 和 3GP，但不支持 MKV、WebM、AVI 或 RAW。Renamer.ai 没有列出任何相机 RAW 格式。

### 在 Mac 上能撤销 AI 重命名吗？

在 Zush 中可以。Rename History 在重启后依然保留，所以之后也能撤销整批操作，Undo All 会在恢复前标出冲突。NameQuick 和 FilesDesk 保留带撤销的历史记录；NameQuick 提示文件被移动后撤销可能失败。RenameClick 在内存中保存 10 条撤销记录，重启后清空。AI Renamer 没有记载撤销功能，所以请在副本上测试。
