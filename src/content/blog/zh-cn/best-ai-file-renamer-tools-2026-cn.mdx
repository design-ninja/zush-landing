### 为什么 Zush 排名第一

以下是可核查的事实，而非印象：

1. **在 Mac 或 Windows 上开箱即用。** 在托管的 Zush Cloud AI 上有 50 次免费 AI 重命名，无需账号、银行卡、API 密钥，也不用下载模型。AI Renamer 需要 Google 登录，FilesDesk 需要登录，RenameClick 的免费 AI 方案则需要下载约 4 GB 的本地模型，并建议 16 GB 内存。NameQuick Managed 同样容易上手，提供 30 次免费重命名。
2. **一份许可证覆盖两个平台，包含云端。** $48 一次性买断可用于最多 3 台 Mac 和 Windows 设备，包含所有模式（Zush Cloud AI、BYOK、Ollama、LM Studio）下的无限次重命名、今后所有更新和 14 天退款。AI Renamer（$19）、RenameClick（$36 + 增值税）、RenamerX（$36）、FilesDesk（$40）和 NameQuick（$69）的一次性许可证都需要你自己的密钥或本地模型。
3. **在你点击 Rename 之前什么都不会改变，之后也能撤回。** Rename History 在重启后依然保留，可以撤销整批操作。RenameClick 的撤销只有内存中的 10 条记录，AI Renamer 没有记载撤销功能，Wisfile 则完全没有撤销。
4. **覆盖面广。** 根据语音、内嵌字幕和元数据为视频命名，包括 MKV；还支持 RAW 照片、设计文件、音频、Office、iWork 和 EPUB。AI Rename 中的重复文件检测不消耗额度。

Zush 不适合的情况：它没有 Linux 版（AI Renamer 有），没有纯浏览器或云存储 API 工作流（Renamed.to 有），退款期为 14 天。评分（截至 2026 年 11 月 17 日）：美国区 Microsoft Store 5.0 分（8 个评分），Softpedia 编辑评测 4.5/5。

### 1. Zush

[Zush](/) 是一款适用于 Mac 和 Windows 的桌面应用，可根据内容为文件命名。它支持 100 多种格式：41 种图片格式（包括 HEIC、AVIF 和相机 RAW）、4 种设计格式（Sketch、Figma .fig、Illustrator .ai、PSD）、40 种文档格式（包括 PDF、Office、iWork、OpenDocument 和 EPUB）、包括 MP4、MOV 和 MKV 在内的视频，以及 7 种音频格式。视频根据语音、内嵌字幕和元数据命名；[如何用 AI 重命名视频文件](/blog/rename-video-files-with-ai) 说明了它读取哪些内容。

使用方式：选择一个现成的 Template（Smart Rename、Screenshots、Movies & TV、Remove Duplicates 等），或者用 145+ 个 Naming Blocks 和 Custom AI Blocks 自己搭建。Zush 会为每个文件给出名称。双击任意名称即可编辑，在你点击 Rename 之前什么都不会改变。

**优点**：

- 首次启动即可使用托管云端 AI，无需账号或密钥
- 一个工作流中有四条 AI 路线：Zush Cloud AI、BYOK（Gemini、OpenRouter、OpenAI、Claude）、Ollama、LM Studio，并可通过 Ollama 或 LM Studio 对视频进行本地语音识别
- 应用前预览，持久保存的 Rename History 支持批量撤销，Undo All 会标出冲突
- 重复文件检测：保留副本、在名称中标记，或移到废纸篓/回收站，不消耗额度
- 文件夹监控，包括 Mac 上重新连接后自动恢复的外置硬盘
- 可自定义起始值和前导零的序号，按文件夹编号
- 可选的 AI 文件夹分类，支持嵌套文件夹
- 云端模式很轻量：约 200 MB，至少 4 GB 内存
- 界面支持 11 种以上语言；名称支持 60 种以上语言

**局限**：

- 没有 Linux 版，也没有纯浏览器版
- Zush Cloud AI 和 BYOK 需要联网；Ollama 和 LM Studio 在你的电脑上运行
- 识别没有标签的音乐目前仅限 Windows

**最适合**：拥有混合文件夹、希望 AI 重命名立即可用并且一次性付费的 Mac 和 Windows 用户。

一份 Zush 许可证最多可用于 3 台 Mac 和 Windows 设备。你可以 [导出 Templates](/docs/template-import-export) 并在另一台电脑上导入。

#### 可选的 AI 文件夹分类

Zush 还能把文件分类到文件夹。选择 **Auto**，或者写下 **Folder rules**，例如“发票按公司分组，收据按月份分组”。规则可以创建嵌套文件夹，也可以使用日期、页数等文件信息（Mac 应用还能使用大小、相机和时长）。你可以只分类不重命名，选择目标文件夹，并复用现有文件夹。把设置保存为 Template 并分配给受监控的文件夹，即可处理新到达的文件。请看 [文件夹分类指南](/docs/folder-sorting) 和 [AI 文件整理工具](/ai-file-organizer) 页面。

### 2. FilesDesk

FilesDesk 支持 Mac 和 Windows，提供 Watch Folders、可重命名 Gmail、iCloud 或 IMAP 电子邮件附件的 Watch Inbox、模板，以及带撤销的历史记录。登录后赠送 15 个免费额度。托管 AI 仅通过订阅提供：每月 $8 含 500 个额度，或每月 $20 含 2,000 个（按年 $80 或 $200），每条 AI 名称建议消耗 1 个额度；重新处理某个文件会再消耗一个额度。$40 的 Self-Managed 许可证使用你自己的密钥或本地模型（Ollama、LM Studio、vLLM），绑定 1 台设备，含一年更新，退款期为 3 天。

**适合选择 FilesDesk 的情况**：你希望电子邮件附件一到就被重命名。**不足**：其一次性许可证不含托管 AI。请看 [Zush 与 FilesDesk 对比](/blog/zush-vs-filesdesk)。

### 3. RenameClick

RenameClick（官网现为 rename.click）支持 Mac 和 Windows。4.1.2 版新增了 MP4、MOV、M4V 和 3GP 视频支持，使用画面和本地语音转写；不支持 MKV、WebM 和 AVI，也不支持相机 RAW 或设计文件。免费版每月允许 100 次重命名或移动，分析次数不限。终身许可证 $36 + 增值税，直接下载版本最多 3 台设备，不含服务商费用。

**适合选择 RenameClick 的情况**：你想要一个无需配置 Ollama 的自带本地模型。**不足**：该模型下载约 4 GB，建议 16 GB 内存，撤销只在内存中保存 10 条记录，重启后清空。请看 [Zush 与 RenameClick 对比](/blog/zush-vs-renameclick)。

### 4. AI Renamer

AI Renamer（airenamer.app）是一款支持 Mac、Windows 和现在也支持 Linux 的桌面应用。1.9 版新增了 Watch Folder（测试版），只在应用打开时运行，并跳过子文件夹；1.10 版新增了视频、音频、RAW、HEIC、Office 和 EPUB 支持。Local Mode 一次性 $19，使用你自己的密钥或 Ollama/LM Studio；云端额度每 200 个 $10，Google 登录后赠送 10 个。未说明退款政策，额度购买一经完成不可退。GitHub 上免费的 GPL-3.0 `ozgrozer/ai-renamer` 命令行工具是一个毫不相关的项目。

**适合选择 AI Renamer 的情况**：你需要 Linux，或者想以最低的一次性价格使用本地 AI。**不足**：它没有记载撤销功能。请看 [Zush 与 AI Renamer 对比](/blog/zush-vs-airenamer)。

### 5. Renamer.ai

Renamer.ai 提供 Windows 和 Mac 应用以及网页界面，包含 Magic Folders、模板、预览和撤销。所有档位都提供本地模式，包括免费的 Starter 方案（每月 25 个文件）。付费云端方案为 Pro 每月 $9.95（200 个文件）、Power $29.95（1,000 个）和 Ultimate $99.95（5,000 个），按年付费便宜 15%。BYOK 仅限 Ultimate。它的 Softpedia 编辑评分为 4.5/5。

**适合选择 Renamer.ai 的情况**：你想要文档模板和免费的本地处理。**不足**：没有一次性许可证，所以托管 AI 按月计量。请看 [Zush 与 Renamer.ai 对比](/blog/zush-vs-renamer-ai)。

### 6. NameQuick

NameQuick（3.0.57 版，现已上架 Mac App Store）支持 Mac 和 Windows，提供 Watch Folders、Rules、Quick Organize 和撤销。它提供 30 次免费 Managed 重命名，无需电子邮件或银行卡；14 天 Managed 试用（70 次重命名）需要绑定银行卡。Managed 方案每月 $12 起，重命名包为 $19 购 500 次或 $39 购 1,500 次，12 个月内有效。Self-Managed 一台电脑 $69 一次性买断，含终身更新和 14 天退款；AI 费用另计。

**适合选择 NameQuick 的情况**：你想在 AI 命名之上再加一个规则引擎。**不足**：一次性许可证限一台电脑，且不含托管 AI。请看 [Zush 与 NameQuick 对比](/blog/zush-vs-namequick)。

### 7. RenamerX

RenamerX 是一款本地优先的 Mac 和 Windows 重命名工具。其内置模型（Qwen3.5 4B）下载约 3.4 GB，可在 Apple Silicon 或配有兼容 GPU 的 Windows x64 PC 上运行。它也能连接 Ollama、LM Studio、任何兼容 OpenAI 的端点，或用你自己的密钥连接 OpenAI 和 Gemini。其官网列出了文档、包括相机 RAW 在内的图片、包括 MKV 在内的视频，以及 Watch Folders 和撤销。免费版每月 50 个额度；Pro 终身版 $36，额度不限。其主页未说明设备数量、退款条款和更新政策。

**适合选择 RenamerX 的情况**：你想要自带本地模型并支持 RAW 和 MKV。**不足**：没有托管云端，也没有列出音频文件。

### 8. Wisfile

Wisfile 免费，在 Mac 和 Windows 上 100% 本地运行，专注于 PDF 和 Word 文件。它没有撤销功能。

**适合选择 Wisfile 的情况**：你偶尔重命名文档，不想花钱，也不想用云端。**不足**：没有撤销，意味着一批出错后只能手动修复。

### 9. Renamed.to

Renamed.to 是一项提供 API 和 CLI 的云服务。它先提供 50 次免费重命名，之后出售额度：$9 购 1,000 个或 $49 购 10,000 个，有效期 12 个月。

**适合选择 Renamed.to 的情况**：你的文档存放在云存储中，或者你需要 API。**不足**：仅限云端，没有本地处理的路线。

### 10. File Renamer AI

File Renamer AI 是一款浏览器工具：上传文件、审阅名称、下载 ZIP。额度为 $10 购 1,000 个或 $100 购 10,000 个，永不过期。其主页现在提到了 PDF、Office、视频和音频，而价格页面仍然只描述图片。

**适合选择 File Renamer AI 的情况**：你无法安装软件。**不足**：没有桌面应用，没有文件夹监控，下载 ZIP 后也无法撤销。

### 另外：Riffo

## 常见问题

### 什么是 AI 文件重命名工具？

AI 文件重命名工具是一种会读取每个文件的内容、并为它建议描述性名称的应用。规则工具可以对一批文件添加日期或替换文本，但当发票和合同都叫 `scan_004.pdf` 时，它分辨不出哪个是哪个。AI 重命名工具会读取文字、图片、音频或视频，为每个文件取专属名称，而且你应当能在任何改动之前审阅这些名称。

### 2026 年最好的 AI 文件重命名工具是哪款？

在 Mac 和 Windows 上，我们推荐 Zush。它首次启动就能使用，提供 50 次免费 AI 重命名，无需账号、银行卡或 API 密钥。它的 $48 一次性许可证包含托管云端 AI、BYOK、Ollama 和 LM Studio，最多可用于 3 台设备，每一批都会先预览，并保存在支持批量撤销的 Rename History 中。AI Renamer 是 Linux 选项，Wisfile 在 Mac 和 Windows 上免费且本地运行；Renamed.to 适合云存储和 API 工作流。

### $48 的一次性许可证比 $19 或 $36 的更值吗？

取决于你希望 AI 运行在哪里。$19 的 AI Renamer、$36 的 RenameClick 和 $36 的 RenamerX 许可证涵盖的是应用本身，AI 则是你自己的 API 密钥或必须由你的电脑运行的本地模型。Zush 的 $48 包含托管的 Zush Cloud AI 和无限次重命名，以及 BYOK 和本地模型、今后所有更新、3 台 Mac 和 Windows 设备，以及 14 天退款。

### 我的文件在哪里处理？

取决于模式。使用 Zush Cloud AI 或 BYOK 时，文件内容会发送到 AI 服务来生成名称。使用 Ollama 或 LM Studio 时，分析在你自己的电脑上进行。RenameClick 和 RenamerX 默认使用自带的本地模型；Renamer.ai 所有档位都提供本地模式；Wisfile 仅限本地；Renamed.to 和 File Renamer AI 是云服务。数据保留条款请查看各厂商的隐私页面。

### 哪些 AI 文件重命名工具支持 Linux？

在本文对比的工具中，AI Renamer 现在发布了 Linux 版本。截至 2026 年 11 月 17 日核查，Zush、FilesDesk、RenameClick、NameQuick、RenamerX 和 Wisfile 都有 Mac 和 Windows 应用，但没有 Linux 版；Wisfile 将 Linux 列为即将推出。Renamed.to 和 File Renamer AI 等浏览器和 API 工具可在任何操作系统上使用，但你的文件会进入它们的云服务。

### 能撤销 AI 重命名吗？

在 Zush 中可以：Rename History 会持久保存，所以几天后也能撤销整批操作，Undo All 会在恢复前列出所有冲突。FilesDesk 和 NameQuick 也保留带撤销的历史记录。RenameClick 在内存中保存 10 条撤销记录，重启后清空。AI Renamer 没有记载撤销功能，Wisfile 则完全没有，所以请先在副本上测试它们。
