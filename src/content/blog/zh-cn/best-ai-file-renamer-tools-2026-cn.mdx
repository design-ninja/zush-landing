## 命名控制、恢复和AI模式

对于 Mac 和 Windows 上的混合文件夹，我们推荐 Zush：选择模板，检查建议文件名，再应用所选更改。需要时可通过 Rename History 恢复原名。本地分析可连接 LM Studio 或 Ollama；BYOK 使用你自己的云服务商。Zush 在原位置重命名文件，不提供跨文件夹自动分类或云存储 API。

### 2. FilesDesk

包含“FilesDesk”是因为它的目标是类似的 Mac +“Windows”工作流程，具有托管 AI、“BYOK”/本地模式、监视文件夹、模板、批处理和处理历史记录。它的主要限制是结构性的：托管建议是计量的，而生命周期路径需要您自己的 API 密钥或本地模型。有关直接权衡，请参阅“[“Zush”与“FilesDesk”](/blog/zush-vs-filesdesk)”。

### 3. RenameClick

内存中最多保留 10 条 Undo 记录，重启后清除. [RenameClick](https://rename.click/docs/getting-started/how-it-works)

“RenameClick”包含在其 AI 搜索和重命名加文件夹路由工作流程中。它为“macOS”和“Windows”提供桌面应用程序，内置本地人工智能、“Ollama”、LM Studio、可选云提供商和 Auto Flow。本地处理不被视为优势，因为这里的几种产品（包括“Zush”）支持它。它的主要限制是覆盖范围较窄：没有记录的相机 RAW、设计或视频支持。

### 4. AI Renamer

两个独立的项目共享这个名称，将它们混为一谈夸大了付费产品提供的功能。 **airenamer.app 上的“AI Renamer”是一款商业 Mac 和“Windows”桌面应用程序，其定价页面列出了三件事：本地模式一次性 19 美元，云模式每 200 个积分 10 美元，以及注册时免费获得 10 个积分。它没有宣传 CLI，也没有开源版本。 **`ozgrozer/ai-renamer`** 是 GitHub 上一个不相关的免费 G​​PL-3.0 Node.js CLI，它在 Ollama、LM Studio 或 OpenAI 密钥上运行，并处理图像和视频（通过 ffmpeg）。当您看到“AI Renamer 是免费且开源的”时，这是 GitHub 项目，而不是 19 美元的应用程序。

### 5. Renamer.ai

Renamer.ai 的 Windows 页面描述本地处理，但隐私政策称文件内容会传给 AI 分处理商。我们没有独立验证其网络行为。这些资料不足以确认离线工作流程。 [Windows](https://renamer.ai/ai-file-renamer-windows) · [Renamer.ai](https://renamer.ai/privacy-policy/)

### 6. NameQuick

“NameQuick”现在发布“Windows”和 Mac 下载。其记录的 Mac 工作流程涵盖“Finder”集成、监视文件夹、规则、撤消、OCR 和 30 多种格式类别。供应商没有发布完整的平台矩阵，因此此比较并不假设“Windows”上存在每个 Mac 特定功能。

### 7. 无线文件

Wisfile 是一个完全本地的 AI 文件重命名器和组织器。该网站表示，它完全在用户的设备上运行，不依赖于云，不收费，也没有数据离开机器。

### 8. Riffo

“Riffo”是一款 Mac 应用程序和 Web 演示，用于 AI 支持的文件重命名和文件夹组织。其公共主页将该产品定位为免费，并显示批量文件重命名以及将文件分类到文件夹中。除此之外，几乎没有什么需要验证的——没有定价页面，没有格式列表，没有撤消语句，并且检查的页面上没有文件夹监视语句。

### 9. 重命名为

公开文档中的差异不是独立质量测试的结果。没有文档说明不等于功能不存在。 [Renamed.to](https://www.renamed.to/faq)
