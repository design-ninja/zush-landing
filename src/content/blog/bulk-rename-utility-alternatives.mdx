## What Bulk Rename Utility does well

BRU has been the default answer for Windows batch renaming for two decades, and version 4.1.0.1 is still strong at rule-based work:

- **Pattern renaming at scale.** Prefixes, suffixes, numbering, find-and-replace, case changes and character removal, all previewed before you commit.
- **Regular expressions and JavaScript.** An AI-powered JavaScript and Regex Assistant helps you write complex rules. JavaScript renaming itself needs a paid home or academic license ($24.95).
- **Free for home use.** Personal use at home costs nothing. Business use needs a commercial license, $92.95 per computer.
- **Everything on one screen.** The dense panel layout is fast once you learn it.

Softpedia's editors rate it 4.0/5. If your batch looks like `IMG_001.jpg → Croatia-2026-001.jpg`, one rule for many files, BRU may be all you need on Windows.

## Where it stops helping

Pattern tools share one blind spot: **they can only work with what is already in the filename or metadata.** BRU's AI assistant writes rules for you, but it does not look inside your files. These jobs stay manual:

- A Downloads folder of `document (1).pdf`, `scan_0042.pdf`, `Screenshot 2026-06-12.png`. No pattern exists, because each file needs its own name.
- Invoices and receipts that should be named by vendor, date and amount from inside the PDF.
- Screenshots that should say what is on screen, not when they were taken.

The other hard limit: **there is no Mac version**.

## Bulk Rename Utility on Mac: your actual options

1. **Finder's built-in renamer** (free, already installed). Select files, right-click, Rename: replace text, add text, or apply a name-and-index format. Our [batch rename on Mac guide](/blog/batch-rename-files-on-mac-complete-guide) walks through it alongside Automator and Terminal.
2. **Pattern utilities for Mac.** A Better Finder Rename ($29.95) or NameChanger cover the regex-and-sequences niche BRU fills on Windows. Advanced Renamer now runs on both platforms; see [Advanced Renamer alternatives](/blog/advanced-renamer-alternatives).
3. **An AI renamer.** When the folder is mixed and every file needs a different name, patterns don't help on any platform. That is the job [Zush](/mac) was built for, on Mac and Windows.

### From batch names to content-based folders

Zush can also **sort files into folders with AI**. Use **Auto** or write **Folder rules**, for example “Group receipts by month and invoices by supplier.” The grouping comes from file content; Naming Blocks define the filename separately.

Choose a **Destination folder**, or keep the source folder as the root. Enable **Reuse existing folders** to prefer suitable folders already there. Review both the suggested names and folders before applying. To rename in place, leave sorting off.

Save the settings in a **Template** and assign it to **Monitor** for new files in the watched folder. Changing the Monitor Template does not reorganize files already processed. See the [folder sorting guide](/docs/folder-sorting).

## FAQ

### What is the best Bulk Rename Utility alternative?

Our [AI batch rename tool](/batch-rename-files) is the best fit when files need names based on their content: it works on Mac and Windows, includes 50 free renames, previews every batch and keeps full undo. For pure pattern work, PowerRename is the free Windows alternative, and A Better Finder Rename or Finder cover Macs. We make Zush, so test it on copies.

### Is Bulk Rename Utility free?

For personal, private use at home, yes. JavaScript renaming needs a paid home or academic license ($24.95), and business or commercial use needs a commercial license at $92.95 per computer. Zush, by comparison, gives 50 free AI renames and costs $48 one-time for up to 3 devices, with the managed Zush Cloud AI included.

### Is Bulk Rename Utility available for Mac?

No. BRU is Windows-only. On a Mac, use Finder's built-in renamer for simple patterns, A Better Finder Rename or NameChanger for regex and sequences, Advanced Renamer if you want one rule tool on both platforms, or Zush when every file needs a descriptive name based on what it contains.

### Can Bulk Rename Utility rename files based on their content?

No. It works from filenames and file metadata such as dates and EXIF tags. Its AI assistant helps you write JavaScript or regex rules, but it does not read what a document, screenshot or photo contains. Content-aware naming is what AI renamers do; see [how Zush renames files by content](/blog/rename-files-by-content-guide).

### Does an AI renamer send my files to the cloud?

It depends on the mode. Zush with Ollama or LM Studio keeps analysis on your computer. With Zush Cloud AI or your own API key, file content is sent to that model to generate a name. Bulk Rename Utility, PowerRename and Finder rename entirely locally, because they only apply rules and never analyze content.

### Can I undo a batch if the new names are wrong?

In Zush, yes, even later. Every applied batch goes into a persistent Rename History, so you can undo a whole batch after closing the app or restarting, and Undo All lists any conflicts and offers to restore under a new name. Bulk Rename Utility also has undo, as the table above shows. Whatever tool you pick, run the first batch on copies of a real folder before touching the originals.
