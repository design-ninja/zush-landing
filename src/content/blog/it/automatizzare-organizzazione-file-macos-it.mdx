## Di quali file dovrebbe occuparsi per primi un organizzatore automatico

Comincia dai file che arrivano spesso e che ti danno più fastidio. Il primo giorno non serve costruire un grande sistema unico. Basta togliere di mezzo uno o due problemi ricorrenti, vedere i risultati e allargare da lì.

I candidati migliori per l'automazione:

- **Screenshot** - macOS li chiama `Screenshot 2026-03-12 at 10.44.11.png`, un nome che non dice nulla del contenuto
- **Cartella Download** - download del browser, allegati email e file AirDrop si accumulano in fretta con nomi generici
- **Esportazioni ricorrenti** - fatture, estratti conto, report che escono ogni settimana dalle stesse app
- **Foto in arrivo dalla fotocamera** - tra sei mesi `IMG_4382.HEIC` non ti servirà a niente
- **Mucchi di documenti ripetitivi** - consegne per i clienti, PDF di ricerca, materiali di progetto

L'automazione rende di più quando elimina una seccatura settimanale, non quando crea un sistema complicato che poi nessuno mantiene.

### Come trovare le cartelle messe peggio

Apri il Finder e ordina la cartella Download o la Scrivania per data di modifica. Guarda gli ultimi 50 file e conta quanti hanno un nome che ti dice cosa contengono. Se sono meno della metà, quella cartella è un'ottima candidata all'automazione.

Puoi anche controllare quanti file finiscono in una cartella. Apri il Terminale ed esegui:

```bash
ls -1 ~/Downloads | wc -l
```

Se il numero supera 200, hai un arretrato che vale la pena automatizzare.

## Ordinare file misti in cartelle con l'IA

L'[ordinatore di file con IA di Zush](/ai-file-sorter) può dare nomi descrittivi ai file supportati e raggrupparli in cartelle vere in base al contenuto, nello stesso lotto. **L'ordinamento in cartelle con l'IA funziona su Mac e Windows.** Lascia vuoto **Folder rules** per il raggruppamento Auto, oppure descrivi i gruppi in linguaggio naturale. Per file misti, prova con:

> Raggruppa le fatture per azienda e le ricevute per mese.

1. Aggiungi in **AI Rename** un piccolo lotto di file copiati e scegli un Template.
2. Attiva **+ Sort** e scegli la **Destination folder**, cioè la cartella principale che conterrà le sottocartelle ordinate. Se non indichi una destinazione separata, la cartella principale resta quella di origine.
3. Scrivi l'istruzione di raggruppamento in **Folder rules**. Il formato del nome dei file si imposta a parte con i **Naming Blocks**.
4. Attiva **Reuse existing folders** se nella cartella di destinazione ci sono già gruppi adatti. Se nessuno va bene, Zush può creare una cartella nuova.
5. Controlla sia i nomi proposti sia i gruppi di cartelle. Correggi i nomi delle cartelle o la posizione dei file prima di applicare il lotto.

![Zush per Mac che mostra in anteprima i gruppi di cartelle basati sul contenuto e i nomi proposti prima di Rename & sort](/images/showcase/macos/folder-sorting-light.webp)

Salva nel Template la destinazione e le regole che hai provato. Assegnalo a **Monitor** per rinominare e ordinare i nuovi file che arrivano direttamente nella cartella monitorata. I file già elaborati non vengono riorganizzati a posteriori. Con l'ordinamento disattivato e la destinazione originale selezionata, i file restano nella cartella in cui si trovano.

Segui la [guida passo passo all'ordinamento su Mac](/blog/sort-files-into-folders-with-ai-mac) oppure consulta la [documentazione sull'ordinamento in cartelle](/docs/folder-sorting) e [30 esempi di Folder rules](/blog/ai-folder-sorting-prompts).

## Smart Folders: configurazione passo passo

Le Smart Folders non spostano i file. Li mostrano in modo dinamico in base a criteri di ricerca: sono in pratica ricerche Spotlight salvate che compaiono nella barra laterale del Finder.

Servono a trovare file sparsi in posti diversi senza cambiare la struttura delle cartelle.

### Come creare una Smart Folder

1. Apri il Finder
2. Premi **Cmd + F** oppure scegli **File > Nuova cartella smart**
3. Fai clic sul pulsante **+** in alto a destra per aggiungere criteri
4. Imposta le condizioni (trovi degli esempi qui sotto)
5. Fai clic su **Salva** e dai un nome alla Smart Folder
6. Seleziona **Aggiungi alla barra laterale** per averla sempre a portata di mano
7. Scegli dove salvare il file `.savedSearch` (la posizione predefinita va bene)

### I criteri più utili per le Smart Folders

| A cosa serve la Smart Folder | Criteri da impostare |
|---|---|
| Screenshot recenti | Tipo = Immagine, Nome contiene "Screenshot", Data ultima modifica = ultimi 7 giorni |
| File grandi che occupano il disco | Dimensione > 500 MB |
| PDF recenti | Tipo = PDF, Data ultima modifica = ultimi 30 giorni |
| Documenti da rivedere | Tag = "Da rivedere", Tipo = Documento |
| Tutte le presentazioni | Tipo = Presentazione |
| Download recenti | Cartella = Download, Data ultima modifica = ultimi 3 giorni |

### Suggerimenti avanzati per le Smart Folders

- Tieni premuto **Opzione** mentre fai clic sul pulsante **+** per aggiungere criteri composti (gruppi AND/OR)
- Puoi filtrare per estensione, data di creazione, data dell'ultima apertura e decine di altri campi di metadati
- Le Smart Folders si aggiornano in tempo reale, quindi mostrano sempre lo stato attuale del disco
- Funzionano su tutti i volumi montati, dischi esterni compresi

Le Smart Folders non sono una vera automazione, perché non spostano né rinominano nulla. Sono però un ottimo primo passo: ti fanno vedere cosa va sistemato prima di fissare delle regole.

Per approfondire, leggi la nostra [guida agli strumenti di ricerca file di macOS](/blog/finder-tags-guide-organize-files-mac).

## Automator e Shortcuts: flussi di lavoro veri e propri

Automator (e il suo successore più recente, Shortcuts) ti permette di creare veri flussi di elaborazione dei file. Può rinominare, spostare, copiare, ridimensionare e convertire file con un'interfaccia a trascinamento.

### Azione cartella di Automator: smistare i download per tipo di file

È uno dei flussi di Automator più pratici. Tiene d'occhio la cartella Download e sposta i file in sottocartelle in base all'estensione.

**Configurazione passo passo:**

1. Apri **Automator** (cercalo con Spotlight)
2. Scegli **Azione cartella** come tipo di documento
3. In alto, imposta la cartella **Download** come cartella da cui l'azione riceve i file e le cartelle aggiunti
4. Aggiungi l'azione **Esegui script shell**
5. Imposta "Passa input" su **come argomenti**
6. Incolla questo script:

```bash
for f in "$@"; do
    ext="${f##*.}"
    ext=$(echo "$ext" | tr '[:upper:]' '[:lower:]')
    case "$ext" in
        pdf)
            dest="$HOME/Documents/PDFs" ;;
        jpg|jpeg|png|heic|webp|gif)
            dest="$HOME/Pictures/Downloads" ;;
        zip|gz|tar|dmg)
            dest="$HOME/Downloads/Archives" ;;
        doc|docx|xlsx|pptx|csv)
            dest="$HOME/Documents/Office" ;;
        *)
            dest="" ;;
    esac
    if [ -n "$dest" ]; then
        mkdir -p "$dest"
        mv "$f" "$dest/"
    fi
done
```

7. Salva il flusso con un nome descrittivo, per esempio "Smista Download per tipo"
8. L'azione cartella ora è attiva: i nuovi file in Download verranno smistati in automatico.

### Shortcuts: un'alternativa più semplice da macOS Ventura in poi

Con macOS Ventura o versioni successive, Shortcuts può sostituire Automator in molti casi. Il vantaggio è un'interfaccia più pulita e un'integrazione più stretta con le attivazioni di sistema.

**Esempio: rinominare e spostare gli screenshot**

1. Apri **Shortcuts**
2. Crea un nuovo comando
3. Aggiungi l'azione **Ottieni contenuto della cartella** (impostata sulla cartella degli screenshot)
4. Aggiungi l'azione **Filtra file** con la condizione Nome contiene "Screenshot"
5. Aggiungi l'azione **Rinomina file** con uno schema come `Screenshot-[Date Created]`
6. Aggiungi l'azione **Sposta file** verso la cartella di destinazione che preferisci
7. Per farlo partire da solo, vai nella scheda **Automazione** e crea un'attivazione per quando vengono aggiunti file alla cartella degli screenshot

Shortcuts è più adatto alle automazioni singole, Automator ai flussi complessi in più passaggi che richiedono script shell. Per una guida completa alla rinomina dei file con Automator, leggi la nostra [guida per rinominare file con Automator](/blog/macos-automator-rename-files-guide).


## Hazel per script e archiviazione

Hazel è utile quando una cartella ha bisogno di regole continue con più condizioni e di azioni che Zush non ha, come archiviare, eseguire script o caricare file online. Una regola che si limita a spostare le fatture PDF in cartelle per anno e mese non ne ha più bisogno: Zush lo fa con una Folder rule come "Metti le fatture in cartelle per anno e mese", e riconosce una fattura anche quando il file si chiama `scan0043.pdf`.

Hazel funziona quando estensione, data, tag, uno schema nel nome del file o il testo estratto forniscono una condizione affidabile. Zush può usare gli stessi dati, con i Naming Blocks di data ed estensione e i filtri di Monitor per tipo di file o prefisso del nome, e in più capisce cosa c'è in uno screenshot, una foto, un video o una scansione generica prima di dargli un nome o archiviarlo.

Se li usi entrambi, assegna a ciascuno una cartella diversa. Non lasciare che due strumenti monitorino e modifichino nello stesso momento la stessa cartella di arrivo. Per un confronto funzione per funzione, leggi [Zush come alternativa a Hazel](/hazel-alternative).

## Dove l'automazione a regole non basta

Le regole funzionano quando il file dice già cos'è attraverso il nome, l'estensione o i metadati.

Non funzionano quando il file arriva così:

- `IMG_4382.HEIC`
- `Screenshot 2026-03-12 at 10.44.11.png`
- `download (7).jpg`
- `Document.pdf`
- `Untitled.png`
- `image (3).webp`

Una regola può spostare questi file in una cartella precisa, ma non può dire cosa contengono. E senza un nome descrittivo non li ritroverai più, anche se sono archiviati in cartelle perfette.

È qui che i nomi generati dall'IA diventano utili. Gli strumenti che analizzano il contenuto del file (i pixel di un'immagine, alcuni fotogrammi di un video, il testo di un PDF, l'impaginazione di un documento) possono creare nomi che descrivono davvero cosa c'è nel file.

Per capire come funziona in pratica la rinomina dei file con l'IA, visita il nostro [rinominatore di file per Mac e Windows](/).

## Configurazione consigliata per organizzare i file in automatico, passo passo

Ecco una configurazione pratica che puoi mettere in piedi in meno di un'ora e che unisce gli strumenti visti finora in un unico sistema coerente. È l'approccio con il miglior rapporto tra impegno e risultati.

### Passo 1: valuta il disordine attuale

Apri le cartelle Download, Scrivania e Documenti. Annota quali contengono più file con nomi inutili e scegli le due messe peggio.

### Passo 2: controlla in anteprima i nomi di Zush e gli eventuali gruppi di cartelle

Installa il [rinominatore di file con IA per Mac](/mac), indicagli la copia della cartella di arrivo, scegli un Template e controlla i primi nomi proposti. Assicurati che Rename History sia disponibile prima di attivare il monitoraggio continuo.

### Passo 3: se vuoi, crea delle Smart Folders per la visibilità

Imposta tre Smart Folders nel Finder:

1. **File grandi recenti** -- Dimensione > 100 MB, Data ultima modifica = ultimi 30 giorni
2. **Screenshot da sistemare** -- Tipo = Immagine, Nome contiene "Screenshot", Data ultima modifica = ultimi 14 giorni
3. **Documenti recenti** -- Tipo = Documento OPPURE Tipo = PDF, Data ultima modifica = ultimi 7 giorni

Così vedi subito cosa richiede attenzione.

### Passo 4: se vuoi, imposta uno smistamento di base

Scegli una di queste opzioni in base alle tue preferenze:

**Opzione A: azione cartella di Automator** (gratuita, integrata)
- Crea il flusso di smistamento dei download descritto sopra
- Richiede 10 minuti e gestisce i tipi di file più comuni

**Opzione B: regole di Hazel** (a pagamento, più potente)
- Installa Hazel e imposta 3-5 regole per la cartella Download
- Concentrati su: PDF in Documenti, immagini in Immagini, archivi in una cartella dedicata
- Aggiungi una regola di pulizia per i file più vecchi di 30 giorni

**Opzione C: automazione con Shortcuts** (gratuita, macOS Ventura e successivi)
- Crea un comando che smista i file per tipo
- Fallo partire secondo una pianificazione o a mano

**Opzione D: Folder rules di Zush** (incluse in Zush)
- Attiva Sort in un Template e descrivi le cartelle, per esempio "PDF in Documenti, immagini in Immagini, ricevute per mese"
- Assegna il Template a Monitor, così i nuovi download vengono rinominati e ordinati appena arrivano

### Passo 5: attiva il monitoraggio di Zush dopo la prova

![Scheda Monitor di Zush con la configurazione del monitoraggio e la cartella Scrivania selezionata](/images/showcase/macos/monitor-light.webp)

Dopo aver verificato il lotto di prova, imposta Zush per monitorare la cartella degli screenshot e la cartella Download. Così gestisci i file a cui gli strumenti a regole non sanno dare un nome sensato:

- Gli screenshot vengono rinominati in base all'app e al contenuto visibili
- I PDF vengono rinominati in base al testo che contengono
- Le foto vengono rinominate in base a cosa mostrano
- Le immagini scaricate ricevono nomi descrittivi al posto di `download (7).jpg`

### Passo 6: fissa un controllo settimanale

Anche con l'automazione, dedica 5 minuti alla settimana a dare un'occhiata alle tue Smart Folders. Così intercetti i casi particolari e affini le regole nel tempo.

### Passo 7: allarga un po' alla volta

Dopo una settimana con questa configurazione, guarda cosa continua a sfuggire. Aggiungi nuove regole di Hazel o nuove Smart Folders quando serve. Non cercare di coprire ogni caso particolare fin dall'inizio.

| Elaborare file con un clic | Shortcuts | Interfaccia pulita, facile da condividere |

## Errori comuni da evitare

**Automatizzare troppo e troppo presto.** Non costruire un sistema Hazel da 20 regole prima di sapere quali file hanno davvero bisogno di essere smistati. Parti con 2-3 regole e allarga.

**Trascurare il problema dei nomi.** Spostare i file in cartelle ordinate non serve se ogni file si chiama `IMG_4382.HEIC`. Dovrai comunque aprirli uno a uno per trovare quello che ti serve. Rinominare conta almeno quanto ordinare.

**Non provare le regole.** Prima di attivare un'azione cartella o una regola di Hazel sulla vera cartella Download, provala su una cartella di prova con file di esempio. Una sola regola di spostamento sbagliata può spargere file per tutto il disco.

**Dimenticare le sottocartelle.** Quasi tutti gli strumenti di automazione, di default, controllano un solo livello di cartella. Se i file finiscono in sottocartelle, devi attivare esplicitamente il monitoraggio ricorsivo.

**Non avere un modo per tornare indietro.** Ogni automazione che rinomina o sposta file deve poter essere annullata. Hazel tiene dei log. Zush permette di annullare le modifiche. Automator no, quindi attenzione alle azioni distruttive.

## Domande frequenti

### Come si automatizza l'organizzazione dei file su Mac senza installare nulla?

Usa gli strumenti integrati: le Smart Folders per far emergere i file, e Automator o Shortcuts per smistarli. Le Smart Folders si creano nel Finder da File > Nuova cartella smart. Automator può creare azioni cartella che partono quando arrivano file in una certa cartella. Così copri lo smistamento di base per tipo di file, data e schemi nel nome, senza software di terze parti.

### Che differenza c'è tra Automator e Shortcuts su macOS?

Automator è lo strumento più vecchio, con più tipi di azioni, supporto agli script shell e integrazione con le azioni cartella. Shortcuts è più recente (macOS Monterey e successivi), ha un'interfaccia più pulita e supporta le attivazioni di sistema e Siri. Per l'automazione dei file in particolare, Automator resta più capace grazie alle azioni con script shell e alle maggiori possibilità di gestione dei file. Apple sta spostando a poco a poco le funzioni su Shortcuts, quindi conviene conoscerli entrambi.

### Hazel può rinominare i file in base al contenuto?

Hazel può leggere il testo dentro PDF e documenti e usarlo nelle regole di rinomina. Per esempio, puoi estrarre una data o una parola chiave da un PDF e inserirla nel nome del file. Hazel però non sa analizzare il contenuto di immagini o video, perché non ha capacità di visione. Per screenshot, foto, registrazioni dello schermo e altri file visivi ti serve uno strumento con IA che guardi davvero cosa c'è nel file.

### Come evito che la cartella Download si riempia di confusione?

Imposta un sistema a due livelli. Prima crea regole di smistamento (Folder rules di Zush, Automator o Hazel) che spostano i file in cartelle per tipo appena arrivano. Poi aggiungi una regola di pulizia che sposta i file più vecchi di 30 giorni in una cartella Archivio o nel Cestino. Insieme, le due cose tengono snella la cartella Download senza perdere nulla di importante. Per una procedura dettagliata, leggi la nostra [guida per organizzare la cartella Download](/blog/how-to-organize-downloads-folder-mac).

### La rinomina dei file con l'IA è sicura? Può rovinarmi i file?

La rinomina con l'IA cambia solo il nome del file, non il contenuto. Gli strumenti fatti bene come Zush tengono anche una cronologia delle rinomine, così puoi annullare all'istante qualsiasi cambio di nome. Il rischio è basso, ma conviene sempre provare prima su un piccolo lotto e verificare la qualità dei nomi prima di attivare il monitoraggio su cartelle con molto traffico.

### Come si automatizza l'organizzazione delle foto in particolare?

Le foto sono un caso a parte, perché i nomi originali (`IMG_`, `DSC_`, `DCIM`) non dicono nulla del contenuto. L'approccio migliore è la rinomina con l'IA per dare nomi descrittivi, abbinata all'ordinamento in cartelle per data o per evento. Per un flusso pensato per le foto, leggi la nostra [guida per organizzare le foto su Mac](/blog/best-ways-to-organize-photos-on-mac).

### Posso combinare più strumenti di automazione?

Sì, quando serve davvero un secondo livello. Parti da Zush per i nomi e l'ordinamento in cartelle, poi aggiungi se vuoi le Smart Folders per la visibilità, oppure Hazel o Automator per script e archiviazione. Tieni poche regole aggiuntive, così il sistema resta facile da gestire.

### Cosa succede se due regole di automazione vanno in conflitto?

Se Hazel e un'azione cartella di Automator controllano la stessa cartella, possono intralciarsi a vicenda. Il risultato è imprevedibile: un file potrebbe essere spostato prima che l'altro strumento lo elabori. La soluzione è semplice: un solo strumento di automazione per cartella. Zush può rinominare e ordinare in un solo passaggio, quindi spesso basta un unico strumento. Se Hazel ha ancora un compito, come l'archiviazione, lascia che Zush finisca prima e fai controllare a Hazel la cartella di destinazione.

## Conclusione

Per automatizzare bene l'organizzazione dei file su macOS, lascia le decisioni semplici a regole semplici e affida all'IA i file visivi ambigui. Con questo equilibrio ottieni un sistema che riesci davvero a mantenere.

Parti da Zush per i nomi basati sul contenuto, l'ordinamento facoltativo in cartelle con l'IA e la possibilità di annullare. Salva in un Template per Monitor una configurazione di ordinamento già provata. Usa le Smart Folders per le viste salvate, e Automator o Hazel per script e archiviazione. Fai un controllo ogni settimana e allarga un po' alla volta.

Non serve un sistema perfetto. Serve un sistema che ti faccia passare cinque minuti a settimana a organizzare i file invece di trenta.
