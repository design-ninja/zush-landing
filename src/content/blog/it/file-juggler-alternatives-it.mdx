## Cosa fa bene File Juggler

File Juggler è uno strumento di automazione per Windows creato da uno sviluppatore indipendente in Danimarca. Le regole si compongono di tre parti:

1. **Cartelle monitorate**, come Download, Desktop o la cartella dello scanner.
2. **Condizioni**: nome e percorso del file, testo contenuto nel file, dimensione, data di creazione o di modifica.
3. **Azioni**: spostare, copiare, rinominare, cambiare estensione, eliminare o mandare nel Cestino, estrarre archivi, aggiungere a uno zip, eseguire un comando o caricare su Evernote.

Reagisce quasi all'istante perché si iscrive alle notifiche di modifica delle cartelle invece di scansionarle a intervalli. Sa leggere il testo di PDF, Word ed Excel e riutilizzare parole e date trovate lì dentro nel nuovo nome del file. La versione 3.1.9 è uscita il 30 ottobre 2026, quindi non è un progetto abbandonato. La redazione di Softpedia gli dà 4,5/5, lo stesso voto che assegna a Zush.

Il prezzo è semplice: $50 una tantum, tasse escluse al checkout, con tutti gli aggiornamenti futuri compresi. Una licenza copre una persona su più PC, oppure un PC condiviso da più persone. La prova di 30 giorni include ogni funzione; alla scadenza l'app ricorda di acquistarla ma continua a funzionare.

## Perché si cerca un'alternativa

- **Niente IA.** Ogni regola va scritta a mano. Nessuna regola può intercettare `Screenshot 2026-10-02 141203.png` o `IMG_4382.jpg`, perché né il nome né il testo dicono che cosa sia il file.
- **Niente OCR.** Le FAQ di File Juggler spiegano che le scansioni composte solo da immagini non hanno testo ricercabile, quindi serve un programma OCR a parte prima che le regole sul contenuto possano riconoscerle.
- **Solo Windows.** Non esiste una versione per Mac. Su Mac l'equivalente è [Hazel](/hazel-alternative).
- **Non è un servizio.** Funziona finché un utente ha effettuato l'accesso, quindi non è adatto ai server.
- **Il prezzo**, se ti basta ordinare i file per tipo. Diversi strumenti gratuiti lo fanno.

## 1. Zush: per i file che le regole non sanno descrivere

[Zush per Windows](/windows) funziona su Windows 10 e 11 ed è disponibile sul [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X). Invece di verificare condizioni, legge il file: il testo di un PDF o di una scansione, il contenuto di una foto o di uno screenshot, i fotogrammi, il parlato e i sottotitoli di un video (MKV compresi). Poi propone un nome come `2026-09-12_acme_invoice_1042.pdf` o `stripe-revenue-dashboard-september.png`.

![Zush per Windows che rinomina un lotto misto in base al contenuto, mostrando ogni nome proposto prima di applicarlo](/videos/windows/zush-batch-rename.mp4)

Dove File Juggler richiede una regola per ogni destinazione, Zush accetta una sola frase in **Folder rules**, ad esempio "Raggruppa le fatture per azienda e le ricevute per mese", oppure raggruppa i file per contenuto in modalità Auto. Nomi e cartelle proposti si controllano insieme prima che qualcosa venga spostato. Verifica i file ambigui prima di applicare.

![Zush per Windows che mostra in anteprima i gruppi di cartelle basati sul contenuto e i nomi proposti prima di Rename & sort](/images/showcase/windows/folder-sorting-light.webp)

Per la parte sempre attiva di File Juggler, salva la configurazione in un Template e assegnalo a **Monitor**. I nuovi file in Download o nella cartella dello scanner vengono così rinominati e ordinati appena arrivano. Rename History conserva i nomi vecchi e nuovi anche dopo un riavvio, e Undo All annulla un intero lotto elencando gli eventuali conflitti. AI Rename riconosce anche i download duplicati e li sposta nel Cestino; le copie non consumano crediti e Undo le ripristina.

Funziona subito: le prime 50 rinomine con l'IA girano sulla Zush Cloud AI gestita, senza account, carta, chiave API o download di modelli. Per i file che devono restare sul PC passa a Ollama o LM Studio, oppure usa la tua chiave API.

![Scheda Monitor di Zush per Windows che sorveglia le cartelle Screenshot e Download e rinomina i nuovi file all'arrivo](/images/showcase/windows/monitor-light.webp)

Scegli Zush quando la lista di regole continua a crescere e lascia comunque fuori dei file. Guide passo per passo: [ordinare i file in cartelle con l'IA su Windows](/blog/sort-files-into-folders-with-ai-windows) e [30 regole per cartelle pronte all'uso](/blog/ai-folder-sorting-prompts).

Come per File Juggler, la licenza una tantum comprende tutti gli aggiornamenti futuri, e in più include la Zush Cloud AI gestita oltre a BYOK, Ollama e LM Studio, rinomine illimitate, fino a 3 dispositivi tra Windows e Mac e un rimborso entro 14 giorni. ## 2. DropIt: il motore di regole gratuito

DropIt è gratuito e open source. Le regole riconoscono i file per nome, dimensione, data, proprietà o espressioni regolari, e 21 azioni coprono spostamento, copia, rinomina, compressione, estrazione e altro. Puoi trascinare i file su un bersaglio fluttuante oppure fargli scansionare le cartelle monitorate a intervalli.

Punto debole: l'ultima versione, la 8.5.1, risale a febbraio 2018. Funziona ancora, ma non aspettarti nuove funzioni né IA.

Scegli DropIt quando ti basta "i PDF vanno qui, le immagini là" e pagare non è un'opzione.

## 3. Sortio: piani con l'IA e regole sotto

Sortio unisce i due approcci. Puoi scrivere regole classiche oppure descrivere l'organizzazione in linguaggio naturale, controllare un piano e poi lasciargli rinominare, creare cartelle e spostare i file. Le Smart Folders continuano ad applicare il piano ai nuovi arrivi. Funziona su Windows, macOS e Linux.

Il piano gratuito include l'ordinamento a regole con un massimo di cinque regole e tre Spaces, anteprima, cronologia, annullamento e una prova unica dell'IA. Cartelle monitorate e automazioni richiedono Pro, a $14,99 al mese o $99 all'anno con una quota mensile di IA. Ollama mantiene l'elaborazione in locale, e l'accesso avviene con un account email.

Scegli Sortio se vuoi regole in stile File Juggler e IA nella stessa app, o se ti serve Linux. Punto debole: la parte sempre attiva è riservata a Pro. Confronto dettagliato: [Zush vs Sortio](/blog/zush-vs-sortio).

## 4. Wisfile: pulizia gratuita dei documenti con l'IA

Wisfile è gratuito, funziona in locale su Mac e Windows e rinomina i documenti in base al contenuto con modelli come `Author-Year-Title`. Può anche raggruppare un lotto in cartelle per argomento. Le sue FAQ indicano Word e PDF come formati supportati.

Non c'è monitoraggio delle cartelle né pianificazione: trascini i file e lo avvii ogni volta. Le FAQ precisano anche che non esiste un annullamento integrato, quindi prova prima su delle copie.

Scegli Wisfile per una pulizia una tantum di un archivio cartaceo o di documenti. Per un'analisi più da vicino leggi [Zush vs Wisfile](/blog/zush-vs-wisfile).

## 5. PowerShell e Utilità di pianificazione: la strada fai da te

Windows sa svolgere i compiti di base di File Juggler senza software aggiuntivo. PowerShell sposta e rinomina i file; l'Utilità di pianificazione esegue lo script all'accesso o a intervalli di pochi minuti:

```powershell
Get-ChildItem "$env:USERPROFILE\Downloads" -Filter *.pdf |
  Move-Item -Destination "$env:USERPROFILE\Documents\PDFs"
```

È gratuito e flessibile quanto i tuoi script. Però nomi duplicati, file bloccati, log e annullamento sono a carico tuo. Altre opzioni: [come organizzare la cartella Download su Windows](/blog/organize-downloads-folder-windows).

## Tenere File Juggler o cambiare?

- I tuoi file seguono schemi fissi (stessa banca, stesso layout, stesso prefisso nel nome): **tieni File Juggler**.
- Screenshot, scansioni, foto dal telefono e download casuali con nomi senza senso: **Zush**.
- Ordinamento gratuito per estensione o nome: **DropIt** o **PowerShell**.
- Regole e IA in un unico strumento, oppure Linux: **Sortio**.
- Un passaggio gratuito e una tantum su PDF e file Word: **Wisfile**.

Puoi anche usarli entrambi. Zush monitora Download e scrive nomi prevedibili come `2026-10-02_acme_invoice.pdf`, e File Juggler sposta `*_invoice.pdf` in una cartella Finanze fissa. Ogni strumento fa la parte in cui riesce meglio. Prova qualsiasi configurazione prima su delle copie; la nostra checklist su [come rinominare file in blocco in sicurezza](/blog/how-to-safely-batch-rename-files) elenca cosa controllare.

Per un confronto più ampio tra strumenti con IA, leggi [i migliori organizzatori di file con IA per Windows 11](/blog/best-ai-file-organizers-windows). Arrivi da un Mac? Leggi [le alternative a Hazel per Windows](/blog/hazel-for-windows-alternatives).

## Domande frequenti

### Esiste un'alternativa gratuita a File Juggler?

Sì. DropIt è gratuito e open source, ma l'ultima versione risale a febbraio 2018. Il piano gratuito di Sortio include fino a cinque regole, anche se le cartelle monitorate richiedono Pro. PowerShell con l'Utilità di pianificazione è gratuito se sai scrivere script. Wisfile è gratuito per i file PDF e Word. Zush include 50 rinomine gratuite con l'IA, senza account né carta, se il tuo problema sono i nomi dei file poco chiari.

### File Juggler è ancora mantenuto?

Sì. La versione 3.1.9 è uscita il 30 ottobre 2026, secondo la pagina delle novità di File Juggler, e la licenza include tutti gli aggiornamenti futuri. È quindi uno dei pochi organizzatori a regole per Windows che riceve ancora aggiornamenti regolari. DropIt, la principale alternativa gratuita, non ha nuove versioni da febbraio 2018.

### File Juggler usa l'IA?

No. Confronta le condizioni che scrivi tu, comprese le parole trovate dentro file PDF, Word ed Excel, e può riutilizzare le date che trova nel testo. Non sa leggere le scansioni composte solo da immagini senza un programma OCR separato, e non può capire che cosa mostri una foto o uno screenshot. Per quei file serve uno strumento con IA come Zush, Sortio o Wisfile.

### File Juggler a $50 conviene rispetto a Zush a $48?

Comprano cose diverse. Con i $50 più tasse di File Juggler ottieni un motore di regole con tutti gli aggiornamenti futuri, ma senza IA. La licenza una tantum da $48 di Zush include nomi e ordinamento in cartelle con l'IA tramite la Zush Cloud AI gestita, le modalità locale e BYOK, rinomine illimitate, tutti gli aggiornamenti futuri e fino a 3 dispositivi tra Windows e Mac. Molti usano entrambi.

### Zush o File Juggler inviano i miei file da qualche parte?

File Juggler esegue le regole in locale. Con Zush dipende dalla modalità che scegli: con Ollama o LM Studio l'analisi resta sul tuo PC; con la Zush Cloud AI o con la tua chiave API il contenuto del file viene inviato a quel modello cloud per generare il nome. Scegli una modalità locale per le cartelle riservate, e controlla anche l'impostazione di Sortio, che offre IA ospitata, BYOK oppure Ollama.

### Esiste un File Juggler per Mac?

No, File Juggler è solo per Windows. Hazel è l'equivalente più vicino su Mac per le regole, e la redazione di Softpedia gli dà 5,0/5. Zush per Mac copre nomi e ordinamento in cartelle con l'IA, comprese le cartelle monitorate su dischi esterni. Leggi la nostra pagina sull'[alternativa a Hazel](/hazel-alternative) per vedere come si confrontano i due approcci su Mac.

### Zush può sostituire del tutto File Juggler?

Per dare un nome ai file in base al contenuto e ordinarli in cartelle sì, cartelle monitorate comprese. File Juggler ha però azioni che Zush non offre, come eseguire un comando, estrarre archivi o caricare su Evernote. Se ti servono, tieni File Juggler per quella parte e lascia che Zush scriva i nomi descrittivi che le sue regole possono riconoscere.
