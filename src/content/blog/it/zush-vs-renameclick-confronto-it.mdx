## Supporto formato

### Zush è più ampio per cartelle miste reali

Zush supporta formati foto RAW , file di progettazione, audio, video, file iWork , file Office , sottotitoli e formati dati/testo. Questo è il vantaggio pratico se le tue cartelle sono disordinate perché sono reali: screenshot accanto alle foto del telefono, file RAW della fotocamera accanto ai PDF, file Figma/Sketch/PSD accanto ai documenti Keynote/Pages e file video accanto agli appunti della riunione. L'audio non fa più parte di questa lacuna: RenameClick ora gestisce i formati audio più comuni, ma RAW, file di progettazione, iWork e video lo sono ancora.

### RenameClick copre immagini comuni, un ampio elenco di documenti e ora audio

RenameClick copre bene i flussi di lavoro comuni di immagini e documenti: JPEG, PNG, GIF, WebP, AVIF, BMP, SVG, HEIC, HEIF, TIFF, oltre a PDF, DOC/DOCX, TXT, Markdown, CSV, RTF, ODT, JSON, XML, YAML, HTML, registri, SQL, sottotitoli e file di calendario/contatti e ha aggiunto l'audio (MP3, WAV, FLAC, M4A, AAC) con trascrizione vocale locale. Il divario riguarda i media e i formati di progettazione. I documenti di RenameClick non elencano i formati della fotocamera RAW né i file di progettazione come Sketch/Figma/PSD e chiamano esplicitamente file video, archivi ed eseguibili non supportati. Se questi formati contano, Zush è più sicuro.

## Automazione e organizzazione

Entrambi gli strumenti possono controllare le cartelle, ma enfatizzano risultati diversi.

Il monitoraggio delle cartelle Zush è basato sulla ridenominazione automatica dell'intelligenza artificiale con modelli riutilizzabili e Naming Blocks. È adatto per la pulizia dei download, gli screenshot, le cartelle client ricorrenti e le convenzioni di denominazione prevedibili in cui i nuovi file dovrebbero ottenere nomi ricercabili non appena arrivano.

RenameClick Auto Flow è più un sistema a righe di regole. Ogni riga può avere la propria cartella di origine, cartella di destinazione, formato di denominazione, istruzioni personalizzate, lingua, preimpostazione di ordinamento, impostazione ricorsiva e impostazione di applicazione automatica. Può eseguire più righe contemporaneamente, attendere che i file diventino stabili prima dell'elaborazione, evitare l'elaborazione in loop all'interno delle cartelle di destinazione e mettere in pausa quando i crediti del piano gratuito si esauriscono.

Se il tuo obiettivo di automazione è "rinominare i file in modo coerente", Zush è il sistema documentato più potente. Considerare RenameClick solo quando la stessa azione deve anche spostare file; la copertura del formato più ristretto rimane il costo di tale scelta.

## Ricerca, metadati e recupero

Zush facilita il recupero generando nomi di file significativi, aggiungendo tag Finder e scrivendo metadati compatibili con Spotlight. Questo è adatto agli utenti Mac che già effettuano ricerche in Finder/Spotlight e desiderano che i nomi dei file contengano il contesto più importante.

RenameClick aggiunge uno spazio di lavoro AI Search separato. Ti consente di cercare in base al significato del contenuto, non solo alle parole chiave del nome file. Ad esempio, una ricerca di fatture può corrispondere alle scansioni PDF anche se il nome file originale è `scan_001.pdf`. AI Search è di sola lettura per scopi di rinomina/spostamento, ma può rivelare file, escludere risultati o spostare elementi nel cestino.

Per la scoperta all'interno di cartelle caotiche, AI Search di RenameClick è un elemento di differenziazione significativo. Per trasformare i file in risorse ricercabili a lungo termine nel sistema operativo, il flusso di lavoro nome file + tag + metadati di Zush è il livello quotidiano migliore.

## Domande frequenti

### RenameClick è più economico di Zush?

Dipende dal piano e dall'IVA locale. Zush è $10/month o $48 una tantum. RenameClick è $8+ IVA/mese o $48+ IVA a vita. I totali mensili sono vicini al netto dell'IVA in molti mercati, mentre Zush ha il totale di pagamento più basso perché entrambi iniziano da $48 e RenameClick aggiunge l'IVA.

### RenameClick funziona offline?

SÌ. RenameClick è prima locale. Dopo aver scaricato il modello locale, il provider locale integrato può funzionare senza Internet, senza una chiave API e senza costi API . I provider cloud richiedono Internet e la tua chiave provider.

### Zush funziona offline?

Sì, tramite la modalità AI offline tramite Ollama. La differenza è che Zush non raggruppa il proprio modello locale come percorso predefinito; imposti Ollama e scegli un modello locale compatibile.

### RenameClick supporta le foto RAW ?

L'elenco pubblico dei file supportati da RenameClick non include i formati della fotocamera RAW come CR2, CR3, NEF, ARW, DNG, ORF, RAF, RW2, PEF, SRW o SR2. Zush supporta esplicitamente i formati RAW .

### RenameClick supporta file video o audio?

Audio sì, video no. I suoi documenti ora elencano MP3, WAV, FLAC, M4A e AAC con trascrizione vocale locale, mentre i file video (`.mp4`, `.mov`, `.mkv`, `.webm`), altri codec audio, archivi ed eseguibili non sono esplicitamente supportati. Zush supporta i formati video 16 insieme al suo elenco audio.

### Quale ha una migliore automazione delle cartelle?

Dipende dall'obiettivo. Zush è migliore per la denominazione automatica con modelli e Naming Blocks. RenameClick è migliore per il routing delle cartelle perché Auto Flow può rinominare, classificare e spostare i file nelle cartelle di destinazione.
