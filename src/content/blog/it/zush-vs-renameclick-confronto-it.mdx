## Zush

<BlogToolMeta platform="Mac (&quot;macOS&quot; 15+) e &quot;Windows&quot; 10/11" website="https://zushapp.com/" label="zushapp.com"><Fragment slot="pricing">Livello gratuito (50 rinominazioni), Pro<BlogHighlight>$ 10 al mese o $ 48 una tantum</BlogHighlight>per rinominazioni PRO illimitate, "BYOK" opzionale al costo API (Gemini/OpenRouter/OpenAI/Claude), AI offline tramite "Ollama / LM Studio"</Fragment></BlogToolMeta>

![Risultati di ridenominazione AI "Zush" che mostrano file con nomi descrittivi prima e dopo e segni di spunta verdi](/images/showcase/macos/batch-rename-light.webp)

"Zush" è un rinominatore di file AI desktop per cartelle miste. Il suo vantaggio più importante è il sistema di denominazione: "Templates" integrato per flussi di lavoro comuni, oltre 145 "Naming Blocks", "Custom AI Blocks", prompt, ordine dei campi, maiuscole e minuscole, separatori, formati di data, lingua, tag "Finder", metadati "Spotlight" e assegnazioni di modelli per cartella. "Rename History" memorizza nomi, cartelle e timestamp originali e nuovi e può ripristinare un batch applicato. I suoi oltre 100 formati comprendono immagini, RAW, design, documenti, "iWork", sottotitoli, video e audio.

La parte importante in questo confronto è che "Zush" non forza un silo di tipo file. Una cartella con `IMG_4821.HEIC`, `_DSC0019.NEF`, `checkout-flow.fig`, `voice-memo.m4a`, `client-brief.pages`, `recording.mov` e `invoice.pdf` può rimanere in un flusso di lavoro.

Il prezzo è semplice: $ 10 al mese o $ 48 una tantum per PRO. Entrambi i piani a pagamento rimuovono il limite di ridenominazione su Cloud AI, "BYOK" e Offline AI. "Templates", "Naming Blocks" e i prompt personalizzati sono inclusi gratuitamente.

Una licenza Zush copre fino a 3 dispositivi Mac o Windows.

Puoi [esportare i Templates](/docs/template-import-export) con Naming Blocks, Custom AI Blocks e regole per le cartelle, quindi importarli su un altro computer. Le destinazioni locali, le autorizzazioni e le connessioni IA vanno configurate di nuovo. Si trasferiscono le impostazioni, non i file.

Zush supporta cartelle annidate, ad esempio per anno e poi per mese. Puoi ordinare file già rinominati senza modificarne nuovamente il nome o consumare un altro credito di rinomina. Controlla le destinazioni prima di applicare. Questa operazione è separata da Monitor: modificare il suo Template non riorganizza i file precedenti. L’[ordinamento IA](/docs/folder-sorting) funziona su Mac e Windows.

"RenameClick" è un'app desktop locale per "macOS" e "Windows". Il suo punto centrale è la privacy: dopo il download una tantum del modello locale, il suo provider Qwen3-VL integrato può elaborare i file sul dispositivo senza una chiave API o una connessione Internet. Supporta inoltre LM Studio e "Ollama" per i flussi di lavoro del server locale, oltre a OpenAI, Google Gemini e Alibaba Cloud Qwen quando colleghi esplicitamente le chiavi API cloud. "RenameClick" rileva che i fornitori di servizi cloud non sono disponibili nella versione per Mac App Store; utilizzare il download diretto se tali fornitori sono importanti.

"RenameClick" non è solo un rinominatore. È più vicino a un organizzatore di file: può rinominare file, classificarli, spostarli in cartelle, eseguire regole di controllo del flusso automatico, cercare per contenuto con Ricerca AI e creare nomi da segnaposto EXIF/data. La documentazione dei file supportati ora copre tre categorie: immagini comuni (JPEG, PNG, GIF, WebP, AVIF, BMP, SVG, HEIC, HEIF, TIFF), un lungo elenco di documenti (PDF, DOC/DOCX, XLSX, PPTX, TXT, MD, CSV, RTF, ODT, JSON, XML, YAML, HTML, log, SQL, SRT/VTT, ICS/VCF) e audio (MP3, WAV, FLAC, M4A, AAC) con trascrizione del parlato locale. File video, altri codec audio, archivi ed eseguibili sono esplicitamente elencati come non supportati.

## Supporto del formato

### "Zush" è più ampio per le cartelle miste reali

"Zush" supporta formati foto RAW, file di progettazione, audio, video, file "iWork", file Office, sottotitoli e formati dati/testo. Questo è il vantaggio pratico se le tue cartelle sono disordinate perché sono reali: screenshot accanto alle foto del telefono, file RAW della fotocamera accanto ai PDF, file Figma/Sketch/PSD accanto ai documenti Keynote/Pages e file video accanto agli appunti della riunione. L'audio non rientra più in questa lacuna: ora "RenameClick" gestisce i formati audio più comuni, ma RAW, file di progettazione, "iWork" e video lo sono ancora.

### "RenameClick" copre immagini comuni, un ampio elenco di documenti e ora audio

"RenameClick" copre bene i flussi di lavoro comuni di immagini e documenti: JPEG, PNG, GIF, WebP, AVIF, BMP, SVG, HEIC, HEIF, TIFF, oltre a PDF, DOC/DOCX, XLSX, PPTX, TXT, Markdown, CSV, RTF, ODT, JSON, XML, YAML, HTML, registri, SQL, sottotitoli e file di calendario/contatti, e ha aggiunto audio (MP3, WAV, FLAC, M4A, AAC) con parlato locale trascrizione. Dispone inoltre di utili dettagli sull'elaborazione dei documenti: estrazione del testo per PDF di testo e documenti Office, fallback di visione per PDF scansionati e limiti di ritaglio del testo dei documenti configurabili.

Il divario riguarda i media e i formati di progettazione. I documenti di "RenameClick" non elencano i formati RAW della fotocamera o i file di progettazione come Sketch/Figma/PSD e chiamano esplicitamente file video, archivi ed eseguibili non supportati. Se questi formati contano, "Zush" è più sicuro.

## L’intelligenza artificiale locale è parità; il controllo dei nomi non lo è

Entrambi i prodotti possono eseguire modelli locali, quindi l'elaborazione offline non rappresenta un vantaggio unico. "RenameClick" raggruppa un modello dopo un download di più GB; "Zush" si collega a "Ollama". La differenza più importante è il resto del flusso di lavoro: "Zush" documenta "Templates" già pronti, oltre 145 "Naming Blocks", "Custom AI Blocks", localizzazione più ricca e controlli di metadati e "Rename History" persistente.

Zush è adatto a cartelle con formati diversi, modelli di nomi precisi e cronologia delle modifiche, con IA cloud inclusa. Offre anche BYOK, LM Studio e Ollama. OpenRouter non è un vantaggio esclusivo di Zush. [Zush](https://zushapp.com/docs/ai-modes).

Il compromesso pratico è semplice: scegli Zush per profondità dei nomi, dettaglio del ripristino, varietà di file e ordinamento guidato da prompt. Considera RenameClick solo se lo spazio AI Search conta più della mancanza di RAW, file di design, iWork e video.

## Automazione e organizzazione

Entrambi gli strumenti possono controllare le cartelle, ma enfatizzano risultati diversi.

Il monitoraggio delle cartelle di Zush si basa sulla rinomina automatica con IA tramite Template e Naming Blocks riutilizzabili. Un Template con ordinamento attivo sposta anche ogni nuovo file in una cartella scelta dalle tue regole in linguaggio naturale o da Auto, e Monitor continua a usare le cartelle che ha creato. È adatto a Download, cartelle dello scanner, screenshot e cartelle di clienti ricorrenti.

Il flusso automatico "RenameClick" è più un sistema di righe di regole. Ogni riga può avere la propria cartella di origine, cartella di destinazione, formato di denominazione, istruzioni personalizzate, lingua, preimpostazione di ordinamento, impostazione ricorsiva e impostazione di applicazione automatica. Può eseguire più righe contemporaneamente, attendere che i file diventino stabili prima dell'elaborazione, evitare l'elaborazione in loop all'interno delle cartelle di destinazione e mettere in pausa quando i crediti del piano gratuito si esauriscono.

Se il tuo obiettivo è rinominare i file in modo coerente e archiviarli con regole descritte con parole tue, Zush è il sistema meglio documentato. Considera RenameClick quando basta scegliere tra set di cartelle o l’abbinamento a cartelle che già mantieni; la copertura dei formati più ristretta resta il prezzo di questa scelta.

## Ricerca, metadati e recupero

"Zush" facilita il recupero generando nomi di file significativi, aggiungendo tag "Finder" e scrivendo metadati compatibili con "Spotlight". Questo è adatto agli utenti Mac che già effettuano ricerche in "Finder"/"Spotlight" e desiderano che i nomi dei file riportino il contesto più importante.

Dalla versione 2.18, AI Search consente di rinominare e spostare i risultati. Ricerca e indicizzazione non consumano crediti per applicare modifiche; i file modificati sì. RenameClick 2.18.

Per la scoperta all'interno di cartelle caotiche, la ricerca AI di "RenameClick" è un significativo elemento di differenziazione. Per trasformare i file in risorse ricercabili a lungo termine nel sistema operativo, il flusso di lavoro nome file + tag + metadati di "Zush" è il livello migliore per tutti i giorni.

## Domande frequenti

### RenameClick è più economico di Zush?

Zush costa $10/mese o $48 a vita. RenameClick costa $8/mese o $36 a vita, più IVA.

### "RenameClick" funziona offline?

SÌ. "RenameClick" è locale-first. Dopo aver scaricato il modello locale, il provider locale integrato può funzionare senza Internet, senza chiave API e senza costi API. I provider cloud richiedono Internet e la tua chiave provider.

### "Zush" funziona offline?

Sì, tramite la modalità AI offline tramite "Ollama". La differenza è che "Zush" non raggruppa il proprio modello locale come percorso predefinito; imposti "Ollama" e scegli un modello locale compatibile.

### "RenameClick" supporta le foto RAW?

L'elenco pubblico dei file supportati da "RenameClick" non include i formati RAW della fotocamera come CR2, CR3, NEF, ARW, DNG, ORF, RAF, RW2, PEF, SRW o SR2. "Zush" supporta esplicitamente questi formati RAW.

### "RenameClick" supporta file video o audio?

Secondo la documentazione, RenameClick supporta audio MP3, WAV, FLAC, M4A e AAC, ma non i video. Zush supporta i video su Mac e Windows, inclusi MP4, MOV, MKV, AVI e WMV. [Zush](/docs/supported-file-types).

### Quale ha una migliore automazione delle cartelle?

Zush, per la maggior parte delle cartelle. Entrambe le app possono rinominare i nuovi file e spostarli in cartelle. Zush ordina con regole in linguaggio naturale o Auto, riutilizza le cartelle esistenti e nomina i file con Template e Naming Blocks. L’Auto Flow di RenameClick ordina in set di cartelle o in sottocartelle esistenti fino a tre livelli di profondità, con 12 proposte di cartella per file per impostazione predefinita e fino a 50, e può copiare invece di spostare.
