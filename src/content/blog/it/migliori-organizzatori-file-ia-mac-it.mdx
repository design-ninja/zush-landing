## Scegli Zush per nomi, cartelle e arrivi ricorrenti

In Zush, queste sono tre parti di un unico flusso di lavoro:

| Il tuo compito | Cosa configurare in Zush | Cosa controllare prima dell'applicazione |
|---|---|---|
| Rendere ricercabili schermate, PDF ed esportazioni | Scegli un Modello e i relativi Naming Blocks | Ciascun nome proposto descrive il file effettivo? |
| Raggruppare file misti per cliente, azienda o mese | Attiva Ordina e inserisci Folder rules, oppure usa Auto | Le cartelle di destinazione proposte sono corrette? |
| Mantenere i Download organizzati man mano che i file arrivano | Assegna il Modello testato a Monitor | Le regole funzionano sui nuovi esempi così come sul primo batch? |

Zush può rinominare sul posto: mantieni Ordina disattivato e conserva la destinazione originale. Per l'organizzazione delle cartelle, attiva Ordina e verifica sia il nome che la destinazione. La rinomina modifica anche i percorsi dei file, quindi usa copie per il primo prova ed evita di spostare i file a cui fanno riferimento progetti attivi.

## Prova Zush su dieci file Mac copiati

1. Installa [Zush per Mac](/mac). Copia dieci file rappresentativi in una cartella di prova: fatture, ricevute, schermate, foto e documenti che puoi riconoscere.
2. Apri **AI Rename**, aggiungi le copie e scegli un Modello. Usa i Naming Blocks per impostare i campi del nome file e la formattazione.
3. Scegli una destinazione all'interno della tua area di prova, attiva **Ordina** e inserisci questa regola per le cartelle:

> Raggruppa le fatture per azienda e le ricevute per mese. Nomina le cartelle dei mesi YYYY-MM.

4. Rivedi ogni nome file e cartella proposta. Controlla le date e i nomi delle aziende rispetto ai file sorgente. Correggi o salta i suggerimenti incerti prima di applicare.
5. Applica il batch revisionato, apri i file dalle loro nuove posizioni, quindi usa [Rename History](/docs/undo-history) per testare il ripristino dei nomi e delle cartelle originali.

Ad esempio, una fattura potrebbe spostarsi da `Test/scan_0042.pdf` a `Test/Organized/Acme/2026-07-18_Acme_INV-1042.pdf`. Questo è un obiettivo illustrativo, non un risultato misurato. Il Modello controlla il nome del file; i Folder rules controllano il raggruppamento. Un campo mancante o ambiguo richiede comunque il tuo giudizio.

## Mantieni la configurazione che funziona

Salva la configurazione riuscita come [Modello](/docs/templates). Assegnala al [monitoraggio delle cartelle](/docs/folder-monitoring) per una cartella di prova prima di usare Download. Monitor automatizza i nuovi arrivi; non dare per scontato che abbia lo stesso passaggio di approvazione manuale del primo batch di AI Rename. Ispeziona i primi risultati e la cronologia prima di espandere il flusso di lavoro.

Zush offre analisi cloud gestita, BYOK e analisi locale supportata tramite Ollama o LM Studio. BYOK invia comunque l'analisi a un provider cloud. Le modalità locali richiedono una configurazione e un modello idoneo; controlla la [guida all'IA locale](/offline-ai-file-renamer) per i tuoi file. FREE include 50 rinomine in tutte le modalità, non un reset mensile. Vedi i [piani attuali](/pricing) prima di scegliere PRO.

## Breve confronto: quando Zush è adatto e quando no

| Requisito | Come decidere |
|---|---|
| Nomi basati sul contenuto più gruppi di cartelle opzionali | **Inizia con Zush:** testa entrambe le azioni in un unico batch revisionato, quindi riusa il Modello. |
| Condizioni esplicite, script e automazione macOS | [Hazel](https://www.noodlesoft.com/) documenta questi flussi di lavoro. I Folder rules di Zush sono istruzioni IA, non un sostituto per un motore di scripting. |
| Rimozione dei duplicati o recupero di spazio su disco | [Sparkle](https://makeitsparkle.co/) include la pulizia. Zush organizza nomi e cartelle; non elimina i duplicati né disinstalla le app. |
| È richiesto Linux | [Sortio](https://www.getsortio.com/) elenca il supporto per Linux. Zush è disponibile su Mac e Windows. |
| Un flusso di lavoro di denominazione specifico per documenti esistente | Confronta i requisiti esatti in [Zush vs NameQuick](/blog/zush-vs-namequick); la sola IA locale non è un'esclusiva di Zush. |

Questi confini sono più utili di una classifica universale. Per il flusso di lavoro di denominazione e smistamento di cartelle miste sopra descritto, Zush rimane la nostra migliore scelta in assoluto. Se la pulizia o gli script sono il tuo requisito principale, Zush non sostituisce tali funzioni.

## Domande frequenti

### Qual è il miglior organizzatore di file IA per Mac?

Zush è la nostra scelta migliore in assoluto per rendere i file misti ricercabili e organizzarli in cartelle. Combina denominazione basata sul contenuto configurabile, raggruppamento IA Folder rules o Auto, anteprima, Rename History e Monitor. Testalo con i tuoi file copiati; questa raccomandazione non è un'affermazione misurata secondo cui Zush è più accurato di ogni alternativa.

### Zush può organizzare i file senza spostarli?

 Sì. Mantieni Ordina disattivato e conserva la destinazione originale per rinominare sul posto. I nomi cambiano comunque, quindi controlla i riferimenti da altre applicazioni. Attiva Ordina solo quando desideri anche il raggruppamento in cartelle.

### Posso descrivere le mie cartelle in inglese semplice?

Sì. In Zush, i Folder rules possono descrivere gruppi come azienda, tipo di documento o mese. Lascia il campo vuoto per Auto. Rivedi i gruppi proposti prima di applicarli.

### Cosa dovrei provare dopo il primo batch?

Usa il [flusso di lavoro Download di Zush](/automate-downloads-folder) per gli arrivi ricorrenti, oppure segui la [procedura guidata di smistamento cartelle su Mac](/blog/sort-files-into-folders-with-ai-mac) per perfezionare i gruppi. Avvia l'automazione solo dopo che il Modello funziona su file rappresentativi.
