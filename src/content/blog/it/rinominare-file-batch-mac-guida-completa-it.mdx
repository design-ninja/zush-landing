## Metodo 1: "Finder" Rinomina elementi

"Finder" ha uno strumento di rinomina batch integrato che la maggior parte degli utenti Mac non scopre mai. Gestisce tre tipi di ridenominazione: sostituzione del testo nei nomi dei file, aggiunta di testo prima o dopo il nome esistente e formattazione dei nomi con un numero sequenziale o un contatore.

### Quando utilizzare la ridenominazione batch "Finder".

- Sostituzione di una stringa comune su più file (ad esempio, modifica di "IMG_" in "vacanze-")
- Aggiunta di un prefisso data o suffisso progetto a un gruppo di file
- Numerazione sequenziale di una serie di file (ad esempio, `photo-001.jpg`, `photo-002.jpg`)
- Qualsiasi ridenominazione in cui a ogni file viene applicata la stessa regola

### Passo dopo passo: come rinominare in batch i file in "Finder".

**Passaggio 1: seleziona i file.**
Apri la cartella contenente i file che desideri rinominare. Seleziona tutti i file con Cmd+A oppure seleziona un intervallo specifico facendo clic sul primo file, quindi Maiusc+clic sull'ultimo. Per selezionare singoli file, tieni premuto Cmd e fai clic su ciascuno di essi.

**Passaggio 2: apri la finestra di dialogo di ridenominazione.**
Fai clic con il pulsante destro del mouse (o Control+clic) su qualsiasi file selezionato e scegli "Rinomina..." dal menu contestuale. Puoi anche utilizzare la barra dei menu Finder: vai su File > Rinomina.

**Passaggio 3: scegli la modalità di ridenominazione.**
La finestra di dialogo di ridenominazione ha un menu a discesa in alto con tre opzioni:

- **Sostituisci testo** -- Trova una stringa nei nomi dei file correnti e sostituiscila con qualcos'altro.
- **Aggiungi testo**: aggiungi o anteponi testo a ogni nome file.
- **Formato** -- Sostituisci l'intero nome con un nome base più un numero sequenziale, un contatore o una data.

**Passaggio 4: configura e visualizza l'anteprima.**
Compila i campi. "Finder" mostra un'anteprima del nuovo nome in modo da poterlo verificare prima di impegnarsi. Controlla che il risultato sia corretto.

**Passaggio 5: fai clic su Rinomina.**
Tutti i file selezionati vengono rinominati immediatamente. Se hai commesso un errore, premi immediatamente Cmd+Z per annullare l'intero batch.

### Limitazioni della ridenominazione batch "Finder".

"Finder" applica la stessa regola a ogni file selezionato. Non può assegnare a ciascun file un nome descrittivo univoco in base al suo contenuto. Inoltre, non è in grado di gestire modelli regex, logica condizionale o denominazione basata sui metadati. Per questi lavori, è necessario uno strumento diverso. Gli switcher "Windows" spesso richiedono "["Bulk Rename Utility" su Mac](/blog/bulk-rename-utility-alternatives)": non esiste per "macOS" e "[Advanced Renamer](/blog/advanced-renamer-alternatives)" copre la nicchia di pattern e metadati su entrambe le piattaforme; nessuno dei due nomina i file in base al contenuto.

### La ridenominazione batch "Finder" modifica i metadati del file?

No. La ridenominazione batch "Finder" modifica solo il nome del file. Il nuovo nome è visibile nelle finestre di dialogo "Finder", "Spotlight", Apri e nel percorso del file, ma la ridenominazione non scrive automaticamente i metadati EXIF, i tag "Finder", i commenti "Finder", i campi del titolo PDF o le proprietà del documento.

Questa distinzione è importante quando desideri che i file rimangano ricercabili in seguito:

|Campo|Modificato dalla ridenominazione batch "Finder"?|Impatto sulla ricerca|
|---|---|---|
|Nome file|SÌ|La ricerca "Spotlight" e "Finder" può corrispondere al nuovo nome|
|Percorso del file|SÌ|Il percorso riflette immediatamente il nuovo nome|
|Tag "Finder".|NO|I tag devono essere aggiunti separatamente|
|Commenti "Finder".|NO|I commenti devono essere aggiunti separatamente|
|EXIF/metadati della fotocamera|NO|I metadati delle foto rimangono invariati|
|Proprietà del documento PDF o Office|NO|I campi titolo/autore del documento rimangono invariati|

Se hai solo bisogno di nomi di file più puliti, Finder è sufficiente. Se desideri anche nomi, tag e metadati semantici per screenshot, PDF, foto e documenti misti, utilizza un rinominatore di file AI che scriva intenzionalmente nomi e metadati facili da ricercare. "Zush" supporta "[Tag "Finder" e metadati compatibili con "Spotlight".](/mac)" insieme ai nomi di file generati dall'intelligenza artificiale.

Per ulteriori informazioni sull'impostazione delle convenzioni di denominazione che rendono efficaci le ridenominazioni batch, vedere "[Convenzioni di denominazione dei file: best practice per qualsiasi flusso di lavoro](/blog/file-naming-conventions-best-practices)".


## Metodo 2: flussi di lavoro "Automator".

"Automator" è uno strumento di automazione "macOS" che ti consente di creare flussi di lavoro in più fasi senza scrivere codice. Per la ridenominazione dei file, fornisce più potenza di "Finder" perché puoi concatenare più azioni di ridenominazione, utilizzare metadati come la data di creazione e allegare il flusso di lavoro a una cartella in modo che venga eseguito automaticamente.

### Quando utilizzare "Automator".

- È necessario che la stessa regola di ridenominazione venga applicata regolarmente (esportazioni settimanali, rapporti ricorrenti)
- Vuoi combinare la ridenominazione con altre azioni (spostamento di file, modifica delle estensioni)
- Hai bisogno di una denominazione basata sui metadati (data di creazione, dimensione del file, dimensioni dell'immagine)
- Desideri un'applicazione drag-and-drop per i membri del team non tecnici

### Passo dopo passo: creazione di un flusso di lavoro di ridenominazione in "Automator".

**Passaggio 1: apri "Automator".**
Avvia Automator da Applicazioni o Spotlight (Cmd+Spazio, digita "Automator"). Scegli "Nuovo documento" quando richiesto.

**Passaggio 2: seleziona il tipo di flusso di lavoro.**
Scegli uno di questi a seconda del tuo caso d'uso:

- **Flusso di lavoro** - Esegui manualmente da "Automator". Buono per i test.
- **Applicazione** -- Crea un'app autonoma su cui puoi trascinare i file. Buono per un uso occasionale.
- **Azione cartella** -- Allegato a una cartella specifica. Viene eseguito automaticamente quando vengono aggiunti nuovi file. Buono per l'automazione continua.
- **Azione rapida** -- Appare nel menu contestuale del tasto destro in Finder. Buono per l'uso su richiesta.

Per la ridenominazione batch, **Applicazione** o **Azione cartella** sono le scelte più pratiche.

**Passaggio 3: aggiungi l'azione di ridenominazione.**
Nella barra laterale di sinistra, cerca "Rinomina elementi Finder". Trascinalo nell'area del flusso di lavoro sulla destra. Automator ti chiederà se desideri aggiungere prima il passaggio "Copia elementi Finder" per preservare gli originali. Fai clic su "Non aggiungere" se desideri rinominare sul posto o su "Aggiungi" se desideri conservare i backup.

**Passaggio 4: configura la regola di ridenominazione.**
L'azione "Rinomina elementi Finder" prevede diverse modalità:

- **Aggiungi data o ora**: anteponi o aggiungi la data di creazione o modifica del file. Utile per organizzare cronologicamente le esportazioni.
- **Cambia maiuscole/minuscole** -- Converti i nomi dei file in minuscolo, maiuscolo o maiuscolo.
- **Trova e sostituisci** -- Come Sostituisci testo di Finder, ma concatenabile con altre azioni.
- **Rendi sequenziale** -- Aggiungi un numero di indice a ciascun file.
- **Sostituisci testo** -- Scambia una stringa con un'altra.

È possibile impilare più azioni di ridenominazione in sequenza. Ad esempio: sostituisci prima `IMG_` con una stringa vuota, quindi aggiungi la data di creazione come prefisso, quindi modifica le maiuscole in minuscole.

**Passaggio 5: aggiungi input.**
Se hai scelto un flusso di lavoro, aggiungi l'azione "Ottieni elementi Finder specificati" in alto e trascina i file al suo interno. Se scegli un'azione Applicazione o Cartella, i file vengono passati automaticamente.

**Passaggio 6: testa il flusso di lavoro.**
Fare clic sul pulsante Esegui in alto a destra. Controlla i risultati in "Finder". Se qualcosa è andato storto, premi Cmd+Z in "Finder" per annullare.

**Passaggio 7: salva.**
Salva con un nome descrittivo come "Rinomina esportazioni cliente". Se hai creato un'applicazione, salvala nella cartella Applicazioni o sul desktop. Se hai creato un'azione cartella, questa si allega alla cartella specificata.

### Limitazioni "Automator".

"Automator" è basato su modelli. Funziona bene quando ogni file deve seguire la stessa regola. Non può guardare un PDF e decidere che il nome del file dovrebbe essere "dichiarazione dei redditi-2025.pdf" invece di "scan_003.pdf". Inoltre, non ha alcuna integrazione con l'intelligenza artificiale e la sua affidabilità negli aggiornamenti "macOS" è diventata incoerente. Apple ha spostato gli investimenti verso "Shortcuts", che gestisce alcune delle stesse attività ma con un'interfaccia diversa.

Per istruzioni dettagliate su come eseguire automaticamente "[Automator rinomina i file su Mac](/blog/macos-automator-rename-files-guide)", leggere la guida dedicata a "Automator".

### "Shortcuts": dove Apple si sta impegnando adesso

"Shortcuts" viene fornito con "macOS" Monterey e versioni successive ed è lo strumento che Apple sta sviluppando attivamente, quindi vale la pena saperlo anche se i flussi di lavoro "Automator" esistenti sono ancora in esecuzione. Per la ridenominazione batch copre la maggior parte di ciò che fa "Rinomina elementi Finder", con un modello di assieme diverso: costruisci un piccolo ciclo invece di configurare un'azione.

Un collegamento minimo per la ridenominazione batch è simile al seguente:

1. Avvia un nuovo collegamento e imposta **Ricevi** input su **File** da **Azioni rapide**.
2. Aggiungi **Ripeti con ciascuno**, passando a **Input scorciatoia**.
3. All'interno del ciclo, aggiungi **Rinomina file**, imposta il file su **Ripeti elemento** e crea il nuovo nome con **Testo**, ad esempio un risultato **Formatta data**, un carattere di sottolineatura e l'indice di ripetizione.
4. Nel riquadro dei dettagli del collegamento, attiva **Utilizza come azione rapida** e seleziona **Finder**.

Il collegamento viene quindi visualizzato nel sottomenu **Azioni rapide** del tasto destro del mouse di Finder, quindi selezioni i file, eseguilo e l'intero batch viene rinominato sul posto.

Nella pratica contano due limiti. "Shortcuts" è ancora basato su modelli: può comporre un nome da una data, un contatore o un testo esistente, ma non può decidere che un PDF sia un contratto di locazione. E una ridenominazione eseguita da "Shortcuts" non è nello stack di annullamento di "Finder", quindi Cmd+Z non la invertirà; prova prima su una cartella copiata.

Scegli "Automator" se hai già file ".workflow" in funzione o hai bisogno di un'azione cartella; scegli "Shortcuts" per qualsiasi cosa nuova, perché è il percorso che Apple continua ad aggiornare.

## Metodo 3: script Terminal per rinominare in blocco i file su Mac

Se hai dimestichezza con la riga di comando, gli script di shell ti danno il massimo controllo sulla ridenominazione batch su Mac. Puoi utilizzare espressioni regolari, condizionali, loop e qualsiasi metadato disponibile tramite gli strumenti da riga di comando.

### Quando utilizzare gli script

- Hai bisogno di una corrispondenza di pattern basata su regex (ad esempio, estrarre le date dai nomi dei file)
- Desideri rinominare in base ai metadati del file (dati EXIF, proprietà PDF)
- Hai bisogno di una logica condizionale (rinominare solo i file che corrispondono a determinati criteri)
- Ti senti già a tuo agio in "Terminal".

### Rinomina di base con un ciclo

Rinomina tutti i file `.jpeg` in `.jpg`:

```bash
for f in *.jpeg; do
  mv "$f" "${f%.jpeg}.jpg"
done
```

### Sostituisci il testo nei nomi dei file

Sostituisci gli spazi con trattini in tutti i nomi di file nella directory corrente:

```bash
for f in *\ *; do
  mv "$f" "${f// /-}"
done
```

### Aggiungi un prefisso della data dai metadati del file

Anteponi a ogni JPEG la data di creazione EXIF ​​utilizzando "exiftool":

```bash
for f in *.jpg; do
  date=$(exiftool -d "%Y-%m-%d" -DateTimeOriginal -s3 "$f")
  mv "$f" "${date}_${f}"
done
```

Prima e dopo:

|Prima|Dopo|
|---|---|
|`IMG_4201.jpg`|`2026-01-15_IMG_4201.jpg`|
|`IMG_4202.jpg`|`2026-01-15_IMG_4202.jpg`|
|`IMG_4203.jpg`|`2026-01-16_IMG_4203.jpg`|

### Numerazione sequenziale con riempimento di zero

Rinominare un insieme di file con un prefisso e numeri preceduti da zero:

```bash
counter=1
for f in *.png; do
  mv "$f" "$(printf 'slide-%03d.png' $counter)"
  counter=$((counter + 1))
done
```

|Prima|Dopo|
|---|---|
|`Schermata 2026-02-01.png`|"slide-001.png".|
|`Schermata 2026-02-02.png`|"slide-002.png".|
|`Schermata 2026-02-03.png`|`slide-003.png`|

### Utilizzando il comando `rename` (basato su Perl)

Se installi l'utilità Perl `rename` tramite Homebrew ("brew install rename"), otterrai il supporto regex in un singolo comando:

```bash
rename 's/IMG_/vacation-/' *.jpg
```

Questo sostituisce "IMG_" con "vacation-" in ogni nome di file ".jpg" nella directory corrente.

### Limitazioni dello script

Gli script sono potenti ma richiedono conoscenze tecniche. Un errore di battitura in uno script di ridenominazione può danneggiare i nomi dei file in un'intera directory senza possibilità di annullamento. Prova sempre prima su una copia dei tuoi file, oppure usa `echo` prima di `mv` per vedere in anteprima cosa accadrà. Il "[guida sicura per rinominare i file batch](/blog/how-to-safely-batch-rename-files)" completo spiega le prove di prova, i controlli di estensioni e collisioni, i rischi dei file collegati e le opzioni di ripristino tra strumenti e script della GUI:

```bash
for f in *.jpg; do
  echo "mv $f -> vacation-${f#IMG_}"
done
```

Gli script condividono anche la stessa limitazione fondamentale di "Finder" e "Automator": applicano regole, non capiscono. Uno script non può guardare un'immagine e decidere cosa mostra. Per la ridenominazione basata sui contenuti, hai bisogno dell'intelligenza artificiale.

## Metodo 4: ridenominazione in base al contenuto assistita dall'intelligenza artificiale

La ridenominazione dell'IA è diversa da tutti i metodi sopra indicati. Invece di applicare uno schema o una regola ai nomi dei file, analizza il contenuto effettivo di ciascun file e genera un nome descrittivo in base a ciò che trova. Uno screenshot di una dashboard Stripe diventa "stripe-monthly-revenue-chart.png". Un PDF scansionato diventa "contratto di locazione di appartamento-2026.pdf". Una foto scaricata diventa "golden-gate-bridge-foggy-morning.jpg".


### Quando utilizzare la ridenominazione AI

- Schermate con nomi di timestamp che non dicono nulla sul contenuto
- Documenti scansionati e PDF con nomi come "scan_001.pdf".
- Immagini scaricate con nomi senza significato come `download.jpg` o `IMG_4392.heic`
- Qualsiasi cartella in cui i nomi dei file devono descrivere cosa contiene effettivamente il file

### Come funziona

1. Seleziona i file o punta lo strumento su una cartella
2. L'intelligenza artificiale analizza ogni file: legge il testo nei documenti, riconosce oggetti e scene nelle immagini, campiona i fotogrammi video e comprende gli elementi dell'interfaccia utente negli screenshot
3. Genera un nome file descrittivo per ciascun file in base al contenuto
4. I file vengono rinominati individualmente, ciascuno con un nome univoco che riflette ciò che contiene

Questa è la differenza fondamentale rispetto a ogni altro metodo: ogni file ottiene il proprio nome in base al proprio contenuto, non a un modello condiviso applicato al gruppo.

## Errori comuni durante la ridenominazione batch

### Dimenticare di includere l'estensione del file

Quando si utilizzano script, la rimozione o la sovrascrittura accidentale delle estensioni dei file è un errore comune. Un file rinominato da `report.pdf` a `quarterly-report` (senza `.pdf`) non si aprirà correttamente facendo doppio clic. Conserva sempre l'estensione nella logica di ridenominazione.

### Non testare prima su una copia

Rinominare è distruttivo. Se applichi un modello errato a 500 file, annullarlo può essere doloroso o impossibile (specialmente con gli script). Copia un piccolo campione di file in una cartella di prova, esegui lì la ridenominazione e verifica i risultati prima di toccare gli originali.

### Usare personaggi che causano problemi

Evita questi caratteri nei nomi file su macOS: `/`, `:` e byte null. Sebbene "macOS" sia più permissivo di "Windows", i nomi di file con caratteri speciali possono causare problemi durante la sincronizzazione con l'archivio cloud, il trasferimento su unità esterne o la condivisione con "Windows" o utenti Linux. Attenersi a lettere, numeri, trattini e trattini bassi.

### Applicare il metodo sbagliato al problema

Usare Sostituisci testo di Finder per rinominare una cartella di screenshot misti è una perdita di tempo perché ogni screenshot mostra qualcosa di diverso. Al contrario, usare l'intelligenza artificiale per rinominare un batch di file che necessita semplicemente della modifica di "IMG_" in "vacanza-" è eccessivo. Abbina lo strumento al compito reale.

### Ignorando l'ordinamento

Se hai bisogno di file in un ordine specifico, utilizza numeri con zero (`001`, `002`, non `1`, `2`). Senza riempimento, il file "10" viene ordinato tra "1" e "2" in "Finder" perché viene ordinato in ordine alfabetico, non numerico. Utilizza almeno tre cifre per le raccolte inferiori a 1.000 file.

## Suggerimenti per risultati migliori nella ridenominazione batch

Non provare a rinominare un'intera cartella di tipi di file misti in un unico passaggio. ### Usa l'annullamento immediato di Finder

La ridenominazione batch di Finder supporta l'annullamento Cmd+Z, ma solo immediatamente dopo la ridenominazione. Se esegui prima altre azioni "Finder", la cronologia degli annullamenti prosegue. Controlla i risultati subito dopo aver rinominato e annulla immediatamente se qualcosa non va.

## Domande frequenti

### Qual è il modo più veloce per rinominare in batch i file su Mac?

"Finder" è il modo più veloce quando ogni file riceve la stessa modifica: seleziona i file, fai clic con il pulsante destro del mouse, scegli Rinomina, seleziona Sostituisci testo, Aggiungi testo o Formato e applica. Sono circa dieci secondi per qualsiasi numero di file e non richiedono installazione o download. È più veloce solo quando una regola si adatta all'intero batch: se ogni file necessita di un nome descrittivo diverso, "Finder" non può svolgere affatto il lavoro e un rinominatore AI che legge il contenuto del file è il percorso più veloce nonostante l'installazione aggiuntiva.

### Come posso rinominare in batch i file su Mac senza installare nulla?

Utilizza lo strumento di ridenominazione integrato di Finder. Seleziona i file che desideri rinominare, fai clic con il pulsante destro del mouse e scegli "Rinomina..." dal menu contestuale. Puoi sostituire testo, aggiungere testo o formattare nomi con numeri sequenziali. Funziona su qualsiasi Mac con macOS Yosemite (10.10) o versioni successive senza bisogno di download.

### Finder può rinominare i file in base al loro contenuto?

No. La ridenominazione batch di "Finder" è strettamente basata su modelli. Può sostituire stringhe di testo, aggiungere prefissi o suffissi e applicare una numerazione sequenziale, ma non può analizzare cosa contiene un file. Per la ridenominazione in base al contenuto in cui a ogni file viene assegnato un nome descrittivo univoco, è necessario uno strumento basato sull'intelligenza artificiale in grado di leggere immagini, video e documenti.

### Il nome e l'indice "Finder" aggiungono metadati su Mac?

No. Il nome e l'indice Finder modificano solo il nome del file e il percorso del file visibile. Non aggiunge tag "Finder", commenti "Finder", metadati EXIF, metadati PDF o proprietà dei documenti Office. "Spotlight" può cercare il nuovo nome file, ma i metadati più profondi richiedono uno strumento separato.

### C'è un modo per annullare una ridenominazione batch su Mac?

Sì, se usi "Finder". Immediatamente dopo una ridenominazione batch, premere Cmd+Z per annullare l'intera operazione. Tutti i file ripristinano i nomi originali. Questo annullamento è disponibile solo come azione successiva. Se utilizzi gli script "Terminal", non è disponibile l'annullamento integrato, quindi prova sempre prima le copie o salva un elenco di nomi di file originali prima di eseguire lo script.

### Qual è il modo migliore per rinominare le foto con le date su Mac?

Per aggiungere la data di creazione del file come prefisso, l'azione di rinomina "Aggiungi data o ora" di Automator è l'opzione più semplice. Per aggiungere le date di acquisizione EXIF ​​dai metadati della fotocamera, utilizza uno script "Terminal" con "exiftool". Per aggiungere date e nomi di contenuto descrittivi, uno strumento di intelligenza artificiale come "Zush" può combinare modelli di date con l'analisi del contenuto.

### Come posso rinominare centinaia di screenshot su Mac?

Per le rinominazioni di base, come la sostituzione di "Screenshot" con il nome di un progetto, "Finder" lo gestisce in pochi secondi. Per assegnare a ogni screenshot un nome descrittivo in base a ciò che mostra, utilizza la ridenominazione AI. Seleziona tutti gli screenshot, lascia che l'intelligenza artificiale analizzi ogni immagine e ottieni nomi come "slack-design-review-thread.png" invece di "Screenshot 2026-02-08 at 10.45.33.png". Per rinominare automaticamente gli screenshot futuri, imposta il monitoraggio delle cartelle. Vedere "[Come rinominare automaticamente gli screenshot su Mac](/blog/rename-screenshots-automatically-mac)".

### Posso rinominare in batch i PDF in base al loro contenuto?

Sì, con gli strumenti di rinominazione AI. L'intelligenza artificiale legge il contenuto testuale di ciascun PDF e genera un nome file che riflette l'oggetto del documento. Una fattura scansionata denominata "scan_042.pdf" diventa "invoice-7842-webdesign-services-march-2026.pdf". Per una guida completa, vedere "[Come rinominare automaticamente i file PDF: flusso di lavoro AI per cartelle ripetute](/blog/rename-pdf-files-automatically)".

### La ridenominazione in batch influisce sui metadati dei file o sulle date di creazione?

Rinominare un file in "Finder" o tramite "Automator" non ne modifica la data di creazione, la data di modifica o i metadati interni. Il contenuto del file rimane identico. Cambia solo il nome del file nel filesystem. Tuttavia, alcuni servizi di sincronizzazione cloud potrebbero considerare una ridenominazione come un nuovo caricamento, quindi controlla lo stato di sincronizzazione dopo aver rinominato batch di grandi dimensioni nelle cartelle sincronizzate.

### Quale convenzione di denominazione dovrei utilizzare per i file rinominati in batch?

Utilizza lettere minuscole, trattini tra le parole e date in formato ISO (AAAA-MM-GG) quando è importante l'ordine cronologico. Evita spazi, caratteri speciali ed etichette vaghe come "final-v2". Una convenzione coerente rende i file ordinabili, ricercabili e trasferibili tra sistemi operativi.
