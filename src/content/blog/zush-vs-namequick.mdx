Zush runs on both Mac (macOS 15+) and Windows (10/11) and offers two PRO plans: $10/month or $48 one-time, both with unlimited PRO renames. BYOK remains available when you want to use your own AI provider key. Version 3.0 supports 100+ formats: 41 image formats including RAW, HEIC, AVIF, SVG, and TIFF; 4 design formats including Sketch, Figma .fig, Adobe Illustrator .ai, and PSD; 37 document and PDF-related formats including Office, iWork, OpenDocument, text, CSV/TSV, JSON, XML/YAML, EML, SRT, and VTT; 16 video formats including MP4, MOV, M4V, MPEG, 3GP, TS, MTS, M2TS, DV, and VOB; and 7 audio formats including MP3, M4A, WAV, FLAC, OGG, WebM, and MPGA.

For Mac users, there is also Offline AI mode via Ollama where files never leave the device.

## NameQuick

  <Fragment slot="pricing">Managed from $12/mo, metered at 500 / 2,000 / 5,000 / 10,000 renames per month; Self-Managed $69 one-time for 1 device with lifetime updates and BYOK; 14-day trial with 50 renames.</Fragment>

![NameQuick Mac app interface (image: namequick.app)](/images/blog/competitors/namequick.png)

NameQuick is a Mac-only AI file renamer with two distinct purchase paths. **Managed starts at $12/mo and is metered by volume** — the public tiers run 500, 2,000, 5,000, and 10,000 renames per month, so the plan you need is decided by how many files you actually process, not by which features you want. **Self-Managed is $69 one-time**, covers one device, includes lifetime updates, and is the BYOK/local-model path: you bring your own cloud API key or run a local model on your Mac and pay the provider directly.

Their AI provider menu is broader than most: OpenAI, OpenRouter, Claude, Gemini, Ollama, LM Studio, and MLX — seven public options, three of them local. The privacy story is strong: "EU-routed & encrypted" with "no permanent storage" and "data is never used to train AI" per their site.

Two things worth stating plainly, because comparison posts often get them wrong: NameQuick has **Watch Folders** for monitoring directories and **one-click Undo & Recovery** on any rename. Neither automation nor rollback is a Zush-only capability in this matchup.

The Rules Engine is one of NameQuick's distinct features — beyond renaming, it can move, tag, archive, and reorganize files automatically based on conditions you define.

For BYOK-heavy paths, Zush is cheaper at the one-time entry point. Zush's $48 One-Time plan includes the full PRO desktop workflow and Mac + Windows support, while NameQuick's Self-Managed path is $69, Mac-only, and limited to one device.

If you are choosing on platform and format coverage, Zush wins. NameQuick's value comes from things Zush intentionally does not chase as deeply: more AI provider options, a richer Rules Engine for file operations, and Mac-native polish.

## Format support

### RAW photos: Zush yes, NameQuick unclear

Zush publishes a complete RAW format list (CR2, CR3, NEF, ARW, DNG, ORF, RAF, RW2, PEF, SRW, SR2). NameQuick lists "30+ file formats" on their site but does not enumerate camera RAW formats specifically. If you shoot RAW, Zush is the safer pick.

### Office docs and OCR: both cover the common case

NameQuick advertises OCR for scanned docs and EXIF extraction for photos. Zush supports PDF, DOCX, XLSX, PPT, PPTX, TXT, MD, JSON, EML, CSV, DOC, plus iWork files such as Pages, Numbers, and Keynote. Both handle the everyday office formats.

### Audio / video / archives

NameQuick mentions audio, video, and archives as part of its 30+ formats. Zush 3.0 supports common video files, subtitle sidecars, design files, iWork documents, and audio files including MP3, M4A, WAV, FLAC, OGG, WebM, and MPGA. NameQuick is still broader if ZIP/archive renaming is central to your workflow.

## AI provider menu

NameQuick publicly lists seven AI backends: OpenAI, OpenRouter, Claude, Gemini, Ollama, LM Studio, and MLX. Zush supports 4 cloud providers: Gemini, Groq, OpenAI, and Claude — plus Ollama for the Offline AI mode.

The big differentiators:

- <BlogHighlight>Groq</BlogHighlight> — listed on Zush, not on NameQuick's public provider list.
- <BlogHighlight>OpenRouter</BlogHighlight> — only on NameQuick. OpenRouter aggregates 50+ models, useful if you want to test alternatives.

## Pick by use case

**Pick Zush if:**

- You need a Windows app, not just Mac
- You want one desktop workflow across Mac and Windows
- You shoot RAW photos and want explicit format support
- You rename design assets, iWork files, audio, videos, and documents in the same folders

**Pick NameQuick if:**

- You are Mac-only
- You want the richer AI provider menu (OpenRouter, LM Studio, and MLX)

- EU data routing matters for your compliance story

## Migration tip

If you are coming from NameQuick to Zush: install Zush, run the 5-file demo on a sample folder, then choose Monthly or One-Time PRO if it fits. If you were on the BYOK plan, you already have an API key — paste it into Zush's BYOK settings and continue with no API change.

If you are coming from Zush to NameQuick (rare, given pricing): if you need OpenRouter or LM Studio specifically, NameQuick adds those. Otherwise the migration mostly just costs more.

## FAQ

### Does NameQuick run on Windows?

No. NameQuick is macOS only. If you need a Windows app, Zush has one in the Microsoft Store.

### Is BYOK free in both tools?

In Zush, BYOK is included with paid PRO plans — no separate BYOK purchase. In NameQuick, the public Self-Managed plan is $69 one-time, after which you bring your own API key or local model.

### Does Zush support all NameQuick AI providers?

No. Zush supports 4 cloud providers (Gemini, Groq, OpenAI, Claude) plus Ollama for the Offline AI mode. NameQuick publicly lists OpenAI, OpenRouter, Claude, Gemini, Ollama, LM Studio, and MLX. If specific providers matter, especially OpenRouter, LM Studio, or MLX on Apple Silicon, NameQuick is broader.

### Does NameQuick support RAW photos?

NameQuick's public format list says "30+ formats" without enumerating RAW camera variants. Zush explicitly lists 11 RAW formats. Photographers who rely on RAW are safer with Zush.

### Which has better Mac integration?

Both tools integrate with Finder tags. NameQuick adds Finder Comments, the Rules Engine, and a global hotkey. Zush has Finder tags + Spotlight metadata + Offline AI via Ollama. NameQuick has the deeper macOS-native polish; Zush trades some Mac depth for cross-platform support.
