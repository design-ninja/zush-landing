## O que o File Juggler faz bem

O File Juggler é uma ferramenta de automação para Windows criada por um desenvolvedor independente na Dinamarca. Você monta regras a partir de três partes:

1. **Pastas monitoradas**, como Downloads, Área de Trabalho ou uma pasta de scanner.
2. **Condições**: nome e caminho do arquivo, texto dentro do arquivo, tamanho e data de criação ou modificação.
3. **Ações**: mover, copiar, renomear, alterar a extensão, excluir ou enviar para a Lixeira, extrair arquivos compactados, adicionar a um zip, executar um comando ou enviar para o Evernote.

Ele reage quase na hora porque assina as notificações de alteração de pastas em vez de fazer varreduras em intervalos. Consegue ler texto em arquivos PDF, Word e Excel e reaproveitar palavras e datas encontradas ali em um novo nome de arquivo. A versão 3.1.9 saiu em 30 de outubro de 2026, então ele não foi abandonado. Os editores do Softpedia dão 4,5/5 a ele, a mesma nota que dão ao Zush.

O preço é simples: $50 em pagamento único antes dos impostos no checkout, válido para todas as atualizações futuras. Uma licença cobre uma pessoa em vários PCs, ou um PC compartilhado por várias pessoas. O teste de 30 dias tem todos os recursos e, quando termina, o app lembra você de comprar, mas continua funcionando.

## Por que as pessoas procuram uma alternativa

- **Sem IA.** Toda regra precisa ser escrita à mão. Nenhuma regra captura `Screenshot 2026-10-02 141203.png` ou `IMG_4382.jpg`, porque nada no nome ou no texto diz o que o arquivo é.
- **Sem OCR.** O FAQ do File Juggler diz que digitalizações só de imagem não têm texto pesquisável, então você precisa de um programa de OCR separado antes que as regras de conteúdo consigam identificá-las.
- **Só para Windows.** Não existe versão para Mac. No Mac, o equivalente é o [Hazel](/hazel-alternative).
- **Não é um serviço.** Ele roda enquanto um usuário está conectado, então não serve bem para servidores.
- **O preço**, se você só precisa separar arquivos por tipo. Várias ferramentas gratuitas fazem isso.

## 1. Zush: para os arquivos que regras não conseguem descrever

O [Zush para Windows](/windows) roda no Windows 10 e 11 pela [Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X). Em vez de comparar condições, ele lê o arquivo: o texto de um PDF ou de uma digitalização, o conteúdo de uma foto ou captura de tela, os quadros, a fala e as legendas de um vídeo (MKV incluído). Depois sugere um nome como `2026-09-12_acme_invoice_1042.pdf` ou `stripe-revenue-dashboard-september.png`.

![Zush para Windows renomeando um lote misto pelo conteúdo, com cada nome de arquivo proposto exibido antes de o lote ser aplicado](/videos/windows/zush-batch-rename.mp4)

Onde o File Juggler precisa de uma regra por destino, o Zush aceita uma frase em **Folder rules**, como "Agrupe faturas por empresa e recibos por mês", ou agrupa os arquivos por conteúdo no modo Auto. Você revisa os nomes e as pastas sugeridos juntos antes que qualquer coisa seja movida. Confira os arquivos ambíguos antes de aplicar.

![Zush para Windows mostrando a prévia dos grupos de pastas por conteúdo e dos nomes de arquivo propostos antes de Rename & sort](/images/showcase/windows/folder-sorting-light.webp)

Para a parte sempre ativa do File Juggler, salve a configuração em um Template e atribua-o ao **Monitor**. Os novos arquivos em Downloads ou em uma pasta de scanner passam a ser renomeados e organizados assim que chegam. O Rename History guarda os nomes antigos e novos mesmo depois de reiniciar, e o Undo All reverte um lote inteiro e lista os conflitos que houver. O AI Rename também detecta downloads duplicados e os move para a Lixeira; as cópias não gastam créditos, e o Undo as restaura.

Ele funciona na hora: as primeiras 50 renomeações com IA rodam no Zush Cloud AI gerenciado, sem conta, cartão, chave de API ou download de modelo. Para arquivos que devem ficar no PC, mude para Ollama ou LM Studio, ou use sua própria chave de API.

![Aba Monitor do Zush para Windows observando as pastas Screenshots e Downloads e renomeando novos arquivos assim que chegam](/images/showcase/windows/monitor-light.webp)

Escolha o Zush quando sua lista de regras não para de crescer e ainda assim deixa arquivos de fora. Passo a passo: [organize arquivos em pastas com IA no Windows](/blog/sort-files-into-folders-with-ai-windows) e [30 regras de pasta prontas](/blog/ai-folder-sorting-prompts).

## 2. DropIt: o mecanismo de regras gratuito

O DropIt é gratuito e de código aberto. As regras identificam arquivos por nome, tamanho, data, propriedades ou expressões regulares, e 21 ações cobrem mover, copiar, renomear, compactar, extrair e mais. Você arrasta os arquivos para um alvo flutuante ou deixa o programa varrer pastas monitoradas em intervalos.

Ponto fraco: a versão mais recente, 8.5.1, é de fevereiro de 2018. Ainda funciona, mas não espere recursos novos nem IA.

Escolha o DropIt quando você só precisa de "PDFs vão para cá, imagens vão para lá" e pagar não é uma opção.

## 3. Sortio: planos com IA e regras por baixo

O Sortio mistura as duas abordagens. Você pode escrever regras clássicas ou descrever a organização em linguagem natural, revisar um plano e então deixar que ele renomeie, crie pastas e mova os arquivos. As Smart Folders continuam aplicando o plano ao que chega depois. Ele roda no Windows, no macOS e no Linux.

O plano gratuito inclui organização por regras com até cinco regras e três Spaces, prévia, histórico, desfazer e um teste único de IA. Pastas monitoradas e automações exigem o Pro, a $14.99 por mês ou $99 por ano, com uma cota mensal de IA. Com Ollama o processamento fica local, e o login é feito com uma conta de e-mail.

Escolha o Sortio se você quer regras no estilo do File Juggler e IA em um só app, ou se precisa de Linux. Ponto fraco: a parte sempre ativa é exclusiva do Pro. Veja a comparação detalhada: [Zush vs Sortio](/blog/zush-vs-sortio).

## 4. Wisfile: limpeza gratuita de documentos com IA

O Wisfile é gratuito, roda localmente no Mac e no Windows e renomeia documentos pelo conteúdo com modelos como `Author-Year-Title`. Também consegue agrupar um lote em pastas por assunto. O FAQ dele lista Word e PDF como formatos suportados.

Não há monitoramento de pastas nem agendamento: você arrasta os arquivos e executa a cada vez. O FAQ também diz que não existe desfazer embutido, então teste primeiro em cópias.

Escolha o Wisfile para uma limpeza única de um arquivo de papéis ou documentos. Veja [Zush vs Wisfile](/blog/zush-vs-wisfile) para uma análise mais próxima.

## 5. PowerShell e Agendador de Tarefas: o caminho faça você mesmo

O Windows dá conta de tarefas básicas do File Juggler sem software extra. O PowerShell move e renomeia arquivos; o Agendador de Tarefas executa o script no login ou a cada poucos minutos:

```powershell
Get-ChildItem "$env:USERPROFILE\Downloads" -Filter *.pdf |
  Move-Item -Destination "$env:USERPROFILE\Documents\PDFs"
```

É gratuito e tão flexível quanto o seu script. Em compensação, nomes duplicados, arquivos bloqueados, registro e desfazer ficam por sua conta. Mais opções: [como organizar a pasta Downloads no Windows](/blog/organize-downloads-folder-windows).

## Manter o File Juggler ou trocar?

- Seus arquivos seguem padrões fixos (mesmo banco, mesmo layout, mesmo prefixo no nome): **fique com o File Juggler**.
- Capturas de tela, digitalizações, fotos do celular e downloads aleatórios com nomes sem sentido: **Zush**.
- Organização gratuita por extensão ou nome: **DropIt** ou **PowerShell**.
- Regras e IA na mesma ferramenta, ou Linux: **Sortio**.
- Uma passada única e gratuita em PDFs e arquivos do Word: **Wisfile**.

Você também pode usar os dois. O Zush monitora Downloads e escreve nomes previsíveis como `2026-10-02_acme_invoice.pdf`, e o File Juggler move `*_invoice.pdf` para uma pasta fixa de Finanças. Cada ferramenta faz a parte em que é boa. Teste qualquer configuração primeiro em cópias; nosso checklist sobre [como renomear arquivos em lote com segurança](/blog/how-to-safely-batch-rename-files) mostra o que conferir.

## Perguntas frequentes

### Existe uma alternativa gratuita ao File Juggler?

Sim. O DropIt é gratuito e de código aberto, mas a última versão é de fevereiro de 2018. O plano gratuito do Sortio inclui até cinco regras, embora as pastas monitoradas exijam o Pro. PowerShell com o Agendador de Tarefas é gratuito se você sabe escrever scripts. O Wisfile é gratuito para arquivos PDF e Word. O Zush inclui 50 renomeações com IA grátis, sem conta nem cartão, se o seu problema são nomes de arquivo que não dizem nada.

### O File Juggler ainda recebe manutenção?

Sim. A versão 3.1.9 saiu em 30 de outubro de 2026, segundo a página de novidades do próprio File Juggler, e a licença inclui todas as atualizações futuras. Isso faz dele um dos poucos organizadores por regras para Windows que ainda recebem atualizações regulares. O DropIt, a principal alternativa gratuita, não tem uma versão nova desde fevereiro de 2018.

### O File Juggler usa IA?

Não. Ele compara condições que você escreve, incluindo palavras encontradas dentro de arquivos PDF, Word e Excel, e pode reaproveitar datas que encontra no texto. Não consegue ler digitalizações só de imagem sem um programa de OCR separado, nem dizer o que uma foto ou captura de tela mostra. Para esses arquivos você precisa de uma ferramenta de IA como Zush, Sortio ou Wisfile.

### O File Juggler por $50 vale a pena em comparação com o Zush por $48?

Eles compram coisas diferentes. Os $50 mais impostos do File Juggler dão um mecanismo de regras com todas as atualizações futuras, mas sem IA. A licença única de $48 do Zush inclui nomes com IA e organização em pastas com o Zush Cloud AI gerenciado, modos local e BYOK, renomeações ilimitadas, todas as atualizações futuras e até 3 dispositivos entre Windows e Mac. Muita gente usa os dois.

### O Zush ou o File Juggler enviam meus arquivos para algum lugar?

O File Juggler executa as regras localmente. No Zush, depende do modo escolhido: com Ollama ou LM Studio, a análise fica no seu PC; com o Zush Cloud AI ou sua própria chave de API, o conteúdo do arquivo é enviado a esse modelo na nuvem para gerar um nome. Escolha um modo local para pastas confidenciais e confira também a configuração do Sortio, que oferece IA hospedada, BYOK ou Ollama.

### Existe File Juggler para Mac?

Não, o File Juggler é só para Windows. O Hazel é o equivalente mais próximo no Mac para regras, e os editores do Softpedia dão 5,0/5 a ele. O Zush para Mac cobre nomes com IA e organização em pastas, incluindo pastas monitoradas em discos externos. Veja nossa página de [alternativa ao Hazel](/hazel-alternative) para comparar as duas abordagens no Mac.

### O Zush substitui o File Juggler por completo?

Para nomear arquivos pelo conteúdo e organizá-los em pastas, sim, inclusive em pastas monitoradas. O File Juggler ainda tem ações que o Zush não oferece, como executar um comando, extrair arquivos compactados ou enviar para o Evernote. Se você depende delas, mantenha o File Juggler para essa parte e deixe o Zush escrever os nomes descritivos que as regras dele conseguem identificar.
