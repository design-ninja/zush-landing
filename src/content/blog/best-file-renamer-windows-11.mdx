## 1. File Explorer: fine for five files

Select several files, press **F2**, type a name, press Enter. Windows names them `Trip (1).jpg`, `Trip (2).jpg`, and so on. **Ctrl+Z** undoes it right away.

That is all it does. No preview, no dates, no find-and-replace. Use it when the result only needs to be tidy, not meaningful.

## 2. PowerRename: the best free pick for most people

[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename) comes with Microsoft PowerToys. Select files, right-click, choose **Rename with PowerRename**, and you get search and replace with a live preview.

It handles more than it looks like:

- Regular expressions, including capture groups (`29-03-2020` → `2020-03-29`)
- Counters with padding and start values (`Image_${padding=4}`)
- File creation date variables like `$YYYY-$MM-$DD`
- Photo EXIF and XMP tokens such as `$DATE_TAKEN_YYYY` and `$CAMERA_MODEL`

Ctrl+Z undoes the last rename. It has no AI and never opens the file, so it can't tell what a scan or screenshot shows. Pick PowerRename for any job you can describe as a pattern. For the AI side, see our [PowerRename alternative](/windows) page.

## 3. Bulk Rename Utility: maximum control

Bulk Rename Utility packs every pattern option into one dense window: regex, JavaScript, auto-numbering, EXIF dates, MP3 tags, CSV-driven renames, and timestamp changes. It handles 100,000+ files without slowing down. Undo works by generating a batch file that reverses the change.

It is free for personal use, but JavaScript renaming needs a paid license ($24.95), and commercial use costs $92.95 per computer. Version 4.1.0.1 added an AI assistant that writes JavaScript and regex rules for you; it helps build the pattern but does not read file content. The interface takes some getting used to. More in our [Bulk Rename Utility alternatives](/blog/bulk-rename-utility-alternatives) guide.

## 4. Advanced Renamer: best for photos and music metadata

Advanced Renamer builds a name from stacked methods: tags from EXIF, ID3, video properties, and GPS (it can turn coordinates into a city name). It shows a live preview and can undo a full batch. It also runs on macOS. Version 4.28 is current, and its scripting method can extract text from PDF and TXT files, but there is no AI or OCR: scanned PDFs and photos stay unreadable, and you write the script that turns text into a name.

It is free for light personal use. Regular users are asked to buy a $30 personal license, and work use requires a $50 commercial one. Both are one-time. See our [Advanced Renamer review](/blog/advanced-renamer-alternatives).

## 5. ReNamer: rules and scripts

ReNamer applies an ordered list of rules: insert, delete, replace, case, regex, meta tags, and Pascal Script for anything custom. It is portable and supports 25+ interface languages.

ReNamer Lite is free for non-commercial use, limited to 5 rules and 5 presets. Pro removes those limits and allows commercial use.

### Sort the renamed files into folders

On Windows, Zush can also **sort files into folders with AI**. Choose **Auto** grouping or write **Folder rules** such as “Group invoices by company and receipts by month.” Review the suggested folder groups alongside the filenames; a pattern renamer is still sufficient when all you need is the same text change across a batch.

Choose a **Destination folder**, or keep the source folder as the root. Enable **Reuse existing folders** to prefer suitable folders already there; Zush can create a new one when nothing fits. In a manual batch, review both the suggested names and folders before applying. To rename in place, leave sorting off and keep the original destination.

Save the sorting settings in a **Template** and assign it to **Monitor** for new files directly inside the watched folder. Changing the Monitor Template does not automatically reorganize files already processed. Test the Template in a manual batch first. See the [folder sorting guide](/docs/folder-sorting) for the setup and monitoring scope.

Zush also supports nested folder rules, such as grouping by year and then month. You can sort already renamed files without changing their names again or spending another rename credit. Review the destinations before applying. This separate action handles an existing batch; changing a Monitor Template does not retroactively reorganize it. - Same change for every file (prefix, date, number): **PowerRename**.
- Complex patterns on huge folders: **Bulk Rename Utility**.
- Names from photo, music, or GPS metadata: **Advanced Renamer**.
- Screenshots, scans, downloads, and photos that need real names: **Zush**.

Plenty of people keep both kinds. PowerRename for quick mechanical fixes, Zush for the folders where you currently open every file to see what it is.

## FAQ

### Can Zush rename video and music files on Windows 11?

Yes. Zush for Windows names videos from speech, embedded subtitles and metadata, including MKV, and can identify music even when a track has no tags, a feature that is Windows-only for now. For offline work, you can download optional on-device speech recognition from AI settings and use it with Ollama or LM Studio. Pattern tools such as PowerRename only change names by rule, so they can't tell what a recording contains.

### What is the best free file renamer for Windows 11?

PowerRename, part of Microsoft PowerToys. It is free, previews every change, supports regex, counters, date variables and EXIF/XMP tokens, and undoes with Ctrl+Z. For heavier personal jobs, Bulk Rename Utility is free too, though JavaScript renaming needs a paid license. Advanced Renamer is free for light personal use. None of them read file content; for that, Zush gives 50 free AI renames with no account.

### Does Windows 11 have a built-in bulk rename?

Yes, but a basic one. Select files in File Explorer and press F2 to give them one name with numbers in brackets. For find-and-replace or dates, install PowerToys and use PowerRename.

### Can a file renamer read what is inside my files?

Pattern tools mostly cannot. They read the existing name and metadata fields like EXIF or ID3. Advanced Renamer can extract text from PDF and TXT files through scripts, but it has no AI or OCR, so scans and photos stay unreadable. AI renamers such as Zush read the content itself (text, images, speech and frames in video) and propose a new descriptive name you review before applying.

### Which file renamer is safest?

Any tool with a preview and a batch undo. PowerRename, Advanced Renamer, and Zush all show results before applying. Zush also keeps a persistent Rename History, so you can revert a batch days later, not just right after.

### Is Zush worth paying for if PowerRename is free?

Only if your files need names based on their content. PowerRename is the right tool for uniform pattern changes and costs nothing. If you open screenshots, scans or downloads to see what they are before naming them, Zush does that reading for you. Its $48 one-time license includes managed cloud AI with unlimited renames, BYOK and local models, all future updates, 3 devices and a 14-day refund.

### Where does Zush process my files on Windows?

It depends on the mode. Zush Cloud AI and BYOK send file content to an AI service to generate a name; BYOK uses your own provider account. With Ollama or LM Studio, analysis runs on your PC, and on-device speech recognition is available for video. PowerRename, Bulk Rename Utility and Advanced Renamer never send files anywhere because they don't analyze content. See the [offline AI file renamer](/offline-ai-file-renamer).
