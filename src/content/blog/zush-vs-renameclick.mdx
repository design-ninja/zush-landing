## Why choose Zush for a mixed archive?

A client folder often contains an invoice PDF, a camera RAW, a Figma design, a Pages brief, a recording, and a voice memo. Zush’s [supported-format list](/docs/supported-file-types) explicitly covers these categories. RenameClick’s list excludes video and does not list RAW, design, or iWork formats. An unlisted format is a reason to verify support, not proof that every such file fails.

![Zush on Mac previewing descriptive names for mixed files before applying a batch](/images/showcase/macos/batch-rename-light.webp)

Zush can use speech, embedded subtitles, and metadata for video naming, including supported MKV files. Windows 3.16 adds Cloud AI identification of untagged music using a matching title and artist. That music feature is documented for Windows Cloud AI; do not assume the same recognition on Mac or with every local model. Check the proposed name before applying it.

A supported extension does not guarantee that every codec, encrypted document, or damaged file can be read. Try representative copies during the free allowance.

## Naming control: compare the fields you actually need

Both products now offer visual naming controls. RenameClick 3.1 has a parts editor and live preview, so a pattern builder is no longer a useful exclusive claim for Zush.

Zush’s reason to be on your shortlist is the combination of ready-made Templates, [145+ Naming Blocks](/docs/naming-blocks), and [Custom AI Blocks](/docs/custom-ai-blocks). You can put a supplier, document date, invoice number, and title in a fixed order instead of asking AI to invent the whole filename. Set case, separators, and language once, then reuse the Template for a batch or monitored folder.

The **Sequence Number** block adds a custom starting number and leading zeros, with a separate sequence in each folder. This is useful for client deliverables and numbered archives. RenameClick also has configurable counters; compare the behavior across destination folders rather than treating numbering itself as unique.

## Recovery: what happens after a rename?

Zush’s [Rename History](/docs/undo-history) retains original and new names, folders, and timestamps. **Undo All** shows restored files and files needing attention, and offers restoration under a new name when the original location is occupied. This matters if another file has arrived since the rename: inspect the result instead of assuming the entire batch was restored.

RenameClick’s normal Rename workspace keeps up to 10 undo entries in memory and clears them on restart. Auto Flow has separate persistent records for eligible applied operations. Zush is the stronger documented fit when you need persistent recovery for manual batches, not just automation records.

## Folder sorting and monitoring

Zush can sort with Auto grouping or a rule such as “Group invoices by company and receipts by month.” [Folder rules](/docs/folder-sorting) choose destinations; Naming Blocks control filenames. Keep current names when they already contain approved identifiers. Both AI Rename and Monitor support this mode on Mac and Windows.

RenameClick supports editable folder sets and existing nested folders. It can also sort without renaming. The earlier “50 top-level folders” description does not describe the current workflow. Auto Flow and AI Search are legitimate reasons to test RenameClick if those workspaces fit your needs.

For Zush, test a Template in a reviewed batch before assigning it to Monitor. Changes affect new arrivals, not files processed earlier. Mac 3.20 supports external-drive monitoring after reconnection; Windows 3.16 handles safe-removal requests and resumes watching if removal is cancelled.

At published list prices, RenameClick’s $36 + VAT lifetime license is cheaper before tax than Zush’s $48 one-time license. ## Which should you choose?

Start with **Zush** if you need mixed RAW, design, document, video, and audio files in one workflow; recurring names built from explicit fields; persistent manual-batch recovery; and included managed cloud AI without a monthly file allowance.

Consider **RenameClick** if dedicated content search, its bundled local model, editable folder sets, or the recurring free allowance matters more to you. Confirm your specialist formats and the recovery behavior of the workspace you will actually use.

Before switching, copy ten representative files into a test folder. Compare extracted details, naming consistency, destination previews, and restoring a batch after restarting the app. That test is more useful than an unsupported claim that one model is always more accurate.

## FAQ

### Is Zush a good RenameClick alternative?

Yes, especially for mixed Mac and Windows archives that include RAW photos, design files, iWork documents, and video. Zush adds a documented field-based naming system, per-folder sequence numbers, and persistent Rename History with conflict handling. Its $48 one-time PRO plan includes managed cloud AI and unlimited app renames.

### Does RenameClick have a visual naming editor?

Yes. Version 3.1 lets you build formats from parts and preview names before saving. Zush also has visual Naming Blocks; choose by required fields, reusable Templates, format coverage, and recovery rather than assuming RenameClick lacks an editor.

### Can both apps sort without changing filenames?

Yes. Zush supports keeping current names in AI Rename and Monitor. RenameClick allows sorting with Rename disabled. Test the folder plan on copies, especially when reusing an existing archive.

### Does RenameClick support video and audio?

Its documentation supports common audio formats with local speech transcription and explicitly excludes video. Zush supports video and audio, subject to readable content and codecs. See [Zush media support](/docs/supported-file-types#video-and-audio).

### Do both support OpenRouter and offline AI?

Yes. RenameClick’s direct Mac and Windows builds accept OpenAI-compatible APIs, including OpenRouter; the Mac App Store build excludes cloud providers. Zush offers OpenRouter through BYOK and local AI through LM Studio or Ollama. Downloads and setup are needed before offline use; external API usage is billed separately.
