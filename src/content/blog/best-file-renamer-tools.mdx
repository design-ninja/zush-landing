## Class 1: built-in and free pattern renamers

### Finder rename (Mac)

Select files, right-click, choose **Rename**: replace text, add text, or name and number. No install needed. There is no regex, no metadata and no content reading. The [Mac batch rename guide](/blog/batch-rename-files-on-mac-complete-guide) covers Finder alongside Automator and Terminal.

**Choose it if** one rule fixes every file. **Weakness:** no regex or metadata at all.

### PowerRename (Windows)

Part of Microsoft PowerToys. Right-click a selection for search and replace with regex, counters, creation-date variables and photo EXIF/XMP tokens, with a live preview. Ctrl+Z undoes the rename. It has no AI and does not read file content. More on the [Zush for Windows](/windows) page, which compares the two.

**Choose it if** you can describe the change as a pattern. **Weakness:** it can't name `scan_004.pdf` by what the scan shows.

### Bulk Rename Utility (Windows)

BRU stacks rules for prefixes, numbering, case, regex, EXIF and ID3 tags in one dense window. It is free for personal use. JavaScript renaming needs a paid license ($24.95), and commercial use costs $92.95 per computer. Version 4.1.0.1 added an AI assistant that writes JavaScript and regex for you; it still does not read file content. There is no Mac version. See our [Bulk Rename Utility alternatives](/blog/bulk-rename-utility-alternatives).

**Choose it if** you run complex mechanical rules over very large folders. **Weakness:** the interface is dense, and business use is priced per computer.

## Class 2: metadata renamers

**Advanced Renamer** and **A Better Finder Rename** build names from EXIF dates, GPS coordinates, ID3 tags and file dates. Advanced Renamer (version 4.28) can also pull text out of PDF and TXT files through its scripting method, but it has no AI or OCR, so scanned PDFs and images stay unreadable and you write the logic that turns extracted text into a name. It is free for light personal use; regular users are asked to buy a $30 personal license, and work use needs a $50 commercial one. A Better Finder Rename is $29.95 for Mac.

The limit is that metadata describes *when* and *with what*, not *what*. A photo's EXIF says when it was shot, not that it shows a golden retriever in a park. Our [Advanced Renamer alternatives](/blog/advanced-renamer-alternatives) review maps where those rules run out.

**Choose them if** the full name you want already sits in EXIF, GPS or tags. **Weakness:** no understanding of images or scanned documents.

## FAQ

### What is the best free file renamer?

For pattern jobs, Finder on Mac and PowerRename on Windows are free and preview every change. Bulk Rename Utility is free for personal use, and Advanced Renamer is free for light personal use. For names based on file content, Zush gives 50 free AI renames with no account, card or API key, using the same preview and Rename History as the paid version. ### Can a file renamer name files based on what's inside them?

Only AI renamers do this properly. Pattern tools rearrange the existing name; metadata tools read EXIF or ID3 tags. Advanced Renamer can extract text from PDF and TXT files through scripts, but it has no AI or OCR, so scans and images stay unreadable. An AI renamer such as Zush reads text, images, audio and video, including scans without a text layer, and proposes a name you review first.

### Is an AI file renamer worth paying for?

If your renaming is mechanical, no: free pattern tools do the job. If you regularly open files to see what they are, yes. Zush's $48 one-time license includes managed cloud AI with unlimited renames, plus BYOK and local models, all future updates, up to 3 devices across Mac and Windows, and a 14-day refund. Try the 50 free renames on copies first.

### Where does Zush process my files?

That depends on the mode you choose. Zush Cloud AI and BYOK send file content to an AI service to generate names; BYOK uses your own provider account. With Ollama or LM Studio, analysis runs on your own computer and files stay there. Pattern tools like Finder, PowerRename and Bulk Rename Utility never read content, so nothing leaves your machine.
