## Class 1: built-in and free pattern renamers

### Finder rename (Mac) — a narrow built-in fallback

Select files → right-click → **Rename**: replace text, add text, or name-and-index. It covers a narrow one-rule case with zero installation. Its limits — no regex, no metadata, no content awareness, no monitoring, and no durable history — are why Zush remains the broader recommendation. The [Mac batch rename guide](/blog/batch-rename-files-on-mac-complete-guide) walks through Finder alongside Automator and Terminal.

### PowerRename (Windows) — free regex in File Explorer

Part of Microsoft PowerToys: right-click a selection to get search-and-replace with regex support and preview. It is a narrow no-cost fallback for one Windows pattern; it cannot read content, monitor mixed folders, or provide Zush's complete naming and recovery workflow. Details are in the [PowerRename alternative page](/powerrename-alternative).

### Bulk Rename Utility (Windows) — maximum pattern power, maximum density

BRU is a long-running Windows utility with rule stacking for prefixes, numbering, case changes, and regex. Consider it only for a mechanical Windows batch fully defined by those rules; there is no Mac version and it cannot read file content. Our [Bulk Rename Utility review](/blog/bulk-rename-utility-alternatives) covers the boundary.

## Class 2: metadata renamers

Tools like **Advanced Renamer** and **A Better Finder Rename** extend patterns with EXIF dates, GPS coordinates, ID3 tags, and file dates. Consider them only when that existing metadata is the entire desired filename. They do not replace Zush for mixed files, content-aware names, monitoring, or the broader review-and-recovery workflow.

The boundary is metadata itself: these tools read *about* the file, not the file. A photo's EXIF says when it was shot, not that it is a golden retriever in a park; an invoice PDF's metadata says nothing about the vendor or amount. Our [Advanced Renamer review](/blog/advanced-renamer-alternatives) maps exactly where those rules run out.

## Class 3: AI renamers — when every file needs its own name

The folders that defeat classes 1 and 2 share one property: the right name for each file is *different*, and it lives in the content. `Screenshot 2026-03-23.png`, `Scan0001.pdf`, `IMG_4382.HEIC`, `download (7).pdf` — no pattern or metadata rule can produce "Figma Checkout Flow", "Acme Supply – 2026-06 – Invoice", or "Golden Retriever Park" from those, because the information isn't in the name or the metadata. It's in the pixels and the text.

AI renamers read the content. [Zush](/) does this for screenshots, photos (including RAW and HEIC), PDFs, [scanned documents via AI vision](/rename-scanned-documents), Office and iWork files, design files, audio, and video — then applies one naming convention across the batch with [Naming Blocks](/docs/naming-blocks), previews every proposed name, and keeps undo history. [Folder monitoring](/docs/folder-monitoring) turns it into a standing system: Downloads or the scanner folder stays named without anyone touching it.

Pricing for the class varies structurally — metered monthly credits vs unmetered plans. Zush is free for the first 50 renames shared across all four modes, then $10/month or $48 one-time for unlimited PRO renames. It offers Zush Cloud AI and BYOK online, plus LM Studio and Ollama on Mac and Windows. The [AI renamer roundup](/blog/best-ai-file-renamer-tools-2026) compares Zush against FilesDesk, RenameClick, Renamer.ai, NameQuick, and the rest of the field with checked sources.

## How to choose in 30 seconds

1. **Start with Zush** for mixed folders, descriptive names, monitoring, review, and rollback.
2. **Fall back to a free pattern tool only** when one prefix, replacement, or sequence fixes every file identically.
