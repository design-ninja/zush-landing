## How AI file sorters decide where a file goes

Every sorter needs a rule for choosing the folder. There are three kinds:

| Approach | You provide | Example | Who uses it |
|---|---|---|---|
| **Prompt** | A sentence describing the folders | "Group invoices by company and receipts by month" | Zush, Sortio, Sparkle |
| **Category list** | Folder names the AI picks from | Invoices, Receipts, Contracts, Other | RenameClick, AI File Sorter |
| **Conditions** | If/then rules on name, date, or text | If name contains "invoice", move to Finance | Hazel, NameQuick Rules, File Juggler, DropIt |

A prompt is the most flexible because the folders can be created from what the files contain: one folder per supplier, per client, per month, or per subject. A category list is predictable but you must maintain it. Conditions are exact but break when a file does not match the pattern you expected.

## 1. Zush: best overall AI file sorter

[Zush](/ai-file-sorter) combines two jobs in one reviewed batch: it names each file by its content and sorts it into a folder. You decide how the folders work in **Folder rules**, a plain-language field that accepts up to 2,000 characters. Leave it empty and Auto groups files by content into a few broad, reusable folders.

What makes Zush different:

- **It reads more kinds of files.** Zush understands PDFs and image-only scans, photos including RAW and HEIC, screenshots, Office and iWork documents, design files, 16 video formats, and audio. "Group videos by topic" works because Zush looks at video frames, not just the filename.
- **Names and folders are planned together.** Your Template sets the filename (date, vendor, amount, client, subject), Folder rules set the location. You see both before anything moves.
- **It files into folders you already have.** With **Reuse existing folders** on, Zush matches files to suitable existing folders and creates a new one only when nothing fits.
- **It keeps sorting new files.** Save the rules in a Template, assign it to Monitor, and new downloads or scans are renamed and sorted as they arrive. Monitor remembers the folders it created.
- **Sorting can run offline.** With LM Studio or Ollama, both analysis and folder planning stay on your computer.
- **Unmetered pricing.** PRO is $10 a month or $48 one-time, with no monthly file cap, including the managed Zush Cloud AI.

Limits to know: folder sorting is labeled beta, and each batch creates one level of folders inside the destination you pick. Review ambiguous files before applying. Step-by-step setup: the [Mac guide](/blog/sort-files-into-folders-with-ai-mac) and the [Windows guide](/blog/sort-files-into-folders-with-ai-windows).

## 2. Sortio: closest alternative, plus Linux

[Sortio](https://www.getsortio.com/) is also prompt-driven: you describe the organization in plain English, it builds a plan, renames files, creates folders, and routes files. It can restrict sorting to a list of existing folders and send unmatched files to a fallback folder. It runs on macOS, Windows, and Linux.

The free plan includes unlimited rule-based sorting with up to five rules, watch folders, undo, and a one-time AI trial. Pro is $14.99 per month or $99 per year with a monthly AI allowance; BYOK and Ollama are available on every plan. Its site describes reading documents, images, PDFs, and spreadsheets, but it does not publish a full format list.

Choose Sortio if you need Linux or team seats. Choose Zush for video and audio sorting, deeper filename control, and a one-time price. Full breakdown: [Zush vs Sortio](/blog/zush-vs-sortio).

## 3. RenameClick: sort into categories you define

[RenameClick](https://rename.click/) offers three sorting methods: **AI Categories**, where the AI picks from a preset list of category names you write; **Metadata Folders** built from dates or EXIF fields; and **Match Folders**, which chooses among up to 50 existing top-level folders. Auto Flow watches a folder and moves or copies files while the app is running.

The free plan includes unlimited analysis and 100 successful renames or moves a month. Pro was $8 plus VAT per month or $36 plus VAT lifetime when checked. RenameClick bundles a local model, which is convenient offline. Video, RAW, and design files are not in its published format list.

Choose RenameClick if your categories are fixed and known in advance. Choose Zush if you want to describe the grouping ("by supplier", "by month") and let folders be created from the content. See [Zush vs RenameClick](/blog/zush-vs-renameclick).

## 4. Sparkle: hands-off cleanup for a Mac

[Sparkle](https://makeitsparkle.co/) organizes Desktop, Downloads, Documents, and other folders on a schedule. It builds an AI Library of folders from patterns in your files, accepts natural-language requests, and also cleans up duplicates and old screenshots. Deleted items go to the Trash first.

It is Mac only. The marketing page lists plans from $9.25 a month and the plans page showed $119 a year when checked; Sparkle is also included in the Every bundle. Sparkle does not rename files.

Choose Sparkle for set-and-forget cleanup of a personal Mac. Choose Zush when filenames matter too, when you work on Windows, or when you want the folder logic spelled out. See [Sparkle alternatives](/blog/sparkle-alternatives).

## 5. NameQuick: rules after renaming

[NameQuick](https://www.namequick.app/) renames documents by content and then runs conditional Rules that can move a file into a folder, add tags, set a color label, or archive it. That makes it strong for predictable document workflows on a Mac.

Managed plans start at $12 a month for 500 renames and meter usage; the $69 Self-Managed license needs your own API key or local model. Sorting is condition-based, so each destination needs a rule.

Choose NameQuick if you want if/then routing after AI naming. See [Zush vs NameQuick](/blog/zush-vs-namequick).

## 6. AI File Sorter: free and open source

[AI File Sorter](https://github.com/hyperfield/ai-file-sorter) is a free, AGPL-licensed desktop app for Windows, macOS, and Linux. It suggests categories and optional subcategories for each file, supports whitelists of allowed categories, reads images with a local vision model and extracts text from documents, and can suggest new filenames. It runs on local models or your own API key and has an undo for the last run.

There is no free-text prompt for the grouping and no watch folder. Audio and video are classified from embedded metadata rather than content.

Choose AI File Sorter for a free, one-off cleanup when you are comfortable setting up a local model.

## 7. Hazel, File Juggler, and DropIt: rules without AI

[Hazel](https://www.noodlesoft.com/) ($42, Mac), [File Juggler](https://www.filejuggler.com/) (about $40, Windows), and [DropIt](https://www.dropitproject.com/) (free, Windows) watch folders and act on conditions: name patterns, extensions, dates, or matched text. They are reliable when files are predictable.

They do not understand what a photo, scan, or video shows, so every case needs its own rule. Many people pair them with an AI renamer: descriptive names make rules easier to write. Or replace the rule set with one Zush prompt. See the [Hazel alternative](/hazel-alternative) page and [Hazel for Windows alternatives](/blog/hazel-for-windows-alternatives).

## Test any sorter on 20 files first

1. Copy 20 mixed files into a test folder: invoices, receipts, photos, a screenshot, a scan, a video.
2. Write one rule you actually need, for example "Group invoices by company and receipts by month."
3. Check the plan: are folder names consistent, and did every file land where you expected?
4. Apply, then try undo.
5. Only then point the sorter at Downloads or a real archive.

## FAQ

### What is the best AI file sorter?

Zush is the best AI file sorter for most people on Mac and Windows. You describe the folders in plain language or use Auto, and Zush reads each file, renames it, and moves it into the right folder after you review the batch. It handles PDFs, scans, photos, video, and audio, works with local AI, and PRO has no monthly file meter.

### Can AI sort files into folders automatically?

Yes. Zush, Sortio, RenameClick, and Sparkle can all move files into folders based on content. In Zush, save your Folder rules in a Template and assign it to Monitor: every new file in that folder is renamed and sorted as it arrives.

### Is there a free AI file sorter?

AI File Sorter is free and open source. Zush includes 50 free AI renames, which covers a real test of folder sorting. Sortio has a one-time AI trial, and RenameClick includes 100 free renames or moves a month.

### Which AI file sorter works offline?

Zush sorts offline with LM Studio or Ollama on Mac and Windows: both file analysis and folder planning run on your computer. RenameClick bundles a local model, Sortio supports Ollama, and AI File Sorter runs on local models.

### What is the difference between an AI file sorter and a rules-based organizer?

A rules-based organizer such as Hazel or DropIt moves files that match conditions you write, like a filename pattern or extension. An AI file sorter such as Zush reads what the file contains and follows an instruction like "group invoices by company," so it can sort files whose names give no clue.
