## File Jugglerの優れている点

File Jugglerは、デンマークの個人開発者が作ったWindows用の自動化ツールです。ルールは次の3つの要素で作ります。

1. **監視するフォルダ**：ダウンロード、デスクトップ、スキャナーの保存先など。
2. **条件**：ファイル名とパス、ファイル内のテキスト、サイズ、作成日または更新日。
3. **アクション**：移動、コピー、名前の変更、拡張子の変更、削除またはごみ箱へ送る、アーカイブの展開、zipへの追加、コマンドの実行、Evernoteへのアップロード。

タイマーで定期的にスキャンするのではなく、フォルダの変更通知を受け取る仕組みなので、ほぼ即座に反応します。PDF、Word、Excelファイル内のテキストを読み取り、見つけた単語や日付を新しいファイル名に使うこともできます。バージョン3.1.9は2026年10月30日にリリースされており、開発が止まったツールではありません。Softpediaの編集部は5点満点中4.5点と評価しており、Zushと同じスコアです。

価格はシンプルで、購入時に税別の買い切り$50。今後のアップグレードもすべて含まれます。ライセンス1つで、1人が複数のPCで使うことも、1台のPCを複数人で共有することもできます。30日間の試用版は全機能が使え、期間が終わると購入を促す表示は出ますが、そのまま動き続けます。

## 代替ツールが探される理由

- **AIがない。** ルールはすべて手で書く必要があります。`Screenshot 2026-10-02 141203.png`や`IMG_4382.jpg`のようなファイルは、名前にもテキストにも中身を示す手がかりがないため、ルールでは拾えません。
- **OCRがない。** File JugglerのFAQによると、画像だけのスキャンには検索できるテキストがないため、内容ベースのルールを効かせるには別のOCRソフトが必要です。
- **Windows専用。** Mac版はありません。Macで同じことをするなら[Hazel](/hazel-alternative)です。
- **サービスとしては動かない。** ユーザーがログインしている間だけ動作するので、サーバー用途には向きません。
- **価格。** ファイルの種類ごとに分けるだけなら、無料ツールでも十分にできます。

## 1. Zush：ルールでは説明できないファイルのために

[Windows版Zush](/windows)はWindows 10と11で動き、[Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X)から入手できます。条件にマッチさせる代わりに、ファイルそのものを読み取ります。PDFやスキャンのテキスト、写真やスクリーンショットに写っている内容、動画（MKVを含む）のフレーム・音声・字幕などです。そのうえで、`2026-09-12_acme_invoice_1042.pdf`や`stripe-revenue-dashboard-september.png`のような名前を提案します。

![Windows版Zushが内容をもとに種類の混ざったファイルをまとめてリネームし、適用前に提案されたファイル名をすべて表示している様子](/videos/windows/zush-batch-rename.mp4)

File Jugglerでは振り分け先ごとにルールが1つ必要ですが、Zushでは**Folder rules**に「請求書は会社ごと、領収書は月ごとにまとめる」のような1文を書くだけです。Autoにすれば内容に応じて自動でグループ分けします。ファイルが動く前に、提案された名前とフォルダをまとめて確認できます。判断が分かれそうなファイルは、適用前に確認しておきましょう。

![Windows版Zushが「名前を変更して仕分け」の前に、内容ベースのフォルダ分けと提案ファイル名をプレビューしている画面](/images/showcase/windows/folder-sorting-light.webp)

File Jugglerの「常に動き続ける」部分を置き換えるには、設定をTemplateとして保存し、**Monitor**に割り当てます。これでダウンロードやスキャナーのフォルダに届いた新しいファイルが、その都度リネームされて仕分けられます。Rename Historyは再起動後も変更前と変更後の名前を保持し、Undo Allはバッチ全体を元に戻して、競合があれば一覧で示します。AI Renameは重複したダウンロードを見つけてごみ箱へ移すこともでき、重複分はクレジットを消費せず、Undoで復元できます。

インストールしてすぐに使えます。最初の50回のAIリネームは、アカウント、カード、APIキー、モデルのダウンロードなしで、管理型のZush Cloud AIで動きます。PCの外に出したくないファイルには、OllamaやLM Studioに切り替えるか、自分のAPIキーを使います。

![Windows版ZushのMonitorタブがスクリーンショットとダウンロードのフォルダを監視し、新しいファイルを届いた順にリネームしている画面](/images/showcase/windows/monitor-light.webp)

ルールの一覧が増え続けているのに、まだ取りこぼしがあるならZushを選びましょう。手順は[WindowsでAIを使ってファイルをフォルダに仕分ける方法](/blog/sort-files-into-folders-with-ai-windows)と[すぐに使えるフォルダルール30選](/blog/ai-folder-sorting-prompts)で解説しています。

価格：月額$10または買い切り$48。File Jugglerと同じく、買い切りライセンスには今後のアップデートがすべて含まれます。さらに管理型のZush Cloud AIに加えてBYOK、Ollama、LM Studio、無制限のリネーム、WindowsとMacあわせて最大3台のデバイス、14日間の返金保証が付きます。Microsoft Store（米国）でZushは8件の評価で5.0、Softpediaの編集部の評価は5点満点中4.5点です（2026年11月17日時点）。

File Jugglerと比べた弱点：Zushには「コマンドの実行」、アーカイブの展開、Evernoteへのアップロードといったアクションがないため、それらに依存するルールの連鎖は置き換えられません。

## 2. DropIt：無料のルールエンジン

DropItは無料のオープンソースです。ルールは名前、サイズ、日付、プロパティ、正規表現でファイルにマッチし、移動、コピー、名前の変更、圧縮、展開など21種類のアクションが使えます。画面に浮かぶターゲットにファイルをドラッグするか、監視フォルダをタイマーでスキャンさせます。

弱点：最新リリースの8.5.1は2018年2月のものです。今も動きますが、新機能やAIは期待できません。

「PDFはここ、画像はあそこ」程度の振り分けで十分で、お金をかけたくないならDropItです。

## 3. Sortio：ルールを土台にしたAIの整理プラン

Sortioは両方のやり方を組み合わせています。従来型のルールを書くことも、整理の仕方を普通の文章で説明することもでき、プランを確認してからリネーム、フォルダ作成、移動を実行させます。Smart Foldersは新しく届いたファイルにもプランを適用し続けます。Windows、macOS、Linuxで動作します。

無料プランには、最大5つのルールと3つのSpacesによるルールベースの仕分け、プレビュー、仕分け履歴、元に戻す機能、1回限りのAIお試しが含まれます。フォルダ監視と自動化にはProが必要で、月額$14.99または年額$99、毎月一定量のAIが使えます。Ollamaを使えば処理はローカルで完結し、サインインにはメールアドレスのアカウントを使います。

File Juggler風のルールとAIを1つのアプリで使いたい場合や、Linuxが必要な場合はSortioです。弱点：常時動作の部分はPro限定です。詳しくは[Zush vs Sortio](/blog/zush-vs-sortio)で比較しています。

## 4. Wisfile：文書向けの無料AI整理

Wisfileは無料で、MacとWindowsのローカルで動き、`Author-Year-Title`のようなテンプレートで文書の内容から名前を付けます。バッチをトピック別のフォルダにまとめることもできます。FAQに記載されている対応形式はWordとPDFです。

フォルダ監視やスケジュール実行はなく、毎回ファイルをドラッグして実行します。FAQには元に戻す機能が組み込まれていないとも書かれているので、まずはコピーで試してください。

紙の書類や文書アーカイブを一度だけ整理するならWisfileです。詳しくは[Zush vs Wisfile](/blog/zush-vs-wisfile)をご覧ください。

## 5. PowerShellとタスク スケジューラ：自作するルート

基本的なFile Jugglerの作業なら、追加のソフトなしでWindowsだけでもできます。PowerShellでファイルを移動・リネームし、タスク スケジューラでそのスクリプトをログイン時や数分おきに実行します。

```powershell
Get-ChildItem "$env:USERPROFILE\Downloads" -Filter *.pdf |
  Move-Item -Destination "$env:USERPROFILE\Documents\PDFs"
```

無料で、柔軟性はスクリプトの腕次第です。そのかわり、名前の重複、ロックされたファイル、ログ、元に戻す処理もすべて自分で面倒を見ることになります。ほかの方法は[Windowsでダウンロードフォルダを整理する方法](/blog/organize-downloads-folder-windows)で紹介しています。

## File Jugglerを使い続けるか、乗り換えるか

- ファイルが決まったパターンに沿っている（同じ銀行、同じレイアウト、同じ名前の接頭辞）：**File Jugglerを継続**。
- スクリーンショット、スキャン、スマホの写真、意味のない名前のダウンロード：**Zush**。
- 拡張子や名前で無料で仕分けたい：**DropIt**または**PowerShell**。
- ルールとAIを1つのツールで、またはLinuxで使いたい：**Sortio**。
- PDFとWordファイルを一度だけ無料で整理したい：**Wisfile**。

両方を併用する手もあります。Zushがダウンロードを監視して`2026-10-02_acme_invoice.pdf`のような予測しやすい名前を付け、File Jugglerが`*_invoice.pdf`を決まった経理フォルダへ移す、という分担です。それぞれが得意な部分を受け持てます。どんな構成でも、まずはコピーで試してください。確認すべき点は[ファイルを安全に一括リネームする方法](/blog/how-to-safely-batch-rename-files)のチェックリストにまとめています。

AIツールをより広く比べたい場合は[Windows 11向けAIファイル整理ツールのおすすめ](/blog/best-ai-file-organizers-windows)を、Macから移ってきた方は[Windowsで使えるHazelの代替](/blog/hazel-for-windows-alternatives)をご覧ください。

## よくある質問

### File Jugglerの無料の代替はありますか？

あります。DropItは無料のオープンソースですが、最新リリースは2018年2月です。Sortioの無料プランでは最大5つのルールを使えますが、フォルダ監視にはProが必要です。スクリプトが書けるなら、PowerShellとタスク スケジューラの組み合わせは無料です。WisfileはPDFとWordファイルなら無料です。わかりにくいファイル名が悩みなら、Zushはアカウントもカードもなしで50回まで無料でAIリネームできます。

### File Jugglerは今も開発が続いていますか？

はい。File Juggler自身のニュースページによると、バージョン3.1.9が2026年10月30日にリリースされており、ライセンスには今後のアップグレードもすべて含まれます。定期的に更新が続いているルールベースのWindows用整理ツールは数少なく、そのうちの1つです。無料の代表的な代替であるDropItは、2018年2月以降リリースがありません。

### File JugglerはAIを使っていますか？

いいえ。自分で書いた条件にマッチさせる仕組みで、PDF、Word、Excelファイル内の単語も条件に使え、テキストから見つけた日付を再利用することもできます。ただし、画像だけのスキャンは別のOCRソフトがないと読めず、写真やスクリーンショットに何が写っているかも判断できません。そうしたファイルには、Zush、Sortio、WisfileのようなAIツールが必要です。

### 買い切り$48のZushと比べて、File Jugglerの$50は払う価値がありますか？

買っているものが違います。File Jugglerの$50（税別）で手に入るのは、今後のアップグレードがすべて付いたルールエンジンで、AIはありません。Zushの買い切り$48のライセンスには、管理型のZush Cloud AIによるAI命名とフォルダ仕分け、ローカルモードとBYOKモード、無制限のリネーム、今後のアップデートすべて、WindowsとMacあわせて最大3台のデバイスが含まれます。両方を併用している人も多くいます。

### ZushやFile Jugglerはファイルをどこかへ送信しますか？

File Jugglerはルールをローカルで実行します。Zushは選んだモードによります。OllamaやLM Studioなら解析はPC内で完結し、Zush Cloud AIや自分のAPIキーを使う場合は、名前を生成するためにファイルの内容がそのクラウドモデルへ送られます。機密性の高いフォルダにはローカルモードを選びましょう。Sortioもホスト型AI、BYOK、Ollamaから選べるので、設定を確認してください。

### Mac版のFile Jugglerはありますか？

ありません。File JugglerはWindows専用です。ルールベースでMacに最も近いのはHazelで、Softpediaの編集部は5点満点中5.0点と評価しています。Mac版ZushはAIによる命名とフォルダ仕分けに対応し、外付けドライブ上の監視フォルダも扱えます。Macで2つのアプローチがどう違うかは、[Hazelの代替](/hazel-alternative)のページで比較しています。

### ZushでFile Jugglerを完全に置き換えられますか？

中身に応じたファイル名を付け、フォルダへ仕分ける用途なら、監視フォルダも含めて置き換えられます。ただしFile Jugglerには、コマンドの実行、アーカイブの展開、Evernoteへのアップロードなど、Zushにないアクションがあります。それらに頼っているなら、その部分はFile Jugglerに任せ、Zushにはルールがマッチしやすいわかりやすい名前を付けさせるとよいでしょう。
