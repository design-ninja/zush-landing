## 1. Zush

内容に基づく名前と任意のAIフォルダ分類（ベータ）.

Zushのフォルダ分類はMacとWindowsでベータ提供中です。対応ファイルの内容から名前とグループを提案します。Autoを使う場合はFolder rulesを空欄にし、独自の分類には自然な言葉で指示を書きます。ファイル名の形式はNaming Blocksで別に設定します。

書き出した画像やフォルダのコピーで試してください。Photosライブラリパッケージの内部を並べ替えないでください。カタログ登録済みの原本には、そのソフトの改名や再リンク手順を使います。改名も移動もファイルパスを変更します。

## 2. Sortio

Sortioは指示に基づき、名前変更、フォルダ作成、移動の計画を表示します。Smart Foldersは新しいファイルを処理し、Linuxにも対応します。AIの利用枠と計画を確認してください。移動するとファイルパスが変わります。

[Sortio](https://www.getsortio.com/).

## 3. Wisfile

WisfileはPDF、論文、教材などローカルの文書を中心に扱います。内容から名前を付け、バッチをテーマ別にまとめられます。製品ページでは画像・動画のワークフロー、フォルダ監視、取り消し履歴は説明されていません。

[Wisfile](https://www.wisfile.ai/).

## 4. RenameClick

RenameClickは大きなモデルをダウンロードしてローカルで動作します。Auto Flowでは新しいファイルの名前変更と移動が可能です。対応形式を確認してください。限られた取り消し履歴は再起動で消え、バックアップの代わりにはなりません。

[RenameClick](https://rename.click/).

## 5. File Juggler

File JugglerはPDFの内容やプロパティを含む明示的な条件で、該当ファイルを改名・移動します。AIを使わない定型作業に向いています。各ルールを具体的に定義し、代表的なファイルでテストする必要があります。

[File Juggler](https://www.filejuggler.com/).

## 6. DropIt

DropItは名前、拡張子、日付、サイズ、正規表現で整理します。ファイルをドラッグするか、監視フォルダを定期的に確認する方式です。無料ですが内容を理解するAIはなく、最終版は2018年のものです。

[DropIt](https://www.dropitproject.com/).

## AIでファイルをフォルダに分類する

Zushのフォルダ分類はMacとWindowsでベータ提供中です。対応ファイルの内容から名前とグループを提案します。Autoを使う場合はFolder rulesを空欄にし、独自の分類には自然な言葉で指示を書きます。ファイル名の形式はNaming Blocksで別に設定します。

> 請求書は会社別、領収書は月別にまとめてください。月のフォルダ名はYYYY-MMにしてください。

1. 小さなファイルのコピーをAI Renameに追加し、Templateを選びます。
2. + Sortを有効にし、サブフォルダの親となるDestination folderを選びます。別の移動先を指定しなければ元のフォルダが親になります。
3. Folder rulesに分類方法を書きます。移動先の既存フォルダを使うにはReuse existing foldersを有効にします。適したものがなければ新規作成できます。
4. バッチを適用する前に、提案された名前とフォルダグループを確認し修正します。

確認した移動先とルールをTemplateに保存します。Monitorでは監視フォルダ直下に新しく届くファイルの命名と分類ができます。処理済みファイルをさかのぼって再整理するものではありません。分類を無効にして元の移動先を選べば、現在のフォルダに残ります。

## よくある質問

### Zushは実際にファイルをフォルダへ移動できますか？

はい。任意のベータ分類を有効にし、移動先と名前、グループを確認します。同じフォルダで改名するには分類を無効にし元の移動先を保ちます。

### 新しいファイルを自動で分類できますか？

はい。テスト済みTemplateをMonitorに割り当てます。監視フォルダ直下の新しいファイルが対象で、処理済みの古いファイルを再配置しません。

### 既存フォルダや外付けドライブは使えますか？

Reuse existing foldersで親フォルダ内の適した既存フォルダを使い、必要なら新規作成できます。ドライブとファイルにアクセスできることが必要です。クラウドのファイルは先にダウンロードします。

### ファイルはクラウドAIに送信されますか？

Zush Cloud AIとBYOKは選択したクラウド提供元へ内容を送ります。OllamaとLM Studioは対応するローカル分析を利用できます。ローカル分析でもアプリの全機能がオフラインになるわけではありません。
