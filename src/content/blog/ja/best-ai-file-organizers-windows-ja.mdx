## その場でリネームするか、フォルダへ移すか

AIファイル整理ソフトがすることは、次のどちらか、または両方です。

1. File ExplorerやWindows Searchが中身で探せるように、ファイルの名前を変える。
2. ファイルをフォルダ構成の中へ移す（構成をソフトが考えることもある）。

どちらもファイルのパスが変わるので、ショートカットやプロジェクト内のリンクが切れることがあります。移動のほうが影響は大きく、だからこそプレビューと、再起動後も使える元に戻す機能が必要です。何のファイルか確かめるためだけにファイルを開いているなら、まず解決すべきは命名の問題です。

## 1. Zush：中身に応じた名前とAIによるフォルダ仕分け

[Windows版Zush](/windows)はWindows 10と11で動き、[Microsoft Store](https://apps.microsoft.com/detail/9ND4WVZSDQ3X)からインストールできます。スクリーンショット、PDF、スキャン、写真、Office文書、デザインファイル、音声、動画が入ったフォルダを放り込むと、Zushが1つずつ読み取り、`2026-09-18_acme_invoice_1042.pdf`や`stripe-revenue-dashboard-september.png`のような名前を提案します。動画はMKVを含め、音声、埋め込み字幕、メタデータから名前を付け、音楽はタグがなくても特定できます。

インストールしてすぐに使えます。最初の50回のAIリネームは、アカウント、カード、APIキー、モデルのダウンロードなしで管理型のZush Cloud AIで動き、クラウドモードに必要なRAMは4 GBだけです。フォルダをPCの外に出したくないときは、OllamaやLM Studioに切り替えます。任意のオンデバイス音声認識を使えば、動画の文字起こしもローカルで完結します。

何かが変わる前に、すべての提案を確認できます。名前をダブルクリックして編集したり、1件だけ作り直したり、バッチを適用したりできます。用意されたTemplates（Movies & TVやRemove Duplicatesを含む）と145種類以上のNaming Blocksで、日付、取引先、金額、顧客、ゼロ埋めした連番など、名前の形式をそろえられます。

![Windows版Zushが内容をもとに種類の混ざったファイルをまとめてリネームし、適用前に提案されたファイル名をすべて表示している様子](/videos/windows/zush-batch-rename.mp4)

ファイリングまで任せるなら、Autoを使うか、**Folder rules**に「請求書は会社ごと、領収書は月ごとにまとめる」のようなルールを書きます。グループ分けをプレビューし、**Destination folder**を選び、**Reuse existing folders**で既存のフォルダを再利用します。ルールは入れ子にでき、日付やページ数などのファイル情報も使えます。今の名前を変えずに仕分けだけすることもできます。AI Renameは重複も検出し、残す、名前に印を付ける、ごみ箱へ移す、から選べます。重複分はクレジットを消費せず、Undoで復元できます。手順は[WindowsでAIを使ってファイルをフォルダに仕分ける方法](/blog/sort-files-into-folders-with-ai-windows)と[すぐに使えるフォルダルール30選](/blog/ai-folder-sorting-prompts)、設定の詳細は[フォルダ仕分けのドキュメント](/docs/folder-sorting)をご覧ください。

![Windows版Zushが「名前を変更して仕分け」の前に、内容ベースのフォルダ分けと提案ファイル名をプレビューしている画面](/images/showcase/windows/folder-sorting-light.webp)

**Monitor**は、保存したTemplateをダウンロードやスキャナーのフォルダに届く新しいファイルに適用します。Rename Historyは再起動後も変更前と変更後の名前を保持し、Undo Allはバッチ全体を元に戻します。競合があれば一覧で示し、別の名前で復元することもできます。

![Windows版ZushのMonitorタブがスクリーンショットとダウンロードのフォルダを監視し、新しいファイルを届いた順にリネームしている画面](/images/showcase/windows/monitor-light.webp)

## 2. Sortio：指示文で仕分け、Linuxにも対応

Sortioは「請求書は年ごと、スクリーンショットはプロジェクトごと」のような普通の言葉の指示を受け取り、プランを見せてから、リネーム、フォルダ作成、ファイルの移動を行います。Windows 10/11、macOS、Linuxで動き、サインインにはメールアドレスのアカウントを使います。

無料プランには、最大5つのルールと3つのSpacesによるルールベースの仕分け、1回限りのAIお試し、プレビュー、仕分け履歴、元に戻す機能が含まれます。フォルダ監視と自動化は現在Proが必要で、月額$14.99または年額$99、毎月一定量のAIが使えます。自分のキーを使えばその利用枠に縛られず、Ollamaなら処理はローカルで完結します（RAMは最低8 GB）。

Linuxやチーム向けのシートが必要ならSortioです。弱点：ホスト型AIは毎月の利用枠制で、無料プランではフォルダ監視ができなくなりました。[Zush vs Sortio](/blog/zush-vs-sortio)もご覧ください。

## 3. Wisfile：書類向けの無料の選択肢

Wisfileは無料で、WindowsとMacの端末上だけで動きます。書類を中身（タイトル、著者、年）からリネームし、バッチをトピック別のフォルダにまとめることもできます。`Author-Year-Title`のようなテンプレートに対応しています。

![ランダムなPDFの名前が、日付入りでわかりやすい書類名に変わる様子を描いたWisfile公式のイラスト](/images/blog/competitors/wisfile.webp)

予算を最優先に、PDFとWordのアーカイブを一度だけ整理したいならWisfileです。弱点：元に戻す機能もフォルダ監視もなく、画像や動画ではなくPDFとWordが中心です。コピーで作業しましょう。

## 4. RenameClick：ローカルモデルを同梱

RenameClickの無料のAIは、組み込みのローカルモデルです。ダウンロードは約4 GBで、推奨RAMは16 GBです。Ollamaを設定する必要がないのは、確かに便利です。画像、書類、音声に加え、バージョン4.1.2からは動画（MP4、MOV、M4V、3GP。フレームとローカルの文字起こしを使用）もリネームします。MKV、WebM、AVI、RAW写真、デザインファイルは対応形式に入っていません。Auto Flowは、アプリの起動中に新しいファイルをリネームして移動します。

無料プランでは解析は無制限で、リネームまたは移動は毎月100回までです。初めて適用する前に一度オンラインにする必要があります。Lifetimeは直販版で最大3台、$36＋VATで、返金は法律で義務付けられている場合に限られます。Standard Renameの取り消し履歴はメモリ上に10件までで、再起動すると消えます。評価：Microsoft Store（米国）で6件の評価で3.0、Softpediaの編集部の評価は3.5です。

![RenameClick（画面はMac版）がRename & Moveの前に、リネームしたファイルをLegal Documents、Medical Documents、Uncategorizedに仕分けている画面](/images/blog/competitors/renameclick.webp)

設定なしでオフラインのAIを使いたく、RAMにも余裕があるならRenameClickです。詳しい比較は[Zush vs RenameClick](/blog/zush-vs-renameclick)をご覧ください。

## 5. NudgeFile：無料のローカルAIフォルダ監視

NudgeFileはWindows 10と11向けの新しめのアプリで、Microsoft Storeから無料でダウンロードできます。公式サイトによると、ダウンロードやデスクトップなどのフォルダを監視し、新しいファイルに標準化された名前を付け、振り分け先のフォルダへ送り、チェックサムとローカルの画像AIで重複を見つけます。AIはOllamaを通じてローカルで動き、クラウドも選べます。「Human Approval Pipeline」で提案を確認するか自動で実行させるかを選べ、どの操作もワンクリックで元に戻せるとサイトには書かれています。

Windowsで常時動く無料のローカル整理ツールが欲しいならNudgeFileです。弱点：FAQにはモデルが「ファイルのメタデータと構造」を解析すると書かれており、サイトには対応ファイル形式も有料プランも載っていません。まずは自分のファイルで試してください。

## 6. Foldora：$14.99で一度だけローカル整理

FoldoraはWindows 10、11とmacOSで動きます。選んだファイルをローカルで解析し、フォルダとよりわかりやすいファイル名を提案し、プレビューを承認すると適用します。価格はLifetimeで$14.99です。購入、アクティベーション、定期的なライセンス確認にはインターネット接続が必要です。

種類の混ざったバッチを、安く、ローカルで、一度だけ片付けたいならFoldoraです。弱点：フォルダ監視がなく、ワンクリックで確実に元に戻せる機能はうたっていないと開発元自身が述べているので、大きな変更の前にはバックアップを取っておきましょう。

## 7. File Juggler：AIなしの予測しやすいルール

File Jugglerは長く使われているWindows用の自動化ツールで、今も開発が続いています（バージョン3.1.9は2026年10月30日にリリース）。「ダウンロード内のPDFに『Invoice』が含まれていたら、日付を付けてリネームし経理フォルダへ移す」のようなルールを書くと、ファイルが届くたびに適用します。ルールのためにPDF、Word、Excelのテキストを読むこともできます。Softpediaの編集部の評価は4.5/5です。

価格は$50＋税の買い切りで、30日間は全機能を試せます。弱点：AIもOCRもないので、ケースごとにルールが必要で、画像だけのスキャンには別途OCRの処理が要ります。ほかの選択肢は[File Jugglerの代替](/blog/file-juggler-alternatives)をご覧ください。

## 8. DropIt：無料のルールエンジン

DropItは無料のオープンソースです。ルールは名前、サイズ、日付、正規表現でファイルにマッチし、ファイルをDropItにドラッグするか、監視フォルダをタイマーでスキャンさせます。移動、コピー、名前の変更、圧縮、展開など21種類のアクションがあります。

弱点：最新リリースの8.5.1は2018年2月のもので、アップデートやAIは期待できません。拡張子や名前のパターンで無料のシンプルな仕分けをしたいならDropItです。Macから移ってきた方は[Windowsで使えるHazelの代替](/blog/hazel-for-windows-alternatives)もご覧ください。

## どれを選ぶべきか

- ファイル名が問題、または名前とフォルダを1回の確認でまとめて処理したい：**Zush**。
- Linuxやチーム向けのシートが必要：**Sortio**。
- 無料・ローカルで書類だけ整理したい：**Wisfile**。
- 設定不要のオフラインAIで、RAMは16 GBある：**RenameClick**。
- 試すのをいとわない無料のローカル監視ツール：**NudgeFile**。
- 安く一度だけローカルで片付けたい：**Foldora**。
- 厳密なルールで、AIは不要：**File Juggler**、無料にこだわるなら**DropIt**。

## どの整理ソフトも、まず10ファイルで試す

よくあるファイルを10個テスト用フォルダにコピーします。スクリーンショット、請求書、領収書、スマホの写真、表計算ファイル、Word文書、スライド資料、動画、音声ファイル、適当なダウンロードです。そのうえで次を確認しましょう。

## よくある質問

### Windows 11で最適なAIファイル整理ソフトはどれですか？

私たちのおすすめはZushです。ファイルを中身からリネームし、Autoか自分の指示でフォルダへ仕分け、プレビュー、Templates、監視、再起動後も残る元に戻す機能を備えています。Linuxが必要ならSortio、ローカルモデル同梱がいいならRenameClick、AIなしの厳密なルールでファイルに合うならFile Jugglerが代替です。Zushは私たちの製品なので、どれを選ぶにしても、まずはコピーで試してください。

### Windows向けの無料のAIファイル整理ソフトはありますか？

あります。WisfileはPDFとWordファイルなら無料かつローカルで、NudgeFileはMicrosoft Storeから無料でダウンロードできます。Zushはアカウント、カード、APIキーなしで50回まで無料でAIリネームできます。RenameClickは4 GBのモデルをダウンロードしたあと、毎月100回までリネームまたは移動ができます。DropItも無料ですが、AIではなく固定のルールで動きます。

### 買い切りでいちばん多くのものが手に入るWindows用整理ソフトは？

Foldoraは$14.99、RenameClickは$36＋VATですが、どちらもローカルか自分で用意したAIでしか動きません。Zushの$48のライセンスには、管理型のZush Cloud AIに加えて、BYOK、Ollama、LM Studio、無制限のリネーム、今後のアップデートすべて、WindowsとMacあわせて最大3台のデバイス、14日間の返金保証が含まれます。File Jugglerの$50のライセンスで手に入るのはルールで、AIではありません。

### AIファイル整理ソフトはファイルをアップロードしますか？

モードによります。OllamaかLM Studioを使ったZushは解析をPC内で行い、Zush Cloud AIとBYOKは命名のためにファイルの内容をクラウドモデルへ送ります。Wisfile、Foldora、RenameClickの組み込みモデルはローカルで動き、NudgeFileは初期設定でローカルAIを使います。Sortioはホスト型AIに加え、全プランでBYOKやOllama、LM Studioが使えます。機密性の高いフォルダに使う前に、各アプリのAI設定を確認しましょう。

### WindowsでAIにダウンロードフォルダを自動で整理させられますか？

できます。Zushはダウンロードを監視し、新しいファイルをリネームして、Templateに保存したフォルダルールを適用できます。RenameClickのAuto Flow、Sortio Pro、NudgeFileもフォルダを監視します。重要なフォルダを自動化する前に、まずテスト用のフォルダ1つで始めましょう。Zushでの設定方法は[ダウンロード自動化のガイド](/ai-file-sorter)で解説しています。
