結論から言うと、接頭辞、日付、連番のように、すべてのファイルに同じ種類の変更を加えるなら**PowerRename**を使いましょう。Microsoftの無料ツールで、たいていのパターン処理はこなせます。ファイルごとに中身に応じた名前が必要なら、[Zush](/windows)のようなAIリネームツールが向いています。1つ1つのファイルを読み取り、アカウントなしで50回まで無料でAIリネームできます。

**確認方法：** 執筆は[Zush](/)の開発元です。競合ツールの価格、機能、評価は2026年11月17日に各社の公式サイトと公式ストアで確認しました（[出典は記事末尾](#sources-and-how-we-checked)）。ここで比べているのは公開されている機能で、実機テストの結果ではありません。

この違いで、ほかのすべてが決まります。パターン型のツールは速くて正確ですが、ファイルがすでに持っている名前を変形することしかできません。`IMG_4382.jpg`を`Vacation_001.jpg`にはできても、`lisbon-tram-at-night.jpg`にはできないのです。

## 1. File Explorer：5ファイル程度なら十分

複数のファイルを選んで**F2**を押し、名前を入力してEnterを押します。Windowsが`Trip (1).jpg`、`Trip (2).jpg`のように名前を付けます。**Ctrl+Z**ですぐに元に戻せます。

できるのはそれだけです。プレビューも、日付も、検索と置換もありません。意味のある名前でなくても、見た目が整えばよいときに使いましょう。

## 2. PowerRename：ほとんどの人にとって最良の無料ツール

[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)はMicrosoft PowerToysに含まれています。ファイルを選んで右クリックし、**PowerRenameで名前を変更**を選ぶと、ライブプレビュー付きの検索と置換が使えます。

見た目以上にいろいろなことができます。

- キャプチャグループを含む正規表現（`29-03-2020` → `2020-03-29`）
- 桁埋めと開始値を指定できるカウンター（`Image_${padding=4}`）
- `$YYYY-$MM-$DD`のようなファイル作成日の変数
- `$DATE_TAKEN_YYYY`や`$CAMERA_MODEL`のような写真のEXIF・XMPトークン

Ctrl+Zで直前のリネームを元に戻せます。AIはなく、ファイルを開くこともないので、スキャンやスクリーンショットに何が写っているかはわかりません。パターンとして説明できる作業なら、どれもPowerRenameで足ります。AIの側については、[PowerRenameの代替](/windows)のページをご覧ください。

## 3. Bulk Rename Utility：最大限の制御

Bulk Rename Utilityは、あらゆるパターン処理の設定を1つの密度の高いウィンドウに詰め込んでいます。正規表現、JavaScript、自動連番、EXIFの日付、MP3のタグ、CSVによるリネーム、タイムスタンプの変更などです。10万件以上のファイルでも速度は落ちません。元に戻す処理は、変更を逆にするバッチファイルを生成する仕組みです。

個人利用は無料ですが、JavaScriptでのリネームには有料ライセンス（$24.95）が必要で、商用利用はPC1台あたり$92.95です。バージョン4.1.0.1では、JavaScriptや正規表現のルールを書いてくれるAIアシスタントが追加されました。パターン作りは手伝ってくれますが、ファイルの中身は読みません。画面には慣れが必要です。詳しくは[Bulk Rename Utilityの代替](/blog/bulk-rename-utility-alternatives)のガイドで解説しています。

## 4. Advanced Renamer：写真や音楽のメタデータに最適

Advanced Renamerは、複数のメソッドを積み重ねて名前を組み立てます。EXIF、ID3、動画のプロパティ、GPS（座標を都市名に変換できます）のタグを使えます。ライブプレビューがあり、バッチ全体を元に戻せます。macOSでも動きます。現行バージョンは4.28で、スクリプトのメソッドを使えばPDFやTXTファイルからテキストを抜き出せますが、AIやOCRはありません。スキャンしたPDFや写真は読めないままで、テキストを名前に変えるスクリプトも自分で書く必要があります。

軽い個人利用なら無料です。日常的に使う人には$30の個人向けライセンスの購入が求められ、仕事で使うには$50の商用ライセンスが必要です。どちらも買い切りです。[Advanced Renamerのレビュー](/blog/advanced-renamer-alternatives)もご覧ください。

## 5. ReNamer：ルールとスクリプト

ReNamerは、挿入、削除、置換、大文字・小文字、正規表現、メタタグ、独自処理用のPascal Scriptなど、順番に並べたルールを適用します。ポータブル版で、25以上の言語のインターフェースに対応しています。

ReNamer Liteは非商用なら無料ですが、ルールとプリセットはそれぞれ5つまでです。Proではこの制限がなくなり、商用利用もできます。

## 6. Zush：ファイルごとに別の名前が必要なとき

[Zush](/windows)のやり方は違います。古い名前を編集するのではなく、ファイルそのものを見ます。PDFのテキスト、スクリーンショットに写っているもの、写真の場面、WordやExcelファイルの内容です。そのうえで、中身を表す名前を書きます。

| 変更前 | 変更後 |
|---|---|
| `Screenshot 2026-09-18 141203.png` | `github-pull-request-review-comments.png` |
| `scan_0042.pdf` | `2026-09-12_acme_invoice_1042.pdf` |
| `Document1.docx` | `q3-marketing-plan-draft.docx` |
| `IMG_4382.jpg` | `2026-08-30_lisbon_tram_street.jpg` |

名前の形は自分で決められます。Templatesと145種類以上のNaming Blocksで、順序（日付、取引先、顧客、タイトル）、大文字・小文字、区切り文字を固定できます。すべての提案を適用前に確認でき、Rename Historyを使えばあとからバッチ全体を元に戻せます。フォルダ監視を使えば、ダウンロードやスキャナーのフォルダに届いた新しいファイルも自動でリネームされます。

AIはZush Cloud AI、自分のAPIキー、またはOllamaやLM Studioを使ったローカル処理から選べます。最初の50回のAIリネームは、アカウント、カード、APIキーなしで無料です。その後は月額$10または買い切り$48です。買い切りライセンスには、無制限にリネームできる管理型クラウドAI、今後のアップデートすべて、WindowsとMacあわせて最大3台のデバイス、14日間の返金保証が含まれます。AI Renameの途中で重複ファイルも見つけ（重複分はクレジットを消費しません）、動画は音声や字幕から名前を付け、Windowsではタグのない音楽も特定します。

Zushのライセンス1つで、MacとWindowsあわせて最大3台のデバイスで使えます。

Naming Blocks、Custom AI Blocks、フォルダルールを含む[Templatesをエクスポート](/docs/template-import-export)し、別のコンピュータでインポートできます。ローカルの保存先、フォルダの権限、AIの接続はその端末で選び直してください。移るのはワークフローの設定で、ファイルそのものではありません。

### Zushでリネームしたファイルをフォルダに仕分ける

Windowsでは、Zushで**AIを使ってファイルをフォルダに仕分ける**こともできます。**Auto**でのグループ分けを選ぶか、「請求書は会社ごと、領収書は月ごとにまとめる」のような**Folder rules**を書きます。提案されたフォルダ分けをファイル名と並べて確認できます。バッチ全体に同じテキスト変更を加えるだけなら、パターン型のリネームツールで十分です。

**Destination folder**を選ぶか、元のフォルダをそのまま起点にします。**Reuse existing folders**を有効にすると、すでにある適切なフォルダが優先され、合うものがなければZushが新しいフォルダを作ります。手動のバッチでは、適用前に提案された名前とフォルダの両方を確認しましょう。その場でリネームだけしたいなら、仕分けをオフにして元の保存先のままにします。

仕分けの設定を**Template**に保存して**Monitor**に割り当てれば、監視フォルダの直下に届く新しいファイルにも適用されます。MonitorのTemplateを変えても、処理済みのファイルが自動で整理し直されることはありません。まずは手動のバッチでTemplateを試してください。設定方法と監視の範囲は[フォルダ仕分けガイド](/docs/folder-sorting)をご覧ください。

Zushは、年ごと、さらに月ごとにまとめるといった入れ子のフォルダルールにも対応しています。リネーム済みのファイルを、名前を変え直したりリネームのクレジットをもう一度使ったりせずに仕分けることもできます。適用前に振り分け先を確認しましょう。この操作は既存のバッチを対象にした別の処理で、MonitorのTemplateを変えてもさかのぼって整理されるわけではありません。[AIによるフォルダ仕分け](/docs/folder-sorting)はMacとWindowsで使えます。

## どのリネームツールを使うべきか

- すべてのファイルに同じ変更（接頭辞、日付、番号）：**PowerRename**。
- 大量のフォルダに複雑なパターン：**Bulk Rename Utility**。
- 写真、音楽、GPSのメタデータから名前を付ける：**Advanced Renamer**。
- ちゃんとした名前が必要なスクリーンショット、スキャン、ダウンロード、写真：**Zush**。

両方のタイプを使い分けている人もたくさんいます。機械的な修正はPowerRenameで手早く、何のファイルか確かめるためにいちいち開いているフォルダにはZush、という具合です。

## よくある質問

### ZushはWindows 11で動画や音楽ファイルの名前を変えられますか？

はい。Windows版Zushは、MKVを含む動画に音声、埋め込み字幕、メタデータから名前を付け、タグのない曲でも音楽を特定できます（音楽の特定は今のところWindows限定の機能です）。オフラインで作業するなら、AI設定から任意のオンデバイス音声認識をダウンロードし、OllamaやLM Studioと組み合わせて使えます。PowerRenameのようなパターン型のツールはルールで名前を変えるだけなので、録音の中身はわかりません。

### Windows 11で最良の無料ファイル名変更ツールは何ですか？

Microsoft PowerToysに含まれるPowerRenameです。無料で、すべての変更をプレビューでき、正規表現、カウンター、日付の変数、EXIF/XMPトークンに対応し、Ctrl+Zで元に戻せます。もっと重い個人の作業ならBulk Rename Utilityも無料ですが、JavaScriptでのリネームには有料ライセンスが必要です。Advanced Renamerは軽い個人利用なら無料です。どれもファイルの中身は読みません。中身を読ませたいなら、Zushならアカウントなしで50回まで無料でAIリネームできます。

### Windows 11に一括リネームの機能は標準でありますか？

あります。ただし基本的なものです。File Explorerでファイルを選んでF2を押すと、括弧付きの番号を付けて1つの名前にそろえられます。検索と置換や日付を使いたいなら、PowerToysを入れてPowerRenameを使いましょう。

### ファイル名変更ツールはファイルの中身を読めますか？

パターン型のツールはほとんど読めません。読むのは既存の名前と、EXIFやID3のようなメタデータのフィールドです。Advanced RenamerはスクリプトでPDFやTXTファイルからテキストを抜き出せますが、AIやOCRがないため、スキャンや写真は読めないままです。ZushのようなAIリネームツールは中身そのもの（テキスト、画像、動画の音声とフレーム）を読み、適用前に確認できるわかりやすい新しい名前を提案します。

### いちばん安全なファイル名変更ツールはどれですか？

プレビューとバッチ単位の元に戻す機能があるツールなら、どれでも安全です。PowerRename、Advanced Renamer、Zushはいずれも適用前に結果を表示します。Zushは再起動後も残るRename Historyを持っているので、直後だけでなく数日後でもバッチを元に戻せます。

### PowerRenameが無料なのに、Zushにお金を払う価値はありますか？

ファイルに中身に応じた名前が必要な場合に限ります。一律のパターン変更ならPowerRenameが適切で、費用もかかりません。名前を付ける前に、スクリーンショットやスキャン、ダウンロードを開いて中身を確かめているなら、Zushがその読み取りを代わりにやってくれます。買い切り$48のライセンスには、無制限にリネームできる管理型クラウドAI、BYOKとローカルモデル、今後のアップデートすべて、3台のデバイス、14日間の返金保証が含まれます。

### ZushはWindowsでファイルをどこで処理しますか？

モードによります。Zush Cloud AIとBYOKでは、名前を生成するためにファイルの内容がAIサービスへ送られます。BYOKでは自分のプロバイダーのアカウントを使います。OllamaやLM Studioなら解析はPC上で行われ、動画向けにオンデバイスの音声認識も使えます。PowerRename、Bulk Rename Utility、Advanced Renamerは中身を解析しないため、ファイルをどこにも送りません。詳しくは[オフラインのAIファイル名変更ツール](/offline-ai-file-renamer)をご覧ください。
