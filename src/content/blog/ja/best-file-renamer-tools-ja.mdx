## 分類1：標準搭載・無料のパターン型リネームツール

### Finderの名前変更（Mac）

ファイルを選んで右クリックし、**名前を変更**を選びます。テキストの置換、テキストの追加、名前と連番の指定ができます。インストールは不要です。正規表現やメタデータは使えず、中身も読みません。[Macでの一括リネーム完全ガイド](/blog/batch-rename-files-on-mac-complete-guide)では、FinderとあわせてAutomatorやターミナルも解説しています。

**こんな人に：** 1つのルールですべてのファイルを直せる場合。**弱点：** 正規表現もメタデータもまったく使えません。

### PowerRename（Windows）

Microsoft PowerToysの一部です。選択したファイルを右クリックすると、正規表現、カウンター、作成日の変数、写真のEXIF/XMPトークンを使った検索と置換が、ライブプレビュー付きで使えます。Ctrl+Zでリネームを元に戻せます。AIはなく、ファイルの中身も読みません。2つを比べた詳しい説明は[Windows版Zush](/windows)のページにあります。

**こんな人に：** 変更をパターンとして説明できる場合。**弱点：** `scan_004.pdf`に、スキャンの中身に応じた名前は付けられません。

### Bulk Rename Utility（Windows）

BRUは、接頭辞、連番、大文字・小文字、正規表現、EXIFやID3のタグといったルールを、1つの密度の高いウィンドウで積み重ねます。個人利用は無料です。JavaScriptでのリネームには有料ライセンス（$24.95）が必要で、商用利用はPC1台あたり$92.95です。バージョン4.1.0.1では、JavaScriptや正規表現を書いてくれるAIアシスタントが加わりましたが、ファイルの中身は今も読みません。Mac版はありません。[Bulk Rename Utilityの代替](/blog/bulk-rename-utility-alternatives)もご覧ください。

**こんな人に：** 非常に大きなフォルダに複雑な機械的ルールを適用する場合。**弱点：** 画面が詰め込まれていて、業務利用はPC単位の料金です。

## 分類2：メタデータ型リネームツール

**Advanced Renamer**と**A Better Finder Rename**は、EXIFの日付、GPS座標、ID3タグ、ファイルの日付から名前を組み立てます。Advanced Renamer（バージョン4.28）はスクリプトのメソッドでPDFやTXTファイルからテキストを抜き出すこともできますが、AIやOCRはありません。そのため、スキャンしたPDFや画像は読めないままで、抜き出したテキストを名前に変えるロジックも自分で書くことになります。軽い個人利用なら無料で、日常的に使う人には$30の個人向けライセンスの購入が求められ、仕事で使うには$50の商用ライセンスが必要です。A Better Finder RenameはMac向けで$29.95です。

限界は、メタデータが表すのは「いつ」「何で」であって、「何が」ではないことです。写真のEXIFからわかるのは撮影日時で、公園にいるゴールデンレトリバーが写っていることまではわかりません。そうしたルールがどこで行き詰まるかは、[Advanced Renamerの代替](/blog/advanced-renamer-alternatives)のレビューで整理しています。

**こんな人に：** 付けたい名前がすべてEXIF、GPS、タグの中にある場合。**弱点：** 画像やスキャンした書類の中身は理解できません。

## 分類3：AIリネームツール（ファイルごとに別の名前が必要なとき）

上の2つの分類ではどうにもならないフォルダがあります。`Screenshot 2026-03-23.png`、`Scan0001.pdf`、`IMG_4382.HEIC`、`download (7).pdf`のようなファイルです。それぞれに合う名前は違い、その手がかりはピクセル、テキスト、音声の中にしかありません。

[Zush](/)は、スクリーンショット、写真（RAWやHEICを含む）、PDF、[スキャンした書類](/rename-scanned-documents)、OfficeやiWorkのファイル、デザインファイル、音声、動画の中身を読み取ります。動画はMKVを含め、音声、埋め込み字幕、メタデータから名前を付けます。用意されたTemplateを選ぶか、145種類以上の[Naming Blocks](/docs/naming-blocks)で命名規則を作り、提案された名前をすべて確認します。「名前を変更」をクリックするまで何も変わりません。Rename Historyは再起動後も残り、バッチ全体を元に戻せます。[フォルダ監視](/docs/folder-monitoring)を使えば、ダウンロードやスキャナーのフォルダに届いたファイルにも次々と名前が付きます。

料金に含まれるもの：

- **すぐに使える：** Zush Cloud AIで50回まで無料でAIリネームでき、アカウント、カード、APIキー、モデルのダウンロードは不要です。
- **買い切り価格にクラウドも含まれる：** $48のLifetimeで、Zush Cloud AI、BYOK、Ollama、LM Studioでの無制限のリネーム、今後のアップデートすべて、MacとWindowsあわせて最大3台のデバイス、14日間の返金保証が付きます。月額$10のプランもあります。
- **重複にも対応：** AI Renameが重複ファイルを見つけます。重複分はクレジットを消費せず、Undoで復元できます。[重複ファイルを削除する](/remove-duplicate-files)もご覧ください。
- **クラウドモードなら軽量：** 約200 MB、RAM 4 GBで動きます。

### リネームと同時にフォルダへ仕分ける

Zushは、**Auto**でのグループ分けや**Folder rules**を使ってファイルをフォルダに仕分けることもできます。入れ子のフォルダにも対応し、名前を変えずに仕分けだけすることもできます。**Destination folder**を選ぶか元のフォルダを起点にし、**Reuse existing folders**を有効にすると、すでにある適切なフォルダが優先されます。設定をTemplateに保存して**Monitor**に割り当てれば、新しいファイルにも適用されます。詳しくは[フォルダ仕分けガイド](/docs/folder-sorting)、手順は[MacでAIを使ってファイルをフォルダに仕分ける方法](/blog/sort-files-into-folders-with-ai-mac)、指示の例は[すぐに使えるフォルダルール30選](/blog/ai-folder-sorting-prompts)をご覧ください。

ほかにも、それぞれ一長一短のAIリネームツールがあります。[クロスプラットフォームのAIリネームツール比較](/blog/best-ai-file-renamer-tools-2026)では10個を取り上げており、[Mac](/blog/best-ai-file-renamer-tools-mac-compared)と[Windows](/blog/best-ai-file-renamer-tools-windows-compared)の個別ランキングもあります。

## 30秒で選ぶ方法

1. すべてのファイルに同じ変更：**Finder**または**PowerRename**。
2. 巨大なフォルダに複雑なルール：**Bulk Rename Utility**。
3. 付けたい名前がすでにEXIF、GPS、タグにある：**Advanced Renamer**または**A Better Finder Rename**。
4. 名前を付ける前に、何のファイルか確かめるために開いている：**Zush**。

両方のタイプを使い分けている人もたくさんいます。機械的な修正にはパターン型ツールを、名前に意味を持たせたいフォルダにはAIを、という具合です。Windowsに絞った比較は[Windows 11向けおすすめファイル名変更ツール](/blog/best-file-renamer-windows-11)をご覧ください。

## よくある質問

### 無料で使えるおすすめのファイル名変更ソフトは？

パターン処理なら、MacのFinderとWindowsのPowerRenameが無料で、すべての変更をプレビューできます。Bulk Rename Utilityは個人利用なら無料、Advanced Renamerは軽い個人利用なら無料です。中身に応じた名前を付けたいなら、Zushはアカウント、カード、APIキーなしで50回まで無料でAIリネームでき、有料版と同じプレビューとRename Historyが使えます。[無料でAIリネームする方法](/blog/rename-files-with-ai-free)もご覧ください。

### ファイル名変更ソフトは、中身に応じた名前を付けられますか？

ちゃんとできるのはAIリネームツールだけです。パターン型ツールは既存の名前を並べ替え、メタデータ型ツールはEXIFやID3のタグを読みます。Advanced RenamerはスクリプトでPDFやTXTファイルからテキストを抜き出せますが、AIやOCRがないため、スキャンや画像は読めないままです。ZushのようなAIリネームツールは、テキストレイヤーのないスキャンも含めてテキスト、画像、音声、動画を読み取り、先に確認できる名前を提案します。

### AIファイル名変更ソフトにお金を払う価値はありますか？

リネームが機械的な作業なら、払う必要はありません。無料のパターン型ツールで十分です。何のファイルか確かめるために頻繁にファイルを開いているなら、価値はあります。Zushの買い切り$48のライセンスには、無制限にリネームできる管理型クラウドAIに加えて、BYOKとローカルモデル、今後のアップデートすべて、MacとWindowsあわせて最大3台のデバイス、14日間の返金保証が含まれます。まずはファイルのコピーで、無料の50回を試してみてください。

### Zushはファイルをどこで処理しますか？

選んだモードによります。Zush Cloud AIとBYOKでは、名前を生成するためにファイルの内容がAIサービスへ送られます。BYOKでは自分のプロバイダーのアカウントを使います。OllamaやLM Studioなら、解析は自分のコンピュータ上で行われ、ファイルもそこから出ません。Finder、PowerRename、Bulk Rename Utilityのようなパターン型ツールは中身を読まないので、何も外に出ません。設定方法は[オフラインのAIファイル名変更ツール](/offline-ai-file-renamer)をご覧ください。

### Macでおすすめのファイル名変更ソフトは？

ファイルごとにわかりやすい名前が必要な、種類の混ざったフォルダなら[Mac版Zush](/mac)です。スクリーンショット、PDF、RAW写真、デザインファイル、音声、動画を読み取り、再起動後も残るRename Historyを保持します。共通のルール1つで済むなら標準搭載のFinder、EXIFやメタデータのパターンならA Better Finder Rename（$29.95）が使えます。全体の比較は[Mac向けAIリネームツール比較](/blog/best-ai-file-renamer-tools-mac-compared)をご覧ください。

### Windows 11でおすすめのファイル名変更ソフトは？

パターン処理なら、PowerRenameが無料で、変更をプレビューでき、Ctrl+Zで元に戻せます。Bulk Rename UtilityとAdvanced Renamerは、より複雑なルールやメタデータを扱えます。ファイルごとに中身に応じた名前が必要なら、[Windows版Zush](/windows)をMicrosoft Storeから入れれば、プレビュー、フォルダ監視、再起動後も残るRename Historyが使えます。[Windows向けAIリネームツール比較](/blog/best-ai-file-renamer-tools-windows-compared)もご覧ください。
