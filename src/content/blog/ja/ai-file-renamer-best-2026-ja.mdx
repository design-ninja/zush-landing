### Zushが1位の理由

印象ではなく、確かめられる事実です。

1. **MacでもWindowsでもすぐに使える。** 管理型のZush Cloud AIで50回まで無料でAIリネームでき、アカウント、カード、APIキー、モデルのダウンロードは不要です。AI RenamerはGoogleでのサインイン、FilesDeskはサインインが必要で、RenameClickの無料のAIは、推奨RAM 16 GBで約4 GBのローカルモデルをダウンロードする方式です。NameQuick Managedも同じくらい始めやすく、無料で30回リネームできます。
2. **1つのライセンスで両方のプラットフォームに対応し、クラウドも込み。** 買い切り$48で、MacとWindowsあわせて最大3台、すべてのモード（Zush Cloud AI、BYOK、Ollama、LM Studio）での無制限のリネーム、今後のアップデートすべて、14日間の返金保証が付きます。AI Renamer（$19）、RenameClick（$36＋VAT）、RenamerX（$36）、FilesDesk（$40）、NameQuick（$69）の買い切りライセンスは、いずれも自分のキーかローカルモデルが必要です。
3. **「名前を変更」をクリックするまで何も変わらず、あとから戻せる。** Rename Historyは再起動後も残り、バッチ全体を元に戻せます。RenameClickの取り消しはメモリ上に10件まで、AI Renamerは取り消しの記載がなく、Wisfileには取り消し機能がありません。
4. **対応範囲の広さ。** 動画はMKVを含め、音声、埋め込み字幕、メタデータから名前を付けます。RAW写真、デザインファイル、音声、Office、iWork、EPUBにも対応しています。AI Renameの中での重複検出はクレジットを消費しません。

Zushが答えにならない場面：Linux版はなく（AI Renamerにはあります）、ブラウザだけで使う方法やクラウドストレージ向けのAPIのワークフローもなく（Renamed.toにはあります）、返金期間は14日間です。評価（2026年11月17日時点）：米国Microsoft Storeで8件の評価で5.0、Softpediaの編集部レビューで4.5/5。

### 1. Zush

[Zush](/)は、ファイルに中身から名前を付けるMacとWindows向けのデスクトップアプリです。100以上の形式に対応しています。HEIC、AVIF、カメラのRAWを含む画像41形式、デザイン4形式（Sketch、Figmaの.fig、Illustratorの.ai、PSD）、PDF、Office、iWork、OpenDocument、EPUBを含む書類40形式、MP4、MOV、MKVを含む動画、音声7形式です。動画は音声、埋め込み字幕、メタデータから名前を付けます。何を読み取るかは[AIで動画ファイルをリネームする方法](/blog/rename-video-files-with-ai)で説明しています。

仕組み：用意されたTemplate（Smart Rename、Screenshots、Movies & TV、Remove Duplicatesなど）を選ぶか、145種類以上のNaming BlocksとCustom AI Blocksで自分で作ります。Zushがファイルごとに名前を提案します。どの名前もダブルクリックで編集でき、「名前を変更」をクリックするまで何も変わりません。

**強み：**

- 管理型クラウドAIで、アカウントもキーもなしに初回起動からすぐに使える
- 1つのワークフローで4つのAIルート：Zush Cloud AI、BYOK（Gemini、OpenRouter、OpenAI、Claude）、Ollama、LM Studio。OllamaやLM Studioを通じて動画のローカル音声認識にも対応
- 適用前のプレビュー、再起動後も残るRename Historyと一括の取り消し、競合を知らせるUndo All
- 重複の検出：コピーを残す、名前に印を付ける、ゴミ箱（Windowsではごみ箱）に移す、から選択。クレジットは消費しない
- フォルダ監視。Macでは外付けドライブも対象で、再接続すると再開
- 開始番号とゼロ埋めを指定でき、フォルダごとに番号を振れる連番
- 入れ子のフォルダにも対応した、任意のAIによるフォルダ仕分け
- クラウドモードなら軽量：約200 MB、RAMは最低4 GB
- インターフェースは11以上の言語、名前は60以上の言語に対応

**制限：**

- Linux版もブラウザだけで使える版もない
- Zush Cloud AIとBYOKにはインターネットが必要。OllamaとLM Studioはコンピュータ上で動く
- タグのない音楽の特定は、今のところWindows限定

**向いている人：** 種類の混ざったフォルダを抱え、AIリネームをすぐに使い始めて、支払いは一度で済ませたいMacとWindowsのユーザー。

Zushのライセンス1つで、MacとWindowsあわせて最大3台のデバイスで使えます。[Templatesをエクスポート](/docs/template-import-export)して、別のコンピュータでインポートすることもできます。

#### 任意のAIによるフォルダ仕分け

Zushはファイルをフォルダに仕分けることもできます。**Auto**を選ぶか、「請求書は会社ごと、領収書は月ごとにまとめる」のような**Folder rules**を書きます。ルールで入れ子のフォルダを作ることができ、日付やページ数などのファイル情報も使えます（Macアプリではサイズ、カメラ、再生時間も使えます）。名前を変えずに仕分けることも、保存先のフォルダを選ぶことも、既存のフォルダを再利用することもできます。設定をTemplateに保存して監視フォルダに割り当てれば、新しく届くファイルにも適用されます。[フォルダ仕分けガイド](/docs/folder-sorting)と[AIファイル整理](/ai-file-organizer)のページをご覧ください。

### 2. FilesDesk

FilesDeskはMacとWindowsで動き、Watch Folders、Gmail、iCloud、IMAPのメール添付ファイルをリネームするWatch Inbox、テンプレート、取り消し付きの履歴を備えています。サインイン後に15クレジットが無料で付きます。管理型AIはサブスクリプションのみで、500クレジットで月額$8、2,000クレジットで月額$20（年額$80または$200）、AIによる名前の提案1件につき1クレジットを使い、同じファイルを再実行するとさらに1クレジット使います。$40のSelf-Managedライセンスは自分のキーかローカルモデル（Ollama、LM Studio、vLLM）を使い、1台に紐づき、1年間のアップデートが付き、返金期間は3日間です。

**FilesDeskを選ぶべき人：** 届いたメールの添付ファイルをその都度リネームしたい場合。**弱点：** 買い切りライセンスに管理型AIが含まれません。[Zush vs FilesDesk](/blog/zush-vs-filesdesk)もご覧ください。

### 3. RenameClick

RenameClick（現在はrename.click）はMacとWindowsで動きます。バージョン4.1.2ではMP4、MOV、M4V、3GPの動画に対応し、フレームとローカルの文字起こしを使います。MKV、WebM、AVIは非対応で、カメラのRAWやデザインファイルにも対応していません。無料プランでは解析は無制限で、毎月100回のリネームまたは移動ができます。Lifetimeライセンスは直販版で最大3台、$36＋VATで、プロバイダーの料金は含まれません。

**RenameClickを選ぶべき人：** Ollamaの設定が要らない、同梱のローカルモデルが欲しい場合。**弱点：** そのモデルはダウンロードが約4 GBで推奨RAMは16 GB、Undoはメモリ上に10件までしか保持せず、再起動すると消えます。[Zush vs RenameClick](/blog/zush-vs-renameclick)もご覧ください。

### 4. AI Renamer

AI Renamer（airenamer.app）は、MacとWindows、そして今ではLinux向けのデスクトップアプリです。バージョン1.9ではWatch Folder（ベータ）が加わりましたが、動くのはアプリの起動中だけで、サブフォルダは対象外です。バージョン1.10では動画、音声、RAW、HEIC、Office、EPUBに対応しました。Local Modeは買い切り$19で、自分のキーかOllama/LM Studioを使います。クラウドクレジットは200ごとに$10で、Googleでのサインイン後に10クレジットが無料で付きます。返金の記載はなく、クレジットの購入は返品できません。GitHubにある無料のGPL-3.0の`ozgrozer/ai-renamer`というCLIは、無関係のプロジェクトです。

**AI Renamerを選ぶべき人：** Linuxが必要な場合や、ローカルAIを最も安い買い切り価格で使いたい場合。**弱点：** 取り消しについて記載がありません。[Zush vs AI Renamer](/blog/zush-vs-airenamer)もご覧ください。

### 5. Renamer.ai

Renamer.aiはWindowsとMacのアプリとWebのインターフェースを提供し、Magic Folders、テンプレート、プレビュー、取り消しを備えています。ローカルモードは、無料のStarterプラン（毎月25ファイル）を含むすべてのプランで使えます。有料のクラウドプランは、Proが月額$9.95（200ファイル）、Powerが$29.95（1,000）、Ultimateが$99.95（5,000）で、年払いなら15%安くなります。BYOKはUltimateのみです。Softpediaの編集部の評価は4.5/5です。

**Renamer.aiを選ぶべき人：** 書類のテンプレートと無料のローカル処理が欲しい場合。**弱点：** 買い切りライセンスがないため、管理型AIは月額の従量制です。[Zush vs Renamer.ai](/blog/zush-vs-renamer-ai)もご覧ください。

### 6. NameQuick

NameQuick（バージョン3.0.57、現在はMac App Storeにもあり）はMacとWindowsで動き、Watch Folders、Rules、Quick Organize、取り消しを備えています。メールアドレスもカードもなしでManagedのリネームを30回無料で使え、14日間のManagedの試用（70回）にはカードが必要です。Managedプランは月額$12からで、リネームパックは500回で$19、1,500回で$39（有効期間12か月）です。Self-Managedはコンピュータ1台で買い切り$69、生涯アップデートと14日間の返金保証が付きます。AIの費用は別です。

**NameQuickを選ぶべき人：** AIでの命名に加えてルールエンジンが欲しい場合。**弱点：** 買い切りライセンスはコンピュータ1台分で、管理型AIは含まれません。[Zush vs NameQuick](/blog/zush-vs-namequick)もご覧ください。

### 7. RenamerX

RenamerXは、MacとWindows向けのローカル優先のリネームツールです。組み込みのモデル（Qwen3.5 4B）はダウンロードが約3.4 GBで、Apple Siliconか、互換性のあるGPUを積んだWindows x64のPCで動きます。Ollama、LM Studio、任意のOpenAI互換のエンドポイント、または自分のキーでOpenAIやGeminiにも接続できます。サイトには、書類、カメラのRAWを含む画像、MKVを含む動画に加え、Watch Foldersと取り消しが載っています。Freeでは毎月50クレジット、Proは無制限のクレジットでLifetime $36です。デバイス数、返金条件、アップデートの方針はトップページに記載がありません。

**RenamerXを選ぶべき人：** 同梱のローカルモデルでRAWとMKVに対応したい場合。**弱点：** 管理型クラウドがなく、音声ファイルは対応一覧に載っていません。

### 8. Wisfile

Wisfileは無料で、MacとWindowsで100%ローカルに動き、PDFとWordファイルに重点を置いています。取り消し機能はありません。

**Wisfileを選ぶべき人：** たまに書類をリネームする程度で、費用もクラウドも避けたい場合。**弱点：** 取り消しがないので、失敗したバッチは手で直すことになります。

### 9. Renamed.to

Renamed.toはAPIとCLIを備えたクラウドサービスです。最初の50回は無料で、その後はクレジットを1,000で$9、10,000で$49で販売しており、有効期間は12か月です。

**Renamed.toを選ぶべき人：** 書類がクラウドストレージにある場合や、APIが必要な場合。**弱点：** クラウド専用なので、ローカルで処理する方法はありません。

### 10. File Renamer AI

File Renamer AIはブラウザのツールです。ファイルをアップロードし、名前を確認して、ZIPでダウンロードします。クレジットは1,000で$10、10,000で$100で、有効期限はありません。トップページではPDF、Office、動画、音声にも触れていますが、料金ページは今も画像について説明しています。

**File Renamer AIを選ぶべき人：** ソフトをインストールできない場合。**弱点：** デスクトップアプリもフォルダ監視もなく、ZIPをダウンロードしたあとは元に戻せません。

## よくある質問

### AIファイル名変更ツールとは何ですか？

AIファイル名変更ツールは、1つ1つのファイルの中身を読み取り、内容がわかる名前を提案するアプリです。パターン型のツールはバッチ全体に日付を付けたりテキストを置き換えたりできますが、どちらも`scan_004.pdf`という名前なら、請求書と契約書の区別はつきません。AIリネームツールはテキスト、画像、音声、動画を読み取って、ファイルごとに別の名前を付けます。何かが変わる前に、その名前を確認できるべきです。

### 2026年に最適なAIファイル名変更ツールはどれですか？

MacとWindowsなら、私たちのおすすめはZushです。アカウント、カード、APIキーなしで、初回起動から50回まで無料でAIリネームできます。買い切り$48のライセンスには、最大3台で使える管理型クラウドAI、BYOK、Ollama、LM Studioが含まれ、すべてのバッチはプレビューでき、一括で取り消せるRename Historyに残ります。LinuxならAI Renamer、MacとWindowsで無料・ローカルならWisfile、クラウドストレージやAPIのワークフローならRenamed.toが合っています。

### 買い切り$48のライセンスは、$19や$36のライセンスより価値がありますか？

AIを何で動かしたいかによります。$19のAI Renamer、$36のRenameClick、$36のRenamerXのライセンスはアプリの代金で、AIは自分のAPIキーか、コンピュータで動かすローカルモデルです。Zushの$48には、無制限にリネームできる管理型のZush Cloud AIに加えて、BYOKとローカルモデル、今後のアップデートすべて、MacとWindowsあわせて3台、14日間の返金保証が含まれます。

### ファイルはどこで処理されますか？

モードによります。Zush Cloud AIやBYOKでは、名前を生成するためにファイルの内容がAIサービスへ送られます。OllamaやLM Studioなら、解析は自分のコンピュータ上で行われます。RenameClickとRenamerXは初期設定で同梱のローカルモデルを使い、Renamer.aiはすべてのプランでローカルモードを提供し、Wisfileはローカルのみで、Renamed.toとFile Renamer AIはクラウドサービスです。データの保持条件は各社のプライバシーページで確認してください。

### Linuxで使えるAIファイル名変更ツールは？

ここで比べたツールのうち、Linux版を公開しているのは今のところAI Renamerです。Zush、FilesDesk、RenameClick、NameQuick、RenamerX、WisfileにはMacとWindowsのアプリがありますが、Linux版はありません（2026年11月17日時点）。WisfileはLinux版を近日公開としています。Renamed.toやFile Renamer AIのようなブラウザやAPIのツールはどのOSからでも使えますが、ファイルはそのクラウドサービスへ送られます。

### AIリネームは元に戻せますか？

Zushなら戻せます。Rename Historyは再起動後も残るので、数日後でもバッチ全体を元に戻せ、Undo Allは復元前に競合を一覧で示します。FilesDeskとNameQuickも取り消し付きの履歴を持っています。RenameClickは取り消し履歴をメモリ上に10件保持し、再起動すると消えます。AI Renamerは取り消しの記載がなく、Wisfileには取り消し機能がないので、まずはコピーで試してください。
