## AIで書類を整理する2つのやり方

どの機能があるかよりも、この2つのどちらを選ぶかのほうが重要です。

1. **フォルダ型ツール**は、ファイルが今ある場所で名前を変え、移動します。書類はFinder、File Explorer、iCloud、OneDrive、Dropbox上の普通のファイルのままです。Zush、NameQuick、Wisfile、File Jugglerがこのタイプです。
2. **アーカイブ型ツール**は、書類を独自のライブラリやサーバーに取り込み、タグ、全文検索、メタデータを付けます。Paperless-ngxとDEVONthinkがこのタイプです。

税理士やチーム、ほかのアプリとフォルダを共有しているならフォルダ型を。すべてを1か所で検索でき、そのアプリの中で作業するのが苦にならないならアーカイブ型を選びましょう。

## 1. Zush：今使っているフォルダのための最適なAI書類整理ツール

[Zush](/ai-file-organizer)はMacとWindowsで動きます。PDF、スキャン、レシート、契約書、Word、Excel、Pages、EPUBのファイルが入ったフォルダを放り込むと、テキストレイヤーのない画像だけのスキャンも含めて1件ずつ読み取ります。そして日付、取引先、金額、顧客、書類の種類、請求書番号など、検索に使う項目を組み合わせた名前を提案します。「名前を変更」をクリックするまで何も変わらず、提案はダブルクリックで編集できます。

![種類の混ざったフォルダについて、Mac版Zushが適用前に提案ファイル名を1件ずつ表示している画面](/images/showcase/macos/batch-rename-light.webp)

Zushでは名前がTemplateに沿って付けられるので、AIがその場で思いついた名前ではなく、すべての請求書が同じ形式になります。Bookkeeper Expensesは用意されているTemplatesの1つで、145種類以上のNaming Blocksを使えば、必要に応じて連番も含めた独自のパターンを作れます。

書類のファイリングまでZushに任せるなら、**Folder rules**に「請求書は会社ごと、領収書は月ごとにまとめる」のような1文を書くか、Autoのままにします。名前とフォルダは1つのプレビューでまとめて確認できます。ルールには日付やページ数などのファイル情報も使え、MacでもWindowsでも、名前を変えずに仕分けだけすることもできます。

![請求書を会社ごと、領収書を月ごとにまとめる指示とルール例が入ったZushのFolder rulesダイアログ](/images/showcase/macos/folder-rules-light.webp)

次々に届く書類には、スキャナーやダウンロードのフォルダでTemplateを**Monitor**に割り当てます。AI Renameは重複したスキャンも検出し、残す、名前に印を付ける、ゴミ箱（Windowsではごみ箱）へ移す、から選べます。重複分はクレジットを消費しません。Rename Historyは再起動後も残り、Undo Allはバッチを元に戻して競合を知らせます。

インストールしてすぐに使えます。Zush Cloud AIで50回まで無料でAIリネームでき、アカウント、カード、APIキー、モデルのダウンロードは不要です。機密性の高いファイルは、OllamaやLM Studioを使えばコンピュータの外に出さずに処理できます。買い切り$48のライセンスには、管理型のクラウドAIに加えてすべてのローカルモードとBYOKモード、今後のアップデートすべて、MacとWindowsあわせて最大3台のデバイス、14日間の返金保証が含まれます。

書類を、共有フォルダから誰でも開ける普通のファイルのままにしておきたいならZushを選びましょう。参考ガイド：[スキャンした書類を自動でリネームする方法](/blog/rename-scanned-documents-automatically)、[AIで請求書をリネーム](/rename-invoices-with-ai)、[AIで領収書をリネーム](/rename-receipts-with-ai)。スキャンが重複しているなら[重複ファイルを削除する](/remove-duplicate-files)をご覧ください。

## 2. Paperless-ngx：無料でセルフホストできる最良のアーカイブ

Paperless-ngx（v3.4.2）は、自分のサーバーやNASで、たいていはDockerを使って動かすオープンソース（GPL-3.0）の文書管理システムです。Tesseractによる100以上の言語のOCRを実行し、原本とPDF/Aのアーカイブ用コピーを並べて保管し、機械学習でタグ、差出人、書類の種類を提案します。メールから書類を取り込むこともできます。

AI機能は任意で、初期設定ではオフです。AIによる提案、書類とのチャット、類似書類の検索があり、Ollama経由のローカル処理か、OpenAI互換のAPIで動きます。ファイル名と保存パスはPaperless自身が管理し、形式は設定で変えられます。

セルフホストに抵抗がなく、家庭や小さなオフィスで紙の書類を検索できるアーカイブにしたいならPaperless-ngxです。弱点：サーバーとDockerの準備が必要で、書類は既存のフォルダ構成ではなくPaperlessのアーカイブ内に置かれます。

## 3. DEVONthink：Mac向けの最良の書類データベース

DEVONthink 4.4.2は、書類の保管、検索、分類のために長く使われてきたMacアプリです。OCRと生成AIの機能（チャット、要約、タグ付け、スマートルールによる一括処理）は、ProとServerのエディションにしかありません。対応モデルはChatGPT、Claude、Mistralに加え、OllamaやLM Studio経由のローカルモデルです。

価格はStandardが$99、Proが$199、Serverが$499で、いずれもMac 2台分のライセンスと1年間のアップデートが付きます。ライセンスに期限はなく、アップデートをさらに1年延長するにはそれぞれ$44、$89、$134かかります。

Macで研究レベルの書類ライブラリを作りたいならDEVONthinkです。弱点：スキャンを読むには少なくとも$199のProが必要で、書類はDEVONthinkのデータベース内に置かれます。書類に名前を付けてファイリングしたいだけの人には過剰です。

## 4. NameQuick：条件付きルールで書類をリネーム

NameQuickは、MacとWindowsで繰り返し届くPDF、スキャン、レシート、請求書、契約書、Word文書、表計算ファイルに焦点を当てています。Presetsで内容に応じてリネームし、フォルダを監視し、名前を付けたあとにファイルを移動・タグ付け・アーカイブする条件付きRulesを実行します。

![スキャンした請求書、領収書、契約書が日付と取引先名でリネームされる様子を示すNameQuickの宣伝画像](/images/blog/competitors/namequick.webp)

メールアドレスもカードもなしで、Managedのリネームを30回まで無料で試せます。Managedプランは500回で月額$12から10,000回で月額$99まであり、リネームパックは500回で$19、1,500回で$39（有効期間12か月）です。$69のSelf-Managedライセンスはコンピュータ1台分で、自分のAPIキーかローカルモデルが必要です。

if/thenのRulesを軸にした書類ワークフローを組みたいならNameQuickです。弱点：買い切りライセンスには管理型AIが含まれず、リネーム後にファイルを移動すると元に戻せないことがあります。詳しい比較は[Zush vs NameQuick](/blog/zush-vs-namequick)をご覧ください。NameQuickの料金体系を比べる際は、Managedプランと買い切りの違いに注意してください。

## 5. Wisfile：PDFとWordを無料でローカルにリネーム

Wisfileは無料で、MacとWindowsのローカルで動きます。PDFとWord文書を内容からリネームし（論文なら`Author-Year-Title`など）、トピック別のフォルダにまとめることもできます。

![ランダムなPDFの名前が、日付入りでわかりやすい書類名に変わる様子を描いたWisfile公式のイラスト](/images/blog/competitors/wisfile.webp)

予算をかけずに書類アーカイブを一度だけ整理したいならWisfileです。弱点：FAQによると、フォルダ監視、スケジュール実行、組み込みの元に戻す機能がないため、コピーで作業してください。詳細は[Zush vs Wisfile](/blog/zush-vs-wisfile)をご覧ください。

## 6. File Juggler：Windowsで決まった形式の書類をルールで処理

File JugglerはAIではありませんが、いつも同じ形式の書類を振り分けるのは得意です。ルールはPDF、Word、Excelファイル内の単語にマッチでき、テキスト中の日付を再利用して、ファイルの名前を変えて移動します。バージョン3.1.9は2026年10月30日にリリースされ、Softpediaの編集部は5点満点中4.5点と評価しています。

価格は税別の買い切り$50で、30日間は全機能を試せます。弱点：画像だけのスキャンは、別のOCRソフトがないと読めません。書類の形式がばらばらなら、[File Jugglerの代替](/blog/file-juggler-alternatives)をご覧ください。

## よくある質問

### 最適なAI書類整理ツールはどれですか？

MacやWindowsの普通のフォルダに置いておきたい書類なら、Zushです。PDF、スキャン、Officeファイルを内容に応じて命名・仕分けし、変更前にプレビューでき、元に戻す履歴も残ります。セルフホストのアーカイブが欲しいなら無料のPaperless-ngxが最良で、本格的な書類データベースを求めるMacユーザーにはDEVONthink Proが向いています。Zushは私たちの製品なので、ご自身の書類のコピーで試してみてください。

### 無料のAI書類整理ツールはありますか？

あります。Paperless-ngxは無料のオープンソースですが、サーバーが必要です。WisfileはMacとWindowsでPDFとWord文書なら無料ですが、元に戻す機能はありません。Zushはアカウント、カード、APIキーなしで50回まで無料でAIリネームでき、NameQuickはManagedのリネームを30回まで無料で使えます。DEVONthinkとFile Jugglerは無料プランではなく試用期間を設けています。

### AI書類整理ツールはスキャンしたPDFを読めますか？

読めますが、すべてのツールではありません。Zushは画像だけのスキャンも、別のOCR処理なしでそのまま読み取ります。Paperless-ngxは取り込み時にTesseract OCRを実行し、DEVONthinkはProとServerのエディションでのみOCRを実行します。NameQuickとWisfileもスキャンに対応しています。File Jugglerはルールがファイル内にすでにあるテキストにしかマッチしないため、先に別のOCRソフトが必要です。

### 書類をアップロードせずにAIで整理できますか？

できます。OllamaかLM Studioを使ったZush、Wisfile、ローカルのOllamaをバックエンドにしたPaperless-ngx、ローカルモデルを使ったDEVONthink Pro、ローカルモデルを使ったNameQuick Self-Managedは、いずれも書類を自分のハードウェア上に置いたまま処理します。Zush Cloud AIやBYOKのモードでは、解析のために書類の内容がクラウドモデルへ送られるので、機密ファイルにはローカルモードを選びましょう。

### 書類整理ツールの買い切りライセンスには何が含まれますか？

ツールによって大きく違います。DEVONthinkの$99〜$499のライセンスには1年間のアップデートが付きます。NameQuickの$69のSelf-Managedライセンスはコンピュータ1台分で、AIは自分で用意する必要があります。File Jugglerの$50で手に入るのは、AIなしのルールです。Zushの$48のライセンスには、管理型のZush Cloud AI、ローカルモードとBYOKモード、無制限のリネーム、今後のアップデートすべて、MacとWindowsあわせて最大3台のデバイスが含まれます。
