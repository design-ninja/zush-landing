## 自動ファイル整理でまず対象にすべきもの

最初は、頻繁に発生していて、しかも面倒に感じているファイルから手を付けましょう。初日から全部をまとめる大がかりな仕組みを作る必要はありません。繰り返し困っていることを1つか2つなくし、効果を確かめてから広げていけば十分です。

自動化に向いている対象：

- **スクリーンショット**：macOSは`Screenshot 2026-03-12 at 10.44.11.png`のような名前を付けますが、これでは中身がまったくわかりません
- **ダウンロードフォルダ**：ブラウザからのダウンロード、メールの添付ファイル、AirDropで受け取ったファイルが、ありきたりな名前のままどんどんたまります
- **定期的に書き出すファイル**：請求書、銀行の取引明細、毎週同じアプリから出すレポートなど
- **カメラから取り込んだ写真**：`IMG_4382.HEIC`では、半年後には何の写真かわかりません
- **繰り返し出てくる書類の山**：クライアントへの納品物、調査用のPDF、プロジェクトの素材など

自動化がいちばん効くのは、毎週のちょっとしたストレスを取り除くときです。結局メンテナンスしなくなる凝った仕組みを作っても効果は出ません。

### 特に散らかっている場所を見つける

Finderでダウンロードフォルダかデスクトップを開き、変更日順に並べ替えます。直近の50ファイルを見て、名前から中身がわかるものがいくつあるか数えてください。半分に満たなければ、そのフォルダは自動化する価値があります。

フォルダにたまっているファイルの数を調べる方法もあります。ターミナルを開いて次のコマンドを実行します。

```bash
ls -1 ~/Downloads | wc -l
```

200を超えていれば、自動化して片づける価値のある量がたまっています。

## 種類の混ざったファイルをAIでフォルダに仕分ける

[ZushのAIファイル仕分け](/ai-file-sorter)を使うと、対応するファイルにわかりやすい名前を付け、同じバッチの中で中身ごとに実際のフォルダへまとめられます。**AIによるフォルダ仕分けはMacとWindowsの両方で使えます。** **Folder rules**を空欄にするとAutoで分類され、分け方を普通の言葉で書くこともできます。種類の混ざったファイルなら、たとえば次のように書きます。

> 請求書は会社ごと、領収書は月ごとにまとめてください。

1. コピーした少量のファイルを**AI Rename**に追加し、Templateを選びます。
2. **+ Sort**を有効にして**Destination folder**を選びます。ここが仕分け先サブフォルダの親になります。別の保存先を指定しなければ、元のフォルダが親になります。
3. **Folder rules**に分け方の指示を書きます。ファイル名の形式は**Naming Blocks**で別に設定します。
4. 保存先の親フォルダに使えるフォルダがすでにあるなら、**Reuse existing folders**を有効にします。合うフォルダがなければ、Zushが新しく作れます。
5. 提案された名前とフォルダ分けの両方を確認します。フォルダ名やファイルの置き場所は、バッチを適用する前に直してください。

![Mac版ZushがRename & sortの前に、中身に基づくフォルダ分けと提案ファイル名をプレビューしている画面](/images/showcase/macos/folder-sorting-light.webp)

確認した保存先とルールはTemplateに保存します。そのTemplateを**Monitor**に割り当てると、監視フォルダの直下に新しく届いたファイルがリネームされ、仕分けられます。すでに処理したファイルがさかのぼって整理し直されることはありません。仕分けをオフにして元の保存先を選んでいれば、ファイルは今のフォルダに残ります。

詳しくは[Macでのフォルダ仕分けの手順ガイド](/blog/sort-files-into-folders-with-ai-mac)、[フォルダ仕分けのドキュメント](/docs/folder-sorting)、[Folder rulesの例30選](/blog/ai-folder-sorting-prompts)をご覧ください。

## Smart Folders：設定手順

Smart Foldersはファイルを移動しません。検索条件に合うファイルをその場で表示するだけです。Finderのサイドバーに置ける、保存済みのSpotlight検索と考えるとわかりやすいでしょう。

フォルダ構成を組み替えずに、あちこちに散らばったファイルを探したいときに便利です。

### Smart Folderの作り方

1. Finderを開きます
2. **Cmd + F**を押すか、**ファイル > 新規スマートフォルダ**を選びます
3. 右上の**+**ボタンをクリックして条件を追加します
4. 条件を設定します（下の例を参照）
5. **保存**をクリックしてSmart Folderに名前を付けます
6. いつでも開けるように**サイドバーに追加**にチェックを入れます
7. `.savedSearch`ファイルの保存場所を選びます（初期設定のままでかまいません）

### よく使うSmart Folderの条件

| 目的 | 設定する条件 |
|---|---|
| 最近のスクリーンショット | 種類＝イメージ、名前に「Screenshot」を含む、変更日＝過去7日間 |
| 容量を圧迫している大きなファイル | ファイルサイズ＞500 MB |
| 最近のPDF | 種類＝PDF、変更日＝過去30日間 |
| 確認が必要な書類 | タグ＝「Review」、種類＝書類 |
| すべてのプレゼンテーション | 種類＝プレゼンテーション |
| 最近のダウンロード | フォルダ＝ダウンロード、変更日＝過去3日間 |

### Smart Foldersの応用テクニック

- **Option**キーを押しながら**+**ボタンをクリックすると、AND／ORを組み合わせた複合条件を追加できます
- ファイルの拡張子、作成日、最後に開いた日など、数十種類のメタデータで絞り込めます
- Smart Foldersはリアルタイムで更新されるので、常にディスクの今の状態が反映されます
- 外付けドライブを含め、マウントされているすべてのボリュームが対象になります

Smart Foldersは何も移動もリネームもしないので、本当の意味での自動化ではありません。それでも、ルールを決める前に何を整理すべきかが見えるので、最初の一歩としてはとても役立ちます。

さらに詳しくは、[macOSのファイル検索を使いこなすガイド](/blog/finder-tags-guide-organize-files-mac)をご覧ください。

## AutomatorとShortcuts：実際に動くワークフローを作る

Automator（と、その後継にあたるShortcuts）では、実際にファイルを処理するワークフローを作れます。ドラッグ＆ドロップの操作で、ファイルのリネーム、移動、コピー、サイズ変更、変換ができます。

### Automatorのフォルダアクション：ダウンロードを種類別に自動で仕分ける

Automatorのワークフローの中でも特に実用的なものの1つです。ダウンロードフォルダを監視し、拡張子に応じてファイルをサブフォルダへ移動します。

**設定手順：**

1. **Automator**を開きます（Spotlightで検索できます）
2. 書類の種類として**フォルダアクション**を選びます
3. 上部の「フォルダアクションが受け取る項目の追加先」で**ダウンロード**フォルダを指定します
4. **シェルスクリプトを実行**アクションを追加します
5. 「入力の引き渡し方法」を**引数として**に設定します
6. 次のスクリプトを貼り付けます。

```bash
for f in "$@"; do
    ext="${f##*.}"
    ext=$(echo "$ext" | tr '[:upper:]' '[:lower:]')
    case "$ext" in
        pdf)
            dest="$HOME/Documents/PDFs" ;;
        jpg|jpeg|png|heic|webp|gif)
            dest="$HOME/Pictures/Downloads" ;;
        zip|gz|tar|dmg)
            dest="$HOME/Downloads/Archives" ;;
        doc|docx|xlsx|pptx|csv)
            dest="$HOME/Documents/Office" ;;
        *)
            dest="" ;;
    esac
    if [ -n "$dest" ]; then
        mkdir -p "$dest"
        mv "$f" "$dest/"
    fi
done
```

7. 「ダウンロードを種類別に仕分け」のような、内容がわかる名前でワークフローを保存します
8. これでフォルダアクションが有効になり、ダウンロードに入った新しいファイルが自動で仕分けられます

### Shortcuts：macOS Ventura以降のもっと手軽な選択肢

macOS Ventura以降を使っているなら、多くの作業はAutomatorの代わりにShortcutsでこなせます。画面がすっきりしていて、システムのトリガーとの連携が密なのが利点です。

**例：スクリーンショットをリネームして移動する**

1. **Shortcuts**を開きます
2. 新しいショートカットを作成します
3. **フォルダの内容を取得**アクションを追加します（スクリーンショットのフォルダを指定）
4. **ファイルをフィルタ**アクションを追加し、名前に「Screenshot」を含むものに絞ります
5. **ファイル名を変更**アクションを追加し、`Screenshot-[Date Created]`のようなパターンを使います
6. **ファイルを移動**アクションを追加し、移動先のフォルダを指定します
7. 自動で実行するには、**オートメーション**タブで、スクリーンショットのフォルダにファイルが追加されたときに動くトリガーを作成します

Shortcutsは単発の自動化に、Automatorはシェルスクリプトを使う複数ステップの複雑なワークフローに向いています。Automatorを使ったリネームを詳しく知りたい場合は、[Automatorでファイル名を変更するガイド](/blog/macos-automator-rename-files-guide)をご覧ください。


## スクリプトとアーカイブにはHazel

Hazelが役立つのは、アーカイブ、スクリプトの実行、アップロードなど、Zushにないアクションを含む複数条件のルールをフォルダで常に動かしたいときです。請求書のPDFを年と月のフォルダへ移すだけのルールなら、もうHazelは要りません。Zushなら「請求書を年と月のフォルダに入れる」のようなフォルダルールで同じことができ、ファイル名が`scan0043.pdf`でも請求書だと判断できます。

Hazelは、拡張子、日付、タグ、ファイル名のパターン、抽出したテキストが確かな条件になる場合にうまく働きます。Zushも同じ情報を使えます。日付や拡張子のNaming Blocksがあり、Monitorではファイルの種類や名前の先頭文字で絞り込めます。そのうえで、スクリーンショット、写真、動画、ありきたりな名前のスキャンの中身を理解してから、名前を付けたりフォルダへ振り分けたりします。

両方を使う場合は、ツールごとに担当するフォルダを分けてください。同じ受け取り用フォルダを2つのツールが同時に監視して書き換えるのは避けましょう。機能ごとの製品比較は、[Hazelの代替としてのZush](/hazel-alternative)をご覧ください。

## ルールベースの自動化が通用しないケース

ルールがうまく働くのは、名前、拡張子、メタデータからファイルの正体がすでにわかる場合です。

次のような名前で届くファイルには通用しません。

- `IMG_4382.HEIC`
- `Screenshot 2026-03-12 at 10.44.11.png`
- `download (7).jpg`
- `Document.pdf`
- `Untitled.png`
- `image (3).webp`

ルールでこうしたファイルを特定のフォルダに移すことはできても、中身が何かを示すことはできません。わかりやすい名前がなければ、フォルダにきれいに整理されていても、あとで目的のファイルを見つけられません。

ここでAIによる名前付けが役に立ちます。画像のピクセルそのもの、動画から抜き出したフレーム、PDFのテキスト、書類のレイアウトといったファイルの中身を解析するツールなら、そのファイルが実際に何なのかを表す名前を付けられます。

AIによるリネームが実際にどう動くかは、[MacとWindows向けのファイルリネームツール](/)で詳しく紹介しています。

この違いは見た目だけの問題ではありません。わかりやすいファイル名があれば、Spotlight検索がきちんと機能します。フォルダを眺めるだけで、ファイルを開かなくても中身がわかります。Smart Folders、Hazelのルール、手作業での閲覧など、その後に使う仕組みもすべて使いやすくなります。

AIによる自動リネームの全体的な手順は、[Macでファイル名を自動で変更するガイド](/blog/auto-rename-files-mac-guide)をご覧ください。

## おすすめの自動ファイル整理の設定手順

ここまでのツールを1つのまとまった仕組みに組み合わせる、1時間以内で作れる実用的な設定を紹介します。手間と効果のバランスがとれたやり方です。

### ステップ1：今の散らかり具合を確認する

ダウンロード、デスクトップ、書類の各フォルダを開きます。役に立たない名前のファイルがどのフォルダに多いかを確かめ、問題の大きいフォルダを2つ選びます。

### ステップ2：Zushの名前と、必要に応じたフォルダ分けをプレビューする

[Mac用AIファイルリネームツール](/mac)をインストールし、コピーした受け取り用フォルダを指定してTemplateを選び、最初に提案された名前を確認します。継続的な監視を有効にする前に、Rename Historyを使える状態にしておいてください。

### ステップ3：必要なら見える化のためにSmart Foldersを作る

Finderで3つのSmart Foldersを作ります。

1. **最近の大きなファイル**：ファイルサイズ＞100 MB、変更日＝過去30日間
2. **未整理のスクリーンショット**：種類＝イメージ、名前に「Screenshot」を含む、変更日＝過去14日間
3. **最近の書類**：種類＝書類 または 種類＝PDF、変更日＝過去7日間

これで、手を付けるべきものがすぐにわかります。

### ステップ4：必要なら基本的な振り分けを設定する

好みに合わせて、次のどれかを選びます。

**方法A：Automatorのフォルダアクション**（無料、標準搭載）
- 上で紹介したダウンロードの仕分けワークフローを作成します
- 10分ほどで作れ、よくあるファイルの種類に対応できます

**方法B：Hazelのルール**（有料、より高機能）
- Hazelをインストールし、ダウンロードフォルダに3〜5個のルールを設定します
- 中心にするのは、PDFは書類フォルダへ、画像はピクチャフォルダへ、アーカイブは専用フォルダへ、という振り分けです
- 30日より古いファイルを片づけるルールも追加します

**方法C：Shortcutsのオートメーション**（無料、macOS Ventura以降）
- ファイルを種類別に仕分けるショートカットを作成します
- スケジュールで動かすか、手動で実行するように設定します

**方法D：Zushのフォルダルール**（Zushに含まれます）
- TemplateでSortをオンにし、「PDFは書類へ、画像はピクチャへ、領収書は月ごとに」のようにフォルダの分け方を書きます
- そのTemplateをMonitorに割り当てると、新しいダウンロードが届いた時点で名前が付き、仕分けられます

### ステップ5：テストが済んだらZushの監視を有効にする

![デスクトップフォルダを選択した、Zushのフォルダ監視設定のMonitorタブ](/images/showcase/macos/monitor-light.webp)

テスト用のバッチで問題がないことを確かめたら、スクリーンショットのフォルダとダウンロードフォルダをZushで監視するように設定します。ルールベースのツールではうまく名前を付けられないファイルを、これで処理できます。

- スクリーンショットは、写っているアプリと内容に基づいてリネームされます
- PDFは、テキストの内容に基づいてリネームされます
- 写真は、写っているものに基づいてリネームされます
- ダウンロードした画像には、`download (7).jpg`ではなくわかりやすい名前が付きます

### ステップ6：毎週の見直しを習慣にする

自動化していても、週に1回、5分ほどSmart Foldersに目を通しましょう。例外的なケースに気づけて、少しずつルールを改善できます。

### ステップ7：少しずつ広げる

この設定で1週間運用したら、まだ取りこぼしているものがないか確認します。必要に応じてHazelのルールやSmart Foldersを追加してください。最初からすべての例外に対応しようとしなくてかまいません。


## 比較：どの作業にどのツールを使うか

| 作業 | おすすめ | 理由 |
|---|---|---|
| 種類の混ざったファイルに中身から名前を付け、フォルダ分けする | **Zush（総合おすすめ）** | AIによる命名、任意のフォルダ仕分け、Templateを使った監視、プレビュー、履歴 |
| ファイルを移動せずに探す | Smart Folders（任意） | 仮想フォルダなので、構成を組み替える必要がない |
| ファイルを種類や日付でフォルダに仕分ける | Zush、Automator、Hazel | Zushは普通の言葉で書くフォルダルール、AutomatorとHazelは拡張子のルールを使う |
| 古いファイルを自動でアーカイブする | Hazel | 日付の条件とバックグラウンドでの監視 |
| スクリーンショットにわかりやすい名前を付ける | Zush（AI） | 画像解析で中身に合った名前を付ける |
| PDFを中身に基づいてリネームする | Zush（AI） | 書類のテキストを読んで名前を付ける |
| パターンで一括リネームする | FinderまたはAutomator | 標準のパターン置換機能 |
| ワンクリックでファイルを処理する | Shortcuts | 画面がすっきりしていて、共有しやすい |
| スクリプトや独自のアクションを含むルール | Hazel | macOSで最も高機能なルールエンジン |

一括リネームの方法をもっと詳しく比べたい場合は、[Macでファイル名を一括変更する方法のガイド](/blog/batch-rename-files-on-mac-complete-guide)をご覧ください。共通の接頭辞ではなく、AIでファイルごとに異なる名前を付けたいとわかっているなら、[Mac用の一括リネームツール](/mac)がいちばんの近道です。アカウント登録なしで50回まで無料でリネームできます。

## よくある失敗

**早い段階で自動化しすぎる。** どのファイルに振り分けが必要かわからないうちに、20個ものルールを持つHazelの設定を作るのはやめましょう。2〜3個のルールから始めて、少しずつ増やします。

**名前の問題を放置する。** どのファイルも`IMG_4382.HEIC`のような名前なら、きれいなフォルダに移しても役に立ちません。結局、目的のファイルを探すために1つずつ開くことになります。リネームは仕分けと同じくらい、あるいはそれ以上に重要です。

**ルールをテストしない。** 実際のダウンロードフォルダでフォルダアクションやHazelのルールを有効にする前に、サンプルファイルを入れたテスト用フォルダで試してください。移動ルールが1つ間違っているだけで、ファイルがディスクのあちこちに散らばることがあります。

**サブフォルダを忘れる。** ほとんどの自動化ツールは、初期設定では1階層のフォルダしか監視しません。サブフォルダの中にファイルが入る場合は、下の階層まで監視するように明示的に設定する必要があります。

**元に戻す手段を用意しない。** ファイルをリネームしたり移動したりする自動化には、元に戻す方法が必要です。Hazelはログを残し、Zushはロールバックに対応しています。Automatorには元に戻す機能がないので、取り返しのつかない操作には注意してください。

## よくある質問

### 何もインストールせずにMacでファイル整理を自動化するには？

標準ツールを使います。ファイルを一覧するならSmart Folders、振り分けるならAutomatorかShortcutsです。Smart FoldersはFinderの「ファイル」>「新規スマートフォルダ」から作れます。Automatorでは、特定のフォルダにファイルが入ったときに動くフォルダアクションを作れます。サードパーティのソフトがなくても、ファイルの種類、日付、名前のパターンによる基本的な仕分けはこれでまかなえます。

### macOSのAutomatorとShortcutsの違いは？

Automatorは古くからあるツールで、アクションの種類が多く、シェルスクリプトやフォルダアクションにも対応しています。Shortcutsは新しいツール（macOS Monterey以降）で、画面がすっきりしており、システムのトリガーやSiriとの連携に対応しています。ファイルの自動処理に限れば、シェルスクリプトのアクションとファイル操作の幅広さから、今でもAutomatorのほうができることは多いです。Appleは少しずつ機能をShortcutsへ移しているので、両方知っておく価値があります。

### Hazelはファイルの中身に基づいてリネームできますか？

HazelはPDFや書類の中のテキストを読み取り、リネームのルールに使えます。たとえば、PDFから日付やキーワードを抜き出してファイル名に入れることができます。ただし、Hazelは画像や動画の中身を解析できません。画像を認識する機能がないためです。スクリーンショット、写真、画面収録などの視覚的なファイルには、中身を実際に見て判断できるAIベースのツールが必要です。

### ダウンロードフォルダが散らからないようにするには？

2段構えの仕組みを作ります。まず、届いたファイルを種類別のフォルダへ移す振り分けルールを用意します（Zushのフォルダルール、Automator、Hazelのいずれか）。次に、30日より古いファイルをアーカイブ用フォルダかゴミ箱に移す片づけルールを追加します。この組み合わせで、大事なものを失わずにダウンロードフォルダをすっきり保てます。詳しい手順は[ダウンロードフォルダの整理ガイド](/blog/how-to-organize-downloads-folder-mac)をご覧ください。

### AIによるリネームは安全ですか？ファイルが壊れることはありませんか？

AIによるリネームで変わるのはファイル名だけで、ファイルの中身は変わりません。Zushのようなきちんとしたツールはリネームの履歴も残すので、名前の変更はすぐにロールバックできます。リスクは低いものの、ファイルが大量に届くフォルダで監視を有効にする前に、まず少量のバッチで試し、名前の質を確認してください。

### 写真のファイル整理を自動化するには？

写真は元の名前（`IMG_`、`DSC_`、`DCIM`）から中身がまったくわからないので、特有の難しさがあります。いちばんよいのは、AIによるリネームでわかりやすい名前を付け、日付やイベントごとのフォルダ分けと組み合わせる方法です。写真向けの手順は、[Macで写真を整理するガイド](/blog/best-ways-to-organize-photos-on-mac)をご覧ください。

### 複数の自動化ツールを組み合わせられますか？

はい。2つ目の仕組みが本当に必要な場合は組み合わせられます。名前付けとフォルダ仕分けはZushから始め、必要に応じて、見える化のためにSmart Foldersを、スクリプトやアーカイブのためにHazelかAutomatorを追加します。仕組みを保守しやすく保つために、追加するルールは少なめにしてください。

### 2つの自動化ルールがぶつかるとどうなりますか？

HazelとAutomatorのフォルダアクションが同じフォルダを監視していると、互いに先を争うことがあります。結果は予測できず、一方のツールが処理する前に、もう一方がファイルを移動してしまうかもしれません。解決策は簡単で、1つのフォルダには1つの自動化ツールだけを使うことです。Zushはリネームと仕分けを一度に行えるので、たいていはツール1つで足ります。アーカイブなど、まだHazelに任せたい仕事がある場合は、Zushの処理が終わってから、仕分け先のフォルダをHazelに監視させてください。

## まとめ

macOSでファイル整理を効果的に自動化するには、単純な判断は単純なルールに任せ、見た目だけではわからないファイルはAIに任せることです。このバランスなら、無理なく維持できる仕組みになります。

中身に合った名前付け、必要に応じたAIフォルダ仕分け、取り消しのためにZushから始めましょう。テスト済みの仕分け設定はTemplateに保存してMonitorで使います。保存済みの表示にはSmart Foldersを、スクリプトやアーカイブにはAutomatorかHazelを使います。毎週見直しながら、少しずつ広げていきましょう。

目指すのは完璧な仕組みではありません。ファイル整理にかける時間を、週30分から5分に減らせる仕組みです。
