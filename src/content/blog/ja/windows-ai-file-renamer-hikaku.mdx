### ZushがWindowsで1位の理由

1. **Microsoft Storeからインストールできる。** Windows 10と11向けのx64とARM64のパッケージがあり、アップデートはStoreが管理します。ポータブル版のZIPもあります。
2. **File Explorerになじむ。** Explorer、OneDrive、デスクトップからファイルをドロップゾーンにドラッグするか、Explorerで最大10ファイルを選んでQuick Renameのショートカットを押します。バッチはプレビューでき、再起動後でもRename Historyからバッチ全体を元に戻せます。
3. **PowerRenameには読めないものを読む。** PowerRenameは選んだファイル全体に1つのルールを適用します。Zushは中身から1つ1つのファイルに別々の名前を付けます。PDFのテキスト、写真に写っているもの、動画（MKVを含む）の音声と字幕、そしてWindows限定の機能として、タグのない音楽も特定します。
4. **オフラインのAIは音声にも対応。** OllamaかLM Studioに加えて、AI設定からダウンロードできる任意のオンデバイス音声認識を使えば、音声と動画にクラウドなしで名前を付けられます。同じ$48のライセンスには、最大3台で使える管理型のZush Cloud AIも含まれます。

米国Microsoft Storeでの評価（2026年11月17日時点）：Zushは8件の評価で5.0、RenameClickは6件で3.0、FilesDeskは掲載されていますがまだ評価がありません。Softpediaの編集部の評価：Zush 4.5/5、Renamer.ai 4.5/5、RenameClick 3.5/5。

## ZushはWindowsでどんなクラウドとローカルのAIを使えるか

Zushにはクラウドの選択肢が2つ、ローカルの選択肢が2つあります。名前の組み立て方、プレビュー、適用の手順を変えずに切り替えられます。

| ZushのAIの選択肢 | 解析が行われる場所 | 向いている使い方 |
|---|---|---|
| **Zush Cloud AI** | Zushが管理するクラウドサービス | プロバイダーやモデルの設定なしですぐに始める |
| **BYOK** | 自分のGemini、OpenRouter、OpenAI、Claudeのアカウント | 自分のプロバイダーのアカウントとAPIキーを使う |
| **Ollama** | 自分のPC | 既存のOllama環境でモデルを動かす |
| **LM Studio** | 自分のPC | LM Studioが提供するモデルを使う |

機密性の高いフォルダには、ローカルの選択肢を使えば解析はPCの中で完結し、任意のオンデバイス音声認識で動画にも対応できます。BYOKは、自分が管理するアカウントを経由するとはいえ、クラウドのルートです。それぞれのルートで何が扱われるかは[プライバシーとセキュリティのガイド](/docs/privacy-security)で説明しています。

## AIリネームとPowerRenameの違い

PowerRenameのようなパターン型ツールは、選んだすべてのファイルに1つのルールを適用します。AIリネームツールは1つ1つのファイルを開きます。書類のテキスト、画像やスクリーンショットに写っているもの、動画の音声などです。そのうえでファイルごとに違う名前を提案するので、`scan_004.pdf`が`invoice-7842-webdesign-services.pdf`になります。共通の接頭辞や連番だけで足りるなら、PowerRenameは無料で十分に使えます。そうしたツールは[Windows 11向けファイル名変更ツールのガイド](/blog/best-file-renamer-windows-11)で取り上げています。

[Windows版Zush](/windows)は、スクリーンショット、PDF、Officeファイル、RAWを含む写真、デザインファイル、音声、動画に中身から名前を付けます。用意されたTemplates（Smart Rename、Movies & TV、Remove Duplicatesなど）と145種類以上のNaming Blocksで構造を固定し、組み込みのブロックでカバーできない項目はCustom AI Blocksで抜き出します。

**強み：**

- Microsoft Storeからインストールでき、自動でアップデート
- 1つのワークフローで4つのAIルート：Zush Cloud AI、BYOK、Ollama、LM Studio
- 動画はMKVを含め、音声、埋め込み字幕、メタデータから命名

- フォルダごとにTemplateを割り当てられるフォルダ監視と、任意のAIによるフォルダ仕分け
- 再起動後も残るRename Historyと一括の取り消し。Undo Allは競合を知らせる

**制限：**

- Zush Cloud AIとBYOKにはインターネットが必要。OllamaとLM Studioはローカルで動く

## 2. FilesDesk

FilesDeskはWindowsとMacで動き、Microsoft Storeにも掲載されています。Watch Folders、Gmail、iCloud、IMAPの添付ファイルをリネームするWatch Inbox、テンプレート、取り消し付きの履歴を備えています。サインイン後に15クレジットが無料で付きます。管理型AIはサブスクリプションのみで、500クレジットで月額$8、2,000クレジットで月額$20（年額$80または$200）、AIによる名前の提案1件につき1クレジットを使い、同じファイルを再実行するとさらに1クレジット使います。$40のSelf-Managedライセンスは自分のキーかローカルモデル（Ollama、LM Studio、vLLM）を使い、1台に紐づき、1年間のアップデートが付き、返金期間は3日間です。

**FilesDeskを選ぶべき人：** 届いたメールの添付ファイルをその都度リネームしたい場合。**弱点：** 買い切りライセンスに管理型AIが含まれません。[Zush vs FilesDesk](/blog/zush-vs-filesdesk)もご覧ください。

## 3. RenameClick

RenameClick（現在はrename.click、バージョン4.1.2）はローカルモデルを同梱し、Ollama、LM Studio、自分のクラウドのキーでも動きます。バージョン4.1.2ではMP4、MOV、M4V、3GPの動画に対応しましたが、MKV、WebM、AVIは非対応で、カメラのRAWやデザインファイルにも対応していません。Auto Flowはアプリの起動中にファイルをリネームして移動します。無料プランでは毎月100回のリネームまたは移動ができ、Lifetimeは直販版で最大3台、$36＋VATです。

**RenameClickを選ぶべき人：** Ollamaを設定せずにローカルAIを使いたい場合。**弱点：** 同梱モデルはダウンロードが約4 GBで推奨RAMは16 GB、Undoはメモリ上に10件までで再起動すると消えます。[Zush vs RenameClick](/blog/zush-vs-renameclick)もご覧ください。

## 4. AI Renamer

AI Renamer（airenamer.app）は、Windows、Mac、Linux向けのデスクトップアプリです。バージョン1.9.0ではWatch Folder（ベータ）が加わりましたが、動くのはアプリの起動中だけで、サブフォルダは対象外です。バージョン1.10.0では動画、音声、RAW、HEIC、Office、EPUBに対応しました。Local Modeは買い切り$19で、自分のキー、Ollama、LM Studioを使います。クラウドクレジットは200ごとに$10で、Googleでのサインイン後に10クレジットが無料です。返金の記載はなく、クレジットの購入は返品できません。

GitHubにある無料のGPL-3.0のコマンドラインツール[`ozgrozer/ai-renamer`](https://github.com/ozgrozer/ai-renamer)とは、無関係の別プロジェクトなので混同しないでください。

**AI Renamerを選ぶべき人：** 最も安い買い切りのローカルライセンスが欲しい場合や、Linuxが必要な場合。**弱点：** 取り消しについて記載がありません。[Zush vs AI Renamer](/blog/zush-vs-airenamer)もご覧ください。

## 5. Renamer.ai

Renamer.aiは書類中心のリネームツールで、WindowsとMacのアプリとWebのインターフェースがあります。Microsoft Storeにはありません。Magic Folders、テンプレート、OCR、プレビュー、取り消しが含まれ、ローカルモードは無料のStarterプラン（毎月25ファイル）を含むすべてのプランで使えます。クラウドのプランは、Proが月額$9.95（200ファイル）、Powerが$29.95（1,000）、Ultimateが$99.95（5,000）で、年払いなら15%安くなります。BYOKはUltimateのみです。対応形式の一覧には、カメラのRAW、PSD、Sketch、Figmaがありません。

**Renamer.aiを選ぶべき人：** 主に書類をリネームし、無料でローカル処理をしたい場合。**弱点：** 買い切りライセンスがないため、管理型クラウドでのリネームは月額の従量制です。[Zush vs Renamer.ai](/blog/zush-vs-renamer-ai)や[Renamer.aiの代替](/blog/renamer-ai-alternatives)もご覧ください。

## 6. NameQuick

NameQuickはWindows（x64のインストーラー。ARMのPCではエミュレーションで動作）とMacで動き、Watch Folders、Rules、中身の検索、取り消しを備えています。現行バージョンは3.0.57です。メールアドレスもカードもなしでManagedのリネームを30回使え、70回のリネームが付いた14日間のManagedの試用にはカードが必要ですが、Self-Managedの試用には不要です。Managedプランは月額$12からで、リネームパックは500回で$19、1,500回で$39（有効期間12か月）です。Self-Managedはコンピュータ1台で買い切り$69、生涯アップデートと14日間の返金保証が付きます。AIの費用は別です。

**NameQuickを選ぶべき人：** AIでの命名に加えてルールエンジンが欲しい場合。**弱点：** 買い切りライセンスはコンピュータ1台分で、管理型AIは含まれません。[Zush vs NameQuick](/blog/zush-vs-namequick)もご覧ください。

## 7. PowerShellやPythonで自作

自分で処理の仕組みを作ることもできます。ファイルを読み、テキストや画像をモデルに送り、出力を安全なファイル名に整え、リネームする、という流れです。ただ、再試行、おかしなモデルの出力、名前の重複、Windowsのパスの長さ制限、認証情報、取り消しを加えていくと、一気に難しくなります。

**自作を選ぶべき人：** スクリプトを作って保守すること自体が仕事の一部である場合。**弱点：** 上のアプリに備わっている安全機能は、すべて自分で書くことになります。

## よくある質問

### AIリネームソフトとは何ですか？

AIリネームソフトは、1つ1つのファイルの中身（書類のテキスト、画像に写っているもの、動画の音声）を読み取り、内容がわかるファイル名を提案します。一括リネームツールはバッチ全体でテキストを置き換えたり番号を付けたりできますが、どちらも`scan_004.pdf`という名前なら、請求書と保証書の区別はつきません。Zush、FilesDesk、RenameClick、AI Renamer、Renamer.ai、NameQuickは、Windows向けのAIリネームツールです。

### Windowsで最適なAIファイル名変更ツールはどれですか？

私たちのおすすめはZushです。Microsoft Storeからインストールでき、アカウント、カード、APIキーなしで50回まで無料でAIリネームでき、買い切り$48のライセンスには最大3台で使える管理型クラウドAI、BYOK、Ollama、LM Studioが含まれます。すべてのバッチはプレビューでき、一括で取り消せるRename Historyに残ります。FilesDesk、RenameClick、AI Renamer、Renamer.ai、NameQuickは、それぞれより限られた用途に向いています。

### Renamer.aiとAI Renamerは同じものですか？

違います。Renamer.ai（renamer.ai）はWindows、Mac、Web向けのサブスクリプション型のリネームツールで、プランは月額$9.95〜$99.95、すべてのプランにローカルモードがあります。AI Renamer（airenamer.app）はデスクトップアプリで、買い切り$19のLocal Modeと$10のクラウドクレジットパックがあります。3つ目のプロジェクトであるGitHubの`ozgrozer/ai-renamer`というコマンドラインツールは無料で、どちらとも無関係です。

### 買い切り$48のライセンスは、もっと安いライセンスより価値がありますか？

AIが含まれているほうがいいかどうかによります。AI Renamer Local（$19）とRenameClick Lifetime（$36＋VAT）はアプリの代金で、AIは自分のキーか、PCで動かすモデルで動きます。Zushの$48には、無制限にリネームできる管理型のZush Cloud AIに加えて、BYOKとローカルモデル、今後のアップデートすべて、WindowsとMacあわせて3台、14日間の返金保証が含まれます。

### WindowsのZushでは、ファイルはどこで処理されますか？

Zush Cloud AIやBYOKでは、名前を生成するためにファイルの内容がAIサービスへ送られます。BYOKでは自分のプロバイダーのアカウントを使います。OllamaやLM Studioなら解析はPC上で行われ、任意のオンデバイス音声認識が動画を処理します。プレビュー、手動での確認、Rename Historyは、どのモードでも同じように使えます。[プライバシーとセキュリティのガイド](/docs/privacy-security)をご覧ください。

### WindowsでZushはPowerRenameとどう違いますか？

PowerToysのユーティリティである[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)は、File Explorerで選んだファイルに共通のルールを1つ適用します。検索と置換、正規表現、カウンター、日付やEXIF/XMPのトークンなどです。AIはなく、ファイルの中身も読みません。Zushは1つ1つのファイルを読み取って個別の名前を提案し、バッチをプレビュー、適用、取り消しできます。一律のパターン変更なら、PowerRenameは無料で十分に使えます。

### ブラウザのツールではなく、ネイティブのWindowsアプリはありますか？

あります。[Windows版Zush](/windows)はx64とARM64のパッケージでMicrosoft Storeからインストールでき、Windows 10と11で動きます。FilesDeskとRenameClickもMicrosoft Storeにあります。AI Renamer、Renamer.ai、NameQuickは、それぞれの公式サイトでWindows用のインストーラーを提供しています。ブラウザのツールは代わりにファイルをアップロードするので、ソフトをインストールできないときにたまに使う用途に向いています。
