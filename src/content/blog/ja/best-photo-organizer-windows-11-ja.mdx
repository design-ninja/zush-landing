結論から言うと、ほとんどの人にとってWindows 11で最適な写真整理ソフトは、最初から入っている**Microsoft Photos**です。顔認識、タグ、レーティングのある無料のライブラリなら**digiKam**、一度買えば済む有料のカタログなら**ACDSee Photo Studio**、編集とカタログ管理を両立するなら**Lightroom Classic**、一括処理ツール付きの高速な無料ビューアなら**FastStone Image Viewer**か**IrfanView**です。

**確認方法：** 執筆は[Zush](/)の開発元です。競合ツールの価格、機能、評価は2026年11月17日に各社の公式サイトと公式ストアで確認しました（[出典は記事末尾](#sources-and-how-we-checked)）。ここで比べているのは公開されている機能で、実機テストの結果ではありません。

普通のフォルダにある写真ファイルにも、役に立つファイル名と、カタログを開かなくても理解できる構成が必要です。`IMG_4382.jpg`だけでは、ほとんど何もわかりません。ライブラリが写真の中身を覚えているのは、そのアプリの中だけです。フォルダをドライブにコピーしたり、メールに添付したり、アプリを乗り換えたりすると、その情報は置き去りになります。[Zush](/windows)はわかりやすいファイル名を提案し、対応する写真を中身に応じて実際のフォルダにまとめることもできます。何かが変わる前にはプレビューできます。

## ライブラリ管理と普通の写真フォルダ

写真整理ソフトが解決すべき問題は、2つに分かれます。

- **ライブラリ。** 閲覧、アルバム、顔、レーティング、検索。アプリのデータベースの中にあります。
- **ファイルとフォルダ。** File Explorer、バックアップ用ドライブ、共有フォルダで見える名前と、中身に基づくグループ。

ライブラリアプリは、閲覧、アルバム、カタログ情報を管理します。Zushは、普通のフォルダでのわかりやすい名前と任意のAIによるグループ分けに特化していて、ライブラリのワークフローを補うことができます。

## 1. Microsoft Photos：標準搭載の写真管理

標準の[フォトアプリ](https://support.microsoft.com/en-us/windows/apps/photos/search-photos)は、ピクチャフォルダ、OneDriveの写真、iCloud写真、接続したデバイスを1つのタイムラインに表示します。日付やフォルダで閲覧でき、簡単な編集もできます。

**フォルダー**ペインで、2台目のドライブやカメラの取り込み先など、フォトアプリに表示させるフォルダを追加します。そこでフォルダを削除しても、フォトアプリに表示されなくなるだけで、何も消えません。残したい写真にハートのアイコンを付ければ、お気に入りにまとまります。

検索はどのPCでも、ファイル名、撮影日、ファイルの種類で使え、位置情報を使う機能を許可すれば場所でも探せます。Copilot+ PCでは、説明による検索が加わります。「ビーチの夕日」と入力すると、端末上のAIを使って一致するローカルの写真を見つけます。

Microsoftは2026年10月15日に、自然な言葉での検索、人物のフィルター、OneDriveのモーメントを備えた、フォトアプリの新しいギャラリーを発表しました。まずWindows Insider向けに展開され、Microsoftによると2026年中にすべてのWindows 11ユーザーに提供されます。

できないこと：ファイルのリネーム、中身に応じた写真のフォルダ分け、メタデータの一括編集。ディスク上の名前は`IMG_4382.jpg`のままなので、フォトアプリで見つけた写真も、File Explorer、バックアップ用ドライブ、共有フォルダでは探しにくいままです。

主に閲覧と共有をするならこれで十分です。費用も設定も要りません。

## 2. digiKam：最良の無料写真ライブラリ

digiKamは、KDEコミュニティによる無料のオープンソースの写真管理ソフトで、Windows、macOS、Linuxで動きます。現在の安定版は9.1.0（2026年6月）です。アルバム、階層型のタグ、レーティング、カラーラベル、RAW対応、本格的なメタデータエディタを備え、大きなコレクション向けに作られています。

AI機能はローカルで動きます。顔の検出と認識に加え、AIによるタグ付けとレーティングもあります。メタデータに基づく一括リネームのツールもあります。

サブスクリプションなしで本格的なカタログが欲しいならdigiKamです。画面は情報が多く、慣れるまで時間がかかります。

## 3. Lightroom Classic：編集もするなら

Adobe Lightroom Classicは、カタログ（コレクション、キーワード、レーティング、顔）とプロ品質のRAW編集を組み合わせています。取り込み時に、日付、連番、メタデータから作るテンプレートでファイル名を変えられます。

Lightroom 1TBプランは年間契約で月額$11.99から、フォトプラン1TBは$19.99からです。以前のフォトプラン20GBは新規の申し込みを受け付けていません。買い切りはありません。旧プランについてはAdobeのプランFAQで説明されています。

編集がワークフローの一部ならLightroom Classicです。家族の写真を整理するだけなら過剰です。

## 4. ACDSee Photo Studio：買い切りのカタログ

ACDSee Photo Studio Homeは、カタログ、キーワード、カテゴリ、レーティング、エディタを備えたWindows用の写真管理ソフトです。顔の検出と認識、重複の検出に加え、リネーム、リサイズ、変換の一括ツールもあります。2027年版は64ビット版のWindows 10と11で動きます。

本格的なカタログを今も買い切りで買える、数少ない選択肢の1つです。Photo Studio Home 2027の定価は$69.99です（ACDSeeのストアでは2026年11月18日までのセール価格$59.95が表示されていました）。サブスクリプションならACDSee 365ですが、ストアのページに価格は載っていません。無料の試用版があります。必要なRAMは8 GBで、16 GBが推奨です。

サブスクリプションなしで、Lightroomのような整理をWindowsでしたいならACDSeeです。

## 5. Zoner Studio：写真管理付きの編集ソフト

Zoner Studio（旧Zoner Photo Studio X）は、チェコの開発元によるWindows用の写真編集ソフトで、フォルダの閲覧、レーティング、キーワード付けのための管理機能を備えています。料金ページには顔認識についての記載がありません。

サブスクリプションのみで、個人ライセンスは年額$59、ファミリープランは年額$98です。7日間の無料試用にカードは不要です。

Windows向けに作られた、より軽いLightroomの代替が欲しく、年額プランが気にならないならZoner Studioです。

## 6. XnView MP：高速なビューアと一括処理ツール

XnView MP（バージョン1.12.3）はRAW、HEIF、AVIFを含む500以上の画像形式を開け、大きなフォルダの閲覧も高速です。EXIF、IPTC、XMPのメタデータを編集でき、タグとカテゴリに対応し、重複を見つけ、一括リネームと一括変換もあります。

個人利用と教育目的は無料で、商用ライセンスは€29からです。

飾り気がなく素早く使えて、一括処理ツールが強いブラウザが欲しいならXnView MPです。

## 7. FastStone Image Viewer：Windowsの定番無料ソフト

FastStone Image Viewer（バージョン8.5、2026年6月）は、長く使われているWindows用のビューア、変換ツール、簡易エディタです。タグ付けと1〜5のレーティング、最大4枚を並べて比べる表示、ファイルを変換・リネームする設定可能な一括処理に対応しています。

個人利用と教育目的は無料です。

顔認識は不要で、大きな写真フォルダを素早く見られる無料のブラウザが欲しいならFastStoneです。

## 8. IrfanView：軽量なビューアと一括変換

IrfanViewは、ほぼあらゆる画像形式を開ける小さくて速いビューアで、古いWindowsからWindows 11まで動きます。一括変換とリネームのダイアログで、大きなフォルダを一度に処理できます。

非商用ならフリーウェアで、商用ライセンスは1つ$18です。

ライブラリではなく、閲覧と一括処理のためのできるだけ軽いツールが欲しいならIrfanViewです。

## 9. Mylio Photos：端末間のプライベートな同期

Mylio Photosは、ライブラリを自分の端末に置いたまま、クラウドへのアップロードなしにピアツーピアで同期します。Windows、macOS、iOS、Androidで動きます。顔認識と写真の検索は端末上で行われ、重複も見つけます。

無料で始められ、有料プランで機能が増えます。プランページにはPersonalとBusinessのプランが価格なしで載っているので、価格は購入手続きで確認してください。

写真がスマホ、ノートPC、外付けドライブに散らばっていて、GoogleやiCloudを使わずに1か所にまとめたいならMylioです。

## 10. Zush：わかりやすい名前とAIによるフォルダ仕分け

[Zush](/windows)は写真ライブラリではありません。写真ファイルを中身に応じてリネームするので、どのアプリを使っていても、File Explorer、Windows Search、バックアップ、共有フォルダで見つけやすくなります。

JPG、PNG、HEICや、CR3、NEF、ARW、DNGのようなRAW形式を含む画像を1枚ずつ読み取り、見えたものとメタデータを組み合わせます。

| 変更前 | 変更後 |
|---|---|
| `IMG_4382.jpg` | `2026-08-30_lisbon_tram_28_street.jpg` |
| `DSC01877.ARW` | `2026-06-14_wedding_first_dance.ARW` |
| `PXL_20260712_183455.jpg` | `2026-07-12_dog_running_on_beach.jpg` |

`{Capture Date}_{Event}_{Scene}`のようなパターンはTemplateで決め、「名前を変更」をクリックするまで何も変わりません。提案はダブルクリックで編集できます。Rename Historyはすべてのバッチを記録し、Undo Allで元の名前に戻せます。名前の競合があれば一覧で示し、別の名前での復元を提案します。

Templateで**Detect duplicate files**をオンにすると、バッチ内の完全なコピーを見つけられます。残す、名前に印を付ける、ごみ箱へ移す、から選べます。重複分はクレジットを消費せず、Undoで復元できます。対象は完全に同一のファイルだけで、似たカットは含みません。[重複ファイルの削除](/remove-duplicate-files)もご覧ください。

![Windows版Zushが内容をもとに種類の混ざったファイルをまとめてリネームし、適用前に提案されたファイル名をすべて表示している様子](/videos/windows/zush-batch-rename.mp4)

最初の50回のリネームは、アカウント、カード、APIキーなしでZush Cloud AIを使います。PROは月額$10または買い切り$48です。買い切りライセンスには、Zush Cloud AI、自分のAPIキー、Ollama、LM Studioでの無制限のリネーム、今後のアップデートすべて、WindowsとMacあわせて最大3台のデバイス、14日間の返金保証が含まれます。自分のAPIプロバイダーの利用料は別途請求されます。

Naming Blocks、Custom AI Blocks、フォルダルールを含む[Templatesをエクスポート](/docs/template-import-export)し、別のコンピュータでインポートできます。ローカルの保存先、フォルダの権限、AIの接続はその端末で選び直してください。移るのはワークフローの設定で、ファイルそのものではありません。

## AIで写真ファイルをフォルダに仕分ける

[Zush](/ai-file-sorter)は、対応するファイルにわかりやすい名前を付け、同じバッチで中身に応じて実際のフォルダにまとめることができます。**AIによるフォルダ仕分けはMacとWindowsで使えます。** **Folder rules**を空欄にすればAutoでグループ分けし、普通の言葉でグループを説明することもできます。写真ファイルなら、たとえば次のように書きます。

> 画像を、人物、料理、風景のように被写体ごとにまとめる。

1. コピーした少量のバッチを**AI Rename**に追加し、Templateを選びます。
2. **+ Sort**を有効にし、仕分け後のサブフォルダの起点となる**Destination folder**を選びます。別の保存先を選ばなければ、元のフォルダが起点のままです。
3. **Folder rules**にグループ分けの指示を入力します。ファイル名の形式は**Naming Blocks**で別に決めます。
4. 保存先の中にすでに適切なグループがあるなら、**Reuse existing folders**を有効にします。合うものがなければZushが新しいフォルダを作ります。
5. 提案された名前とフォルダ分けの両方を確認します。バッチを適用する前に、フォルダ名やファイルの置き場所を直しましょう。

![Windows版Zushが「名前を変更して仕分け」の前に、内容ベースのフォルダ分けと提案ファイル名をプレビューしている画面](/images/showcase/windows/folder-sorting-light.webp)

試した保存先とルールをTemplateに保存します。それを**Monitor**に割り当てれば、監視フォルダの直下に届く新しいファイルもリネームして仕分けます。処理済みのファイルがさかのぼって整理し直されることはありません。仕分けをオフにして元の保存先を選んでいれば、ファイルは今のフォルダに残ります。

普通に書き出した画像か、コピーしたFile Explorerのフォルダを使いましょう。digiKam、Lightroom Classic、ACDSeeのようなカタログが管理している元画像は、そのカタログのリネームや再リンクの手順に従ってください。フォルダ分けでアルバム、顔認識、バックアップが加わるわけではありません。

[Windowsでのフォルダ仕分けの手順ガイド](/blog/sort-files-into-folders-with-ai-windows)に沿って進めるか、[フォルダ仕分けのドキュメント](/docs/folder-sorting)と[Folder rulesの例30選](/blog/ai-folder-sorting-prompts)をご覧ください。

Zushは、年ごと、さらに月ごとにまとめるといった入れ子のフォルダルールや、開始番号とゼロ埋めを指定できる連番にも対応しています。リネーム済みのファイルを、名前を変え直したりリネームのクレジットをもう一度使ったりせずに仕分けることもできます。適用前に振り分け先を確認しましょう。この操作は既存のバッチを対象にした別の処理で、MonitorのTemplateを変えてもさかのぼって整理されるわけではありません。[AIによるフォルダ仕分け](/docs/folder-sorting)はMacとWindowsで使えます。

## よくある質問

### Windows 11で最適な写真管理ソフトはどれですか？

用途によります。閲覧と共有ならMicrosoft Photosで十分で、すでにインストールされています。digiKamは、顔、タグ、レーティングを備えた最も強力な無料ライブラリです。RAWファイルの編集もするならLightroom Classic、サブスクリプションなしのカタログが欲しいならACDSee Photo Studio Homeです。ファイルそのものにわかりやすい名前と中身に基づくフォルダが必要なら、Zushを加えましょう。

### Windows 11で最適な無料の写真整理ソフトはどれですか？

日常使いなら、標準搭載で費用もかからないMicrosoft Photosです。顔認識、タグ、レーティングを使う大きなライブラリには、MacやLinuxでも動くdigiKamが最良の無料の選択肢です。一括処理ツール付きの高速なビューアだけでよければ、FastStone Image ViewerとIrfanViewが個人利用なら無料です。XnView MPは個人利用なら無料で、重複検出もあります。

### サブスクリプションなしで使えるWindows用の写真整理ソフトは？

digiKam、FastStone Image Viewer、IrfanView、XnView MPは個人利用なら無料です。ACDSee Photo Studio Homeは定価$69.99の買い切りです。Zushは買い切り$48で、そのライセンスには管理型のZush Cloud AI、無制限のリネーム、今後のアップデートすべて、WindowsまたはMacで最大3台のデバイスが含まれます。Lightroom ClassicとZoner Studioはサブスクリプションのみで、それぞれ月額$11.99、年額$59です。

### Windows 11にはAIによる写真検索がありますか？

Copilot+ PCならあります。フォトアプリは、端末上のAIを使って「ビーチの犬」のような説明からローカルの写真を見つけられます。2026年10月に発表された新しいギャラリーは、まずWindows Insider向けに展開されています。ほかのPCでは、検索はファイル名、日付、ファイルの種類で行われるので、Zushでわかりやすいファイル名を付けておけば、どのPCでもFile ExplorerやWindows Searchで写真を見つけられます。

### 写真を自分のPCの中に置いたまま使えるWindowsの写真整理ソフトは？

digiKamは顔認識とタグ付けをローカルで行い、Mylio Photosは端末上の顔認識を使ってピアツーピアで同期します。Microsoft Photosは、Copilot+ PCでの説明による検索に端末上のAIを使います。Zushは初期設定ではZush Cloud AIにファイルを送りますが、OllamaかLM Studioを選べば解析はPC内で完結します。Lightroomはクラウドライブラリを持ちますが、Lightroom Classicはローカルのカタログで動きます。

### 写真はリネームすべきですか、それともアルバムだけで十分ですか？

両方です。アルバムとタグは1つのアプリのデータベースの中にあるので、フォルダをバックアップ用ドライブにコピーしたり、誰かに送ったり、アプリを乗り換えたりすると置き去りになります。ファイル名はファイルと一緒に、バックアップ、ほかのアプリ、ほかの人のもとへ移動します。大事な写真のまとまりを一度リネームしておけば、どこでも中身がわかり、そのうえでライブラリアプリにアルバムや顔を加えることもできます。

### Windowsで写真を日付順に整理するには？

File Explorerの詳細表示で撮影日時で並べ替えるかグループ化するか、各ファイル名の先頭に撮影日を入れておけば、コピーや共有をしても順番が保たれます。ZushはEXIFから撮影日を読み取り、そのあとに内容の説明を加えられます。無料の方法を含む4つのやり方は、[Windowsで写真を日付でリネームする方法](/blog/rename-photos-by-date-windows)をご覧ください。
