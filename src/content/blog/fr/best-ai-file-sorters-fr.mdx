## Trois façons de décider du dossier

Une consigne décrit la logique : Zush, Sortio et Sparkle. Une liste de catégories impose les choix : RenameClick et AI File Sorter. Des conditions routent par nom, date ou texte : Hazel, NameQuick Rules, File Juggler et DropIt. Les consignes créent des groupes d’après le contenu ; les catégories doivent être entretenues ; les règles échouent face aux fichiers imprévus.

## 1. Zush

Choisissez le **Destination folder** comme racine des dossiers proposés.

**Folder rules** accepte jusqu’à 2 000 caractères ; vide, Auto crée quelques dossiers généraux réutilisables. Le **Template** définit le nom — date, fournisseur, montant, client, sujet — et Folder rules le lieu. Les deux sont prévisualisés ensemble.

Zush lit PDF et scans image, RAW, HEIC, captures, Office, iWork, design, 16 formats vidéo et audio. La vidéo est analysée à partir de ses images. **Reuse existing folders** réutilise les dossiers adaptés et en crée si besoin. **Monitor** applique un Template aux nouveaux fichiers et mémorise les dossiers créés. LM Studio et Ollama gardent analyse et planification sur l’ordinateur. PRO inclut Zush Cloud AI sans quota mensuel.

Le tri est en bêta et crée un niveau de dossiers sous la destination choisie. Vérifiez les fichiers ambigus. Guides [Mac](/blog/sort-files-into-folders-with-ai-mac) et [Windows](/blog/sort-files-into-folders-with-ai-windows).

## 2. Sortio

[Sortio](https://www.getsortio.com/) planifie noms, dossiers et déplacements à partir d’une consigne. Il peut limiter les destinations aux dossiers existants et prévoir un dossier de repli. Le gratuit comprend tri par règles illimité avec cinq règles maximum, surveillance, annulation et essai IA unique. BYOK et Ollama sont disponibles dans tous les forfaits ; Pro a un quota IA. Documents, images, PDF et tableurs sont annoncés sans liste exhaustive. Choisissez Sortio pour Linux ou les équipes, Zush pour audio, vidéo, contrôle des noms et achat unique. [Comparatif Sortio](/blog/zush-vs-sortio).

## 3. RenameClick

[RenameClick](https://rename.click/) propose AI Categories, Metadata Folders et Match Folders parmi 50 dossiers de premier niveau maximum. Auto Flow surveille et copie ou déplace pendant que l’application tourne. Analyse gratuite illimitée, 100 renommages ou déplacements réussis par mois ; modèle local fourni. Vidéo, RAW et design ne figurent pas dans la liste publiée. Adapté aux catégories fixes ; Zush aux regroupements déduits du contenu. [Comparatif RenameClick](/blog/zush-vs-renameclick).

## 4. Sparkle

[Sparkle](https://makeitsparkle.co/) range Bureau, Téléchargements et Documents selon un calendrier. Il construit une AI Library, reçoit des consignes et nettoie doublons et anciennes captures, d’abord vers la Corbeille. Mac uniquement, aussi dans le bundle Every. Aucun renommage. Pour un nettoyage automatique personnel ; choisissez Zush si les noms, Windows ou des règles de dossiers explicites comptent. [Alternatives à Sparkle](/blog/sparkle-alternatives).

## 5. NameQuick

[NameQuick](https://www.namequick.app/) renomme les documents par contenu puis applique des Rules pour déplacer, taguer, colorer ou archiver. Managed commence à $12/mois pour 500 renommages ; Self-Managed à $69 exige une clé API ou un modèle local. Chaque destination demande une règle. [Comparatif NameQuick](/blog/zush-vs-namequick).

## 6. AI File Sorter

[AI File Sorter](https://github.com/hyperfield/ai-file-sorter) est une application AGPL gratuite : catégories, sous-catégories facultatives, listes autorisées, vision locale, extraction de texte et suggestions de noms. Modèles locaux ou clé API personnelle ; annulation du dernier passage. Pas de consigne libre de regroupement ni de surveillance. Audio et vidéo sont classés par métadonnées intégrées. Pour un rangement ponctuel avec configuration de modèle.

## 7. Hazel, File Juggler et DropIt

[Hazel](https://www.noodlesoft.com/) ($42, Mac), [File Juggler](https://www.filejuggler.com/) (environ $40, Windows) et [DropIt](https://www.dropitproject.com/) (gratuit, Windows) surveillent les conditions de nom, extension, date ou texte. Fiables pour des fichiers prévisibles, ils ne comprennent pas les images, scans ou vidéos. Des noms IA peuvent simplifier les règles. [Alternative à Hazel](/hazel-alternative), [options Windows](/blog/hazel-for-windows-alternatives).

Zush pour les consignes libres et les formats variés ; Sortio pour Linux et les équipes ; RenameClick pour des catégories fixes ; Sparkle pour nettoyer un Mac sans renommer ; AI File Sorter pour le gratuit ; Hazel, File Juggler ou DropIt pour des règles exactes.

## Questions fréquentes

### Quel est le meilleur choix général ?
Zush pour Mac et Windows : contenu, aperçu, audio, vidéo et PRO sans quota mensuel.

### Peut-on automatiser ?
Zush, Sortio, RenameClick et Sparkle déplacent les fichiers en dossiers. Avec Zush, enregistrez Folder rules dans un Template et affectez-le à Monitor pour les nouveaux fichiers directement dans le dossier surveillé.

### Quelles options gratuites ?
AI File Sorter est gratuit et ouvert ; Zush offre 50 renommages, Sortio un essai IA unique et RenameClick 100 renommages ou déplacements mensuels.

### Quelles options hors ligne ?
Zush avec LM Studio ou Ollama, RenameClick avec son modèle fourni, Sortio avec Ollama et AI File Sorter avec des modèles locaux.

### IA ou règles classiques ?
Les règles reconnaissent des noms ou extensions ; l’IA lit le contenu et peut regrouper les factures par entreprise même quand leur nom ne dit rien.
