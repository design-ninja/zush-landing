## What Files Magic AI does well

[Files Magic AI](https://1dot.ai/files-magic-ai) bundles three tools:

1. **Organization.** It looks at your filenames and proposes a folder structure, which you preview, adjust, and apply.
2. **Magic Rename.** It reads file contents on your Mac and suggests names, for example `Scan_0043.pdf` becoming `2026-03-14_Invoice_Acme-Studios.pdf`. The vendor documents three local engines—Apple Intelligence, a built-in model, and an optional Rename LLM—plus watched folders for automatically renaming new files.
3. **System Cleaner.** It finds duplicates, unused apps, and caches such as `node_modules`, Xcode, Flutter, and Gradle.

For privacy, the vendor says file contents stay on your Mac; only filenames are sent for AI organization. It supports locally available iCloud, Dropbox, and Google Drive folders.

It is a good fit if you want one inexpensive utility for a messy Mac and you are comfortable letting an app move files.

## What Zush does differently

[Zush](/mac) combines detailed filename controls with optional content-based folder sorting (beta).

**You decide the shape of every name.** Pick a ready-made Template (Screenshots, Bookkeeper Expenses, Photographer Shoots, Client Meeting Notes, and others) or build your own from Naming Blocks: date, vendor, amount, client, scene, capture date, document type. Custom AI Blocks let you ask for any field in plain language. The result is a name that follows the same pattern every time:

- `scan_0042.pdf` → `2026-09-12_acme_invoice_1042_1250usd.pdf`
- `Screenshot 2026-09-18 at 14.12.03.png` → `stripe-revenue-dashboard-september.png`
- `DSC01877.ARW` → `2026-06-14_wedding_first_dance.ARW`

**New files are handled automatically.** Folder monitoring renames files as they land in Downloads, Screenshots, or a scanner folder.

**Nothing is permanent.** Rename History records original name, new name, folder, and time for every batch, and restores it whenever you need.

**It covers more file types**, including RAW photos, PSD, Figma, Sketch, Illustrator, video, and audio.

**It works on Windows too**, with the same Templates and AI modes.

Zush optionally sorts files into AI-named folders (beta) and lets you choose a destination. It does not clean up disk space.

## Sort mixed files into folders with AI

[Zush](/ai-file-sorter) can give supported files descriptive names and group them into real folders by content in the same batch. **AI folder sorting is in beta on Mac and Windows.** Leave **Folder rules** empty for Auto grouping, or describe the groups in plain language. For mixed files, try:

> Group invoices by company and receipts by month.

1. Add a small copied batch in **AI Rename** and select a Template.
2. Enable **+ Sort** and choose the **Destination folder**, which is the root for the sorted subfolders. Without a separate destination, the source folder remains the root.
3. Enter the grouping instruction in **Folder rules**. **Naming Blocks** set the filename format separately.
4. Enable **Reuse existing folders** if suitable groups already exist inside the destination root. Zush can create a new folder when none fits.
5. Review both the proposed names and folder groups. Correct folder names or file placement before applying the batch.

![Zush for Mac previewing content-based folder groups and proposed filenames before Rename & sort](/images/showcase/macos/folder-sorting-light.webp)

Save the tested destination and rules in the Template. Assign it to **Monitor** to rename and sort new files arriving directly inside the watched folder. This does not retroactively reorganize files already processed. With sorting off and the original destination selected, files keep their current folder.

Follow the [step-by-step Mac sorting guide](/blog/sort-files-into-folders-with-ai-mac) or see the [folder sorting documentation](/docs/folder-sorting) and [30 example Folder rules](/blog/ai-folder-sorting-prompts).

## Privacy compared

Both apps can keep file contents on your computer:

- Files Magic AI's Magic Rename runs on device. Its folder organization sends filenames, not contents, to the cloud.
- Zush's local modes (Ollama or LM Studio) keep analysis on your Mac or PC. Zush Cloud AI and BYOK send file content to the selected cloud model to generate names.

For sensitive folders, use Files Magic AI's Magic Rename or Zush with a local model.

## FAQ

### Is Files Magic AI available for Windows?

No. Files Magic AI is Mac only and requires macOS 12 or later. Zush runs on both Mac and Windows.

### Does Files Magic AI upload my files?

According to the vendor, file contents stay on your Mac. For folder organization, only filenames are sent to the cloud; Magic Rename runs on device.

### Can Zush organize files into folders like Files Magic AI?

Yes. Zush offers optional AI folder sorting (beta) and destination folders. Review the proposed groups before applying a batch.

### Which is cheaper, Zush or Files Magic AI?

On lifetime plans they are close: $48 for Zush, $49.99 for Files Magic AI. Files Magic AI's discounted yearly plan is $29; Zush monthly is $10.
