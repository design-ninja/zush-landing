## Why choose Zush?

### Group files by what they contain

Zush's [folder sorting](/docs/folder-sorting) can group invoices by company, receipts by month, or photos by subject. It supports nested folders and custom rules on size, dates, camera, duration, or page count, and it can sort already renamed files without another rename credit. You review proposed names and destinations before applying the batch.

This matters when a folder holds names such as `scan_0042.pdf`: the company or topic is often only inside the file. Files Magic AI sends filenames to plan folders, so it works from the name. Zush can use the content for the folder plan as well as the filename.

### Name video, creative files and documents in one pass

Zush supports [100+ file formats](/docs/supported-file-types), including RAW photos, HEIC, Office, iWork and EPUB documents, PSD, Figma, Sketch, Illustrator, audio, and video. Videos are named from speech, embedded subtitles, and metadata, including MKV. Files Magic AI marks video as not supported. For a project with paperwork, design assets, and clips, that is a reason to start with Zush.

The following are illustrative naming patterns, not measured test results:

- `scan_0042.pdf` → `2026-09-12_acme_invoice_1042_1250usd.pdf`
- `Screenshot 2026-09-18 at 14.12.03.png` → `stripe-revenue-dashboard-september.png`
- `DSC01877.ARW` → `2026-06-14_wedding_first_dance.ARW`

### Undo a whole batch, weeks later

Zush's [Rename History](/docs/undo-history) persists and can revert a whole batch. Undo All lists any conflicts and offers to restore under a new name. Files Magic AI undoes the last rename and recent moves, can revert a single file to its original name, and keeps rename history for 30 days.

### Build a naming convention you can reuse

Zush's [Naming Blocks](/docs/naming-blocks) cover dates, document fields, subjects, and metadata. Combine them in a Template, set case, separators, language, and sequence numbers with a custom start and leading zeros, then add a [Custom AI Block](/docs/custom-ai-blocks) for a field specific to your work. A bookkeeper can keep supplier, invoice number, date, and amount in a fixed order.

Files Magic AI also has reusable templates. Zush's edge is the library of 145+ blocks and saving naming and sorting settings together. Assign a Template to [Monitor](/docs/folder-monitoring) to apply it to new arrivals; on Mac this also covers external drives and resumes after you reconnect them.

Zush also runs on [Windows](/windows), and one license covers up to 3 devices across Mac and Windows, so you can [export Templates](/docs/template-import-export) and keep the same conventions on both.

## Sort mixed files into folders with AI

[Zush](/ai-file-sorter) can give supported files descriptive names and group them into real folders by content in the same batch. **AI folder sorting works on Mac and Windows.** Leave **Folder rules** empty for Auto grouping, or describe the groups in plain language. For mixed files, try:

> Group invoices by company and receipts by month.

1. Add a small copied batch in **AI Rename** and select a Template.
2. Enable **+ Sort** and choose the **Destination folder**, which is the root for the sorted subfolders. Without a separate destination, the source folder remains the root.
3. Enter the grouping instruction in **Folder rules**. **Naming Blocks** set the filename format separately.
4. Enable **Reuse existing folders** if suitable groups already exist inside the destination root. Zush can create a new folder when none fits.
5. Review both the proposed names and folder groups. Correct folder names or file placement before applying the batch.

![Zush for Mac previewing content-based folder groups and proposed filenames before Rename & sort](/images/showcase/macos/folder-sorting-light.webp)

Save the destination and rules in the Template. Assign it to **Monitor** to rename and sort new files arriving in the watched folder. This does not reorganize files already processed. With sorting off and the original destination selected, files keep their current folder.

Follow the [step-by-step Mac sorting guide](/blog/sort-files-into-folders-with-ai-mac) or see the [folder sorting documentation](/docs/folder-sorting) and [30 example Folder rules](/blog/ai-folder-sorting-prompts).

## Privacy: choose the processing mode deliberately

Zush lets you choose [Zush Cloud AI](/docs/zush-cloud-ai), your own provider key, or a local model through [Ollama or LM Studio](/docs/local-ai). Local analysis stays on your computer and does not silently fall back to the cloud. Cloud AI and BYOK send the content needed for analysis to the selected provider; BYOK usage can incur separate provider charges.

Files Magic AI's Magic Rename runs on-device with Apple Intelligence or a built-in model, or with Cloud AI, which sends the text read from the file. Folder organizing sends filenames only. So it isn't purely offline, but its local option needs no separate model download, which is a real convenience over setting up Ollama. For more on local naming in Zush, see the [offline AI file renamer](/offline-ai-file-renamer) page.

## Which should you choose?

Choose **Zush** for searchable, consistent filenames and content-based folder sorting of mixed files, especially when video, RAW photos, or design files are in the batch, and when you want a one-time license that includes managed cloud AI.

## FAQ

### Is Zush a good Files Magic AI alternative?

Yes, for renaming and sorting. Zush groups files by content rather than filename, supports 100+ formats including RAW, design files, and video (which Files Magic AI can't rename), and keeps a persistent Rename History with batch undo. Its $48 one-time license includes managed cloud AI on up to 3 devices. Files Magic AI remains the better pick if you want a system cleaner in the same app.

### Which is better value: Zush $48 or Files Magic AI $49.99 lifetime?

The prices are $1.99 apart, so compare what's included. Zush's $48 license gives unlimited renames on Zush Cloud AI, BYOK, and local models, all future updates, and up to 3 Mac or Windows devices. Files Magic AI's $49.99 lifetime plan, currently marked as a sale, lists unlimited renames on local AI models plus its System Cleaner. Both have a 14-day refund.

### Can I keep file analysis offline?

Yes, in both. In Zush, connect a local model in Ollama or LM Studio; analysis stays on your Mac or Windows PC with no silent cloud fallback. Files Magic AI can rename on-device with Apple Intelligence or a built-in model, so no extra download is needed, but its Cloud AI option sends extracted text. Folder organizing sends filenames only.

### Can Zush organize files that already have good names?

Yes. Zush can sort already renamed files into folders without renaming them again or using another rename credit. You can use Auto grouping, plain-language Folder rules, or custom rules on size, dates, camera, duration, or page count, including nested folders. Review the destination and proposed groups in the preview before anything moves.

### Does Zush replace a Mac cleanup app?

Partly. Zush detects duplicate files during AI Rename and can keep them, mark them in the name, or move them to the Trash, and Undo restores them. It does not uninstall apps, clear caches, or remove developer leftovers such as node_modules. Use a cleanup utility like Files Magic AI's System Cleaner when reclaiming disk space is the main task.
