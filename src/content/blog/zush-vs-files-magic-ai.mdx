## Why choose Zush?

### Use one workflow on Mac and Windows

Zush runs on [Mac](/mac) and [Windows](/windows). You can reuse the same naming conventions across both systems and [export Templates](/docs/template-import-export) rather than rebuild them by hand. Choose the destination folder and grant folder access again on the receiving computer.

One Zush license covers up to 3 devices. If you work on a MacBook and a Windows desktop, you can use both under one license and keep the same filename structure and folder rules.

### Group files by what they contain

Zush's [folder sorting](/docs/folder-sorting) can group invoices by company, receipts by month, or photos by subject. It supports nested folders and can sort already renamed files without another rename credit. You review proposed names and destinations before applying the batch.

The distinction matters when a folder contains names such as `scan_0042.pdf`: the company or document topic may only be available inside the file. Zush can use that content for the folder plan as well as the filename.

### Name creative files alongside documents

Zush supports [100+ file formats](/docs/supported-file-types), including RAW photos, HEIC, Office and iWork documents, PSD, Figma, Sketch, Illustrator, video, and audio. For a project containing paperwork, design assets, and clips, this coverage is a reason to start with Zush.

The following are illustrative naming patterns, not measured test results:

- `scan_0042.pdf` → `2026-09-12_acme_invoice_1042_1250usd.pdf`
- `Screenshot 2026-09-18 at 14.12.03.png` → `stripe-revenue-dashboard-september.png`
- `DSC01877.ARW` → `2026-06-14_wedding_first_dance.ARW`

### Build a naming convention you can reuse

Zush's [Naming Blocks](/docs/naming-blocks) cover dates, document fields, subjects, and metadata. Combine them in a Template, set case, separators, and language, then add a [Custom AI Block](/docs/custom-ai-blocks) for a field specific to your work. For example, a bookkeeper can keep supplier, invoice number, date, and amount in a fixed order.

Files Magic AI also supports reusable templates. Zush's appeal is its library of 145+ blocks and the ability to save naming and sorting settings together. Assign a Template to [Monitor](/docs/folder-monitoring) to apply it to new arrivals, and use [Rename History](/docs/undo-history) to review and undo changes.

## Sort mixed files into folders with AI

[Zush](/ai-file-sorter) can give supported files descriptive names and group them into real folders by content in the same batch. **AI folder sorting works on Mac and Windows.** Leave **Folder rules** empty for Auto grouping, or describe the groups in plain language. For mixed files, try:

> Group invoices by company and receipts by month.

1. Add a small copied batch in **AI Rename** and select a Template.
2. Enable **+ Sort** and choose the **Destination folder**, which is the root for the sorted subfolders. Without a separate destination, the source folder remains the root.
3. Enter the grouping instruction in **Folder rules**. **Naming Blocks** set the filename format separately.
4. Enable **Reuse existing folders** if suitable groups already exist inside the destination root. Zush can create a new folder when none fits.
5. Review both the proposed names and folder groups. Correct folder names or file placement before applying the batch.

![Zush for Mac previewing content-based folder groups and proposed filenames before Rename & sort](/images/showcase/macos/folder-sorting-light.webp)

Save the destination and rules in the Template. Assign it to **Monitor** to rename and sort new files arriving directly inside the watched folder. This does not retroactively reorganize files already processed. With sorting off and the original destination selected, files keep their current folder.

Follow the [step-by-step Mac sorting guide](/blog/sort-files-into-folders-with-ai-mac) or see the [folder sorting documentation](/docs/folder-sorting) and [30 example Folder rules](/blog/ai-folder-sorting-prompts).

## Privacy: choose the processing mode deliberately

Zush lets you choose [Zush Cloud AI](/docs/zush-cloud-ai), your own provider key, or a local model through [Ollama or LM Studio](/docs/local-ai). Local analysis stays on your computer and does not silently fall back to the cloud. You install and run the compatible model yourself. Cloud AI and BYOK send content needed for analysis to the selected provider; BYOK usage can incur separate provider charges.

Files Magic AI's main page now offers local and Cloud AI renaming. Cloud mode sends extracted text; folder organization sends filenames. Its separate Magic Rename guide still describes an entirely local workflow. We use the main page's explicit engine choices here, so readers should not assume every mode is offline.

Both apps offer local processing. Choose Zush if you want to manage local models on either Mac or Windows.

## FAQ

### Is Zush a good Files Magic AI alternative?

Yes. Zush is a strong alternative for AI file renaming and content-based folder sorting, particularly if you use Windows, handle RAW photos and media files, or want 145+ Naming Blocks. Its one-time PRO plan costs $48 and includes unlimited renames across AI modes.

### Can Zush organize files that already have good names?

Yes. Zush can sort already renamed files into folders without renaming them again or using another rename credit. Review the destination and proposed groups before moving them.

### Can I keep file analysis offline with Zush?

Yes. Connect Zush to a compatible local model in Ollama or LM Studio. Local analysis stays on your Mac or Windows PC, with no silent cloud fallback. Cloud AI and BYOK are separate choices.

### Does Zush replace a Mac cleanup app?

Zush handles file naming and organization. It does not remove duplicate files, uninstall apps, or clear developer caches. Use a cleanup utility when reclaiming disk space is the main task.
