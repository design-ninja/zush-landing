## What Hazel does, and what you need to replace

Hazel 6 (current version 6.1.2) watches folders on a Mac and applies rules: if a file matches conditions (name, type, date, contents, source), it renames, moves, tags, archives or runs a script. It costs $42 and has no AI. Softpedia's editors rate it 5.0/5, which is higher than the 4.5 they give Zush, and it earns that for rules-based work.

On Windows, look for the same three pieces:

1. **Folder watching.** Something that notices new files in Downloads, Desktop or a scanner folder.
2. **Conditions.** A way to recognize a file, by pattern or by reading it.
3. **Actions.** Rename, move, copy, delete, extract.

Rules work well for predictable files: every bank statement has the same sender and layout. They fall apart on screenshots, phone photos and PDFs called `document(3).pdf`, because there is no pattern to match. That is the gap AI naming fills. If you are still on a Mac and weighing Hazel itself, our [Hazel alternative](/hazel-alternative) page covers that comparison.

## 1. File Juggler: the closest Hazel replacement

File Juggler is built for the Hazel workflow. You create a rule with a monitored folder, conditions and actions. It can rename using PDF properties, match text inside PDF, Word and Excel files, move files into dated folders, extract archives, run a command, and upload to Evernote. It is still maintained: version 3.1.9 shipped on October 30, 2026, and Softpedia's editors rate it 4.5/5.

A license is $50 one-time plus tax and covers one person on several PCs. The 30-day trial has no feature limits.

Pick it if you already think in Hazel rules. Weakness: like Hazel, it cannot catch a file you cannot describe with a condition, and it has no OCR for image-only scans.

## 2. DropIt: the free option

DropIt is free and open source. Rules match files by name, size, date, properties or regex, and 21 actions cover move, copy, rename, compress, extract and more. You drag files onto a floating target, or let it scan monitored folders on a timer.

Pick it for simple sorting by extension or name pattern when paying is not an option. Weakness: the last release, 8.5.1, came out in February 2018, so it will not get new features.

## 3. Zush: rules plus file content

[Zush](/windows) covers the basic Hazel jobs: Naming Blocks such as Created Date, Modified Date, Extension and Original Name build names from file details, and Monitor can watch only the file types you pick. It also handles the files that break rules. It reads each file, including screenshots, scans, photos, Office documents, audio and video (named from speech, subtitles and metadata, MKV included), and writes a descriptive name:

- `Screenshot 2026-09-18 141203.png` → `stripe-revenue-dashboard-september.png`
- `scan_0042.pdf` → `2026-09-12_acme_invoice_1042.pdf`
- `IMG_4382.jpg` → `2026-08-30_lisbon_tram_28_street.jpg`

Monitor makes it work like a Hazel rule: new files in Downloads or a scanner folder are renamed as they arrive. A Template sets the pattern, so every invoice follows the same `date_vendor_invoice_number` shape. You preview names before applying, and Rename History, which survives a restart, reverts a whole batch later.

Zush can also sort files into folders. Use Auto grouping or write one sentence, such as “Group invoices by company and receipts by month,” in place of a stack of Hazel-style rules. Review the names and destinations, then apply. AI Rename can also catch duplicates and move them to the Recycle Bin; copies use no credits. See [how to sort files into folders on Windows](/blog/sort-files-into-folders-with-ai-windows).

It works right away: 50 free AI renames on Zush Cloud AI, with no account, card, API key or model download. For files that should stay on the PC, use Ollama or LM Studio. The $48 one-time license includes the managed cloud AI plus every local and BYOK mode, all future updates, up to 3 devices across Windows and Mac, and a 14-day refund. On the Microsoft Store (US) Zush has 5.0 from 8 ratings (as of November 17, 2026).

Weakness: Zush has no general scripting engine, and it does not offer actions like extracting archives or running a command.

## 4. Sortio: AI that plans folders and moves files

Sortio takes a sentence like "sort invoices by year and screenshots by project", shows a plan, then renames and moves files. It runs on Windows 10/11, macOS and Linux.

The free plan includes up to five rules and three Spaces, a one-time AI trial, preview and undo. Smart Folders that keep watching for new files need Pro, at $14.99 per month or $99 per year. Local models via Ollama or LM Studio and your own API key work on every plan, including Free, and a local model keeps processing on your PC.

Pick it when you want AI to decide where files go and also need Linux. Weakness: the Hazel-like watching part is Pro-only, and hosted AI is a monthly allowance unless you use your own key or a local model. See [Zush vs Sortio](/blog/zush-vs-sortio).

## 5. PowerShell and Task Scheduler: the DIY route

Windows already has the parts: PowerShell can rename and move files, and Task Scheduler can run a script every few minutes or at login. A minimal "move PDFs out of Downloads" script looks like this:

```powershell
Get-ChildItem "$env:USERPROFILE\Downloads" -Filter *.pdf |
  Move-Item -Destination "$env:USERPROFILE\Documents\PDFs"
```

It is free and as flexible as your scripting. You also own everything: duplicate names, locked files, logging and undo.

## A Hazel-style setup on Windows

For content-based grouping, save a Zush Template with Folder rules, a destination and Reuse existing folders, then assign it to Monitor. New files directly inside the watched folder are renamed and sorted; changing the Template later does not reorganize files already processed. Preview a manual batch first. See [AI folder sorting](/docs/folder-sorting).

Zush can do the moves from a typical rule itself, for example “Invoices to Finance\Invoices, receipts to Finance\Receipts.” Add a second tool only for actions Zush lacks:

1. **Zush monitors Downloads** and renames and sorts each new file, using a Template such as `{Created Date}_{Vendor}_{Document Type}`.
2. **File Juggler watches the destination folder** and runs the extra action, such as extracting archives or running a command.

Test with copies first. Once both steps look right, point them at the real folder.

## FAQ

### Is there a Hazel for Windows?

No. Hazel is macOS-only, and Noodlesoft does not make a Windows version. File Juggler is the closest Windows equivalent for rule-based renaming and moving, with instant folder monitoring and a $50 one-time license. DropIt is a free alternative, though its last release is from 2018. Zush renames and sorts by date and file type too, and adds AI naming and folder sorting for files with no pattern.

### What is the best free Hazel alternative for Windows?

DropIt is free and open source, but it has not been updated since February 2018. PowerShell with Task Scheduler is free if you can script. Sortio's free plan covers up to five rules without folder watching. Zush gives 50 free AI renames with no account or card, and it sorts files into folders as well.

### Is a Hazel alternative for Windows worth paying for?

If your rules keep growing, yes. File Juggler is $50 plus tax one-time for rules without AI. Zush is $48 one-time and includes the managed Zush Cloud AI, local and BYOK modes, unlimited renames, all future updates and up to 3 devices across Windows and Mac. Sortio Pro is $99 a year. Try each on copies during its trial before buying.

### Do these tools send my files to the cloud?

File Juggler, DropIt and PowerShell process everything locally because they only use rules. Zush keeps analysis on your PC when you choose Ollama or LM Studio; in Zush Cloud AI or BYOK mode, file content goes to that cloud model to generate a name. Sortio offers hosted AI, plus your own key or a local model via Ollama or LM Studio on every plan, including Free; watch folders need Pro. Use a local mode for confidential folders.

### Can Zush sort files into folders as well as rename them?

Yes. Choose Auto or write Folder rules, select the destination, and review both names and groups in a manual batch. A sorting-enabled Template can also process new files directly inside a monitored folder; changing the Template does not reorganize files already processed. Leave sorting off and keep the original destination if you only want better names.

### Can Zush replace Hazel on Windows?

Partly. Zush can name files by date, file type and content and move them into AI-planned folders, including through Monitor, which covers the most common Hazel jobs. It does not provide a general scripting engine, archive extraction or every conditional action Hazel has. If you rely on those, pair Zush with File Juggler, or compare the actions your workflow actually needs.

### Can Windows organize files automatically without extra software?

Partly. Storage Sense can delete old files from Downloads, and PowerShell scripts scheduled with Task Scheduler can move or rename files. Neither reads what a file contains, so a screenshot or scan with a generic name stays unidentified. See [how to organize files automatically on Windows 11](/blog/organize-files-automatically-windows-11) for the built-in options.
