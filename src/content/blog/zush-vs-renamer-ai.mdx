![Zush AI rename results showing files with descriptive before and after names and green checkmarks](/images/showcase/macos/batch-rename-light.webp)

Zush's strongest advantage is naming control. Ready-made Templates cover recurring jobs, while 145+ Naming Blocks and Custom AI Blocks define exactly which fields appear. Formatting, localization, tags, metadata, and per-folder Template assignment keep the convention consistent. Rename History stores original and new names, folder, and timestamp and can revert an applied batch. Version 3.0 also supports 100+ image, RAW, design, document, video, and audio formats.

Pricing has two PRO options: <BlogHighlight>$10/month</BlogHighlight> for flexibility or <BlogHighlight>$48 one-time</BlogHighlight> for lifetime access. FREE includes 50 renames shared across Zush Cloud AI, BYOK, LM Studio, and Ollama; both PRO options remove that limit. BYOK supports Gemini, OpenRouter, OpenAI, and Claude, while both local routes work on Mac and Windows.

### AI folder sorting in Zush

Zush also **sorts files into folders with AI (beta)**. Choose **Auto** grouping or write **Folder rules**, for example “Group invoices by supplier and videos by topic.” This works alongside filename Templates and Naming Blocks: naming fields set the convention, while folder instructions decide the groups. It is part of Zush’s desktop workflow, not a browser workflow.

Choose a **Destination folder**, or keep the source folder as the root. Enable **Reuse existing folders** to prefer suitable folders already there; Zush can create a new one when nothing fits. In a manual batch, review both the suggested names and folders before applying. To rename in place, leave sorting off and keep the original destination.

Save the sorting settings in a **Template** and assign it to **Monitor** for new files directly inside the watched folder. This does not reorganize files already processed. Test the Template in a manual batch first. See the [folder sorting guide](/docs/folder-sorting) for the setup and monitoring scope.

Renamer.ai is a desktop and web tool focused on document-heavy workflows. It lists 30+ formats, including PDFs, Office files, common photos, vectors, and email. Its v5 release adds downloadable local models, OpenAI/Gemini BYOK, account-synced templates, a Template Gallery, sample-file tests, reusable nested folder structures, and destination previews. Camera RAW, Sketch, Figma, and PSD are still absent from its published format list; that is a documentation boundary, not proof that every unlisted file fails.

Pricing is monthly subscription with four tiers: free Starter (25 files/month), Pro $9.95/mo (200 files), Power User $29.95/mo (1,000 files), and Ultimate $99.95/mo (5,000 files). Annual billing gives a 15% discount per their site.

## Format support

Mixed-file folders are where format coverage starts to matter:

### Camera RAW is documented in Zush; HEIC is shared

Zush's public format list includes 11 RAW variants: CR2, CR3 (Canon), NEF (Nikon), ARW (Sony), DNG (Adobe), ORF (Olympus), RAF (Fujifilm), RW2 (Panasonic), PEF (Pentax), SRW (Samsung), SR2 (Sony). Renamer.ai's public format list does not include any camera RAW formats.

If you are a photographer or anyone with `IMG_4382.HEIC` or `_DSC0019.NEF` files in your library, Zush is the documented fit. Renamer.ai's omission of RAW from its public format list is a concrete limitation.

### Vector, design, and office formats

On the document/vector side, Renamer.ai lists EPS, SVG, and AI. Zush 3.0 now supports SVG plus design-first formats: Sketch, Figma `.fig`, Adobe Illustrator `.ai`, and Photoshop `.psd`. Zush also adds iWork files, audio formats, video formats, and subtitle sidecars. If EPS specifically matters, Renamer.ai has that listed publicly; if your folders mix design handoff assets with screen recordings, iWork docs, audio, and RAW photos, Zush is broader.

### Both handle the common case

For JPG, PNG, HEIC, PDF, DOCX, and XLSX, both publish support. Both also offer BYOK, local processing, monitoring, and undo. Compare specialist file coverage and naming controls rather than treating those shared features as exclusive to Zush.

## Features that differ

### BYOK

<BlogHighlight>Zush includes BYOK on every plan</BlogHighlight>: connect Gemini, OpenRouter, OpenAI, or Claude within the 50-rename free allowance, or without the Zush app cap on PRO. Renamer.ai v5 documents OpenAI and Gemini BYOK, key validation, and an optional usage counter. Provider charges are separate in either product; confirm Renamer.ai's Local/BYOK license entitlements before purchase.

### Local AI mode

Zush connects to LM Studio or Ollama on Mac and Windows. Renamer.ai v5 downloads models inside the app and documents processing entirely on the computer, with model quality levels and hardware checks. Neither product's local-mode quality or speed was independently benchmarked for this article.

Processing depends on the mode. Local inference keeps the analysis on the device according to each vendor; cloud processing uses remote services; BYOK sends the required content to the chosen provider under your account. Renamer.ai's older generic FAQ still describes server transmission, so it should not be used to claim that all v5 desktop modes upload files.

### Web access

Renamer.ai has a web interface in addition to the desktop app — useful if you cannot install software (corporate machine, occasional one-off use). Zush is desktop-only on Mac and Windows.

### Language support

Zush states 60+ output languages; Renamer.ai states 20+. If you generate filenames in non-English languages routinely, Zush is broader.

## Pick by use case

**Pick Zush if:**

- You want one-time pricing instead of recurring billing
- You handle RAW photos (CR2/NEF/ARW/DNG/etc.) or HEIC from iPhone
- You work with design assets, iWork files, audio, videos, or mixed project folders
- You want templates and Naming Blocks for repeatable filename structures
- You want BYOK available on every plan
- You want LM Studio or Ollama for on-device work
- You need 60+ language support for non-English filenames

**Where Renamer.ai has a different fit:**

- You need a web interface in addition to a desktop app
- You need account-synced templates or an in-app downloadable model workflow
- Its published cloud allowance fits your workload, and you have checked support for your specialist formats

## FAQ

### Can Zush sort files into folders as well as rename them?

Yes. Its optional AI folder sorting is in beta on Mac and Windows. Choose Auto or write Folder rules, select the destination, and review both names and groups in a manual batch. A sorting-enabled Template can also process new files directly inside a monitored folder; it does not reorganize files already processed. Leave sorting off and keep the original destination for naming only.

### Is Zush cheaper than Renamer.ai?

Yes by a large margin if you choose Zush One-Time. Zush is $48 one-time or $10/month. Renamer.ai's cheapest paid tier is $9.95/month ($120/year). Over 5 years, Zush One-Time is more than 12× cheaper than Renamer.ai's Pro tier and more than 120× cheaper than their Ultimate tier.

### Does Renamer.ai support RAW photos like CR2 or NEF?

The format list on Renamer.ai's public site does not include camera RAW formats. If you shoot RAW, Zush is the safer pick — its image list explicitly covers CR2, CR3, NEF, ARW, DNG, ORF, RAF, RW2, PEF, SRW, SR2, and generic RAW extensions.

### Does Renamer.ai keep files local?

Yes in its v5 Local mode, according to the September 25 release notes. Cloud and BYOK have different data paths. Select and verify the mode, model, and license terms rather than relying on older generic desktop-upload FAQ wording.

### Can I use my own OpenAI key with Renamer.ai?

Yes. Renamer.ai v5 supports OpenAI and Gemini BYOK. Zush supports Gemini, OpenRouter, OpenAI, and Claude on every plan. Both require a provider account and may incur API charges.

### Do both have folder monitoring?

Yes. Zush has folder monitoring built into the desktop app. Renamer.ai calls theirs "Magic Folders" and includes it in paid tiers.

### Can I undo renames in either tool?

Yes. Zush keeps a full rename history with one-click revert. Renamer.ai supports undo as well.

## Verdict

Both tools work for everyday AI file renaming and both have folder monitoring + undo. The decision splits cleanly:

- If you want to pay once and never think about it again, handle RAW/HEIC/design/iWork/audio/video, and run BYOK without a separate BYOK purchase: <BlogHighlight>Zush at $48 one-time</BlogHighlight>.
- Renamer.ai adds web access, account-synced templates, and downloadable local models. Its cloud plans remain metered, and the public format list does not establish camera RAW or design-project coverage.
