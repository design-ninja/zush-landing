## What cloud and local AI options does Zush offer on Windows?

Zush has two cloud options and two local ones. You can switch between them without changing how you build, preview and apply names.

| Zush AI option | Where analysis runs | Best fit |
|---|---|---|
| **Zush Cloud AI** | Zush-managed cloud service | Start immediately, no provider or model setup |
| **BYOK** | Your Gemini, OpenRouter, OpenAI or Claude account | Use your own provider account and API key |
| **Ollama** | Your PC | Run models from an existing Ollama setup |
| **LM Studio** | Your PC | Use models served by LM Studio |

For sensitive folders, a local option keeps analysis on your PC; optional on-device speech recognition covers video. BYOK is still a cloud route, through an account you control. The [privacy and security guide](/docs/privacy-security) explains what each route handles.

## How AI renaming differs from PowerRename

Pattern tools like PowerRename apply one rule to every selected file. An AI renamer opens each file: document text, what an image or screenshot shows, or the speech in a video. Then it proposes a different name for each one, so `scan_004.pdf` becomes `invoice-7842-webdesign-services.pdf`. If a shared prefix or number sequence is all you need, PowerRename is free and fine; the [Windows 11 file renamer guide](/blog/best-file-renamer-windows-11) covers those tools.

## 2. FilesDesk

FilesDesk runs on Windows and Mac and is listed in the Microsoft Store. It has Watch Folders, a Watch Inbox that renames attachments from Gmail, iCloud or IMAP, templates, and history with undo. You start with 15 free credits after sign-in. Managed AI is subscription-only: $8/month for 500 credits or $20/month for 2,000 ($80 or $200 yearly), at 1 credit per AI name suggestion; re-running a file uses another credit. The $40 Self-Managed license uses your own key or a local model (Ollama, LM Studio, vLLM), binds to 1 device, includes one year of updates, and has a 3-day refund window.

**In our test:** sign-in came first. FilesDesk silently left out all RAW and HEIC photos, and with 24 files selected it refused to start until we cut the batch to its 15 free credits. Undo works one file at a time.

## 7. DIY PowerShell or Python

You can build your own pipeline: read files, send text or images to a model, clean the output into a safe filename, rename. It gets harder once you add retries, bad model output, duplicate names, Windows path limits, credentials and undo.

## FAQ

### What is AI renamer software?

AI renamer software reads the content of each file (document text, what an image shows, speech in a video) and suggests a descriptive filename for it. A bulk rename tool can replace text or add numbers across a batch, but it cannot tell an invoice from a warranty card when both are named `scan_004.pdf`. Zush, FilesDesk, RenameClick, AI Renamer, Renamer.ai and NameQuick are AI renamers for Windows.

### What is the best AI file renamer for Windows?

Our pick is Zush. It installs from the Microsoft Store, gives 50 free AI renames with no account, card or API key, and its $48 one-time license includes managed cloud AI, BYOK, Ollama and LM Studio on up to 3 devices. Every batch is previewed and kept in Rename History with batch undo. In our test of six apps on the same 30 files it renamed all 30 and scored 94.8 out of 100. FilesDesk, RenameClick, AI Renamer, Renamer.ai and NameQuick each fit narrower needs.

### Is Renamer.ai the same as AI Renamer?

No. Renamer.ai (renamer.ai) is a subscription renamer for Windows, Mac and web, with plans from $9.95 to $99.95 a month and local mode on every tier. AI Renamer (airenamer.app) is a desktop app with a $19 one-time Local Mode and $10 cloud credit packs. The free `ozgrozer/ai-renamer` command-line tool on GitHub comes from the same developer as AI Renamer but is a separate project.

### Is a $48 one-time license worth more than a cheaper one?

It depends on whether you want AI included. AI Renamer Local ($19) and RenameClick Lifetime ($36 + VAT) cover the app, but the AI runs on your own key or a model your PC must run. Zush's $48 includes managed Zush Cloud AI with unlimited renames, plus BYOK and local models, all future updates, 3 devices across Windows and Mac, and a 14-day refund.

### Where are my files processed with Zush on Windows?

With Zush Cloud AI or BYOK, file content goes to an AI service to generate names; BYOK uses your own provider account. With Ollama or LM Studio, analysis runs on your PC, and optional on-device speech recognition handles video. Preview, manual confirmation and Rename History work the same in every mode. See the [privacy and security guide](/docs/privacy-security).

### How is Zush different from PowerRename on Windows?

[PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename), the PowerToys utility, applies one shared rule to your File Explorer selection: search and replace, regex, counters, and date or EXIF/XMP tokens. It has no AI and never reads file content. Zush reads each file and proposes its own name, then lets you preview, apply and undo the batch. PowerRename is free and fine for uniform pattern changes.

### Is there a native Windows app, not just a browser tool?

Yes. [Zush for Windows](/windows) installs from the Microsoft Store with x64 and ARM64 packages and runs on Windows 10 and 11. FilesDesk and RenameClick are also in the Microsoft Store. AI Renamer, Renamer.ai and NameQuick offer Windows installers from their own sites. Browser tools upload your files instead, which suits occasional use when you cannot install software.
