## Try ten files before choosing a paid plan

1. Install [Zush for Windows](/windows) through the Microsoft Store. Managed cloud is the simplest starting point if you do not want to configure a provider or local model.
2. Copy ten recognizable files into a test folder: a screenshot, invoice PDF, Word document, spreadsheet, presentation, and other formats you use.
3. Open **AI Rename** and choose a Template. Inspect every suggestion, including identifiers, dates, and extensions. Adjust Naming Blocks or skip results that need more work.
4. Apply the reviewed names, then open the renamed files. Use [Rename History](/docs/undo-history) to test restoring the batch.
5. Save the Template only when its results fit your convention. Test [Monitor](/docs/folder-monitoring) separately on new arrivals before assigning your everyday Downloads folder.

## Choose cloud or local processing

| Zush mode | Where supported analysis runs | What you configure |
|---|---|---|
| Managed cloud | Through the Zush-managed cloud service | No personal provider key or local model |
| BYOK | Through your chosen cloud provider | Your provider account and API key |
| Ollama | On your device through Ollama | A suitable local model and connection |
| LM Studio | On your device through LM Studio | A suitable model and local server |

BYOK is cloud processing, not an offline mode. Local options require setup and suitable model capabilities. Follow [local AI setup](/offline-ai-file-renamer) and the [privacy guide](/docs/privacy-security). FREE includes 50 renames across all modes; Zush PRO costs $10/month or $48 one-time; check [current pricing](/pricing) and remember that your own API provider can charge separately.

## Add folder sorting after naming works

In Zush, turn on **Sort**, choose a test destination, and enter a Folder rule such as “Group invoices by company and receipts by month.” Leave the rules empty for Auto grouping. Naming Blocks control the filename separately from the folder instruction.

![Zush for Windows previewing proposed folders and filenames before Rename & sort](/images/showcase/windows/folder-sorting-light.webp)

Folder sorting is in beta. Review every destination before applying and test restoring names and folders from history. Avoid files referenced by active projects. A sorting-enabled Template can later be assigned to Monitor; automated arrivals do not necessarily wait for the same manual approval as your first batch. See the [Windows sorting walkthrough](/blog/sort-files-into-folders-with-ai-windows).

## FAQ

### What is the best AI file renamer for Windows?

Zush is our best overall choice for mixed desktop folders. It combines Templates, content-based naming, broad published format support, preview, persistent Rename History, and Monitor, with managed cloud, BYOK, Ollama, and LM Studio options.

### Is Zush a FilesDesk alternative?

Yes. Try Zush when you want a Microsoft Store app with configurable naming, cloud or local analysis, and persistent history. Run a copied sample of the formats you actually use. The [direct comparison](/blog/zush-vs-filesdesk) explains plan and workflow differences; support for your files matters more than a universal winner.

### What if I only need to replace text in filenames?

AI may be unnecessary. Zush is most useful when the new name depends on what is inside a screenshot, document, or other supported file. Pattern-only changes are a different task.

### What should I test for PDFs and Downloads?

Start with the [Zush PDF workflow](/rename-pdf-with-ai) and verify extracted fields. After the Template works, follow [Downloads automation](/automate-downloads-folder), inspect the first arrivals, and keep only one organizer responsible for the folder.
