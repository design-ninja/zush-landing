Zush runs local analysis through [LM Studio](/docs/lm-studio) or [Ollama](/docs/offline-ai) on Mac and Windows. You choose and run a compatible model in the local server, then connect Zush to it. Supported analysis stays on your computer while the local mode is selected.

## Requirements

- the latest Zush version for Mac or Windows
- macOS 15 or later, or Windows 10/11
- LM Studio or Ollama installed on the same computer
- a compatible local model with enough disk space and memory for your hardware
- internet access for installation and model download; analysis can run offline afterward

## Set up local AI

<Steps>
1. Open Zush Settings and select **AI Modes**.
2. Start LM Studio or Ollama and load a compatible model.
3. In Zush, select **LM Studio** or **Ollama**.
4. Confirm the local server address and model.
5. Open **AI Rename** and test a small representative batch.
</Steps>

## Choose a local server

| Option | Use it when |
| --- | --- |
| [LM Studio](/docs/lm-studio) | You want a desktop model catalog and server controls |
| [Ollama](/docs/offline-ai) | You already manage local models through Ollama or prefer its command-line workflow |

<Aside type="note">
LM Studio and Ollama normally listen on a local address on your Mac or Windows PC. Zush does not silently fall back to cloud analysis while either local mode is selected.
</Aside>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Zush cannot connect | Confirm that LM Studio or Ollama is running and that the server address matches Zush Settings |
| The model is not listed | Load or pull a compatible model in LM Studio or Ollama, then refresh the model list in Zush |
| Analysis is slow | Try a smaller compatible model or close other memory-intensive apps |
| A file type fails | Test a supported file with a vision-capable model and check the relevant local-server logs |
