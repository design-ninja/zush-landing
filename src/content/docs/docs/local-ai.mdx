Local AI is built into Zush for Mac and Windows. Zush downloads a supported model, runs the local inference runtime on your computer, and keeps supported analysis content off cloud AI services.

</figure>

## Requirements

- the latest Zush version for Mac or Windows
- macOS 15 or later, or Windows 10/11
- about 3.4 GB of free disk space for the current model download
- enough memory for the selected **Resource Use** profile
- internet access for the initial model download; analysis can run offline afterward

## Set up Local AI

<Steps>
1. Open Zush Settings and select **AI Modes**.
2. Select **Local AI**.
3. Click **Download & Start**.
4. Keep Zush open while the model downloads and is verified.
5. When the status is **Running**, choose a **Resource Use** profile if needed.
6. Open **AI Rename** and test a small representative batch.
</Steps>

## Resource Use profiles

| Profile | Use it when |
| --- | --- |
| Memory Saver | You want the smallest memory footprint |
| Recommended | You want the default balance of speed and memory use |
| Max Speed | Your computer has enough available memory and you want higher throughput |

Changing the profile restarts the local runtime. You can stop Local AI, re-download the model, or delete it from the same settings card.

<Aside type="note">
Local AI listens only on a loopback address on your Mac or Windows PC. Zush does not fall back to cloud analysis while this mode is selected.
</Aside>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Download stops | Check the network connection and click **Check Again** or restart the download |
| Local AI will not start | Free memory, choose **Memory Saver**, and try again |
| Analysis is slow | Try **Recommended** or **Max Speed** if your computer has enough available memory |
| You need a different model | Use [LM Studio](/docs/lm-studio) or [Ollama](/docs/offline-ai) |
