The app runs on Mac and Windows. Install it from the product page for your operating system, then use the same core AI file renaming workflow on either platform.

Quick links: [download for Mac](/download/mac), open the [Mac App Store listing](https://apps.apple.com/app/zush/id6758432449), install with [Homebrew](https://formulae.brew.sh/cask/zush), or open the [Microsoft Store listing](https://apps.microsoft.com/detail/9ND4WVZSDQ3X).

## Install on Mac

Mac users can install the app from the [Mac product page](/mac), the [direct signed .dmg download](/download/mac), the [Mac App Store listing](https://apps.apple.com/app/zush/id6758432449), or the [Homebrew cask](https://formulae.brew.sh/cask/zush) with `brew install --cask zush`. Depending on the build you choose, updates are handled by the store channel, Homebrew, or the signed direct app update flow.

The Mac app supports macOS 15.0 and newer. Folder access is granted by the user when files, folders, or monitored folders are selected.

## Install on Windows

Install from the [Microsoft Store listing](https://apps.microsoft.com/detail/9ND4WVZSDQ3X) for Store-managed installation and updates. The [Windows product page](/windows) links to the Store.

For a portable installation, download a ZIP for your architecture from the [official Windows releases](https://github.com/design-ninja/zush-windows-releases/releases/latest), extract it, and run Zush. Portable builds are updated separately from the Microsoft Store; download a newer portable release when needed.

The Windows app supports Windows 10 and Windows 11.

## Requirements

| Requirement | Notes |
| --- | --- |
| Memory | 4 GB minimum; more memory is recommended for local models. |
| Disk space | About 200 to 250 MB for the app, plus the space required by any Ollama or LM Studio models you install. |
| Network | Required for managed Cloud AI, BYOK, updates, and initial model downloads. Local AI modes can analyze offline after setup. |
| Local AI | Available through Ollama or LM Studio on Mac and Windows. See the [Local AI guide](/docs/local-ai). |
| External local models | Install [Ollama](/docs/offline-ai) or [LM Studio](/docs/lm-studio) and a compatible vision model. |

## Update behavior

Store builds update through the platform store. The direct Mac app uses its signed update flow; Homebrew users can also update through Homebrew. Windows portable builds use the separate release download. Keep the app current before testing new file types, [AI modes](/docs/ai-modes), or [monitored folder workflows](/docs/folder-monitoring).
