The managed cloud AI mode works without an API key or a local model. Choose it when you want to add files and start renaming immediately.

## Use managed Cloud AI

<Steps>
1. Open Zush Settings.
2. Select **AI Modes**.
3. Select **Zush Cloud AI**.
4. Open **AI Rename**, add supported files, and start analysis.
5. Review the proposed names before applying the batch.
</Steps>

## What is sent for analysis

Zush keeps your original files on your Mac or Windows PC. Depending on the file type, cloud analysis can use a compressed visual preview, sampled media, extracted text, or a compact summary needed to generate a filename. See [Privacy and security](/docs/privacy-security) for the detailed processing model.

<Aside type="note">
Choose [LM Studio](/docs/lm-studio) or [Ollama](/docs/offline-ai) when supported analysis content must stay on your Mac or Windows PC. The [local AI overview](/docs/local-ai) compares both routes.
</Aside>

## When to choose another mode

- Use [LM Studio](/docs/lm-studio) for advanced local model and server control.
- Use [BYOK](/docs/byok) for your own cloud provider key and account.
- Use [Ollama](/docs/offline-ai) for models you already manage through Ollama.
