Zush Cloud AI is the managed mode that works without an API key or a local model. Choose it when you want to add files and start renaming immediately.

## Use Zush Cloud AI

<Steps>
1. Open Zush Settings.
2. Select **AI Modes**.
3. Select **Zush Cloud AI**.
4. Open **AI Rename**, add supported files, and start analysis.
5. Review the proposed names before applying the batch.
</Steps>

## What is sent for analysis

Zush keeps your original files on your Mac. Depending on the file type, cloud analysis can use a compressed visual preview, sampled media, extracted text, or a compact summary needed to generate a filename. See [Privacy and security](/docs/privacy-security) for the detailed processing model.

<Aside type="note">
Choose [Local AI](/docs/local-ai), [LM Studio](/docs/lm-studio), or [Ollama](/docs/offline-ai) when supported analysis content must stay on your Mac.
</Aside>

## When to choose another mode

- Use [Local AI](/docs/local-ai) for built-in offline analysis managed by Zush.
- Use [LM Studio](/docs/lm-studio) for advanced local model and server control.
- Use [BYOK](/docs/byok) for your own cloud provider key and account.
- Use [Ollama](/docs/offline-ai) for models you already manage through Ollama.
