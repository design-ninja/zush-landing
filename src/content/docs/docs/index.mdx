## Rename and organize files

- [Batch rename](/docs/batch-rename-files) — review and edit suggested filenames before applying changes.
- [Quick Rename](/docs/quick-rename) — rename selected files with a shortcut or the Mac Finder action.
- [Folder monitoring](/docs/folder-monitoring) — automatically process new files in a watched folder.
- [Folder sorting](/docs/folder-sorting) — move files into suggested folders, use nested rules, or keep current names.
- [Undo history](/docs/undo-history) — restore names and locations, and handle files that cannot be restored immediately.
- [Find files later](/docs/file-search) — make filenames useful in Finder, File Explorer, and system search.

## Set up your filenames

Start with **Smart Rename**, the default naming setup. Save a separate Template when a workflow needs different names or sorting rules.

- [Templates](/docs/templates) — save a setup and use it in a batch or monitored folder.
- [Naming Blocks](/docs/naming-blocks) — combine titles, dates, sequence numbers, and file details.
- [Custom AI Blocks](/docs/custom-ai-blocks) — create a field for a detail you want AI to extract.
- [Custom prompts](/docs/custom-prompts) — guide the wording of names and tags.
- [Metadata and tags](/docs/metadata-tags) — add extra context, with different storage options on Mac and Windows.
- [Import and export Templates](/docs/template-import-export) — back up a setup or share it with another computer.

## Choose where AI runs

**Zush Cloud AI** is the starting point if you do not want to configure a provider. Choose a local mode when supported analysis content needs to stay on your computer. The AI mode is shared across workflows; it is not saved per Template or monitored folder.

- [Compare AI modes](/docs/ai-modes) — choose managed cloud, your own API key, or a local server.
- [Zush Cloud AI](/docs/zush-cloud-ai) — start without an API key or local model.
- [Your own API key (BYOK)](/docs/byok) — connect Gemini, OpenRouter, OpenAI, or Anthropic.
- [Local AI overview](/docs/local-ai) — understand local setup and limitations.
- [Ollama setup](/docs/offline-ai) — download and start Ollama, then set up a local model using Zush’s buttons.
- [LM Studio setup](/docs/lm-studio) — connect a vision-capable LM Studio model.
- [Privacy and security](/docs/privacy-security) — understand what is processed and where it goes.
