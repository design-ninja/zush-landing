Folder monitoring lets Zush watch selected folders and rename new supported files as they arrive. [Install Zush](/docs/install-update) first, then use monitoring when clutter keeps returning after every manual cleanup.

## Good folders to monitor

| Folder | Typical files |
| --- | --- |
| Downloads | PDFs, invoices, images, browser exports, archives, receipts |
| Screenshots | UI captures, support screenshots, design references, bug reports |
| iCloud or OneDrive | Synced work documents, shared assets, client files |
| Project export folders | Design exports, videos, audio, subtitles, reports |
| Camera or media imports | Photos, RAW files, screen recordings, clips |

## Set up monitoring

<Steps>
1. Open the monitoring workflow in Zush.
2. Add the folder you want to watch.
3. Choose included and excluded file types.
4. Choose a [Template](/docs/templates) for that folder, or use Smart Rename. The Template supplies its Naming Blocks, prompts, metadata, and sorting settings.
5. Check the [AI mode](/docs/ai-modes) in Settings. This mode applies across Zush, including all monitored folders.
6. Test the same Template in [AI Rename](/docs/batch-rename-files), where you can review names before applying them. Then turn monitoring on.
</Steps>

Monitor applies changes automatically; it has no review-before-rename switch. Use **Activity** to inspect completed work and [undo a change](/docs/undo-history). Keep Zush running for monitoring to process new arrivals.

## Best practices

Start with one folder. Downloads and Screenshots usually show the fastest payoff because they collect unrelated files with weak names. If you need a reusable naming setup first, create a [Template](/docs/templates).

Use exclusions for temporary files, application caches, installer folders, and formats you do not want renamed. For team folders, confirm the naming convention before you automate it.

<Aside type="caution">
A sorting-enabled Template can rename and group new files with [AI folder sorting](/docs/folder-sorting). Monitor is not a general conditional action engine for scripts, archive extraction, or uploads. Test the Template on a manual batch before enabling automatic processing.
</Aside>

## Sort new arrivals into folders

Assign a Template with [AI folder sorting](/docs/folder-sorting) enabled to rename and sort new files directly inside a monitored folder. Choose a destination, reuse suitable existing folders, and add custom folder rules. Changes apply to new files, not to files already processed.

Enable **Keep current names** in the sorting setup when you only want to move incoming files into folders.

## External drives on Mac

Zush for Mac can monitor folders on external drives and resume monitoring when a drive reconnects. A disconnected drive cannot be processed; leave the folder configured and reconnect the drive to continue.

When you select the root of an external drive, Zush watches for new files without scanning the entire drive on startup. To organize files already on the drive, add them to a manual batch in **AI Rename**.
