Zush is built for mixed folders. You can [batch rename files](/docs/batch-rename-files) from ordinary Mac and Windows folders without separating screenshots, ebooks, PDFs, photos, design files, video, and audio into different tools.

Support depends on what can be extracted from the file: visual previews, text, metadata, subtitles, transcript context, sampled frames, or compact summaries.

## Mac and Windows differences

Most listed formats work on both platforms. **Sketch, Figma, Pages, Numbers, and Keynote files are supported on Mac; they are not supported inputs in the Windows app.** Export them to a supported format such as PDF or an image before using Zush on Windows.

Format support also differs from AI capability. A local model can use available previews and text without receiving the original audio. See [Audio and video analysis](/docs/audio-video) for mode-specific behavior.

## Images and screenshots

Supported visual formats include PNG, JPG, JPEG, WEBP, AVIF, GIF, BMP, TIFF, HEIC, HEIF, SVG, PDF previews, JP2, EXR, TGA, ICO, ICNS, PBM, PGM, PPM, PFM, and common RAW formats such as CR2, CR3, NEF, ARW, DNG, ORF, RAF, RW2, PEF, SRW, SR2, and RAW.

## Documents and PDFs

Zush supports PDFs, EPUB and FB2 ebooks, plain text, Markdown, JSON, EML, CSV, TSV, LOG, XML, YAML, YML, SRT, VTT, RTF, ODT, ODS, ODP, Pages, Numbers, Keynote, Word, PowerPoint, and Excel formats.

For ebooks, Zush reads EPUB, FB2, and FB2.ZIP files and can use the book title, author, subjects, text, and cover to suggest a useful filename. Encrypted or DRM-protected ebooks may not expose enough content for analysis.

Common Office formats include DOC, DOCX, DOCM, DOTX, DOTM, PPT, PPTX, PPTM, POTX, POTM, PPSX, PPSM, XLS, XLSX, XLSM, XLTX, and XLTM.

## Design files

Supported design formats include Sketch, Figma, Illustrator, and PSD files where previews or metadata are available for analysis.

## Video and audio

Zush supports video files on Mac and Windows, including MP4, MOV, QT, M4V, MPEG, MPG, M2V, 3GP, 3GPP, 3G2, 3GP2, DV, TS, MTS, M2TS, VOB, MKV, AVI, and WMV.

Container support does not guarantee that every codec, damaged file, or protected video can be analyzed. Try representative files before processing a library.

Supported audio formats include MP3, M4A, WAV, FLAC, OGG, WEBM, and MPGA. Audio can use metadata, recognition, and transcript context when available. The [audio and video guide](/docs/audio-video) explains excerpt lengths and local-mode limits.

## Structured and text files

Zush can work with text-heavy and structured files such as TXT, Markdown, JSON, CSV, TSV, LOG, XML, YAML, YML, SRT, and VTT. These are useful for transcripts, subtitles, logs, exports, and data files that need readable names.
